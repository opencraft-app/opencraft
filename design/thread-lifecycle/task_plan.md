# 会话生命周期严格实现

## 目标
维护身份、上下文、订阅和持久化语义，实现本机 Fork/Side Chat、unsubscribe、命名与归档。

## 阶段
1. 原生接口核对、红测与设计契约 — 完成。
2. 修复 Side Chat 清理事务和迟到 unsubscribe — 完成。
3. OpenCraft 会话目录与逻辑连接订阅，接通本机 RPC — 完成。
4. DSH 原生历史分支、真实临时存储与边界注入 — 完成。
5. UI 命名/归档/Fork、事件投影和能力声明 — 完成且已验证。
6. 聚焦、真实引擎、桌面和完整门禁验收 — 完成。

## 非目标
不提交、推送、发布；不删除用户工作目录；不修改模型设置；保留当前工作树改动。

## 错误记录
- 无 context 路由，按已定位调用链有界核对。
- 原生包名为 dsh-agent/dsh-session，不是 dsh-agents/dsh-sessions；改用安装清单定位。
- 默认 YAML 含 !!js，仅读取插件 ID/配置键，不输出求值配置或凭据。
- UI 样式/Modal 类型为目录模块，并非猜测的单文件；改用精确文件清单定位，避免重复失败搜索。
- UI 探针的自定义 middleware 返回 500；改为 Vite resolve/load 虚拟模块，使用项目内完整编译路径。
- 桌面 QA 的 TSX 序列化 helper __name 不存在，按项目既有探针方式在实际 renderer 加载后补测试 helper；不改产品代码。
- 桌面空模型 fixture 借用了 DSH 私有缺省但未启用该模型，Fork 被实际能力校验拒绝；fixture 改为显式配置合成本地模型，不修改用户默认或执行推理。
