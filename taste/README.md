# OpenCraft 代码样例与评审标准

每个 Agent 在开始本仓库的任务前通读本页和下列六篇短样例。同一任务内读一遍即可。进入具体实现时继续读对应目录的 `AGENTS.md` 和专题契约。

1. [身份与权限](identity.md)
2. [会话与执行](conversation.md)
3. [存储与运行时](storage.md)
4. [界面与跨端](interface.md)
5. [插件与产品装配](extensions.md)
6. [部署与升级](deployment.md)

用下面四个问题审查受改动影响的行为。答案应当能从类型、调用链和测试里找到。

- 对象用什么标识，在哪个作用域内有效，有哪些合法状态？
- 谁批准并提交改变？其他调用方消费哪份结果？
- 并发、取消、超时和重启会改变什么？何时可以报告成功？
- 哪个用例能在破坏这条不变量时失败？外部行为通过哪条真实入口验收？

优先把规则留在现有 owner。共享抽象应有实际消费者，或有独立的生命周期需要管理。碰到存量折中时，用当前改动恢复受影响的边界，按实际风险安排后续收敛。

每篇样例只示范一个关键决策。标为「目标样例」的片段用于说明期望的建模，片段里的接口是示意。当前产品行为以链接的源码、测试和专题契约为准。
