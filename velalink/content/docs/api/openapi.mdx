# OpenAPI 与 Scalar

API 的 client-facing wire contract 只有一个来源：

```txt
public/openapi/velachat.v1.yaml
```

本地预览启动后，Scalar API Reference 位于：

```txt
/api-reference
```

## 为什么用 Scalar

MDX 文档解释架构、行为、边界和示例；OpenAPI 定义唯一的 wire-level paths、schemas、parameters、responses 和字段名；Scalar 负责把 OpenAPI 渲染成可浏览、可调试的 API reference。

## Source of truth

- 唯一 wire contract：`public/openapi/velachat.v1.yaml`
- 人读版解释：`content/docs/api/*.mdx`
- 交互式 reference：`app/api-reference/route.ts`

如果 MDX 示例、领域类型草案或内部实现类型与 OpenAPI 不一致，client-facing wire compatibility 以 OpenAPI 为准。

## Requirements

### Requirement: OpenAPI 契约必须存在

Client-facing endpoints MUST 维护 OpenAPI 3.1 文档，并以 OpenAPI 作为唯一 wire contract。

#### Scenario: mobile 生成类型

- **WHEN** mobile client 需要更新 API types
- **THEN** 它可以从 OpenAPI 生成类型

### Requirement: Scalar 跟随同一个 OpenAPI 文件

Scalar API Reference MUST 加载同一个 OpenAPI 文件。

#### Scenario: endpoint schema 改变

- **WHEN** OpenAPI 中 endpoint schema 变化
- **THEN** interactive reference 在 rebuild 后展示同一契约
