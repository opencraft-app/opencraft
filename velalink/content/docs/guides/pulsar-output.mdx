# Pulsar 输出

Pulsar 是预留集成路径，不是 v1 依赖。

## 推荐阶段

1. 只有本地 event log。
2. 本地 event log + optional canonical `EventSink`。
3. Pulsar mirror，用于 audit/analytics。
4. Pulsar ingest raw provider output。
5. Pulsar-derived canonical ledger，用于 cloud/distributed deployment。

## Requirements

### Requirement: Pulsar 不控制 v1 command

Pulsar MUST NOT 成为 v1 用户输入、权限批准、cancel 的必需路径。

#### Scenario: Pulsar 不可用

- **WHEN** Pulsar down
- **THEN** 本地 desktop/mobile 仍然能通过 daemon 控制 sessions

### Requirement: Agent output 可以镜像

Canonical agent output SHOULD 可以通过 event sink 镜像到 Pulsar。

#### Scenario: audit pipeline 开启

- **WHEN** daemon append canonical events
- **THEN** event sink 发布到 Pulsar
- **AND** client APIs 不变化
