# 用户自定义 Skills

> 🛡️ 这个目录是你的"安全区"。
> 放在这里的 `.md` 文件，**工具升级时永远不会被覆盖、删除或修改**。

## 何时使用此目录

- 你写了一些团队专属的 AI 行为规范，但又不想被工具升级冲掉
- 你修改了工具默认 skill 但担心新版升级丢失改动 → **复制到这里并改名**
- 你的项目有特殊技术栈需要 AI 遵循的额外规则

## 使用方式

直接在本目录下创建 `.md` 文件即可，文件名建议：
- `<team-name>-<purpose>.md`，例如 `mygroup-react-guideline.md`
- 避免与 `superpowers/` 和 `team-extensions/` 中的同名文件冲突

## 与其他 Skills 目录的区别

| 目录 | 来源 | 升级行为 |
|------|------|---------|
| `superpowers/` | 工具内置核心 | 升级时整体覆盖 |
| `team-extensions/` | 团队规范默认 | 升级时合并（同名覆盖） |
| `user-custom/` | **你自己写的** | **永远保留** ✅ |

## 进阶：覆盖默认 Skill

如果你想"覆盖"工具默认 Skill 的行为而非完全替代，可以创建同名文件：
例如想自定义 `cr-check.md` 的部分规则，把 `team-extensions/cr-check.md` 复制到本目录并修改即可。
AI 工具会优先读取 `user-custom/` 中的同名文件。
