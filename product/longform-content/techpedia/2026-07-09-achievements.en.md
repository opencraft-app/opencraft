# Introducing Achievements: Your Hermes Agent Now Earns Its Own Badges

[RECOMMEND ADD IMAGE: The Achievements page in the LightVela console — a grid of achievement cards with icons, progress bars, and tier badges (a few unlocked in bright color, a few grayed-out "discovered" ones with partial progress, and one or two mystery "secret" cards) — so readers see right away it feels like a game progression screen.]

LightVela is a [cloud-hosted personal AI agent platform](https://lightvela.ai/docs/overview) where you build and run a Hermes Agent — an always-on AI assistant that connects to channels like Telegram, WhatsApp, and Discord, uses skills, and remembers things over time. The longer you use it, the more your agent actually *does*: it runs tools, edits files, searches the web, recovers from errors, switches models. Until now, all of that activity quietly disappeared into session history.

The new **Achievements** feature turns that history into something you can see and enjoy. Open the Achievements page and your Hermes Agent has its own collection of badges — earned from real things it really did. It's a progress screen for your agent, not for you to grind.

## What Is the Achievements Page?

It's a dedicated page in your LightVela console that shows every achievement tied to your Hermes Agent: what's been unlocked, what's in progress, and what's still hidden. Each achievement is a small card with an icon, a name, a short description, a progress bar, and — once earned — a tier badge and the moment it was unlocked.

[RECOMMEND ADD IMAGE: A single achievement card close-up — icon on the left, name and description, a progress bar reading something like "412 / 500", and a tier badge like "Gold" on the right — so readers see how one achievement tracks a concrete behavior.]

Every achievement has a plain-language "counting rule" you can expand, so it's never a black box. For example, an achievement about reading logs is earned by genuinely inspecting logs across sessions; one about web research is earned by extracting real web content. The page also shows four summary tiles at the top — unlocked count, discovered (in-progress) count, secret count, and your highest tier reached.

## Why It Matters

Two things change when an agent's history becomes visible.

First, it gives the agent a **sense of progression**. A Hermes Agent isn't a one-shot chat — it's a long-running assistant you keep coming back to. Achievements make that longevity tangible: the more deeply you and your agent work together, the more the page fills in. It's a quiet way of saying "this agent has been around, and it's gotten good at certain things."

Second, it's a **map of what your agent has actually been doing**. Because every achievement is tied to a real category of behavior, scanning the page tells you where your agent spends its energy — heavy on web research, light on memory, big on terminal commands, or whatever your real usage looks like. It doubles as a usage dashboard you didn't have to set up.

## How It Works

You don't do anything extra. The Achievements page reads your Hermes Agent's own session history and recognizes the behaviors that match each achievement.

- **Pick your agent** in the console and open its Achievements page. (Achievements are one section of the agent workbench — the rest of the agent setup lives in the [configuration docs](https://lightvela.ai/docs/configuration).)
- **Browse by status or category.** Filter to see only unlocked, in-progress ("discovered"), or hidden ("secret") achievements, or filter by category like tool mastery, research, or model usage.
- **Re-scan anytime.** A refresh button re-reads the latest history, so newly earned achievements show up after a session.

[RECOMMEND ADD IMAGE: The filter bar with the status dropdown (All / Unlocked / Discovered / Secret) and category dropdown open, plus the four summary stat tiles above it — so readers see how to slice and navigate a large collection.]

Each achievement comes in tiers — Copper, Silver, Gold, Diamond, and Olympian (大师) — so the same behavior scales from "you did it" to "you did it *a lot*." Progress bars show how far the next tier is, so there's always a clear next step. You can even pair this with scheduled [automations](https://lightvela.ai/docs/configuration/automation) — a recurring task that runs daily will quietly chip away at the long-running-process achievements while you sleep.

## What You Can Do With It

- **Watch your agent's personality emerge.** Use it heavily for coding and you'll unlock terminal, patch, and testing achievements. Use it for research and the web-research line fills up. The unlocked grid becomes a portrait of how *this* agent works.
- **Spot gaps you might want to fill.** If the memory achievements are all empty, maybe your agent hasn't been writing things down — a good nudge to revisit memory and [skills](https://lightvela.ai/docs/configuration/skill).
- **Enjoy the flavor.** The achievement names aren't corporate — they're written with a wink ("重启大法好", "3000 端口又被占了", "失之毫厘"). Half the fun is discovering what each one is really about.
- **Track long-term growth.** Because tiers scale with real usage volume, your Olympian-tier badges become a genuine record of how much your agent has grown into its role.

## What Comes Next

This is the first version of Achievements: a read-only progression screen that reflects real agent behavior. The direction is clear — as Hermes Agents do more (and as new skills and capabilities ship), the achievement catalog grows with them, giving your agent an ever-richer story of what it's become.

If you already have a Hermes Agent you use regularly, open its Achievements page, hit re-scan, and see which badges it's already quietly earned. New to LightVela? Spin one up in the [quickstart](https://lightvela.ai/docs/quickstart) and start earning.
