# Introducing 成就：你的 Hermes Agent 现在能挣自己的徽章了

[RECOMMEND ADD IMAGE: LightVela 控制台里的成就页 —— 一整面成就卡片墙，带图标、进度条和等级徽章（几张已解锁的亮色卡片、几张有部分进度的灰色「已发现」卡片，再加一两张神秘「隐藏」卡片）—— 让读者一眼看出这就像一张游戏进度墙。]

LightVela 是一个[云端托管的个人 AI Agent 平台](https://lightvela.ai/zh-sg/docs/overview)，你在这里搭建并运行一个 Hermes Agent——一个常驻在线、能接到 Telegram、WhatsApp、Discord 等频道的 AI 助手，它会用各种技能，还会长期记住事情。你用得越久，你的 Agent 做的事就越多：跑工具、改文件、搜网页、从报错里自我恢复、切换模型。只不过在这之前，这些活动都悄悄消失在了会话历史里。

新上线的**成就**功能，把这段历史变成了看得见、玩得起的东西。打开成就页，你的 Hermes Agent 自带一整面徽章墙——而且每一个徽章，都对应它真的做过的事。这是属于你 Agent 的进度墙，不是要你去刷的。

## 什么是成就页？

它是你 LightVela 控制台里的一个专属页面，展示和这个 Hermes Agent 绑定的所有成就：哪些解锁了、哪些有进度、哪些还藏着。每个成就是一张小卡片，上面有图标、名字、一句话说明、一根进度条，解锁之后还会显示等级徽章和解锁时间。

[RECOMMEND ADD IMAGE: 单张成就卡片的近景 —— 左侧图标，名字和说明，进度条显示类似「412 / 500」，右侧是一枚「金」的等级徽章 —— 让读者看到单个成就怎么追踪一个具体行为。]

每张卡片都能展开看一段大白话的「计数规则」，绝不黑箱。比如和「读日志」相关的成就，是 Agent 真的在多个会话里去查看了日志才解锁；和「网页研究」相关的成就，是真的提取过网页内容。页面顶部还有四块汇总统计——已解锁数、已发现（有进度）数、隐藏成就数，以及你目前达到的最高等级。

## 为什么它重要

当 Agent 的历史变得可见之后，有两件事变了。

第一，它给了 Agent **成长的实感**。Hermes Agent 不是一次性的聊天，而是一个你会反复回来的长期助手。成就页把这种「长久」变成了看得见的东西——你和你的 Agent 越深入地一起干活，这面墙就越丰富。它在悄悄说：「这个 Agent 已经陪了你一阵子，并且在某些事情上越来越熟练了。」

第二，它是一张**「你的 Agent 到底在做什么」的地图**。因为每个成就都绑着一个真实的行为类别，扫一眼这面墙，你就能看出你的 Agent 把精力花在哪——网页研究多、记忆用得少、终端命令跑得多，还是别的什么。它顺带就是一张你不用自己搭的使用画像。

## 它是怎么工作的

你不用额外做任何事。成就页读取的是你 Hermes Agent 自己的会话历史，识别出和每个成就匹配的行为。

- **选你的 Agent**，打开它的成就页。（成就只是 Agent 工作台里的一个板块，其余配置见[配置文档](https://lightvela.ai/zh-sg/docs/configuration)。）
- **按状态或分类浏览**。可以只看已解锁、有进度（「已发现」）或隐藏（「secret」）的成就，也可以按分类筛选，比如工具使用、研究网页、模型相关等。
- **随时重新扫描**。点一下刷新按钮就会重新读取最新历史，刚跑完一场会话新解锁的成就会立刻出现。

[RECOMMEND ADD IMAGE: 筛选栏 —— 状态下拉框（全部 / 已解锁 / 已发现 / 隐藏）和分类下拉框打开的样子，上方是四块汇总统计瓦片 —— 让读者看到面对一整面成就时怎么切片浏览。]

每个成就还分等级——铜、银、金、钻石、大师——所以同一个行为会从「你做到了」一路升级到「你做到了很多」。进度条会显示离下一档还差多少，永远有一个明确的下一步。你甚至可以把它和定时[自动任务](https://lightvela.ai/zh-sg/docs/configuration/automation)搭配：一个每天跑的周期任务，会趁你睡觉时悄悄推进那些「长时间运行」相关的成就。

## 你可以用它做什么

- **看你的 Agent 性格长出来**。重度用于写代码，终端、补丁、测试类的成就就会解锁；重度用于研究，网页研究的这一条线就会涨起来。解锁墙最终会变成「这个 Agent 怎么干活」的一幅画像。
- **发现自己想补的空白**。如果记忆类成就一直空着，可能说明你的 Agent 还没好好把事情记下来——这就提醒你去回顾一下记忆和[技能](https://lightvela.ai/zh-sg/docs/configuration/skill)。
- **享受其中的趣味**。成就名字一点都不一本正经——它们写得有点皮（「重启大法好」「3000 端口又被占了」「失之毫厘」）。发现的乐趣，有一半就在搞清楚每个成就到底在说什么。
- **追踪长期成长**。因为等级跟着真实用量走，那些「大师」级的徽章，就是你 Agent 在这个角色里长了多少的真记录。

## 接下来会怎样

这是成就功能的第一个版本：一面只读的进度墙，如实反映 Agent 的真实行为。方向很清楚——随着 Hermes Agent 能做的事越来越多（随着新技能、新能力上线），成就目录也会跟着长，让你的 Agent 拥有一段越来越丰富的「它变成了什么样」的故事。

如果你已经有一个在用的 Hermes Agent，打开它的成就页，点一下重新扫描，看看它已经悄悄解锁了哪些徽章。刚接触 LightVela？可以跟着[快速上手](https://lightvela.ai/zh-sg/docs/quickstart)建一个，开始你的第一枚徽章。
