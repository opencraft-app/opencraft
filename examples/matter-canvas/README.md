# 事项画布原型

一个不依赖构建的 HTML 原型：打开一件事，先看懂现在差什么、谁在办、要不要自己出手；想多看一层，再去看 Bot 的手机往来、电脑材料和「现场」。

直接用浏览器打开 `index.html` 即可，电脑和手机都能用。所有执行都是本地模拟，进度和设置存在浏览器的 localStorage 里。

| 文件 | 负责 |
|---|---|
| `scenario.js` | 场景 DSL：36 位 Bot、联系方式、发送许可和三个事项 |
| `engine.js` | 运行时：读取 DSL，按「满足发送条件 → 发出 → 送达 → 接收方处理 → 校验 → 交付 → 验收」产生事件，状态由事件归并得到；不依赖 DOM |
| `app.js` / `styles.css` | 画布、事项卡、手机与电脑抽屉、演示驱动 |
| `engine.test.mjs` | 交付验收对应的引擎测试：`node --test examples/matter-canvas/engine.test.mjs` |

这是独立原型，界面文案直接写在源码里，没有接入 Workbench 的国际化、设计系统和真实的 Bot、沙盒或 Hub。画布编辑、用消息示例训练 Bot 和三维视图尚未实现。
