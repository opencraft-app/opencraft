# 事项画布原型

一个不依赖构建的 HTML 结构原型：老板管一群 Bot 的工具，版式照聊天应用，一次只看一屏。产品规格见 [OpenCraft Agent 公司：产品规格](https://claude.ai/artifact/A6P4C4qMKGZ5Wrk82HHAXD)（私有链接，需作者分享）。

它没有接真实的 Bot，也没有任何东西会自己往前走。打开时带一份示例内容，是一张静态快照，全部按老板会看到的样子写：他派出去的事、员工之间说的话、交到他手里的东西。在「事情」页底部可以清空；清空后各处如实显示为空，并说明接通后那里会出现什么。

- **员工**（首页）：一列员工，像聊天列表。事情从人开始：先选一位，进入和他的对话，对他说要办什么，说出去的那句话就是一件交给他的事。对话里能看到派过的事和他的回话。右上角进他的名片，按四个问题组织：手机下面是「他在联系谁」和「他能联系谁」；电脑下面是「他在做什么」和「他能做什么」（分配一台电脑、一个云环境、若干连接器，都由老板先登记再分配）。另有岗位和岗位提示。
- **事情**：所有派出去的事的总览，没有添加入口，也没有「待分配」。分「要我出手的」（等我验收）和「别人在办的」，结束的收进「已结束」。点进去是状态、要我看的东西和确认或退回、负责人、子事情、经过；可以换负责人、打勾或取消。
- **动态**：谁对谁说了什么、谁交出了什么、老板自己做过的操作，按时间倒序。

直接用浏览器打开 `index.html` 即可，电脑和手机都能用。数据存在浏览器的 localStorage 里。
