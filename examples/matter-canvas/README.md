# 事项画布原型

一个不依赖构建的 HTML 原型，只有一组概念：一件事，几个 Bot，每个 Bot 有一台电脑和一部手机。消息从手机发到手机，对方收到后电脑才开始干活并产出材料。

直接用浏览器打开 `index.html` 即可，电脑和手机都能用。所有执行都是本地模拟，进度存在浏览器的 localStorage 里。

| 文件 | 负责 |
|---|---|
| `scenario.js` | 场景数据：Bot、联系方式和三个事项的步骤 |
| `engine.js` | 运行时：按「发出 → 送达 → 接收方处理 → 校验 → 交付 → 验收」产生事件，状态由事件归并得到；不依赖 DOM |
| `app.js` / `styles.css` | 界面：画布上的 Bot、电脑和手机，底部一行说明和操作 |
| `engine.test.mjs` | 引擎测试：`node --test examples/matter-canvas/engine.test.mjs` |

界面只用到引擎的一部分。发送许可、电脑开关、交付前的叮嘱、留下帮手和多轮事项仍在引擎里并有测试，但界面上没有入口。这是独立原型，文案直接写在源码里，没有接入 Workbench 的国际化、设计系统和真实的 Bot。
