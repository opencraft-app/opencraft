# OpenCraft 办公室（原型）

老板管理 Bot 员工的结构原型。直接用浏览器打开 `index.html`（需要联网加载 three.js 和 GSAP）。

结构是微信那一套：底部三个标签，点进去是整页，左上角返回。

- 消息：老板自己的手机。直接归你管的人的对话列表，有东西等你看的排在最前；右上角「招募」。
  点进去是对话：对他说要办什么；他交上来等你看的东西在这里回「可以」或「退回」。
- 通讯录：所有员工和公司外的人，「招募新员工」在最上面。点进去是员工资料，三个页签：
  - 手机：他在联系谁（聊天记录只读）、他能联系谁（勾选）。
  - 电脑：他在做什么、他能做什么（分配电脑、云环境、连接器）。
  - 岗位：名字、岗位、归谁管、岗位提示。
- 办公室：三维画面，只占这一个标签。每个小家伙一张桌、一台电脑、一部手机；拱门外是公司外的人。
  座位按「能联系谁」自动聚堆。不点人时没有任何线；点一个人，地上的细线是他归谁管、管着谁，
  升起的弧线是他能联系谁，底部卡片可以进对话或资料。单指拖动、双指缩放（电脑上用滚轮）可以凑近看。

没有接真实的 Bot：发出去的话不会有人回，示例内容是静态快照，可以清空。数据存在浏览器本地。

文件：`scene.js` 三维办公室，`app.js` 数据和页面，`styles.css` 样式。`visions.html` 是之前比较视觉方向的草图。
