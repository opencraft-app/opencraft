# OpenCraft 办公室（原型）

老板管理 Bot 员工的结构原型。直接用浏览器打开 `index.html`（需要联网加载 three.js 和 GSAP）。

电脑宽屏时和微信桌面版一样，左边列表、右边对话或资料。

结构和观感都按微信：灰色导航栏居中标题、白色通栏列表、圆角方头像、绿色带尾巴的气泡，底部三个标签，点进去是整页，左上角返回。

- 消息：老板自己的手机。直接归你管的人的对话列表，有没看的消息排在最前、带红点（和微信一样就是未读）；右上角 ⊕ 招募。
  招募时点一个常见岗位，就填好岗位和一段岗位提示，名字也预先给好；招来后直接进他的对话。
  后来改归别人管的人，以前的对话还留在这里，只能看，不能再交办新事。
  点进去是对话：对他说要办什么。没有专门的验收按钮，你直接回话。
  他做事留下的副作用（订了会议室、开了账号、在网盘新建或改了文件）会作为卡片跟在他的话后面，卡片标出是用哪个工具做的。
- 通讯录：所有员工和公司外的人，「招募新员工」在最上面。点进去是员工资料，三个页签：
  - 手机：他在联系谁（包括和你的对话，聊天记录只读）、他能主动联系谁、谁能主动联系他。
    联系是单向的：勾上他才能主动找对方，对方能不能找他要在对方那边勾。上级和直接下属总能互相联系，不用勾。
    取消勾选后，以前的聊天还在，标「现在不能联系」。
  - 电脑：他在做什么；他留下的改动（所有副作用，不一定是交给谁的）；电脑、云环境、连接器各一组，每组一句话说明是什么，可以从已有的里选，也可以就地添加一个新的给他。
  - 岗位：名字、岗位、归谁管、岗位提示。
- 办公室：三维画面，只占这一个标签。每个小家伙一张桌、一部手机；分配了电脑或云环境的，桌上才有电脑。拱门外是公司外的人。你是老板不是员工，没有工位。
  座位按「能联系谁」自动聚堆。不点人时没有任何线；点一个人，地上的细线是他归谁管、管着谁，
  彩色箭头弧线是他能主动找的人，灰色箭头弧线是能主动找他的人，底部卡片可以进对话或资料。名字旁的绿方块是他最近一小时在外面动过的工具（副作用），卡片上有一行写他最后动了什么。
  点人时镜头自动把他和跟他有箭头的人框进画面。单指拖动、双指缩放（电脑上用滚轮）可以凑近看。

没有接真实的 Bot：发出去的话不会有人回，示例内容是静态快照，可以清空。数据存在浏览器本地。

文件：`scene.js` 三维办公室，`app.js` 数据和页面，`styles.css` 样式。`visions.html` 是之前比较视觉方向的草图。
