# 事项画布原型

一个不依赖构建的 HTML 原型：老板的两个界面，版式照聊天应用，一次只看一屏。

- **事情**：待办跟着事情走。每件事有一个负责人，没有负责人的事要先分配。点进一件事能看到现在差什么、负责人、进度、参与的人和交出的材料；轮到老板时，按钮就在最上面。
- **员工**：每个 Bot 有岗位和一段可以修改的岗位提示，下面是他负责的事、他的手机（聊天记录）和电脑（做过的事）。

直接用浏览器打开 `index.html` 即可，电脑和手机都能用。全部是本地模拟，进度、负责人和岗位提示存在浏览器的 localStorage 里。

| 文件 | 负责 |
|---|---|
| `scenario.js` | 场景数据：Bot、联系方式和三件事的步骤 |
| `engine.js` | 运行时：按步骤产生事件，状态由事件归并得到；不依赖 DOM |
| `app.js` / `styles.css` | 界面：事情、员工、通讯录三个标签和它们的下级页面 |
| `engine.test.mjs` | 引擎测试：`node --test examples/matter-canvas/engine.test.mjs` |

岗位提示目前只是保存和展示的文字，不会改变模拟的结果。文案直接写在源码里，没有接入 Workbench 的国际化和设计系统。
