# OpenCraft 办公室（原型）

老板管理 Bot 员工的结构原型。直接用浏览器打开 `index.html`（需要联网加载 three.js 和 GSAP）。

- 上面是三维办公室：每个小家伙一张桌、一台电脑、一部手机；拱门外是公司外的人。
  不点人时办公室里没有任何线。点一个人：地上的细线是他「归谁管、管着谁」，升起的弧线是「他能联系谁」。
  座位不是摆的：能互相联系的人自动坐得近。
  单指拖动、双指缩放（电脑上用滚轮）可以凑近看，画面按屏幕像素重画，不会糊。
- 下面（宽屏在右边）是面板：点谁就打开谁，四个页签。
  - 对话：对他说要办什么；他交上来等你看的东西在这里回「可以」或「退回」。只能对直接归你管的人说。
  - 手机：他在联系谁（聊天记录只读）、他能联系谁（勾选后他会自己换座位）。
  - 电脑：他在做什么、他能做什么（分配电脑、云环境、连接器）。
  - 岗位：名字、岗位、归谁管、岗位提示。

没有接真实的 Bot：发出去的话不会有人回，示例内容是静态快照，可以清空。数据存在浏览器本地。

文件：`scene.js` 三维办公室，`app.js` 数据和面板，`styles.css` 样式。`visions.html` 是之前比较视觉方向的草图。
