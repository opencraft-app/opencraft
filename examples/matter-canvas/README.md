# 事项画布原型

一个不依赖构建的 HTML 原型：老板看员工。一列员工（Bot），点进去是这个人，再往里是他的手机（聊天记录）和电脑（做过的事和交出的材料）。版式照聊天应用，一次只看一屏。

直接用浏览器打开 `index.html` 即可，电脑和手机都能用。页面打开时用引擎把「周五版本交付」跑完一遍，展示的就是跑完后的数据；全部是本地模拟。

| 文件 | 负责 |
|---|---|
| `scenario.js` | 场景数据：Bot、联系方式和事项步骤 |
| `engine.js` | 运行时：按步骤产生事件，状态由事件归并得到；不依赖 DOM |
| `app.js` / `styles.css` | 界面：员工列表 → 员工 → 手机 / 电脑 |
| `engine.test.mjs` | 引擎测试：`node --test examples/matter-canvas/engine.test.mjs` |

界面只读，也只用到引擎的一小部分；逐步播放、发送许可、校验返工、另外两个场景等仍在引擎和场景数据里并有测试，但界面上没有入口。文案直接写在源码里，没有接入 Workbench 的国际化和设计系统。
