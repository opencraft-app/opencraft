# OpenCraft Bot 手机（最小 demo）

整个 demo 只讲一句话：

> 每个人都有一部手机：手机里有谁（或哪个群），就能找谁（或在哪个群里说话）。Bot 还有一台电脑：电脑上有什么，就能用什么。人和 Bot 都一样。

直接用浏览器打开 `index.html`。办公室视图需要联网加载 three.js 和 GSAP，列表不需要。

## 名词

- **成员**：你、Bot、同事都是成员，都有一部手机。Bot 另外有一台电脑。头像一眼能分开：Bot 是带眼睛的圆角方块，人是圆的剪影，你是深色的。
- **公司外的人**：只是某个人手机里的联系人，没有自己的手机。
- **群聊**：也只是能放进手机里的一个条目。谁的手机里有这个群，谁就在群里；拉人进群就是往他手机里放这个群。头像是成员头像拼成的格子。

没有上下级、没有禁用、没有通讯录标签，也没有单独的群权限。

## 页面

- **首页是你的 Inbox**：大标题，搜索框和「+」，下面两个小标签。
  - 对话：你手机里的人、Bot 和群，按最近一句排，正在做事的 Bot 名字旁有个绿点。不在你手机里的 Bot 不出现，底部指向「成员」。
  - 成员：所有 Bot（写着正在做什么或空闲，右边直接「加入 / 移出」你的手机）、同事、公司外的人，以及公司的东西。每行第二行是反方向：谁能找他、谁能用它。
  - 「+」：新 Bot 或新群聊。搜索只隐藏不匹配的行；对话里找不到时提示去「成员」找。
- **一个 Bot**：名片、和你的对话、他的手机和他的电脑（两张对称卡片，宽时并排）。手机里“你”永远排第一个，也可以有同事和群；卡片底部写着谁能找他。电脑最上面是正在做的事，可以停下；拿走他正在用的东西，手上的事也会停。点一样东西看还有谁能用它。
- **一个人、一个群或一样东西**：分「能」和「不能」两组，每行直接给他或移除。群的这一页就是群成员。
- **对话**：和 Bot 的对话页右上角能打开他的手机和电脑；群聊页底部「群成员」。看两个人的聊天是只读的，底部分两句写清两个方向。

所有说法只用一种句式，主语在前：「谁 能找 谁」「谁 在 哪个群里」「谁 能用 什么」。单向关系最容易被当成双向，所以方向总是写成一句完整的话，不换说法。
所有改动一点就生效，底部浮出一行**结果**（“沐川现在用不了公司网盘了”“苏禾现在在「2.3 交付」里了”），可以撤销，不弹确认（删掉 Bot 也一样）。

## 验收

把上面那句话告诉一个没看过的人，然后让他做这几件事，能不问问题一次做对：

1. 让阿岚能找客户（成员 → 客户周姐 → 阿岚「给他」；或打开阿岚 → 他的手机 → 添加）。
2. 不让沐川用公司网盘（成员 → 公司网盘 → 沐川「移除」；或打开沐川 → 他的电脑）。
3. 看小折在干什么（成员里小折那一行）。
4. 把苏禾拉进「2.3 交付」群（对话 → 2.3 交付 → 群成员 → 拉进群）。

界面细节按产品标准做：图标几何取自 `@opencraft/design-system` 的 action-artwork；焦点环只在键盘操作时出现，用中性色，触摸后不画；触摸设备上按钮和图标命中区域至少 36–44px；手机上进出页面有方向一致的滑入，减少动态效果时关闭；对话里别人的消息带头像和气泡，隔二十分钟插一个时间，同一个人连续的消息合在一起。

样式用 OpenCraft 设计系统的语义名（`--color-text`、`--color-background-button-primary` 等），数值取自默认中性主题，浅色和深色都有。
宽屏时 Inbox 在左，右边默认打开最近的对话。没有接真实的 Bot，你发出去的话不会有人回；数据存在浏览器本地，首页底部可以恢复示例。
