# OpenCraft Bot 手机（最小 demo）

整个 demo 只讲一句话：

> 每个人都有一部手机：手机里有谁（或哪个群），就能找谁（或在哪个群里说话）。Bot 还有一台电脑：电脑上有什么，就能用什么。人和 Bot 都一样。

直接用浏览器打开 `index.html`。办公室视图需要联网加载 three.js 和 GSAP，列表不需要。

## 名词

- **成员**：你、Bot、同事都是成员，都有一部手机。Bot 另外有一台电脑。头像一眼能分开：Bot 是对话气泡，尾巴在右下（朝着他自己说的话），眼睛是两条竖的胶囊；人是写着名字第一个字的圆形，你是深色的。Bot 有三种状态，画在同一个地方：空闲看着你；正在做事眼睛往下看（看电脑），右上角绿点；需要你时右上角琥珀色点。三个点只表示“正在输入”，所以不用来表示忙。
- **公司外的人**：只是某个人手机里的联系人，没有自己的手机。
- **群聊**：也只是能放进手机里的一个条目。谁的手机里有这个群，谁就在群里；拉人进群就是往他手机里放这个群。头像是成员头像拼成的格子。

没有上下级、没有禁用、没有通讯录标签，也没有单独的群权限。

## 页面

- **首页是你的 Inbox**：大标题，搜索框和「+」，下面两个小标签。
  - 对话：你手机里的人、Bot 和群。有 Bot 等你拍板的对话排在最前，带琥珀色的「需要你」，消息里也标着“等你回复”；你在那里回话，问题就算答了。Bot 只能在找得到你的地方问你（示例里小折不在你手机里，所以他在群里问）。其余按最近一句排。一对一的对话不画头像，页头已经说了是谁。没读的消息在时间下面标数字，标签上也有总数；正在做事的 Bot 名字旁有个绿点。不在你手机里的 Bot 不出现，底部指向「成员」。
  - 成员：所有 Bot（写着正在做什么或空闲，右边直接「加入 / 移出」你的手机）、同事、公司外的人，以及公司的东西。每行第二行是反方向：谁能找他、谁能用它。
  - 「+」：新 Bot 或新群聊。
- **办公室**：Inbox 右上角的立方体。同一批人放在一个三维办公室里，长相和列表头像对得上：颜色相同；Bot 是同一个对话气泡，面前有桌子和电脑，正在做事时眼睛变成三个绿点、屏幕亮绿色；同事是圆的，没有桌子；公司外的人站在门边的小台子上。点一个人，深色箭头是他能找的人，浅灰箭头是能找他的人，底部卡片写着他能找几个人、能用几样东西、几个人能找他，并能直接发消息或打开他的手机和电脑。宽屏时办公室在右边，Inbox 留在左边。Esc 先取消选择，再退出。搜索只隐藏不匹配的行；对话里找不到时提示去「成员」找。
- **一个 Bot**：名片、和你的对话、他的手机和他的电脑（两张对称卡片，宽时并排）。手机里“你”永远排第一个，也可以有同事和群；卡片底部写着谁能找他。电脑最上面是正在做的事，可以停下；拿走他正在用的东西，手上的事也会停。点一样东西看还有谁能用它。
- **一个人、一个群或一样东西**：分「能」和「不能」两组，每行直接给他或移除。群的这一页就是群成员。
- **对话**：和 Bot 的对话页右上角能打开他的手机和电脑；群聊页底部「群成员」。看两个人的聊天是只读的，底部分两句写清两个方向。

所有说法只用一种句式，主语在前：「谁 能找 谁」「谁 在 哪个群里」「谁 能用 什么」。单向关系最容易被当成双向，所以方向总是写成一句完整的话，不换说法。
所有改动一点就生效，底部浮出一行**结果**（“沐川现在用不了公司网盘了”“苏禾现在在「2.3 交付」里了”），可以撤销，不弹确认（删掉 Bot 也一样）。

## 验收

把上面那句话告诉一个没看过的人，然后让他做这几件事，能不问问题一次做对：

1. 让阿岚能找客户（成员 → 客户周姐 → 阿岚「给他」；或打开阿岚 → 他的手机 → 添加）。
2. 不让沐川用公司网盘（成员 → 公司网盘 → 沐川「移除」；或打开沐川 → 他的电脑）。
3. 看小折在干什么（成员里小折那一行）。
4. 把苏禾拉进「2.3 交付」群（对话 → 2.3 交付 → 群成员 → 拉进群）。

界面细节按产品标准做：图标几何取自 `@opencraft/design-system` 的 action-artwork；焦点环只在键盘操作时出现，用中性色，触摸后不画；触摸设备上按钮和图标命中区域至少 36–44px；手机上进出页面有方向一致的滑入，减少动态效果时关闭；对话里别人的消息带头像和气泡，隔二十分钟插一个时间，同一个人连续的消息合在一起。状态点静止不闪；鼠标设备上头像的移除按钮悬停才出现，触摸设备一直显示；输入为空时发送和创建按钮不可点；Esc 返回上一层；内容滚到页头下面时出现一条细线。

样式用 OpenCraft 设计系统的语义名（`--color-text`、`--color-background-button-primary` 等），数值取自默认中性主题，浅色和深色都有。
宽屏时 Inbox 在左，右边默认打开最近的对话。没有接真实的 Bot，你发出去的话不会有人回；数据存在浏览器本地，「成员」最下面可以恢复示例。
