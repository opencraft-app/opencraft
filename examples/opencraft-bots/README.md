# OpenCraft Bot 手机（最小 demo）

整个 demo 只讲一句话：

> 你有几个 Bot。每个 Bot 有一部手机和一台电脑：手机里有谁，他就能找谁；电脑上有什么，他就能用什么。你也一样，只能找你手机里的 Bot。

直接用浏览器打开 `index.html`（办公室视图需要联网加载 three.js 和 GSAP，没有网时列表照常能用）。
前两版原型在 `../matter-canvas/` 和 `../opencraft-office/`，保持不动。

## 页面

- **首页就是你的手机**：最上面是三条规则；下面分两组，「在你手机里」和「不在你手机里」，每行写他正在做什么或空闲，右边直接「移出 / 加入」。右上角可以切到「办公室」，看的是同一批人，箭头指向他手机里的人。电脑宽屏时首页在左，右边默认打开第一个 Bot。
- **点开一个 Bot**：一页从上到下，没有页签。
  - 名片：头像、名字、岗位、正在做什么；右边「发消息」，他不在你手机里时是「加到我的手机」。
  - 和你的对话：最近两句，点开是完整对话。
  - 他的手机 / 他的电脑：两张对称的卡片，各带那条规则，宽时并排。
    手机是一排头像，右上角 × 移除，「添加」在最后；点“你”打开你们的对话，点别人看他俩的聊天（只读），底部说清两个方向：他能不能找对方、对方能不能找他。
    电脑最上面是正在做的事（可以停下），下面是能用的东西，每样「移除」；拿走正在用的那样，手上的事也会停。空着时写明“他现在只能聊天”。
- 新 Bot：手机里先只有你，电脑上什么都没有。

所有改动一点就生效，底部浮出一行提示可以撤销，不弹确认（删掉 Bot 也一样）。
公司外的人只是某个 Bot 手机里的联系人，带“公司外”小标签。没有通讯录标签、没有上下级、没有禁用、没有页签。

## 验收

把上面那句话告诉一个没看过的人，然后让他做三件事，能不问问题一次做对：

1. 让阿岚能找客户（打开阿岚 → 他的手机 → 添加 → 客户周姐）。
2. 不让沐川用公司网盘（打开沐川 → 他的电脑 → 公司网盘 → 移除）。
3. 看小折在干什么（首页小折那行，或打开小折看电脑最上面）。

样式用 OpenCraft 设计系统的语义名（`--color-text`、`--color-background-button-primary` 等），数值取自默认中性主题，浅色和深色都有。
宽屏时首页在左、打开的页面在右。没有接真实的 Bot，你发出去的话不会有人回；数据存在浏览器本地，首页底部可以恢复示例。
