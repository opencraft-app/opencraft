# OpenCraft 新办公室（原型）

按精简后的模型重做的一版。旧原型在 `../matter-canvas/`，保持不动，方便对照。
直接用浏览器打开 `index.html`（需要联网加载 three.js 和 GSAP）。

## 模型

四个名词：

- **人**：你、员工、公司外的人。三种人点进去是同一种资料页。你也在通讯录里，和员工用同一种资料页，只是没有岗位和工具；你的资料页只有“你能联系谁”，你和谁聊过在「消息」里。
- **对话**：两个人之间的消息。你的「消息」页就是你的手机；员工资料里的「他在联系谁」是他的手机，是同一个视图。
- **工具**：他能用的电脑、云环境和账号，一张清单，每样都可以禁用或删除。改动会标出是用哪个工具做的。
- **改动**：员工用工具在外面做的事，比如订会议室、开账号、在网盘新建文件。做了就是做了，不能撤回。

只有一种关系：

- **能联系谁**：单向，在每个人的「联系」里直接勾，对公司里的人和公司外的人都一样。没有上下级。
  招人时默认你和他互相能联系。你是老板，所有人的设置你都能改。

## 页面

观感按 OpenCraft 工作台：中性的黑白灰，Inter 字体，细边框圆角卡片和淡分隔线，深色主按钮、淡灰次按钮。
颜色、字号和圆角用设计系统的语义名（`--color-text`、`--color-background-button-primary` 等），数值取自默认中性主题，深色模式用主题引擎算出的深色值。
电脑宽屏：左边侧栏（消息、通讯录、办公室和员工名单），右边列表和详情左右排。手机：底部三个标签，点进去是整页，左上角返回。

- 消息：你的对话。有没看的消息排在最前；右上角招募。还不能联系的人，对话页会说在哪里添加。
- 通讯录：招募、添加公司外的人、你、员工、公司外的人。
- 点一个员工，打开他的页面：顶部是头像、名字和岗位，点名字打开「关于他」（名字、岗位、做事说明、让他离开）；右上角「发消息」。
  下面「通讯录 / 电脑」分段切换，只管两件事：
  - 通讯录：他能联系谁（单向）。按最近聊天排序，每人下面是最后一句话，这就是他在联系谁。
    每行右边直接有「禁用/启用」和「删除」，不用滑动也不用悬停。禁用的人还在通讯录里，只是暂时联系不上。
    点一个人看他们的聊天记录（只读），底部有“允许联系”的开关。列表标题旁「添加联系人」。
  - 电脑：他能用的东西。电脑、云环境、账号一样一行，右边同样是「禁用/启用」和「删除」，列表标题旁「添加」给他一样（公司已有的或登记新的）。
    正在用的那样排在最前，下面写“正在：……”。点进去看他用它做过的改动，正在做的事可以让他停下。
- 办公室：三维画面。箭头是他能联系的人；名字旁的绿方块是他最近一小时用过的工具。

删除、停下这类收不回的操作在原位点两下确认，不弹窗（发布页面里浏览器的确认框不会出现）。

没有接真实的 Bot：发出去的话不会有人回，示例内容是静态快照，可以清空。数据存在浏览器本地。
