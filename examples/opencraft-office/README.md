# OpenCraft 新办公室（原型）

按精简后的模型重做的一版。旧原型在 `../matter-canvas/`，保持不动，方便对照。
直接用浏览器打开 `index.html`（需要联网加载 three.js 和 GSAP）。

## 模型

四个名词：

- **人**：你、员工、公司外的人。三种人点进去是同一种资料页。你也在通讯录里，和员工对称，只是没有岗位和工具。
- **对话**：两个人之间的消息。你的「消息」页就是你的手机；员工资料里的「他在联系谁」是他的手机，是同一个视图。
- **工具**：工作环境（一台电脑或一个云环境，只能选一个）和账号（飞书、邮箱、网盘等，可以多个）。
- **改动**：员工用工具在外面做的事，比如订会议室、开账号、在网盘新建文件。做了就是做了，不能撤回。

两种关系：

- **归谁管**：只是组织关系，他向谁汇报。改它不会改任何权限。
- **权限**：能找他（给他发消息）、能管他（改他的岗位、做事说明、工具和权限，让他停下手上的事）。
  权限由被找、被管的那个人的管理者给，所以在一个人的「联系」里改的是“谁能找他”“谁能管他”；“他能找谁”是汇总出来的，只能看。
  招人时按归谁管给默认值：上级能找他、能管他，他能找上级；你是老板，一直能管所有员工。

联系公司外的人靠账号：员工有那个人用的账号，就能联系他，不另外勾。

## 页面

- 消息：你的对话。有没看的消息排在最前；右上角 ⊕ 招募。不能主动找的人，对话页会说怎么开通。
- 通讯录：招募、添加公司外的人、你、员工、公司外的人。
- 员工资料三个页签：联系（他在联系谁、谁能找他、谁能管他、他能找谁）、工作（在做什么和「让他停下」、做过的改动、工作环境、账号）、岗位（名字、岗位、归谁管、做事说明、让他离开）。
- 办公室：三维画面，和旧版一样。地上细线是归谁管，彩色箭头是他能找的人，灰色箭头是能找他的人；名字旁的绿方块是他最近一小时用过的工具。

删除、停下这类收不回的操作在原位点两下确认，不弹窗（发布页面里浏览器的确认框不会出现）。

没有接真实的 Bot：发出去的话不会有人回，示例内容是静态快照，可以清空。数据存在浏览器本地。
