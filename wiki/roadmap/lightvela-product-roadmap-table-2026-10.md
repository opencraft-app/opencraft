# LightVela 产品规划（表格版）

> 更新时间：2026-10-12

## 阶段说明

1. **阶段一：基本的 Agent 运行及其环境**。建设 Agent 创建、配置、持续运行及其所需的环境能力。
2. **阶段二：更多 Agent 上下文接入**。让 Agent 接入更多用户资料、外部应用与任务上下文，并支持信息和结果的沉淀、复用。
3. **阶段三：主动上下文洞察**。基于稳定运行和充足上下文，让 Agent 主动形成与用户相关的洞察、提醒与建议。

三个阶段体现产品能力的演进方向，建设工作可以交叠推进。当前产品整体处于阶段一向阶段二演进的过程中，阶段一仍有大量工作需要完善，会与阶段二的建设持续并行推进。

## 一、阶段一：Agent 运行稳定性与运行架构

需要优先解决用户环境下 Hermes Agent 的运行稳定性问题。自动化、常态化验证机制与运行稳定性优化实施路径并行建设。

| 描述 | 名称/类目 | 基本描述 | 方向负责人 |
| --- | --- | --- | --- |
| 自动化、常态化验证机制 | 核心使用场景验证 | 围绕用户核心使用场景建立自动化、常态化验证机制，持续发现产品运行中的可靠性问题。 | |
| 运行稳定性优化实施路径（短期） | 1. 观测 | 只观测、不执行修复动作；结合实例状态、TAT 在线状态、Hermes 健康接口和网关请求结果，判断存活、故障或未知，在控制台展示并提示；不发起合成请求，同时确定基线指标。 | |
| 运行稳定性优化实施路径（短期） | 2. 快照与手动入口 | 系统盘定期创建快照并保留多份，控制台支持选择快照回滚及“重启机器”；所有操作按钮执行前先创建保护点；存量机器在原形态下只实施前两步。 | |
| 运行稳定性优化实施路径（短期） | 3. 新镜像 | Agent 进入 Sandbox，程序只读，用户数据放数据盘；“重置 Agent”从镜像重建容器并原样挂回数据，自装软件记账并在重建时重放；一键更新改为替换制品，先灰度再全量。 | |
| 运行稳定性优化实施路径（短期） | 4. 配置移出 Sandbox | 平台配置启动时注入，重置即可恢复；用户配置提供“上次正常配置”和“恢复默认”；之后将渠道连接器移到宿主层。 | |
| 运行稳定性优化实施路径（短期） | 5. 换机 | VM 层发生故障时，从资源池更换机器并挂上数据盘。 | |
| 运行稳定性优化实施路径（短期） | 6. 存量迁移 | 仅在修复失败或用户要求时按需迁移到新形态，不进行批量迁移。 | |
| 运行架构优化（长期） | 整体优化 Agent 运行架构 | 对 Agent 运行架构进行整体优化，具体方案与实施路径待讨论。 | |

## 二、阶段二：Agent 上下文相关工作

| 描述 | 名称/类目 | 基本描述 | 方向负责人 |

| Agent 表现层提升 | Hermes Agent 系统提示词定制 | 基于 LightVela 的产品特性，定制 Hermes Agent 的系统提示词。 | |
| Agent 基础能力提升 | 云电脑能力 | 提供云电脑能力。 | |
| Agent 基础能力提升 | 连接器能力 | 提供 Agent 与第三方应用对接的标准入口。 | |
| Agent 基础能力提升 | 海外通道配置体验优化 | 优化海外通道配置体验。 | |
| Agent 基础能力提升 | 邮箱接入 | 为 Agent 接入邮箱能力。 | |
| Agent 基础能力提升 | 钱包接入 | 为 Agent 接入钱包能力。 | |
| Agent 基础能力提升 | 场景化模型能力 | 提供语言模型以外的能力支持，例如图片模型、视频模型、联网搜索等。 | |
| Agent 基础能力提升 | Agent 产物与云存储体验提升 | 支持产物预览，并提供在产物界面中与 Agent 交互的体验。 | |
| Agent 运行环境扩展 | 公网访问能力 | 为 Agent 运行环境配置公网 IP，国内站使用 IPv4，国际站使用 IPv6。 | |
| Agent 运行环境扩展 | 云存储空间扩展 | 扩展 Agent 的云存储空间。 | |
| Agent 运行环境扩展 | Agent 记忆增强 | 支持外接 Agent Memory。 | |
| 上手体验与信任建立（并行支线） | Agent 创建体验优化 | 降低用户开始提供上下文时建立信任感的门槛；优化创建流程，将连接能力纳入用户上手过程。 | |
| 上手体验与信任建立（并行支线） | Agent 迁移能力 | 支持已有 Agent 迁移到 LightVela，第一波优先支持来自 OpenClaw 类型产品的 Agent 迁移。 | |
| 上手体验与信任建立（并行支线） | 品牌新形象的视觉应用 | 将最新产品品牌形象应用到产品交互中。 | |
| 用户成长与激励机制设计 | 亲密度设计 | 按亲密度组织用户与 Agent 可完成的任务，直观呈现使用深度的持续提升，并基于使用深度提供产品激励。 | |
| 用户成长与激励机制设计 | 用户留存与促活策略设计 | 设计用户留存与促活策略，促进持续使用。 | |
| Agent 协作能力提升（长期规划） | 多 Bot 协作 | 支持 Hermes Agent 的多个 Bot 在同一协作空间中协作，例如看板或群聊。 | |
| Agent 协作能力提升（长期规划） | 跨 Agent Runtime 协作 | 支持 Hermes Agent 调度其他 Agent Runtime 或与其协作，例如 DeepSeek Harness，以及更多本地 Agent。 | |
| 硬件生态接入（纯探索支线） | 硬件生态接入 | 探索手机和 Web 覆盖范围之外的硬件场景，为 Agent 获取更多用户上下文。 | |

## 三、阶段二向阶段三演进：APP 主端建设

**APP 后续将成为 LightVela 产品的主端。** 围绕个人用户的体验要求，逐步建设以下能力。

| 描述 | 名称/类目 | 基本描述 | 方向负责人 |
| --- | --- | --- | --- |
| 入口层 | Agent 优先的 APP | 扩展 APP 入口，以 Agent 为核心重新设计交互体验，发挥第一方产品的能力，为个人用户提供比 IM 更好的 Agent 交互体验。 | |
| 连接层 | 个人上下文接入 | 通过 APP 接入更多用户个人上下文，包括手机操作系统内的数据。 | |
| 主动性机制探索 | 主动行为的用户感知 | 探索 Agent 主动行为的机制，通过 APP 接入手机通知等能力，让用户感知主动洞察、提醒等行为。 | |

## 四、并行建设

云端 Agent 特性功能建设旨在帮助用户通过 Agent 在云端构建并部署自己的应用，目前已建成基于底层 COS 静态资源的网页部署能力，并正在初步测试基于中间件、带数据库的应用部署能力。

| 描述 | 名称/类目 | 基本描述 | 方向负责人 |
| --- | --- | --- | --- |
| Chat | 能力分发枢纽 | 持续优化自建 Chat，将其建设为所有能力分发的枢纽。 | |
| 云端 Agent 特性功能建设 | 连接器数据源接入 | 将连接器作为数据源，接入云端应用部署能力。 | |
| 云端 Agent 特性功能建设 | 身份与数据源访问控制 | 参考 ChatGPT Side 的方向，探索按访问者身份控制数据源访问权限，让每位用户看到与自身身份权限对应的数据。 | |
| 云端 Agent 特性功能建设 | 自定义域名与部署基础设施 | 支持用户自定义域名配置，完善底层域名解析与证书配置能力。 | |
| 独立站基础能力 | 支付能力 | 国际站接入微信支付；国内站与国际站均支持微信签约。 | |
| 独立站基础能力 | 订单、发票与退款能力 | 在 LightVela 中接入腾讯云订单与发票机制，支持退款机制与腾讯云代金券体系。 | |
| 独立站基础能力 | 账号能力 | 支持账号注销与冷静期机制。 | |
| 独立站基础能力 | 安全与合规 | Chat 层面接入内容安全与风控能力；整个站点支持防薅机制。 | |
| 独立站基础能力 | 开放能力建设 | 逐步开放 API、SDK 或 MCP 的接入能力。 | |
| 数据体系建设 | 用户场景挖掘 | 建立用户场景的持续挖掘机制。 | |
| 数据体系建设 | 产品使用与经营数据 | 建立产品使用规模、经营与成本的数据体系。 | |
| 数据体系建设 | 独立站访问数据 | 建立覆盖独立站访问信息的完整数据体系。 | |
| 安全性建设 | 代码安全与漏洞扫描 | 接入代码安全与漏洞扫描的公共机制。 | |
