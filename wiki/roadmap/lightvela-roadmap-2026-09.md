# LightVela Roadmap（2026 年 9 月）

| 分类 | 功能 | 基本描述 |
|---|---|---|
| Agent 创建与托管 | Hermes Bot | 支持用户直接创建和托管持续在线的 Hermes Bot，无需自行准备服务器。 |
| Agent 创建与托管 | 场景化自动配置 | 根据用户选择的使用场景，自动配置 Agent 人格和 Skills，并支持用户调整。 |
| 云端执行 | Hermes 协同云端 Coding Agent | Hermes 与 DSH 协同，在隔离的云端沙箱中完成代码修改、测试和构建。 |
| 云端执行 | 云端浏览器 | Agent 使用独立的云端浏览器完成网页访问和操作，用户可以查看过程并在关键步骤接管。 |
| 产物与应用 | Hermes Artifacts | 统一保存 Hermes 和 Coding Agent 生成的代码、页面、文件及构建结果。 |
| 产物与应用 | 云端应用部署与托管 | 将 Hermes Artifacts 直接部署为持续在线的云端应用，本月优先支持静态页面和前端应用。 |
| 数据与上下文 | Agent 云盘 | 为 Agent 提供持久化云端文件空间，保存用户资料和任务产物，并支持 Agent 在授权范围内读写。 |
| 数据与上下文 | 外接云端 Memory | 连接第三方云端 Memory，提供独立于单个 Hermes 实例的长期记忆能力。 |
| 第三方连接 | Integrations | 与第三方应用和数据源打通，使 Agent 能够读取信息、执行操作并响应外部事件。 |
| 后续方向 | 多 Agent 与本地 Agent 协同 | 多 Agent 云端协作，以及 Hermes 驱动本地 Codex、Claude Code 等客户端，本月暂不投入。 |
