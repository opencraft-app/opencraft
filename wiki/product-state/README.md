# Product State

本目录维护 LightVela 当前项目状态，回答“现在目标是什么、路线怎么走、风险在哪里”。

## 文件说明

- `current-focus.md`：当前阶段最需要聚焦的方向。
- `roadmap.md`：产品能力迭代路线图。
- `goals.md`：阶段目标与验收口径。
- `risks.md`：当前风险与观察点。

## 更新规则

- 状态类内容优先写当前有效判断，避免堆叠历史过程。
- 如果判断来自会议、脑暴或调研材料，应在正文中指向 `../sources/`。
- 当路线或目标发生变化时，同步检查 `current-focus.md`、`roadmap.md`、`goals.md` 和 `risks.md` 是否仍一致。
