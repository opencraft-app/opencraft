# Product State

本目录维护 LightVela 当前项目状态，回答“现在目标是什么、路线怎么走、风险在哪里”。

## 文件说明

- `current-focus.md`：当前阶段最需要聚焦的方向。
- `environment.md`：本地、预览、现网环境关系，以及账号、实名、手机号、邮箱、套餐隔离规则。
- `roadmap.md`：产品能力迭代路线图。
- `goals.md`：阶段目标与验收口径。
- `risks.md`：当前风险与观察点。
- `geo-fact-table.md`：GEO 事实表，为对外产品事实（产品状态、价格、试用、模型、渠道、实名、数据保留期、到期处理）指定唯一负责人与唯一来源，并记录站内事实冲突与缺口。

## 更新规则

- 状态类内容优先写当前有效判断，避免堆叠历史过程。
- 如果判断来自会议、脑暴或调研材料，应在正文中指向 `../sources/`。
- 当路线、目标或环境规则发生变化时，同步检查 `current-focus.md`、`environment.md`、`roadmap.md`、`goals.md` 和 `risks.md` 是否仍一致。
- 对外文案涉及产品事实（状态、价格、试用、模型、渠道、实名、数据保留期、到期处理）时，先查 `geo-fact-table.md` 中该事实的唯一来源，改来源后再同步镜像位置，不直接改镜像。
