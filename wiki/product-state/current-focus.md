# Current Focus

更新时间：2026-07-21

## 当前聚焦

LightVela 当前重点是把云端 Agent 从“部署形态”推进到“持续执行、状态沉淀、资产复用”的产品能力。

## 主线

- 自动任务与场景化持续执行：让 Agent 在用户不在场时持续执行、保持状态，并将结果沉淀为可复用资产。
- 基础功能体系建设：补齐计费、服务、账号和 AI 网关等运营基础能力。
- Agent 场景 + 云服务探索：围绕海外云端主机、云端能力扩展和记忆增强验证差异化场景。
- 基础能力体验提升：持续改善模型配置和云端对话体验。

## 当前判断

- 云端部署是基础层，不是完整产品价值。
- 持续任务应被视为一等产品对象，而不是一次定时调用。
- 复用与流转需要资产模型、版本、权限、来源和交接能力支撑。
