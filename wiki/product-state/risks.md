# Risks

更新时间：2026-07-22

## 当前风险

1. 云端部署叙事不足
   - 风险：用户把 LightVela 理解为一种部署形态，而不是新的工作方式。
   - 观察点：是否能形成持续任务、结果沉淀和复用流转的真实闭环。

2. 自动任务退化为定时调用
   - 风险：只做 Cron/Webhook，缺少目标、输入来源、执行历史、异常处理和下一步动作。
   - 观察点：任务运行后是否有状态、结果和可接续路径。

3. 资产复用缺少中间层
   - 风险：有持久化结果，但没有资产模型、版本、权限、来源和交接机制。
   - 观察点：一个任务结果能否被重新输入、授权给他人或被另一个 Agent 接续。

4. 基础能力分散推进
   - 风险：计费、服务、账号、AI 网关各自推进，但没有服务自动任务主线。
   - 观察点：基础能力是否都能支撑持续执行和商业化闭环。

5. 预览环境与现网环境验证结论串线
   - 风险：本地和分支预览连接北京环境后端，而上海环境才是正式现网环境；账号、实名、手机号、邮箱和套餐数据隔离，预览验证结果可能被误认为现网结论。
   - 观察点：排查账号、实名、套餐、权益问题时，是否先确认入口环境，并区分 LightVela 环境隔离规则与腾讯云影子账号底层配额。
