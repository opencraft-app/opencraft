# LightVela 产品能力迭代路线图

来源：用户提供的 `lightvela-roadmap-overview.html`，整理时间：2026-07-21。

## 总览

自动任务是云端重点能力，基础建设、云服务探索与体验提升并行推进。

核心目标是让 Agent 在用户不在场时持续执行、保持状态，并将结果沉淀为可复用资产。

## Module 01：自动任务与场景化持续执行

### 五个迭代阶段

1. 事件触发与技能引入
   - Webhook 触发
   - 绑定 Skill

2. 执行记录与结果沉淀
   - 执行任务、记录
   - 云存储结果

3. 任务目标与输入来源
   - 输入任务目标
   - 输入参考来源

4. 异常处理与下次动作
   - 失败、超时重试
   - 确认通知

5. 复用与流转方向
   - 任务能力复用
   - 结果流转接续

### 场景验证

四类持续任务并行探索：

- 监控提醒类：价格、舆情、工单、部署、账单、MR、故障、竞品更新。
- 周期汇总类：日报、竞品动态、用户反馈、数据报告、行业动态。
- 持续维护类：知识库、需求池、FAQ、项目看板、内容更新、客户跟进。
- 长时间等待类：测试、爬取、异步审批、批量生成、批处理、资料收集。

### Dogfood

能力上线前运行真实任务，并验证结果是否被打开、复用、修改和接续。

## 自动任务规划与 Hermes 能力基础

参考 Hermes Agent main `56e2ba5e`（2026-07-17）整理。

| 规划阶段 | Hermes 基础 |
| --- | --- |
| 事件触发与技能引入 | Cron 支持定时、间隔与单次调度，任务可绑定多个 Skill；Webhook 支持事件类型、过滤规则、脚本转换、Skill 和多渠道投递。 |
| 执行记录与结果沉淀 | 每次 Cron 运行生成独立 Session，完整消息、工具调用和状态写入 SQLite；结果按任务和运行时间保存为 Markdown，默认保留最近 50 次，并提供运行历史 API。 |
| 任务目标与输入来源 | Prompt 可承载任务目标，支持预执行脚本输出和 Webhook payload 作为实时输入；支持 `context_from` 引用前置任务最新结果，`workdir` 可引入项目文件与上下文。 |
| 异常处理与下次动作 | 已有 Agent 无活动超时、脚本超时、错误状态和失败消息投递；支持手动重新运行，Cron 安全审批可设置为拒绝或自动通过。 |
| 复用与流转方向 | 支持任务结果串联、可接续消息、Profiles 和 Skill bundles；Kanban 提供持久化任务、附件、运行记录与多 Agent 工作者调度基础。 |
