# LightVela 日会进展 - 2026-09-22

## 总览

LightVela 当前处于「创建 Agent 流程打磨 + 跨 SCP 升级收尾 + 连接器接入 + 节前运营冲刺」阶段，今日重点是：

- 产品侧：创建 Bot 问题已于昨晚修复，待在预发环境或现网验证；国内站创建 Agent 流程优化代码已合并至北京环境，需确认是否已发布现网并验证，国际站能力已完成但开关仍关闭，待国内站验证完毕后开启；跨 SCP 升级测试环境流程已走通，今日重点测试边界场景并调整前端按钮判定逻辑，整体预计节前上线；连接器界面已基本完成，今日优先接入腾讯文档与腾讯会议（两者鉴权方式不同，可作为两类形态验证），之后再重点推进国际站连接器；组件重构的导航改动已与现网改动合并，今日完成代码审查（CR）并发版，后续按页面拆分发布。
- 商业化侧：账号注销能力确定两阶段方案——短期提供删除账号能力以应对周末工单等紧急情况，长期与账号团队对齐业务账号与隐私账号联动销毁；注销策略将设置冷静期及手机不可再次注册的冻结期（如 15 天，具体待定），避免用户反复注销领取免费套餐额度。
- 运营侧：好友送积分问题已修复，正在测试账号验证，若无 Bug 则节前可发；好友送时长仍依赖续费代码联调，国内站节前上线无风险，国际站接入需额外时间，若时间紧张则优先上线积分功能；今日撰写工作与旅游场景多 Bot 文章，并借鉴国际站「Lighthouse 部署 Agent」爆款文章（30 万阅读，植入「24 小时不掉线」等高频关键词）经验优化标题与关键词；公关侧计划将 Lighthouse 新能力及好友送积分活动提报给主编评估。
- 规划侧：10 月核心方向为多 Bot 群聊协作，并结合沙箱对现有应用部署及 DSH 做整体优化；接入沙箱后 Agent 运行时可部署在独立云环境中、天然支持前后端运行，突破当前静态网页部署在 COS 难以拓展后端的限制，并支持 CodeBuddy、Cloud 等多种运行时；外部版优先提供沙箱能力，Chat 能力为 10 月重点。
