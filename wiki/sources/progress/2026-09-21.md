# LightVela 日会进展 - 2026-09-21

## 总览

LightVela 当前处于「积分包与续费联调 + 账号注销合规 + Agent Chat 多通道建设 + 国内外站推广」阶段，今日重点是：

- 商业化侧：积分包交互优化国内站已包含国际站，国际站存在价格请求不到的问题（后端测试询价正常），需开发提供测试环境信息进一步排查；续费商品已与点视完成对接并进入联调，因测试环境复杂，后续直接发至线网回归测试；账号注销方案已与账号团队沟通，后续需支持销毁注销账号能力，今日完成对接并向用户回复；跨 SPP 分配升配已进入开发，预计国庆节前上线。
- 产品侧：Agent 页面与账号页面已按新规范完成组件重构并发布至分支预览环境，需尽快验证基础能力；飞书通道接入后需补齐权限等参数配置才能实现群聊实时回复，计划输出教程文章；Slack 通道计划评估 Chat 能力，优先用 Redis 搭建基础单聊与群聊；连接器底层已复用社区开源 MCP，分工调整为由前端团队推进。
- 运营侧：今日在国内社群宣传 Dbot 功能（企微不支持群聊，主推飞书与 QQ 渠道），并同步发布国内站与国际站的 Dbot 教程及场景化内容；国内站转化率长期维持 30%（实名流程繁琐），国际站转化率近期飙升至 90% 且注册量偏高，需持续关注 Discord、WhatsApp 社群动态；上周已开通 3 个 KOL 账号，今日线下再对接开通 4 个。
