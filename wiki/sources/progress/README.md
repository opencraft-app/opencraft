# Progress

本目录用于沉淀 LightVela 每日进展对齐记录，属于 `wiki/sources/` 下的原始输入层。

日会原始纪要不直接按会议结构堆叠，而是统一整理为固定模块视图，方便持续追踪产品推进状态。

## 模块划分

- 产品：主要关注能力建设。
- 运营：主要关注产品增长。
- 商业化：主要关注公测策略与计费能力。
- 基础设施：主要关注项目环境、发布流程与协作机制。
- 场景化：主要关注差异化能力探索。

## 更新规则

- 每日新增一个日期文件，命名格式为 `YYYY-MM-DD.md`。
- 每次更新优先记录变化，未变化事项可以保留原状态但不重复展开。
- 跨天未解决、影响上线、影响增长、影响付费的事项，需要进入「关键风险」。
- 状态建议固定使用：未启动、进行中、联调中、待发布、已完成、阻塞、暂缓。
- 已经形成稳定产品理解的内容，应同步沉淀到 `../../knowledge/`。
