# LightVela 日会进展 - 2026-07-27

## 总览

LightVela 当前处于「国际站计费待办拆解 + 商业化发布准备」阶段，今日重点是：

- 逐项复盘国内站计费上线时的建设项，判断国际站哪些已完成、哪些仍需补齐。
- 国际站计费主链路的后端能力基本完成，但仍受计费接入单发布、国际站环境、影子账号和签约支付流程影响。
- 国际站测试环境优先按「首尔测试 / 东京预发布 / 新加坡现网」思路推进，目标是本周具备内部测试条件。
- 新购、续费等资源生命周期能力已完成测试，当前主要卡在计费接入单发布。
- 国际站 AI 积分、积分邀请、自动续费等能力存在底层依赖，需要先推动 New API / 新网关和相关计费能力上线。
