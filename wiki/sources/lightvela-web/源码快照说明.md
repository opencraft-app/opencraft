## 本地启动

在解压后的 `lightvela-web` 目录运行（Node.js 22.12+）：

```bash
npm install -g pnpm@9.15.9
pnpm install --frozen-lockfile
pnpm dev --host 127.0.0.1 --port 5173 --strictPort
```

浏览器打开 `http://127.0.0.1:5173/#/profile01`。在其他设备使用时，需在那台设备启动服务器。

重新导入XML需要Python 3，运行 `pnpm import:deck`。完整修改方式见README.md。
