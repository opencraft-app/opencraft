# 2026-07-28 BrainStorm：海外增长合作与 AI 积分能力扩展

> 来源：2026-07-28 LightVela 脑暴会逐字稿。本文用于沉淀海外增长合作、KOL/KOC 建联、高校活动，以及 AI 积分能力扩展方向的阶段性讨论，不直接等同于已排期需求。

## 总览

本次脑暴主要讨论两个方向：

1. 海外增长合作：通过 KOL/KOC、高校活动、培训机构渠道等方式，探索国际站冷启动与内容共建。
2. AI 积分能力扩展：将当前主要用于语言模型额度抵扣的 AI 积分，进一步扩展到联网搜索和多模态理解能力。

整体判断是：海外合作可先用轻量活动验证转化与内容沉淀；AI 积分扩展方向具备场景价值和基础设施条件，但需要进一步验证网关能力、Hermes 工具接入方式和成本模型。

## 方向一：海外增长合作

### 当前进展

近期海外增长侧主要推进了三类事项：

- KOL/KOC 建联：已私信触达约 30 家非洲区域相关 KOL/KOC，主要介绍 LightVela 产品，当前等待回复。
- 高校活动：已与南洋理工大学、新加坡管理大学、香港大学进行初步沟通，合作意愿较强；香港大学对接人同时具备大湾区港澳生同学会资源。
- 培训机构渠道：已与香港一家本地小型培训机构建联，并与国际站渠道团队对齐返佣政策。

渠道政策初步判断：

- 中长尾客户由腾讯云签约的保底总经销商承接。
- 头部或大型机构由渠道团队 case by case 评估返佣和推进方式。

### KOL/KOC 建联策略

当前触达情况：

- 已联系非洲区域 KOL/KOC 约 30 家。
- 暂未收到明确回复，可能与使用个人账号联系、可信度不足有关。
- 后续计划使用更官方或更可信的账号继续触达，并扩大博主地域范围。

合作设想：

- 邀请 KOL/KOC 体验 LightVela。
- 鼓励其发布产品使用感受、软文或推文。
- 合作资源置换方式待确认，例如代金券、免费使用时长、月度/年度权益。

触达方式判断：

- 博主更倾向通过邮件沟通。
- 对长期使用者或反馈时效要求较高的用户，可沉淀到 Discord、WhatsApp 等社群。
- 社群更适合作为长期用户关系维护，而不是初次建联的唯一入口。

### 高校合作模式

已讨论两种合作模式。

#### 模式 A：轻量直播合作

形式：

- 面向高校学生开展一次 AI 趋势讲解 + LightVela 产品介绍直播。
- 直播后组织学生答疑和实践案例提交。
- 优秀实践案例可沉淀为官网教程或外部内容素材。

LightVela 侧提供：

- 直播内容和讲解支持。
- 14 天产品使用资格。
- 优秀作品评选和展示渠道。

高校/社团侧提供：

- 校内宣发。
- 组织学生参与活动。
- 协调案例提交。
- 根据合作效果，在校园网或社团社媒发布报道。

优点：

- 产品侧投入较轻。
- 可快速验证高校渠道的获客和内容共建效果。

风险：

- 直播后约束力较弱，学生可能只参与直播而不持续使用。
- 留存和实践案例产出不确定。

#### 模式 B：课程 + Mini 赛事共建

形式：

- 提供 6-8 节精品 Mini 课程，单节约 10 分钟。
- 学生学习课程后，基于自身学习或生活场景使用 LightVela 做实践。
- 通过 Mini 赛事收集作品和案例。

LightVela 侧提供：

- 全套课程内容。
- 赛事评委和答疑支持。
- 14 天产品体验资格。
- 奖池或权益激励。
- 优秀作品官网展示渠道。
- 核心获奖团队成员可进入国际站亲友团。

高校/社团侧提供：

- 将课程纳入社团常规活动。
- 组织成员学习课程并参与赛事。
- 配合赛事宣发。

优点：

- 课程内容可长期沉淀和复用。
- 更容易产出优秀作品、教程和真实实践案例。
- 有机会筛选国际站亲友团或种子用户。

风险：

- 产品侧课程建设和赛事运营成本更高。
- 当前无法提供大量 Token 赞助，学生自费购买 Token 会降低参与意愿。
- 如果奖池吸引力不足，作品数量和质量可能低于预期。

### 高校用户诉求

高校学生参与 AI 活动的主要诉求包括：

- 获得活动证明或完课证明，可用于 LinkedIn、简历或个人经历展示。
- 获得实习或内推资源。
- 获得权益激励，例如 Token、代金券或产品使用资格。
- 学习与自身学习场景、学习生活、社团运营相关的 AI 产品用法。
- 部分社团/学生会成员对 AI 辅助社媒运营感兴趣。

关于证明：

- 不需要公司盖章或正式实习证明。
- 可考虑类似“产品级认证证书”或“繁星大使”风格的电子证明。
- 证明可带产品 Logo、产品名、证书编号和活动身份。

### 初步结论

- 高校合作可以先从模式 A 轻量直播切入，选择一所高校做试点。
- 8 月中旬可优先找南洋理工或新加坡管理大学开展一次轻量直播，验证效果。
- 后续根据直播效果、学生反馈和高校建议，再判断是否升级到课程 + Mini 赛事模式。
- 需要先明确可提供的资源包，包括体验资格、内推码、活动证明、权益激励等。

## 方向二：AI 积分能力扩展

### 用户场景背景

当前用户使用云端 Agent 时存在两个高频能力缺口：

1. 联网能力不稳定。
   - LightVela 当前部署的云端 Agent 实例公网访问能力不够稳定。
   - 没有像 Lighthouse 一样提供独立公网 IP。
   - Agent 在执行需要联网的任务时，容易受模型能力影响。
   - DeepSeek 等模型可能误判当前环境无法联网。
   - 现网中超过半数用户使用 DeepSeek 模型，因此该问题影响面较大。

2. 多模态理解能力不足。
   - 当前大多数配置仍以语言模型为主。
   - 如果用户不使用 Kimi 等具备多模态能力的模型，Agent 难以理解图片等多模态信息。
   - 用户已反馈过相关问题。

这些问题在定时任务等自动化场景中更明显，例如需要查询公开网页、核验资料、抓取信息或理解图片输入时。

### 基础设施背景

近期出现两个新的基础条件：

- AI 网关已由 skipzhang 基于开源项目重构，具备接入多类型 AI 服务的基础。
- TokenHub / MaaS 侧已提供联网搜索、多模态理解等对应模型或服务，价格相对可接受。

这意味着 AI 积分不必只用于语言模型额度抵扣，也可以扩展为多种 AI 服务能力的统一消费载体。

### 初步能力设想

可将 AI 积分扩展到：

- 联网搜索。
- 多模态理解。
- 后续可能还有更多 AI 服务调用能力。

产品形态示例：

- 启航版 AI 型套餐每月支持 100 次联网搜索。
- 不同套餐对应不同搜索次数、多模态调用次数或额度。
- 用户无需自行配置第三方 API Key，系统默认提供可用工具。

底层实现设想：

- 在 AI 网关中接入 TokenHub / MaaS 联网搜索和多模态模型。
- 通过预置工具或 Skill，将能力注册到 Hermes Agent 可发现的工具范围内。
- API Key 由系统或网关注入，用户不可见。
- 调用次数或成本通过 AI 积分抵扣。
- 后续补充调用观测能力，支持统计和成本核算。

### 联网搜索能力价值

可支持的场景包括：

- 资料查询。
- 公开信息检索。
- 网页内容核验。
- 定时任务中的动态信息获取。
- 自动任务和内容生产中的事实补充。

当前没有统一联网工具时，Agent 可能只能依赖：

- 用户自行配置的 Tavily Search 等 Skill。
- 模型自行发现无头浏览器等间接路径。

这两种方式都不够稳定。内置联网搜索能力可以降低用户配置门槛，并提升定时任务成功率。

### 多模态理解能力价值

可支持的场景包括：

- 图片内容理解。
- 图文资料处理。
- 用户上传截图或图片后的分析。
- 内容创作中的图片理解与描述。

在用户未配置多模态模型时，系统可通过工具方式补齐多模态能力。

### Hermes 接入方式

当前初步观察到两类可能路径：

1. 内置工具方式。
   - 在 Hermes Agent 可发现的工具范围内注册工具。
   - 工具中配置网关侧 API Key。
   - Agent 在遇到联网、多模态任务时调用工具。

2. 内置能力配置方式。
   - Hermes 内置部分工具可能支持配置辅助场景模型。
   - 不同场景可配置 provider 和 API Key，例如图片生成、联网搜索等。

具体采用哪种方式，需要继续调研 Hermes 机制和 AI 网关能力。

### 初步结论

- 联网搜索和多模态理解是当前云端 Agent 场景中的真实能力缺口。
- AI 网关重构和 TokenHub / MaaS 能力接入，为 AI 积分扩展提供了基础条件。
- 该方向值得进一步细化为产品方案，但还需要验证：
  - 网关是否支持统一注入和计费。
  - Hermes 工具/能力机制如何接入。
  - 套餐次数和成本如何测算。
  - 是否能真正提升自动任务与场景化能力稳定性。

## 后续待研究问题

### 海外增长合作

- KOL/KOC 资源置换标准如何制定，例如代金券、免费体验时长、月度或年度权益。
- 是否需要使用官方账号或统一邮箱提升 KOL/KOC 触达可信度。
- 高校活动优先采用直播模式，还是课程 + Mini 赛事模式。
- LightVela 能否提供产品级电子证明，具体样式、命名、编号和权益如何设计。
- 是否能给高校学生提供专属内推码、活动权益和作品展示通道。

### AI 积分能力扩展

- AI 网关是否能统一支持联网搜索、多模态等服务的接入、注入和计费。
- 联网搜索、多模态理解分别如何映射到 AI 积分。
- 不同套餐应提供多少次调用额度。
- Hermes 中应通过工具、Skill，还是内置 provider 配置来暴露这些能力。
- 如何让 Agent 自动选择系统联网搜索，而不是继续误判环境无法联网。
- 如何观测调用量、成功率、成本和用户使用场景。
