# Sources

本目录维护 LightVela 产品知识的原始输入材料。

## 目录结构

- `progress/`：日会进展对齐记录，按照日期维护。
- `brainstorm/`：产品、运营、商业化、基础设施、场景化等方向的阶段性脑暴。
- `meetings/`：会议纪要、访谈记录或待整理会议材料。
- `market-analysis/`：市场、竞品、冷启动和产品调研等来源材料。

## 维护规则

- 来源材料优先保留原始语义，不直接改写成当前结论。
- 已经沉淀为稳定理解的内容，应同步进入 `../knowledge/`。
- 影响当前目标、风险或路线的内容，应同步检查 `../product-state/`。
