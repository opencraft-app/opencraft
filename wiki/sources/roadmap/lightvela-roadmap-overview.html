Automatic Task Foundation

自动任务规划与 Hermes 能力基础

Hermes Agent main · 56e2ba5e · 2026-07-17

规划阶段 Hermes 基础
01

事件触发与技能引入
  • Cron 支持定时、间隔与单次调度，任务可绑定多个 Skill。
  • Webhook 支持事件类型、过滤规则、脚本转换、Skill 和多渠道投递。
02

执行记录与结果沉淀
  • 每次 Cron 运行生成独立 Session，完整消息、工具调用和状态写入 SQLite。
  • 结果按任务和运行时间保存为 Markdown，默认保留最近 50 次，并提供运行历史 API。
03

任务目标与输入来源
  • Prompt 可承载任务目标，支持预执行脚本输出和 Webhook payload 作为实时输入。
  • 支持 context_from 引用前置任务最新结果，workdir 可引入项目文件与上下文。
04

异常处理与下次动作
  • 已有 Agent 无活动超时、脚本超时、错误状态和失败消息投递。
  • 支持手动重新运行，Cron 安全审批可设置为拒绝或自动通过。
05

复用与流转方向
  • 支持任务结果串联、可接续消息、Profiles 和 Skill bundles。
  • Kanban 提供持久化任务、附件、运行记录与多 Agent 工作者调度基础。
