## 基本信息

- 当前产品：LightVela Agent 控制台 / 自动任务（需求一）；LightVela 国际站首页（需求二）
- 需求单状态：已开发完成，待 CR 与发布
- 创建人：keriaxu

- 最后更新时间：2026-09-14

- 发布范围：需求一为国内站 `lightvela.com` 控制台；需求二为国际站 `lightvela.ai` 首页（含多语种）

## 需求背景

需求一：自动任务模板专区采用固定 `pageSize = 6` 的分页策略，不随视口尺寸变化。宽屏下模板区右侧留白、一屏放不满两页内容；小屏下每页卡片过高，一页塞不下，需要频繁翻页。模板专区是用户发现和快速启用自动任务的主要入口，分页密度直接影响浏览效率。

需求二：国际站首页页脚的「对比」栏目，8 个语种静态首页片段中除 `zh-CN` 外均被写成「分析 / Analysis / Análisis / Analisis / 분석」，与国内站页脚以及站内页脚组件 i18n 的「对比」语义不一致。该文案源自国际站静态首页导入源（源站 en 即为 "Analysis"），属于源文案映射错误，且会在下次重新执行导入脚本时回退，需要连同导入脚本一起修正。

两项改动均为前端局部优化，互不耦合，合并到同一个分支与 MR 交付。

## 目标用户与场景

- 需求一目标用户：使用 LightVela 自动任务创建周期提醒、工作总结、行情监控等任务的用户。
  - 宽屏（笔记本 / 外接显示器）用户希望一屏看到更多模板，而不是大幅留白。
  - 小屏（笔记本）用户希望一页内完整看到模板，减少翻页次数。
- 需求二目标用户：访问国际站 `lightvela.ai` 的海外用户（中文简繁、日、韩、西、印尼、英语种）。
  - 用户从首页页脚进入「与 Hostinger 对比」等对比文档，栏目名称需与落地页语义一致，否则会造成预期偏差。

## 目标

- 模板专区每页展示量随视口宽度与高度自适应，消除宽屏留白与小屏溢出。
- 模板行列计算仅在必要时执行，不引入滚动或渲染性能问题。
- 国际站各语种首页页脚栏目名称与链接文案统一修正为「对比」语义，并与站内页脚 i18n 对齐。
- 修正后的文案具备抗回退能力：重新执行导入脚本后仍保持「对比」。

## 功能详细描述

### 1. 模板分页按视口行列自适应（国内站）

- 列数由断点决定：`xl` 及以上 3 列，`sm` 及以上 2 列，其余 1 列。
- 行数由视口高度决定，取值区间 2~5 行：视口越高，每页可容纳行数越多，800px 视口约 4 行。
- 每页展示量 = 列数 × 行数，随窗口尺寸变化实时生效。
- 行数计算只在组件挂载与窗口 `resize` 时触发，页面滚动不触发重算，避免频繁重排。

### 2. 提示文案位置修正

- 模板专区位置调整后，引导文案由「可从上方任务模板快速启用」改为「可从下方任务模板快速启用」。
- 新文案通过 i18n 生成链路补齐 7 个语种，不硬编码。

### 3. 国际站页脚「分析」改为「对比」（含多语种）

- 栏目标题：zh-SG「对比」/ zh-Hant「對比」/ ja-JP「比較」/ ko-KR「비교」/ en-US「Compare」/ es「Comparar」/ id-ID「Perbandingan」。
- 链接文案：zh-SG「与本地部署对比」「与 Hostinger 对比」「与 Manus 对比」「与 ChatGPT 对比」「与 Genspark 对比」；繁体「與 X 對比」；日文「ローカル展開との比較」「Hostinger と比較して」等；韩文「X 비교」；英文「Compare with X」；西语「Comparar con X」；印尼语「Bandingkan dengan X」。
- 导入脚本同步修改，确保源文案模板、语种映射与路由键三处一致，避免下次导入打回旧文案。
- 国际站需求按规范：**多语种版本与中文版本同步修改、同步验收**。

## 产物交接

- 产品：确认每页行数的取值区间（2~5 行）与视口高度的映射是否符合预期。
- 设计：确认宽屏下无右侧留白、小屏下一页可容纳的视觉密度。
- 前端：完成分页逻辑、文案、导入脚本与测试。
- QA：验证不同视口下的列数行数、翻页、模板启用、空模板情况；验证国际站 8 个语种页脚文案与链接跳转。

## 方案决策

- 采用方案：分页量 = 断点列数 × 视口高度自适应行数；页脚文案在 fragment 与导入脚本两处同步修正。
- 选择理由：列数跟随断点可复用现有响应式体系，行数按视口高度自适应能在不新增交互的前提下覆盖宽屏与小屏；导入脚本同步修改是防止文案回退的必要动作。
- 备选方案与取舍：
  - 固定 pageSize 只改列数：无法解决小屏一页塞不下的问题，不采用。
  - 由用户手动选择每页数量：增加交互成本，收益有限，不采用。
  - 只改 fragment 不改导入脚本：下次导入会回退到「分析」，不可接受。
- 延后或不做：模板推荐排序、模板分页状态持久化、国际站首页其他栏目文案治理。

## 验收标准

1. 宽屏（xl 及以上）模板区为 3 列，中等屏（sm 及以上）为 2 列，小屏为 1 列。
2. 每页行数随视口高度自适应（2~5 行，800px 视口约 4 行），宽屏无右侧留白，小屏一页可完整展示。
3. 调整窗口大小时分页重新计算；页面滚动时不触发重算，无抖动或性能回退。
4. 提示文案为「可从下方任务模板快速启用」，7 个语种均已同步。
5. 国际站 8 个语种首页页脚栏目名为「对比 / 對比 / 比較 / 비교 / Compare / Comparar / Perbandingan」，不再是「分析」。
6. 页脚对比链接文案各语种均为「与 X 对比」语义，链接跳转正常。
7. 重新执行首页导入脚本后，页脚文案仍为「对比」，未被打回。
8. 相关测试（copy 测试 + next-site 首页 / 页脚测试 + 自动任务面板测试）通过，`pnpm i18n:check` 通过，`pnpm check` 无新增类型错误。
