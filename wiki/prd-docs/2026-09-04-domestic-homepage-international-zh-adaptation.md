# 国内站首页跟进国际站中文版适配

## 基本信息

- 当前产品：LightVela
- 需求单状态：已确认
- 创建人：Keria / Codex
- 创建日期 / 最后更新时间：2026-09-04 / 2026-09-04

## 需求背景

国际站中文版首页已经形成较完整的产品表达和页面结构，国内站首页需要跟进这一版本，降低双站首页体验差异。但国内站面向 `lightvela.com` 用户，涉及国内登录、订阅、渠道、备案合规、转化链路和文案语境，不能直接照搬国际站内容。

## 目标用户与场景

- 目标用户画像：访问 `lightvela.com` 的国内潜在用户、已登录未订阅用户、已订阅但未创建 Agent 的用户。
- 典型场景：用户从官网首页了解 LightVela 是什么、能做什么、如何创建 Hermes Agent，并进入国内站订阅或创建流程。

## 目标

- 国内站首页复用国际站中文版的信息架构和核心卖点。
- 国内站文案、CTA、渠道说明、页脚与合规信息完成本地化适配。
- 首页体验保持双站一致，但国内站不出现国际站专属登录、支付、渠道或海外合规表达。

## 范围

- 本次包含：
  - 复用国际站中文版首页结构、视觉节奏和核心模块。
  - 国内站首页文案适配为国内用户语境。
  - CTA 适配国内订阅与创建路径。
  - 渠道与能力表达适配国内可用能力，如微信、企业微信、钉钉、飞书、QQ 等。
  - 首页 hero 演示区保留国际站原有对话内容，并按国内常见 IM 通道重新分配到微信、QQ、企业微信、钉钉、飞书的客户端外壳中。
  - 页脚按国内站截图口径保留 LightVela 品牌块，链接区调整为「产品 / 对比 / 社区 / 公司」四列，并保留版权、备案、法律入口等合规展示。
  - 更新首页 metadata 中的国内站 title 与 description。
- 本次不包含：
  - 不重做全新首页设计。
  - 不新增后端能力、套餐规则或支付能力。
  - 不修改国际站现有中文版首页内容，除非发现共用组件导致必须兼容。
  - 不新增独立活动页或运营落地页。
- 优先级：P0
- 已知依赖：国内站当前编译期 `isCN` / `isGlobal` 分支、国际站 V2 首页静态片段、Next App Router 首页入口。

## 功能详细描述

- 国内站根路径 `/` 使用国际站 V2 首页的 `zh-CN` 静态片段，而不是继续回退到旧版 `PublicHomePage`。
- 国内站片段中的导航、CTA、文档链接、法律链接统一使用国内站裸路径，例如 `/subscribe`、`/docs/overview`、`/privacy-policy`，不输出 `/zh-cn/...` 前缀。
- 国内站片段中的渠道表达替换为国内语境：微信、企业微信、钉钉、飞书、QQ 等；不把 WhatsApp、Telegram、Discord、Slack 作为国内站主渠道卖点。
- 首页 hero 演示区保留国际站原有 demo 对话内容：微信承接金融监控 / 美股速览，QQ 承接原 Discord 社区赛提醒与时区换算对话，企业微信承接原 Slack 项目推进与客户回访排序，钉钉承接项目纪要和待办提醒，飞书承接 DSH / 研发协作；对应面板需要呈现国内客户端会话列表、群聊标题和输入区，但删除左侧应用级功能导航栏与右侧成员列表。微信、QQ、企业微信左侧会话栏按缩略客户端比例展示，顶部为紧凑的「搜索框 + 独立加号按钮」；微信不展示额外标题栏、筛选标签或分组入口。钉钉面板保留顶部窗口栏结构承载应用标识与搜索入口，但文字和图标使用灰白中性色，不使用钉钉蓝或强调紫；飞书面板左侧标题使用缩小后的图标加「消息」样式。不展示 Telegram、Discord、Slack 等国际通道外壳；平台外壳可体现结构差异，但聊天内容区保持国际站无头像展示方式，气泡使用白色 / 浅灰色，LightVela 名称、mention 和机器人标识统一使用国际站紫色，不额外引入平台蓝、微信绿或自定义浅紫皮肤。
- 国内站页脚与版权表达使用国内站语境，但视觉比例沿用国际站紧凑 footer：左侧保留 LightVela 品牌块与「Copyright © 2026 LightVela 版权所有 · 腾讯轻量云出品」，并将「京ICP备11018762号-1137」以同字号同色单独放在品牌文案下方，保持适当行距；产品列展示 14 天免费试用、定价和 QQ、微信、企微、钉钉、飞书接入指引，其中钉钉入口先跳转到已包含钉钉接入说明的核心概念文档；对比列展示本地部署、Manus、AI Chatbot；社区列展示加入交流群；公司列展示关于我们、帮助与反馈、隐私政策、服务条款；不再额外展示底部中文版权条。
- 国内站页脚不输出国际站社区外链、海外增长渠道、国际站博客入口、国际站相关产品入口或开源声明入口。
- 国际站已发布 V2 首页 locale 不受影响，继续只在 `isGlobal` 构建中启用。

## 发布站点与同步策略

- 发布范围：国内站 `lightvela.com`
- 国际站是否同步：否，本次以国内站跟进国际站中文版为目标，不反向修改国际站。
- 国内站是否同步：是
- 差异化原因：国内站登录、订阅、渠道、备案/合规、用户语境与国际站不同。
- 路由与内容影响：首页 `/`、首页文案、CTA、文档入口、页脚链接、metadata。
- 上线顺序：国内站单独上线。

## LightVela 影响面

- 前端页面/路由：`frontend/src/app/(site)/page.next.tsx`、`frontend/next-site/international-home-routing.ts`、`frontend/next-site/international-home-page.tsx`、`frontend/public/lightvela-intl-home/index-fragment.zh-CN.html`。
- Hermes/OpenClaw/运行时：无新增运行时接口。
- SkillHub/MCP/工具：无新增工具能力。
- SDK/文档/运营：影响首页渠道、Agent 能力、套餐入口的运营表达。
- 权限/安全/数据：无新增权限和数据采集；继续禁止脚本片段中出现不受控脚本或 `javascript:` 链接。

## 非功能性需求

- 性能指标：复用现有静态片段加载方式，不新增阻塞接口请求。
- 兼容性：沿用现有 Next static export 与桌面/移动端兼容要求。
- 安全与权限：静态片段仍需保持 script-free，外链必须使用 `target="_blank"` 与 `rel="noreferrer"`。
- 国际化 / 无障碍：国内站默认 `zh-CN`；本次不扩展国际站 locale。

## 产物交接

- 需要交接的角色/事项负责人：前端 owner、产品 owner、运营/内容确认人。
- 各方交付物：前端实现、国内站首页文案确认、测试与预览结果。
- 输入与依赖：国际站中文版 V2 首页现有片段、国内站渠道与合规口径。
- 时序和上线节点：随国内站前端分支预览验收后进入 MR。
- 责任人/待确认：最终国内站文案是否需要运营二次精修。

## 方案决策

- 采用方案：复用国际站中文版首页结构，国内站做内容与链路适配。
- 选择理由：实现范围可控，体验一致性好，避免重新设计带来的评审和实现成本。
- 备选方案与取舍：
  - 强国内增长版：更贴合增长目标，但需要额外设计与产品评审，本次不采用。
  - 先迁移后优化版：上线最快，但产品表达可能不够准，本次不采用。
- 延后或不做：更激进的首页转化实验、运营活动位、全新视觉设计。

## 验收标准

1. 访问 `lightvela.com/` 时，首页整体结构与国际站中文版保持一致，不再是明显落后一版的国内首页。
2. 国内站首页所有核心文案符合国内用户语境，不出现国际站专属支付、登录、渠道或海外合规表达。
3. 首页 CTA 对未登录、未订阅、已订阅用户分别进入正确的国内站路径。
4. 国内站页脚按截图展示品牌块和四列链接，品牌块文案为「Copyright © 2026 LightVela 版权所有 · 腾讯轻量云出品」，下方以同字号同色展示 ICP 备案号并保留适当行距，不再保留额外底部中文版权条：产品、对比、社区、公司四列文案与顺序正确；产品列包含钉钉接入指引；备案号链接到工信部备案入口；帮助与反馈链接到腾讯问卷入口；隐私政策和服务条款使用国内站正式外链。
5. 首页 hero 演示区的 tab 为微信、QQ、企业微信、钉钉、飞书，QQ 位于微信之后；微信面板展示金融监控 / 美股速览，QQ 面板展示原 Discord 社区赛提醒与时区换算对话，企业微信面板展示原 Slack 项目推进对话，飞书面板展示 DSH / 研发协作；QQ、企业微信、钉钉、飞书面板分别使用国内客户端外壳，但不渲染最左侧应用功能导航栏或右侧成员列表。微信、QQ、企业微信左侧会话栏为紧凑比例的「搜索框 + 独立加号按钮」；微信不出现筛选标签或分组入口；钉钉面板展示顶部窗口栏且文字图标以灰白中性色为主，飞书左侧标题为缩小后的图标加「消息」；聊天内容区不显示头像，气泡与 LightVela 颜色复用国际站首页原有 hero 预览色系，不额外引入平台蓝、微信绿或自定义浅紫皮肤，不显示 Telegram、Discord、Slack 等国际通道名称或主视觉。
6. 桌面端和移动端首页无明显布局错位、遮挡、文本溢出。
7. 国内站首页 metadata 使用国内站适配后的中文 title 和 description。
8. `pnpm i18n:check`、`pnpm check` 通过；如修改首页测试，相关 landing/page 测试通过。
