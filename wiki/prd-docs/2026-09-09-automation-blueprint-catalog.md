# 定时任务模板目录与多 Skill 能力升级

## 基本信息

- 当前产品：LightVela
- 需求单状态：已确认，进入研发评审
- 创建人：LightVela 产品与研发协作
- 创建日期：2026-09-09
- 最后更新时间：2026-09-09

## 需求背景

LightVela 的定时任务底层使用 Hermes Cron，但现有页面主要展示少量前端模板，无法完整表达 Hermes Automation Blueprint 已提供的场景和执行能力。模板任务说明偏技术化，部分语言会回退为英文；模板预置 Skill 与 Agent 实际安装状态不一致时，还会出现“不可用”并阻断用户理解。

本次升级把 Hermes Blueprint 能力转化为用户能直接理解和修改的定时任务模板，同时保留 LightVela 已有的本地化场景和原创建链路。

用户价值：用户可从真实场景模板开始，通过简短说明创建可运行的任务，不需要理解 Blueprint、Cron 或内部 Prompt。

业务价值：提高模板启用率和定时任务创建成功率，并减少因语言、Skill 状态和模板重复造成的流失。

## 目标用户与场景

- 目标用户：国内站及国际站使用 Agent 定时任务的个人用户。
- 典型场景：创建晨间简报、价格与库存监控、竞品动态监控、每日学习、膳食计划、交租提醒、健康提醒、感恩复盘等周期任务。
- 核心诉求：快速看懂模板用途，只修改与自己有关的对象、条件、主题或时间，然后可靠保存和执行。

## 目标

- 在现有 `/agents/automations/` 页面提供更完整、更真实的模板目录。
- 让模板预填内容保持简洁、符合当前界面语言并可直接修改。
- 完整支持 Hermes 新版的多个 Skill，并避免未安装的推荐 Skill 阻断创建。
- 国内站与国际站共用能力，按站点语言显示本地化内容。
- 不改变已有定时任务的创建、编辑、暂停、恢复、执行和通知语义。

## 范围

### 本次包含

- 升级现有模板，并补充 Hermes Blueprint 中已有但页面尚未展示的真实场景。
- 在原定时任务页面内优化模板卡片、分类、分页和外层低圆角容器。
- 为监控、学习、膳食等模板提供简洁且可修改的专属预填说明。
- 将执行约束作为内部规则随任务发送给 Hermes，不增加普通用户需要理解的配置项。
- 支持 Skill 搜索多选、删除、继续添加、完整保存和完整回显。
- 仅自动带入当前 Agent 已安装的推荐 Skill；保留未改动的历史失效 Skill。
- 在任务详情和运行记录中展示全部 Skill。
- Hermes 镜像保留模板需要的内置 Skill，并提供构建测试。
- 覆盖简体中文、繁体中文、英语、西班牙语、日语、韩语和印尼语。

### 本次不包含

- 不创建独立模板数据库或运营后台。
- 不直接执行 `/blueprint`，不新增第二套任务创建链路。
- 不迁移或修改用户已有任务。
- 不在本次解决测试运行约 2 至 3 分钟的等待体验；该问题作为后续体验优化。
- 不新增模型供应商或修复外部模型额度、QQ AppID/Secret 等环境配置问题。

- 优先级：P0
- 已知依赖：Hermes Cron、运行时 Blueprint Catalog、Agent Skill 安装状态、现有通知通道。

## 功能详细描述

### 1. 模板目录

模板目录合并 LightVela 精选模板、前端 Blueprint 基线和当前 Agent 运行时返回的 Hermes Blueprint。语义重叠的模板合并展示，避免出现用途相同的重复卡片；运行时读取失败时继续显示本地模板。

模板覆盖晨间简报、重要邮件、自定义提醒、晚间收尾、价格与库存监控、竞品动态、每周膳食、每日学习、感恩复盘、历史上的今天，以及原有喝水吃药、交租、汇率、健身、天气、股票等场景。

### 2. 页面呈现

- 保留原定时任务页面和每页六张模板的浏览方式。
- 外层增加低圆角容器，卡片使用紧凑的真实结果摘要，不新增独立模板页面。
- 提供日常、工作效率、监控提醒、健康生活和学习成长等分类。
- 卡片展示名称、用途、运行频率；条件型任务标明仅在需要时通知。
- 点击模板后打开现有新建任务弹窗并预填内容，不直接创建任务。

### 3. 简洁任务说明与内部规则

前端只展示用户需要理解和修改的内容，例如：

- 价格监控：监控对象或链接、目标价格或库存条件。
- 每日学习：学习主题。
- 膳食计划：人数、饮食偏好和时间限制。

监控类任务默认在达到条件或出现重要变化时提醒，并包含当前价格、差额、库存及来源链接；相同内容不重复提醒，无变化时返回 `[SILENT]`。这些规则由系统作为内部执行规则补充，不在任务说明中展开复杂技术细节。

### 4. 多 Skill

- “调用技能”支持搜索多选。
- 已选 Skill 显示为可删除标签，可继续添加。
- 新建、编辑和保存均使用完整 `skills[]`，不再只处理第一个 Skill。
- 模板推荐的多个 Skill 仅在当前 Agent 已安装时自动带入。
- 用户新增 Skill 时逐个校验是否安装。
- 编辑历史任务时，未修改但已经失效的 Skill 保留，避免无关数据丢失。
- 任务详情和运行记录展示全部 Skill。

### 5. 创建与执行

模板继续复用现有表单和 Hermes Cron 创建接口。用户可修改名称、执行时间、任务说明、Skill、通知方式和高级参数。保存时将可见任务说明、内部执行规则及完整 Skill 数组传给 Hermes。

### 6. 国际化

- 国内站默认展示简体中文。
- 国际站根据用户所选语言展示繁体中文、英语、西班牙语、日语、韩语或印尼语。
- 模板名称、用途、时间描述和任务预填说明全部本地化。
- 中文界面统一使用“定时任务”，不再出现中文字段搭配英文任务说明。

### 7. 异常与降级

- Blueprint Catalog 读取失败：静默回退到 LightVela 本地模板。
- 推荐 Skill 未安装：不自动选择，不显示不可用标签，不阻断创建。
- 历史 Skill 失效：编辑时保留并标识，不因保存其他字段被删除。
- 通知通道测试失败：明确提示检查通道配置，不影响用户继续编辑。
- 模型供应商暂不可用：运行记录保留 Hermes 返回的失败原因，不将其误判为模板创建失败。

### 8. 数据观测

沿用现有模板点击和创建事件，并记录 `template_id`、`template_source` 和 `template_category`，用于区分模板浏览与实际启用。

## 产品原型说明

- 目标页面：`/agents/automations/`
- 用户主路径：浏览或筛选模板 → 点击模板 → 修改预填内容 → 测试运行或创建 → 在任务列表查看状态和运行记录。
- 页面结构：模板目录、分类筛选、分页、任务列表、新建/编辑弹窗。
- 关键组件：模板卡片、Skill 多选器、任务说明输入框、通知通道、测试运行按钮。
- 关键状态：Catalog 加载失败、Skill 未安装、通知失败、任务执行失败、无任务空态。
- 原型处理：不另建独立原型；本次直接复用现有页面、本地预览和已确认截图进行评审。

## 发布站点与同步策略

- 发布范围：国内站 `lightvela.com` 与国际站 `lightvela.ai` 双站同步。
- 国际站是否同步：是。
- 国内站是否同步：是。
- 差异化原因：功能和数据结构一致，仅根据 locale 展示不同语言内容。
- 路由与内容影响：`/agents/automations/`、模板文案、任务说明、Skill 选择器及 i18n 字典；不新增公开路由，不影响 sitemap。
- 上线顺序：同一前端版本同步发布，按站点分别回归语言和通知配置。

## LightVela 影响面

- 前端页面/路由：定时任务页面、新建/编辑弹窗、任务详情和运行记录。
- Hermes/OpenClaw/运行时：Blueprint Catalog 读取、完整 `skills[]`、内部执行规则、Cron 创建与测试运行。
- SkillHub/MCP/工具：使用 Agent 已安装 Skill 列表进行推荐和校验；不新增 SkillHub 协议。
- SDK/文档/运营：本次 PRD 与研发设计说明进入同一 MR；暂无新增用户文档入口。
- 权限/安全/数据：不新增权限，不在模板中写入凭据，不暴露运行时路径和底层错误栈。

## 非功能性需求

- 性能：本地模板立即可见，运行时 Catalog 异步加载且不阻塞任务列表。
- 兼容性：沿用现有桌面端和移动端兼容范围。
- 安全与权限：Catalog 读取仅返回模板元数据，不创建任务、不写文件。
- 国际化：新增模板必须覆盖产品启用的七种语言，不使用英文作为中文或印尼语模板的默认预填。
- 无障碍：模板卡片保持键盘可操作，表单标签、禁用态和错误提示沿用现有语义。

## 产物交接

- 产品/设计：确认模板分类、卡片密度、中文术语和各场景预填内容。
- 前端：实现目录合并、页面呈现、多 Skill、i18n 和异常降级，并维护组件测试。
- Hermes/镜像：保留模板推荐的内置 Skill，验证镜像构建与存量实例升级策略。
- QA：双站覆盖模板预填、创建、编辑、多 Skill、通知和运行记录；至少使用一个测试 Agent 完成真实通知验收。
- 发布运维：按现有前端及 Hermes 镜像流程发布，核对 live revision、workload image 和公网静态资源 hash。

## 方案决策

- 采用方案：在现有定时任务页面内合并 LightVela 模板和 Hermes Blueprint，并通过内部规则与安装状态适配屏蔽技术复杂度。
- 选择理由：复用现有可靠创建链路，用户无需学习 Blueprint 命令，同时能够随 Hermes 能力升级。
- 备选方案：单独创建 Blueprint 页面或直接让用户输入 `/blueprint`；因入口割裂、理解成本高且会形成第二条创建链路而不采用。
- 延后：测试运行提速、单次试跑防重复点击和更明确的预计完成时间。

## 验收标准

1. 国内站和国际站进入 `/agents/automations/` 均能看到升级后的模板目录，功能结构一致且文案随 locale 变化。
2. 简体中文、繁体中文、英语、西班牙语、日语、韩语和印尼语的模板名称、用途与任务说明不存在非预期英文回退。
3. 价格监控、每日学习和膳食计划等模板提供简洁、可修改的专属预填内容。
4. 监控类任务在无变化时支持 `[SILENT]`，有变化时包含关键状态和来源，并避免重复提醒。
5. Skill 可搜索多选、删除和继续添加；新建、编辑、保存、详情及运行记录均保留完整 Skill 数组。
6. 模板推荐 Skill 未安装时不自动带入、不显示为不可用，也不阻断任务创建。
7. Hermes Catalog 不可用时，本地模板和现有任务管理功能仍可使用。
8. 相关单元测试、组件测试、i18n 校验和类型检查通过；真实测试 Agent 能创建任务并通过已配置通道收到执行结果。

## 发布与观测

- 灰度/开关：沿用现有分支预览和前端发布流程，无新增产品开关。

- 回滚：回滚前端版本即可恢复原模板目录；镜像内保留 Skill 为兼容性增加，不修改用户任务数据。
