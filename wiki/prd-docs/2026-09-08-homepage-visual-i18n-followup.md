# LightVela 国际站首页顶部入口与多语言展示修复

## 基本信息

- 当前产品：LightVela 国际站官网首页。
- 需求单状态：已确认，待 MR 评审、合并与发布。
- 创建人：Keria / Codex。
- 创建日期 / 最后更新时间：2026-09-08 / 2026-09-08。
- 需求来源：国内站与国际站首页上线后的视觉及多语言回归反馈。

## 需求背景

国际站新版首页上线后，简体中文与繁体中文 Footer 沿用了国内站布局标记，导致“相关产品”单独换到第二行；同时 Footer 行动文案、栏目标题和部分链接残留英文。日语与韩语首屏动态标题还存在句尾早于轮播词出现的问题。国际站页头还重复展示了“开始使用”入口，需要只保留语言切换及登录/头像入口。

这些问题会让用户误以为页面尚未完成本地化或站点之间存在非预期差异，影响首页的专业感、可读性和转化入口理解。

## 目标用户与场景

- 目标用户：访问 `lightvela.ai` 各语言首页的海外用户。
- 典型场景：用户首次进入首页，通过页头切换语言或登录，在首屏理解产品定位，并在页尾查看产品、分析、社区、公司和相关产品入口。

## 目标

- 国际站首页页头不再显示重复的“开始使用”入口。
- 国际站简体中文与繁体中文 Footer 使用国际站布局，并完成对应中文本地化。
- 国际站各语言 Footer 在桌面和移动端保持稳定、无横向溢出。
- 日语、韩语首屏标题的动态词与句尾按完整语义同步出现。

## 范围

### 本次包含

- 国际站首页顶部移除重复的“开始使用”入口，保留语言切换和登录/头像入口。
- 国际站 `zh-SG`、`zh-Hant` Footer 移除国内站专属布局标记，桌面使用品牌列加五个链接栏的六列布局。
- 国际站 `zh-SG`、`zh-Hant` Footer CTA、栏目标题和链接分别使用简体中文、繁体中文。
- 国际站中文版权固定为两行英文：第一行 `© 2026 LightVela. All rights reserved.`，第二行 `Built by Tencent Lighthouse.`。
- 日语 `になります`、韩语 `입니다` 与动态角色词共享入场时机；移动端和减少动态效果场景直接完整显示。
- 同步静态片段生成器、运行时、样式、资源版本和回归测试。

### 本次不包含

- 不重新设计首页、Footer 或导航的信息架构。
- 不调整登录、订阅、支付、渠道、套餐或后端能力。
- 不修改国内站页头、Hero、Footer、文案或布局；国内站保持当前线上行为。
- 不翻译产品名、渠道名和平台品牌等专有名词，例如 LightVela、Hermes Agent、WhatsApp、Discord、Tencent EdgeOne。
- 不新增埋点、实验开关、原型或独立活动页面。

- 优先级：P0。
- 已知依赖：国际首页静态片段导入器、Next 首页运行时、双站编译期区域配置。

## 功能详细描述

### 1. 国际站顶部入口

- 国际站首页不再显示重复的“开始使用”入口。
- 未登录状态保留登录按钮；已登录状态保留头像入口。
- 语言切换入口和既有导航不受影响。

### 2. 国际站中文 Footer

- `zh-SG` 与 `zh-Hant` 使用国际站通用 Footer 网格。
- 桌面宽度下六个区块必须同一行：“品牌、产品、分析、社区、公司、相关产品”。
- 移动端按现有断点切换为单列，不强制压缩成多列。
- 简体中文栏目使用“产品、分析、社区、公司、相关产品”；繁体中文使用“產品、分析、社群、公司、相關產品”。
- CTA、试用、定价、接入指引、分析、公司和相关产品文案均使用对应简繁体；品牌专名保持原文。
- 英文版权严格保留一个显式换行，不合并为单行，也不改写成中文。

### 3. 日语、韩语动态标题

- 日语首屏句式保持“LightVelaはあなたの + 动态角色词 + になります”。
- 韩语首屏句式保持“LightVela는 당신의 + 动态角色词 + 입니다”。
- 桌面端句尾与动态角色词使用同一个延迟变量入场，不允许句尾先出现。
- 移动端及 `prefers-reduced-motion: reduce` 场景不执行入场动画，动态词和句尾直接以完整、可读状态显示。

## 发布站点与同步策略

- 发布范围：仅国际站 `lightvela.ai`。
- 国际站是否同步：是；包含 `en-US`、`zh-SG`、`zh-Hant`、`id-ID`、`es`、`ja-JP`、`ko-KR`。
- 国内站是否同步：否；本需求不修改 `lightvela.com` 的页面行为或展示。
- 差异化原因：本轮问题只出现在国际站，国内站当前展示符合预期。
- 路由与内容影响：国际站首页页头、国际站中文 Footer、国际站日语和韩语首屏动态标题。

## LightVela 影响面

- 前端页面/路由：国际站首页运行时、国际站静态片段、样式与生成器。
- Hermes/OpenClaw/运行时：无影响。
- SkillHub/MCP/工具：无影响。
- SDK/文档/运营：新增本 PRD 与评审说明，不修改产品文档站或 SDK。
- 权限/安全/数据：无新增权限、接口或数据采集。

## 非功能性需求

- 性能：不新增网络请求或阻塞资源；沿用现有静态首页加载方式。
- 兼容性：沿用现有桌面和移动端浏览器要求；重点验证 1280px 桌面与小于 640px 的移动断点。
- 安全与权限：无新增安全边界；静态片段继续禁止不受控脚本与 `javascript:` 链接。
- 国际化：国际站公开语言均需完成静态文案核对；简中与繁中必须区分字形和用词。
- 无障碍：减少动态效果场景必须保持完整文案可见；页头登录入口的既有可访问名称不变。
- 页面与链接：现有 locale 路由前缀和链接目标保持不变；页面不得产生横向溢出。

## 方案决策

- 采用方案：在现有首页结构内做最小差异化修复，并把规则同步到生成源、静态产物和回归测试。
- 选择理由：不改变已确认的信息架构，影响范围可控，同时防止后续重新生成静态片段时回退。
- 备选方案与取舍：统一双站 Footer 结构会破坏国内站既有栏目和合规口径，本次不采用；只手改静态 HTML 无法防止生成器覆盖，本次不采用。
- 延后或不做：整页视觉重构、全站历史翻译缺口清理、真实设备专项兼容测试。

## 验收标准

1. 国际站首页顶部不显示重复的“开始使用”入口，语言切换与登录/头像入口正常；国内站行为与本次修改前一致。
2. 国际站 `zh-SG`、`zh-Hant` Footer 桌面端六个区块同一行，移动端为单列，页面无横向溢出。
3. 国际站简中、繁中 Footer CTA、栏目标题和链接分别使用对应中文，品牌专名保持原文。
4. 国际站中文版权严格显示为指定英文两行，中间仅一个显式换行。
5. 英语、印尼语、西班牙语、日语、韩语 Footer 保持各自本地化文案和国际六列布局。
6. 日语 `になります`、韩语 `입니다` 在桌面端与动态词同步入场，移动端及减少动态效果场景完整可见且不提前闪现。
7. 相关 Vitest、i18n 校验、类型基线与 `git diff --check` 通过；国际站本地页面完成桌面和移动端浏览器回归。
