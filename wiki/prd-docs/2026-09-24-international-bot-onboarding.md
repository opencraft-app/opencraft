# 国际站开放 Bot 创建引导与 Agent 总览

## 基本信息
- 产品：LightVela；日期：2026-09-24。
- 状态：用户已确认方案 A，授权核对国际站模板后启动实施；尚未发布。

## 背景与目标
国内站已有新的 Bot 创建引导，国际站已开放多 Bot，但创建引导和总览仍被区域开关关闭。国际站用户应在订阅成功后创建首个 Bot、已有套餐首次创建及新增 Bot 时进入现有引导，完成配置后进入对应 Bot 的总览页。

## 范围与方案
- 国际站全量开放现有引导与总览。存量用户直接访问 `/agents` 默认进入总览，显式访问通道等子页面仍保留目的地。
- 复用头像、名称、描述、模板、空白创建与从现有 Bot 复制的交互；默认空白创建，复制由用户主动选择。
- 保留按区域解析的模板：国际站使用现有英文模板、skills.sh 和 Hermes 官方 GitHub 技能；国内专属模板不进入国际站。
- 存量 Bot 不因开启功能被强制重新引导；新建标记、未完成配置恢复与显式引导意图沿用现有逻辑。
- 不改套餐、配额、支付、后端 API、技能目录或其他隐藏工具。不增加新的灰度系统。
- 备选分批开放需要增加灰度控制及两套流程维护；用户选择直接全量开放。

## 已核对的模板
国际站现有 7 个模板：Health Steward、Market Analyst、Industry Researcher、Morning Briefing、AI Study Buddy、Growth Experimenter、Social Muse。
Health Steward 不安装额外技能；Market Analyst 使用 Hermes 官方 `optional-skills/finance/stocks`；其余使用 skills.sh 的 research、teach、marketing-ideas、social-content。
育儿参谋、防骗员、编程搭子为国内专属，不出现在国际站。此结论来自本地定义与测试，不代表已在生产实例完成真实安装验证。

## 流程与异常
1. 订阅成功并同步权益后，无 Bot 用户进入新创建引导；重复回跳且已有 Bot 时不重复创建。
2. 已有套餐无 Bot 时，“新建 Bot”进入首个 Bot 引导；有 Bot 时进入额外 Bot 引导并可选择复制来源。
3. 实例准备及配置写入使用目标 Bot/profile；完成后刷新列表并进入 `/agents/overview?bot=<新 Bot ID>`。
4. 创建失败显示错误；配置中断沿用已有恢复机制。额度不足禁止提交，额外 Bot 仍受多 Bot 运行时开关限制。

## 发布站点与内容
- 发布范围：国际站 lightvela.ai；国内站已有行为保持一致，执行回归验证。
- 国际站中文与其他现有 locale 沿用现有翻译与区域模板，不把国内技能源随语言切换带入国际站。
- 使用现有私域页面和路由，无新增公开索引页面、metadata 或 sitemap 范围。
- 无新增权限和性能要求，沿用现有兼容性与无障碍行为。

## 验收标准
- 国际站订阅后、首个 Bot、额外 Bot 创建均进入新引导，默认模板来自国际站目录。
- 完成配置后落到创建目标的总览页，不误跳主 Bot，不把技能/人设写入其他 profile。
- 存量用户看到总览入口，默认进入总览，无创建意图时不弹引导。
- 国内专属模板不泄漏；国际技能安装命令保留 skills.sh/GitHub 来源及 profile 定向。
- 额度、多 Bot 开关、失败展示和中断恢复继续有效；国内站创建流程不回退。
- 聚焦测试、前端 check/test/build、生成层漂移检查与文档门禁有真实结果记录。

## Demo 与交接
复用已实现的国内站页面结构和国际模板，无新增页面设计，跳过独立 Demo。前端交付开关变更与回归测试；QA 覆盖国际站语言、订阅回跳、新增/复制、额度及失败恢复；发布负责人在审批后发布国际站前端并验证实际创建与安装。

## 发布与观测
通过前端构建发布全量开放，检查创建成功、目标跳转与配置失败反馈。回滚恢复区域开关并重新发布前端。用户已授权合并最新 master、审查后提交并创建 MR；TAPD 和生产发布不在此次交付范围。
