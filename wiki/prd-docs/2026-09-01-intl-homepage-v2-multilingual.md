# LightVela 国际站 V2 多语言首页接入

## 基本信息

- 当前产品：LightVela 国际站
- 需求单状态：已确认，待 MR 评审
- 创建日期：2026-09-01
- 最后更新时间：2026-09-01
- 发布范围：仅国际站 `lightvela.ai`

## 需求背景

国际站已有一套完成视觉验收的 V2 首页设计，但正式站仍使用旧首页，且不同语言的页面结构、图片、交互动效和本地化完整度不一致。用户在多轮本地验收中进一步确认：简体中文页面作为结构与动态基准，繁体中文对齐简体中文效果，其他语言使用英文版标题字体基准，同时保留现有本地页脚、用户评价和 DeepSeek Harness 模块。

如果不完成本次接入，国际站不同语言之间会继续出现聊天演示静态、语言切换后动态失效、标题字体和换行不一致、CTA 遗留英文以及资源缺失等体验问题。

## 目标用户与场景

- 目标用户：访问 LightVela 国际站的英文、简体中文、繁体中文、印尼语、西班牙语、日语和韩语用户。
- 典型场景：
  - 用户从首页快速理解 LightVela 的云端 AI 伙伴定位与能力。
  - 用户切换 WhatsApp、Telegram、Discord、Slack，查看与真实产品语境一致的动态对话演示。
  - 用户通过场景与产品模块了解自动任务、工作台和 DeepSeek Harness。
  - 用户在站内切换语言后继续获得完整动效，而不需要强制刷新。
  - 用户通过首页导航、CTA 和页脚进入订阅、文档、Agent 工作台及社区链接。

## 目标

- 将已验收的 V2 首页接入国际站全部已发布首页语言。
- 让七个国际站语种共享同一页面结构、交互动态和正式导航契约。
- 消除本地化页面中的英文回退、破图、标题异常换行和语言切换后动效丢失。
- 保持国内站，以及国际站其他公开页面的主体内容、认证、订阅及 Agent 业务逻辑不变。

## 范围

### 本次包含

- 国际站首页语言：`en-US`、`zh-SG`、`zh-Hant`、`id-ID`、`es`、`ja-JP`、`ko-KR`。

- 简体中文与繁体中文保持中文版字体；英文、印尼语、西班牙语、日语、韩语标题使用英文版 editorial 字体基准。
- 印尼语与西班牙语长 Hero 标题在桌面端保持一行；印尼语能力区长标题在桌面端保持一行。

- 不修改 About、Changelog、Docs、Subscribe 等其他公开页面的主体设计。
- 不修改认证、计费、订阅、Agent 创建、后端 API 或发布配置。

## 功能详细描述

### 1. 首页路由与静态输出

- 仅当 `isGlobal === true` 且 locale 属于七个已发布国际站语种时渲染 V2 首页。
- 国内站与 `zh-CN` 继续渲染现有 `PublicHomePage`。
- 页面正文在服务端构建阶段读取仓库内 fragment，进入静态导出 HTML；不使用 iframe，不依赖客户端请求后再显示正文。

### 2. Hero 与渠道动态

- 主标题逐字入场，动态副标题持续轮播 LightVela 可承担的角色。
- 四个渠道标签可切换对应演示；切换时从首条消息重新播放。
- 对话按角色、消息顺序、打字状态与滚动位置逐步呈现。
- 站内切换语言时移除旧语言动态脚本，并以新 locale 重新加载 runtime、hero-chat、scene-wheel 三段脚本。

### 3. 多语言字体与版式

- 简体、繁体中文使用中文版字体与尺寸基准。
- 其他语言的营销标题使用英文版 serif editorial 字体栈。
- 长标题只在足够宽的桌面视口强制单行；中等桌面按固定断点缩小字号；移动端允许自然换行，不能产生横向溢出。
- 页面文字不得遮挡相邻内容，图片不得拉伸、破图或使用错误语种。

### 4. 产品模块与保留模块

- “LightVela 可以做什么”、免费试用 CTA 等已指定区域完整同步 V2 结构和动态。
- 自动任务、工作台、DeepSeek Harness 以鼠标悬停切换当前内容，不要求额外点击。
- 页脚、用户评价、DeepSeek Harness 的本地定制模块不被远端模板覆盖。

### 5. 导航与账号入口

- 国际站首页及其他公开页面顶部复用同一套生产语言切换器和登录入口；未登录时只保留语言切换与黑色登录按钮，不展示“立即创建”或 Free trial。
- 顶部品牌入口只渲染透明 SVG 完整字标，不重复展示第二个 `LightVela` 文本。
- 所有站内链接按当前 locale 保留前缀；外部社区与相关产品链接在新窗口打开并带 `noreferrer`。
- Hero、产品 CTA、试用入口分别进入正式 Agent 或订阅落点。

### 6. 异常与边界

- 动效资源加载失败时记录错误，不阻塞静态正文展示。
- 认证服务暂时不可用时沿用 SessionProvider 现有未登录降级行为，本需求不修改认证错误策略。
- 用户启用 reduced motion 时缩短动画时间，保持内容可见。

## 发布站点与同步策略

- 发布范围：国际站 `lightvela.ai` only。
- 国际站是否同步：是，覆盖七个已发布首页语种。
- 国内站是否同步：否。
- 差异化原因：本次页面源、海外渠道、国际语言与正式导航均面向国际站；国内站保留现有首页与 `zh-CN` 路由。
- 路由与内容影响：国际站 `/`、`/zh-sg/`、`/zh-hant/`、`/id-id/`、`/es/`、`/ja-jp/`、`/ko-kr/` 首页及其静态资源。
- 上线顺序：合并后随国际站前端发布；国内站构建由负向路由测试保护。

## LightVela 影响面

- Hermes/OpenClaw/运行时：无后端运行时变更，仅展示首页产品场景。
- SkillHub/MCP/工具：无变更。
- SDK/文档/运营：新增本 PRD 与 OpenSpec 规格；不修改 SDK。
- 权限/安全/数据：无新增权限、Cookie、接口或用户数据处理。

## 非功能性需求

- 性能：静态正文可直接输出；动效脚本只在 V2 首页挂载；非首屏图片沿用懒加载。
- 兼容性：沿用现有国际站浏览器兼容范围；桌面和移动端均不能出现横向溢出。
- 安全：HTML fragment 必须来自仓库内审核过的生成物；禁止 `javascript:`、空锚点、本地 HTML 路径和未解析资源；外链必须使用安全属性。
- 国际化：七个 locale 的导航、Hero、演示、场景、CTA 和页脚不得出现非预期英文或中文回退。
- 无障碍：图片保留 alt，图标按钮保留 aria-label，reduced-motion 下内容仍可访问。

## 方案决策

- 采用方案：国际站专用 Server/Client 首页组件 + 仓库内多语言静态 fragment + 三段受控动态脚本。
- 选择理由：保留静态导出与 SEO，最大程度复用已验收视觉和动态，同时通过区域/locale 选择函数保护国内站。
- 备选方案与取舍：
  - iframe：接入快，但 SEO、滚动、导航和账号控件集成较差，不采用。
  - 全量重写 React 组件：长期可维护性更统一，但改写面和视觉回归风险过大，本次不采用。
- 延后或不做：不重构现有静态页面生成体系，不扩展后端或埋点。

## 验收标准

1. 七个国际站首页 locale 均渲染对应语言 fragment，国内站与 `zh-CN` 不选择 V2 首页。
2. WhatsApp、Telegram、Discord、Slack 均可切换并播放对应动态；站内切换语言后动态无需强制刷新即可重新绑定。
3. 简繁中文字体与中文版一致，其他语言标题字体与英文版一致；印尼语和西班牙语指定长标题桌面端保持一行，移动端无横向溢出。
4. 印尼语、西班牙语、日语、韩语免费试用 CTA 无英文回退。
5. 页脚、用户评价、DeepSeek Harness 保持已确认的本地模块，图片无破图或错语种。
6. 首页顶部只显示一个完整 LightVela 字标，不出现重复品牌文字；国际站其他公开页面的账号区与首页一致，仅显示语言切换和黑色登录按钮。
7. 所有站内外链接均使用正式落点；外链安全属性完整。
8. 定向测试、类型检查、国际化检查、国际站构建和 `git diff --check` 通过；浏览器 smoke 无新增页面错误。
