## 背景、用户与目标
原总览位于 Bot 选择器下方，只展示当前 Bot 的资料卡。创建更多 Bot 的入口藏在左侧选择器附近，用户需要先切换才能查看和管理其他 Bot。

目标用户为国内站和国际站已订阅、拥有一个或多个 Bot 的个人用户。用户可以直接发现创建入口、同时查看多个 Bot，并明确地修改、复制或删除指定 Bot。

本次保留原页面视觉和已有业务流程，将总览入口移至左侧最上方，将单 Bot 资料区升级为多 Bot 卡片区；顶部统计根据后续确认改为账号相关信息。具体布局及交互以下文为准，不追加其他设置入口。

## 范围与非目标
包含：导航位置、My Bots 列表及创建入口、资料编辑/复制/删除、当前 Bot 角标、按数量调整布局及横向分页、顶部统计、六种翻译语言兼容。

沿用：原头像、资料弹窗与保存流程、创建引导、删除确认、配额和权限校验、最新动态、定时任务推荐。修复最新动态中定时任务图片的旧路径，使用仓库已有 WebP 图片。

不包含：重做原页面风格、卡片内通道/定时任务/打开 Bot 等快捷入口、批量操作、跨 Bot 任务汇总、团队权限、新套餐、后端多 Bot 机制、云资源和生产配置变更。

## 站点与开关
- 当前实现和本地验收范围：国内站 `lightvela.com` 与国际站 `lightvela.ai`。
- 双站共用同一套新总览，由现有多 Bot 开关及原总览/引导开关共同控制；关闭时沿用旧单 Bot 总览与导航。
- 国内站同步全部已确认的总览交互；创建模板、实名、配额、邀请功能等继续使用各站现有规则。源码同步不等于双站已发布。
- 已邀请好友与账号管理页共用 `referralEnabled` 开关。关闭时不展示该指标，也不请求邀请统计。
- 使用既有 `/agents/overview` 和 `/account`，不增加公开路由或调整 SEO、sitemap。

## 页面结构与导航
从上到下：原顶部横幅 → 我的 Bots → 最新动态 → 原定时任务推荐。

- 左侧总览入口位于 Bot 选择器及 Explore/Chat 上方；移除额外的“Bot workspace”标题。
- 原 Bot 选择器和其他菜单继续使用。切换左侧 Bot 只改变当前 Bot 及后续工作区上下文，不缩小总览的列表范围。
- 旧的带 `?bot=` 的总览链接兼容；列表始终来自当前账号授权可见的 Bot 集合。
- 点击卡片打开资料编辑，不切换当前 Bot。进入单 Bot 工作区仍通过左侧导航。

## 顶部横幅
保留原背景、徽章、服务天数、有效期、数字样式、卡片圆角和间距。移除原顶部定时任务、工作台两项，不做跨 Bot 汇总。

| 指标 | 数据口径 | 无数据表现 | 点击去向 |
| --- | --- | --- | --- |
| 剩余积分 | 原账户套餐额度 | 沿用原行为 | 套餐与费用 `/account/billing`（国内、国际双站） |
| Bot 数量 | 与 My Bots 同一份列表的总数，包含列表返回的各生命周期状态 | 加载或读取失败为“—”；成功空列表为 0 | 总览 `/agents/overview` |
| 已邀请好友 | 账号管理页同源的成功邀请人数，即 `getReferralStats().successfulReferrals` | 无数据、字段缺失、加载中、请求失败统一显示 0 | 账号管理 `/account` |

已邀请好友的 0 是用户指定的显示回落，不代表接口失败时能够确认真实人数为零。不发放邀请码、不新增邀请资格或奖励计算。

## 我的 Bots
### 创建入口
- 标题右侧保留带加号的“创建 Bot”文字按钮，采用完整胶囊圆角。
- 移除空白创建卡片、列表刷新按钮和左右翻页箭头。
- 点击创建复用原引导；默认空白创建，不直接创建资源。
- 达到配额时按钮禁用并显示原限制原因；列表加载或失败时禁用创建。
- 套餐、实名、所属账号、数量限制及后端权限仍由现有流程校验，不增加旁路。
- 保留原创建进度页、自动恢复及完成跳转，新 Bot 由真实列表刷新后展示。

### 布局与滑动
| Bot 数量 | 桌面布局 | 滑动引导 |
| --- | --- | --- |
| 0 | 展示空态说明与标题旁唯一创建按钮 | 无 |
| 1 | 一张卡片占满内容区 | 无 |
| 2 | 一行两张，各占一半，扣除原卡片间距 | 无 |
| 3 | 一行三张 | 无 |
| 大于 3 | 单排横向排列，同屏三张 | 提示文字与底部分页点 |

中等屏幕最多两张并排，手机一张；三张以内保持响应式网格，超过三张保持横向滑动。

- 超过三张时隐藏系统滚动条，标题下显示“左右滑动查看更多 Bot”。
- 支持触控板、触屏及键盘原生滚动；底部圆点可点击定位到对应页。
- 当前页用黑色短条，其他页用灰点，居中紧凑排列。手动滑动同步当前页。
- 页数随可见宽度调整；末页贴齐内容末端，允许与上一页重复展示部分卡片。
- 卡片无阴影，4px 圆角，与相邻板块保持一致。资料保存返回列表后恢复分页监听。

### 卡片内容与操作
- 保留头像、名字、简介、名字右侧状态、右上角三点菜单；不增加卡片底部操作区。
- 名字过长省略显示并保留完整标题，简介最多两行。
- 当前选中的 Bot 左上角显示黑底白字“当前 Bot”，跟随左侧选择，不因编辑其他卡片而切换。
- 头像和默认插画复用原逻辑；名字与简介读取目标 Bot 的资料，失败时采用同一目标缓存或列表回落，不能展示另一 Bot 的资料。
- 整卡点击打开原资料编辑弹窗；三点菜单独立点击，不同时触发整卡编辑。
- 三点菜单固定顺序：修改资料 → 复制 Bot → 删除。

| 操作 | 行为与门禁 |
| --- | --- |
| 修改资料 | 运行中、目标 profile 已知、资料读取完成后可用；复用原弹窗的头像预览、形状、换一批、名字、可选描述、取消和保存。保存绑定所点 Bot/profile，成功后刷新资料 |
| 复制 Bot | 复用现有创建引导并预选所点 Bot 为来源；来源需运行中且 profile 已知，并满足创建配额；提交前仍可在原引导调整 |
| 删除 | 传入所点 Bot，复用原删除确认及风险文案，输入该 Bot 名称后确认；主 Bot 有同实例其他 Bot 时禁止删除，未知同实例 Bot 的警告沿用原逻辑 |

创建中和删除中的卡片保留状态并禁用菜单。暂停、失败或 profile 未就绪时禁用需要运行环境的编辑与复制；修复和详细设置仍从原工作区进入。保存期间使用原进度与错误视图，切换目标或卸载不会把后续写入改到另一 Bot。

## 状态与异常
| 场景 | 预期 |
| --- | --- |
| 首次加载 | 沿用页面原加载流程；创建入口不可提交 |
| Bot 列表失败 | 显示列表失败提示，不将失败解释为空账号；顶部 Bot 数量显示“—” |
| 成功空列表 | 显示空态及一个创建入口，Bot 数量显示 0 |
| 资料读取失败 | 保留目标回落信息或同目标缓存；按原读取状态决定编辑是否可用 |
| 创建/删除中 | 原流程接管时显示原状态页；卡片可见时展示对应状态并禁用不适用操作 |
| 配额已满 | 显示创建限制原因，创建和复制不可用 |
| 初次引导/套餐升级 | 原引导及升级状态优先，不被新总览抢占 |
| 邀请统计失败或空值 | 按用户要求显示 0，仍可点击进入账号管理 |

## 多语言与无障碍
- 简体中文作为原文，覆盖英文、繁体中文、印尼语、西班牙语、日语和韩语六个翻译版本；新加坡简体中文复用既有简体词典映射。
- 范围包括顶部指标、My Bots 标题/说明、创建按钮、状态、当前 Bot 角标、菜单、滑动提示和页数，以及复用的资料弹窗、动态与推荐任务。
- 保留页数变量替换，不出现未解析 key、占位符或缺失译文。用户填写的 Bot 名称和简介不自动翻译。
- 卡片与分页使用可键盘访问的按钮，图标按钮有可读名称；资料弹窗沿用原焦点管理并提供语义标题与描述。原删除弹窗的行为不在本轮重新设计。

## 数据及实现边界
- Bot 集合、生命周期、配额来自现有 context 和 Repository；资料按 `botId + profileId` 隔离。
- 复用现有创建、复制、删除及资料保存流程，不新增服务接口或权限。
- 卡片挂载时读取资料，不新增各 Bot 的定时任务聚合或任务摘要请求。当前父页面原 `useHeroStats` 仍会读取当前 Bot 任务数和工作台数量，虽新横幅不展示；这是可后续收敛的非阻塞请求冗余。
- 邀请统计仅在邀请功能开启时读取，组件卸载后丢弃返回结果；不请求邀请码写入接口。
