# 云存储页面增加实例存储容量展示

## 基本信息

- 状态：需求已确认，进入研发
- 优先级：P1
- 日期：2026-09-02
- 适用范围：国内站与国际站 `/agents/files`

## 背景与问题

当前云存储页面只展示目录和文件大小，用户无法判断 Agent 实例磁盘还剩多少空间。上传较大文件或长期积累运行数据时，用户可能在空间不足后才发现问题。

页面现有文件能力已经通过 TAT/TSSH 通道连接 Agent 实例，并可执行固定命令，因此本期可以复用同一通道查询文件系统容量，不需要新增后端接口。

## 目标

在云存储页面标题下方增加“实例存储”容量卡片，展示：

- 已用容量 / 总容量；
- 剩余可用容量；
- 当前使用率进度条；
- 查询中的加载态和查询失败的独立错误态。

帮助用户在上传或清理文件前，快速判断实例磁盘空间是否充足。

## 产品口径

“实例存储”指 `/home/agentuser` 所在文件系统的实际磁盘容量。已用空间不仅包含云存储页面可见的用户文件，也包含操作系统、Agent 运行环境、依赖、日志及同一文件系统上的其他数据。

因此，本功能不是“云存储目录文件大小汇总”，也不是业务配额或可扩容额度。

## 用户故事

作为使用云存储的 Agent 用户，我希望进入页面时看到实例磁盘的已用、总量和剩余空间，以便在上传文件或清理数据前判断容量是否充足。

## 功能方案

### 展示位置与内容

容量卡片位于云存储页面标题和说明下方、文件操作区上方。卡片展示：

- 标题：`实例存储`；
- 辅助说明：容量包含 Agent 运行环境和云存储文件；
- 数值：`已用 {used} / {total}`；
- 数值：`剩余 {available}`；
- 进度条：`used / total`，范围限制在 0%–100%。

容量单位复用页面现有文件大小格式，按 B、KB、MB、GB、TB 自动转换。

### 查询方式

前端复用现有 `TencentTsshFileClient.execCommand()`，通过 TAT/TSSH 的 `PtyExecCmdStream` 执行固定的只读查询命令。

命令读取 `/home/agentuser` 所在文件系统的 `statvfs` 信息，并只输出以下 JSON 字段：

```json
{
  "total_bytes": 53687091200,
  "used_bytes": 10737418240,
  "available_bytes": 42949672960
}
```

命令不拼接用户输入、当前目录或文件名，不输出目录内容及其他敏感信息。

### 刷新时机

以下场景重新查询容量：

1. 首次进入云存储页面；
2. 用户点击文件列表的刷新按钮；
3. 文件上传成功后；
4. 文件或目录删除成功后。

本期不增加定时轮询。切换目录、创建文件夹或重命名时不主动刷新容量。

### 状态与异常

- 加载中：卡片保留稳定结构，显示“正在查询存储容量”；
- 成功：显示容量数值和进度条；
- 失败：显示“存储容量暂不可用”；
- 容量查询失败不得影响目录浏览、上传、下载、重命名和删除；
- 用户可通过现有刷新按钮重新查询。

## 双站与本地化

国内站和国际站使用同一组件和同一数据逻辑。新增文案进入现有 i18n 提取和翻译流程，覆盖所有已开放 locale；不得只在中文或英文环境生效。

## 验收标准

1. 国内站和国际站进入 `/agents/files` 后，标题下方均显示“实例存储”容量卡片。
2. 查询成功时，已用、总量、剩余空间和进度条均与命令返回数据一致。
3. 页面首次进入、手动刷新、上传成功、删除成功后均会重新查询容量。
4. 容量查询失败时显示独立错误态，文件列表仍能正常加载和操作。
5. 进度条具备可访问名称、最小值、最大值和当前值；容量数字使用等宽数字排版。
6. 查询命令固定且只读，不包含用户输入，也不输出目录、文件名或凭据。
7. 不新增后端接口，不使用 debug/exec，不引入新的轮询或第三方依赖。

## 非目标

- 统计 `/home/agentuser/.hermes` 或当前目录的文件总大小；
- 新增业务配额、套餐容量、扩容入口或容量不足通知；
- 展示容量历史趋势；
- 定时轮询；
- 新增后端容量接口或修改 TAT 协议；
- 调整现有文件管理业务行为。

## 埋点与观测

本期不新增业务埋点，复用现有页面曝光与前端错误监控。容量查询错误只记录必要的失败上下文，不记录命令输出中的额外实例信息。

## 风险与应对

- Python 不可用或命令执行失败：展示独立错误态，不阻塞文件功能。
- 文件系统返回异常值：严格校验非负有限数字，总量必须大于 0，否则按失败处理。
- 切换 Agent 时旧请求晚返回：使用请求序号丢弃过期结果。
- 已用容量包含系统和运行环境：通过“实例存储”命名与辅助说明明确口径。

## 原型说明

本需求是在现有页面中增加一张信息卡片，不改变页面主流程和信息架构，因此不单独制作交互原型；最终视觉沿用现有工作台卡片、颜色和响应式规范。
