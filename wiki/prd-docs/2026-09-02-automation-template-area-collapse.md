# 自动任务模板专区折叠与视觉收敛

## 基本信息

- 当前产品：LightVela Agent 控制台 / 自动任务
- 需求单状态：草稿，待确认
- 创建人：待确认
- 创建日期：2026-09-02
- 最后更新时间：2026-09-02
- 发布范围：国内站 `lightvela.com` 与国际站 `lightvela.ai` 自动任务控制台同步

## 需求背景

自动任务页面的模板专区默认完整展开，占用较多首屏空间；当用户已经熟悉模板能力或主要想查看现有任务时，模板卡片会干扰任务列表浏览。同时，模板专区外层卡片和模板卡片圆角偏大，和控制台内其他工作型界面的收敛、轻量视觉不一致。

本需求独立于国际站首页改版，只处理 Agent 控制台自动任务页面的模板专区展示方式。

## 目标用户与场景

- 目标用户：使用 LightVela 自动任务创建周期提醒、工作总结、行情监控等任务的用户。
- 典型场景：
  - 用户首次进入自动任务页时，需要看到可用模板并快速启用。
  - 用户已经配置过自动任务后，希望收起模板区，把更多空间留给任务列表。
  - 用户在同一浏览器中再次进入页面时，希望保留上次收起或展开的选择。

## 目标

- 保持模板专区首次访问默认展开，降低新用户发现成本。
- 支持用户手动收起和展开模板专区，并在浏览器本地记住选择。
- 收敛模板专区视觉层级，让自动任务页面更轻、更工作化。

## 范围

### 本次包含

- 自动任务模板专区新增收起/展开控制。
- 收起状态只展示轻量标题行和展开入口，不展示模板卡片和说明文案。
- 展开/收起状态使用浏览器本地存储保存。
- 模板专区移除外层卡片框，模板卡片圆角降低、背景更接近白色。
- 补充自动任务模板专区单元测试。

### 本次不包含

- 不修改自动任务创建、编辑、执行、删除、通知或上游任务能力。
- 不修改模板内容、模板数量、模板分页规则或后端数据结构。
- 不新增后端接口，不把收起状态同步到账号或服务端。
- 不包含国际站首页 SEO、图片性能、移动端改版；这些属于独立 PRD。

- 优先级：P1
- 已知依赖：现有自动任务模板数据、现有 i18n 文案和浏览器 `localStorage`。

## 功能详细描述

### 1. 默认展示与本地记忆

- 首次访问自动任务页时，模板专区默认展开。
- 用户点击“收起”后，隐藏模板卡片并写入浏览器本地存储。
- 用户再次打开页面时，沿用上次收起状态。
- 用户点击“展开”后，恢复模板卡片展示并更新本地存储。

### 2. 视觉收敛

- 模板专区不再使用外层卡片边框、背景和阴影。
- 收起状态仅保留弱化标题和轻量展开入口。
- 模板卡片保持可点击按钮语义，但视觉更轻，圆角从大圆角收敛为小圆角。

### 3. 可访问性与状态语义

- 收起/展开按钮提供明确的 `aria-expanded` 与可访问名称。
- 模板列表容器在展开时与控制按钮保持关联。
- 模板启用按钮保留原有可访问名称与点击行为。

## 产品原型说明

- 不新增独立原型。
- 跳过原因：本需求是在现有自动任务模板专区上做局部交互和视觉优化，直接以现有页面和截图反馈为验收基线。

## 产物交接

- 产品：确认模板专区状态只做浏览器本地记忆，不做账号级同步。
- 设计：确认小圆角、轻量标题行和白色模板卡片是否符合控制台视觉。
- 前端：完成组件状态、样式和测试。
- QA：验证首次展开、收起记忆、重新展开、模板启用、分页和空模板情况。

## 方案决策

- 采用方案：前端本地状态 + `localStorage` 持久化 + 轻量视觉收敛。
- 选择理由：能解决首屏占用和重复访问干扰，成本低，不影响自动任务业务数据。
- 备选方案与取舍：
  - 服务端保存用户偏好：可跨设备同步，但需要新增接口和数据模型，本次不采用。
  - 默认全部收起：会降低新用户对模板能力的发现，本次不采用。
  - 删除模板专区：会伤害模板启用入口，不采用。
- 延后或不做：账号级偏好同步、模板内容重排、模板推荐算法。

## 验收标准

1. 首次访问自动任务页时，模板专区默认展开。
2. 点击收起后，模板卡片隐藏，只保留轻量标题和展开入口。
3. 同一浏览器再次进入页面时，保持用户上次选择的收起或展开状态。
4. 点击展开后，模板卡片恢复展示，模板启用和分页行为不受影响。
5. 模板专区外层不再呈现重卡片框，模板卡片圆角和背景更收敛。
6. 相关单元测试、`pnpm check` 和 `git diff --check` 通过。
