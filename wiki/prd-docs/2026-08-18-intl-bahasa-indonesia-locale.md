# 国际站新增 Bahasa Indonesia 语言版本

## 基本信息
- 当前产品：LightVela（国际站 lightvela.ai）
- 需求单状态：已实现，MR 评审中
- 创建人：keriaxu（代产品沉淀）
- 创建日期 / 最后更新时间：2026-08-18 / 2026-08-18
- 需求类型：重大产品更新 / 国际化与地域拓展
- 发布范围：国际站 only
- 优先级：P0
- 关联 MR：wisp/mono2!2962

## 需求背景
- 为什么要做：LightVela 国际站此前已支持 English、简体中文（zh-SG）和繁体中文（zh-Hant），但缺少面向印度尼西亚用户的本地语言体验。本次产品重大更新计划扩展部分可使用国家，包括菲律宾、印度尼西亚、尼日利亚和肯尼亚等，其中印度尼西亚需要同步提供 Bahasa Indonesia 的官网、文档和控制台界面。
- 不做会怎么样：印度尼西亚用户只能使用英文或中文浏览与配置产品，理解成本高；国际站新增可使用国家后缺少对应语言，会影响信任感、转化和后续合规材料承接。
- 用户价值：印度尼西亚用户可以用更自然、当地用户容易理解的 Bahasa Indonesia 完成产品了解、文档阅读、控制台配置和常见任务启用。
- 业务价值：支撑 LightVela 国际站在多国扩展中的印度尼西亚市场落地，补齐地域上线所需的本地化基础设施，并为后续运营、SEO/GEO 和法务内容本地化提供语言底座。

## 目标用户与场景
- 目标用户画像：访问 lightvela.ai 的印度尼西亚个人用户、开发者和早期试用用户；也包括需要评审国际站本地化质量的产品、内容、法务和 QA 同学。
- 典型场景：
  - 用户从语言切换器选择 Bahasa Indonesia，官网首页、价格、支持、文档入口和页脚文案切换为印尼语。
  - 用户直接访问 `/id-id/...` 链接，页面识别为印尼语版本，并保持同站点同语言跳转。
  - 用户进入 Agent 控制台主要模块，看到通道、Skills、Soul、场景任务等核心界面已本地化。
  - 用户在文档站搜索或浏览导航时，看到与英文/中文版本数量和结构一致的印尼语内容。

## 目标
- 产品结果：国际站新增 `id-ID` locale 和 `/id-id` URL 前缀，作为与 `en-US`、`zh-SG`、`zh-Hant` 并列的语言版本；国际站主要用户可见页面与控制台模块完成印尼语展示。
- 业务目标：让印度尼西亚用户可以在不依赖英文或中文的情况下完成产品认知和基础使用，降低新增地域上线后的语言阻力。

## 范围
- 本次包含：
  - 国际站新增 locale `id-ID`，URL 前缀使用 `id-id`，避免与印度相关缩写混淆。
  - 语言切换器新增 Bahasa Indonesia，并保持 URL 前缀、localStorage、初始语言识别和页面跳转一致。
  - 国际站公开站页面补齐印尼语展示，包括首页、价格页、支持页、更新日志入口、页脚和法律页入口等。
  - 国际站文档站补齐印尼语文档导航、文档内容、文档搜索和 docs manifest。
  - Agent 控制台主要模块补齐印尼语，包括通道配置、自动任务、Soul/人设、Skills/技能、场景任务、通知和常见状态文案。
  - SEO、sitemap、canonical、hreflang、HTML lang、静态路由和文档路由纳入 `id-ID`。
  - 印尼语文案按当地用户理解习惯处理，避免生硬直译或 AI 腔；产品名、模型名、渠道名和专有名词保持一致。
- 本次不包含：
  - 国内站 lightvela.com 的印尼语支持。
  - Models 模块整体本地化；该模块由 Walker 后续统一调整，避免重复和冲突。
  - 印度地域或印度语言支持；本需求只处理印度尼西亚，语言缩写为 `id-ID`，路径为 `id-id`。
  - 新增后端接口、套餐能力、支付能力或地域运营活动。
  - 法务条款内容本身的更新；法务文件更新由关联 PRD《国际站法务文件内容更新》覆盖。
- 优先级：P0
- 已知依赖：
  - 现有国际站多语言框架、语言切换器和 URL 前缀机制。
  - 英文、简体中文、繁体中文既有文案结构。
  - 内容/产品对印尼语用词准确性的抽检。

## 功能详细描述
- 功能点拆解：
  1. **Locale 注册**：将 `id-ID` 加入国际站语言集合，语言名展示为 Bahasa Indonesia，URL 前缀为 `id-id`。
  2. **语言隔离**：所有公开站、文档站和控制台入口按当前 locale 生成链接；从印尼语页面点击法律、文档、首页、控制台入口时不得跳回中文或英文。
  3. **公开站本地化**：首页首屏、功能区、价格、支持、页脚、社区入口、CTA 和法律入口均展示印尼语。
  4. **文档站本地化**：文档数量、侧栏分类、正文、页面内目录、搜索占位和文档路由与其他国际站语言保持结构一致。
  5. **控制台本地化**：除 Models 模块外，Agent 控制台主要模块按 `id-ID` 展示印尼语；按钮、提示、空态、错误态和操作文案不混入中文或英文。
  6. **场景任务与 Skills 本地化**：印尼语场景任务卡片、任务 prompt、字段标签、Skills 分类和详情文案保持本地化；英文 prompt 和印尼语 prompt 字段标签不得串用。
  7. **SEO 与静态产物**：`/id-id` 页面写入正确 `lang`、alternate、canonical 和 sitemap 条目。
- Demo / 页面结构说明：不新增页面结构，复用现有国际站页面与控制台结构；Demo 以 `/id-id/`、`/id-id/docs/...` 和 `/agents/...` 的本地预览/分支预览为准。
- 交互说明：用户选择 Bahasa Indonesia 后，当前 URL 更新为 `/id-id/...`；后续同站内跳转保持 `id-id` 前缀；返回其他语言时遵循已有语言切换规则。
- 边界条件与异常处理：
  - 直接访问不存在的 `/id-id/...` 页面时，沿用现有 404 或回退策略，不出现空白页。
  - 某个非核心文案暂未覆盖时，不得影响页面渲染；上线前通过全站语言扫描尽量清零明显英文/中文残留。
  - 与印度相关的缩写不得使用 `in`、`hi` 等误导性值，本需求固定使用 `id-ID` / `id-id`。
- 数据埋点需求：如现有语言切换或页面访问埋点包含 locale，新增 `id-ID` 枚举；不新增独立埋点。

## 发布站点与同步策略
- 发布范围：国际站 lightvela.ai。
- 国际站是否同步：是，本需求只作用于国际站。
- 国内站是否同步：否。国内站不新增印尼语入口；如有共享导航文案调整，应由独立需求或本次 MR 的附加说明覆盖，不归入本 PRD。
- 差异化原因：本需求服务国际站新增印度尼西亚地域和海外用户本地化；国内站不面向该语言场景。
- 路由与内容影响：新增 `/id-id` 语言前缀；影响公开站页面、文档站、控制台主要模块、i18n 字典、SEO、sitemap、docs manifest、搜索索引和法律页入口。
- 上线顺序：国际站随本次重大更新上线；上线前先在分支预览与本地 preview 完成多语言回归。

- SDK/文档/运营：文档站新增印尼语内容；运营和内容需要抽检关键文案质量。

## 非功能性需求
- 性能指标：新增语言资源不应显著拖慢国际站首屏；文档和大字典资源按现有打包策略处理。
- 兼容性：沿用国际站现有浏览器和设备兼容要求。
- 安全与权限：无新增权限或安全要求。
- 国际化 / 无障碍：`html lang` 使用 `id-ID`；文案自然、准确，按钮和导航仍可被辅助技术识别。

## 方案决策
- 采用方案：方案 A —— 在国际站现有多语言体系中并列新增 `id-ID`，URL 使用 `/id-id`，并补齐公开站、文档站和控制台主要模块。
- 选择理由：与现有 `en-US`、`zh-SG`、`zh-Hant` 架构一致，SEO 和语言切换规则清晰；`id-ID` 是印度尼西亚语的准确 locale，能避免与印度市场混淆。
- 备选方案与取舍：
  - 方案 B：仅官网和法务页面先上线印尼语，控制台继续英文。该方案上线快，但用户进入产品后语言断层明显，不采用。
  - 方案 C：先用英文页面服务印度尼西亚用户。该方案实现成本低，但不满足新增地域后的本地化体验，不采用。
- 延后或不做：Models 模块整体本地化、印尼专属运营活动、其他东南亚语言。

## 验收标准
1. 国际站语言切换器展示 Bahasa Indonesia，选择后 URL 前缀为 `/id-id`，刷新后语言保持。
2. `/id-id/`、`/id-id/docs/...`、国际站法律页和主要公开页面可以正常访问，页面不跳回其他语言。
3. 国际站四语言 `en-us / zh-sg / zh-hant / id-id` 路由、SEO、sitemap、docs manifest 和文档搜索均可正常生成。
4. 印尼语文档侧栏数量和结构与目标国际站文档集合一致，正文无明显英文或中文残留。
5. Agent 控制台除 Models 模块外的主要模块展示印尼语，不出现中文残留或英文大段残留。
6. 场景任务英文 prompt 使用英文字段标签，印尼语 prompt 使用印尼语字段标签，不发生交叉串用。
7. `pnpm check`、相关 i18n/SEO/文档/场景任务测试通过。

## 发布与观测
- 灰度/开关：不新增业务开关；可先通过分支预览验证 `/id-id`，确认后随国际站发布。
- 日志/埋点/指标：观测 `id-ID` 页面访问、语言切换占比、文档搜索和控制台关键操作失败率。
- 回滚：如发现严重翻译或路由问题，可临时隐藏 Bahasa Indonesia 语言切换入口，并保留其他语言不受影响。
