## 需求背景

Agent 创建使用旧几何头像，用户难以组合出首页已认可的立体玩偶形象；换装预览与真实工作台头像容易割裂。用户希望自由选择形状、颜色与配饰，并让创建后的侧栏、资料与对话入口持续显示同一个形象。存量旧头像也应在代码发布后统一进入新的视觉体系。

用户关注真实佩戴感：帽子应有贴合头部的帽口，两侧边缘要保留；耳机不能遮住眼睛；五种底模的颜色、天线和珠光球应一致。此前未被认可的几何图、黑色和皇冠不再作为本次选择项。

## 目标用户与场景

- 双站新用户：首次创建 Agent，选择头像、填写名字与可选描述，完成必要配置后开始使用。
- 双站已有用户：创建另一个 Bot，保留高级与既有复制配置能力。
- 存量用户：发布后看到首页七角色之一的稳定头像，并可以主动进入换装编辑。
- 多 Bot 用户：切换 Bot 与编辑当前 Bot 头像目标清楚，不能把一个 Bot 的外观写到另一个 Bot。

本需求中的头像是 **Agent/Bot 头像**，不涉及用户账号头像。

## 目标与范围

### 产品目标

1. 自由搭配出的结果接近用户认可的首页玩偶效果，保持正脸、柔和配色与一致材质。
2. 创建、完成、工作台与再次编辑形成同一外观读写链路。
3. 用户能理解创建是否完成、头像是否保存及发生失败后可以做什么。
4. 国内与国际站都有可用入口、完整翻译与同等验收标准。

### 本次包含

- 颜色 → 形状 → 配饰的换装步骤；已有默认外观允许直接创建。
- 5 种正脸底模、5 种颜色、独立配饰选择与重复点击取下、随机样式和现有涂鸦能力。
- 创建弹窗、必做配置进度弹窗、完成后“开始旅程”。
- 当前 Agent 头像的编辑入口、桌面横向布局与手机单列布局。
- 推荐模板头像、存量旧头像的首页七角色展示兼容。
- 外观持久化、目标隔离、失败恢复、多语言和无障碍状态。

### 本次不包含

- 账号头像、首页 MR 的再次改版、恢复已退场的总览入口。
- 新增模型、权限、套餐、支付、实名或 Bot 配额规则。
- 新增皇冠、黑色选择、自由上传图片或运行时三维建模系统。
- 自动批量改写生产 Bot 的远端配置、自动合并或部署。
- 新增头像运营市场、收藏、付费配饰或未定义的统计目标。

## 功能详细描述

### 创建主路径

1. 从现有首次引导或创建 Bot 入口进入真实创建弹窗。
2. 桌面左侧为玩偶与搭配，右侧为名字、可选描述、高级选项；推荐模板使用首页认可形象。手机按单列呈现。
3. 用户可使用默认外观，也可按颜色 → 形状 → 配饰搭配。换形状保留当前颜色；换颜色保留形状和配饰。形状卡不显示角色名字，保留可访问名称。
4. 选择模板和复制配置沿用原能力；高级选项保持可用。
5. 提交创建后进入“喂咖啡”配置弹窗，展示真实执行进度。执行期间为必做路径，不提供关闭，Escape、外部点击不退出。
6. 配置成功后提供“开始旅程”。点击完成创建收尾、关闭弹窗并进入所创建 Bot 的既有工作台/聊天路径。未成功时不显示可误认为完成的状态。
7. 必需配置失败须保留错误与重试路径；重试复用已创建目标，不能重复创建 Bot。沿用原有必需/可选步骤失败规则。

### 形状、颜色与配饰

- 形状：round、bean、square、drop、cloud 共五种。云朵保持认可参考中的宽两侧轮廓。
- 颜色：浅紫、蜜桃、奶黄、薄荷、晴空；五种底模使用相同目标配色。旧 `white`、`charcoal` 进入换装时统一映射到浅紫，面板始终显示当前色选中状态。
- 珠光球复用同一视觉，天线统一略倾斜；底模不自带配饰。
- 配饰包括耳机、巫师帽、渔夫帽、贝雷帽、针织帽、星星眼镜、飞行眼镜、披风、领巾、唱片、书本、相机。
- 不同槽位可以组合；同一槽位的互斥配饰替换。再次点击已选配饰取下；全部取下清除配饰与涂鸦。
- 配饰按点击顺序决定彼此遮挡，重新佩戴移到后选层级。规范化、颜色切换、保存、读取和再次编辑不得重排这一顺序。
- 帽口保留左右回边、去除被头遮住的中间后部；接触阴影不形成悬空接缝。五种形状分别使用佩戴锚点，不用同一位置生硬叠图。
- 随机样式改变形状、颜色与配饰组合，不生成超出可选颜色或配饰范围的外观。

### 创建后头像与更换入口

- 工作台侧栏展示圆形脸部近景，保证小尺寸下能辨认面部与主要配饰；使用所创建 Agent 的外观，而非账号头像。
- 当前 Agent 的头像可进入“更换头像”；其他 Agent 头像仍切换目标。停止、资料未就绪等不能写入的状态禁用编辑入口。
- 桌面编辑弹窗左预览、右形状/颜色/配饰与确认；手机单列，可滚动访问全部选项。确认按钮不能覆盖配饰。
- “返回”返回上层资料编辑或关闭当前头像编辑，不展示与实际行为不符的“返回创建”。
- 保存前读取期间禁用重复确认和选项，明确显示保存状态。真正写入期间使用现有进度弹窗；失败保留错误出口，不刷新成虚假成功。
- 只改外观时保留名字、描述与 SOUL 人设正文。成功后刷新资料、Bot 列表和侧栏，关闭编辑弹窗。
- Bot/Profile 身份变化或组件卸载后，旧异步操作不得写入新的目标。

### 存量兼容

- 未配置新版外观的旧 Agent，在前端代码发布后按 Bot/Profile 身份稳定分配首页七角色之一；刷新不重新随机。
- 七角色池：bean-lilac、round-coral、square-mint、drop-sky、cloud-butter、round-peach、bean-periwinkle，复用认可素材。
- 已保存的新版外观优先显示，不覆盖用户自选。
- 首页肖像与打开编辑时的底模使用同一个身份规则，避免展示角色与可编辑形象不匹配。
- 展示兼容不自动改写远端存量资料，也不能误判新用户已完成创建配置。

## 数据、依赖与非功能需求

- 沿用 HermesAppearance v1 和现有 Profile 元数据读写链路；外观合法性校验保留。
- 依赖当前 Bot/Profile 身份、现有配置执行器、首页七角色与透明配饰 WebP 素材。
- 复用既有 Dialog、翻译与头像组件，不新增服务接口、权限或敏感数据。
- 无新增性能指标，沿用前端性能基线；小头像不重复生成新的大图。
- 桌面、手机及长译文不能遮挡操作；选择项有名称与选中状态，键盘焦点可见，返回涂鸦后恢复焦点，减少动态效果设置受尊重。

## 方案决策与 Demo

- 采用已由用户逐轮确认的方案：正脸裸底模 + 独立配饰 + 自由搭配，创建与编辑共用外观数据。
- 固定整套头像不能满足自由组合；单纯缩小整只玩偶不能满足侧栏小头像识别。未采用这两种方案。
- 不重新打开已确认的产品方案，不追加未要求的能力。
- Demo：本地真实工作台 `http://127.0.0.1:5183/agents/`，开发试玩 `http://127.0.0.1:5183/dressup-preview/`。均需本地服务运行；真实链路依赖现有登录态与可用实例，试玩保存到本机不能证明远端创建成功。
- 原型说明：复用现有真实页面与本次已留证截图，不另做平行设计稿。关键状态包括表单、搭配、配置执行、成功、失败、加载及不可编辑。

## 验收标准

| 编号 | 场景 | 验收要求 |
| --- | --- | --- |
| A01 | 5形状×5颜色 | 颜色一致、正脸裸底模、珠光球一致，选项中无黑色/皇冠与可见形状名字 |
| A02 | 自由搭配 | 颜色→形状→配饰可前进返回，变化保留其他维度；再次点击可取下 |
| A03 | 佩戴视觉 | 所有形状×所有配饰无明显悬空、切断、眼睛遮挡或帽檐灰色拖尾；组合按点击层级遮挡 |
| A04 | 随机与旧颜色 | 随机确实改变组合；white/charcoal映射同一可见选中颜色 |
| A05 | 真实创建 | 高级与模板/复制可用；配置进度必做不可关闭；成功后开始旅程关闭并进入新Bot |
| A06 | 头像持续性 | 创建后的侧栏、资料及编辑显示相同外观；保存与刷新后形状、颜色、配饰顺序不丢失 |
| A07 | 存量头像 | 七角色稳定分配；离线/加载态不回旧几何头像；自选外观不被覆盖；展示与底模身份一致 |
| A08 | 读写隔离 | 重复确认只启动一次读取；读取失败不写、目标切换不写旧目标；外观编辑保留名字/描述/SOUL正文 |
| A09 | 异常恢复 | 失败不误报成功；有错误和重试/退出路径；创建重试不重复建Bot |
| A10 | 桌面与手机 | 左右编辑布局、手机单列完整可达，确认不遮配饰，头像近景可辨认 |
| A11 | 双站多语言 | 国内/国际分别验证；注册字典无空译文、长译文可用；OpenCraft生成副本与真源一致 |
