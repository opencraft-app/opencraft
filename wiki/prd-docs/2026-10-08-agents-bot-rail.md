# LightVela `/agents` Bot 独立竖栏 PRD

## 基本信息

- 产品：LightVela 国内站 `lightvela.com`、国际站 `lightvela.ai`
- 状态：产品已确认，研发实现中
- 创建日期：2026-10-08
- 类型：Agent 控制台信息层级与交互调整
- 现状基线：开发前同步的 `origin/master`，`e32b6e8e9`

## 需求背景

当前 `/agents` 的 Bot 选择器位于宽侧栏顶部的 Bot 卡片中。用户点击卡片下拉后才能看到其他 Bot，切换对象与当前 Bot 的「日常／探索」导航混在同一层。多 Bot 用户在分区页面间工作时，难以一眼识别可切换的 Bot，也会让下拉、状态、重启、删除和新增入口挤在同一行附近。

现有总览把账号权益、全部 Bot、产品动态和定时任务推荐放在进入 Agent 后的首页。Bot 已能在竖栏直接切换后，总览的 Bot 列表不再承担切换入口；用户希望进入或切换 Bot 后直接开始新会话。账号级权益信息仍需要可查，适合放入左侧导航底部现有账户入口。

用户提供的 Codex 与微信收藏截图均采用最左窄竖栏承载顶层对象或产品入口、右侧宽栏承载当前对象内导航的层级。本需求借鉴这一层级，不照搬截图中的其他功能、图标或颜色。

## 目标用户与场景

- 单 Bot 用户：在 Agent 区域看清当前 Bot 身份和状态，继续使用原导航。
- 多 Bot 用户：直接在最左竖栏切换 Bot，随后在宽侧栏和主区操作目标 Bot。
- Bot 管理者：仍能看到当前 Bot 状态及到期提示，执行重启／修复、删除，或按现有资格新建 Bot。

## 目标与非目标

### 目标

1. 桌面端形成「Bot 竖栏 → 当前 Bot 宽侧栏 → 主内容」的稳定层级，Bot 一次点击即可切换。
2. 当前 Bot 的身份、状态、操作目标清楚；切换后不得闪现或操作上一个 Bot 的会话、配置。
3. 双站使用一致的结构和规则，沿用各自现有文案、权限、套餐和多 Bot 开关。
4. 移除总览入口，进入或切换 Bot 默认到该 Bot 的新建会话页；账号级权益信息在左侧导航底部账户入口可查。

### 本次包含

- `/agents` 及已有 `/agents/<section>` 分区页的 Bot 切换入口与桌面布局。
- 原 Bot 卡片、下拉列表、重启／修复、删除、Bot 资料编辑／复制、套餐提示及新增 Bot 入口的安置。
- 总览退场后的默认落点、旧链接处理、账号权益信息迁移，以及总览下方推荐模块的移除。
- 单 Bot、多 Bot、列表过长、加载、失效、侧栏折叠与移动端可达性。
- 双站文案和键盘、焦点、触屏交互验收。

### 本次不包含

- 改动「日常／探索」分组、既有会话内容及其他 Bot 配置分区。
- 增加 Bot 搜索、排序、置顶、批量操作或新的管理页面。
- 改变 Bot 创建、克隆、修复、删除、配额、实名、权限、运行时 Profile 或对话能力。
- 在其他页面删除产品动态或定时任务模板；本期只移除 `/agents` 总览中的两块展示。
- 改造全站导航、OpenCraft 桌面工作台或生产发布配置。

## 方案决策

采用 **A：最左竖栏直接展示可切换 Bot 的头像**。点击头像即切换；竖栏承载 Bot 列表、新增入口和底部管理入口。桌面端宽侧栏从「日常／探索」开始；聊天页顶栏仅展示已有会话标题及改名入口。

备选 B 为竖栏只放一个 Bot 图标，再用浮层选 Bot；它节省竖向空间，但仍需两次操作，用户不能直接看到有哪些 Bot。桌面端 Bot 管理操作集中于竖栏底部的菜单。

## 页面结构与交互

```text
站点顶部导航
┌──────────┬──────────────────────────┬─────────────────────────────┐
│ Bot 竖栏 │ 宽侧栏                    │ 当前分区主内容                │
│ [头像 A●]│ 日常／探索                │ 聊天：会话标题 [改名]         │
│ [头像 B] │ 原有分区导航与会话列表    │ 当前 Bot 的新建会话           │
│ [头像 C] │                          │                             │
│   ⋮      │                          │                             │
│ [＋新增] │                          │ 配置页：直接展示页面内容      │
│ [管理]   │ 底部账户入口 → 权益概览   │                             │
└──────────┴──────────────────────────┴─────────────────────────────┘
```

### Bot 竖栏

- 只列出当前账号、当前功能开关下原选择器可见的 Bot；创建中、删除中等现有不可选对象不因改版变为可切换。
- 每个头像是独立按钮，显示清晰选中态和该 Bot 的状态点。选中态使用与头像同色系、混合比例约 8% 的浅色背景，不加外圈边框；头像之间保留 12px 纵向间距。悬浮、键盘聚焦时显示完整 Bot 名称与状态；图标按钮提供可读名称，当前项可被辅助技术识别。
- Bot 过多时头像列表在竖栏内独立滚动；新增入口固定在竖栏下方，不被滚动推出视口。宽侧栏和主区各自维持原滚动逻辑。
- 新增入口的虚线框高 32px，与侧栏会话行一致；外层保留 44px 点击区域。它复用现有创建引导及 `multiBotEnabled`、创建资格和配额规则。现有规则要求禁用并提示原因时，迁移后仍展示禁用状态与原因；不靠前端显示规则取代后端校验。
- 单 Bot 时仍显示一个选中头像；无 Bot 时沿用当前首次创建引导，不渲染虚假的当前 Bot。
- 「管理 Bot」图标固定在最左竖栏底部、账户入口上方，头像列表滚动时仍可达；菜单向右展开，操作始终作用于当前 Bot。

### 宽侧栏、聊天顶栏与 Bot 管理

- 桌面端多 Bot 模式移除宽侧栏顶部 Bot 卡片；「日常／探索」及其现有分区导航、会话列表从侧栏顶部开始。最左竖栏是唯一常驻的 Bot 头像与状态点展示位置。单 Bot 与移动端暂沿用现有 Bot 卡片，避免本次 PC 调整改变这两种布局。
- 桌面多 Bot 展开态的 Bot 竖栏宽 56px，右侧功能导航栏宽 232px；顶部品牌区和底部账户区合计宽 288px、各高 60px，与主内容分界对齐。折叠态两列各宽 56px，上下区保持同高。
- 聊天页主内容顶栏左侧只显示已有会话名称和编辑名称按钮，不显示 Bot 名称或分隔符。新建会话页不显示“新建对话”占位标题，左侧不占用标题位置。通道、技能、定时任务等配置分区不展示「Bot 名称／页面名称」这一整条主内容顶栏，页面内容直接开始。新建会话页不显示右侧预览面板开关；进入已有聊天会话后显示，原预览能力保持可用。
- 竖栏底部的管理图标打开「管理 Bot」菜单，集中提供「修改资料」「复制 Bot」「重启／失败修复」「删除」。删除项图标和文字与其他菜单项同色；不可删除时保留简短操作名称并置灰，悬停或键盘聚焦时提示原因。操作始终作用于当前选中 Bot，保留原资格、确认弹窗和主 Bot 删除限制。菜单不承担 Bot 切换。
- Bot 非运行、重启及失败状态由头像竖栏的状态点与提示表达，管理菜单保留相应操作说明。套餐到期／续费提示保留现有账户入口，窄宽度下会话标题可以截断，管理入口必须可达。
- 移除「总览」入口；宽侧栏折叠开关、「日常／探索」、会话和底部账户入口保持原逻辑。折叠时 Bot 管理菜单仍可达。
- 桌面端左侧收起后，Bot 头像、新建 Bot、「日常／探索」及功能导航图标在悬浮或键盘聚焦时，于按钮右侧显示与顶部「展开导航」一致的白底、浅边框、轻阴影提示；不使用浏览器原生 `title` 气泡。提示不能被两列的滚动容器裁切；移动端头像条维持原提示方向。

### 账户入口与总览内容去向

- 账号级信息（套餐有效期、剩余 AI 积分、Bot 数量、已邀请好友）收进左下角账户入口的展开菜单或账户详情区，不展示“已服务”天数。可升级时把“升级套餐”入口放在菜单顶部套餐名称旁，沿用原有资格判断和跳转。桌面多 Bot 时，账号区横跨 Bot 竖栏与宽侧栏，延伸到页面最左边；点击账户入口可查看权益，不在 Bot 卡片重复展示账号级指标。
- Bot 数量按账号下全部 Bot 统计，不随当前头像变化；邀请数据只在原功能开启时显示。加载中和失败时给出明确占位，不把未知显示为 0。窄侧栏折叠时账户入口仍可打开；移动端从原账户入口查看。
- 「产品动态」「定时任务推荐」随总览页移除；独立的产品动态入口和现有定时任务功能不受影响。

### 切换、新会话与路由

- 在任意 Bot 分区点击**另一个** Bot 头像，写入目标 `?bot=` 并进入该 Bot 的新建会话页；不保留先前的「日常／探索」分区或会话 ID。目标对话不可用时沿用现有通道页兜底。重复点击当前头像不新建会话。
- 未选中 Bot 头像提供目标对话页的真实链接，首屏尚未完成水合时仍可导航；选中态以 URL 中有效的 `?bot=` 为准。双站均需覆盖首次打开页面、异步跳转及刷新后的切换。
- 新会话使用产品现有创建逻辑；切换后看到目标 Bot 的空白新会话，不自动发送消息。切换开始即隔离上一个 Bot 的会话列表、选中会话及操作句柄；目标 Bot 数据加载完成前不展示旧 Bot 内容。历史会话保留在原 Bot 下，可从它的会话列表重新打开。
- `/agents` 默认进入可用 Bot 的新建会话；有效 `?bot=` 优先选择指定 Bot。原 `/agents/overview` 深链以替换历史记录的方式落到该 Bot 新建会话，保留有效 Bot 参数；参数失效时沿用现有安全兜底。已有 Bot 分区深链仍进入指定分区，不被默认规则覆盖。两站采用同一落点，不再以是否开启国内站引导决定进入总览。
- 首次创建与资料配置引导仍按原条件出现；新建或复制 Bot 完成既有创建／引导流程后落到新 Bot 的新建会话，不返回已移除的总览。创建中、失败和删除中的反馈仍需有明确落点。
- 已有 Bot 时点击「新建 Bot」进入独立的浏览器历史状态；创建前按浏览器返回，回到进入前的 `/agents` 页面和 Bot 分区，不触发创建。创建等待文案按通常 10 秒内完成表述；超过 10 秒只显示实际已等待时间和仍在创建状态。
- Bot 消失、失效或权限变化时，沿用现有可用 Bot 兜底；无法选择时展示可理解状态，不能将请求静默转到其他 Bot。

### 移动端适配

移动端沿用当前导航抽屉，在抽屉顶部增加与导航内容分隔的横向 Bot 头像条；不在聊天主区常驻窄竖栏。头像条可横向滚动，当前项可见；新增入口位于头像条末尾并沿用现有禁用提示。切换后抽屉关闭，进入目标 Bot 新建会话。研发验收需核对 390px 及更窄视口。

## 状态与异常

| 场景 | 预期 |
| --- | --- |
| Bot 列表加载中 | 路由和数据两层加载骨架均与最终布局一致：多 Bot 桌面显示独立头像竖栏、无 Bot 卡片的功能导航、60px 上下区域；聊天主区显示问候语与输入框轮廓，配置主区显示内容占位。折叠态保持两列各 56px；不得把旧列表当作新账号或新 Bot 数据。 |
| 列表失败 | 提示读取失败并保留安全导航；不得解释为无 Bot。 |
| 无 Bot | 沿用首次创建引导；无选中头像、无当前 Bot 操作卡片。 |
| 单 Bot | 一个选中头像；现有卡片状态与操作仍可用；新建入口按原规则显示或禁用。 |
| 多 Bot／列表过长 | 头像直接可选；列表独立滚动，新增入口仍可达。 |
| 当前 Bot 运行异常 | 头像竖栏显示状态点和提示，管理菜单保留修复入口与禁用说明；竖栏选中态不冒充运行正常。 |
| Bot 被删除或失去权限 | 移除失效头像，清空旧 Bot 数据，使用现有安全兜底。 |
| 宽侧栏折叠 | Bot 竖栏仍可切换；宽侧栏原折叠与展开行为不回归。 |
| 进入 `/agents` 或旧 `/agents/overview` | 有 Bot 时打开指定或兜底 Bot 的新建会话；无 Bot 时沿用首次创建引导。 |
| 从配置分区切换 Bot | 进入目标 Bot 新建会话；原 Bot 分区和历史会话仍可重新打开。 |
| 账号权益数据加载或失败 | 底部账户入口可用；未知指标显示占位／错误，不误报为 0。 |
| 创建受限 | 新增入口保持原禁用状态及原因；不能绕过配额或权限。 |

## 发布站点与影响面

- **发布范围：国内站与国际站同步。** 两站共用组件结构；分别核对中文、英文及现有其他 locale 的 Bot 名称提示、状态、禁用原因和创建入口。用户自定义名称保持原文。
- 两站都沿用现有多 Bot 功能开关、账号资格与后端校验；前端改版不宣布两站运行时能力已统一开启。
- 路由仍为 `/agents` 及其现有分区；旧 `/agents/overview` 做兼容跳转，不新增 sitemap、SEO 页面或外部链接。
- 前端页面、样式、响应式布局和导航测试受影响；无新增 API、存储字段、数据迁移或 Hermes/OpenClaw 命令。
- 页面宽度需检查 1024px、1280px、1440px 桌面与 390px 手机；竖栏不遮挡主内容，导航和内容无横向溢出。

## 原型说明

- [Bot 顶栏交互原型](demos/2026-10-08-agents-bot-header-proposal.html) 记录早期桌面布局；后续交互以本 PRD 为准：管理入口已移到竖栏底部，配置页不再展示 Bot／页面名称顶栏。原 [Bot 竖栏 Demo](demos/2026-10-08-agents-bot-rail.html) 保留用于查看头像切换、底部账户权益、创建限制、列表滚动和移动端适配。
- Demo 不连接真实账号，不执行创建、重启、删除或续费；这些操作的最终弹窗、门禁和数据结果均以现有产品实现及设计评审为准。
- 实现需核对竖栏同色系选中态、头像间距、管理入口、长名称截断、Bot 数量较多时的滚动、聊天标题重命名、配置页无顶栏、宽侧栏折叠组合及移动端头像条视觉。

## 验收标准

1. 国内站与国际站在多 Bot 能力开启时，`/agents` 和各既有分区页面显示最左 Bot 竖栏；旧 Bot 卡片不再展开 Bot 下拉列表。
2. 单 Bot、多 Bot 与大量 Bot 均可辨认当前选中项；切换仅一次点击，头像完整名称可通过悬浮、聚焦和辅助技术获得。
3. 点击另一 Bot 头像进入目标 Bot 的空白新会话，`?bot=`、头像、顶栏、导航和主区一致；旧会话及操作状态不闪现、不串用，也不删除历史会话。重复点击当前头像不创建会话；不可用对话沿用现有兜底。
4. 多 Bot 桌面端侧栏无 Bot 卡片，聊天顶栏仅保留已有会话名称及编辑按钮，不显示 Bot 名称或分隔符；通道／技能／定时任务等配置页不显示 Bot／页面名称顶栏，竖栏底部管理菜单始终可达。新建会话页不显示“新建对话”占位标题及右侧预览开关，已有会话可重命名且预览面板开关正常。重启／修复、删除及从原总览迁来的修改资料／复制 Bot 继续作用于当前 Bot，原禁用、主 Bot 删除与确认规则不变；新增入口复用原资格、禁用原因和创建引导。
5. 「总览」入口与页面移除；`/agents`、创建完成后的落点及旧 `/agents/overview` 深链进入新建会话，其他现有分区深链、宽侧栏折叠和「日常／探索」导航保持可用。
6. 桌面多 Bot 账号区从侧栏底部延伸到页面最左边；账号套餐天数／有效期、AI 积分、全账号 Bot 数量和邀请数可从该入口查看，保留真实数据及原有跳转；加载／失败不显示虚假 0。总览中的产品动态和定时任务推荐不再出现在 `/agents`，对应独立功能保持可用。
7. 无 Bot、加载失败、Bot 删除或失权、Bot 异常与创建受限时，页面有准确状态且不误用其他 Bot 数据。
8. 桌面收起侧栏时，左上显示现有 LightVela 图标，Bot 竖栏与功能导航列等宽，左下账户头像旁保留菜单箭头；头像、管理入口与功能图标的统一提示出现在各自按钮右侧且不被裁切。选中头像采用对应头像色系的浅色背景、不加外圈边框，头像间距为 12px。展开态维持完整品牌与账户信息。键盘、焦点、触屏和现有 locale 可用；桌面与移动端目标视口无横向溢出；移动端头像条位于导航抽屉顶部，切换后关闭抽屉并进入新会话。
9. 双站分别完成聚焦视觉与交互回归；源代码合入不等于生产发布。

## 发布、观测与回滚

- 以同一产品需求覆盖两站，但各站独立完成测试和发布核验。灰度与上线时序由发布评审确定，不在本 PRD 中假定已发布。
- 沿用现有 Bot 切换、创建与操作事件；如需区分入口，给切换／创建事件增加 `source=bot_rail`，不采集 Bot 名称、聊天正文或配置原文。上线前后比较切换成功率与失败率，不虚构目标值。
- 回滚为恢复原卡片下拉、总览与新增入口的位置；不迁移或删除 Bot 数据。

## 产物交接与待确认

- 产品／设计：细化移动端头像条与竖栏尺寸，核对聊天顶栏及底部管理入口在展开／折叠状态下的可达性。
- 前端：复用当前 Bot 选择、新会话、创建、重启／修复和删除逻辑；迁移资料编辑／复制及账号权益展示；保留原会话标题与预览控制；补双站 locale、响应式与回归证据。
- QA：按验收标准覆盖双站、零／单／多 Bot、深链刷新、异常及权限／配额门禁。
- 发布负责人：分别核对双站功能开关、构建与实际发布状态。
- 待确认：生产验收所需的两站灰度与上线时序。
