# LightVela 双站首页展示与交互优化

## 基本信息

- 产品：LightVela 官网首页。
- 创建及更新日期：2026-09-07。
- 状态：当前预览已获用户确认，待 MR 评审、合并与发布。
- MR：https://git.woa.com/wisp/mono2/-/merge_requests/3680。
- 分支：`frontsandbox/intl-channel-preview-restore`，目标：`master`。
- 范围：国内站 `lightvela.com`、国际站 `lightvela.ai` 首页及国际站已有语言版本。
- 事实源：本次对话最终确认、当前双站预览和本分支相对 master 的实际代码差异。
- 本文整理并替代早期草稿中的旧角色词、MR 3610 前版本等历史口径，不新增页面需求。

## 背景、用户与目标

首次访问和返回首页的用户需要清楚理解产品能力，并能在桌面、手机上阅读演示、访问定价和文档。此次反馈集中在首屏词表与字体裁切、国际站 IM 还原、功能切换过早、手机滚动、用户之声尺寸、导航入口和页脚比例。

目标是保留用户已确认的双站设计，修复指定体验问题；不做整页重新设计，不擅自统一双站业务差异，不以审查或文档补充为理由追加代码修改。

## 范围与边界

包含首屏角色轮播、IM 展示样式、功能展示交互与角标、用户之声、首页导航、页脚及上述内容的本地化。复用现有静态片段、CSS、运行时与 Radix 移动菜单，不引入后台服务。

不包含套餐或支付规则变更、定价页面重做、文档正文或 SEO 路由改造、登录后控制台功能、用户头像运营替换、新埋点或 Skills 修改。MR 提交不代表合并、部署或线上发布。

## 功能与验收要求

### 1. 首屏角色轮播

- 中文按以下六项顺序循环：工作助理、知识库、监控雷达、定时闹钟、经营助手、生活管家。
- 英文依次为：`work assistant`、`knowledge base`、`monitoring radar`、`scheduled reminder`、`business assistant`、`life manager`。
- 其他国际语言使用同六类能力对应词；不得把标签中的孤立“知识”直接拼进“成为你的……”句子。
- 西语、印尼语使用句中小写；日语使用“LightVelaはあなたの……になります”，韩语使用“LightVela는 당신의……입니다”。
- 保留斜体、Vela 紫、下划线及已确认动效，处理轮播宽度测量、字形裁切、初始化与离开页面后的清理。
- 首次打开或刷新时，按“静态主标题 → `LightVela 可以成为你的`（各语言对应前缀）→ 首个角色词”的顺序完成入场；首个角色词完整展示后才开始循环，不得被 `pageshow` 或页面可见性事件提前切换。
- 初次加载、刷新应能启动；不可见页面及减少动态效果场景采用运行时既有降级策略。
- 静态主标题和眉题文案不纳入本次调整范围，不借本次角色词调整重写品牌标语。

### 2. 国内与国际 IM

- 国际站保留用户以 5173 源页面和截图确认的 WhatsApp、Telegram、Discord、Slack 展示，包括侧栏、消息、颜色、密度、格式和已有动态。
- 国内站保留微信、QQ、企业微信、钉钉、飞书与国内链接，不替换为国际站渠道。
- 当前最终预览是本轮交付视觉基准，不再根据早期草稿推导另一版 IM。
- 页面根容器结构不作为本次新增需求处理；最终提交以当前预览中的单根容器结构为准。

### 3. 自动任务、工作台、DeepSeek Harness

- 三个右上角标依次为 `0 Token`、`New`、`New`，复用 Harness 的角标样式和选中态。
- 自动任务说明为“有模版库，直接装。通知任务&脚本任务无需消耗任何token。”；国际各语言有对应描述。
- 桌面鼠标移入标签时选中对应面板，保留点击操作；不得因修复自动轮播过早而移除悬停切换。
- 自动轮播在可阅读区域等待 8 秒；手动选择、鼠标停留、焦点位于区域内、不可见页面及减少动态效果时停止相应自动播放。
- 桌面面板共用网格位置预留高度，减少切换造成的页面跳动。
- 手机不自动轮播、不因合成 hover 切换；纵向手势不拦截，横向手势切换仅调整标签横向位置，不滚动整页。

### 4. 用户之声

- 卡片缩小，桌面宽度 288px，窄屏 250px；相应调整内边距、头像和正文尺寸。
- 两行评论根据页面滚动进度反向位移，滚动停止后停止更新；区域不可见时停止监听，尊重减少动态效果设置。
- 用户头像素材和图片加载策略不属于本次调整范围，本轮不替换用户头像。

### 5. 导航与入口

- 双站首页登录入口去重，顶部不再同时强调重复的免费试用与登录按钮；首屏试用入口保留。
- 修正桌面登录区域贴右边缘的定位问题。
- 窄屏增加导航菜单，复用当前站点和语言的首页、定价、文档等导航配置。
- 菜单支持关闭、选择链接关闭、切换到桌面宽度关闭以及 Radix 提供的焦点管理。

### 6. 页脚

- 国际站保持最终确认的品牌列与五列链接布局，不再挪动或改文案。
- 国内站品牌列加四列链接，四列整体向右，避免空出不存在的第六列；仅国内桌面采用该规则。
- 英文版权在 `All rights reserved.` 后换行，再展示 `Built by Tencent Lighthouse.`。
- 国内版权在“Copyright © 2026 LightVela 版权所有 ·”后换行，再展示“腾讯轻量云出品”；保留备案链接。
- 保留现有移动布局，桌面链接列不因固定宽度过大掉到下一排。

### 7. 本地化与业务差异

- 覆盖 en-US、zh-CN、zh-SG、zh-Hant、id-ID、es、ja-JP、ko-KR 和默认英文片段。
- 国际多语言片段按当前最终预览和语法检查保留，同步生成器和测试；不额外替换未授权内容。
- 国内 CTA 为“免费体验，30秒极速部署”，LightVela 14 天、AI Token 3 天。
- 国际站保留无需信用卡的对应表达，LightVela 14 天、AI Token 7 天。不得把两站试用天数强行统一。
- 国内首页定价链接仍使用 `/subscribe`；本 MR 不改定价页实现或 metadata。

## 实际代码差异补充说明

此节记录当前代码相对 master 的事实，不把所有差异重新包装成用户新增需求。最终提交阶段按用户要求冻结页面代码，不额外清理这些差异。

- 国内能力卡描述由“我在云端 7×24 小时在线，不用一直开着你的电脑……”变为“我在云端，不用你电脑开着……”。
- 英文页脚 `Compare / Compare with ...` 为当前预览的 `Analysis / ... analysis` 文案。
- 国际英文 Harness 展示图引用从 `deepseek-harness-en-us.webp?v=20260904-harness-sharp` 变为既有 `deepseek-harness-en-us.png?v=20260901-deepseek-ui`；本 MR 没有新增图片二进制文件。
- 部分图片属性顺序、空属性及 HTML 序列化格式变化。评审后补回国际首页导航的 `aria-current="page"`、场景按钮初始 `aria-pressed`，并将两个章节标题设为 `h2`；沿用原 class，不调整标题样式。
- 国内片段最终为当前预览中的单根容器结构，不把历史误改过程写入需求范围。
- CSS 中保留当前片段导入和历史覆盖规则，不在此次冻结提交中做去重重构。
