# 国内站登录弹窗交互优化 PRD

## 基本信息

- 当前产品：LightVela 国内站 `lightvela.com`
- 需求单状态：草稿
- 创建日期：2026-07-29
- 最后更新时间：2026-07-29
- 关联分支：`frontsandbox/domestic-login-phone`

## 背景

国内站登录弹窗需要形成更明确的默认路径。微信是国内用户更熟悉的登录方式，手机号验证码登录已有能力但仍作为隐藏入口，QQ 需要保留为兼容入口。

本版不引入后端改动。微信登录使用现有 OAuth 跳转方式；如果后续要做弹窗内扫码登录，需要另起后端与网关方案评审。

## 目标

- 国内站弹窗默认展示微信登录。
- 手机号登录正式入口化。
- QQ 作为备用登录方式保留。
- 选中任一方式后，另外两种出现在底部“其他登录方式”。
- 协议勾选位置上移到“其他登录方式”上方。
- 底部其他方式按钮使用 logo + 文案，无边框，用竖线分隔。

## 范围

### 本次包含

- 登录弹窗国内站三方式切换。
- 微信 / QQ 现有 OAuth 跳转按钮。
- 手机号验证码登录表单。
- 登录协议勾选与统一拦截提示。
- 相关中文文案和 i18n。

### 本次不包含

- 国际站登录改版。
- 后端接口、OAuth callback、网关配置变更。
- 微信二维码嵌入弹窗。
- QQ、微信、手机号账号合并或绑定。
- 实名认证、套餐、支付、订阅链路调整。

## 验收标准

1. 打开国内站登录弹窗，默认展示 `微信登录` 和 `微信账号登录` 按钮。
2. 未勾选协议时，点击微信或 QQ 主按钮不跳转，并展示 `请先勾选同意服务协议`。
3. 勾选协议后，点击微信主按钮跳转现有微信 OAuth start URL。
4. 点击底部 `手机` 后展示手机号验证码表单，底部展示 `微信` 和 `QQ`。
5. 点击底部 `QQ` 后展示 QQ 登录按钮，底部展示 `微信` 和 `手机`。
6. 底部其他方式按钮有 logo、无边框，按钮之间有竖线分隔。
7. 国际站 Google / GitHub 登录行为不变。
