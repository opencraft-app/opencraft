## 需求背景

1. **Hero 轮播词与当前产品定位脱节**：线上 6 个词（工作助理 / 知识库 / 监控雷达 / 定时闹钟 / 经营助手 / 生活管家）偏能力罗列，未覆盖开发、理财、创意、自媒体等高频真实使用场景。该组文案曾于 2026-09-06 更新为七项场景角色（提交 `954c54b5d`、`6e091ae51`），后于 2026-09-07 提交 `60eca3f2a` 被整体回退，线上恢复为旧文案。本次为重新落地该组已确认文案。
2. **头部首屏渲染滞后**：`authReady` 依赖 Session 网络往返，期间头部动作区整体渲染为骨架占位，语言切换器与登录入口均延迟出现。
3. **用户之声缺少目标市场样本**：印尼为重点市场之一，用户之声区无对应地区样本。
4. **国内平台图标为通用占位**：微信 / QQ / 企业微信 / 钉钉 / 飞书使用线性通用图标，其中 QQ 与钉钉共用同一个 `#i-users`，缺乏品牌辨识度；设计仓已产出品牌真图但未同步至生产仓。

不做的后果：首页文案继续与产品能力错位；首屏头部持续闪烁；目标市场缺少可信样本；平台图标错位影响国内站专业度。

- 用户价值：一眼看懂产品可服务的具体场景；首屏交互元素即时可用；看到熟悉的平台品牌标识。
- 业务价值：提升首页场景表达的匹配度与首屏体验流畅度。

## 目标用户与场景

- 目标用户画像：访问 `lightvela.com` / `lightvela.ai` 首页的潜在用户与已注册回访用户。
- 典型场景：
  - 未登录访客进入首页，通过 Hero 轮播词判断产品是否匹配自身场景。
  - 回访用户希望首屏头部立即可交互，不等待鉴权请求。
  - 国内用户查看 Hero 演示区，通过平台图标确认支持的 IM。

## 目标

- 产品结果：首页文案覆盖 7 类高频场景；首屏头部渲染无明显延迟；国内站平台标识具备品牌辨识度。
- 业务目标：不改变现有转化路径与入口结构的前提下，改善首页表达与首屏体验。

## 功能详细描述

### 1. Hero 轮播词

轮播序列（2.2 秒切换，`prefers-reduced-motion` 下静态显示首词）：

工作搭档 → 开发搭子 → 计划执行官 → 生活管家 → 理财助理 → 创意同行者 → 自媒体运营官

各 locale 按目标语言自然表达本地化：

| Locale | 轮播词 |
| --- | --- |
| `zh-CN` / `zh-SG` | 工作搭档 / 开发搭子 / 计划执行官 / 生活管家 / 理财助理 / 创意同行者 / 自媒体运营官 |
| `zh-Hant` | 工作夥伴 / 開發夥伴 / 計畫執行官 / 生活管家 / 理財助理 / 創意同行者 / 自媒體營運官 |
| `en-US` | work partner / developer buddy / plan executor / life concierge / financial assistant / creative companion / content manager |
| `ja-JP` | 仕事の相棒 / 開発仲間 / 計画実行役 / 暮らしのコンシェルジュ / 資産管理アシスタント / クリエイティブパートナー / コンテンツマネージャー |
| `ko-KR` | 업무 파트너 / 개발 동료 / 계획 실행자 / 생활 매니저 / 재무 어시스턴트 / 창의적 동반자 / 콘텐츠 매니저 |
| `es` | compañero de trabajo / compañero de desarrollo / ejecutor de planes / gestor personal / asistente financiero / compañero creativo / gestor de contenido |
| `id-ID` | rekan kerja / teman pengembang / pelaksana rencana / pengelola hidup / asisten keuangan / rekan kreatif / manajer konten |

文案顺序与各 locale 译法逐字取自 2026-09-07 回退前的线上状态（`60eca3f2a~1`，即 `docs/context/tasks/2026-09-06-homepage-hero-rotator-copy.md` 交付的最终版本），未作任何调整。

宽度自适应由运行时动态测量实现，新增长词不会截断或跳动。

数据埋点：沿用现有首页 CTA 点击、订阅入口点击、登录按钮点击埋点，不新增埋点。

## 方案决策

- 采用方案：只调整文案、图标与渲染时机，完全保留现网转化入口结构。
- 选择理由：
  - 转化入口结构由 `2026-09-04-fix-cn-home-cta` 定义并已修复过一次线上问题，本次不触碰，避免与其验收标准产生分歧。
  - 头部渲染优化只改时机不改结构，对既有验收标准无影响。
  - 文案与图标为纯静态产物变更，回滚成本低。
- 备选方案与取舍：
  - 将 Hero CTA 改为按订阅态分流（未订阅留在转化入口）：能避免未订阅用户落到空控制台，但会推翻 `2026-09-04-fix-cn-home-cta` 已确认的入口规则，需产品与 `pablozhong` 重新对齐，独立需求评估后再定。
  - 双站头部收敛为两个按钮：与现网国内站「立即创建」入口冲突，同样涉及转化路径调整，不在本次范围。
  - 移动端同步补齐语言切换器：需设计确认紧凑头部的空间分配，且与「不扩大移动端需求」约定冲突，本次不做。
  - 平台图标按 logo 线条风格重绘：需设计侧重新出图，超出本次范围。
- 延后或不做：首页转化入口规则调整、移动端头部结构、首页场景轮盘标签同步、无引用的设计仓零散资源同步。
