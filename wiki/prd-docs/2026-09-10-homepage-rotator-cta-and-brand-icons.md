## 需求背景

1. **Hero 轮播词与当前产品定位脱节**：线上 6 个词（工作助理 / 知识库 / 监控雷达 / 定时闹钟 / 经营助手 / 生活管家）偏能力罗列，未覆盖开发、理财、创意、自媒体等高频真实使用场景。该组文案曾于 2026-09-06 更新为七项场景角色（提交 `954c54b5d`、`6e091ae51`），后于 2026-09-07 提交 `60eca3f2a` 被整体回退，线上恢复为旧文案。本次为重新落地该组已确认文案。
2. **头部首屏渲染滞后**：`authReady` 依赖 Session 网络往返，期间头部动作区整体渲染为骨架占位，语言切换器与登录入口均延迟出现。
3. **用户之声缺少目标市场样本**：印尼为重点市场之一，用户之声区无对应地区样本。
4. **国内平台图标为通用占位**：微信 / QQ / 企业微信 / 钉钉 / 飞书使用线性通用图标，其中 QQ 与钉钉共用同一个 `#i-users`，缺乏品牌辨识度；设计仓已产出品牌真图但未同步至生产仓。

不做的后果：首页文案继续与产品能力错位；首屏头部持续闪烁；目标市场缺少可信样本；平台图标错位影响国内站专业度。

- 用户价值：一眼看懂产品可服务的具体场景；首屏交互元素即时可用；看到熟悉的平台品牌标识。
- 业务价值：提升首页场景表达的匹配度与首屏体验流畅度。

## 目标用户与场景

- 目标用户画像：访问 `lightvela.com` / `lightvela.ai` 首页的潜在用户与已注册回访用户。

### 2. 首页转化入口（双站统一）

核心原则：**头部只承载身份操作，转化入口唯一收口到 Hero 主按钮**。桌面端头部在登录前后恒为两个按钮，国内站与国际站行为完全一致，差异仅在文案语言。

| 状态 | 桌面端 Header | Hero 主按钮 |
| --- | --- | --- |
| 未登录 | 语言切换 + 登录 | 各 locale「免费开始」文案 → 订阅页 |
| 已登录 | 语言切换 + 头像 | 各 locale 产品入口文案 → `/agents` |

Hero 主按钮各 locale 文案与落点：

| Locale | 未登录文案 | 未登录落点 | 已登录文案 |
| --- | --- | --- | --- |
| `zh-CN` | 免费试用 | `/subscribe` | 我的智能体伙伴 |
| `zh-SG` | 立即免费体验 | `/zh-sg/subscribe` | 我的智能体伙伴 |
| `zh-Hant` | 立即免費體驗 | `/zh-hant/subscribe` | 我的智能體夥伴 |
| `en-US` | Start free | `/subscribe` | My AI Companion |
| `ja-JP` | 無料で開始 | `/ja-jp/subscribe` | 私のAIパートナー |
| `ko-KR` | 무료 시작 | `/ko-kr/subscribe` | 내 AI 파트너 |
| `es` | Empieza gratis | `/es/subscribe` | Mi compañero de IA |
| `id-ID` | Mulai gratis | `/id-id/subscribe` | Pendamping AI saya |

已登录一律进入 `/agents`。未登录文案全部取自各 locale 页脚已审定表达，未新造译文；订阅路径按站点规则取值，国内为裸路径，国际站带 locale 前缀（不带前缀会 404，已逐个验证可访问）。

实现层面：状态化标记由 `data-domestic-home-hero-cta` 更名为通用 `data-home-hero-cta`，9 个 fragment 全部提供 `anon-label` / `anon-href` / `signed-label` / `signed-href` 四个属性，运行时只读 dataset 做选择，不硬编码任何文案。静态产物默认输出未登录态，避免首屏闪现错误入口。

两条转化路径职责分离：新访客走 Hero 主按钮（先浏览套餐再注册），已注册用户走头部登录入口。

**本次未覆盖移动端。** 移动端头部沿用现有紧凑登录入口，`2026-09-04-fix-cn-home-cta` 已约定「移动 Header 保持现有紧凑登录入口，不扩大本次需求」。移动端未登录头部当前不渲染语言切换器，属改动前既存现象，本次不处理，见「待确认问题」。

### 3.1 登录成功后的落地页分流

头部登录入口在登录成功后改为按用户状态分流，与产品入口按钮复用同一套判断：

| 用户状态 | 落地页 | 说明 |
| --- | --- | --- |
| 未订阅 | 订阅页 | 先完成购买，避免落到无可用内容的控制台 |
| 已订阅、尚无 Agent | 创建 Agent 引导页 | 直接进入创建流程 |
| 已订阅、已有 Agent | `/agents` 控制台 | 回到工作台 |

改动前为无条件跳转 `/agents`。分流后未订阅用户少一次自行寻找购买入口的跳转，已订阅用户行为不变。

实现层面的唯一变化：Hero 状态化标记由 `data-domestic-home-hero-cta` 更名为通用 `data-home-hero-cta`，并改为由四个 `data-*` 属性（`anon-label` / `anon-href` / `signed-label` / `signed-href`）驱动，运行时不再硬编码文案。该标记仅 `zh-CN` 产物携带，国际站产物不带，运行时取不到标记即不做改写。行为与改造前完全等价。

### 3. 头部首屏渲染优化

- 语言切换器与登录态无关，任何阶段直接渲染，不再随 Session 等待。
- 登录/头像按上一次已知登录态乐观渲染，Session 返回后以真实结果为准。
- 骨架停留时间由「一次 Session 网络往返」降至「一帧」。
- 按钮构成、文案、链接均不变。

边界条件：

- Session 请求失败或超时：维持未登录态展示，不阻塞页面。
- 本地存储不可用（隐私模式）：回退为骨架，行为与改动前一致。
- 缓存登录态与真实态不一致：短暂展示后自动纠正为真实态。
- `prefers-reduced-motion`：轮播停止在首词。

数据埋点：沿用现有首页 CTA 点击、订阅入口点击、登录按钮点击埋点，不新增埋点。

### 7. Hero CTA 四态分流

Hero CTA 的分流依据由「是否登录」改为「是否已订阅」：

| # | 用户状态 | Hero CTA | 跳转 | 落地页行为 |
| --- | --- | --- | --- | --- |
| 1 | 未登录 | 免费试用 | `/subscribe` | 免登录浏览；选套餐弹登录/注册 → 支付 → `/agents` |
| 2 | 已登录·未订阅（含过期） | 免费试用 | `/subscribe` | 已登录，直接选套餐 → 支付 → `/agents` |
| 3 | 已登录·已订阅·未建 Agent | 我的智能体伙伴 | `/agents` | 进入创建引导 |
| 4 | 已登录·已订阅·已有 Agent | 我的智能体伙伴 | `/agents` | 进入控制台 |

改动前登录即进入 `/agents`，而 `/agents` 只拦未登录、不拦未订阅，未订阅用户会停在空控制台。本次将其保留在转化入口。

第 3、4 行文案与目标一致，故不读取 Agent 列表，空态由 `/agents` 落地页自行处理。

`OpenClawContext` 新增 `subscriptionReady`：`isSubscribed` 初值为 `false` 且依赖异步 `GET /v1/passes`，未就绪时无法区分「确实未订阅」与「尚未查回」。未就绪时不改写产物默认值，避免已订阅用户先渲染一帧转化文案；接口失败同样置为就绪，降级到转化入口而非停留在加载态。

### 8. 订阅页登录后续跑

未登录用户在订阅页点击套餐时先记录 `pendingPlan` 再拉起登录弹窗，同窗口登录成功后自动接回该套餐的确认订单弹窗，复用邀请码守卫既有的续跑范式。

改动前登录成功仅关闭弹窗，用户被留在定价页，需再次点击同一套餐才能继续，转化路径在此中断。

续跑前重新校验权益与售罄状态，不以登录前的旧口径下单；取出待办套餐后立即清空，弹窗 `onSuccess` 重复触发时天然幂等；关闭登录弹窗会丢弃待办套餐，避免下次登录被旧选择带跑。

OAuth 为整页跳转，`pendingPlan` 随页面卸载丢失，回跳后仍需用户手动点击，见「待确认问题」。
