# Use case

Use for a real or plausible story of a user solving a recurring need with LightVela.

Suggested arc: outcome-led title → hero recommendation → answer-first takeaway → relatable friction → setup (channel, skills, instruction) → example use → automation/repeatability where relevant → lesson and transferable pattern → grounded close.

- Make the setup feel achievable. If a skill or data source is hypothetical, say “you could” rather than claiming it exists.
- First person is appropriate when the prompt asks for a personal narrative; do not force it otherwise.
