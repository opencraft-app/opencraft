# Tutorial

Use for a concrete setup or workflow.

Suggested arc: outcome-focused title → hero recommendation → answer-first result → prerequisites → ordered steps → verification → troubleshooting → constraints/notes → done.

- Verify named product capabilities lightly before writing.
- Use numbered steps only where order matters. Add short prompt examples in fenced code blocks when readers must type something.
