# Brand assets

`assets/lightvela-brand-icon.png` is the approved LightVela icon reference: a rounded white bot face with purple eyes and antenna over a violet-to-peach gradient shape.

Use it as an image-generation reference only when the user wants LightVela visibly represented in an original visual. Keep it recognizable and secondary to the article’s subject; do not redraw it as a new character, modify it into a competing logo, or insert it gratuitously.

`assets/hostinger-brand-icon.png` is an official Hostinger icon captured from Hostinger's own VPS page. Use it only for a Hostinger comparison visual, on the alternative/right side, and preserve it faithfully. For another comparison, use that alternative's official or user-provided icon when available; otherwise keep the alternative side unbranded rather than inventing a logo.

`assets/vs-product-hero-reference.png` is the canonical layout reference for every `vs-product` first hero. Use it as the image-generation reference, preserve its left LightVela half and straight center divider, and replace only the right half for the alternative being compared.
