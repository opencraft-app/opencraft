# Code of Conduct

## Our Pledge

We are committed to a respectful, productive, and harassment-free collaboration environment.

## Expected Behavior

- Be direct and constructive.
- Keep feedback focused on code, product behavior, accessibility, security, and maintainability.
- Use issues and pull requests for scoped, actionable discussions.
- Respect maintainers' time by providing reproduction steps and verification evidence.
- Report security problems privately.

## Unacceptable Behavior

- Harassment, intimidation, or personal attacks.
- Discriminatory language or conduct.
- Publishing private information without permission.
- Deliberately derailing technical discussions.
- Sharing credentials, exploits, or sensitive operational details in public threads.

## Enforcement

Maintainers may moderate, edit, hide, or remove comments, issues, pull requests, or other contributions that violate this code of conduct. Repeated or severe violations may result in a temporary or permanent ban from project spaces.

## Scope

This code applies to project repositories, issue trackers, discussions, pull requests, chat spaces, and events related to the project.
