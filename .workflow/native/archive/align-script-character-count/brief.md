# 脚本字符计数器对齐

## 目标

优化创建任务弹窗中的两处信息层级：将脚本任务的字符计数器从“脚本内容”标题行移动到 Python/Bash 语言切换行右侧；同时将“AI 驱动”能力标签改为与“0 Token”不同的靛蓝色系，强化智能任务辨识度。

## 范围

- 仅调整脚本任务且脚本可编辑时的计数器布局。
- 通知任务的字符计数器继续保留在“通知内容”标题行右侧。
- “AI 驱动”使用无边框靛蓝浅底与靛蓝文字；通知任务和脚本任务的“0 Token”标签继续使用现有蓝色。
- 保持字符限制、计数逻辑、语言切换和脚本编辑行为不变。
- 同步更新聚焦组件测试、Task Pack 与现有 PRD。

## 成功标准

- Python/Bash 切换控件与 `当前字符数/20000` 在同一行两端对齐。
- 脚本内容标题行不再单独展示计数器。
- 通知任务的计数器布局不受影响。
- “AI 驱动”与“0 Token”标签可通过颜色直观区分，且文字标签继续提供非颜色语义。
- 聚焦测试、类型检查、文档检查与 `git diff --check` 通过或明确记录既有门禁基线。
