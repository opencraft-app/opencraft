# WhatsApp 同实例单 Bot 占用提示

## 需求

国际站多 Bot 场景下，一个 LightVela 实例同时只允许一个 Bot 连接 WhatsApp。连接前说明此限制；其他 Bot 看到占用 Bot 和管理入口，不能发起扫码。原 Bot 可重连，断开后其他 Bot 可连接。

## 范围

- 复用微信现有的实例级通道绑定记录和占用状态，在 `ctl` 中增加 WhatsApp 通道键，并在 Bot 列表返回占用方。
- 前端 WhatsApp 卡片展示连接前说明；占用时禁用连接入口、显示占用方并提供切换入口；扫码及断开时维护实例级记录。
- 同步国际站接入文档、必要的 i18n、正式设计文档和聚焦测试。

## 不做

- 不按 WhatsApp 号码在所有实例或所有用户之间去重。
- 不实现 Hermes `profile_routes` 的同号码按聊天对象分流。
- 不开放国际站多 Bot 创建入口；不合并或发布。提交 MR 已获用户后续明确授权。

## 验收

同实例 Bot A 连接 WhatsApp 后，Bot B 看到 A 的占用态及管理入口，扫码按钮不可用；A 可重连；A 断开后 B 可连接。两个页面并发连接同实例 WhatsApp 时至多一个 Bot 取得实例级占用。中文和国际站英文文案准确，其他开放 locale 不回落中文。运行 ctl 聚焦测试、前端聚焦测试、lint/typecheck/i18n 与 change-impact 门禁。

## 已确认

用户在本任务中确认按先前讨论的第 1、2 项实现，接受“同一实例”的边界。主工作区有未提交改动，使用独立 worktree。
