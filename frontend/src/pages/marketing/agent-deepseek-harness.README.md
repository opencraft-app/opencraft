# DeepSeek Harness UI

`AgentDeepSeekHarnessPanel` owns the command client, per-Bot persisted task ID / operation, polling, runtime state, restart and installation handlers, and completion animation scheduling. `DeepSeekHarnessRuntimeView` only renders typed status, progress, URLs, refs and callbacks; it has no repository, client, network or timer ownership. Unmount cancels local polling / pending animation work, retains the saved remote task, and does not request remote cancellation. Repair closes confirmation before starting the existing install command.

`AgentDeepSeekHarnessModelCard` retains provider loading, mutation/refresh ordering, synchronous save-ref deduplication and optimistic confirmed state. Configured-list and provider-controls views receive provider IDs and callbacks. Credential text / visibility stay local to the credential form: an empty edit preserves the key, failure preserves the draft, and the host's successful add form-version remount clears the submitted key.

Provider selection uses the shared Radix Select with raw provider IDs and unique label IDs. The delete dialog uses shared AlertDialog primitives because its existing visible action text and accessible confirmation name differ. Pending deletion blocks dismissal; failure stays open; success closes after the original refresh. Cancel returns to the original button; deletion of that button falls back to the configured-list heading. Repair uses `AgentConfirmDialog`, returns cancellation to its trigger, and accepts the installation-status ref for the host's existing focus handoff on confirmation. Explicit edit cancellation / Escape returns to its provider edit button without saving.

All presentation uses shared Buttons / Input / AgentState / AgentTooltip and explicit `agents-ui` Portal styling. Existing shared defaults and dependencies are unchanged. The `.tech` CN and `.site` global URLs remain selected by the original host region.

Adjacent tests cover real keyboard selection / Escape, safe initial focus and restoration, busy / retry / removed-target deletion, save dedupe / empty edit / failed draft / successful clearing, and actual command spies with per-Bot polling persistence across unmount. `agent-deepseek-harness.global.test.tsx` uses the real English dictionary and the global default; the original controller tests keep their explicit identity translator and assert each environment's correct domain.
