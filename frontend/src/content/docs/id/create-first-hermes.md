# Cara Mengaktifkan Instans Hermes Pertama

## Ringkasan

**Alur membuat instance Hermes pertama: masuk dengan Google atau GitHub → pilih paket yang tersedia → aktifkan sesuai aturan paket saat ini → platform otomatis membuat instance → konfigurasikan model dan kanal. Semuanya dilakukan di browser, tanpa perlu membeli server atau melakukan deployment lokal. Instance Hermes adalah lingkungan runtime Agent di cloud LightVela, dan setelah dibuat ia daring 24/7. Setelah siap, buka konsol "My Hermes" untuk mengatur model, menghubungkan kanal pesan, dan memasang skill; jika belum memiliki API key model sendiri, Anda bisa langsung mulai berbicara memakai kredit model dari paket.**

---

Instans Hermes adalah runtime cloud tempat LightVela Agent Anda berjalan. Aktivasi instans pertama dilakukan dalam lima langkah: **masuk dengan Google atau GitHub → pilih paket yang tersedia → aktifkan melalui alur aktivasi saat ini → biarkan LightVela menyiapkan instans → atur model dan kanal**. Semua dilakukan di browser, tanpa membeli server atau melakukan deployment lokal. Halaman ini memandu prosesnya secara berurutan.

## Alur aktivasi

### 1. Masuk dengan Google atau GitHub

Buka LightVela dan lakukan otorisasi dengan Google atau GitHub. Akun LightVela Anda dibuat otomatis saat pertama kali masuk, jadi tidak ada kata sandi terpisah yang perlu diatur. Gunakan identitas login yang sama pada kunjungan berikutnya untuk mengakses instans Hermes dan data yang sama.

### 2. Pilih paket yang tersedia di halaman Subscribe

Buka [halaman Subscribe](/subscribe) untuk melihat paket dan kuota yang saat ini tersedia. [Paket](./plans.md) menjelaskan struktur sumber daya Launch dan Cruise, tetapi halaman Subscribe adalah sumber resmi untuk mengetahui apa yang bisa diaktifkan sekarang.

Situs internasional tidak memiliki langkah verifikasi nama asli Tiongkok. Setelah masuk dengan Google atau GitHub, Anda dapat memilih paket apa pun yang saat ini tersedia.

### 3. Aktifkan paket lewat alur internasional saat ini

LightVela berencana masuk beta publik dan mulai menagih pada 18 Agustus 2026 (Waktu Singapura). Setelah beta publik dan penagihan resmi dimulai, masa berlaku paket pengguna beta yang sudah ada akan diperpanjang satu bulan, dan pengguna baru dapat mencoba Launch gratis selama 14 hari. Ikuti instruksi pada kartu paket untuk mengaktifkannya, lalu jadikan halaman Subscribe sebagai acuan informasi terbaru.

### 4. Biarkan LightVela menyiapkan instans secara otomatis

Setelah paket diaktifkan, LightVela **otomatis menyediakan lingkungan cloud khusus dan membuat instans Hermes pertama Anda**. Anda tidak perlu membeli, men-deploy, atau mengonfigurasi server. Provisioning biasanya dimulai segera, dan Anda dapat membuka konsol saat instans sudah siap.

### 5. Atur dan aktifkan Agent Anda

Setelah instans siap, buka konsol dan selesaikan setup dasar:

1. **Atur model** — Pilih model bahasa yang mendasari Agent; lihat [Ringkasan Konfigurasi](./05-configuration.md#2-model)

2. **Hubungkan kanal** — Tambahkan Telegram, WhatsApp, Discord, Slack, WeChat, atau kanal lain yang didukung, lalu bicara dengan Agent dari aplikasi chat tersebut

3. **Tambahkan Skill dan tugas terjadwal bila perlu** — Perluas kemampuan Agent dari konsol

Hermes Agent pertama Anda kini siap online di cloud 24/7.

## FAQ

### Seberapa cepat instans bisa digunakan setelah aktivasi?

LightVela mulai menyiapkan instans Hermes secara otomatis setelah paket aktif. Saat instans siap, atur model dan kanal di konsol, lalu mulai percakapan.

### Apa yang terjadi setelah penagihan dimulai?

Setelah penagihan resmi dimulai, masa berlaku paket pengguna beta yang sudah ada akan diperpanjang satu bulan. Pengguna baru dapat mencoba Launch gratis selama 14 hari. Periksa [halaman Subscribe](/subscribe) dan [Paket](./plans.md) untuk informasi terbaru.

### Berapa banyak instans Hermes yang dapat diaktifkan satu akun?

Jumlahnya bergantung pada kuota Agent dari paket yang dipilih. Launch dan Cruise masing-masing mencakup satu Agent. Lihat [Paket](./plans.md).

### Apakah saya perlu memelihara server setelah aktivasi?

Tidak. Instans Hermes Anda berjalan di lingkungan cloud yang dikelola LightVela. LightVela menangani operasi dan ketersediaan 24/7; Anda cukup mengatur Agent melalui konsol web.
