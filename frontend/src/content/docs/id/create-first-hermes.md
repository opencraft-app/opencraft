Selesaikan pengaturan Bot pertama: isi nama yang wajib, tambahkan deskripsi jika perlu, dan atur tampilannya. Pilih Buat, lalu tunggu pembuatan dan konfigurasi awal selesai. ---

Tombol tutup dan opsi salin lanjutan hanya tersedia jika ada Bot sumber yang valid. Pengaturan pertama tanpa sumber harus diselesaikan. Kontrol tampilan mengubah warna, bentuk, dan aksesori, bukan memilih sumber salinan.

## Alur aktivasi

### 1. Masuk dengan Google atau GitHub

Buka LightVela dan lakukan otorisasi dengan Google atau GitHub. Akun LightVela Anda dibuat otomatis saat pertama kali masuk, jadi tidak ada kata sandi terpisah yang perlu diatur. Gunakan identitas login yang sama pada kunjungan berikutnya untuk mengakses instans Hermes dan data yang sama.

### 2. Pilih paket yang tersedia di halaman Subscribe

Buka [halaman Subscribe](/subscribe) untuk melihat paket dan kuota yang saat ini tersedia. [Paket](./plans.md) menjelaskan struktur sumber daya Launch dan Cruise, tetapi halaman Subscribe adalah sumber resmi untuk mengetahui apa yang bisa diaktifkan sekarang.

Situs internasional tidak memiliki langkah verifikasi nama asli Tiongkok. Setelah masuk dengan Google atau GitHub, Anda dapat memilih paket apa pun yang saat ini tersedia.

### 3. Aktifkan paket lewat alur internasional saat ini

Pilih paket yang tersedia di [halaman Subscribe](/subscribe/) dan ikuti petunjuk pada kartu paket untuk mengaktifkannya. Periksa halaman tersebut untuk penawaran dan harga terbaru.

### 4. Selesaikan pengaturan Bot pertama

Setelah masuk dengan Google atau GitHub dan mengaktifkan paket yang tersedia, buka [konsol Agent](/agents/overview/). Selesaikan pengaturan Bot pertama: isi nama yang wajib, tambahkan deskripsi jika perlu, dan atur tampilannya. Pilih **Buat**, lalu tunggu pembuatan dan konfigurasi awal selesai. Setelah konfigurasi selesai, pilih **Mulai perjalanan**, lalu buka Chat web untuk Bot tersebut. Kanal pesan bersifat opsional; balasan memerlukan kredit model paket yang tersedia atau model yang telah dikonfigurasi.

### 5. Atur dan aktifkan Agent Anda

Setelah instans siap, buka konsol dan selesaikan setup dasar:

1. **Periksa model** — Kredit paket yang tersedia memungkinkan Anda memulai tanpa API key sendiri; lihat [Ringkasan Konfigurasi](./05-configuration.md#2-model) bila perlu

2. **Coba Chat web** — Mulai percakapan di Daily → Chat dan kirim pesan; lihat [Chat](./configuration/agent-chat.md)

3. **Hubungkan kanal bila perlu** — Gunakan Telegram, WhatsApp, Discord, atau WeChat jika ingin memakai Bot di aplikasi pesan

4. **Tambahkan Skill dan tugas terjadwal bila perlu** — Perluas kemampuan Agent dari konsol

Hermes Agent pertama Anda kini siap online di cloud 24/7.

## FAQ

### Seberapa cepat instans bisa digunakan setelah aktivasi?

Setelah pembuatan selesai, pastikan nama Bot baru muncul di pemilih, buka Chat web-nya, dan kirim pesan uji singkat. Jika pembuatan atau konfigurasi awal gagal, ikuti tindakan coba lagi yang ditampilkan dan periksa daftar Bot sebelum membuat lagi. Jika tidak ada balasan, periksa status Bot serta kredit atau konfigurasi model.

### Di mana melihat paket dan penawaran saat ini?

Periksa [halaman Subscribe](/subscribe/) dan [Paket](./plans.md) untuk ketentuan paket, penawaran pengguna baru, dan aturan perpanjangan terbaru.

### Berapa banyak instans Hermes yang dapat diaktifkan satu akun?

Jumlahnya bergantung pada kuota Agent dari paket yang dipilih. Launch dan Cruise masing-masing mencakup satu Agent. Lihat [Paket](./plans.md).

### Apakah saya perlu memelihara server setelah aktivasi?

Tidak. Instans Hermes Anda berjalan di lingkungan cloud yang dikelola LightVela. LightVela menangani operasi dan ketersediaan 24/7; Anda cukup mengatur Agent melalui konsol web.
