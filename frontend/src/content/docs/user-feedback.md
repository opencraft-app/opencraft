# 用户反馈

## 摘要

**国内站用户登录 LightVela 后，可打开[用户反馈](/support)，提交使用问题或产品建议。反馈分为建议与 Bug 两类，联系方式和附件均为选填；提交后以页面显示的成功提示为准。**

## 打开反馈页面

登录 [LightVela](https://lightvela.com)，再打开[用户反馈](/support)。未登录时需先登录才能提交。需要社群交流或其他联系入口，可查看[联系我们](./contact-us.md)。

## 填写反馈内容

### 建议与产品反馈

选择建议类后，按页面填写了解渠道、角色、使用频率、行业和 AI 用途，再选择具体反馈类型，说明希望改善的体验、功能或文档问题。选择「其他」时，还需填写具体类型。

描述建议时，可写清当前操作、遇到的限制和期望结果。套餐或账单问题可先查阅[套餐说明](./plans.md)，并在反馈中提供便于定位的订单信息。

### Bug 与故障

选择 Bug 类，填写问题现象及发生频率。建议附上操作步骤、实际结果和期望结果；若仅在特定 Bot 或渠道出现，也请说明对应场景。

## 联系方式与附件

邮箱选填，不填写也可以提交。需要补充截图或文件时，可添加附件：最多 5 个文件，单个不超过 50 MB，合计不超过 100 MB。上传前请遮挡密码、验证码、令牌及其他敏感信息。

## 提交与确认

检查必填项后点击提交。若页面提示缺少内容，补齐对应字段再提交；显示成功提示后，表示本次反馈已提交。若提交失败，请保留填写内容，检查网络后重试。
