# Bagaimana Saya Mengaktifkan Instance Hermes Pertama Saya?

## Ringkasan

**Mencipta contoh Hermes pertama anda dilakukan seperti ini: log masuk dengan Google atau GitHub, pilih pelan yang tersedia, aktifkan di bawah peraturan pelan semasa, biarkan platform mencipta contoh secara automatik, kemudian gunakan Web Chat; sambungkan saluran apabila anda ingin menggunakan aplikasi pesanan. Segalanya berlaku di penyemak imbas — tiada pelayan untuk dibeli, tiada apa yang perlu dikerahkan secara tempatan. Contoh Hermes ialah runtime awan tempat ejen anda berada, dan selepas dicipta ia kekal dalam talian 24/7. Setelah ia sedia, buka My Agent untuk menggunakan Daily → Chat, kemudian konfigurasikan model, saluran pesanan, atau Kemahiran mengikut keperluan; jika anda belum mempunyai kunci model API sendiri, anda boleh mula bercakap segera menggunakan kredit model yang disertakan dengan pelan anda.**

---

Satu instance Hermes adalah runtime awan di mana Ejen LightVela anda berada. Mengaktifkan instance pertama anda mengikuti lima langkah: **log masuk dengan Google atau GitHub → pilih pelan yang tersedia → aktifkan melalui aliran pengaktifan semasa → biarkan LightVela menyediakan instance → mula dalam Web Chat, kemudian sambungkan saluran jika perlu**. Semuanya berlaku di pelayar, tanpa perlu membeli pelayan atau penyebaran tempatan. Laman ini membimbing proses secara berperingkat.

## Perkara yang dilindungi oleh halaman ini

- Proses lengkap untuk mengaktifkan instance Hermes pertama anda

- Prasyarat dan butiran penting untuk setiap langkah

- Bagaimana untuk mengkonfigurasi dan menggunakan Ejen anda selepas pengaktifan

## Prasyarat

- Akaun Google atau GitHub

- Pelan yang tersedia pada masa ini dipilih daripada [Langgan halaman](/subscribe); tapak antarabangsa tidak memerlukan pengesahan nama sebenar China

- Akaun Telegram, WhatsApp, Discord, Slack, atau WeChat hanya jika anda merancang untuk menggunakan aplikasi pesanan tersebut

---

## Aliran pengaktifan

### 1. Log masuk dengan Google atau GitHub

Buka LightVela dan benarkan akses dengan Google atau GitHub. Akaun LightVela anda dibuat secara automatik pada kali pertama anda log masuk, jadi tiada kata laluan berasingan untuk ditetapkan. Teruskan menggunakan identiti log masuk yang sama pada lawatan akan datang untuk mengakses kejadian dan data Hermes yang sama.

### 2. Pilih pelan yang tersedia pada halaman Langgan

Buka [Langgan halaman](/subscribe) untuk melihat rancangan dan kuota yang tersedia pada masa ini. [Pelan](./plans.md) menerangkan struktur sumber Pelancaran dan Pelayaran, tetapi halaman Langgan berwibawa untuk perkara yang boleh diaktifkan sekarang.

Tiada langkah pengesahan nama sebenar China di tapak antarabangsa. Selepas log masuk dengan Google atau GitHub, anda boleh memilih mana-mana pelan yang tersedia pada masa ini.

### 3. Aktifkan pelan melalui aliran pengaktifan antarabangsa semasa

Pilih pelan yang tersedia di [halaman Langgan](/subscribe/) dan ikuti kad pelan untuk mengaktifkannya. Semak halaman tersebut untuk tawaran pengenalan dan harga semasa.

### 4. Biarkan LightVela menyediakan contoh secara automatik

Selepas pelan diaktifkan, LightVela **menetapkan persekitaran awan khusus secara automatik dan mencipta contoh Hermes pertama anda**. Anda tidak perlu membeli, menggunakan atau mengkonfigurasi pelayan. Peruntukan biasanya bermula serta-merta, dan anda boleh membuka konsol apabila contoh sudah sedia.

### 5. Konfigurasikan dan bangunkan Ejen anda

Setelah contoh sedia, buka konsol dan lengkapkan persediaan asas:

1. **Semak model** — Kredit pelan yang tersedia membolehkan anda mula tanpa kunci API sendiri; lihat [Konfigurasi Model](./configuration/model.md) jika perlu

2. **Cuba Sembang Web** — Mulakan perbualan di bawah Harian → Sembang dan hantar mesej; lihat [Sembang](./configuration/agent-chat.md)

3. **Sambungkan saluran jika perlu** — Tambah Telegram, WhatsApp, Discord, atau WeChat untuk menggunakan Bot dalam aplikasi mesej

4. **Secara pilihan tambah kemahiran dan tugasan berjadual** — Lihat [Konfigurasikan Tugasan Berjadual](./configuration/automation.md)

Hermes Agent pertama anda kini bersedia untuk kekal dalam talian di awan 24/7.

## Soalan Lazim

### Berapa lama saya boleh menggunakan contoh selepas pengaktifan?

LightVela mula menyediakan contoh Hermes secara automatik selepas pengaktifan pelan. Setelah Bot sedia dan kredit pelan tersedia atau model dikonfigurasikan, hantar mesej di Daily → Chat. Sambungkan saluran luaran kemudian jika perlu.

### Di mana saya boleh menyemak pelan dan tawaran semasa?

Semak [halaman Langgan](/subscribe/) dan [Pelan](./plans.md) untuk terma pelan semasa, tawaran pengenalan, dan peraturan pembaharuan.

### Berapa banyak Hermes kejadian boleh satu akaun diaktifkan?

Nombor bergantung kepada elaun Ejen pelan yang dipilih. Pelancaran dan Pelayaran setiap satu termasuk seorang Ejen. Lihat [Pelan](./plans.md).

### Adakah saya perlu mengekalkan pelayan selepas pengaktifan?

Tidak. Instance Hermes anda berjalan dalam persekitaran awan terurus LightVela. LightVela mengendalikan operasi dan ketersediaan 24/7; anda hanya mengkonfigurasi Ejen melalui konsol web.
