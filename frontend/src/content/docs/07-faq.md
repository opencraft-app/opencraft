## 摘要

**本页汇总 LightVela 使用过程中的常见问题，覆盖账号与登录、套餐与计费、模型配置、通道接入、技能、记忆与运行排查。国内站使用 QQ 或微信一键登录，首次开通套餐前需完成实名认证；微信、QQ、企业微信、飞书、钉钉可作为 Hermes Agent 的聊天通道。套餐附带模型积分，价格、优惠和额度以[套餐管理](./plans.md)及订阅页实时展示为准。技能可在管理台安装和卸载；长期记忆可通过对话请求增删，无需为清除一条记忆而删除整个 Agent。**

## 账号与登录

### 为何仅支持 QQ 和微信登录？

LightVela 主要服务国内用户，QQ / 微信一键登录覆盖面最广，暂未规划手机号登录。

### 同一用户能否用 QQ 和微信各登录一次？

可以，但会是两个独立账号，Hermes Agent、对话记忆、套餐状态均不互通。建议固定使用一种登录方式。

### 如何退出登录

点击右上角头像，选择「退出登录」；或进入账号信息页，在「账号基本信息」卡片中点击退出按钮。退出后账号数据保留，下次登录即可继续使用。

## 实名认证

### 为什么要实名认证

实名认证用于符合国内 SaaS 服务的合规要求。首次开通任意套餐前必须完成实名。

### 实名认证何时触发

登录后浏览首页、阅读文档不需要实名。**首次点击「立即开通」领取套餐**时，若账号未认证，页面顶部会出现提示条，引导前往账号信息页完成认证。

### 实名信息如何保管

姓名和身份证号加密传输并存储，平台仅保留脱敏信息用于展示，认证信息不会用于其他用途。

### 支持哪些证件类型

当前仅支持中国大陆居民身份证，其他证件类型暂未开放。

### 实名是否需要每次开通套餐都做一次

不需要。认证为一次性操作，完成后开通任意套餐、购买 LightVela 其他产品均无需重复认证。

### 实名后能否修改实名信息

可以。进入账号页，在实名认证一行点击「修改」重新提交真实姓名和身份证号。新信息通过核验后会覆盖当前实名信息，后台保留变更记录。

### 实名后能否修改账号显示名或 Hermes Agent 名字

可以。实名认证绑定的是真实姓名和身份证号，与账号显示名、Hermes Agent 实例名称无关，后两者可在对应页面随时修改。

### 认证失败如何处理

| 现象 | 可能原因 | 处理方式 |
|---|---|---|
| 提示姓名与身份证号不匹配 | 填写错误 | 核对后重新提交 |
| 提交后长时间无响应 | 网络波动或后台繁忙 | 稍后重试 |

## 套餐与体验积分

### 当前有哪些套餐

当前订阅页展示启航 Launch 与巡游 Cruise 两个系列，各可选择低积分或高积分档位。套餐权益、实时价格、续费和退款规则详见[套餐管理](./plans.md)。

### 「100 体验积分」的含义

100 积分是启航系列当前可选的低积分档位，每月随该档套餐提供，用于模型调用。启航也可选择更高的 4500 积分档位；巡游可选 200 或 10000 积分。具体以[订阅页](/subscribe/)选中的档位为准。

### 积分耗尽后如何处理

可用积分耗尽后，依赖模型调用的对话与智能任务会受限。已有有效套餐时可在[订阅页](/subscribe/?section=credits)购买额外积分包，也可等待下一周期套餐积分，或在「模型」中配置自有 API Key，详见[AI 积分说明](./credits.md)。

### 积分是否支持充值

支持已有有效套餐的用户另购模型积分包。积分包自到账起有效 1 个月，不属于套餐每月自动发放的积分；具体可选额度、价格与购买入口见[AI 积分说明](./credits.md#购买额外积分包)。

### 启航套餐是否永久免费

不是永久免费。符合条件的首购用户可能看到启航系列首单免费活动；活动名额、免费期限、到期和后续续费规则以订阅页与订单实时展示为准。

### 一个套餐是否只能创建 1 个 Bot

不是。当前订阅页展示启航系列最多 5 个、巡游系列最多 10 个 Bot；当前账号能否新建及剩余额度，以管理台显示和功能开放状态为准。详见[管理与切换 Bot](./configuration/bots-switching.md)。

## 模型相关

### 如何获取 API Key

在管理台「模型」卡片选中某个服务商后，下方显示「点击获取 API KEY」外链，点击可直达该服务商官网的注册与 Key 管理页。详见 [配置模型](./configuration/model.md)。

### 如何选择模型

详见 [配置模型 - 选型参考](./configuration/model.md#选型参考)。

### 能否使用 Claude / GPT / Gemini

可以，通过「自定义模型」接入，需自备可访问的 OpenAI 兼容端点。

### 消息发送后 Hermes Agent 无响应的排查方式

按以下顺序检查：

1. 管理台「已接入通道」是否有记录

2. 若使用自有模型：「当前模型」是否有记录、服务商余额是否充足

3. 若使用体验积分：积分是否耗尽

4. Key 是否在服务商后台被禁用

### 切换模型是否会丢失对话记忆

不会。对话记忆为 Hermes Agent 自身数据，模型仅负责生成响应。

### 能否同时配置多个模型

可以配置多个可用模型，再从已配置模型中选择当前生效的一个。一个 Agent 同一时间只使用一个生效模型；切换时无需新建 Agent。操作见[配置模型](./configuration/model.md)和[模型切换](./configuration/multiple-models.md)。

## 通道相关

### 微信、QQ、企业微信、飞书、钉钉能否同时接入

可以。多个通道指向同一个 Hermes Agent 实例，共享记忆与 Agent 行为。

### 是否支持企业微信

支持。国内站可在管理台连接企业微信，具体步骤见[配置通道 - 企业微信](./configuration/channel-wecom.md)。

### 能否将机器人添加至微信群

当前不支持。微信通道仅支持 1 对 1 对话。

### 更换手机或 QQ / 微信号后的影响

账号基于 QQ / 微信 OpenID 识别，更换号即视为新账号，数据不迁移。如需保留数据，请继续使用原账号登录。

### 如何解除已接入的通道

在管理台「已接入通道」列表中删除对应条目。解除后，该聊天平台中的机器人将失效。

### QQ 机器人是否需要自行注册

选择扫码授权时，按管理台提示操作即可；选择手动绑定时，需要在 [QQ 开放平台](https://q.qq.com) 创建机器人，取得 AppID 与 AppSecret 后填回 LightVela。详见 [配置通道 - QQ](./configuration/channel-qq.md)。

### 如何测试已接入的通道

在管理台找到显示为“已连接”的通道，点击 **测试**。页面提示“测试消息已发送”只表示发送命令已被接受；请到对应聊天软件确认收到测试消息，再向机器人发送一句“你好”，确认 Agent 能回复。若未收到消息，先检查通道连接并重新测试；若能收到但 Agent 不回复，再检查模型和积分，并查看[诊断中心](./configuration/diagnostics.md)。

## 对话与记忆

### 单条消息能否删除

当前不支持单独删除一条聊天消息。聊天记录与长期记忆是不同的数据：如果想让 Agent 忘记某项长期记忆，可以在对话中明确提出删除请求，再让它确认结果，详见[记忆管理](./configuration/memory.md#通过对话增删记忆)。不要为了删除一条记忆而删除整个 Hermes Agent。

### 删除 Hermes Agent 后能否恢复

不能。删除为不可逆操作，对话、通道绑定、已安装技能均会一并清除。

## 技能相关

### 安装技能后是否需要触发词

不需要。使用自然语言描述需求即可，Hermes Agent 自动判断是否调用技能。

### 如何卸载技能

在[技能页](/agents/skills)打开当前 Bot 的 **已安装** 列表，找到目标技能，点击删除图标并确认；系统预置技能不能删除。详见[配置技能 - 删除已安装的技能](./configuration/skill.md#删除已安装的技能)。

### 技能是否额外收费

取决于技能作者。SkillHub 上架的多数技能免费，部分技能可能调用外部付费服务（消耗自有 API 额度），详见技能详情页说明。

### 能否自行开发技能上架

开发者上架能力规划中，当前仅可使用已上架技能。

## 故障排查

### 创建 Hermes Agent 长时间停留在过渡页

可能为云端初始化慢或网络波动。建议：

1. 等待 1 分钟

2. 仍无响应则刷新页面

3. 再无响应则重新点击「+ 创建 Hermes Agent」

### 扫码后管理台无响应

可能为授权未完成或网络延迟。关闭弹窗重新点击「授权接入」生成新二维码。

### 机器人完全无响应的排查顺序

| 检查项 | 方法 |
|---|---|
| 通道状态 | 「已接入通道」列表是否仍在 |
| 体验积分 | 是否耗尽 |
| 模型状态（若使用自有模型） | 「当前模型」是否有记录 |
| Key 状态（若使用自有模型） | 在服务商后台确认余额与 Key 状态 |
| 网络 | 浏览器是否能正常打开 LightVela |

### 回复内容为乱码或无意义

多数情况下为自定义模型的端点不符合 OpenAI 协议。建议先使用其他 OpenAI 兼容客户端验证端点可用性。

### 提示「模型响应超时」

服务商限流或网络波动。稍后重试，或切换其他服务商。

### 如何重建 Hermes Agent

删除当前 Hermes Agent 后重新点击「+ 创建 Hermes Agent」，所有数据将清零。
