## 账号与登录

### 支持什么方式登录？

支持 QQ 或微信登录。

---

## 实名认证

### 实名认证何时触发

登录后浏览首页、阅读文档不需要实名。**首次点击「立即开通」领取套餐**时，若账号未认证，页面顶部会出现提示条，引导前往账号信息页完成认证。

### 支持哪些证件类型

当前仅支持中国大陆居民身份证，其他证件类型暂未开放。

### 实名是否需要每次开通套餐都做一次

不需要。认证为一次性操作，完成后开通任意套餐、购买 LightVela 其他产品均无需重复认证。

### 实名后能否修改实名信息

可以。进入账号页，在实名认证一行点击「修改」重新提交真实姓名和身份证号。新信息通过核验后会覆盖当前实名信息，后台保留变更记录。

### 实名后能否修改账号显示名或 Hermes 名字

可以。实名认证绑定的是真实姓名和身份证号，与账号显示名、Hermes 实例名称无关，后两者可在对应页面随时修改。

### 认证失败如何处理

| 现象 | 可能原因 | 处理方式 |
|---|---|---|
| 提示姓名与身份证号不匹配 | 填写错误 | 核对后重新提交 |
| 提交后长时间无响应 | 网络波动或后台繁忙 | 稍后重试 |

## 启航套餐与体验积分

### 启航套餐包含什么

套餐内容与配额详见 [LightVela 是什么 - 关于套餐](./01-overview.md#关于套餐)。

### 「100 体验积分」的含义

启航套餐预置的模型调用额度。无需自行准备 API Key 即可使用——创建 Hermes、接入通道后发起的对话将消耗此额度。

### 积分耗尽后如何处理

积分耗尽后，消息将无法得到模型响应。需在「模型」卡片配置自有 API Key，详见 [配置模型](./configuration/model.md)。

### 积分是否支持充值

当前不支持单独充值积分，持续使用需配置自有 API Key。

### 一个账号是否只能创建 1 个 Hermes

启航套餐限制为 1 个，巡游、远航套餐即将上线。

## 模型相关

### 如何获取 API Key

在管理台「模型」卡片选中某个服务商后，下方显示「点击获取 API KEY」外链，点击可直达该服务商官网的注册与 Key 管理页。详见 [配置模型](./configuration/model.md)。

### 如何选择模型

详见 [配置模型 - 选型参考](./configuration/model.md#选型参考)。

### 消息发送后 Hermes 无响应的排查方式

按以下顺序检查：

1. 管理台「已接入通道」是否有记录

2. 若使用自有模型：「当前模型」是否有记录、服务商余额是否充足

3. 若使用体验积分：积分是否耗尽

4. Key 是否在服务商后台被禁用

### 切换模型是否会丢失对话记忆

不会。对话记忆为 Hermes 自身数据，模型仅负责生成响应。

## 通道相关

### 微信、飞书、QQ 能否同时接入

可以。多个通道指向同一个 Hermes 实例，共享记忆与 Agent 行为。

### 能否将机器人添加至微信群

当前不支持。微信通道仅支持 1 对 1 对话。

### 如何解除已接入的通道

在管理台「已接入通道」列表中删除对应条目。解除后，该聊天平台中的机器人将失效。

---

## 故障排查

### 创建 Hermes 长时间停留在过渡页

可能为云端初始化慢或网络波动。建议：

1. 等待 1 分钟

2. 仍无响应则刷新页面

3. 再无响应则重新点击「+ 创建 Hermes」

### 扫码后管理台无响应

可能为授权未完成或网络延迟。关闭弹窗重新点击「授权接入」生成新二维码。

### 机器人完全无响应的排查顺序

| 检查项 | 方法 |
|---|---|
| 通道状态 | 「已接入通道」列表是否仍在 |
| 体验积分 | 是否耗尽 |
| 模型状态（若使用自有模型） | 「当前模型」是否有记录 |
| Key 状态（若使用自有模型） | 在服务商后台确认余额与 Key 状态 |
| 网络 | 浏览器是否能正常打开 LightVela |

### 提示「模型响应超时」

服务商限流或网络波动。稍后重试，或切换其他服务商。

### 如何重建 Hermes

删除当前 Hermes 后重新点击「+ 创建 Hermes」，所有数据将清零。
