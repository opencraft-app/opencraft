# Chat

## Resumen

**Después de iniciar sesión y activar un plan de LightVela, puede hablar con el Bot seleccionado desde Chat en la sección de uso diario de My Agent, sin conectar antes un canal de mensajería. La barra lateral muestra las conversaciones de ese Bot y permite iniciar una nueva o retomar una existente. Antes de enviar un mensaje, compruebe que el Bot esté en línea y que haya créditos de modelo disponibles o un modelo configurado.**

![Nueva conversación de Web Chat en la consola internacional de LightVela](../../images/chat-overview-en.webp)

## Iniciar una conversación

Tras iniciar sesión con Google o GitHub y activar un plan disponible, abra la [consola del Agent](/agents/overview/). Complete la configuración del primer Bot: introduzca el nombre obligatorio, añada una descripción opcional y ajuste su apariencia. Seleccione **Crear** y espere a que terminen la creación y la configuración inicial. Cuando termine la configuración, seleccione **Empieza tu viaje** y abra el chat web de ese Bot. El canal de mensajería es opcional; las respuestas requieren créditos de modelo disponibles o un modelo configurado.

1. Abra My Agent y seleccione el Bot en la parte superior de la barra lateral.
2. Abra Chat en la sección de uso diario y elija crear una conversación nueva. También puede iniciar una conversación para un Bot desde su tarjeta en la página de resumen.
3. Escriba una pregunta o tarea en el cuadro de mensajes y envíela.
4. Lea la respuesta. El cuadro de mensajes aparece en cuanto se abre una conversación nueva, así que puede empezar a escribir; el envío se habilita cuando la conexión está lista. Al abrir una conversación existente puede aparecer brevemente un mensaje de espera.

El Chat web no requiere un canal externo. Para usar el mismo Bot en Telegram, WhatsApp, Discord o WeChat, conecte esa plataforma en Canales.

## Retomar o administrar conversaciones

Las conversaciones recientes del Bot seleccionado aparecen bajo Chat. Seleccione un título para continuar o use la opción de mostrar más para ver conversaciones anteriores. El menú de cada conversación permite cambiarle el nombre o eliminarla. Al cambiar de Bot, la lista muestra sus conversaciones correspondientes.

Hermes conserva las preferencias y los datos de proyectos que resulten útiles a largo plazo. Consulte [Memoria](./memory.md) para revisar la memoria del Bot seleccionado; iniciar una conversación nueva no la borra.

## Comprobar el resultado y resolver problemas

- **Resultado esperado:** El mensaje aparece en la conversación, el Bot responde y puede retomar esa conversación desde la barra lateral después de recargar.
- **La pantalla sigue cargando:** Compruebe que el Bot esté en línea y recargue la página. Espere a que aparezca el cuadro de mensajes.
- **No puede enviar o recibir una respuesta:** Revise los créditos del plan o la [configuración del modelo](./model.md) y confirme que el Bot no esté pausado. El Chat web no necesita un canal conectado.
