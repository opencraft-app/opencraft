# ¿Cómo activo mi primera instancia de Hermes?

## Resumen

**Tras iniciar sesión con Google o GitHub y activar un plan disponible, abra la [consola del Agent](/agents/overview/). Complete la configuración del primer Bot: introduzca el nombre obligatorio, añada una descripción opcional y ajuste su apariencia. Seleccione Crear y espere a que terminen la creación y la configuración inicial. Cuando termine la configuración, seleccione Empieza tu viaje y abra el chat web de ese Bot. El canal de mensajería es opcional; las respuestas requieren créditos de modelo disponibles o un modelo configurado.**

---

El control para cerrar y las opciones avanzadas de copia solo aparecen cuando hay Bots de origen válidos. La primera configuración sin origen debe completarse. Los controles de apariencia cambian el color, la forma y los accesorios; no seleccionan el origen de la copia.

## Requisitos previos

- Una cuenta de Google o GitHub

- Un plan actualmente disponible seleccionado desde la [página de Suscripción](/subscribe); el sitio internacional no requiere verificación de identidad real en China

- Una cuenta de Telegram, WhatsApp, Discord, Slack o WeChat solo si desea usar esa aplicación de mensajería

---

## Flujo de activación

### 1. Iniciar sesión con Google o GitHub

Abra LightVela y autorice el acceso con Google o GitHub. Su cuenta de LightVela se crea automáticamente la primera vez que inicia sesión, por lo que no hay contraseña separada que configurar. Continúe utilizando la misma identidad de inicio de sesión en futuras visitas para acceder a las mismas instancias de Hermes y datos.

### 2. Seleccionar un plan disponible en la página de Suscripción

Abra la [página de Suscripción](/subscribe) para ver qué planes y cuotas están actualmente disponibles. [Planes](./plans.md) describe la estructura de recursos Launch y Cruise, pero la página de Suscripción es la autoridad sobre lo que se puede activar ahora.

No hay un paso de verificación de identidad real en China en el sitio internacional. Después de iniciar sesión con Google o GitHub, puede seleccionar cualquier plan actualmente disponible.

### 3. Activar el plan mediante el flujo de activación internacional actual

Elige un plan disponible en la [página de suscripción](/subscribe/) y sigue las indicaciones de la tarjeta para activarlo. Consulta la página para conocer las ofertas y los precios actuales.

### 4. Completar la configuración del primer Bot

Tras iniciar sesión con Google o GitHub y activar un plan disponible, abra la [consola del Agent](/agents/overview/). Complete la configuración del primer Bot: introduzca el nombre obligatorio, añada una descripción opcional y ajuste su apariencia. Seleccione **Crear** y espere a que terminen la creación y la configuración inicial. Cuando termine la configuración, seleccione **Empieza tu viaje** y abra el chat web de ese Bot. El canal de mensajería es opcional; las respuestas requieren créditos de modelo disponibles o un modelo configurado.

### 5. Configure y despierte su Agent

Una vez que la instancia esté lista, abra el consuelo y complete la configuración básica:

1. **Compruebe el modelo** — Si hay créditos disponibles, puede comenzar sin su propia clave de API; consulte [Configurar Modelos](./configuration/model.md) cuando sea necesario

2. **Pruebe el Chat web** — Inicie una conversación en Chat y envíe un mensaje; consulte [Chat](./configuration/agent-chat.md)

3. **Conecte un canal si lo necesita** — Añada Telegram, WhatsApp, Discord o WeChat para usar el Bot en una aplicación de mensajería

4. **Añada Skills y tareas programadas si lo desea** — Consulte [Configurar Tareas programadas](./configuration/automation.md)

Su primer Agent de Hermes ya está listo para permanecer en línea en la nube las 24 horas del día, los 7 días de la semana.

## Preguntas frecuentes

### ¿Cuánto tiempo puedo utilizar la instancia después de la activación?

Tras la creación, compruebe el nombre del nuevo Bot en el selector, abra su chat web y envíe un mensaje breve de prueba. Si falla la creación o la configuración inicial, siga la opción de reintento mostrada y revise la lista de Bots antes de crear otro. Si no recibe respuesta, compruebe el estado del Bot y los créditos o la configuración del modelo.

### ¿Dónde puedo consultar los planes y las ofertas actuales?

Consulta la [página de suscripción](/subscribe/) y [Planes](./plans.md) para conocer las condiciones, las ofertas para nuevos usuarios y las reglas de renovación actuales.

### ¿Cuántas instancias de Hermes puede activar una cuenta?

El número depende de la cuota de Agent del plan seleccionado. Launch y Cruise incluyen cada uno un Agent. Consulte [Planes](./plans.md).

### ¿Necesito mantener un servidor después de la activación?

No. Su instancia de Hermes se ejecuta en un entorno de nube gestionado por LightVela. LightVela se encarga de las operaciones y la disponibilidad las 24 horas del día, los 7 días de la semana; solo usted configura el Agent a través del consuelo web.
