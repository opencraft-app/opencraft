# LightVela 适合哪些人使用？

LightVela 是腾讯轻量云团队推出的云端 Agent 托管产品，适合**想拥有一个长期在线、认识你、越聊越懂你的专属 AI 伙伴，但不想碰服务器、容器和 API 鉴权的用户**。它把 Agent 的部署、运维、7×24 小时运行都放到云端托管，你只需在网页上点选，就能在微信 / QQ / 飞书里和自己的 Hermes Agent 对话。

如果你还不清楚 LightVela 具体是什么，可以先看 [LightVela 是什么](./01-overview.md)。

***

## 适合谁

下面几类人从 LightVela 获益最明显：

* **想用 AI Agent、但没有技术背景的人**
  你不需要懂服务器、Docker、反向代理或 API 鉴权。开通套餐后，云端自动完成环境配置与运行时管理，你面对的只有一个可视化管理面板。

* **希望在日常聊天软件里用 AI，而不是再装一个独立 App 的人**
  Hermes Agent 通过 [通道](./04-core-concepts.md) 接入微信、QQ、飞书。你在平时聊天的地方直接 @ 它就行，不用切换应用。

* **偏好使用国内大语言模型的人**
  支持接入 MiniMax、DeepSeek、Kimi、豆包、千问、智谱、文心、MiMo 等国内模型，也支持任何 OpenAI 兼容端点，具体见 [配置模型](./configuration/model.md)。

* **需要跨会话持续记忆的人**
  与普通聊天机器人不同，Hermes 会跨会话保存对话与记忆，响应时综合历史上下文——不用每次打开都重新自我介绍。

* **想要一个 7×24 小时在线、独立运行的 Agent 的人**
  每个 Hermes 实例拥有独立运行环境，资源隔离、持续在线，不依赖你的本地设备是否开机。

## 典型使用场景

LightVela 特别适合这些场景：

* **个人 AI 助手**：日程提醒、信息整理、随时问答，见 [如何用 LightVela 搭建个人 AI 助手？](./use-cases/personal-ai-assistant.md)

* **常驻在线的对话入口**：把 Agent 挂在微信 / QQ / 飞书里，随时可聊，见 [如何把 AI Agent 接入微信 / QQ / 飞书？](./use-cases/chinese-messaging-channels.md)

* **每日定时任务**：让 Agent 按固定时间自动执行任务、汇总你关心的内容，见 [如何用 Hermes Agent 做每日信息总结？](./use-cases/daily-summary.md)

* **长期记忆与个人知识管理**：把 Agent 当成越用越懂你的知识伙伴，见 [如何用 Agent 管理长期记忆和个人知识？](./use-cases/memory-and-knowledge.md)

## 前置条件

开始使用前，你需要：

* 一个可完成实名认证的账号（首次开通套餐前需实名认证，详见 [账号与实名认证](./03-account.md)）

* 开通一个套餐以获得 Hermes 实例（内测期启航套餐限时免费）

* 至少一个可接入的聊天通道账号（微信 / QQ / 飞书）

无需自备服务器，也无需具备任何运维能力。

***

## 如果你不确定是否适合

如果你的需求是"完全本地运行、数据不离开终端""训练或微调底层模型""把 Agent 集成进自己的网站或 App"，那么 LightVela 可能不是最合适的选择。
