# แชท

## สรุป

**หลังจากเข้าสู่ระบบและเปิดใช้งานแผน LightVela แล้ว คุณสามารถแชทกับบอทที่เลือกจาก Daily → Chat ใน My Agent โดยไม่ต้องเชื่อมต่อช่องทางการส่งข้อความก่อน แถบข้างเก็บบทสนทนาของบอทนั้น ดังนั้นคุณสามารถเริ่มบทสนทนาใหม่หรือกลับไปยังบทสนทนาที่มีอยู่ได้ ก่อนส่งข้อความ ให้แน่ใจว่าบอทออนไลน์และมีเครดิตของโมเดลตามแผนหรือมีการตั้งค่าโมเดลเรียบร้อยแล้ว**

![การสนทนาใหม่ในคอนโซลระหว่างประเทศ LightVela โดยที่แถบด้านข้างถูกย่อ](../../images/chat-overview-en.webp)

## เริ่มต้นการสนทนา

1. เปิด My Agent และเลือกบอทที่คุณต้องการใช้ที่ด้านบนของแถบด้านข้าง
2. ภายใต้ Daily ขยายส่วน Chat แล้วเลือก New conversation คุณสามารถเริ่มการสนทนาสำหรับบอทเฉพาะจากการ์ดของมันบนหน้า Overview ได้เช่นกัน
3. ป้อนคำถามหรือภารกิจของคุณใน “Share your thoughts, or ask me to help with something” จากนั้นส่ง
4. อ่านคำตอบในการสนทนา ตัวเขียนปรากฏขึ้นทันทีที่เริ่มการสนทนาใหม่ ดังนั้นคุณสามารถเริ่มเขียนได้ การส่งข้อความจะพร้อมใช้งานเมื่อการเชื่อมต่อพร้อม การเปิดการสนทนาที่มีอยู่แล้วอาจปรากฏข้อความสั้น ๆ ว่า “Your AI companion will be right here.”

เว็บแชทไม่ต้องการช่องทางการส่งข้อความ ในการใช้บอตเดียวกันใน Telegram, WhatsApp, Discord, หรือ WeChat ให้เชื่อมต่อแพลตฟอร์มนั้นภายใต้ช่องทาง

## กลับไปยังหรือจัดการการสนทนา

การสนทนาล่าสุดสำหรับบอทที่เลือกจะแสดงภายใต้แชท เลือกหัวข้อเพื่อดำเนินการต่อ; ใช้ แสดงเพิ่มเติม เพื่อเปิดเผยการสนทนาที่เก่ากว่า เมนูข้างการสนทนาช่วยให้คุณเปลี่ยนชื่อหรือลบการสนทนานั้น การเลือกบอทอื่นจะแสดงการสนทนาของบอทนั้น

Hermes เก็บความชอบและรายละเอียดโครงการที่มีประโยชน์ในระยะยาวตามความเหมาะสม ดู [ความจำ](./memory.md) เพื่อดูหน่วยความจำระยะยาวของบอทที่เลือก; การเริ่มการสนทนาใหม่จะไม่ล้างข้อมูลนั้น

## ตรวจสอบและแก้ไขปัญหา

- **ผลลัพธ์ที่คาดหวัง:** ข้อความของคุณปรากฏในบทสนทนา บอทตอบกลับ และคุณสามารถกลับไปที่บทสนทนาได้จากแถบด้านข้างหลังจากรีเฟรช
- **ข้อความกำลังโหลดคงอยู่:** ยืนยันว่าบอทออนไลน์ จากนั้นรีเฟรชหน้า รอคอมโพเซอร์ก่อนตัดสินใจว่าแชทไม่สามารถใช้งานได้
- **ไม่สามารถส่งหรือรับข้อความตอบกลับ:** ตรวจสอบเครดิตโมเดลของแผนที่ใช้ได้ หรือ [การกำหนดค่าโมเดล](./model.md) และยืนยันว่าบอทไม่ได้ถูกพัก ไม่จำเป็นต้องเชื่อมต่อช่องทางภายนอกสำหรับ Web Chat
