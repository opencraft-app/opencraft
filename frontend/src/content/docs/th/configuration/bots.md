# จัดการบอท

## สรุป

**บอทคือโปรไฟล์อิสระภายใน Hermes เอเจนต์ของคุณ บอทหลักถูกสร้างขึ้นพร้อมกับเอเจนต์ และบอทเพิ่มเติมแต่ละตัวสามารถมีการตั้งค่ารูปแบบ บุคลิกความจำ ทักษะ ช่องทาง และงานที่กำหนดเวลาได้ เมื่อคุณสร้างบอท ให้เลือกว่าต้องการคัดลอกจากบอทที่มีอยู่แล้วหรือเริ่มต้นด้วยการตั้งค่าพื้นฐาน แผนของคุณจะกำหนดจำนวนบอทที่คุณสามารถสร้างได้ รวมถึงบอทหลักด้วย**


## หน้านี้ครอบคลุม

- ความสัมพันธ์ระหว่างเอเจนต์ Hermes และบอทของมัน
- การสร้างบอทโดยการคัดลอกจากบอทที่มีอยู่แล้วหรือใช้การตั้งค่าเบื้องต้น
- สิ่งที่วิธีการสร้างแต่ละวิธีสืบทอด
- การสลับ เปลี่ยนชื่อ และลบบอท

## ก่อนที่คุณจะเริ่ม

1. ยืนยันว่า Hermes Agent ของคุณกำลังทำงานอยู่  
2. ยืนยันว่าแผนของคุณมีพื้นที่สำหรับ Bot อีกตัว ขีดจำกัดของแผนรวมถึง Bot หลักด้วย  
3. เปิด **Agents** และเลือก Agent ที่คุณต้องการจัดการ

## สร้างบอท

เมื่อต้องการสร้างบอทถัดไป ให้เลือก **บอทใหม่** หากมีปุ่มนี้และโควตาแพ็กเกจยังเพียงพอ กรอก **ชื่อ** (จำเป็น) และ **คำอธิบาย** (ไม่บังคับ) แล้วปรับรูปลักษณ์ตามต้องการ ค่าเริ่มต้นคือ **การตั้งค่าพื้นฐาน** หากมีบอทต้นทางที่คัดลอกได้ ให้เปิด **ขั้นสูง** แล้วเลือกบอทต้นทางที่ต้องการ หากต้องการคัดลอกบอทที่ใช้อยู่ ให้เปิด **จัดการบอท → คัดลอก Bot** แบบฟอร์มจะเลือกต้นทางนั้นไว้ให้ ตรวจสอบต้นทาง เลือก **สร้าง** แล้วรอจนเสร็จ

ปุ่มปิดและตัวเลือกการคัดลอกขั้นสูงจะแสดงเมื่อมีบอทต้นทางที่ใช้ได้เท่านั้น การตั้งค่าครั้งแรกที่ไม่มีต้นทางต้องทำให้เสร็จ ตัวควบคุมรูปลักษณ์ใช้ปรับสี รูปร่าง และเครื่องประดับ ไม่ได้ใช้เลือกต้นทางสำหรับคัดลอก

## เลือกวิธีการสร้าง

| วิธีการ | สืบทอด | ไม่สืบทอด |
| --- | --- | --- |
| คัดลอก Bot | โมเดล, บุคลิก, ทักษะ, ความชอบของผู้ใช้, และความทรงจำระยะยาวจากบอทต้นทางที่เลือก | การสนทนาปัจจุบัน, ประวัติแชท, งานที่กำหนดเวลา, สถานะการทำงาน, และการเชื่อมต่อช่องทาง |
| การตั้งค่าพื้นฐาน | โมเดลหลักปัจจุบันของบอทและข้อมูลประจำตัวของผู้ให้บริการ, รวมถึงทักษะระบบที่ติดตั้งมาในตัว | โมเดลสำรอง, โมเดลอื่นที่กำหนดค่าไว้, บุคลิก, ความทรงจำ, ทักษะที่ติดตั้งภายหลังบนบอทหลัก, ช่องทาง, และงานที่กำหนดเวลา |

**การตั้งค่าพื้นฐานไม่ใช่บอทว่างเปล่า** มันเก็บโมเดลขั้นต่ำและการกำหนดค่าทักษะในตัวที่จำเป็นเพื่อเริ่มต้น ในขณะที่ปล่อยให้พฤติกรรมส่วนตัว ความจำ และการรวมระบบแยกออกต่างหาก

## ยืนยันบอทใหม่

หลังสร้างเสร็จ ให้ตรวจสอบชื่อบอทใหม่ในตัวเลือก เปิดเว็บแชทของบอทนั้น และส่งข้อความทดสอบสั้น ๆ หากการสร้างหรือการตั้งค่าเริ่มต้นล้มเหลว ให้ทำตามปุ่มลองอีกครั้งที่แสดงและตรวจสอบรายการบอทก่อนสร้างใหม่ หากไม่มีคำตอบ ให้ตรวจสอบสถานะบอทและเครดิตหรือการตั้งค่าโมเดล

## ทำงานกับบอทหลายตัว

เลือกอวาตาร์ของบอทที่ต้องการจากแถบบอท หากหน้าจอแคบ ให้เปิดแผงนำทางก่อน ตรวจสอบชื่อก่อนเปลี่ยนโมเดล หน่วยความจำ สกิล ช่องทาง หรืองานตามกำหนดเวลา เว็บแชทและรายการบทสนทนาจะเป็นของบอทที่เลือก บอทเพิ่มเติมก็ใช้เว็บแชทได้ และเว็บแชทไม่ต้องเชื่อมต่อช่องทางรับส่งข้อความ

ในการเปลี่ยนชื่อบอท ให้เลือกบอทนั้นแล้วแก้ไขชื่อที่แสดง ชื่อใหม่สามารถมีอักขระได้สูงสุด 60 ตัว

## ลบบอท

- การลบบอทเพิ่มเติมจะเป็นการลบบัญชีและข้อมูลของบอทนั้นอย่างถาวร  
- ตัดการเชื่อมต่อช่องทางที่เป็นของบอทนั้นก่อนที่จะลบ  
- ลบบอทเพิ่มเติมทั้งหมดก่อนที่จะลบบอทหลัก  
- การลบบอทหลักจะลบเอเจนต์ทั้งหมด รวมถึงแชททั้งหมด การตั้งค่า สกิลที่ติดตั้ง ความทรงจำ และข้อมูลที่เกี่ยวข้องทั้งหมด

การลบไม่สามารถย้อนกลับได้ โปรดอ่านข้อความยืนยันอย่างละเอียดและใส่ชื่อบอทที่ร้องขอก่อนยืนยัน

## การแก้ไขปัญหา

### ทำไมฉันถึงสร้างบอทตัวอื่นไม่ได้?

ตรวจสอบว่าบัญชีเปิดใช้การสร้างหลายบอทหรือไม่ Agent กำลังทำงานหรือไม่ โควตาแพ็กเกจเพียงพอหรือไม่ และมีการสร้างหรือลบบอทอื่นอยู่หรือไม่

### ทำไมบอทที่คัดลอกมาถึงขาดการสนทนา งาน หรือช่องทาง?

รายการเหล่านี้ตั้งใจไม่ถูกคัดลอก เชื่อมต่อช่องทางใหม่และสร้างงานตามกำหนดสำหรับบอทใหม่ตามความจำเป็น

### ทำไมการตั้งค่าพื้นฐานยังแสดงโมเดลและทักษะอยู่?

การตั้งค่าพื้นฐานสืบทอดโมเดลหลักปัจจุบันของบอทหลักและข้อมูลประจำตัวของผู้ให้บริการ และเก็บไว้เฉพาะทักษะในระบบที่ติดตั้งมาแล้วเท่านั้น มันจะไม่คัดลอกโมเดลอื่น ๆ ของบอทหลัก บุคลิกภาพ หน่วยความจำ ทักษะที่ติดตั้งภายหลัง ช่องทาง หรือภารกิจที่กำหนดเวลาไว้
