# ความสําเร็จ

## สรุป

**หน้าความสำเร็จแสดงความก้าวหน้าการใช้งานของ Hermes Agent ของบอทปัจจุบัน โดยสรุปความสำเร็จที่ปลดล็อกแล้ว ค้นพบ และเป็นความลับ ระดับสูงสุดที่ถึง และสถานะของแต่ละการ์ด หมวดหมู่ ความก้าวหน้า กฎการนับ และเซสชันต้นทางเมื่อมี** ใช้หน้าดังกล่าวเพื่อตรวจสอบประวัติ Hermes ของบอทปัจจุบันอีกครั้ง และตรวจสอบว่าการใช้เครื่องมือ การดีบัก การตั้งค่าโมเดล หน่วยความจำ ทักษะ งานเอกสาร และระบบอัตโนมัติได้รับการยอมรับหรือไม่

![หน้ารางวัลแสดงการ์ดสถิติ ตัวกรองสถานะ ตัวกรองหมวดหมู่ และการ์ดความสำเร็จ](../../images/achievements-overview.webp)

---

ความสำเร็จไม่ใช่สิ่งที่คุณตั้งค่าได้ด้วยตนเอง LightVela สร้างมันจากพฤติกรรมในอดีตของ Hermes เอเจนต์ของบอทปัจจุบัน พวกมันช่วยให้คุณเข้าใจว่าคุณได้สำรวจความสามารถของเอเจนต์ใดไปแล้วบ้าง และโมดูลความสำเร็จได้อ่านประวัติล่าสุดหรือไม่

หากคุณเป็นผู้ใช้ใหม่ของ LightVela ให้ลองทำเวิร์กโฟลว์พื้นฐานก่อน เช่น [แชท](./agent-chat.md), [การกำหนดค่าทักษะ](./skill.md), [การจัดการหน่วยความจำ](./memory.md), หรือ [งานที่ตั้งเวลาไว้](./automation.md) จากนั้นกลับไปที่ความสำเร็จเพื่อตรวจสอบความก้าวหน้า

## ก่อนที่คุณจะเริ่ม

1. ลงชื่อเข้าใช้ LightVela และตรวจสอบให้แน่ใจว่าอย่างน้อยมี Hermes เอเจนต์ (Agent) ที่กำลังทำงานอยู่  
2. เปิดคอนโซลสำหรับบอทที่คุณต้องการตรวจสอบ  
3. เพื่อดูความคืบหน้าอย่างมีประสิทธิภาพ บอทควรมีบทสนทนาจริง การเรียกใช้เครื่องมือ การเปลี่ยนแปลงการตั้งค่า หรือกิจกรรมงานตามกำหนดแล้ว

ความสำเร็จจะถูกอ่านตามบอท หลังจากเปลี่ยนไปใช้บอทอื่น ภาพรวมและความก้าวหน้าอาจแตกต่างกัน

## เปิดหน้าความสำเร็จ

1. ลงชื่อเข้าใช้ที่ LightVela
2. เปิดคอนโซล My Hermes
3. เลือก ความสำเร็จ ในเมนูการตั้งค่า
4. รอให้หน้าดึงประวัติ Hermes ของบอทปัจจุบัน

หลังจากการโหลดเสร็จสิ้น หน้าเพจจะแสดงการ์ดสถิติ ตัวกรองสถานะและหมวดหมู่ และกริดการ์ดความสำเร็จ

## อ่านบัตรสถิติ

ด้านบนของหน้าจะแสดงสถิติสี่รายการ:

| สถิติ | ความหมาย |
| --- | --- |
| ปลดล็อกแล้ว | ความสำเร็จที่เงื่อนไขครบถ้วนแล้ว เทียบกับจำนวนที่เห็นอยู่ในปัจจุบัน |
| ค้นพบแล้ว | ความสำเร็จที่มีความคืบหน้าแล้ว แต่ยังไม่ได้ปลดล็อก |
| ความสำเร็จลับ | ความสำเร็จที่เงื่อนไขที่แท้จริงยังถูกซ่อนไว้จนกว่าพฤติกรรมที่เกี่ยวข้องจะปรากฏ |
| ระดับสูงสุด | ระดับสูงสุดที่บอทปัจจุบันบรรลุเรียบร้อยแล้ว ลำดับระดับคือ ทองแดง, เงิน, ทอง, เพชร, และโอลิมเปียน |

หากหน้าบอกว่า Hermes ประวัติถูกอ่าน โมดูลความสำเร็จกำลังสแกนเซสชันอยู่ รอให้การสแกนเสร็จสิ้นก่อนที่จะพิจารณาสถิติเป็นขั้นสุดท้าย

## กรองความสำเร็จ

ใช้ตัวกรองสองตัวด้านล่างสถิติ:

1. **ตัวกรองสถานะ**: แสดงทั้งหมด, ปลดล็อกแล้ว, ค้นพบแล้ว, หรือความสำเร็จลับ  
2. **ตัวกรองหมวดหมู่**: กรองหมวดหมู่เช่น ความเป็นอิสระของเอเจนต์, การแก้จุดบกพร่องอย่างวุ่นวาย, การเขียนโค้ดตามบรรยากาศ, Hermes เนทีฟ, การวิจัย/เว็บ, ความชำนาญในเครื่องมือ, ตำนานของโมเดล, และวิถีชีวิต

ถ้าหน้าเว็บไม่แสดงความสำเร็จที่ตรงกัน ให้สลับตัวกรองทั้งสองกลับไปที่ทั้งหมด หากรายการยังว่างอยู่ ให้สแกนประวัติของบอทปัจจุบันอีกครั้ง

## อ่านการ์ดความสำเร็จ

การ์ดความสำเร็จแต่ละใบสามารถรวมฟิลด์เหล่านี้ได้:

| ฟิลด์ | ความหมาย |
| --- | --- |
| ชื่อและคำอธิบาย | พฤติกรรมเจ้าหน้าที่ Hermes ที่แสดงโดยความสำเร็จ ความสำเร็จที่เป็นความลับจะแสดงเป็นความลับจนกว่าจะถูกค้นพบ |
| สถานะ | ปลดล็อก, ค้นพบ, หรือเป็นความลับ |
| ระดับ | ความสำเร็จแบบมีระดับที่ปลดล็อกสามารถแสดงเป็น ทองแดง, เงิน, ทอง, เพชร, หรือ นักกีฬาโอลิมปิก |
| ความก้าวหน้า | ความก้าวหน้าปัจจุบัน, เกณฑ์ถัดไป, หรือร้อยละ ความสำเร็จที่เป็นความลับจะแสดงข้อกำหนดที่ซ่อนอยู่ |
| กฎการนับ | ขยายกฎเพื่อดูว่าสิ่งใดถูกนับ เช่น การเรียกใช้เครื่องมือ, การตรวจสอบบันทึก, การกำหนดค่าโมเดล, หรือกิจกรรมเอกสาร |
| เซสชันต้นทาง | บางความสำเร็จจะแสดงชื่อเซสชันที่มีหลักฐานสนับสนุนความก้าวหน้า |

กฎการนับมาจากประวัติผู้แทน Hermes หากการ์ดระบุว่าไม่มีกฎการนับที่ถูกส่งกลับ นั่นหมายความเพียงว่าหน้าเพจนั้นไม่มีข้อความกฎให้แสดงสำหรับการ์ดนั้น ไม่ได้หมายความว่าความสำเร็จนั้นจะไม่สามารถปลดล็อกได้

## ประวัติการสแกนซ้ำ

เมื่อคุณเพิ่งทำการสนทนา การเรียกใช้เครื่องมือ หรือการกำหนดค่าเสร็จ แต่หน้ายังไม่เปลี่ยน ให้สแกนประวัติอีกครั้ง:

1. เปิดความสำเร็จ
2. คลิกปุ่มสแกนใหม่ที่มุมบนขวา
3. รอจนกว่าปุ่มจะหยุดหมุนหรือข้อความอ่านประวัติจะหายไป
4. ตรวจสอบว่าการ์ดสถิติและการ์ดความสำเร็จที่เกี่ยวข้องเปลี่ยนหรือไม่

การสแกนซ้ำจะอ่านประวัติ Hermes ปัจจุบันของบอท บอทที่มีประวัติยาวอาจใช้เวลาสแกนนานขึ้น

## ยืนยันว่าการก้าวหน้าได้รับการยอมรับ

หลังจากทำกิจกรรมจริงเสร็จ ใช้รายการตรวจสอบนี้:

1. ในบอทปัจจุบัน ให้ทำการกระทำที่สามารถนับได้ เช่น ตรวจสอบบันทึกการใช้งาน ใช้เครื่องมือ เปลี่ยนการตั้งค่าโมเดล รันงานตามตาราง หรือบำรุงรักษาเอกสาร
2. กลับไปที่หน้า Achievement และสแกนใหม่
3. เลือกสถานะว่า Discovered หรือ Unlocked ในตัวกรองสถานะ
4. เปิดกฎการนับของการ์ดที่เกี่ยวข้องและตรวจสอบว่าความคืบหน้า เปอร์เซ็นต์ หรือข้อมูลเซสชันต้นทางมีการเปลี่ยนแปลงหรือไม่

ถ้าไม่มีอะไรเปลี่ยนแปลง ให้ตรวจสอบก่อนว่าการกระทำเกิดขึ้นในบอทเดียวกับที่คุณกำลังดูอยู่

## คำถามที่พบบ่อย

### ทำไมความสำเร็จของฉันถึงไม่อัปเดตทันทีหลังจากใช้ฟีเจอร์?

หน้าจะอ่านภาพรวมประวัติของบอทปัจจุบัน หลังจากมีกิจกรรมล่าสุด คุณอาจจำเป็นต้องสแกนใหม่ ประวัติขนาดใหญ่อาจใช้เวลาสแกนนานขึ้นเช่นกัน

### ทำไมบางความสำเร็จต้องเก็บเป็นความลับ?

ข้อกำหนดความสำเร็จลับจะปรากฏหลังจาก Hermes เอเจนต์ตรวจพบพฤติกรรมที่เกี่ยวข้อง ให้ใช้ Hermes เอเจนต์ต่อไปในการดีบัก เครื่องมือ หน่วยความจำ ทักษะ ปลั๊กอิน การตั้งค่าโมเดล และเวิร์กโฟลว์อัตโนมัติเพื่อเปิดเผยเพิ่มเติม

### ทำไมหน้าจอถึงบอกว่าการบรรลุผลล้มเหลวในการโหลด?

สาเหตุทั่วไป ได้แก่ Hermes เอเจนต์ไม่สามารถใช้งานได้ชั่วคราว ความล้มเหลวในการวิเคราะห์ หรือความล้มเหลวของคำสั่งความสำเร็จ ลองรีเฟรชหรือทำซ้ำก่อน หากปัญหายังคงอยู่ ให้ใช้ [การวินิจฉัย](./diagnostics.md) เพื่อตรวจสอบสถานะบริการและบันทึก

### ทำไมความสำเร็จถึงเปลี่ยนหลังจากสลับบอท?

ความสำเร็จจะถูกอ่านจากประวัติของบอตปัจจุบัน บอตแต่ละตัวมีการสนทนา การเรียกเครื่องมือ ความจำ ทักษะ และประวัติการกำหนดค่าของโมเดลที่แตกต่างกัน ดังนั้นความก้าวหน้าของพวกมันจึงอาจแตกต่างกันได้

### ความสำเร็จมีผลต่อแผน เครดิต หรือสิทธิ์ของฉันหรือไม่?

ไม่ใช่ ความสำเร็จแสดงเพียงความก้าวหน้าในการใช้งานเท่านั้น มันไม่เปลี่ยนแผนของคุณ เครดิต AI โควต้าบอท หรือสิทธิ์การใช้งาน สำหรับรายละเอียดการเรียกเก็บเงิน ใช้ [แผน](../plans.md) และ [เครดิต](../credits.md)
