# เริ่มต้นอย่างรวดเร็ว

## สรุป

**ในการเริ่มการสนทนาครั้งแรกของคุณใน LightVela ให้เข้าสู่ระบบและเปิดใช้งานแผนรอจนกว่า Bot ของคุณจะพร้อม จากนั้นเปิด Daily → Chat ใน My Agent แล้วส่งข้อความ ไม่จำเป็นต้องมีช่องทางส่งข้อความสำหรับ Web Chat และเครดิตโมเดลในแผนที่มีอยู่จะช่วยให้คุณเริ่มต้นได้โดยไม่ต้องเพิ่มคีย์ API ของคุณเอง หากคุณต้องการใช้ Bot เดียวกันนี้ใน WeChat ด้วย ให้ทำตามขั้นตอนรหัส QR ที่อยู่ในหน้าต่อๆ ไป

---

บทเรียนนี้เริ่มต้นด้วย Web Chat จากนั้นจะแสดงวิธีการเชื่อมต่อ WeChat หากจำเป็น ควรเผื่อเวลาเพิ่มเติมสำหรับการตรวจสอบแผนและการจัดเตรียมเอเจนต์

## หน้านี้ครอบคลุม

- กำลังลงชื่อเข้าใช้ LightVela

- การเปิดใช้งานตัวเลือกการเปิดตัวและการเปิดอินสแตนซ์ Hermes ของคุณ

- ส่งข้อความแรกของคุณในเว็บแชท

- กำลังเชื่อมต่อ WeChat หากจำเป็น

- ส่งข้อความใน WeChat และได้รับการตอบกลับ

> 💡 **ข้อกำหนดเบื้องต้น**
>
> - บัญชี Google หรือ GitHub
>
> แผน Launch รวมเครดิตทดลอง 100 หน่วย ดังนั้นคุณสามารถเริ่มสนทนาได้โดยไม่จำเป็นต้องเตรียมโมเดลภาษาขนาดใหญ่ API Key ล่วงหน้า

---

## 1. เข้าสู่ระบบที่ LightVela

ไปที่ [lightvela.ai](https://lightvela.ai) และคลิก "เข้าสู่ระบบ" ที่มุมขวาบน ในหน้าต่างเข้าสู่ระบบ ให้เลือก Google หรือ GitHub ยอมรับข้อตกลง และดำเนินการอนุญาตให้เสร็จสิ้น

![](../images/2-1.webp)

---

## 2. เปิดใช้งานแผนการเปิดตัว

เปิด [หน้าสมัครสมาชิก](/subscribe) เลือกตัวเลือก **100 เครดิต Launch** ในซีรีส์ Launch และทำตามบัตรแผนจนถึงการชำระเงิน ตรวจสอบราคาที่แสดงและข้อเสนอสำหรับคำสั่งซื้อแรกก่อนยืนยัน

> ⚠️ **ข้อเสนอแนะนำผู้ใช้ใหม่**
>
> ผู้ใช้ใหม่ที่มีสิทธิ์สามารถทดลองใช้ Launch เป็นเวลา 1 เดือน ตรวจสอบ [หน้าสมัครสมาชิก](/subscribe/) สำหรับข้อกำหนดและความพร้อมใช้งานปัจจุบัน

---

## 3. เปิดเอเจนต์ Hermes ของคุณ

หลังจากเปิดใช้งานแผนแล้ว ให้เปิด [Agent console](/agents/overview/) LightVela จะจัดเตรียมอินสแตนซ์คลาวด์สำหรับแผนของคุณ หากคอนโซลขอให้คุณสร้าง Agent ให้ทำตามขั้นตอนบนหน้าจอแล้วรอจนกว่าสถานะของมันจะเป็น **Running** ในแถบด้านข้างจะแสดง **Channels**, **Models**, **Skills**, และ **Scheduled Tasks** คุณสามารถใช้เครดิตโมเดลของแผนโดยไม่ต้องป้อนคีย์ API ของคุณเอง

---

## 4. เริ่มต้นการสนทนาในเว็บแชท

เมื่อบอทพร้อมแล้ว ให้เปิด Daily → Chat ในแถบด้านข้าง เลือก การสนทนาใหม่ และส่งข้อความ “สวัสดี” การตอบกลับจะเป็นการทำให้การสนทนาเว็บครั้งแรกของคุณเสร็จสมบูรณ์ ดู [Chat](./configuration/agent-chat.md) สำหรับการควบคุมการสนทนา

## 5. เชื่อมต่อ WeChat หากจำเป็น

เปิด **ช่องทาง** ในแถบด้านข้างของเอเจนต์ บนการ์ด **WeChat** ให้เลือก **+ เชื่อมต่อ** และทำตามคำแนะนำของรหัส QR สแกนรหัสด้วย WeChat บนโทรศัพท์ของคุณและเสร็จสิ้นการอนุญาตยืนยันว่า WeChat ปรากฏว่าเชื่อมต่อแล้วในคอนโซลก่อนส่งข้อความ ดู [การกำหนดค่าช่องทาง - WeChat](./configuration/channel-wechat.md) หากรหัสหมดอายุหรือการเชื่อมต่อล้มเหลว

---

## 6. ส่งข้อความใน WeChat

ค้นหาบัญชีบอทที่เพิ่มเข้ามาใน WeChat และส่งข้อความทดสอบ:

```
Hi
```

![](../images/2-7.webp)

คุณควรได้รับการตอบกลับจาก Hermes ภายในไม่กี่วินาที Hermes สามารถแชทผ่าน WeChat ได้แล้ว

> 💡 **การเรียกเก็บเงินข้อความ**
>
> ตามค่าเริ่มต้น การเรียกใช้โมเดลจะใช้เครดิต 100 เครดิตที่รวมอยู่ในตัวเลือก Launch หากเครดิตหมด คุณสามารถซื้อ [แพ็กเครดิต](./credits.md) ที่มีสิทธิ์หรือกำหนดค่า API ของคุณเองใน **Models**.

---

## ขั้นสูง: กำหนดค่ารูปแบบของคุณเอง (ไม่บังคับ)

หากคุณต้องการผู้ให้บริการเฉพาะ ให้เปิด **Models** ในแถบด้านข้างของ Agent เลือกผู้ให้บริการและโมเดล เพิ่มคีย์ API ของมัน และตั้งค่าโมเดลหลัก ดูที่ [Configure Models](./configuration/model.md).

---

## คำถามที่พบบ่อย

| ปัญหา | สิ่งที่ต้องตรวจสอบ | ขั้นตอนถัดไป |
|---|---|---|
| ตัวเลือกการเปิดใช้งานไม่สามารถเปิดได้ | ความพร้อมใช้งาน ปัจจุบัน คุณสมบัติ หรือสถานะการชำระเงิน | ตรวจสอบ [หน้าการสมัครสมาชิก](/subscribe) และข้อความยืนยันการชำระเงินสุดท้าย; หลีกเลี่ยงการสั่งซื้อซ้ำที่เสร็จสมบูรณ์แล้ว |
| การตั้งค่าเอเจนต์ใช้เวลานานกว่าที่คาด | ว่าคอนโซลยังคงแสดงการเตรียมการหรือเกิดข้อผิดพลาด | รีเฟรชภาพรวมเอเจนต์หนึ่งครั้ง; หากสถานะไม่เปลี่ยน ให้ใช้ [การวินิจฉัย](./configuration/diagnostics.md) หรือติดต่อฝ่ายสนับสนุน |
| รหัส QR WeChat หมดอายุ | ว่าการอนุมัติบนโทรศัพท์เสร็จสิ้นหรือไม่ | เปิด **ช่องทาง** ใหม่และเริ่มการเชื่อมต่อครั้งใหม่ |
| ข้อความไม่ได้รับการตอบกลับ | การเชื่อมต่อช่องทาง สถานะเอเจนต์ และเครดิตโมเดล | ตรวจสอบ **ช่องทาง** และ **การวินิจฉัย** หากเครดิตหมด ให้อนุทิน [ตัวเลือกเครดิต](./credits.md) |
