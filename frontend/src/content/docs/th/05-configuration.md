# ภาพรวมการตั้งค่า

## สรุป

**คอนโซล Agent จะแยกช่องทาง โมเดล ทักษะ และงานที่กำหนดเวลาออกเป็นหน้าในแถบด้านข้าง เลือก Bot ที่ต้องการก่อนเปลี่ยนการตั้งค่า เชื่อมต่อช่องทางข้อความจากการ์ดของมัน เลือกโมเดลหรือใช้เครดิตแผนงาน และติดตั้งทักษะจาก Skills.sh หรือ ClawHub เมื่อจำเป็น Soul, Memory, Diagnostics, การตั้งค่าขั้นสูง และ Labs จะมีอยู่ในส่วนแยกต่างหาก Cloud Storage เปิดได้จากเมนูผู้ใช้ เมื่อ Bot ออนไลน์และมีเครดิตโมเดลแผนงานหรือมีการตั้งค่าโมเดล ใช้ Daily → Chat เพื่อส่งข้อความโดยไม่ต้องเชื่อมต่อช่องทางก่อน

---

คอนโซลของเอเจนต์จะจัดการการตั้งค่าประจำวันในหน้าแถบด้านข้างสำหรับ **ช่องทาง**, **โมเดล**, **ทักษะ** และ **งานที่กำหนดเวลา** เลือกบอทที่คุณตั้งใจจะกำหนดค่า จากนั้นเปิดหน้าที่เกี่ยวข้อง คู่มือนี้แสดงที่ที่ควรเริ่มต้นและวิธีการตรวจสอบผลลัพธ์

## หน้านี้ครอบคลุม

- วิธีเข้าสู่คอนโซล

- ตัวสลับบอทและข้อมูลบอทที่เลือก

- จะหาช่องทาง โมเดล ทักษะ และคลาวด์สตอเรจได้ที่ไหน

- สถานะสำเร็จหลังการกำหนดค่า

- การดำเนินงานทั่วไป เช่น การจัดการบอท การสลับโมเดล และการเชื่อมต่อหลายช่องทาง

---

## เข้าสู่คอนโซล

หลังจากเข้าสู่ระบบแล้ว ให้เปิด [Agent console](/agents/overview/) เลือก Hermes Agent และ Bot ที่คุณต้องการกำหนดค่า


เว็บแชทอยู่ภายใต้การใช้งานรายวัน; เชื่อมต่อช่องทางภายนอกเฉพาะเมื่อคุณต้องการใช้แอปส่งข้อความ

## บอทและข้อมูลบอทที่เลือก

เลือกอวาตาร์ของบอทที่ต้องการจากแถบบอท หากหน้าจอแคบ ให้เปิดแผงนำทางก่อน ตรวจสอบชื่อก่อนเปลี่ยนโมเดล หน่วยความจำ สกิล ช่องทาง หรืองานตามกำหนดเวลา เว็บแชทและรายการบทสนทนาจะเป็นของบอทที่เลือก บอทเพิ่มเติมก็ใช้เว็บแชทได้ และเว็บแชทไม่ต้องเชื่อมต่อช่องทางรับส่งข้อความ

เมื่อต้องการสร้างบอทถัดไป ให้เลือก **บอทใหม่** หากมีปุ่มนี้และโควตาแพ็กเกจยังเพียงพอ กรอก **ชื่อ** (จำเป็น) และ **คำอธิบาย** (ไม่บังคับ) แล้วปรับรูปลักษณ์ตามต้องการ ค่าเริ่มต้นคือ **การตั้งค่าพื้นฐาน** หากมีบอทต้นทางที่คัดลอกได้ ให้เปิด **ขั้นสูง** แล้วเลือกบอทต้นทางที่ต้องการ หากต้องการคัดลอกบอทที่ใช้อยู่ ให้เปิด **จัดการบอท → คัดลอก Bot** แบบฟอร์มจะเลือกต้นทางนั้นไว้ให้ ตรวจสอบต้นทาง เลือก **สร้าง** แล้วรอจนเสร็จ

หลังจากเลือกบอท ข้อมูลพื้นฐานของมันจะแสดงดังด้านล่าง:

- อวตาร

- ชื่อ (คลิกที่ชื่อหรือไอคอนดินสอเพื่อแก้ไข จากนั้นกด Enter เพื่อบันทึก)

- สถานะ (● กำลังทำงาน / ● ไม่ทราบ)

- เวลาสร้าง

- ปุ่มลบ (ไอคอนถังขยะทางด้านขวา)

> ⚠️ **การลบไม่สามารถย้อนกลับได้**
>
> การลบบอทเพิ่มเติมจะเป็นการลบโปรไฟล์และข้อมูลของบอทนั้นอย่างถาวร การลบบอทหลักจะลบเอเยนต์ Hermes ทั้งหมดรวมถึงข้อมูลที่เกี่ยวข้องทั้งหมด และอนุญาตให้ทำได้ก็ต่อเมื่อบอทอื่น ๆ ถูกลบเรียบร้อยแล้วเท่านั้น

## กำหนดค่าช่องทาง แบบจำลอง และทักษะ

### ช่องทาง

เปิด **Channels** ในแถบด้านข้างของ Agent หน้าจอจะแสดงการ์ดแยกสำหรับ Telegram, WhatsApp, Discord, Slack, WeChat, QQ, WeCom, และ Lark เลือก **+ Connect** ในช่องที่คุณต้องการและทำตามคำแนะนำของมัน WhatsApp, WeChat, WeCom, และ Lark ใช้การอนุญาตด้วยรหัส QR; Telegram, Discord, และ Slack ใช้ข้อมูลรับรอง QQ เสนอการเชื่อมต่อด้วยรหัส QR หรือ App ID / Secret ดู [WhatsApp guide](./configuration/channel-whatsapp.md) สำหรับตัวอย่างรหัส QR

### แบบจำลอง

เปิด **โมเดล** เพื่อดูโมเดลที่ใช้งานอยู่หรือกำหนดค่าผู้ให้บริการ เครดิตโมเดลในแผนสามารถใช้ได้โดยไม่ต้องใส่คีย์ API ของคุณเอง; คุณสามารถเพิ่มผู้ให้บริการเมื่อจำเป็น บอตจะใช้โมเดลหลักเพียงหนึ่งตัวต่อครั้ง และโมเดลสำรองที่กำหนดค่าแยกต่างหากอาจมีให้ใช้ ดู [กำหนดค่าโมเดล](./configuration/model.md) และ [สลับโมเดล](./configuration/multiple-models.md)

### ทักษะ

เปิด **ทักษะ** เพื่อค้นหาทักษะเฉพาะบุคคลหรือเรียกดู **ชุดทักษะ** จาก [Skills.sh](https://skills.sh/) และ [ClawHub](https://clawhub.ai/) เลือก **ติดตั้ง** จากนั้นตรวจสอบผลลัพธ์ใน **ติดตั้งแล้ว** ดู [กำหนดค่าทักษะ](./configuration/skill.md)

## สถานะความสำเร็จหลังการกำหนดค่า

หลังจากการกำหนดค่าเสร็จสมบูรณ์ คอนโซลควรจะแสดงสถานะดังต่อไปนี้:

- รายการ "ช่องทางที่เชื่อมต่อ" มีอย่างน้อยหนึ่งระเบียน (เช่น "WeChat")

- "โมเดลปัจจุบัน" เป็นตัวเลือก; ไม่จำเป็นต้องตั้งค่าหากคุณใช้เครดิตทดลองใช้งาน Launch

- ทักษะที่ติดตั้งแล้วสามารถปรับแต่งตามความต้องการและอาจว่างเปล่าได้

เมื่อ "ช่องทางที่เชื่อมต่อ" มีอย่างน้อยหนึ่งระเบียน คุณสามารถหาบอทในแพลตฟอร์มส่งข้อความที่เกี่ยวข้องและเริ่มการสนทนาได้ Hermes เอเจนต์จะสร้างคำตอบโดยใช้แบบจำลองเริ่มต้นหรือใช้เครดิตทดลองใช้งาน

---

## การดำเนินการทั่วไป

- **สลับโมเดล:** เปิด **Models** สำหรับบอทที่เลือกและเลือกโมเดลที่ตั้งค่าไว้และพร้อมใช้งาน ความจำของบอทยังคงอยู่; ดู [การสลับโมเดล](./configuration/multiple-models.md)  
- **เชื่อมต่อหลายช่องทาง:** เปิด **Channels** และใช้ **+ Connect** ในแต่ละการ์ดที่ต้องการ ช่องทางที่เชื่อมต่อกับบอทเดียวกันจะแบ่งปันบุคลิกและความจำของบอทนั้น  
- **จัดการบอท:** เลือกแท็บบอทก่อนเปลี่ยนการตั้งค่า เมื่อสามารถสร้างได้ ให้ทำตาม [การจัดการบอท](./configuration/bots.md) สำหรับกฎการคัดลอกและการลบ  
- **เปิดที่เก็บข้อมูลบนคลาวด์:** ใช้ **Cloud Storage** ในเมนูผู้ใช้แทนการค้นหาในแถบด้านข้างของเอเจนต์
