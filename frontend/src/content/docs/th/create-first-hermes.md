# ฉันจะเปิดใช้งานอินสแตนซ์ Hermes ตัวแรกของฉันได้อย่างไร?

## สรุป

**หลังจากลงชื่อเข้าใช้ด้วย Google หรือ GitHub และเปิดใช้งานแพ็กเกจที่มีให้ใช้ ให้เปิด [คอนโซล Agent](/agents/overview/) ตั้งค่าบอทแรกโดยกรอกชื่อซึ่งจำเป็นต้องมี เพิ่มคำอธิบายได้ตามต้องการ และปรับรูปลักษณ์ เลือก สร้าง แล้วรอให้การสร้างและการตั้งค่าเริ่มต้นเสร็จสิ้น เมื่อตั้งค่าเสร็จ ให้เลือก เริ่มต้นการเดินทาง แล้วเปิดเว็บแชทของบอทนั้น ช่องทางรับส่งข้อความเป็นตัวเลือกเพิ่มเติม ส่วนการตอบกลับต้องมีเครดิตโมเดลที่ใช้ได้หรือโมเดลที่ตั้งค่าไว้**

---

ปุ่มปิดและตัวเลือกการคัดลอกขั้นสูงจะแสดงเมื่อมีบอทต้นทางที่ใช้ได้เท่านั้น การตั้งค่าครั้งแรกที่ไม่มีต้นทางต้องทำให้เสร็จ ตัวควบคุมรูปลักษณ์ใช้ปรับสี รูปร่าง และเครื่องประดับ ไม่ได้ใช้เลือกต้นทางสำหรับคัดลอก

## หน้าสารบัญของหน้านี้

- กระบวนการทั้งหมดสำหรับการเปิดใช้งานตัวอย่าง Hermes ตัวแรกของคุณ

- ข้อกำหนดเบื้องต้นและรายละเอียดสำคัญสำหรับแต่ละขั้นตอน

- วิธีการกำหนดค่าและใช้งานเอเจนต์ของคุณหลังจากการเปิดใช้งาน

## ข้อกำหนดเบื้องต้น

- บัญชี Google หรือ GitHub

- แผนที่มีอยู่ในปัจจุบันที่เลือกจาก [หน้าสมัครสมาชิก](/subscribe); เว็บไซต์ระหว่างประเทศไม่ต้องการการยืนยันตัวตนจริงในจีน

- บัญชี Telegram, WhatsApp, Discord, Slack, หรือ WeChat ก็ต่อเมื่อคุณวางแผนที่จะใช้แอปส่งข้อความนั้น

---

## ลำดับการเปิดใช้งาน

### 1. เข้าสู่ระบบด้วย Google หรือ GitHub

เปิด LightVela และอนุญาตการเข้าถึงด้วย Google หรือ GitHub บัญชี LightVela ของคุณจะถูกสร้างโดยอัตโนมัติครั้งแรกที่คุณลงชื่อเข้าใช้ ดังนั้นจึงไม่ต้องตั้งรหัสผ่านแยกต่างหาก ใช้ตัวตนในการลงชื่อเข้าใช้เดียวกันในการเข้าชมในอนาคตเพื่อเข้าถึงตัวอย่างและข้อมูล Hermes เดิม

### 2. เลือกแผนที่มีอยู่ในหน้าสมัครสมาชิก

เปิด [หน้าสมัครสมาชิก](/subscribe) เพื่อดูว่าแผนและโควต้าที่มีอยู่ในปัจจุบันมีอะไรบ้าง [แผน](./plans.md) อธิบายโครงสร้างทรัพยากร Launch และ Cruise แต่หน้าสมัครสมาชิกเป็นแหล่งข้อมูลที่เชื่อถือได้สำหรับสิ่งที่สามารถเปิดใช้งานได้ในตอนนี้

ไม่มีขั้นตอนการยืนยันชื่อจริงของจีนบนเว็บไซต์สากล หลังจากเข้าสู่ระบบด้วย Google หรือ GitHub คุณสามารถเลือกแผนใดก็ได้ที่มีให้บริการในปัจจุบัน

### 3. เปิดใช้งานแผนผ่านกระบวนการเปิดใช้งานระหว่างประเทศปัจจุบัน

เลือกแผนที่มีให้บริการบน [หน้าสมัครสมาชิก](/subscribe/) และทำตามบัตรแผนเพื่อตั้งค่าใช้งาน ตรวจสอบหน้าดังกล่าวสำหรับข้อเสนอแนะนำและราคาปัจจุบัน

### 4. ตั้งค่าบอทแรกให้เสร็จ

หลังจากลงชื่อเข้าใช้ด้วย Google หรือ GitHub และเปิดใช้งานแพ็กเกจที่มีให้ใช้ ให้เปิด [คอนโซล Agent](/agents/overview/) ตั้งค่าบอทแรกโดยกรอกชื่อซึ่งจำเป็นต้องมี เพิ่มคำอธิบายได้ตามต้องการ และปรับรูปลักษณ์ เลือก **สร้าง** แล้วรอให้การสร้างและการตั้งค่าเริ่มต้นเสร็จสิ้น เมื่อตั้งค่าเสร็จ ให้เลือก **เริ่มต้นการเดินทาง** แล้วเปิดเว็บแชทของบอทนั้น ช่องทางรับส่งข้อความเป็นตัวเลือกเพิ่มเติม ส่วนการตอบกลับต้องมีเครดิตโมเดลที่ใช้ได้หรือโมเดลที่ตั้งค่าไว้

### 5. กำหนดค่าและปลุกเอเจนต์ของคุณ

เมื่ออินสแตนซ์พร้อมแล้ว ให้เปิดคอนโซลและทำการตั้งค่าพื้นฐาน:

1. **ตรวจสอบโมเดล** — เครดิตแผนที่ใช้งานได้ช่วยให้คุณเริ่มต้นได้โดยไม่ต้องใช้คีย์ API ของคุณเอง; ดูที่ [การกำหนดค่าโมเดล](./configuration/model.md) หากจำเป็น

2. **ลองแชทเว็บ** — เริ่มสนทนาภายใต้รายวัน → แชท และส่งข้อความ; ดูที่ [แชท](./configuration/agent-chat.md)

3. **เชื่อมต่อช่องทางหากจำเป็น** — เพิ่ม Telegram, WhatsApp, Discord, หรือ WeChat เพื่อใช้บอทในแอปส่งข้อความ

4. **สามารถเพิ่มทักษะและงานที่กำหนดเวลาได้ตามต้องการ** — ดูที่ [การกำหนดงานที่กำหนดเวลา](./configuration/automation.md)

เอเจนต์ Hermes ตัวแรกของคุณพร้อมที่จะออนไลน์อยู่บนคลาวด์ตลอด 24 ชั่วโมงทุกวันแล้ว

## คำถามที่พบบ่อย

### ฉันสามารถใช้อินสแตนซ์ได้เร็วแค่ไหนหลังจากเปิดใช้งาน?

หลังสร้างเสร็จ ให้ตรวจสอบชื่อบอทใหม่ในตัวเลือก เปิดเว็บแชทของบอทนั้น และส่งข้อความทดสอบสั้น ๆ หากการสร้างหรือการตั้งค่าเริ่มต้นล้มเหลว ให้ทำตามปุ่มลองอีกครั้งที่แสดงและตรวจสอบรายการบอทก่อนสร้างใหม่ หากไม่มีคำตอบ ให้ตรวจสอบสถานะบอทและเครดิตหรือการตั้งค่าโมเดล

### ฉันสามารถตรวจสอบแผนและข้อเสนอต่าง ๆ ปัจจุบันได้ที่ไหน?

ตรวจสอบ [หน้าสมัครสมาชิก](/subscribe/) และ [แผนบริการ](./plans.md) สำหรับเงื่อนไขแผนปัจจุบัน ข้อเสนอสำหรับสมาชิกใหม่ และกฎการต่ออายุ

### บัญชีหนึ่งสามารถเปิดใช้งานตัวอย่าง Hermes กี่ครั้ง?

จำนวนขึ้นอยู่กับจำนวนเอเจนต์ที่อนุญาตของแผนที่เลือก Launch และ Cruise แต่ละแผนรวมเอเจนต์หนึ่งคน ดู [แผน](./plans.md)

### ฉันจำเป็นต้องดูแลเซิร์ฟเวอร์หลังจากเปิดใช้งานหรือไม่?

ไม่ใช่ ตัวอย่าง Hermes ของคุณทำงานในสภาพแวดล้อมคลาวด์ที่จัดการโดย LightVela LightVela ดูแลการดำเนินงานและความพร้อมใช้งานตลอด 24 ชั่วโมง 7 วัน; คุณเพียงแค่กำหนดค่าเอเจนต์ผ่านคอนโซลเว็บ
