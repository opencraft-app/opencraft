# แนวคิดหลัก

## สรุป

**LightVela มีแนวคิดหลักห้าเรื่อง: Hermes Agent คืออินสแตนซ์คลาวด์; Bots เป็นโปรไฟล์แยกภายในนั้น; แต่ละ Bot มีการตั้งค่าโมเดล ช่องทางการสื่อสารที่เชื่อมต่อ และทักษะที่ติดตั้งได้ Bots สามารถเก็บบุคลิกภาพ ความจำ และงานที่กำหนดเวลาแยกกันได้ ช่องทางที่เชื่อมต่อกับ Bot เดียวกันจะแชร์พฤติกรรมของมัน ในขณะที่ Bot ที่ต่างกันจะไม่แชร์การตั้งค่าโดยอัตโนมัติ ข้อความมาถึงผ่านช่องทางหนึ่ง Bot ที่ถูกเลือกอาจใช้ทักษะและโมเดล และการตอบกลับจะถูกส่งกลับผ่านช่องทางนั้น**

---

LightVela มีแนวคิดที่เกี่ยวข้องห้าประการ: Hermes เอเจนต์, บอท, โมเดล, ช่องทาง และทักษะ หน้านี้อธิบายว่าพวกมันเข้ากันได้อย่างไร

## หน้านี้ครอบคลุม

- ความสัมพันธ์ระหว่างแนวคิดทั้งห้า

- ลักษณะเฉพาะของอินสแตนซ์ของเอเจนต์ Hermes

- จุดการวางตำแหน่งและการกำหนดค่าของโมเดล ช่องทาง และทักษะ

- การไหลภายในของการสนทนาอย่างสมบูรณ์

---

## ความสัมพันธ์ของแนวคิด

```text
Hermes Agent (cloud instance)
  └─ Bot profiles (main Bot and optional additional Bots)
       ├─ Primary model and optional fallbacks
       ├─ Connected channels
       └─ Skills, Soul, memory, scheduled tasks
```

| แนวคิด | บทบาท | คำอธิบาย |
|---|---|---|
| Hermes เอเจนต์ | อินสแตนซ์คลาวด์ | สภาพแวดล้อมที่รองรับโปรไฟล์ของบอท |
| บอท | โปรไฟล์อิสระ | มีโมเดล, ช่องทาง, ทักษะ, บุคลิก, ความจำ และงานตามกำหนดเวลาของตนเอง |
| โมเดล | ความสามารถทางภาษา | โมเดลภาษาที่บอทใช้ |
| ช่องทาง | จุดเริ่มต้นการโต้ตอบ | แพลตฟอร์มที่ผู้ใช้สามารถแชทกับบอทได้ |
| ทักษะ | การขยายความสามารถ | แพ็กเกจความสามารถเพิ่มเติมที่บอทสามารถเรียกใช้ได้ |


---

## Hermes เอเจนต์

Hermes Agent คืออินสแตนซ์ AI Agent ใน LightVela การสร้าง Hermes Agent มีค่าเท่ากับการเริ่มอินสแตนซ์ Agent อิสระในคลาวด์

Hermes เอเจนต์มีลักษณะดังต่อไปนี้:

- **สภาพแวดล้อมคลาวด์เฉพาะ**: เอเจนต์ Hermes แต่ละตัวทำงานในสภาพแวดล้อมของตัวเอง โดยมีทรัพยากรแยกจากอินสแตนซ์อื่น

- **หน่วยความจำถาวร**: เนื้อหาการสนทนาจะถูกบันทึกข้ามหลายเซสชัน และผู้ช่วยจะใช้บริบทจากประวัติศาสตร์ในการตอบ

- **ออนไลน์ตลอดเวลา**: ทำงานตลอด 24 ชั่วโมงทุกวัน และไม่ขึ้นอยู่กับอุปกรณ์ท้องถิ่นของผู้ใช้

แผนการเปิดตัวปัจจุบันรองรับการสร้าง Agent instance ได้สูงสุด 1 Hermes

---

## บอท

เอเจนต์ Hermes แต่ละตัวมีบ็อตหลักและอาจรองรับบ็อตเพิ่มเติมได้ ขึ้นอยู่กับสิทธิ์แผนและความพร้อมใช้งาน บ็อตเหล่านี้อยู่ภายในอินสแตนซ์คลาวด์เดียวกัน แต่เก็บการตั้งค่าและข้อมูลแยกกัน เลือกบ็อตที่ต้องการก่อนเปลี่ยนโมเดล ช่องทาง ทักษะ หรือหน่วยความจำ ดูที่ [จัดการบ็อต](./configuration/bots.md)

---

## แบบจำลอง

โมเดลคือโมเดลภาษาขนาดใหญ่ (LLM) ที่ขับเคลื่อนกระบวนการคิดและการตอบสนองของ Hermes Agent LightVela ไม่ได้ฝึกสอนโมเดลด้วยตัวเอง แทนที่จะเป็นเช่นนั้น ผู้ใช้จะเลือกวิธีการเรียกในบัตร "โมเดล" ของคอนโซล:

| วิธีการ | โหมดการเรียกเก็บเงิน | API แหล่งที่มาของคีย์ | กรณีการใช้งาน |
|---|---|---|---|
| แผนการเขียนโค้ดโมเดล | รายเดือน | ผู้ให้บริการ | การใช้งานความถี่สูง |
| โมเดล API | จ่ายตามการใช้งาน | ผู้ให้บริการ | การใช้งานความถี่ต่ำหรือทดลองใช้งาน |
| โมเดลที่กำหนดเอง | ขึ้นอยู่กับจุดสิ้นสุด | ผู้ใช้ให้มา | เชื่อมต่อโมเดลต่างประเทศหรือจุดสิ้นสุดที่เข้ากันได้กับ OpenAI |

นอกจากนี้ แผนการเปิดตัวยังรวมถึงเครดิตทดลอง 100 เครดิต ทำให้คุณสามารถแชทได้ทันทีโดยไม่ต้องตั้งค่าใด ๆ; หลังจากเครดิตทดลองหมด คุณสามารถตั้งค่า API คีย์ของคุณเองได้

สำหรับโมเดลที่รองรับ การได้มาซึ่งคีย์ API และคำแนะนำในการเลือกโมเดล โปรดดูที่ [กำหนดค่าโมเดล](./configuration/model.md)

> บอทใช้โมเดลหลักเพียงตัวเดียวในแต่ละครั้ง โมเดลที่กำหนดค่าเพิ่มเติมหรือตัวสำรองสามารถใช้งานได้ การสลับโมเดลที่ใช้งานอยู่ไม่จำเป็นต้องลบการกำหนดค่าก่อนหน้า ดู [การสลับโมเดล](./configuration/multiple-models.md)

## ช่องทาง

ช่องทางคือจุดเข้าของแพลตฟอร์มการส่งข้อความที่ผู้ใช้สามารถสนทนากับ Hermes Agent LightVela ปัจจุบันรองรับช่องทางดังต่อไปนี้:

| ช่องทาง | วิธีการเข้าถึง | กรณีการใช้งาน |
|---|---|---|
| WeChat | การอนุญาตด้วย QR-code | การใช้งานส่วนตัวประจำวัน เหมาะสำหรับผู้ใช้ในประเทศจีน |
| Telegram | การเข้าถึงด้วย Bot Token | การส่งข้อความส่วนตัวหรือทีม การตั้งค่าง่าย เหมาะสำหรับระบบอัตโนมัติแบบเบา |
| WhatsApp | การสแกน QR-code | การสื่อสารกับผู้ใช้นานาชาติ บริการลูกค้า การแจ้งเตือน และการเตือนความจำ |
| Discord | การเข้าถึงด้วย Bot Token | การจัดการชุมชน ชุมชนนักพัฒนา กลุ่มเกมหรือกลุ่มตามความสนใจ |
| Slack | การเข้าถึงด้วย Bot Token / App Token | การทำงานร่วมกันเป็นทีม การแจ้งเตือนในพื้นที่ทำงาน และเวิร์กโฟลว์ตามช่องทาง |

บนการ์ด **WeChat** ใน **Channels** ให้เลือก **+ Connect** และสแกนรหัส QR ด้วยโทรศัพท์ของคุณ

ขั้นตอนการเข้าถึงโดยละเอียดสำหรับแต่ละช่องทาง: [กำหนดค่าช่องทาง - WeChat](./configuration/channel-wechat.md) / [Telegram](./configuration/channel-telegram.md) / [WhatsApp](./configuration/channel-whatsapp.md) / [Discord](./configuration/channel-discord.md) / [Slack](./configuration/channel-slack.md).

> 💡 **หลายช่องทางสามารถอยู่ร่วมกันได้**
>
> ช่องทางที่เชื่อมต่อกับบอทตัวเดียวกันจะใช้ตัวตนและความจำของบอทนั้น ช่องทางที่เชื่อมต่อกับบอทต่างตัวกันจะไม่แชร์การตั้งค่าเหล่านั้นโดยอัตโนมัติ

## ทักษะ

ทักษะคือชุดความสามารถเพิ่มเติมที่สามารถเรียกใช้งานโดย Hermes Agent พวกมันขยายขอบเขตของ Hermes Agent เหนือกว่าการสนทนาพื้นฐานสำหรับงานเฉพาะ เช่น การจัดการสิ่งที่ต้องทำ การสร้างรายงานประจำวัน การท่องเว็บ การสร้างภาพ และอื่น ๆ

ทักษะสามารถหาได้จาก [Skills.sh](https://skills.sh/) และ [ClawHub](https://clawhub.ai/) เรียกดูแหล่งข้อมูลเหล่านี้ในหน้าคอนโซล **Skills** และตรวจสอบผลลัพธ์ก่อนติดตั้ง

เปิด **ทักษะ** ในคอนโซล ค้นหาทักษะแต่ละอันหรือเรียกดู **ชุดทักษะ** จากนั้นเลือก **ติดตั้ง** ตรวจสอบแท็บ **ที่ติดตั้งแล้ว** เพื่อตรวจสอบผลลัพธ์ ดูที่ [การกำหนดค่าทักษะ](./configuration/skill.md)

> ⚠️ **การตรวจสอบความปลอดภัยก่อนการติดตั้ง**
>
> สกิลมีสิทธิ์ในการเรียกHermes ความสามารถของเอเจนต์ในขณะรันไทม์ ก่อนติดตั้งสกิล ควรยืนยันว่าผู้เขียนน่าเชื่อถือ และควรเลือกสกิลที่มีการดาวน์โหลดสูงและมีคะแนนรีวิวดี

---

## ลำดับการโต้ตอบ

โฟลว์การสนทนาที่สมบูรณ์ทำงานดังนี้:

1. ผู้ใช้ส่งข้อความไปยังเอเจนต์ Hermes ผ่านช่องทาง (เช่น WeChat)

2. Hermes ผู้แทนกำหนดว่าจำเป็นต้องเรียกใช้ทักษะหรือไม่ตามข้อความ

3. โมเดลประมวลผลบริบทและสร้างคำตอบ

4. การตอบสนองจะส่งกลับไปยังผู้ใช้ผ่านช่องทางเดิม
