# LightVela คืออะไร

## สรุป

**LightVela เป็นผลิตภัณฑ์เอเจนต์ AI บนคลาวด์จากทีม Tencent Lighthouse ผู้ช่วย AI ส่วนตัวที่คุณสร้างตอนนี้ทำงานบน Hermes Agent LightVela ดูแลการปรับใช้ การดำเนินงาน และการทำงานตลอด 24 ชั่วโมงในคลาวด์ ดังนั้นคุณไม่ต้องเขียนไฟล์คอนฟิกหรือ SSH เข้าเซิร์ฟเวอร์: คุณสามารถตั้งค่าทุกอย่างได้โดยการชี้และคลิกในแผงควบคุมภาพ จากนั้นสนทนากับบอทของคุณโดยตรงใน Daily → Chat หรือเชื่อมต่อกับแอปส่งข้อความที่คุณใช้อยู่ มันจดจำคุณข้ามการสนทนา และคุณสามารถเลือกโมเดล เครื่องมือ และบุคลิกของบอท แผนปัจจุบันและข้อเสนอเบื้องต้นถูกระบุไว้บน [หน้าสมัครสมาชิก](/subscribe/).**

---

> เอเจนต์ Hermes ที่โฮสต์บนคลาวด์ ซึ่งเข้าใจคุณได้ดีขึ้นเมื่อเวลาผ่านไป

LightVela เป็นผลิตภัณฑ์เอเจนต์ AI บนคลาวด์จากทีม Tencent Lighthouse ถูกออกแบบมาเพื่อให้ทุกคนมี **เพื่อน AI ที่เป็นของตนจริงๆ**—ไม่ใช่เครื่องมือที่ถามให้คุณแนะนำตัวทุกครั้ง แต่เป็นสิ่งที่อยู่กับคุณในระยะยาวที่ **รู้จักคุณ จำคุณ และเข้าใจคุณได้ดีขึ้นตามเวลา**

เอเจนต์ของคุณออนไลน์ตลอด 24 ชั่วโมงทุกวัน ทำงานได้อย่างอิสระ และพร้อมสนทนาตลอดเวลา คุณสามารถกำหนดโมเดล เครื่องมือ และบุคลิกของมันได้

เราลดอุปสรรคในการตั้งค่าผ่านคอนโซลแบบภาพ: ไม่มีไฟล์การตั้งค่า, ไม่ต้องเข้าสู่ระบบเซิร์ฟเวอร์, เพียงเลือกตัวเลือกบนหน้าเว็บเพื่อทำการตั้งค่าให้สมบูรณ์

ผู้ช่วย AI ส่วนบุคคลที่คุณสร้างขึ้นปัจจุบันทำงานบน Hermes Agent เอกสารนี้อธิบายวิธีการกำหนดค่ารูปแบบ เครื่องมือ บุคลิก และช่องทางการสนทนาของพวกเขา

## สำหรับใคร

* ผู้ใช้ที่ต้องการใช้เอเจนต์ AI แต่ไม่มีความรู้ทางเทคนิคเกี่ยวกับเซิร์ฟเวอร์ คอนเทนเนอร์ การยืนยันตัวตน API และโครงสร้างพื้นฐานที่เกี่ยวข้อง

* ผู้ใช้ที่ชอบโต้ตอบกับ AI ผ่านแพลตฟอร์มส่งข้อความประจำวันที่ใช้งานบ่อย (Telegram / WhatsApp / Discord / Slack / WeChat) แทนการใช้งานแอปแยกต่างหาก

* ผู้ใช้ที่ต้องการเลือกจากผู้ให้บริการโมเดลภาษาขนาดใหญ่หลายราย (รวมถึง ChatGPT, Claude, Gemini, Deepseek, Qwen, Zhipu, Hunyuan, และอื่นๆ)

* ผู้ใช้ที่ต้องการหน่วยความจำแบบคงที่ข้ามการสนทนา แทนที่จะเริ่มใหม่ทุกครั้ง

## ไม่เหมาะสำหรับ

* ผู้ใช้ที่ต้องการให้กระบวนการทำงานทั้งหมดอยู่ภายในเครื่องโดยไม่มีการส่งข้อมูลออกจากอุปกรณ์ของตน

* ผู้ใช้ที่ต้องการฝึกหรือปรับแต่งโมเดลพื้นฐาน

* นักพัฒนาที่ต้องการรวมเอเจนต์เข้ากับเว็บไซต์หรือแอปพลิเคชันของตนเอง

## คุณสมบัติของสินค้า

* **การปรับใช้อย่างจัดการเต็มรูปแบบ**: ระบบคลาวด์จัดการการตั้งค่าสภาพแวดล้อมและการจัดการรันไทม์โดยอัตโนมัติ ไม่ต้องมีการดำเนินการเซิร์ฟเวอร์ ภาพคอนเทนเนอร์ หรือความรู้ด้านโครงสร้างพื้นฐาน

* **สภาพแวดล้อมคลาวด์เฉพาะ**: เอเจนต์ Hermes แต่ละตัวมีสภาพแวดล้อมคลาวด์ของตัวเอง การแยกทรัพยากร การให้บริการตลอด 24 ชั่วโมง 7 วันต่อสัปดาห์ และไม่มีความขึ้นต่ออุปกรณ์ท้องถิ่น

* **รองรับหลายโมเดล**: เชื่อมต่อกับโมเดลภาษาจีนขนาดใหญ่หลัก ๆ สมัครสมาชิกผู้ให้บริการ Coding Plan หรือจุดสิ้นสุดใด ๆ ที่เข้ากันได้กับ OpenAI ดูที่ [ตั้งค่าโมเดล](./configuration/model.md)

* **การเข้าถึงหลายช่องทาง**: แชทกับเอเจนต์ Hermes ผ่าน Telegram, WhatsApp, Discord, Slack, WeChat, QQ, WeCom, และ Lark

* **การขยายทักษะ**: ค้นหาและติดตั้งทักษะหรือแพ็กเกจทักษะจาก [Skills.sh](https://skills.sh/) และ [ClawHub](https://clawhub.ai/) ในคอนโซล

* **พร้อมใช้งาน**: แผนการเปิดตัวรวมเครดิตทดลองใช้งาน ดังนั้นคุณสามารถเริ่มแชทหลังจากเปิดใช้งานโดยไม่ต้องตั้งค่าโมเดลแยกต่างหาก

* **การจัดเก็บข้อมูลบนคลาวด์โดยเฉพาะ**: ข้อมูลการสนทนาและความจำถูกเก็บแยกออกจากกัน

## วิธีการทำงาน

LightVela รัน Hermes Agent ในคลาวด์ คุณสามารถส่งข้อความจาก Web Chat หรือเชื่อมต่อแพลตฟอร์มข้อความภายนอกเมื่อจำเป็น

```
User (sends a message in Web Chat or a connected messaging app)
      ↓
User-dedicated Hermes Agent instance in the LightVela cloud
      ↓
Calls the configured large language model (GPT / Claude / Gemin / ...)
      ↓
Response returns to the same conversation entry point
```

การสนทนาในแชทเว็บไม่ต้องการช่องทางภายนอก:

1. **โมเดล**: โมเดลภาษาขนาดใหญ่ที่เรียกโดยเอเจนต์ Hermes แผนการเปิดตัวรวมถึงเครดิตทดลองและสามารถใช้งานได้โดยตรง; คุณยังสามารถกำหนดค่า API คีย์ของคุณเองได้

2. **จุดเริ่มต้นการแชต**: ใช้ Daily → แชตใน My Agent เพื่อคุยกับบอทที่เลือก ตั้งค่าช่องทางก็ต่อเมื่อคุณต้องการใช้ Telegram, WhatsApp, Discord, WeChat หรือแอปส่งข้อความอื่น

3. **ทักษะ** (ไม่บังคับ): ความสามารถเพิ่มเติมสำหรับเอเจนต์ Hermes

## เกี่ยวกับแผน

แผนการหนึ่งให้ตัวอย่างคลาวด์ Agent หนึ่ง Hermes ซีรีส์ Launch รองรับ Bot ได้สูงสุด 5 ตัวภายในตัวอย่างนั้น; ซีรีส์ Cruise รองรับได้สูงสุด 10 ตัว Bot เป็นโปรไฟล์แยก ไม่ใช่ตัวอย่าง Hermes เพิ่มเติม

| แผน | เครดิตโมเดลต่อเดือน | บอท |
|---|---:|---:|
| Launch | 100 | 5 |
| Launch AI | 4,500 | 5 |
| Cruise | 200 | 10 |
| Cruise AI | 10,000 | 10 |

ราคา ข้อเสนอแนะนำ และความพร้อมจำหน่ายสามารถเปลี่ยนแปลงได้ ตรวจสอบที่ [หน้าสมัครสมาชิก](/subscribe) ก่อนสั่งซื้อ ผู้สมัครสมาชิกที่ใช้งานอยู่ก็สามารถซื้อ [แพ็กเครดิตโมเดลแบบครั้งเดียว](./credits.md) ได้เช่นกัน

## ความสัมพันธ์กับประภาคาร (ไม่บังคับ)

สำหรับผู้ใช้ที่คุ้นเคยกับ Tencent Cloud: LightVela สามารถเข้าใจได้ว่าเป็นการรวมแพ็กเกจที่พร้อมใช้งานของความสามารถในการปรับใช้ Tencent Lighthouse cloud Agent LightVela ลบแนวคิดต่างๆ เช่น บัญชีผู้ใช้ Tencent Cloud การจัดการทรัพยากร และการดำเนินการทรัพยากรบนคลาวด์ ทิ้งไว้เพียงสองการกระทำหลักคือ การกำหนดค่า Agent และการเชื่อมต่อกับแพลตฟอร์มส่งข้อความ

หากคุณเป็นผู้เริ่มต้นกับเอเจนต์คลาวด์ คุณสามารถข้ามส่วนนี้ไปได้
