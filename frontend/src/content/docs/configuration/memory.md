# 记忆管理

记忆（Memory）让 Hermes 记住跨对话、跨设备的关键信息——你的偏好、身份、正在推进的事，以及它自己在长期协作中沉淀下来的经验。它是 Hermes 从"一次性问答"变成"越用越懂你的长期助理"的基础。

[RECOMMEND ADD IMAGE: LightVela 管理台「记忆」页的整体截图，展示「记忆」「用户画像」两个标签页与记忆统计条 — 让读者一眼看到记忆在管理台的入口与呈现方式。]

LightVela 采用云端托管：这些记忆保存在你的 Hermes 所在的云端实例上，不会因为你换了手机、切换了通道（微信 / 飞书 / QQ）而丢失。今天在微信里告诉它的事，明天在飞书里对话时它依然记得。

>
> 你不必刻意去"填写"记忆。在正常对话中，Hermes 会自行判断哪些信息值得长期保留并写入记忆。管理台的记忆页主要用于**查看**它记住了什么，以及在需要时**调整容量**。

## 为什么需要记忆

没有记忆的 AI 助手，每次对话都是一张白纸——你得反复交代自己是谁、喜欢什么、上次聊到哪。记忆解决的正是这个问题：

- **少重复交代**：说过一次"我在深圳、习惯早上收简报"，之后就不用再说。

- **跨通道一致**：微信、飞书、QQ 共享同一份记忆，换个入口它还是同一个懂你的助理。

- **越用越顺手**：随着协作深入，Hermes 会记住你的工作习惯、常用称呼、正在跟进的项目，回答越来越贴合你。

可以把记忆理解为 Hermes 的"长期笔记本"：它不保存每一句闲聊，只沉淀那些对以后有用的关键信息。

## 两类记忆

在管理台的「记忆」页，记忆分为两个标签页，分别对应两种不同用途：

### 记忆

这是 Hermes 在长期协作中自行沉淀的**经验与事实**——你交代过的偏好、约定的做事方式、反复出现的需求等。它由 Hermes 在对话中自动维护，条目会随着使用不断更新。

### 用户画像

这是关于**"你是谁"**的一份稳定档案——例如你的身份、所在城市、职业背景、长期偏好这类不太变动的信息。相比"记忆"，用户画像更像一张长期有效的名片，帮助 Hermes 在任何对话里都能快速对齐你的基本情况。

> ℹ️ **两者的区别**
>
> 简单说：**用户画像**回答"你是一个怎样的人"，**记忆**回答"我们之间发生过什么、约定过什么"。两者配合，Hermes 才能既了解你，又记得住你们的协作历史。

## 查看记忆与占用情况

1. 登录 LightVela，点击右上角「我的 Hermes」进入管理台。

2. 在设置导航中找到「记忆」进入记忆页。

3. 页面顶部会显示**记忆统计**：当前已占用的字符数、容量上限，以及占用百分比。

4. 切换「记忆」与「用户画像」两个标签页，即可分别查看各自的内容。

如果某一类记忆当前是空的，页面会提示"暂无 Agent 记忆"或"暂无用户画像"——这通常意味着你与 Hermes 的协作还比较浅，随着使用它会逐渐积累。

> 💡 **占用百分比的意义**
>
> 记忆容量是有上限的。当占用接近上限时，Hermes 会倾向于保留更重要的信息、淘汰过时的条目。留意这个百分比，可以帮助你判断是否需要调高容量，或清理掉不再需要的内容。

## 调整记忆容量上限

如果你希望 Hermes 记住更多内容，可以在记忆页调高容量上限；反之也可以调低。

- **记忆**容量可在 500 到 4000 字符之间调整。

- **用户画像**容量可在 500 到 3000 字符之间调整。

调整并保存后，即可生效。

> ⚠️ **保存上限会短暂重启，可能中断当前会话**
>
> 保存新的容量上限时，Hermes 网关会进行一次短暂的重启以应用新配置。此过程中正在进行的对话可能会短暂中断，稍候片刻即可恢复。建议在不影响使用的时段调整。

## 通过对话增删记忆

除了在管理台查看，你还可以直接在对话里让 Hermes 记住或忘掉某些信息。这也是日常使用中最自然的方式。

**让它记住：**

```
记一下，我以后发简报统一用早上 8 点
```

```
记住我更喜欢简洁、直接的回答，不要太长
```

**让它忘掉：**

```
之前让你记的那个每天发简报的事，不用了，忘掉吧
```

Hermes 会理解你的意图，更新对应的记忆条目并告知结果。

> ℹ️ **当前以对话方式维护记忆内容**
>
> LightVela 采用云端托管模式，不提供面向用户的文件系统操作。记忆内容的增加与删除主要通过与 Hermes 对话完成；管理台侧则用于查看内容和调整容量上限。

## 常见问题

### 我没主动让它记，它却记住了

这是正常现象。Hermes 会在对话中自动判断哪些信息值得长期保留（如你的偏好、身份、约定）。如果你不希望它记住某条信息，直接在对话里让它忘掉即可。

### 换了手机 / 换了通道，记忆还在吗

在。记忆保存在云端实例上，与设备和通道无关。微信、飞书、QQ 共享同一份记忆。

### 记忆占用满了会怎样

当占用接近上限时，Hermes 会优先保留更重要的信息，逐步淘汰过时或次要的条目。如果你确实需要它记住更多，可在记忆页调高容量上限。

### 记忆页显示"暂无记忆"

说明当前这一类记忆还没有积累到内容。多与 Hermes 协作一段时间，或直接让它记住一些关键信息，内容就会出现。

### 调整容量上限后对话卡住了

保存上限会触发一次短暂重启，正在进行的会话可能瞬时中断。稍等片刻再发消息即可恢复。
