# 成就

## 摘要

**成就页用于查看当前 Bot 的 Hermes Agent 使用进度：页面会统计已解锁、已发现、隐藏成就和最高等级，并按成就状态、分类、进度、计数规则与来源会话展示每张卡片。** 你可以在「成就」中重新扫描当前 Bot 的 Hermes 历史，确认工具使用、调试恢复、模型配置、记忆、技能、文档和自动化等行为是否已经被识别。

![成就页展示统计卡片、状态筛选、分类筛选和成就卡片列表](../images/achievements-overview.webp)

---

成就不是一套需要手动配置的功能，而是 LightVela 根据当前 Bot 的 Hermes Agent 历史行为生成的探索记录。它适合用来确认自己是否已经充分使用了某些 Agent 能力，也适合在排查时判断历史数据是否已经被成就模块读取。

如果你刚刚开通 LightVela，可以先完成 [网页对话](./agent-chat.md)、[配置技能](./skill.md)、[记忆管理](./memory.md) 或 [定时任务](./automation.md) 等基础操作，再回到成就页查看进度变化。

## 开始前

1. 已登录 LightVela，并已开通至少一个 Hermes Agent。
2. 当前 Bot 可以正常进入管理台。
3. 如果要看到更丰富的成就进度，当前 Bot 需要已经发生过一些真实会话、工具调用、配置修改或自动化任务。

成就按 Bot 读取。切换到另一个 Bot 后，看到的是另一个 Bot 的成就快照与历史行为。

## 进入成就页

1. 登录 LightVela。
2. 进入「我的 Hermes」管理台。
3. 在左侧设置导航中选择「成就」。
4. 等待页面读取当前 Bot 的 Hermes 历史。

读取完成后，页面顶部会显示统计卡片，下方显示状态筛选、分类筛选和成就卡片列表。

## 查看统计卡片

成就页顶部包含四类统计：

| 统计项 | 含义 |
| --- | --- |
| 已解锁 | 已完成条件的成就数量，以及当前可见成就总数。 |
| 已发现 | 已经出现进度但尚未解锁的成就数量。 |
| 隐藏成就 | 条件暂未公开，等待相关行为出现后再揭示的成就数量。 |
| 最高等级 | 当前 Bot 已达到的最高等级。等级顺序为铜、银、金、钻石、大师。 |

如果页面提示「正在读取 Hermes Agent 历史」，表示成就模块仍在扫描会话记录；等待扫描完成后再判断统计是否准确。

## 筛选成就

在统计卡片下方，可以使用两个筛选器：

1. **状态筛选**：选择全部、已解锁、已发现或隐藏。
2. **分类筛选**：按 Agent 自主性、调试与恢复、开发工作流、Hermes Agent 原生能力、研究与网页、工具使用、模型与配置、使用习惯等分类查看。

如果筛选后显示「暂无匹配的成就」，先切回「全部」状态和「全部分类」。若仍没有内容，可以重新扫描当前 Bot 的历史数据。

## 阅读成就卡片

每张成就卡片包含以下信息：

| 字段 | 说明 |
| --- | --- |
| 名称与描述 | 说明该成就对应的 Hermes Agent 行为。隐藏成就会先显示为「隐藏成就」。 |
| 状态 | 已解锁、已发现或隐藏。 |
| 等级 | 已解锁的等级型成就会显示铜、银、金、钻石或大师。 |
| 进度 | 显示当前进度、下一门槛或百分比。隐藏成就会显示条件隐藏。 |
| 计数规则 | 展开后可查看该成就的统计口径，例如工具调用、日志查看、模型配置或文档活动次数。 |
| 来源会话 | 部分成就会显示触发进度的会话标题，便于回溯行为来源。 |

计数规则来自 Hermes Agent 历史数据。若某张卡片显示「当前成就暂未返回计数规则」，说明该成就当前没有返回可展示的规则文本，并不一定代表成就不可解锁。

## 重新扫描

当你刚完成一批会话、工具调用或配置操作，但成就页尚未变化时，可以重新扫描：

1. 打开「成就」页。
2. 点击页面右上角的重新扫描按钮。
3. 等待按钮停止旋转，或等待「正在读取 Hermes Agent 历史」提示消失。
4. 检查统计卡片和对应成就卡片是否更新。

重新扫描会读取当前 Bot 的 Hermes 历史。历史较多时可能需要更长时间。

## 确认已生效

完成一次真实操作后，可以用以下方式确认成就模块是否识别到进度：

1. 在当前 Bot 中完成一次可被统计的行为，例如查看日志、使用工具、调整模型配置、运行定时任务或维护文档。
2. 返回「成就」页并点击重新扫描。
3. 在状态筛选中选择「已发现」或「已解锁」。
4. 打开相关卡片的「计数规则」，确认进度、百分比或来源会话是否变化。

如果成就仍没有变化，先确认操作发生在当前 Bot，而不是另一个 Bot。

## 常见问题

### 为什么刚使用完功能，成就没有立即变化？

成就页读取的是当前 Bot 的 Hermes 历史快照。刚完成操作后，可能需要重新扫描；历史较多时扫描也可能需要等待。

### 为什么有隐藏成就？

隐藏成就的具体条件会在 Hermes Agent 发现相关行为后展示。继续在调试、工具、记忆、技能、插件、模型配置和自动化工作流中使用 Hermes Agent，相关成就会逐步揭示。

### 为什么页面提示成就数据读取失败？

常见原因包括 Hermes Agent 暂时不可用、成就数据解析失败，或成就命令执行失败。可以先刷新页面或重试；如果仍失败，进入 [诊断中心](./diagnostics.md) 查看服务状态和日志。

### 切换 Bot 后成就为什么变了？

成就按当前 Bot 的历史读取。不同 Bot 的会话、工具调用、记忆、技能和模型配置历史不同，因此成就进度也可能不同。

### 成就会影响套餐、积分或权限吗？

成就用于展示使用进度，不改变套餐、AI 积分、Bot 数量或权限。套餐和积分仍以 [套餐管理](../plans.md) 与 [AI 积分说明](../credits.md) 为准。
