# 管理与切换 Bot

## 摘要

**一个 LightVela 云端 Agent 可以承载多个用途不同的 Bot。你可以在 Bot 资料菜单中切换当前 Bot；当账户的多 Bot 功能已开放且套餐额度允许时，还能从当前 Bot 旁的“+”入口创建额外 Bot。网页「对话」标签当前只支持主 Bot，其他 Bot 需通过已连接的聊天通道测试。**

**每个 Bot 都有自己的工作区上下文。创建空白 Bot 或复制已有 Bot 时，LightVela 对模型设置、记忆、技能、人设、定时任务和通道连接采用不同的继承规则。**

## 开始前

- 登录 LightVela，并打开一个正在运行的云端 Agent。
- 如果要创建额外的 Bot，请确认当前界面显示“新建 Bot”入口，套餐内仍有 Bot 名额，并且没有其他 Bot 正在创建或删除。入口是否显示还受账户的多 Bot 功能开关控制。
- 如果计划接入通道，请准备该通道所需的凭证或授权方式。

## 创建 Bot

如果当前 Agent 还没有 Bot，先按[首次开通指南](../create-first-hermes.md)完成首个 Bot 的创建。已有 Bot 且额外创建入口可用时，在「我的 Hermes」侧栏当前 Bot 的操作区选择“+”（**新建 Bot**），然后按引导选择头像、填写名称和描述。

创建时可以选择空白 Bot，或在界面提供相应选项时复制已有 Bot。确认前先查看引导中展示的继承范围；创建成功后再切换到新 Bot。

已有其他 Bot 时，创建对话框可能会提供 **复制当前 Bot**、**复制主 Bot** 或 **空白创建** 选项。

例如，要创建一个金融分析师 Bot，可以填写：

> <strong>名称：</strong> Alpha Analyst
>
> <strong>描述：</strong> Alpha Analyst 专注于分析公司报告、市场新闻、投资组合表现、估值和金融风险。它提供简洁且有证据支持的分析，明确区分事实与假设，不会将分析表述为保证性的金融建议。

创建页面还可能提供针对特定角色的模板，例如健康管家、盘面观察员或 AI 学习搭子。

填写信息后确认创建，并等待新 Bot 完成创建。创建期间不要连续发起第二次创建。

## Bot 工作区与设置

创建完成后，Bot 会拥有自己的设置工作区。

你可以在 Agent 主页面的 Bot 标签中选择该 Bot，并管理该 Bot 可用的设置，包括记忆、技能、人设、定时任务和已连接通道。

创建方式决定新 Bot 继承哪些内容：

| 创建方式 | 会继承的内容 | 会独立开始的内容 |
| --- | --- | --- |
| 空白创建 | 主模型及其提供商凭证，以及系统预置技能 | 备用模型、其他已配置模型、人设、记忆、主 Bot 后续安装的技能、通道和定时任务 |
| 复制当前 Bot 或复制主 Bot | 模型、人设、技能、用户偏好和长期记忆 | 当前对话、历史会话、定时任务、运行状态和通道连接 |

如果需要保持设置独立，请在确认创建前查看创建对话框中的继承说明。

创建后，你可以分别管理每个 Bot 的[记忆](./memory.md)、[技能](./skill.md)和[定时任务](./automation.md)。

## 为什么要独立创建多个 Bot？

一个 Bot 可以处理很多任务，但随着职责增加，它的上下文会变得更难管理。

研究员、旅行规划师、金融分析师或质量检查员等专用 Bot，可以分别维护更聚焦的记忆、技能、人设设置和定时任务。

独立的 Bot 也方便你测试另一种工作方式，而不会影响已经用于其他任务的 Bot。

这样可以让 LightVela 工作区更有条理。

要切换 Bot，请点击「我的 Hermes」侧栏中的当前 Bot 资料或展开箭头，再从列表中选择另一个 Bot。

## 如何同时使用多个 Bot？

在国内站，多个 Bot 可以接入支持多 Bot 集成的 QQ、企业微信和飞书等通道。

微信当前每个实例只能连接一个 Bot。

如果该通道已经由另一个 Bot 占用，LightVela 会显示提示，并提供前往管理占用该通道的 Bot 的入口。

![LightVela 提示微信已被另一个 Bot 占用，且每个实例只能连接一个 Bot](../images/bots-switching-wechat.webp)

## 检查 Bot 切换或通道连接结果

完成切换或连接后，请检查以下内容：

1. 侧栏当前 Bot 的名称和头像已经变为你选择的 Bot。
2. 设置页面显示的是所选 Bot 的工作区和配置。
3. 已连接的通道显示在实际拥有该连接的 Bot 下。
4. 在目标 Bot 已连接的聊天通道发送一条简短测试消息，确认消息到达预期 Bot 并收到回复。网页[对话](./agent-chat.md)当前只支持主 Bot。

如果使用群聊通道，请按照已配置的权限发送测试消息，确认 Bot 能否读取群上下文，以及是否可以回复。

## 常见问题

| 问题 | 可能原因 | 处理方式 |
| --- | --- | --- |
| 看不到 **新建 Bot** | 当前账户或环境的多 Bot 功能尚未开放 | 继续使用现有 Bot；以当前控制台可见入口为准，不要尝试绕过功能开关。 |
| **新建 Bot** 显示但不可用 | 当前套餐已达到 Bot 数量上限，或另一个 Bot 仍在创建或删除 | 查看按钮提示；等待当前操作完成，删除不再使用的 Bot，或升级到上限更高的套餐。 |
| 切换后网页 **对话** 不可用 | 选中了非主 Bot | 切回主 Bot 使用网页对话；其他 Bot 在已连接的通道中测试。 |
| 无法选择复制选项 | 当前没有可复制的 Bot 或主 Bot | 选择 **空白创建**，或先回到要复制的 Bot，再打开创建对话框 |
| Bot 列表暂时不可用 | Agent 实例已停止，或 Bot 列表请求失败 | 启动或刷新 Agent，然后重新加载 Bot 设置页面 |
| 通道已经连接到另一个 Bot | 该通道存在单 Bot 占用限制 | 使用提示中的入口打开占用该通道的 Bot，或根据通道配置页面断开后重新连接 |
| 群消息没有收到回复 | Bot 的群权限或通道配置不完整 | 查看对应通道的配置页面，然后再次测试 |

## 在群聊中与多个 Bot 对话

你可以将多个 Bot 邀请到支持的群聊中。

根据设置的权限，Bot 可以读取群聊上下文、回复用户问题，或同时执行这两类操作。

不同平台的群聊行为和设置步骤可能不同。

邀请 Bot 前，请先完成对应的通道配置，并按照平台要求通过直接提及 Bot 或其他触发方式进行测试。
