# 诊断中心

诊断中心是你排查 Hermes 问题、进行维护操作的一站式入口。当 Hermes 表现异常、回答变得奇怪、或你想在做重要操作前留个备份时，来这里就对了：查日志定位问题、一键修复配置、备份与恢复数据。

[RECOMMEND ADD IMAGE: LightVela 管理台「诊断中心」页整体截图，展示两张维护操作卡、备份与恢复面板，以及「最近日志」查询卡 — 让读者看到诊断中心的功能分区。]

因为 LightVela 采用云端托管，Hermes 的运行、配置、数据都在云端实例上。诊断中心把常用的排查与维护动作做成了可视化按钮，让你不用接触命令行，也能自助处理大部分问题。

## 诊断中心能帮你做什么

日常使用中，偶尔会遇到这些情况：

- **Hermes 行为异常**：回答不对劲、某个功能不响应，你想知道到底哪里出了问题。

- **模型配置坏了**：改动模型配置后 Hermes 无法正常回答，想快速恢复到可用状态。

- **疑难杂症**：各种办法都试过仍未解决，需要一次更彻底的修复。

- **重要操作前想留后路**：在做大改动前，先把当前数据备份下来，以防万一。

诊断中心把这些场景对应的操作都集中在一处，按需点击即可。

---

## 查看与导出最近日志

日志是排查问题最直接的线索。当 Hermes 出现异常，先来这里看看它最近发生了什么。

1. 在诊断中心找到「最近日志」卡片。

2. 选择时间段：1 小时 / 3 小时 / 6 小时 / 12 小时 / 24 小时。

3. 点「查询」拉取该时间段的日志；点「导出」把完整日志保存下来。

页面出于性能考虑，仅展示最近 50 条日志。**要查看完整内容，请直接导出。**

[RECOMMEND ADD IMAGE: 「最近日志」卡片截图，展示时间段下拉、查询/导出按钮与日志输出区 — 说明如何查询日志。]

> 💡 **看不懂日志也没关系**
>
> 如果日志内容你看不明白，可以把导出的日志或关键报错反馈给技术支持，或直接贴给 Hermes 让它帮你解读，往往能更快定位问题。

## 重置模型配置

如果 Hermes 因为模型配置问题无法正常回答，可以用这个操作把模型配置初始化回可用的默认状态。

1. 在诊断中心找到「重置模型配置」维护卡，点「执行」。

2. 确认弹窗会提示：**将初始化模型配置，模型相关配置不会保留**；期间 Agent 可能短暂不可用，但工作空间、记忆、通道配置、已安装技能**会保留**。

3. 确认后开始执行，稍候即恢复。

> ⚠️ **模型相关配置不会保留**
>
> 重置会清掉你自定义的模型来源配置，并恢复到默认模型。执行前请确认你不再需要当前的模型配置，或已记录好相关信息。其它数据（记忆、通道、技能）不受影响。

---

## 重装 Agent（保留数据）

当常规办法都无法解决问题时，可以执行一次后台重装。这是更彻底的修复方式，用于处理疑难问题。

1. 在诊断中心找到「重装 Agent（保留数据）」维护卡，点「执行」。

2. 确认弹窗会提示：将执行后台重装流程，**期间 Agent 会有数分钟不可用**；但工作空间、记忆、模型和通道配置、已安装技能**都会保留**。

3. 确认后开始执行，页面会显示执行过程，完成后 Hermes 恢复正常。

> ⚠️ **重装期间 Agent 会有数分钟不可用**
>
> 重装是较重的操作，过程需要数分钟，期间 Hermes 无法响应对话。建议在不影响使用的时段进行。好消息是：你的数据（工作空间、记忆、配置、技能）都会完整保留。

## 备份与恢复

诊断中心提供备份与恢复能力，方便你在关键节点保存数据、或在需要时还原。

- **备份**：把当前数据备份下来（可发送到邮箱保存）。建议在做重大改动前先备份一次。

- **恢复**：在需要时，从已有备份还原数据。

备份任务会显示状态：进行中、已完成或失败，一目了然。

## 常见问题

### 该从哪个操作开始排查

先查「最近日志」。日志能告诉你问题大概出在哪，再据此判断是重置模型配置、还是需要重装 Agent。

### 重置模型配置会丢记忆吗

不会。重置只影响模型相关配置，记忆、通道、已安装技能、工作空间都会保留。

### 重装 Agent 会清空我的数据吗

不会。「重装 Agent（保留数据）」顾名思义会保留数据——工作空间、记忆、模型和通道配置、技能都在。只是过程需要数分钟，期间不可用。

### 日志只显示 50 条，怎么看全部

页面为性能只展示最近 50 条。需要完整日志请点「导出」。

### 什么时候该备份

在做重大改动（如大幅调整配置、执行重装）之前，建议先备份一次，给自己留条后路。
