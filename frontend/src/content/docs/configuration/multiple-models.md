# 多模型配置与切换

多模型让你的 Hermes 不被单一大模型绑定：你可以配置多个模型来源（Provider），随时切换当前生效的模型。想用更强的模型处理复杂任务、用更快更省的模型处理日常问答，或接入自己的 API——都能在管理台里灵活搞定。

[RECOMMEND ADD IMAGE: LightVela 管理台「模型」页整体截图，展示已配置的多个模型来源列表，以及「设为默认 / 当前生效」的标记 — 让读者看到多模型的管理方式。]

因为 Hermes 托管在云端，你配置好的模型来源会保存在云端实例上。切换默认模型后，之后所有对话都会用上新模型，跨设备、跨通道一致生效。

> 💡 **可以保存多个模型来源，随时切换生效模型**
>
> 你不必在多个模型之间二选一。管理台允许你同时保存多个模型来源，然后指定其中一个作为"当前生效"的模型。需要时随时切换，配置无需重填。

---

## 为什么要支持多个模型

不同的模型各有所长，把它们都备好、按需切换，能兼顾效果与成本：

- **能力分级**：复杂推理、长文写作用能力更强的模型；日常闲聊、简单问答用更快更省的模型。

- **多来源灵活接入**：既能用平台预置的模型来源，也能接入你自己的 API。

- **随时切换不返工**：一次配好多个来源，之后切换只需一步，不用每次重新填 API 地址和密钥。

---

## 添加一个模型来源

1. 登录 LightVela，进入管理台，在左侧导航点「模型」。

2. 选择一个模型来源（Provider）。平台内置了多种可选来源，也支持添加自定义来源。

3. 填写该来源所需的信息，通常包括：

   - **API 地址**（Base URL）：模型服务的接入地址。

   - **API Key**：访问该服务的密钥。

   - **模型列表**：该来源下可用的具体模型。

4. 保存。保存后这个模型来源就进入了你的可用列表。

[RECOMMEND ADD IMAGE: 模型来源配置表单截图，展示 Base URL、API Key、模型列表等填写项与「保存」按钮 — 说明如何添加一个模型来源。]

> ℹ️ **保存来源 ≠ 立即启用**
>
> 保存一个模型来源只是把它加入可用列表，并不会立即让 Hermes 改用它。要真正启用，还需在下一步把它设为"当前生效"的模型。

---

## 切换当前生效的模型

配好多个来源后，随时可以指定哪一个作为当前生效的模型：

1. 在「模型」页找到你想启用的模型，将它设为默认 / 当前生效。

2. 切换后，Hermes 之后的对话就会使用这个模型。

已保存的其它来源不会丢失，它们依旧在列表里，你可以随时切回。

> 💡 **切换是"换挡"，不是"重配"**
>
> 切换生效模型只是在已保存的来源之间选择当前使用哪一个，就像换挡一样轻。不需要重新填写 API 信息，配置一直保留着。

---

## 使用自定义模型来源

如果平台预置的来源不能满足你，或你想接入自己的模型服务，可以添加自定义来源：填入你自己的 API 地址、密钥和模型信息即可。保存后它和预置来源一样出现在列表中，可随时设为生效模型。

> ⚠️ **妥善保管你的 API Key**
>
> 自定义来源需要填入你自己的 API Key。请确保密钥来源可信、额度充足；页面在展示时会对密钥做脱敏处理，但你仍应像对待密码一样妥善保管它。

---

## 切换后何时生效

保存模型来源本身不会中断 Hermes。切换当前生效的模型时，为了让新模型正式接管，网关可能会进行一次短暂的刷新/重启，期间正在进行的对话可能会短暂中断，稍候即可恢复。

如果切换后 Hermes 一时没反应，稍等片刻再发消息即可。

> ℹ️ **切换若长时间未生效**
>
> 极少数情况下切换未能自动生效，可前往[诊断中心](./diagnostics.md)手动重启网关，或用「重置模型配置」恢复到可用的默认状态。

## 常见问题

### 我可以同时保存几个模型来源

可以保存多个。它们都留在你的可用列表里，随时切换当前生效的那一个，配置不会互相覆盖。

### 切换模型后，之前的对话记忆还在吗

在。切换的只是"用哪个模型来回答"，记忆、通道、技能等都不受影响。

### 能接入我自己的模型 API 吗

可以。添加自定义模型来源，填入你的 API 地址、密钥和模型信息即可，之后和预置来源一样使用。

### 切换后 Hermes 卡住了

切换生效可能触发一次短暂的网关刷新，对话会瞬时中断。稍等片刻再发消息即可恢复。

### 切换一直不生效怎么办

可到[诊断中心](./diagnostics.md)手动重启网关；若模型配置疑似出问题，也可用那里的「重置模型配置」恢复默认。
