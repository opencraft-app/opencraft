# 스킬 구성

## 요약

**스킬은 Hermes Agent가 호출할 수 있는 추가 기능 팩으로, 기본 대화를 넘어 할 일 정리, 일일 보고서 작성, 웹·뉴스 검색, 이미지 생성 등의 작업을 수행하도록 기능을 확장합니다. 이 스킬들은 OpenClaw와 Hermes가 함께 사용하는 Skills.sh 및 ClawHub 마켓플레이스에서 제공됩니다. 스킬은 선택 사항입니다. 기본 상태에는 설치된 스킬이 없어도 정상적으로 대화할 수 있으므로, 필요한 기능이 생겼을 때 설치하는 것이 좋습니다. 설치 방법은 두 가지입니다. 콘솔의 스킬 섹션에서 이름으로 검색하거나 대화 중에 에이전트에게 설치를 요청할 수 있습니다. 설치한 스킬은 콘솔에서 삭제할 수 있습니다.**

---

스킬은 Hermes에서 호출할 수 있는 추가 기능 패키지입니다. 할 일 자동 정리, 일일 보고서 생성, 웹 페이지 탐색, 뉴스 검색, 이미지 생성 등과 같은 기본적인 대화를 넘어 구체적인 작업 처리를 확장합니다.

모든 스킬은 [**Skills.sh**](https://skills.sh/) 및 [**ClawHub**](https://clawhub.ai/)에서 제공됩니다. OpenClaw 및 Hermes가 공유하는 스킬 마켓플레이스입니다.

>
> Hermes에는 기본적으로 설치된 스킬이 없지만 스킬 없이도 정상적으로 대화할 수 있습니다. 특정 작업에 필요한 기능이 생겼을 때 해당 스킬을 설치하는 것이 좋습니다.

## 스킬의 역할

Hermes가 대형 모델과 결합되어 사용자에게 지능형 AI 보조자를 제공한다면 스킬은 "손과 발"입니다. 스킬은 이미 배포된 Hermes의 기능 경계를 더욱 확장할 수 있습니다.

스킬을 Hermes의 "애플리케이션"으로 생각할 수 있습니다.

- 기본 대화 능력 = 운영체제

- 스킬 = 요청 시 설치된 애플리케이션


각 스킬은 다음과 같은 단일 작업에 중점을 둡니다.

- 브라우저를 사용하여 웹페이지 탐색 및 정보 쿼리

- 매일 할 일을 자동으로 정리

- 예정된 뉴스브리핑 발송

- 설명을 바탕으로 이미지 생성

- 실시간 주식, 펀드 정보 조회

- 채팅 기록을 구조화된 노트로 정리하기


Hermes는 대화 컨텍스트에 따라 해당 스킬을 호출할지 여부를 자동으로 결정합니다. 사용자는 이를 지정할 필요가 없습니다.

## 방법 1: 콘솔 패널을 통해 설치(곧 제공 예정)

LightVela 콘솔은 "스킬" 버튼에 시각적인 스킬 구성 항목을 제공합니다. Skills.sh 또는 ClawHub에서 찾은 스킬 이름을 입력하고 빠르게 설치할 수 있습니다.

### 1. LightVela 콘솔 열기

LightVela에 로그인하고 오른쪽 상단의 "My AI Partners"를 클릭하여 콘솔에 들어간 후 "스킬" 버튼을 찾으세요.

### 2. 검색 및 설치

검색창에 확인해 둔 스킬 이름(예: `gmail`)을 입력하고 **+** 버튼을 클릭하세요.

![](../images/clawhub-install-global-en.webp)

### 3. 대화 가능 여부 확인

연결된 채널(Telegram / WhatsApp / Discord / Slack / WeChat)로 돌아갑니다. 먼저 Hermes에게 스킬 목록을 업데이트하도록 요청한 다음 현재 사용 가능한 스킬을 확인하세요.

```
Please update your skill list
```

```
What skills are currently available?
```

새로 설치된 스킬이 목록에 나타나면 대화에서 사용할 수 있습니다.

---

## 방법 2: 대화를 통해 직접 설치

콘솔 패널을 사용하는 것 외에도 Hermes에게 대화를 통해 직접 스킬을 설치하도록 요청할 수도 있습니다. 설치할 스킬은 여전히 Skills.sh 또는 ClawHub에 나열되어 있어야 합니다.

### 1. 채널 대화가 가능한지 확인하세요

먼저 Hermes가 하나 이상의 채널(Telegram / WhatsApp / Discord / Slack / WeChat)에 연결되어 있고 현재 정상적으로 채팅할 수 있는지 확인하세요.

### 2. 설치할 스킬을 Hermes에게 알리기

아래 명령을 참고하세요. Hermes에게 설치하려는 스킬을 알려 주고 `[skill name]`을 Skills.sh 또는 ClawHub에 표시된 실제 이름으로 바꾸세요.

```
Please install a skill from Skills.sh or ClawHub. Its name is [skill name]
```

예를 들어, `mcd`(McDonald's Assistant)를 설치하려면:

```
Please install a skill from Skills.sh or ClawHub. Its name is mcd
```

정상적으로 처리되면 Hermes가 설치를 완료하고 결과를 알려 줍니다.

> ⚠️ **고위험 스킬 2차 확인**
>
> 선택한 스킬이 Skills.sh 또는 ClawHub에서 고위험으로 표시되면 안전하지 않은 동작이 포함될 수 있습니다. 이 경우 Hermes가 설치 전에 경고하고 2차 확인을 요청합니다. 계속하기 전에 스킬의 동작을 충분히 이해했는지 확인하세요. 확신이 없다면 설치하지 않는 편이 안전합니다.

### 3. 설치 결과 확인

Hermes에게 스킬을 사용하여 설치가 성공했는지 확인하는 방법을 보여달라고 요청할 수 있습니다.

```
Please show me how to use it
```

또는 스킬 이름을 명시적으로 지정합니다.

```
Please show me how to use mcd
```

## 스킬 사용 예

예를 들어 `agent-browser` 브라우저 작업 스킬을 사용하면 설치 후 Hermes에 다음 작업을 수행하도록 요청할 수 있습니다.

> ℹ️ **참고**
>
> 다음 예에서는 WeChat 채널을 사용합니다. Telegram, WhatsApp, Discord 및 Slack은 동일한 방식으로 작동합니다.

### 시나리오 1: 웹페이지 탐색

```
Use the browser to visit Baidu and tell me what is on the page
```

Hermes는 페이지를 열고 내용을 텍스트 형식으로 반환합니다.

### 시나리오 2: 브라우저를 통해 정보 검색

```
Use the browser to look up today's top 5 trending news stories
```

### 시나리오 3: 다단계 복잡한 작업

```
Use the browser to search ClawHub and find the currently most-installed email skill
```

이 작업에는 웹 페이지 열기, 로드 대기, 콘텐츠 입력, 버튼 클릭 등의 여러 단계가 포함됩니다. 비교적 복잡합니다. Hermes는 단계를 완료하고 결과를 반환합니다.

![](../images/clawhub-browser-example-global-en.webp)

## 설치된 스킬 삭제

설치된 스킬을 더 이상 사용하지 않을 경우, 콘솔의 "설치된 스킬" 목록에서 삭제하거나 Hermes에게 대화로 삭제를 요청할 수 있습니다.

### 1. 현재 설치된 스킬 보기

```
What skills do you currently have installed?
```

### 2. 특정 스킬 삭제 요청

삭제하려는 스킬을 찾아 삭제 명령을 보냅니다.

```
Please delete the email skill
```

정상적으로 처리되면 Hermes가 삭제를 완료하고 결과를 알려 줍니다.

> ℹ️ **2차 확인 가능**
>
> 사용 중인 모델이나 Hermes의 성격 설정에 따라 삭제 시 주의 사항이 표시될 수 있습니다. 실제 필요에 따라 확인 메시지에 응답하세요.

### 3. 삭제 결과 확인

현재 설치된 스킬을 다시 확인하고 대상 스킬이 목록에서 제거되었는지 확인합니다.

```
Check again what skills you currently have installed
```

> ℹ️ **콘솔과 대화에서 모두 삭제할 수 있습니다**
>
> 콘솔의 "설치된 스킬" 목록에서 삭제하거나 Hermes에게 대화로 삭제를 요청하세요. LightVela는 클라우드 호스팅 모드를 사용하므로 파일 시스템을 직접 조작할 필요는 없습니다.

## 성공 상태

- 대상 스킬이 콘솔의 "설치된 스킬" 목록에 나타납니다.

- 대화에서 관련 요청을 하면 Hermes가 스킬을 올바르게 인식하고 호출할 수 있습니다.

- 콘솔 또는 대화를 통해 스킬을 정상적으로 삭제할 수 있습니다.

## 설치 안전 팁

스킬에는 런타임 시 Hermes 기능을 호출할 수 있는 권한이 있으며 다음이 포함될 수 있습니다.

- 외부 API 호출(해당 할당량 소비)

- 대화 내용 읽기 또는 보내기

- 예약된 작업 실행

설치하기 전에 스킬 작성자를 신뢰할 수 있는지 확인하세요. 다음 기준을 권장합니다.

- Skills.sh 또는 ClawHub에서 공식적으로 검증된 스킬을 선호합니다.

- 다운로드 수가 많고 사용자 평가가 좋은 스킬을 우선 고려하세요.

- 스킬 설명의 권한 설명을 주의 깊게 읽으세요.

- 설명이 불분명하거나 신뢰하기 어려운 작성자가 만든 스킬은 주의하세요.

## FAQ

### 스킬을 찾을 수 없습니다

**가능한 원인**: 이름의 철자가 틀리거나 스킬이 Skills.sh 또는 ClawHub에서 제거되었습니다.

**해결책**: [**Skills.sh**](https://skills.sh/) 또는 [**ClawHub**](https://clawhub.ai/)로 이동하여 정확한 스킬 이름과 현재 상태를 확인하세요.

### 설치는 성공했지만 대화에서 작동하지 않습니다

**가능한 원인**: 모델이 스킬을 사용해야 함을 인식하지 못했거나 스킬 목록이 새로 고쳐지지 않았습니다.

**해결책**:

1. 대화에서 "스킬 목록을 업데이트하세요"를 보냅니다.

2. "YY를 완료하려면 XX 스킬을 사용하세요."와 같은 보다 명확한 지침을 사용하세요.


### 설치할 때 "속도 제한이 적용되었습니다. 나중에 다시 시도하세요"라는 메시지가 표시됩니다

**가능한 원인**: Skills.sh 및 ClawHub는 서비스 안정성을 보호하기 위해 API 속도 제한을 적용합니다.

**해결책**: 잠시 기다렸다가 다시 시도하세요. 피크 시간대를 피하는 것이 좋습니다.

### 스킬 호출이 계속 실패합니다

**가능한 원인**:

- 스킬에 필요한 외부 서비스를 일시적으로 사용할 수 없습니다.

- 스킬 버전이 오래되었습니다.

- 해당 모델은 도구 호출과 같은 스킬에 필요한 기능을 지원하지 않습니다.


**해결책**:

- Skills.sh 또는 ClawHub에서 스킬의 사용자 후기와 최신 버전 정보를 확인하세요.

- 도구 호출을 지원하는 모델로 전환해 보세요

- 문제가 지속되면 스킬 작성자에게 문의하세요.


### 설치된 스킬이 너무 많아 Hermes의 응답이 느립니다

**가능한 원인**: 스킬이 많아지면 에이전트의 의사결정 부담이 늘어납니다.

**해결책**: 일반적으로 사용되는 스킬만 유지하고 더 이상 사용하지 않는 스킬을 삭제하세요.

### 스킬은 어떻게 개발하나요?

Skills.sh 및 ClawHub 개발자 문서(사용 가능한 경우)를 참조하세요.
