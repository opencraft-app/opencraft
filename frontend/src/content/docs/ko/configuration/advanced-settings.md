# 고급 설정

## 요약

**고급 설정에서는 Hermes Agent가 보안, 메모리, 대화 컨텍스트를 관리하는 방식을 제어할 수 있습니다.**
고위험 작업에 대한 승인 요청 방식을 선택하고, 영구 메모리와 사용자 프로필, 긴 대화의 자동 압축을 관리할 수 있습니다. 또한 압축 시작 시점, 유지할 최근 콘텐츠의 비율, 원문 그대로 보호할 최근 메시지 수를 설정할 수 있습니다.
승인 모드를 저장하면 LightVela가 설정을 다시 읽어 새 값이 적용되었는지 확인합니다.
메모리 또는 컨텍스트 관리 설정을 저장하면 LightVela가 관련 서비스를 재시작한 뒤 설정을 다시 읽어 새 값이 적용되었는지 확인합니다.

![LightVela 콘솔의 고급 설정](../images/setting-1-en.png)

## 이 페이지에서 다루는 내용

- 고위험 작업에 대한 에이전트의 승인 요청 방식 관리
- 영구 메모리 및 사용자 프로필 관리
- 긴 대화의 자동 압축 관리
- 압축 임계값, 콘텐츠 유지 비율, 보호할 최근 메시지 수 설정
- 보안, 메모리 또는 컨텍스트 관리 그룹의 기본값 복원

## 시작하기 전에

1. 대상 에이전트가 실행 중인지 확인합니다.
2. **Agents**를 열고 설정할 에이전트를 선택합니다.
3. **Advanced Settings**를 엽니다.

에이전트가 실행 중이 아니면 현재 값은 볼 수 있지만 변경할 수는 없습니다.

## 사용 가능한 설정

| 그룹 | 설정 | 기능 |
| --- | --- | --- |
| Security | Approval Mode | Smart, Always Ask 또는 Off 중 하나를 선택해 고위험 작업에 대한 에이전트의 승인 요청 방식을 제어합니다. |
| Memory | Persistent Memory | 에이전트가 이후 대화에서 장기 메모리를 읽고 업데이트할 수 있게 합니다. |
| Memory | User Profile | 에이전트가 사용자의 선호도, 소통 방식, 습관을 기록하고 활용할 수 있게 합니다. |
| Context Management | Automatic Compression | 긴 대화가 컨텍스트 한도에 가까워질 때 이전 내용을 요약합니다. |
| Context Management | Compression Threshold | 압축을 시작할 컨텍스트 사용 비율을 0~1 사이로 설정합니다. |
| Context Management | Compression Retention Ratio | 압축 후 유지할 최근 대화 텍스트의 비율을 0.1~0.8 사이로 설정합니다. |
| Context Management | Protected Recent Messages | 압축 중에도 원문 그대로 유지할 최근 메시지 수를 설정합니다. 최솟값은 1입니다. |

## 설정 변경

### Approval Mode

1. **Approval Mode** 목록에서 Smart, Always Ask 또는 Off를 선택합니다.
2. Off를 선택했다면 위험 경고를 읽고 승인 기능을 끌 것인지 확인합니다.
3. 페이지가 설정을 다시 읽을 때까지 기다린 뒤, 선택한 모드가 표시되는지 확인합니다.

승인이 Off이면 에이전트가 고위험 작업에 대한 승인을 더 이상 요청하지 않으며, 페이지에는 위험 경고가 계속 표시됩니다.
신뢰할 수 있는 환경에서만 Off를 사용하세요.

### 스위치 설정

1. Persistent Memory, User Profile 또는 Automatic Compression 옆의 스위치를 선택합니다.
2. 확인 메시지를 읽고 변경을 승인합니다.
3. 저장이 끝날 때까지 기다립니다.

Persistent Memory 또는 User Profile을 꺼도 기존 콘텐츠는 삭제되지 않습니다.
Automatic Compression을 끄면 기존 압축 값은 유지되지만, 이전 대화 콘텐츠의 자동 요약은 중단됩니다.

### 숫자 설정

1. 변경할 값 옆의 편집 버튼을 선택합니다.
2. 허용 범위 안의 값을 입력합니다.
3. Save를 선택하거나 Enter를 눌러 값을 저장합니다.
4. Cancel을 선택하거나 Escape를 눌러 편집을 취소합니다.

압축 임계값, 유지 비율, 보호할 메시지 수는 Automatic Compression이 켜져 있을 때만 변경할 수 있습니다.

## 기본값 복원

고급 설정에서는 **Security**, **Memory**, **Context Management** 그룹별로 **Restore defaults**를 제공합니다.

1. 초기화할 그룹에서 **Restore defaults**를 선택합니다.
2. 확인 메시지를 읽습니다.
3. 복원을 승인합니다.

기본값을 복원하면 선택한 그룹의 사용자 지정 값만 제거되고 해당 그룹이 Hermes Agent 기본값으로 돌아갑니다.
Security 그룹을 복원하면 Approval Mode가 **Smart**로 돌아갑니다.
다른 그룹에는 영향을 주지 않으며 기존 에이전트 메모리도 삭제하지 않습니다.

## 변경 사항 확인

저장 또는 복원이 완료되면 페이지에 에이전트에서 다시 읽어 온 값이 표시됩니다.
Approval Mode를 저장할 때는 관련 서비스가 재시작되지 않으며 페이지가 값을 바로 다시 읽습니다.
Memory 및 Context Management 설정을 저장하거나 복원하면 관련 서비스가 재시작되고 설정을 다시 읽습니다.
자동 압축을 변경한 뒤에는 긴 대화를 이어 가며 에이전트가 새 컨텍스트 관리 규칙을 따르는지 확인하세요.
메모리 설정을 변경한 뒤에는 이후 대화에서 에이전트가 메모리와 선호도를 예상대로 사용하는지 살펴보세요.

## FAQ

### 설정을 변경할 수 없는 이유는 무엇인가요?

먼저 에이전트가 실행 중인지 확인하세요.
LightVela가 설정을 읽거나, 변경 사항을 저장하거나, 기본값을 복원하는 동안에도 컨트롤을 일시적으로 사용할 수 없습니다.

### 에이전트 버전에서 이 설정을 지원하지 않는다고 표시되는 이유는 무엇인가요?

현재 해당 에이전트에서 실행 중인 버전이 이 설정을 지원하지 않습니다.
사용 가능한 설정만 이용하거나 에이전트가 업데이트된 뒤 이 페이지를 다시 확인하세요.

### 입력한 숫자를 저장할 수 없는 이유는 무엇인가요?

압축 임계값은 0~1 사이여야 합니다.
압축 유지 비율은 0.1~0.8 사이여야 합니다.
보호할 최근 메시지 수는 1 이상의 정수여야 합니다.

### Automatic Compression을 끈 뒤 다른 압축 설정을 편집할 수 없는 이유는 무엇인가요?

해당 값은 Automatic Compression이 켜져 있을 때만 적용됩니다.
값을 변경하려면 Automatic Compression을 다시 켜세요.

### 언제 승인을 꺼야 하나요?

승인이 Off이면 고위험 작업에 대해 더 이상 승인을 요청하지 않습니다.
신뢰할 수 있는 환경에서 의도적으로 자동화를 수행하는 경우가 아니라면 Smart를 유지하거나 Always Ask를 선택하세요.

### 저장할 때 재시작 또는 검증 실패가 보고되면 어떻게 해야 하나요?

Memory 또는 Context Management 설정을 변경했다면 설정 자체는 이미 기록되었지만, 관련 서비스 재시작이나 설정 다시 읽기가 끝나지 않았을 수 있습니다.
Approval Mode를 변경했다면 설정 자체는 이미 기록되었지만, 페이지에서 다시 읽은 값의 검증이 끝나지 않았을 수 있습니다.
페이지를 새로 고쳐 표시된 값을 확인한 뒤 다시 시도할지 결정하세요.
