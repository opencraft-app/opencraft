# 메모리 관리

## 요약

**메모리는 Hermes가 대화와 기기가 바뀌어도 중요한 내용을 기억하게 해 줍니다. 여기에는 사용자의 선호도와 정체성, 현재 작업, 장기간 협업하며 축적한 경험이 포함됩니다. 메모리는 Hermes를 일회성 질의응답 도구에서 시간이 흐를수록 사용자를 더 잘 이해하는 어시스턴트로 바꾸는 기반입니다. 메모리는 모델 외부의 에이전트에 저장되므로 모델을 전환해도 잊지 않습니다. 콘솔의 메모리 및 사용자 프로필 페이지에서 축적된 내용을 확인, 편집 또는 삭제할 수 있으며, 모든 메시징 채널이 하나의 메모리를 공유합니다.**

---

메모리는 사용자의 선호도, 정체성, 진행 중인 작업, 장기간 협업하며 쌓인 경험 등 중요한 정보를 Hermes가 대화와 기기가 바뀌어도 유지할 수 있게 합니다. 메모리 덕분에 Hermes는 일회성 질의응답 도구가 아니라 시간이 지날수록 사용자를 더 잘 이해하는 장기 어시스턴트가 됩니다.

![LightVela 콘솔의 메모리 및 사용자 프로필 페이지](../images/memory-management-overview-en.png)

LightVela는 클라우드에서 호스팅되므로 이러한 메모리는 클라우드의 Hermes 인스턴스에 저장됩니다. 기기를 바꾸거나 Telegram, WhatsApp, Discord, Slack, WeChat 사이에서 채널을 전환해도 사라지지 않습니다. 오늘 Telegram에서 Hermes에게 알려 준 내용을 다음 날 WhatsApp에서 대화를 이어 갈 때도 기억할 수 있습니다.

- 에이전트 메모리와 사용자 프로필, 두 가지 메모리 유형

- 콘솔에서 메모리와 용량 사용량을 확인하는 방법

- 메모리 용량 한도를 조정하는 방법

- 대화를 통해 메모리를 추가하거나 삭제하는 방법

>
> 메모리 양식을 작성할 필요가 없습니다. 평소 대화에서 Hermes가 장기적으로 보관할 가치가 있는 정보를 판단합니다. 콘솔의 Memory 페이지는 주로 Hermes가 기억하는 내용을 **확인**하고 필요할 때 **용량을 조정**하는 용도로 사용합니다.

## 메모리가 중요한 이유

메모리가 없다면 AI 어시스턴트와 나누는 모든 대화가 백지에서 시작됩니다. 사용자가 누구인지, 무엇을 선호하는지, 이전 대화가 어디에서 끝났는지 매번 다시 설명해야 합니다. 메모리는 이 문제를 해결합니다.

- **반복 설명 줄이기**: 싱가포르에 거주하며 아침 브리핑을 선호한다고 Hermes에게 한 번 말해 두면 매번 다시 설명할 필요가 없습니다.

- **채널 간 일관성 유지**: Telegram, WhatsApp, Discord, Slack, WeChat이 같은 메모리를 공유합니다. 채널을 바꿔도 여전히 사용자를 이해하는 동일한 어시스턴트와 대화하게 됩니다.

- **지속적인 사용을 통한 개선**: 협업이 이어질수록 Hermes는 사용자의 일상 패턴, 선호하는 호칭, 진행 중인 프로젝트를 기억해 점점 더 관련성 높은 답변을 제공합니다.

메모리를 Hermes의 장기 노트라고 생각하면 됩니다. 일상적인 모든 메시지를 보존하는 것이 아니라 나중에도 유용할 가능성이 높은 세부 정보만 유지합니다.

## 두 가지 메모리 유형

콘솔의 Memory 페이지에는 용도가 서로 다른 두 개의 탭이 있습니다.

### Memory

여기에는 사용자가 공유한 선호도, 합의한 업무 방식, 반복적으로 발생하는 요구 등 Hermes가 장기 협업을 통해 쌓은 **경험과 사실**이 담깁니다. Hermes가 대화 중에 이 콘텐츠를 자동으로 관리하며, 계속 사용할수록 항목도 발전합니다.

### User Profile

정체성, 거주지, 직업적 배경, 장기적인 선호도처럼 **사용자가 누구인지**를 안정적으로 기록합니다. 일반 메모리에 비해 사용자 프로필은 어떤 대화에서든 Hermes가 사용자의 기본 컨텍스트를 빠르게 파악하도록 돕는 영구 프로필 카드에 가깝습니다.

> ℹ️ **두 유형의 차이**
>
> 간단히 말하면 **사용자 프로필**은 “사용자는 어떤 사람인가?”에 답하고, **메모리**는 “우리 사이에 어떤 일이 있었고 무엇에 합의했는가?”에 답합니다. 두 정보를 함께 사용해 Hermes는 사용자와 협업 이력을 모두 이해합니다.

## 메모리 및 용량 사용량 확인

1. LightVela에 로그인하고 오른쪽 상단의 “My Hermes”를 클릭해 콘솔을 엽니다.

2. 설정 탐색 메뉴에서 “Memory”를 찾아 Memory 페이지를 엽니다.

3. 페이지 상단의 **메모리 통계**에서 현재 사용 중인 문자 수, 용량 한도, 사용률을 확인합니다.

4. “Memory”와 “User Profile” 탭을 전환해 각 콘텐츠를 확인합니다.

둘 중 하나가 비어 있으면 페이지에 “No Agent memory” 또는 “No user profile”이 표시됩니다. 대개 Hermes와 충분히 오래 협업하지 않아 해당 유형의 메모리가 아직 형성되지 않았다는 의미입니다. 사용을 이어 가면 콘텐츠가 점차 쌓입니다.

> 💡 **사용률의 의미**
>
> 메모리에는 용량 한도가 있습니다. 사용량이 한도에 가까워지면 Hermes가 더 중요한 정보를 우선하고 오래된 항목은 제거합니다. 사용률을 살펴보면 용량을 늘릴지, 더 이상 필요 없는 정보를 제거할지 판단할 수 있습니다.

---

## 메모리 용량 한도 조정

Hermes가 더 많은 정보를 보관하도록 하려면 용량 한도를 늘릴 수 있고, 필요한 경우 줄일 수도 있습니다.

- **Memory**는 500~4,000자로 설정할 수 있습니다.

- **User Profile**은 500~3,000자로 설정할 수 있습니다.

새 한도는 저장 후 적용됩니다.

> ⚠️ **새 한도를 저장하면 게이트웨이가 잠시 재시작되어 현재 대화가 중단될 수 있습니다**
>
> 새 용량 한도를 저장하면 설정을 적용하기 위해 Hermes 게이트웨이가 잠시 재시작됩니다. 진행 중인 대화가 잠깐 중단될 수 있지만 곧 복구됩니다. 짧은 중단이 작업에 영향을 주지 않는 시점에 변경하세요.

## 대화를 통해 메모리 추가 또는 삭제

콘솔에서 콘텐츠를 확인하는 것 외에도 Hermes에게 정보를 기억하거나 잊어 달라고 직접 요청할 수 있습니다. 일상적으로 메모리를 관리하는 가장 자연스러운 방법입니다.

**기억하도록 요청:**

```
Remember that I want my daily briefing at 8:00 AM.
```

```
Remember that I prefer concise, direct answers.
```

**잊도록 요청:**

```
I no longer need the daily briefing we discussed. Please forget that preference.
```

Hermes가 사용자의 의도를 해석하고 관련 메모리 항목을 업데이트한 뒤 변경 내용을 알려 줍니다.

> ℹ️ **현재 메모리 콘텐츠는 대화를 통해 관리합니다**
>
> LightVela는 관리형 클라우드 모델을 사용하며 사용자에게 파일 시스템 작업을 제공하지 않습니다. 메모리 콘텐츠는 주로 Hermes와 대화하여 추가하거나 삭제하고, 콘솔에서는 콘텐츠 확인과 용량 한도 조정을 수행하세요.

## FAQ

### 저장을 명시적으로 요청하지 않은 내용도 Hermes가 기억하는 이유는 무엇인가요?

정상적인 동작입니다. Hermes는 사용자의 선호도, 정체성, 업무 합의처럼 시간이 지나도 유용할 수 있는 정보를 자동으로 식별합니다. 어떤 정보를 보관하지 않기를 원한다면 대화에서 해당 내용을 잊어 달라고 요청하세요.

### 기기나 채널을 바꿔도 메모리가 유지되나요?

네. 메모리는 클라우드 인스턴스에 저장되며 특정 기기나 채널에 종속되지 않습니다. Telegram, WhatsApp, Discord, Slack, WeChat이 모두 같은 메모리를 공유합니다.

### 메모리 용량이 가득 차면 어떻게 되나요?

사용량이 한도에 가까워지면 Hermes가 더 중요한 정보를 우선하고, 오래되었거나 덜 유용한 항목을 점차 제거합니다. 더 많은 정보를 보관해야 한다면 Memory 페이지에서 용량 한도를 늘리세요.

### Memory 페이지에 메모리가 없다고 표시되는 이유는 무엇인가요?

해당 유형의 메모리에 아직 콘텐츠가 쌓이지 않았기 때문입니다. Hermes와 계속 협업하거나 중요한 세부 정보를 기억해 달라고 직접 요청하면 콘텐츠가 나타나기 시작합니다.

### 용량 한도를 변경한 뒤 대화가 잠시 멈춘 이유는 무엇인가요?

새 한도를 저장하면 게이트웨이가 잠시 재시작되므로 대화가 일시적으로 중단될 수 있습니다. 잠시 기다렸다가 메시지를 다시 보내세요.
