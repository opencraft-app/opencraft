# 채널 - WeChat 구성

## 요약

**WeChat 채널은 QR 코드로 연결하며, 모든 채널 중 설정이 가장 간단합니다. 콘솔의 채널 섹션에서 WeChat을 선택하고 인증을 눌러 QR 코드를 생성한 뒤 휴대폰의 WeChat으로 스캔하면 대화를 시작할 수 있습니다. WeChat이 설치된 휴대폰과 구성된 모델(또는 플랜에 포함된 월간 모델 크레딧)만 있으면 됩니다. 하나의 에이전트를 여러 채널에 동시에 연결할 수 있으며, 모든 채널이 동일한 페르소나와 장기 메모리를 공유합니다.**

---

WeChat 채널은 QR 코드 액세스를 사용하며 구성이 가장 간단한 채널입니다.

## 이 페이지에서는 다음을 다루고 있습니다.

- LightVela에서 WeChat 액세스 QR 코드 생성

- 휴대폰에서 WeChat으로 QR 코드 스캔하기

- WeChat에서 Hermes Agent와 채팅 중


> 💡 **전제 조건**
>
> - WeChat이 설치된 전화기
>
> - [모델 구성](./model.md) 완료(또는 Launch 플랜에 포함된 100 체험 크레딧 사용)
>

---

## 단계

### 1. 콘솔에 들어가세요

LightVela에 로그인하고 오른쪽 상단의 "My Hermes"를 클릭하여 콘솔에 들어간 후 "채널" 버튼을 찾으세요.

### 2. WeChat 채널을 선택하세요.

드롭다운을 클릭하고 "WeChat"을 선택합니다. WeChat 채널 소개 및 "세부 정보 보기" 링크가 아래에 표시됩니다.

### 3. '액세스 승인'을 클릭하세요.

페이지에 QR 코드가 나타납니다.

![](../images/20260424-142558-0pl3.webp)

> ⚠️ **QR 코드 만료**
>
> QR 코드는 몇 분 후에 만료됩니다. 만료되면 대화 상자를 닫고 "액세스 승인"을 다시 클릭하여 새 QR 코드를 생성하세요.

### 4. 휴대폰에서 WeChat으로 스캔하세요.

1. 휴대폰에서 WeChat을 엽니다.

2. 오른쪽 상단의 '+'를 탭하고 → '스캔'을 탭하세요.

3. 컴퓨터 화면에서 QR 코드를 스캔하세요.

4. 인증을 완료하려면 휴대전화의 안내를 따르세요.


### 5. WeChat에서 Hermes Agent를 찾으세요.

스캔이 성공한 후:

- 대화 상자가 자동으로 닫히고 "WeChat" 레코드가 콘솔의 "연결된 채널" 목록에 추가됩니다.

- WeChat은 자동으로 봇 계정을 추가합니다


해당 봇과의 채팅을 열고 테스트 메시지를 보냅니다.

```
Hi
```

몇 초 내에 Hermes Agent 응답을 받게 됩니다.

![](../images/6.1-2.webp)

---

## 성공 상태

- 콘솔의 "연결된 채널" 목록에 "WeChat"이 포함되어 있습니다.

- 해당 봇은 WeChat 연락처에서 찾을 수 있습니다.

- Hermes Agent는 메시지를 보낸 후 응답합니다.


---

## 지원되는 메시지 유형

액세스가 성공한 후 WeChat 봇은 기본 문자 메시지를 수신하고 응답할 수 있으며 다음과 같이 더 많은 메시지 유형을 지원합니다.

| WeChat 봇이 지원하는 메시지 유형 | 지원됨 |
|---|---|
| 문자 메시지 받기 | ✅ 지원됨 |
| 이미지 및 비디오 수신 | ✅ 지원됨 |
| 파일 받기 | ✅ 지원됨 |
| 음성 메시지 받기 | ✅ 지원됨 |
| 문자 메시지로 답장하기 | ✅ 지원됨 |
| 이미지와 동영상으로 답장하기 | ✅ 지원됨 |
| 파일로 답장하기 | ✅ 지원됨 |
| 사전에 메시지 보내기(예: 예약된 알림) | ✅ 지원됨 |

> ℹ️ **실제 처리 능력은 모델에 따라 다릅니다**
>
> 위 표는 채널 레이어에서 WeChat 봇이 지원하는 메시지 유형만 나타냅니다. 이미지, 파일 및 기타 작업을 실제로 처리할 수 있는지 여부도 Hermes Agent에 연결된 대형 언어 모델에 해당 기능이 있는지 여부에 따라 달라집니다.

## FAQ

| 이슈 | 가능한 원인 | 솔루션 |
|---|---|---|
| WeChat은 스캔 후 "잘못된 QR 코드"를 표시합니다. | QR 코드가 만료되었습니다 | 대화상자를 닫고 "액세스 승인"을 다시 클릭하세요. |
| 스캔 후 컴퓨터에서 응답이 없습니다. | 네트워크 지연 또는 승인이 완료되지 않았습니다. | 상태를 확인하려면 콘솔을 새로 고치십시오. 액세스에 실패하면 다시 시도하세요. |
| WeChat에서 봇 연락처를 찾을 수 없습니다. | 메시지는 "서비스 알림"으로 접혀 있습니다. | WeChat 상단에 "LightVela" 또는 Hermes Agent 이름을 검색하세요. |
| 메시지를 보낸 후 응답이 없습니다. | 모델이 구성되지 않았거나 체험 크레딧이 소진되었습니다. | "1. 모델" 카드에서 "현재 모델" 상태를 확인하세요. |
| 연결을 해제하는 방법 | — | "연결된 채널" 목록에서 해당 레코드를 삭제합니다. |
| 동일한 WeChat 계정이 여러 Hermes Agent 인스턴스에 연결할 수 있나요? | Launch 플랜 한도는 1 Hermes Agent입니다. | 해당 없음 |

## 채널 노트

- **메시지 유형**: 텍스트, 이미지, 동영상, 파일, 음성 메시지 등을 지원합니다. 위의 '지원되는 메시지 유형'을 참조하세요.

- **그룹 채팅 지원**: 그룹 채팅은 현재 지원되지 않습니다. 1:1 대화만 지원됩니다.

- **연결 중단**: 오랫동안 응답이 없으면 승인이 취소되었음을 의미할 수 있습니다. 콘솔로 돌아가서 액세스를 다시 승인하세요.
