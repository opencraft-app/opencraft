# Bot 전환

## 요약

**Bot 전환을 사용하면 하나의 LightVela 클라우드 Agent에 여러 전문 Bot을 둘 수 있습니다. 조사, 계획, 코딩, 콘텐츠, 지원 또는 반복 작업을 위한 Bot을 만들고 Agent 프로필 메뉴에서 쉽게 전환할 수 있습니다.**

**각 Bot에는 고유한 작업 공간 컨텍스트가 있습니다. 빈 Bot을 만들지 기존 Bot을 복제할지에 따라 모델 설정, 메모리, Skills, 성격, 예약 작업 및 채널 연결의 상속 규칙이 달라집니다.**

## 시작하기 전

- LightVela에 로그인하고 실행 중인 클라우드 Agent를 엽니다.
- 추가 Bot을 만들려면 현재 요금제가 새 Bot을 허용하고 다른 Bot이 생성 또는 삭제 중이 아닌지 확인합니다.
- 채널을 연결하려면 해당 채널에 필요한 인증 정보 또는 인증 방법을 준비합니다.

## Bot 만들기

**새 Bot**을 선택한 뒤 아바타를 고르고 이름과 설명을 입력합니다. 그런 다음 빈 Bot을 만들지 기존 Bot을 복제할지 선택합니다.

다른 Bot이 이미 있으면 생성 대화 상자에 **현재 Bot 복사**, **기본 Bot 복사** 또는 **빈 Bot 만들기**가 표시될 수 있습니다.

예를 들어 금융 분석가 Bot을 만들려면 다음과 같이 입력할 수 있습니다.

> <strong>이름:</strong> Alpha Analyst
>
> <strong>설명:</strong> Alpha Analyst는 기업 보고서, 시장 뉴스, 포트폴리오 성과, 가치 평가 및 금융 위험 분석을 전문으로 합니다. 근거에 기반한 간결한 분석을 제공하고 사실과 가정을 명확하게 구분하며, 분석을 보장된 금융 조언으로 제시하지 않습니다.

![아바타 선택기, 이름 필드, 설명 필드 및 만들기 버튼이 있는 LightVela Bot 생성 양식](../../images/bots-switching-create.webp)

생성 화면에는 건강 관리자, 시장 관찰자 또는 AI 학습 친구처럼 역할별 템플릿이 표시될 수도 있습니다.

![건강 관리자, 시장 관찰자 및 AI 학습 친구가 포함된 LightVela Bot 생성 템플릿](../../images/bots-switching-templates.webp)

내용을 입력한 뒤 생성을 확인하고 새 Bot의 프로비저닝이 완료될 때까지 기다립니다.

## Bot 작업 공간 및 설정

생성 후 Bot에는 자체 설정 작업 공간이 열립니다. Agent 메인 페이지의 Bot 탭에서 Bot을 선택하고 메모리, Skills, 성격, 예약 작업 및 연결된 채널 등 해당 Bot에서 사용할 수 있는 설정을 관리할 수 있습니다.

![My Bots 영역에 Bot 카드가 표시된 LightVela Agent 개요](../../images/bots-switching-overview.webp)

생성 방식에 따라 새 Bot이 상속하는 내용이 결정됩니다.

| 생성 방식 | 상속되는 내용 | 별도로 시작되는 내용 |
| --- | --- | --- |
| 빈 Bot 만들기 | 기본 모델과 제공업체 인증 정보, 시스템 제공 Skills | 백업 모델, 기타 설정된 모델, 성격, 메모리, 기본 Bot에 나중에 설치한 Skills, 채널 및 예약 작업 |
| 현재 Bot 복사 또는 기본 Bot 복사 | 모델, 성격, Skills, 사용자 환경설정 및 장기 메모리 | 현재 대화, 이전 채팅 기록, 예약 작업, 런타임 상태 및 채널 연결 |

설정을 분리해야 한다면 확인하기 전에 생성 대화 상자의 상속 내용을 검토합니다. 생성 후에는 각 Bot의 [메모리](./memory.md), [Skills](./skill.md) 및 [예약 작업](./automation.md)을 독립적으로 관리할 수 있습니다.

## Bot을 독립적으로 만드는 이유

하나의 Bot으로 많은 작업을 처리할 수 있지만 책임이 늘어날수록 컨텍스트를 관리하기 어려워집니다. 전용 조사원, 여행 계획자, 금융 분석가 또는 품질 검사 Bot을 만들면 메모리, Skills, 성격 설정 및 예약 작업을 더 집중해서 관리할 수 있습니다.

독립적인 Bot을 사용하면 다른 작업에 사용 중인 Bot을 바꾸지 않고도 다른 작업 방식을 시험할 수 있습니다.

![선택할 수 있는 여러 Bot을 보여 주는 LightVela Bot 프로필 메뉴](../../images/bots-switching-selector.webp)

그 결과 LightVela 작업 공간을 더 체계적으로 관리할 수 있습니다. Bot을 전환하려면 Agent 작업 공간 왼쪽 위의 활성 Bot 프로필을 클릭한 다음 메뉴에서 다른 Bot을 선택합니다.

## 여러 Bot을 동시에 사용하는 방법

여러 Bot을 지원되는 메시징 채널에 연결할 수 있습니다. 사용할 수 있는 채널 조합은 LightVela 지역에 따라 다릅니다.

| LightVela 버전 | 여러 Bot 통합을 지원하는 채널 |
| --- | --- |
| 중국 버전 | QQ, WeCom, Lark, DingTalk |
| 글로벌 버전 | Telegram, Discord, Slack, QQ, WeCom, Lark |

WeChat 및 WhatsApp과 같은 채널에서는 현재 설정에 따라 인스턴스 하나에 하나의 Bot만 연결할 수 있습니다. 다른 Bot이 이미 채널을 소유하고 있으면 LightVela는 알림을 표시하고 해당 채널을 소유한 Bot을 관리할 수 있는 방법을 제공합니다.

![WeChat이 다른 Bot에 사용 중이며 하나의 Bot만 연결할 수 있음을 보여 주는 LightVela 알림](../../images/bots-switching-wechat.webp)

## Bot 전환 또는 채널 연결 확인

전환하거나 연결한 후 다음 항목을 확인합니다.

1. 활성 Bot의 이름과 아바타가 선택한 Bot으로 바뀝니다.
2. 설정 페이지에 선택한 Bot의 작업 공간과 구성이 표시됩니다.
3. 연결된 채널이 해당 연결을 소유한 Bot 아래에 표시됩니다.
4. 짧은 테스트 메시지가 원하는 Bot에 도착하고 응답을 반환합니다.

그룹 채널에서는 설정한 권한으로 테스트 메시지를 보내 Bot이 그룹 컨텍스트를 읽기만 하는지 또는 응답도 할 수 있는지 확인합니다.

## 일반적인 문제

| 문제 | 가능한 원인 | 해결 방법 |
| --- | --- | --- |
| **새 Bot**을 사용할 수 없음 | 요금제의 Bot 한도에 도달했거나 다른 Bot이 생성 또는 삭제 중임 | 현재 작업이 끝날 때까지 기다리거나 사용하지 않는 Bot을 삭제하거나 한도가 더 높은 요금제로 변경합니다 |
| 복제 옵션을 사용할 수 없음 | 복사할 유효한 현재 Bot 또는 기본 Bot이 없음 | **빈 Bot 만들기**를 선택하거나 대상 Bot으로 돌아간 뒤 생성 대화 상자를 엽니다 |
| Bot 목록을 일시적으로 사용할 수 없음 | Agent 인스턴스가 중지되었거나 Bot 목록 요청이 실패함 | Agent를 시작하거나 새로 고친 뒤 Bot 설정 페이지를 다시 불러옵니다 |
| 채널이 이미 다른 Bot에 연결됨 | 채널에 하나의 Bot만 소유할 수 있는 제한이 있음 | 알림에서 소유 Bot을 열거나 해당 채널 설정 페이지에 따라 연결을 해제하고 다시 연결합니다 |
| 그룹 메시지에 응답이 없음 | Bot의 그룹 권한 또는 채널 구성이 완전하지 않음 | 해당 [Telegram](./channel-telegram.md), [Discord](./channel-discord.md) 또는 다른 채널 설정 페이지를 확인한 뒤 다시 테스트합니다 |

## 그룹에서 Bot과 대화하기

지원되는 그룹 채팅에 여러 Bot을 초대할 수 있습니다. 설정한 권한에 따라 Bot은 그룹 컨텍스트를 읽거나 사용자 문의에 답하거나 두 작업을 모두 수행할 수 있습니다.

그룹 동작과 설정 단계는 플랫폼마다 다릅니다. Bot을 초대하기 전에 해당 채널 설정 페이지를 따르고 필요한 경우 직접 멘션 또는 플랫폼이 지원하는 다른 트리거로 Bot을 테스트합니다.
