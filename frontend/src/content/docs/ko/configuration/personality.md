# Soul

## 요약

**페르소나는 Hermes Agent 한 대의 일관된 역할, 말투, 우선순위, 행동 경계를 정의합니다.**

**에이전트의 Personality 설정에서 Soul을 선택하고 설명을 검토한 뒤 주입하면 에이전트의 `SOUL.md`가 업데이트됩니다.**

**에이전트에서는 한 번에 하나의 Soul만 활성화되며, 변경된 규칙을 불러오려면 Soul을 바꾼 뒤 새 대화를 시작해야 합니다.**

![LightVela 콘솔의 Soul 페르소나 카드](../images/soul-1.png)

## 이 페이지에서 다루는 내용

- Personality와 Soul이 제어하는 항목
- Soul 선택 및 주입
- 새 페르소나의 활성화 여부 확인
- 페르소나, 사용자 선호도, 메모리, 스킬을 구분해 관리하기
- 일반적인 제한 사항과 문제 해결 단계

## Personality가 제어하는 항목

Soul은 LightVela가 에이전트의 `SOUL.md`에 기록하는 선택된 페르소나입니다.
에이전트가 어떤 존재인지, 평소 어떤 방식으로 소통하는지, 무엇을 우선하는지, 어떤 경계를 지켜야 하는지를 정의합니다.

“결론을 먼저 말하기”, “불확실성을 분명히 밝히기”, “외부 작업을 수행하기 전에 확인받기”처럼 일관되게 적용할 지침은 Personality에 설정하세요.
변경되는 프로젝트 사실, 일회성 요청을 저장하거나 범용 클라우드 파일 편집기처럼 사용해서는 안 됩니다.

Personality는 하나의 대화 채널이 아니라 에이전트에 귀속됩니다.
같은 에이전트가 Telegram과 WhatsApp에 연결되어 있다면 두 채널에서 시작하는 새 대화가 모두 같은 활성 Soul을 사용합니다.

## 시작하기 전에

1. 페르소나를 설정할 Hermes Agent를 엽니다.
2. 결과를 확인할 수 있도록 에이전트에 모델과 사용 가능한 대화 채널이 하나 이상 있는지 확인합니다.
3. 역할, 대상 사용자, 말투, 우선순위, 항상 확인이 필요한 작업을 정합니다.

짧은 브리프만으로도 충분한 경우가 많습니다.
예: “근거보다 결론을 먼저 제시하고, 불확실성을 명시하며, 대화 외부로 무언가를 보내기 전에 확인하는 간결한 리서치 어시스턴트.”

## Soul 구성

### Personality 열기

1. LightVela 콘솔에서 **Agents**를 엽니다.
2. 설정할 Hermes Agent를 선택합니다.
3. 해당 에이전트 설정에서 **Personality** 섹션을 엽니다.

설정은 선택한 에이전트에만 적용됩니다.
다른 에이전트에 서로 다른 역할이나 말투를 적용하려면 먼저 해당 에이전트로 전환하세요.

### Soul 선택

사용 가능한 페르소나 유형을 살펴보려면 **Draw random soul**을 사용합니다.
소통 방식과 행동 선호도에 따른 추천을 받으려면 **Soul personality test**를 사용합니다.

![Draw random soul 대화 상자](../images/soul-2.png)

선택하기 전에 각 Soul 카드의 역할, 말투, 행동 설명, 경계를 검토하세요.
이름이나 어조만 보고 고르기보다 준비한 브리프와 일치하는 Soul을 선택하세요.

### Soul 주입

1. 사용할 Soul을 선택합니다.
2. **Inject soul**을 선택합니다.
3. Personality 섹션에서 주입 결과를 확인합니다.
4. 연결된 대화 채널로 돌아가 `/new`를 보냅니다.

주입에 성공하면 LightVela가 선택한 Soul을 현재 에이전트의 `SOUL.md`에 기록하며, 기존 페르소나를 교체하기 전에 백업을 보관합니다.
기존 대화에는 이전 페르소나 스냅샷이 남아 있을 수 있으므로 `/new`로 업데이트된 Soul을 읽는 새 대화를 시작합니다.

### 직접 만든 Soul 업로드

추천 카드 대신 적용할 Markdown 형식의 Soul이 이미 있을 때 이 옵션을 사용합니다.

1. LightVela 콘솔에서 대상 Hermes Agent를 선택합니다.
2. **Personality**에서 **Upload personality file**을 선택합니다.
3. Soul이 들어 있는 Markdown 파일을 선택합니다.
4. 내용을 검토하거나 편집한 뒤 **Inject**를 선택합니다.
5. 에이전트에 이미 Soul이 있다면 교체할 것인지 확인합니다.
6. 연결된 대화 채널로 돌아가 `/new`를 보냅니다.

![Upload persona file 대화 상자](../images/soul-3.png)

파일 이름이 반드시 `soul.md`일 필요는 없지만, `.md` 확장자를 사용하고 UTF-8로 인코딩되어야 하며 크기는 20KB 이하여야 합니다.
LightVela는 주입 전에 파일 내용을 보여 주므로 마지막으로 편집할 수 있습니다.
기존 Soul을 교체하면 LightVela가 백업을 만든 뒤 업로드한 콘텐츠를 선택한 에이전트의 `SOUL.md`에 기록합니다.

업로드는 에이전트가 선택된 경우에만 사용할 수 있습니다.
에이전트를 선택하지 않았거나 에이전트 샌드박스에 쓸 수 없어 추천 Soul의 다운로드 가능한 사본이 필요하다면 `soul.md` 파일을 로컬 대체 수단으로만 사용하세요.
이 대체 파일을 다운로드하는 것만으로는 에이전트가 업데이트되지 않습니다.

## 컨텍스트 유형별 올바른 저장 위치

| 저장 위치 | 용도 | 예시 |
| --- | --- | --- |
| Personality 및 `SOUL.md` | 일관된 역할, 말투, 우선순위, 행동 경계 | “불확실성을 명시하고 외부 메시지를 보내기 전에 확인한다.” |
| User Profile | 사용자의 정체성, 위치, 언어, 소통 선호도 | “기본적으로 영어를 사용하고 마감일을 먼저 표시한다.” |
| Memory | 변하는 사실, 결정, 장기 프로젝트 컨텍스트 | “현재 프로젝트 출시일은 금요일이다.” |
| Skills | 재사용 가능한 기능과 절차 | 웹 리서치, 파일 정리 또는 일일 보고 워크플로 |

[메모리 관리](./memory.md)에서 메모리와 사용자 프로필의 용량을 확인하세요.
새로운 페르소나 규칙이 아니라 새로운 기능이 필요하다면 [스킬 구성](./skill.md)을 사용하세요.
이러한 경계를 자세히 알아보려면 [Hermes Agent의 페르소나는 어디에서 오는가](../hermes-agent/10-persona-user-memory.md)를 참고하세요.

## Soul 활성화 확인

`/new`를 보낸 뒤 설정한 행동이 드러나는 몇 가지 요청으로 에이전트를 테스트합니다.

```text
What is your current role, main job, and default voice?
```

```text
How do you respond when you are uncertain about a fact?
```

```text
If I ask you to send a message to an external service, what do you do first?
```

새 대화에서 에이전트가 의도한 역할, 말투, 경계를 일관되게 따르면 새 Soul이 활성화된 것입니다.
채널별 안내가 필요하다면 [SOUL.md로 IM 에이전트의 역할, 페르소나, 말투를 정의하는 방법](../use-cases/im-agent-persona-soul-md.md)을 참고하세요.

## 일반적인 문제 해결

| 문제 | 가능한 원인 | 해결 방법 |
| --- | --- | --- |
| 답변이 여전히 이전 말투를 사용함 | Soul을 변경하기 전에 대화가 시작됨 | `/new`를 보낸 뒤 새 대화에서 행동을 다시 테스트합니다. |
| 선택한 Soul이 에이전트의 실제 업무와 맞지 않음 | 역할과 경계가 아니라 스타일만 보고 Soul 카드를 선택함 | Personality로 돌아가 카드 세부 정보를 검토하고 에이전트 브리프와 일치하는 Soul을 주입합니다. |
| 에이전트가 프로젝트 사실을 잊음 | 변경되는 사실을 Memory가 아니라 Personality에 배치함 | 일관된 규칙은 `SOUL.md`에 두고, 변경되는 사실은 Hermes에게 기억해 달라고 요청합니다. |
| 에이전트가 필요한 작업을 수행할 수 없음 | Personality는 행동을 정의할 뿐 기능을 추가하지 않음 | 출처와 권한을 검토한 뒤 적절한 스킬을 설치하거나 구성합니다. |
| 콘솔에서 적용하는 대신 `soul.md`를 다운로드함 | 에이전트를 선택하지 않았거나 에이전트 샌드박스에 새 설정을 쓸 수 없음 | 실행 중인 대상 에이전트를 선택하고 주입을 다시 시도합니다. 다운로드한 파일은 에이전트를 변경하지 않습니다. 콘솔에서 주입 성공을 확인한 뒤에만 `/new`를 보내세요. |
| 직접 만든 Soul을 업로드할 수 없음 | 에이전트를 선택하지 않았거나 파일이 20KB 이하의 유효한 UTF-8 Markdown 파일이 아님 | 대상 에이전트를 선택한 뒤 파일 요구 사항을 충족하는 `.md` 파일을 업로드합니다. |

## FAQ

### 한 에이전트에서 여러 Soul을 동시에 활성화할 수 있나요?

아니요.
한 에이전트에서는 한 번에 하나의 Soul만 활성화됩니다.
한 에이전트의 페르소나를 반복해서 교체하기보다 역할이 실제로 다를 때는 별도의 에이전트를 만드세요.

### 클라우드의 `SOUL.md`를 직접 편집할 수 있나요?

일반적인 사용에서는 클라우드 파일 시스템을 직접 조작할 필요가 없습니다.
Personality 설정은 Soul을 생성하고 주입하지만, 임의의 클라우드 파일을 위한 범용 편집기는 아닙니다.

### 기존 `SOUL.md`를 업로드할 수 있나요?

네.
**Upload personality file**에서 최대 20KB의 UTF-8 Markdown 파일을 선택하고, 검토하거나 편집한 뒤 선택한 에이전트에 주입하세요.
에이전트에 이미 Soul이 있다면 LightVela가 확인을 요청하고 교체 전에 백업을 보관합니다.

### Soul을 바꾸면 새로운 기능도 설치되나요?

아니요.
Soul은 에이전트가 행동하는 방식을 바꾸며, 스킬은 구체적인 기능과 재사용 가능한 절차를 추가합니다.

### 새 Soul을 적용하면 메모리나 채팅 기록이 삭제되나요?

아니요.
Soul을 주입하면 에이전트의 현재 페르소나 설정만 교체됩니다.
장기 메모리나 기존 대화 기록은 삭제되지 않습니다.
