# 모델 구성

## 요약

**모델 구성은 선택 사항입니다. 플랜에는 월간 모델 크레딧이 포함되므로 에이전트를 만들고 채널을 연결한 즉시 대화를 시작할 수 있으며, 크레딧을 모두 사용한 뒤에 자체 모델을 구성해도 됩니다. 콘솔의 모델 섹션에서는 모델 Coding Plan(월간 또는 연간 구독으로 사용량이 많은 경우에 적합), 모델 API(사용량 기반 결제로 가벼운 사용이나 무료 체험에 적합), 사용자 지정 모델(OpenAI 호환 엔드포인트 연결)의 세 가지 옵션을 제공합니다. 세 방식 모두 해당 프로바이더에서 발급한 API 키가 필요합니다. 소스를 선택하고 모델을 지정한 뒤 API 키를 붙여넣고 기본 모델로 설정하세요. 이후 모델을 변경해도 메모리는 유지됩니다. API 키는 민감한 자격 증명입니다. 채팅방이나 공개 페이지에 게시하거나 Git 저장소에 커밋하지 마세요. 키가 노출되면 즉시 프로바이더 콘솔에서 폐기하거나 교체해야 합니다.**

---

이 페이지에서는 세 가지 구성 방법 간의 차이점, API 키를 얻는 방법, 콘솔 구성 단계, 지원되는 모델 및 모델 선택 지침을 포함하여 Hermes Agent에 대한 대규모 언어 모델을 구성하는 방법을 설명합니다.

> 💡 **구성은 선택 사항입니다**
>
> Launch 플랜에는 100 체험 크레딧이 포함되어 있습니다. Hermes Agent를 생성하고 채널을 연결한 후 바로 채팅을 시작할 수 있습니다. 크레딧이 소진된 후 모델을 구성합니다.

## 세 가지 구성 방법

콘솔 "모델" 카드의 첫 번째 수준 드롭다운은 세 가지 옵션을 제공합니다.

| 방법 | 결제 모드 | API 키 소스 | 사용 사례 |
| --- | --- | --- | --- |
| 모델 Coding Plan | 월간/연간 | 프로바이더 | 사용량이 많을 때 |
| 모델 API | 종량제 | 프로바이더 | 사용량이 적거나 무료 체험을 시작할 때 |
| 커스텀 모델 | 엔드포인트에 따라 다름 | 사용자 제공 | 해외 모델 또는 OpenAI 호환 엔드포인트 연결 |

> ⚠️ **나만의 API 키 준비**
>
> 세 가지 방법 모두 사용자가 직접 발급받은 API 키가 필요합니다. 먼저 해당 프로바이더에 가입하고 키를 생성하세요.

---

## API 키를 얻기 위한 일반적인 프로세스

프로바이더마다 화면은 다르지만 일반적인 절차는 같습니다.

1. **프로바이더 웹사이트 방문**: 콘솔의 모델 카드에서 모델을 선택하면 아래에 "API 키 가져오기" 링크가 나타납니다. 클릭하면 프로바이더 웹사이트가 열립니다.

2. **등록 또는 로그인**: 대부분의 중국 플랫폼은 WeChat 또는 전화번호 로그인을 지원합니다.

3. **실명 인증 완료**: 중국 모델 프로바이더는 일반적으로 API 호출을 허용하기 전에 실명 인증을 요구합니다.

4. **API 키 관리 페이지 열기**: 일반적으로 "콘솔 → API 관리 / 키 관리 / 자격 증명"에서 찾을 수 있습니다.

5. **새 키 생성**: 키 이름을 지정하고(예: `LightVela`) 생성 후 즉시 복사합니다. 대부분의 플랫폼은 전체 키를 한 번만 표시합니다.

6. **LightVela로 돌아가서 키를 붙여넣으세요**


> ⚠️ **API 키는 민감한 자격 증명입니다**
>
> 키를 채팅방에 보내거나 웹 페이지에 게시하거나 Git 저장소에 커밋하지 마세요. 키가 유출되면 프로바이더 콘솔에서 즉시 폐기하거나 재발급하세요.

## 콘솔에서 구성

콘솔에 들어가서 "모델" 버튼을 엽니다.

### 구성 단계

1. **소스 선택**(첫 번째 드롭다운): 모델 API / 모델 Coding Plan / 사용자 지정 모델

2. **모델 선택**(두 번째 드롭다운): 앞에서 선택한 소스에 따라 사용 가능한 모델이 표시됩니다.

3. **API 키 입력**: 발급받은 키를 붙여넣습니다. 오른쪽의 눈 아이콘으로 키 표시 여부를 전환할 수 있습니다.

4. **"기본값으로 추가"를 클릭하세요**

5. 해당 항목이 "현재 모델" 목록에 나타나면 구성이 완료된 것입니다.


![](../images/5-1.webp)

### 사용자 정의 모델에 대한 추가 필드

"사용자 지정 모델"을 선택하면 일반적으로 API 키 외에 다음 필드도 입력해야 합니다.

- **기본 URL**: 모델 서비스 API 주소(예: `https://api.openai.com/v1`)

- **모델 이름**: 모델 식별자(예: `gpt-4o` 또는 `claude-3-5-sonnet-20241022`)


실제 필드는 콘솔 인터페이스에 따라 달라집니다.

> 💡 **사용자 정의 모델을 구성하는 방법(예: OpenAI GPT, Google Gemini 등)**
>
> MiniMax, Kimi, Zhipu GLM처럼 콘솔에 표시된 모델 외에도 "사용자 지정 모델"을 통해 목록에 없는 OpenAI GPT, Google Gemini, Claude 등의 모델을 구성할 수 있습니다.

## 모델 전환

### 전환 방법

구성 단계를 다시 진행하세요. 새로 "기본값으로 추가"를 실행하면 이전 구성을 덮어씁니다.

> ⚠️ **하나의 모델만 활성화됩니다**
>
> 현재 각 Hermes Agent에는 활성 모델이 하나만 있을 수 있습니다. 다양한 모델 성능을 비교하려면 별도로 구성하고 사용해 보세요.

### 메모리에 미치는 영향

모델을 전환해도 대화 메모리는 영향을 받지 않습니다. 메모리는 Hermes Agent에 저장되며, 모델은 응답 생성만 담당합니다.

## 선택 안내

우선순위별 선택 기준은 다음과 같습니다.

| 우선순위 | 제안된 방향 |
| --- | --- |
| 무료 할당량 | 많은 프로바이더가 신규 계정에 무료 할당량을 제공합니다. 무료 체험부터 시작해 보세요 |
| 긴 컨텍스트 처리 | 더 큰 컨텍스트 창이 있는 모델 선택(예: Moonshot AI) |
| 응답 속도 | 프로바이더마다 차이가 크므로 실제 사용 결과를 기준으로 선택하세요 |
| 중국어 이해 | 중국어 모델은 일반적으로 중국어를 더 잘 지원합니다. |
| 사용량이 많음 | 해당 프로바이더의 월간 Coding Plan을 선택하세요 |

권장 사항: 먼저 여러 대화에 Launch 플랜 체험 크레딧을 사용하세요. Hermes Agent가 정상적으로 작동하는지 확인한 후 어떤 모델을 사용할지 결정하세요.

## FAQ

| 이슈 | 가능한 원인 | 솔루션 |
| --- | --- | --- |
| 키를 입력한 후에도 "현재 모델"이 비어 있습니다 | 키 형식이 잘못되었거나 공백이 포함되어 있습니다 | 키를 다시 복사해 붙여넣고 앞뒤에 공백이 없는지 확인하세요 |
| 메시지를 보낸 후 오랫동안 응답이 없습니다 | 프로바이더 잔액이 부족하거나 키가 비활성화되었습니다 | 프로바이더 콘솔에서 잔액과 키 상태를 확인하세요 |
| 응답 내용이 깨졌거나 의미가 없습니다. | 사용자 정의 모델 엔드포인트는 OpenAI 프로토콜과 호환되지 않습니다. | 먼저 다른 OpenAI 호환 클라이언트로 엔드포인트 가용성을 확인하세요. |
| "모델 응답 시간 초과" | 프로바이더의 속도 제한 또는 네트워크 불안정 | 나중에 다시 시도하거나 다른 프로바이더로 전환하세요 |
| 사용자 정의 모델의 기본 URL이 확실하지 않습니다. | — | 해당 서비스 API 문서를 확인하세요. 보통 `https://xxx.com/v1`입니다 |

### 대화 오류 "HTTP 401:InvalidAuthentication" 또는 유사한 401 오류

OpenClaw와 대화하는 동안 `HTTP 401:InvalidAuthentication` 또는 다른 `401 xxx` 오류가 나타나는 경우 이는 일반적으로 다음 중 하나로 인해 발생합니다.

1. 모델 API 키가 잘못 구성되었습니다.

2. 사용자가 Coding Plan API 키와 일반 모델 API 키를 혼동했습니다.

3. 모델 프로바이더의 국내 또는 국제 버전을 잘못 선택했습니다.


이런 일이 발생하면 모델 구성을 다시 확인하세요.
