# 채널 - QQ 구성

## 요약

**QQ 채널은 매개변수를 직접 입력해 연결합니다. QQ Open Platform에서 봇을 만들고 AppID와 AppSecret을 발급받은 뒤 LightVela 콘솔의 채널 섹션에 붙여넣으세요. 전체 과정은 약 5~10분이 걸립니다. 봇 관리자로 사용할 QQ 계정과 구성된 모델(또는 플랜에 포함된 월간 모델 크레딧)이 필요합니다. WeChat, WeCom, Lark가 QR 코드 스캔으로 연결되는 것과는 방식이 다릅니다. 연결된 QQ 에이전트는 다른 채널과 동일한 페르소나와 장기 메모리를 공유합니다.**

---

QQ 채널을 사용하려면 QQ Open Platform에서 봇을 만든 뒤 발급된 **AppID**와 **AppSecret**을 LightVela에 입력해야 합니다. 전체 과정은 약 5~10분이 걸립니다.

## 이 페이지에서는 다음을 다루고 있습니다.

- QQ Open Platform에 봇 등록 및 생성

- AppID 및 AppSecret 얻기

- 통합을 완료하려면 LightVela에 자격 증명을 입력하세요.

- QQ에서 Hermes Agent와 채팅 중


> 💡 **전제 조건**
>
> - QQ 계정(봇 관리자 역할을 하기 위해)
>
> - [모델 구성](./model.md) 완료(또는 Launch 플랜에 포함된 100 체험 크레딧 사용)
>

## 단계

### 1. 콘솔에 들어가세요

LightVela에 로그인하고 오른쪽 상단의 "My Hermes"를 클릭하여 콘솔에 들어간 후 "채널" 버튼을 찾으세요.

### 2. QQ 채널을 선택하세요.

드롭다운을 클릭하고 "QQ"를 선택합니다. QQ 채널 소개는 아래에 나와 있습니다.

![](../images/qq1.webp)

### 3. QQ Open Platform에 등록하세요

[QQ Open Platform](https://q.qq.com/qqbot/openclaw/)을 방문하여 QQ 모바일 앱으로 페이지의 QR 코드를 스캔하여 등록/로그인하세요. 처음 방문 시 스캔하면 자동으로 등록되고 현재 QQ 계정이 오픈 플랫폼 계정에 바인딩됩니다.

QQ 모바일 앱을 스캔하고 **동의**를 선택하면 등록이 완료되고 QQ 봇 구성 페이지로 들어갑니다.

### 4. QQ 봇 생성

QQ Open Platform의 봇 페이지에서 "봇 생성"을 클릭하여 새로운 QQ 봇을 생성합니다.

![](../images/qq2.webp)

### 5. AppID 및 AppSecret 획득

봇이 생성된 후 페이지에서 **AppID** 및 **AppSecret**을 찾습니다. 각 항목 옆에 있는 "복사" 버튼을 클릭하고 로컬 메모 파일에 저장하세요.

![](../images/qq3.webp)

> ⚠️ **AppSecret은 민감한 자격 증명입니다**
>
> - 보안상의 이유로 **AppSecret은 일반 텍스트로 다시 볼 수 없습니다. 다시 보면 강제로 재설정됩니다**. 처음 생성되면 즉시 저장하세요.
>
> - 채팅 그룹, 공개 웹 페이지에 붙여넣거나 Git 저장소에 커밋하지 마세요.
>
> - 유출된 경우 즉시 QQ Open Platform의 "Reset Secret"에서 재설정한 후 LightVela에 새 자격 증명을 다시 입력하세요.
>

생성 후 QQ는 자동으로 봇을 메시지 목록에 추가하고 환영 메시지를 보냅니다. 이 시점에서 봇은 아직 LightVela에 바인딩되지 않았습니다. 메시지를 보내면 "이 봇은 화성에 갔습니다. 나중에 다시 시도하십시오"라는 메시지가 반환됩니다. 이는 정상이므로 다음 단계를 계속하십시오.

### 6. LightVela에 자격 증명을 입력합니다.

콘솔 "채널" 카드로 돌아가 드롭다운에서 "QQ"를 선택하고 방금 복사한 자격 증명을 붙여넣습니다.

1. **AppID**: 복사한 AppID를 붙여넣으세요.

2. **AppSecret**: 복사한 AppSecret을 붙여넣습니다.


![](../images/qq4.webp)

### 7. "추가 및 적용"을 클릭하세요.

LightVela는 위의 자격 증명을 사용하여 QQ Open Platform에서 봇을 연결합니다. 수십 초 후에 페이지에 "저장됨"이 표시되고 "QQ" 항목이 "연결된 채널" 목록에 나타납니다.

### 8. QQ에서 Hermes Agent를 찾으세요.

QQ를 열고 방금 생성한 봇을 찾은 후 테스트 메시지를 보냅니다.

```
Hello
```

몇 초 내에 Hermes Agent 응답을 받게 됩니다.

![](../images/qq5.webp)

> ✅ **QQ 그룹 멘션이 지원됩니다**
>
> QQ 바인딩이 성공하면 LightVela는 기본적으로 Hermes' QQ 그룹 채팅 정책을 활성화합니다. QQ 그룹에 봇을 추가한 다음 이를 언급하여 대화를 시작하세요. 기본 정책은 `open`입니다. 이는 봇이 포함된 QQ 그룹의 구성원이 채팅에서 이를 언급할 수 있음을 의미합니다. 멘션이 없는 일반 그룹 메시지는 대화를 시작하지 않습니다.

## 성공 상태

- 봇은 QQ Open Platform에서 생성되었습니다.

- "QQ" 항목이 콘솔의 "연결된 채널" 목록에 나타납니다.

- QQ의 봇은 AI를 사용하여 올바르게 응답합니다.

- 언급될 때 봇은 QQ 그룹으로 응답합니다.

## 지원되는 메시지 유형

통합 후 QQ 봇은 기본 텍스트 이상의 기능을 지원합니다. 전체 목록:

| QQ 봇 — 지원되는 메시지 유형 및 기능 | 지원됨 |
| --- | --- |
| 문자 메시지 받기 | ✅ 예 |
| 이미지 수신 | ✅ 예 |
| 파일 받기 | ✅ 예 |
| 음성 메시지 받기 | ✅ 예 |
| 문자 메시지로 답장하기 | ✅ 예 |
| 이미지로 답장하기 | ✅ 예 |
| 파일로 답장하기 | ✅ 예 |
| 답장 콘텐츠는 마크다운을 지원합니다. | ✅ 예 |
| 사전에 메시지 보내기(예: 예약된 알림) | ✅ 예 |
| 과거 메시지 인용 | ❌ 아직은 아니다 |

> ℹ️ **실제 성능은 모델에 따라 다릅니다**
>
> 위 표에는 QQ 봇이 채널 레이어에서 수신하고 응답할 수 있는 내용만 반영되어 있습니다. 이미지/파일 처리와 같은 작업이 실제로 작동하는지 여부는 Hermes Agent에 연결된 기본 LLM이 해당 기능을 지원하는지 여부에 따라 다릅니다.

## 채널 노트

- **메시지 유형**: 텍스트, 이미지, 파일, 음성 등 - 위의 '지원되는 메시지 유형'을 참조하세요.

- **그룹 채팅 지원**: 그룹 멘션은 바인딩 후 기본적으로 활성화됩니다. 콘솔은 `open` 정책을 적용하여 봇이 포함된 QQ 그룹의 구성원이 채팅에서 이를 언급할 수 있도록 허용합니다. 선택한 그룹에 대한 액세스를 제한하려면 Hermes 인스턴스 구성을 `allowlist`로 전환하고 거기에서 허용 목록을 유지하십시오. 채널 카드는 아직 이 스위치를 노출하지 않습니다.

- **자격 증명 관리**: AppSecret은 생성 시 일반 텍스트로만 표시됩니다. 분실 또는 유출된 경우 재설정해야 합니다.
