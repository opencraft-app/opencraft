# 워크벤치

## 요약

**My Workbench를 사용하면 LightVela에서 AI Agent로 정적 웹사이트를 만들고 배포하고 관리할 수 있습니다. 시작 템플릿을 선택하거나 사이트를 처음부터 설명한 다음 Agent와 함께 결과를 다듬어 게시할 수 있습니다.**

![My Workbench 개요](../images/workbench-01.png)

배포가 끝나면 공개 주소와 현재 상태를 확인하고 기존 워크벤치를 한곳에서 관리할 수 있습니다.

Beta 안내: My Workbench는 Beta 기능이므로 기능이 발전하면서 생성 및 배포 과정이 변경될 수 있습니다.

## My Workbench가 하는 일

My Workbench는 Agent 채팅과 관리형 정적 웹사이트 작업 흐름을 연결합니다.
직접 워크벤치 "worksite"를 시작하거나 제공된 템플릿 중 하나를 선택하고, Agent와 대화하며 내용을 다듬은 뒤 전용 링크로 사이트를 미리 볼 수 있습니다.

![My Workbench 페이지](../images/workbench-02.png)

LightVela가 호스팅 과정을 관리하므로 별도의 호스팅 서버나 클라우드 계정을 설정할 필요가 없습니다.

## My Workbench 열기

1. [https://lightvela.ai/agents/](https://lightvela.ai/agents/)를 엽니다.
2. 왼쪽 탐색 메뉴에서 My Workbench를 엽니다.

Workbench 페이지에는 현재 사용량, 이용 가능한 템플릿, 기존 워크벤치가 표시됩니다.

## 시작 템플릿 선택

시작 템플릿을 사용하면 분명한 방향으로 시작할 수 있습니다.
만들려는 웹사이트 유형에 따라 템플릿을 선택할 수 있습니다.

- Clean Utility Dashboard: 양식, 정보 조회, 가벼운 내부 도구.
- Data Dashboard: 핵심 지표, 추세, 비즈니스 개요, 일일 보고서.
- Campaign Landing Page: 캠페인 페이지, 가입 페이지, 교환 페이지.
- Personal Showcase: 포트폴리오, 개인 홈페이지, 서비스 소개.

템플릿을 선택하면 준비된 요청이 포함된 Agent 채팅이 열립니다.

![시작 템플릿](../images/workbench-03.png)

빈 옵션을 선택하고 Agent가 단계별로 요구 사항을 확인하도록 할 수도 있습니다.

## Agent 채팅으로 Workbench 만들기

1. 시작 템플릿을 선택하거나 빈 워크벤치로 시작합니다.
2. 웹사이트의 목적, 대상 사용자, 콘텐츠, 시각적 방향을 설명합니다.
3. Agent가 요구 사항을 확인하며 묻는 질문에 답합니다.
4. 생성된 결과를 검토하고 Agent에게 변경을 요청합니다.
5. 웹사이트가 준비되면 Agent에게 최신 버전 게시를 요청합니다.

현재 작업 흐름은 생성된 웹사이트에 React, TypeScript, Tailwind CSS 및 일반적인 UI 라이브러리를 사용합니다.

![Agent 채팅으로 Workbench 만들기](../images/workbench-04.png)

Agent는 콘텐츠를 편집 가능하게 유지하고 미리 입력된 가상 비즈니스 데이터를 사용하지 않으며, 임시 로컬 데이터가 적절한 경우 브라우저 로컬 저장소를 사용하도록 안내됩니다.

## Workbench 상태 확인

각 워크벤치에는 방문할 준비가 되었는지 확인할 수 있는 배포 상태가 있습니다.

| 상태 | 설명 |
| --- | --- |
| Building | 웹사이트를 생성하거나 준비하는 중입니다. |
| Publishing | 최신 버전을 게시하는 중입니다. |
| Online | 공개 주소에서 웹사이트를 이용할 수 있습니다. |
| Update failed | 최신 생성 또는 게시 시도가 실패했습니다. |
| Offline | 웹사이트를 이용할 수 없거나 삭제되었습니다. |

워크벤치가 Online 상태이고 공개 주소가 있으면 Visit을 선택해 엽니다.

![Workbench 상태와 웹사이트 미리 보기](../images/workbench-05.png)

워크벤치가 아직 Building 또는 Publishing 상태라면 처리가 끝날 때까지 기다리고 필요하면 페이지를 새로 고칩니다.

## 기존 Workbench 관리

기존 워크벤치 목록에는 웹사이트 이름, 공개 주소, 생성일, 현재 상태가 표시됩니다.

워크벤치를 업데이트하려면 Agent 채팅으로 돌아가 원하는 변경 사항을 설명합니다.
변경 결과를 검토한 뒤 Agent에게 업데이트된 버전의 게시를 요청합니다.

워크벤치를 삭제하려면 다음 단계를 따릅니다.

1. 목록에서 워크벤치를 찾습니다.
2. 삭제 작업을 선택합니다.
3. 삭제를 확인합니다.

워크벤치를 삭제하면 즉시 오프라인으로 전환되고 관련 파일이 제거됩니다.
이 작업은 취소할 수 없습니다.

## Workbench 할당량 및 호스팅 제한

Workbench 한도는 요금제에 따라 다릅니다.

- Launch 요금제: 워크벤치 1개를 만들 수 있습니다.
- 상위 요금제: 워크벤치를 최대 5개까지 만들 수 있습니다.

한도에 도달했다면 새 워크벤치를 만들기 전에 기존 워크벤치를 삭제하거나 요금제를 업그레이드합니다.

## 자주 발생하는 문제

| 문제 | 가능한 원인 | 해결 방법 |
| --- | --- | --- |
| Workbench 페이지에서 로그인을 요청함 | 세션이 만료되었습니다. | 다시 로그인하고 My Workbench를 엽니다. |
| 새 워크벤치를 만들 수 없음 | 요금제 한도에 도달했을 수 있습니다. | 사용량을 확인하거나 사용하지 않는 워크벤치를 삭제합니다. |
| 상태가 Building 또는 Publishing에서 바뀌지 않음 | 배포가 아직 처리 중입니다. | 잠시 기다린 뒤 페이지를 새로 고칩니다. |
| Visit 작업을 사용할 수 없음 | 워크벤치가 아직 Online이 아닙니다. | 상태가 Online으로 바뀔 때까지 기다립니다. |
| 상태가 Update failed로 바뀜 | 최신 생성 또는 게시 시도가 실패했습니다. | Agent 응답을 확인하고 필요한 변경을 적용한 뒤 다시 시도합니다. |
| 다른 브라우저에서 웹사이트 데이터가 사라짐 | 데이터가 브라우저 로컬 저장소에 저장되었습니다. | 공유 또는 영구 데이터가 필요하면 백엔드 서비스를 사용합니다. |
| 삭제한 워크벤치가 목록에 계속 표시됨 | 삭제가 아직 처리 중입니다. | 정리가 끝날 때까지 기다린 뒤 페이지를 새로 고칩니다. |

## 현재 제한

My Workbench는 Agent 채팅을 통해 정적 웹사이트를 만들고 호스팅하기 위한 기능입니다.
서버 측 저장소, 관리형 데이터베이스, 영구 양식 처리, 공유 계정 또는 임의의 백엔드 서비스는 제공하지 않습니다.
워크벤치 수, 트래픽, 저장 공간, 패키지 크기, 파일 수는 활성 요금제에 따라 달라집니다.

## FAQ

### 어떤 종류의 웹사이트를 만들 수 있나요?

대시보드, 내부 도구, 캠페인 페이지, 포트폴리오, 랜딩 페이지 및 기타 정적 프론트엔드 웹사이트를 만들 수 있습니다.

### 코딩 경험이 필요한가요?

아니요.
자연어로 원하는 내용을 설명하면 Agent가 요구 사항 확인, 생성, 게시 과정을 안내합니다.

### 기존 워크벤치를 업데이트할 수 있나요?

예.
Agent 채팅으로 돌아가 변경 사항을 설명하고 결과를 검토한 뒤 Agent에게 업데이트된 버전의 게시를 요청합니다.

### 웹사이트에서 데이터를 저장할 수 있나요?

정적 웹사이트는 현재 브라우저의 로컬 저장소에 데이터를 임시로 저장할 수 있습니다.
LightVela는 Workbench 웹사이트에 서버 측 영구 저장소를 제공하지 않습니다.

### 별도의 호스팅 계정이 필요한가요?

아니요.
LightVela가 정적 워크벤치를 위한 호스팅 작업 흐름을 제공합니다.

### 워크벤치를 바로 사용할 수 없는 이유는 무엇인가요?

생성과 게시에는 시간이 걸릴 수 있습니다.
현재 상태를 확인하고 Online으로 바뀐 뒤 공개 주소를 엽니다.
