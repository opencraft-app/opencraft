# 채널 - WeCom 구성

## 요약

**WeCom 채널은 QR 코드로 연결하며 WeChat과 함께 설정이 가장 간단한 채널입니다. 기업 업무 환경에서 Hermes Agent를 사용하는 데 적합합니다. 콘솔의 채널 섹션에서 WeCom을 선택하고 인증을 눌러 QR 코드를 생성한 뒤 휴대폰의 WeCom으로 스캔하면 대화를 시작할 수 있습니다. WeCom이 설치된 휴대폰과 구성된 모델(또는 플랜에 포함된 월간 모델 크레딧)이 필요합니다. 하나의 에이전트를 여러 채널에 동시에 연결해 동일한 페르소나와 장기 메모리를 공유할 수 있습니다.**

---

WeCom 채널은 QR 코드 액세스를 사용하며 구성이 가장 간단한 채널입니다.

## 이 페이지에서는 다음을 다루고 있습니다.

- LightVela에서 WeCom 액세스 QR 코드 생성

- 휴대폰에서 WeCom으로 QR 코드 스캔

- WeCom에서 Hermes Agent와 채팅 중


> 💡 **전제 조건**
>
> - WeCom이 설치된 전화기
>
> - [모델 구성](./model.md) 완료(또는 Launch 플랜에 포함된 100 체험 크레딧 사용)
>

---

## 단계

### 1. 콘솔에 들어가세요

LightVela에 로그인하고 오른쪽 상단의 "My Hermes"를 클릭하여 콘솔에 들어간 후 "채널" 버튼을 찾으세요.

### 2. WeCom 채널을 선택하세요.

WeCom 모듈을 찾아 "+ 연결"을 클릭하세요.

### 3. '액세스 승인'을 클릭하세요.

페이지에 QR 코드가 나타납니다.

![](../images/wecom1-en.webp)

> ⚠️ **QR 코드 만료**
>
> QR 코드는 몇 분 후에 만료됩니다. 만료되면 대화 상자를 닫고 "액세스 승인"을 다시 클릭하여 새 QR 코드를 생성하세요.

### 4. 휴대폰에서 WeCom으로 스캔하세요.

1. 휴대폰에서 WeCom을 엽니다.

2. 오른쪽 상단의 '+'를 탭하고 → '스캔'을 탭하세요.

3. 컴퓨터 화면에서 QR 코드를 스캔하세요.


![](../images/wecom2.webp)

4. 인증을 완료하려면 휴대전화의 안내를 따르세요.

![](../images/wecom3.webp)

![](../images/wecom4.webp)

### 5. 생성된 봇과 채팅

성공적인 스캔 후:

- 대화 상자가 자동으로 닫히고 생성된 봇 페이지로 이동됩니다.

- WeCom은 자동으로 연락처에 봇을 추가합니다.


봇의 채팅 창을 열고 테스트 메시지를 보냅니다.

```
Hello
```

몇 초 내에 Hermes Agent 응답을 받게 됩니다.

![](../images/wecom5-en.webp)

---

## 성공 상태

- "WeCom" 항목이 콘솔의 "연결된 채널" 목록에 나타납니다.

- 봇은 WeCom 연락처에서 찾을 수 있습니다.

- 메시지를 보내면 Hermes Agent 응답을 받습니다.


---

## 지원되는 메시지 유형

통합 후 WeCom 봇은 기본 텍스트 이상의 기능을 지원합니다. 전체 목록:

| WeCom 봇 — 지원되는 메시지 유형 | 지원됨 |
| --- | --- |
| 문자 메시지 받기 | ✅ 예 |
| 이미지/동영상 수신 | ✅ 예 |
| 파일 받기 | ✅ 예 |
| 음성 메시지 받기 | ✅ 예 |
| 문자 메시지로 답장하기 | ✅ 예 |
| 이미지/동영상으로 답장하기 | ✅ 예 |
| 파일로 답장하기 | ✅ 예 |
| 사전에 메시지 보내기(예: 예약된 알림) | ✅ 예 |

> ℹ️ **실제 성능은 모델에 따라 다릅니다**
>
> 위 표에는 WeCom 봇이 채널 레이어에서 수신하고 응답할 수 있는 내용만 반영되어 있습니다. 이미지/파일 처리와 같은 작업이 실제로 작동하는지 여부는 Hermes Agent에 연결된 기본 LLM이 해당 기능을 지원하는지 여부에 따라 다릅니다.

## FAQ

| 증상 | 가능한 원인 | 해상도 |
| --- | --- | --- |
| WeCom은 스캔 후 "잘못된 QR 코드"를 표시합니다. | QR 코드가 만료되었습니다 | 대화상자를 닫고 "액세스 승인"을 다시 클릭하세요. |
| 스캔 후 바탕화면에 응답이 없습니다. | 네트워크 지연 또는 승인이 아직 완료되지 않았습니다. | 상태를 확인하려면 콘솔 페이지를 새로 고치십시오. 연결되지 않은 경우 다시 시도하세요. |
| WeCom에서 봇 연락처를 찾을 수 없습니다. | '서비스 알림' 아래에 접힌 메시지 | WeCom 상단에서 "LightVela" 또는 Hermes Agent 이름을 검색하세요. |
| 메시지를 보낸 후 응답이 없습니다. | 모델이 구성되지 않았거나 체험 크레딧이 소진되었습니다. | "1. 모델" 카드에서 "현재 모델" 상태를 확인하세요. |
| 연결을 끊는 방법 | — | "연결된 채널" 목록에서 항목을 삭제합니다. |
| 단일 WeCom 계정이 여러 Hermes Agent 인스턴스에 연결할 수 있나요? | Launch 플랜은 1 Hermes Agent로 제한됩니다. | 해당 없음 |

## 채널 노트

- **메시지 유형**: 텍스트, 이미지, 동영상, 파일, 음성 등 - 위의 '지원되는 메시지 유형'을 참조하세요.

- **그룹 채팅 지원**: 현재 그룹 채팅은 지원되지 않습니다. 1:1 대화만 가능

- **연결 끊김**: 응답하지 않는 기간이 길면 일반적으로 승인이 취소되었음을 의미합니다. 콘솔에서 다시 승인하세요.
