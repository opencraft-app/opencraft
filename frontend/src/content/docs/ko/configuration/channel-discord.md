# 채널 - Discord 구성

## 요약

**Discord 채널은 봇 인증 방식으로 연결합니다. Hermes Agent를 Discord 서버에 추가해 질문에 답하거나 업무를 지원하고 커뮤니티 활동을 돕는 데 적합합니다. Discord 개발자 포털에서 애플리케이션과 봇을 만들고 자격 증명을 발급받아 LightVela 콘솔의 채널 섹션에 붙여넣은 다음, 대상 서버에 봇을 초대하세요. 관리자 권한이 있는 Discord 서버와 구성된 모델(또는 플랜에 포함된 월간 모델 크레딧)이 필요합니다. 연결된 Discord 에이전트는 다른 채널과 동일한 페르소나와 장기 메모리를 공유합니다.**

Discord 채널은 봇 인증 방식으로 연결합니다. Hermes Agent를 Discord 서버에 추가하면 채널에서 질문에 답하고 업무를 지원하거나 커뮤니티 구성원과 상호 작용할 수 있습니다.

## 이 페이지에서는 다음을 다루고 있습니다.

- Discord에서 초대 링크 열기 및 인증 완료

- Discord 서버 또는 채널에서 Hermes Agent와 채팅


> 💡 **전제 조건**
>
> - 로그인이 가능한 Discord 계정
>
> - 봇을 추가할 수 있는 Discord 서버
>
> - [모델 구성](./model.md) 완료(또는 Launch 플랜에 포함된 100 체험 크레딧 사용)
>

## 단계

### 1. 콘솔에 들어가세요

LightVela에 로그인하고 오른쪽 상단의 "My Hermes"를 클릭하여 콘솔에 들어간 후 "채널" 버튼을 찾으세요.

### 2. Discord 채널을 선택하세요.

Discord 카드를 찾아 "+ 연결"을 클릭하세요.

### 3. Discord를 열고 개발자 포털로 이동합니다.

봇을 추가하려는 서버를 선택한 다음 [개발자 포털](https://discord.com/developers/home)로 이동합니다.

1. 애플리케이션을 클릭하세요.

![](../images/discord-1-global.webp)

2. 오른쪽 상단 모서리에 있는 새 애플리케이션을 클릭합니다.

3. 애플리케이션 이름을 지정하세요.

4. 애플리케이션에 봇을 추가하고 봇 토큰을 생성합니다. 토큰은 Hermes Agent와 Discord 서버 간의 연결을 인증하는 데 사용됩니다.

![](../images/discord-2-global.webp)

5. 토큰을 Discord 카드에 붙여넣습니다.

![](../images/discord-3-global-en.webp)

### 4. 개발자 포털의 봇 페이지로 이동합니다.

Bot 페이지에서 Privileged Gateway Intents까지 아래로 스크롤하고 다음을 활성화합니다.

- **메시지 콘텐츠 의도**: 필수, 메시지 콘텐츠를 읽는 데 사용됩니다.

- **서버 구성원 의도**: 권장, 역할 목록 및 ID와 일치하는 이름에 사용됩니다.

- **현재 상태 의도**: 선택 사항, 상태 업데이트에만 사용됩니다.

![](../images/discord-4-global.webp)

활성화한 후 하단의 변경 사항 저장을 클릭합니다.

### 5. 개발자 포털의 OAuth2 페이지로 이동합니다.

봇 권한 구성: 왼쪽 사이드바에서 OAuth2를 클릭한 다음 OAuth2 URL 생성기를 선택합니다. 먼저 범위를 구성하십시오. 최소 권한 원칙에 따라 `bot` 및 `applications.commands`를 선호합니다.

![](../images/discord-5-global.webp)

계속해서 아래로 스크롤하여 봇 권한을 구성하고 다음을 선택합니다.

- 채널 보기

- 메시지 보내기

- 메시지 기록 읽기

- 링크 포함

- 파일 첨부

- 반응 추가(선택 사항)

![](../images/discord-6-global.webp)

### 6. 초대링크 복사 및 열기

생성된 초대 링크를 복사하여 브라우저에서 열고 Discord 서버에 봇을 초대합니다(서버 관리자 권한 필요). 계속을 클릭하고 승인하면 봇이 서버에 초대됩니다.

![](../images/discord-7-global.webp)

### 7. Discord에서 새로운 봇과 채팅

이제 봇과 상호작용을 시작할 수 있습니다. 봇과의 채팅을 열고 테스트 메시지를 보냅니다.

```
Hi
```

![](../images/discord-chat-global.webp)

몇 초 내에 Hermes Agent 응답을 받게 됩니다.

## 성공 상태

- 콘솔의 "연결된 채널" 목록에 "Discord"가 포함되어 있습니다.

- 해당 봇은 Discord 연락처에서 찾을 수 있습니다.

- Hermes Agent는 메시지를 보낸 후 응답합니다.


---

## 지원되는 메시지 유형

액세스가 성공한 후 Discord 봇은 기본 문자 메시지를 수신하고 응답할 수 있으며 다음과 같이 더 많은 메시지 유형을 지원합니다.

| Discord 봇이 지원하는 메시지 유형 | 지원됨 |
|---|---|
| 문자 메시지 받기 | ✅ 지원됨 |
| 이미지 및 비디오 수신 | ✅ 지원됨 |
| 파일 받기 | ✅ 지원됨 |
| 문자 메시지로 답장하기 | ✅ 지원됨 |
| 이미지와 동영상으로 답장하기 | ✅ 지원됨 |
| 파일로 답장하기 | ✅ 지원됨 |
| 사전에 메시지 보내기(예: 예약된 알림) | ✅ 지원됨 |

> ℹ️ **실제 처리 능력은 모델에 따라 다릅니다**
>
> 위 표는 채널 레이어에서 Discord 봇이 지원하는 메시지 유형만 나타냅니다. 이미지, 파일 및 기타 작업을 실제로 처리할 수 있는지 여부는 Hermes Agent에 연결된 대형 언어 모델에 해당 기능이 있는지 여부에 따라 달라집니다.

## FAQ

| 이슈 | 가능한 원인 | 솔루션 |
|---|---|---|
| Discord 봇을 생성할 수 없습니다 | Discord 개발자 포털에 들어가지 않았거나 애플리케이션 생성 흐름이 완료되지 않았습니다. | Discord 개발자 포털에 들어가서 애플리케이션을 만든 다음 봇을 추가하세요. |
| 봇 토큰을 찾을 수 없습니다 | 토큰이 생성되지 않았거나 전체가 복사되지 않았습니다. | Bot 페이지에서 토큰 재설정/토큰 복사를 클릭한 다음 전체 토큰을 토큰 필드에 붙여넣습니다. |
| 붙여넣은 후 토큰이 유효하지 않은 것으로 표시됩니다. | 토큰이 불완전하거나 추가 공백/줄바꿈이 포함되어 있습니다. | 전체 봇 토큰을 다시 복사하고 추가 공백이 없는지 확인하세요. |
| 봇을 서버에 초대할 수 없습니다 | OAuth2 URL이 잘못 구성되었거나 계정에 서버 관리자 권한이 부족합니다. | OAuth2 URL 생성기에서 `bot` 범위를 선택하고 서버에 대한 관리자 권한이 있는지 확인하세요. |
| 초대 후 봇이 서버에 나타나지 않습니다. | 초대가 완료되지 않았거나 봇이 온라인 상태가 아닙니다. | 초대 링크를 다시 열어 인증이 성공했는지 확인하세요. Discord 서버 구성원 목록 새로 고침 |
| 메시지를 보낸 후 응답이 없습니다. | 모델이 구성되지 않았거나 체험 크레딧이 소진되었거나 Discord 채널이 성공적으로 연결되지 않았습니다. | "1. 모델" 카드에서 "현재 모델" 상태를 확인하고 Discord 채널이 연결된 것으로 표시되는지 확인하세요. |
| 봇이 메시지 내용을 읽을 수 없습니다. | 메시지 콘텐츠 의도가 활성화되지 않았습니다. | Discord 개발자 포털의 봇 설정에서 메시지 콘텐츠 의도를 활성화합니다. |
| 봇은 채널에 응답할 권한이 없습니다. | 채널 권한이 부족합니다. | 봇에 채널 보기, 메시지 보내기, 메시지 기록 읽기 및 기타 필요한 권한이 있는지 확인하세요. |
| 봇은 직접 메시지를 받을 수 없습니다. | DM 권한 또는 사용자 개인정보 설정 제한 | 봇이 DM을 허용하는지 확인하고 사용자의 Discord 개인 정보 보호 설정을 확인하세요. |
| 연결을 해제하는 방법 | — | "연결된 채널" 목록에서 해당 Discord 레코드를 삭제합니다. |
| 동일한 Discord 봇이 여러 Hermes Agent 인스턴스에 연결할 수 있나요? | 권장되지 않습니다. 하나의 봇 토큰은 하나의 Hermes Agent에 바인딩되어야 합니다. | 여러 Hermes Agent 인스턴스가 필요한 경우 별도의 Discord 봇을 생성하세요. |

## 채널 노트

- **메시지 유형**: 텍스트, 이미지, 동영상, 파일, 음성 메시지 등을 지원합니다. 위의 '지원되는 메시지 유형'을 참조하세요.

- **그룹 채팅 지원**: 그룹 채팅은 현재 지원되지 않습니다. 1:1 대화만 지원됩니다.

- **연결 중단**: 오랫동안 응답이 없으면 승인이 취소되었음을 의미할 수 있습니다. 콘솔로 돌아가서 액세스를 다시 승인하세요.
