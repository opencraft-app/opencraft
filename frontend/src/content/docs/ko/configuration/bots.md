# Bot 관리

## 요약

**Bot은 Hermes Agent 안의 독립 프로필입니다. 기본 Bot은 Agent와 함께 생성되며, 추가 Bot마다 모델 설정, 페르소나, 메모리, Skills, 채널, 예약 작업을 따로 가질 수 있습니다. Bot을 만들 때는 기존 Bot을 복사하거나 Basic setup을 선택합니다. 기본 Bot을 포함해 만들 수 있는 Bot 수는 플랜에 따라 결정됩니다.**

> **국제 사이트 제공 상태**
>
> 추가 Bot 생성 기능은 단계적으로 제공되고 있습니다. 이 기간에는 국제 사이트에서 **Create Bot** 진입점이 기본적으로 표시되지 않습니다. 진입점을 사용할 수 없으면 기본 Bot을 계속 사용하세요.

## 이 페이지에서 다루는 내용

- Hermes Agent와 Bot의 관계
- 기존 Bot 복사 또는 Basic setup을 통한 Bot 생성
- 각 생성 방식에서 상속되는 항목
- Bot 전환, 이름 변경, 삭제

## 시작하기 전에

1. Hermes Agent가 실행 중인지 확인합니다.
2. 플랜에 추가 Bot을 위한 여유가 있는지 확인합니다. 한도에는 기본 Bot도 포함됩니다.
3. **Agents**를 열고 관리할 Agent를 선택합니다.

## Bot 생성

생성 진입점을 사용할 수 있는 경우:

1. **New Bot**을 선택합니다.
2. 60자 이하의 Bot 이름을 입력합니다.
3. 생성 방식을 선택합니다.
4. 상속 요약을 검토한 뒤 **Confirm creation**을 선택합니다.
5. 새 Bot의 프로비저닝이 끝난 다음 구성하거나 사용합니다.

표시되는 복사 옵션은 현재 선택한 Bot에 따라 달라집니다. 기본 Bot에서는 **Copy current (main Bot)**이 표시됩니다. 추가 Bot에서는 **Clone current** 또는 **Clone main Bot**을 선택할 수 있습니다.

## 생성 방식 선택

| 방식 | 상속됨 | 상속되지 않음 |
| --- | --- | --- |
| Copy current, Clone current 또는 Clone main Bot | 선택한 원본 Bot의 모델, 페르소나, Skills, 사용자 환경설정, 장기 메모리 | 현재 대화, 채팅 기록, 예약 작업, 런타임 상태, 채널 연결 |
| Basic setup | 기본 Bot의 현재 기본 모델과 Provider 인증 정보, 내장 시스템 Skills | 대체 모델, 그 밖의 구성된 모델, 페르소나, 메모리, 기본 Bot에 나중에 설치한 Skills, 채널, 예약 작업 |

**Basic setup은 빈 Bot이 아닙니다.** 시작하는 데 필요한 최소 모델 및 내장 Skill 구성을 유지하면서 개인별 동작, 메모리, 연동을 분리합니다.

## 새 Bot 확인

프로비저닝이 끝난 뒤:

1. 입력한 이름으로 새 Bot 탭이 표시되는지 확인합니다.
2. 새 Bot을 선택하고 모델과 Skills가 선택한 생성 방식과 일치하는지 확인합니다.
3. [Soul](./personality.md)을 추가하거나 [Skills](./skill.md)을 설치하거나 채널을 연결하거나 [예약 작업](./automation.md)을 만들기 전에 관련 구성 페이지를 엽니다.

## 여러 Bot 사용

Bot 탭은 Agent 콘솔 상단에 표시됩니다. 모델 설정, 페르소나, 메모리, Skills, 채널, 예약 작업 또는 진단을 변경하기 전에 대상 Bot 탭을 선택하세요.

각 Bot은 자체 프로필과 데이터를 가집니다. 한 Bot의 변경 사항이 다른 Bot에 자동으로 반영되지는 않습니다. 콘솔의 **Chat** 기능은 현재 기본 Bot에서만 사용할 수 있으며, Agent 단위 유지 관리도 기본 Bot에서 수행해야 합니다.

Bot 이름을 변경하려면 해당 Bot을 선택하고 표시 이름을 편집합니다. 새 이름은 60자 이하여야 합니다.

## Bot 삭제

- 추가 Bot을 삭제하면 해당 Bot의 프로필과 데이터가 영구적으로 삭제됩니다.
- 해당 Bot이 소유한 채널을 먼저 연결 해제합니다.
- 기본 Bot을 삭제하기 전에 추가 Bot을 모두 삭제합니다.
- 기본 Bot을 삭제하면 모든 채팅, 구성, 설치된 Skills, 메모리, 관련 데이터를 포함한 Agent 전체가 삭제됩니다.

삭제는 되돌릴 수 없습니다. 확인 메시지를 주의 깊게 읽고 요청된 Bot 이름을 입력한 뒤 확인하세요.

## 문제 해결

### 다른 Bot을 만들 수 없는 이유는 무엇인가요?

국제 사이트의 단계적 제공 중에 생성 진입점이 숨겨져 있거나, 현재 Agent 버전에서 다중 Bot 기능을 사용할 수 없거나, Agent가 실행 중이 아니거나, 플랜의 Bot 한도에 도달했을 수 있습니다.

### 복사한 Bot에 대화, 작업 또는 채널이 없는 이유는 무엇인가요?

이 항목들은 의도적으로 복사되지 않습니다. 필요에 따라 새 Bot에서 채널을 다시 연결하고 예약 작업을 다시 만드세요.

### Basic setup에도 모델과 Skills가 표시되는 이유는 무엇인가요?

Basic setup은 기본 Bot의 현재 기본 모델과 Provider 인증 정보를 상속하고 내장 시스템 Skills만 유지합니다. 기본 Bot의 다른 모델, 페르소나, 메모리, 나중에 설치한 Skills, 채널 또는 예약 작업은 복사하지 않습니다.
