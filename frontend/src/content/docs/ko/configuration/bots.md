# Bot 관리

## 요약

**Bot은 Hermes Agent 안의 독립 프로필입니다. 기본 Bot은 Agent와 함께 생성되며, 추가 Bot마다 모델 설정, 페르소나, 메모리, Skills, 채널, 예약 작업을 따로 가질 수 있습니다. Bot을 만들 때는 기존 Bot을 복사하거나 Basic setup을 선택합니다. 기본 Bot을 포함해 만들 수 있는 Bot 수는 플랜에 따라 결정됩니다.**


## 이 페이지에서 다루는 내용

- Hermes Agent와 Bot의 관계
- 기존 Bot 복사 또는 Basic setup을 통한 Bot 생성
- 각 생성 방식에서 상속되는 항목
- Bot 전환, 이름 변경, 삭제

## 시작하기 전에

1. Hermes Agent가 실행 중인지 확인합니다.
2. 플랜에 추가 Bot을 위한 여유가 있는지 확인합니다. 한도에는 기본 Bot도 포함됩니다.
3. **Agents**를 열고 관리할 Agent를 선택합니다.

## Bot 생성

추가 Bot을 만들려면 생성 기능을 사용할 수 있고 플랜 한도에 여유가 있을 때 **새 Bot**을 선택합니다. **이름**은 필수이고 **설명**은 선택 사항입니다. 필요하면 외형을 조정하세요. 기본 선택은 **빈 Bot 만들기**입니다. 복사할 수 있는 Bot이 있으면 **고급**을 열고 특정 원본 Bot을 선택합니다. 사용 중인 Bot을 복사하려면 **Bot 관리 → Bot 복사**를 엽니다. 생성 양식에서 해당 원본이 미리 선택됩니다. 원본을 확인하고 **만들기**를 선택한 뒤 완료될 때까지 기다립니다.

닫기와 고급 복사 옵션은 유효한 원본 Bot이 있을 때만 표시됩니다. 원본이 없는 첫 설정은 완료해야 합니다. 외형 설정은 색상, 모양, 액세서리를 변경하며 복사 원본을 선택하지 않습니다.

## 생성 방식 선택

| 방식 | 상속됨 | 상속되지 않음 |
| --- | --- | --- |
| Bot 복사 | 선택한 원본 Bot의 모델, 페르소나, Skills, 사용자 환경설정, 장기 메모리 | 현재 대화, 채팅 기록, 예약 작업, 런타임 상태, 채널 연결 |
| 빈 Bot 만들기 | 기본 Bot의 현재 기본 모델과 Provider 인증 정보, 내장 시스템 Skills | 대체 모델, 그 밖의 구성된 모델, 페르소나, 메모리, 기본 Bot에 나중에 설치한 Skills, 채널, 예약 작업 |

**빈 Bot 만들기은 빈 Bot이 아닙니다.** 시작하는 데 필요한 최소 모델 및 내장 Skill 구성을 유지하면서 개인별 동작, 메모리, 연동을 분리합니다.

## 새 Bot 확인

생성이 끝나면 선택 메뉴에서 새 Bot 이름을 확인하고 해당 Bot의 웹 채팅에서 짧은 테스트 메시지를 보냅니다. 생성이나 초기 설정에 실패하면 표시된 재시도 작업을 따르고 다시 생성하기 전에 Bot 목록을 확인하세요. 답변이 없으면 Bot 상태와 모델 크레딧 또는 모델 설정을 확인합니다.

## 여러 Bot 사용

Bot 표시줄에서 원하는 Bot의 아바타를 선택합니다. 화면이 좁으면 먼저 탐색 패널을 여세요. 모델, 메모리, 스킬, 채널, 예약 작업을 바꾸기 전에 이름을 확인하세요. 웹 채팅과 대화 목록은 선택한 Bot에 속하며 추가 Bot도 웹 채팅을 사용할 수 있습니다. 웹 채팅에는 메시징 채널 연결이 필요하지 않습니다.

Bot 이름을 변경하려면 해당 Bot을 선택하고 표시 이름을 편집합니다. 새 이름은 60자 이하여야 합니다.

## Bot 삭제

- 추가 Bot을 삭제하면 해당 Bot의 프로필과 데이터가 영구적으로 삭제됩니다.
- 해당 Bot이 소유한 채널을 먼저 연결 해제합니다.
- 기본 Bot을 삭제하기 전에 추가 Bot을 모두 삭제합니다.
- 기본 Bot을 삭제하면 모든 채팅, 구성, 설치된 Skills, 메모리, 관련 데이터를 포함한 Agent 전체가 삭제됩니다.

삭제는 되돌릴 수 없습니다. 확인 메시지를 주의 깊게 읽고 요청된 Bot 이름을 입력한 뒤 확인하세요.

## 문제 해결

### 다른 Bot을 만들 수 없는 이유는 무엇인가요?

계정에 여러 Bot 생성 기능이 활성화되어 있는지, Agent가 실행 중인지, 플랜 한도에 여유가 있는지, 다른 생성이나 삭제가 진행 중인지 확인하세요.

### 복사한 Bot에 대화, 작업 또는 채널이 없는 이유는 무엇인가요?

이 항목들은 의도적으로 복사되지 않습니다. 필요에 따라 새 Bot에서 채널을 다시 연결하고 예약 작업을 다시 만드세요.

### Basic setup에도 모델과 Skills가 표시되는 이유는 무엇인가요?

Basic setup은 기본 Bot의 현재 기본 모델과 Provider 인증 정보를 상속하고 내장 시스템 Skills만 유지합니다. 기본 Bot의 다른 모델, 페르소나, 메모리, 나중에 설치한 Skills, 채널 또는 예약 작업은 복사하지 않습니다.
