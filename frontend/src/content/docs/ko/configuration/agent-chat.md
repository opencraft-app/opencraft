# 채팅

## 요약

**채팅 페이지는 LightVela 콘솔에 내장된 메시지 창으로, 외부 채널을 연결하지 않고도 Hermes Agent와 직접 대화할 수 있습니다. 모델을 설정한 직후 에이전트가 정상 작동하는지 확인할 때 유용합니다. 외부 메시징 채널과 동일한 에이전트, 동일한 페르소나, 동일한 장기 메모리를 공유하므로 여기에서 알려 준 선호도는 다른 채널에도 적용되며, 반대의 경우도 마찬가지입니다.**

"Chat" 페이지를 열어 채팅 창에서 Hermes Agent와 대화하세요.

## 대화 메모리

Hermes Agent는 대화가 이어지면서 스스로 발전과 진화를 거듭할 수 있습니다. "Memory" 페이지에서 메모리에 관해 자세히 알아보세요.

![](../images/agentchat-2-global-en.webp)

### 메모리 작동 방식

Hermes Agent는 다음 두 가지 메커니즘을 통해 장기 메모리를 자동으로 축적합니다.

- **컨텍스트 압축**: 긴 대화에서 핵심 정보를 추려 장기 메모리로 남깁니다.

- **핵심 메모리 노드**: 개인 선호도, 사용 습관, 나중에 다시 활용할 만한 프로젝트 관련 정보를 자동으로 포착합니다.

### 메모리 저장 방식

메모리는 다음 두 종류의 문서에 영구 저장됩니다.

- `MEMORY.md`: 프로젝트 정보, 실행 환경, 협업 규칙

- `USER.md`: 사용자의 개인 선호도, 사용 습관, 소통 방식

Hermes Agent가 이후 대화에서도 일관되고 개인화된 답변을 제공할 수 있도록 장기적인 가치가 있는 콘텐츠만 보관됩니다.
