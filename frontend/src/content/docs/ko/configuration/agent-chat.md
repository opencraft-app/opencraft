# 채팅

## 요약

**LightVela에 로그인하고 플랜을 활성화한 뒤에는 외부 메시징 채널을 먼저 연결하지 않아도 My Agent의 일상 채팅에서 선택한 Bot과 대화할 수 있습니다. 사이드바에는 해당 Bot의 대화가 표시되며 새 대화를 시작하거나 기존 대화를 이어갈 수 있습니다. 메시지를 보내기 전에 Bot이 온라인이고 플랜의 모델 크레딧을 사용할 수 있거나 모델이 설정되어 있는지 확인하세요.**

![LightVela 국제 콘솔의 새 Web Chat 대화](../../images/chat-overview-en.webp)

## 대화 시작하기

Google 또는 GitHub로 로그인하고 이용 가능한 플랜을 활성화한 뒤 [Agent 콘솔](/agents/overview/)을 엽니다. 첫 Bot 설정에서 필수 이름을 입력하고, 필요하면 설명을 추가하고 외형을 조정합니다. **만들기**를 선택한 뒤 생성과 초기 설정이 끝날 때까지 기다립니다. 설정이 완료되면 **여정 시작**을 선택하고 해당 Bot의 웹 채팅을 엽니다. 메시징 채널 연결은 선택 사항이며, 답변에는 사용 가능한 모델 크레딧이나 설정된 모델이 필요합니다.

1. My Agent를 열고 사이드바 상단에서 사용할 Bot을 선택합니다.
2. 일상 영역에서 채팅을 열고 새 대화를 선택합니다. 개요 페이지의 Bot 카드에서도 해당 Bot의 새 대화를 시작할 수 있습니다.
3. 입력창에 질문이나 작업을 적고 전송합니다.
4. 대화 화면에서 응답을 확인합니다. 새 대화를 열면 입력창이 바로 표시되어 먼저 작성할 수 있고, 전송은 연결이 완료된 뒤에 가능합니다. 기존 대화를 열 때는 잠시 로딩 문구가 표시될 수 있습니다.

웹 채팅에는 외부 채널이 필요하지 않습니다. 같은 Bot을 Telegram, WhatsApp, Discord 또는 WeChat에서 사용하려면 채널 화면에서 해당 서비스를 연결하세요.

## 대화 이어가기와 관리

선택한 Bot의 최근 대화가 채팅 아래에 표시됩니다. 제목을 누르면 이어갈 수 있고 더 보기를 누르면 이전 대화를 볼 수 있습니다. 각 대화의 메뉴에서 이름을 바꾸거나 삭제할 수 있습니다. Bot을 전환하면 해당 Bot의 대화 목록이 표시됩니다.

Hermes는 장기적으로 유용한 선호도와 프로젝트 정보를 필요에 따라 저장합니다. 선택한 Bot의 장기 메모리는 [메모리](./memory.md)에서 확인할 수 있으며 새 대화를 시작해도 지워지지 않습니다.

## 결과 확인과 문제 해결

- **정상 결과:** 보낸 메시지가 대화에 나타나고 Bot이 응답하며, 새로고침한 뒤에도 사이드바에서 대화를 다시 열 수 있습니다.
- **로딩 문구가 계속 보임:** Bot이 온라인인지 확인하고 페이지를 새로고침하세요. 입력창이 나타날 때까지 기다립니다.
- **보내거나 응답받을 수 없음:** 플랜의 모델 크레딧 또는 [모델 설정](./model.md)을 확인하고 Bot이 일시 중지되지 않았는지 살펴보세요. 웹 채팅에는 연결된 외부 채널이 필요하지 않습니다.
