# 첫 번째 Hermes 인스턴스를 활성화하려면 어떻게 해야 합니까?

## 요약

**Google 또는 GitHub로 로그인하고 이용 가능한 플랜을 활성화한 뒤 [Agent 콘솔](/agents/overview/)을 엽니다. 첫 Bot 설정에서 필수 이름을 입력하고, 필요하면 설명을 추가하고 외형을 조정합니다. 만들기를 선택한 뒤 생성과 초기 설정이 끝날 때까지 기다립니다. 설정이 완료되면 여정 시작을 선택하고 해당 Bot의 웹 채팅을 엽니다. 메시징 채널 연결은 선택 사항이며, 답변에는 사용 가능한 모델 크레딧이나 설정된 모델이 필요합니다.**

---

닫기와 고급 복사 옵션은 유효한 원본 Bot이 있을 때만 표시됩니다. 원본이 없는 첫 설정은 완료해야 합니다. 외형 설정은 색상, 모양, 액세서리를 변경하며 복사 원본을 선택하지 않습니다.

## 전제조건

- Google 또는 GitHub 계정

- [구독 페이지](/subscribe)에서 현재 사용 가능한 플랜을 선택하세요. 국제 사이트에서는 중국 본인 인증을 요구하지 않습니다.

- 메시징 앱에서 Bot을 사용할 경우에만 Telegram, WhatsApp, Discord, Slack 또는 WeChat 계정

## 활성화 흐름

### 1. Google 또는 GitHub로 로그인

LightVela를 열고 Google 또는 GitHub를 통해 액세스를 승인하세요. LightVela 계정은 처음 로그인 시 자동으로 생성되므로 별도의 비밀번호를 설정할 필요가 없습니다. 향후 방문 시 동일한 로그인 ID를 계속 사용하여 동일한 Hermes 인스턴스 및 데이터에 액세스하세요.

### 2. 구독 페이지에서 이용 가능한 플랜을 선택하세요.

[구독 페이지](/subscribe)를 열어 현재 사용 가능한 플랜과 할당량을 확인하세요. [플랜](./plans.md) 문서에서는 Launch와 Cruise의 리소스 구성을 설명하며, 현재 활성화할 수 있는 플랜은 구독 페이지에 표시된 내용을 기준으로 합니다.

국제 사이트에는 중국 본인 인증 절차가 없습니다. Google 또는 GitHub에 로그인한 후 현재 사용 가능한 플랜을 선택할 수 있습니다.

### 3. 현재 국제 사이트 절차에 따라 플랜을 활성화합니다.

[구독 페이지](/subscribe/)에서 이용 가능한 플랜을 선택하고 플랜 카드의 안내에 따라 활성화하세요. 첫 구매 혜택과 가격은 해당 페이지에서 확인할 수 있습니다.

### 4. 첫 Bot 설정 완료하기

Google 또는 GitHub로 로그인하고 이용 가능한 플랜을 활성화한 뒤 [Agent 콘솔](/agents/overview/)을 엽니다. 첫 Bot 설정에서 필수 이름을 입력하고, 필요하면 설명을 추가하고 외형을 조정합니다. **만들기**를 선택한 뒤 생성과 초기 설정이 끝날 때까지 기다립니다. 설정이 완료되면 **여정 시작**을 선택하고 해당 Bot의 웹 채팅을 엽니다. 메시징 채널 연결은 선택 사항이며, 답변에는 사용 가능한 모델 크레딧이나 설정된 모델이 필요합니다.

### 5. 에이전트 구성 및 깨우기

인스턴스가 준비되면 콘솔을 열고 기본 설정을 완료합니다.

1. **모델 확인** — 플랜 크레딧을 사용할 수 있다면 자체 API 키 없이 시작할 수 있습니다. 필요한 경우 [모델 구성](./configuration/model.md)을 참고하세요.

2. **웹 채팅 사용** — 일상 → 채팅에서 새 대화를 열고 메시지를 보냅니다. [채팅](./configuration/agent-chat.md)을 참고하세요.

3. **필요하면 채널 연결** — Telegram, WhatsApp, Discord, WeChat 등의 메시징 앱에서 Bot을 사용할 때 연결합니다.

4. **선택적으로 스킬 및 예약 작업 추가** — [예약 작업 구성](./configuration/automation.md)을 참고하세요.

귀하의 첫 번째 Hermes Agent는 이제 24/7 클라우드에서 온라인 상태를 유지할 준비가 되었습니다.

## FAQ

### 활성화 후 인스턴스를 얼마나 빨리 사용할 수 있나요?

생성이 끝나면 선택 메뉴에서 새 Bot 이름을 확인하고 해당 Bot의 웹 채팅에서 짧은 테스트 메시지를 보냅니다. 생성이나 초기 설정에 실패하면 표시된 재시도 작업을 따르고 다시 생성하기 전에 Bot 목록을 확인하세요. 답변이 없으면 Bot 상태와 모델 크레딧 또는 모델 설정을 확인합니다.

### 현재 플랜과 혜택은 어디에서 확인하나요?

현재 플랜, 첫 구매 혜택, 갱신 규칙은 [구독 페이지](/subscribe/)와 [플랜 안내](./plans.md)에서 확인하세요.

### 하나의 계정으로 몇 개의 Hermes 인스턴스를 활성화할 수 있습니까?

개수는 선택한 플랜의 에이전트 허용량에 따라 다릅니다. Launch 및 Cruise에는 각각 하나의 에이전트가 포함되어 있습니다. [플랜](./plans.md)을 참조하세요.

### 활성화 후에도 서버를 유지해야 합니까?

아니요. Hermes 인스턴스는 LightVela 관리형 클라우드 환경에서 실행됩니다. LightVela는 운영 및 24/7 가용성을 처리합니다. 웹 콘솔을 통해서만 에이전트를 구성할 수 있습니다.
