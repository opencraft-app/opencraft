# 첫 번째 Hermes 인스턴스를 활성화하려면 어떻게 해야 합니까?

## 요약

**첫 번째 Hermes 인스턴스를 만들려면 Google 또는 GitHub로 로그인하고 사용 가능한 플랜을 현재 규칙에 따라 활성화하세요. 플랫폼이 인스턴스를 자동으로 생성하면 모델과 채널을 설정합니다. 모든 과정은 브라우저에서 진행되므로 서버를 구매하거나 로컬에 배포할 필요가 없습니다. Hermes 인스턴스는 에이전트가 실행되는 클라우드 런타임이며 생성 후 24/7 온라인 상태를 유지합니다. 준비가 끝나면 "My Hermes" 콘솔에서 모델을 구성하고 메시징 채널을 연결하며 스킬을 설치하세요. 자체 모델 API 키가 없어도 플랜에 포함된 모델 크레딧으로 바로 대화를 시작할 수 있습니다.**

---

Hermes 인스턴스는 LightVela에서 에이전트가 실행되는 클라우드 런타임입니다. 첫 번째 인스턴스 활성화는 5단계를 따릅니다. **Google 또는 GitHub로 로그인 → 사용 가능한 플랜 선택 → 현재 활성화 흐름을 통해 활성화 → LightVela에서 인스턴스 프로비저닝 → 모델 및 채널 구성**. 서버 구매나 로컬 배포 없이 모든 작업이 브라우저에서 이루어집니다. 이 페이지에서는 프로세스를 순서대로 안내합니다.

## 이 페이지에서 다루는 내용

- 첫 번째 Hermes 인스턴스를 활성화하기 위한 전체 프로세스

- 각 단계의 전제 조건 및 중요 세부 사항

- 활성화 후 에이전트를 구성하고 사용하는 방법

## 전제조건

- Google 또는 GitHub 계정

- [구독 페이지](/subscribe)에서 현재 사용 가능한 플랜을 선택하세요. 국제 사이트에서는 중국 본인 인증을 요구하지 않습니다.

- 연결하려는 하나 이상의 메시징 계정(예: Telegram, WhatsApp, Discord, Slack 또는 WeChat)

---

## 활성화 흐름

### 1. Google 또는 GitHub로 로그인

LightVela를 열고 Google 또는 GitHub를 통해 액세스를 승인하세요. LightVela 계정은 처음 로그인 시 자동으로 생성되므로 별도의 비밀번호를 설정할 필요가 없습니다. 향후 방문 시 동일한 로그인 ID를 계속 사용하여 동일한 Hermes 인스턴스 및 데이터에 액세스하세요.

### 2. 구독 페이지에서 이용 가능한 플랜을 선택하세요.

[구독 페이지](/subscribe)를 열어 현재 사용 가능한 플랜과 할당량을 확인하세요. [플랜](./plans.md) 문서에서는 Launch와 Cruise의 리소스 구성을 설명하며, 현재 활성화할 수 있는 플랜은 구독 페이지에 표시된 내용을 기준으로 합니다.

국제 사이트에는 중국 본인 인증 절차가 없습니다. Google 또는 GitHub에 로그인한 후 현재 사용 가능한 플랜을 선택할 수 있습니다.

### 3. 현재 국제 사이트 절차에 따라 플랜을 활성화합니다.

LightVela는 공개 베타 버전에 진입하고 2026년 8월 18일(싱가포르 시간)에 청구를 시작할 계획입니다. 공개 베타 및 청구가 공식적으로 시작된 후 베타 사용자의 기존 플랜 유효 기간은 1개월 더 연장되며 신규 사용자는 Launch를 14일 동안 무료로 사용해 볼 수 있습니다. 플랜 카드의 메시지에 따라 활성화하고 최신 정보를 보려면 구독 페이지를 참조하세요.

### 4. LightVela가 인스턴스를 자동으로 프로비저닝하도록 합니다.

플랜이 활성화되면 LightVela가 **전용 클라우드 환경을 자동으로 할당하고 첫 번째 Hermes 인스턴스를 생성합니다**. 서버를 구입, 배포 또는 구성할 필요가 없습니다. 일반적으로 프로비저닝은 즉시 시작되며 인스턴스가 준비되면 콘솔을 열 수 있습니다.

### 5. 에이전트 구성 및 깨우기

인스턴스가 준비되면 콘솔을 열고 기본 설정을 완료합니다.

1. **모델 구성** — 기본 언어 모델을 선택합니다. [모델 구성](./configuration/model.md)을 참조하세요.

2. **채널 연결** — Telegram, WhatsApp, Discord, Slack, WeChat 또는 지원되는 다른 채널을 추가한 다음 메시징 앱에서 에이전트와 대화하세요.

3. **선택적으로 스킬 및 자동 작업을 추가하세요** — 에이전트의 기능을 확장하세요. [자동 작업 구성](./configuration/automation.md)을 참조하세요.

귀하의 첫 번째 Hermes Agent는 이제 24/7 클라우드에서 온라인 상태를 유지할 준비가 되었습니다.

## FAQ

### 활성화 후 인스턴스를 얼마나 빨리 사용할 수 있나요?

LightVela는 플랜 활성화 후 자동으로 Hermes 인스턴스 프로비저닝을 시작합니다. 인스턴스가 준비되면 콘솔에서 모델 및 채널을 구성하고 대화를 시작합니다.

### 청구가 시작된 후에는 어떻게 되나요?

공식적으로 청구가 시작된 후 베타 사용자의 기존 플랜 유효 기간이 1개월 더 연장됩니다. 신규 사용자는 14일 동안 Launch를 무료로 사용해 볼 수 있습니다. 최신 정보는 [구독 페이지](/subscribe)와 [LightVela 유료 버전 공지](./announcements/public-beta.md)에서 확인하세요.

### 하나의 계정으로 몇 개의 Hermes 인스턴스를 활성화할 수 있습니까?

개수는 선택한 플랜의 에이전트 허용량에 따라 다릅니다. Launch 및 Cruise에는 각각 하나의 에이전트가 포함되어 있습니다. [플랜](./plans.md)을 참조하세요.

### 활성화 후에도 서버를 유지해야 합니까?

아니요. Hermes 인스턴스는 LightVela 관리형 클라우드 환경에서 실행됩니다. LightVela는 운영 및 24/7 가용성을 처리합니다. 웹 콘솔을 통해서만 에이전트를 구성할 수 있습니다.
