# LightVela vs Mira: 개인 AI 에이전트를 운영하려면 어느 쪽이 적합할까요?

## 요약

**개인 루틴에 맞춘 하나의 Hermes Agent에 재사용 가능한 스킬, 예약 작업, 원하는 메시징 채널을 조합하고 싶다면 LightVela가 적합합니다.** 업무와 커뮤니티가 Telegram에 모여 있고, 대화를 후속 조치, 요약, 알림, 실행으로 연결하고 싶다면 Mira가 적합합니다.

두 제품 모두 채팅 창을 넘어선 지원을 지향하지만 출발점은 다릅니다. Mira는 Telegram 중심의 비서이고, LightVela는 더 넓은 워크플로 시스템으로 발전할 수 있는 구성형 개인 에이전트입니다.

![개인 AI 에이전트 운영을 위한 LightVela와 Mira 비교](../images/lightvela-vs-mira.png)

## 한눈에 비교하기

| 비교 항목 | LightVela | Mira |
| - | - | - |
| **가장 적합한 용도** | 오래 함께 사용하는 개인 AI 에이전트 | Telegram 안의 개인 또는 팀 비서 |
| **핵심 경험** | 하나의 에이전트를 루틴과 선호에 맞춰 구성 | 대화를 이해시키고 그 자리에서 행동을 요청 |
| **설정 중심** | 스킬, 예약 작업, 메모리, 페르소나, 모델, 채널 | Telegram 채팅, 그룹 컨텍스트, 연결 도구, 반복 동작 |
| **일상 가치** | 한 번의 대화를 넘어 계속 일하는 일관된 에이전트 | 채팅, 작업, 연결 도구 사이의 전환 감소 |
| **강점** | 시간이 지날수록 개선되는 개인 워크플로 | 대화에서 시작하는 후속 조치, 브리핑, 콘텐츠, 팀 조율 |

## 일상에서 달라지는 점

실용적인 차이는 한 번의 프롬프트에 대한 답변 품질이 아니라, 에이전트가 일상 어디에 존재하고 작동 방식을 얼마나 직접 설계하고 싶은지입니다.

LightVela에서는 클라우드의 Hermes Agent를 자신의 업무 방식에 맞춰 구성한 뒤, 필요가 달라져도 같은 에이전트와 계속 대화합니다. [스킬](../configuration/skill.md), [예약 작업](../configuration/automation.md), [모델](../configuration/model.md), 실제로 사용하는 채널을 조합해 일회성 대화를 계속 실행되는 워크플로로 바꿀 수 있습니다.

매일 브리핑, 반복 모니터링, 콘텐츠 초안, 알림 등을 매번 새로 만들 필요가 없습니다. LightVela는 하나의 에이전트와 계속 발전하는 하나의 설정을 중심으로 합니다.

[Mira](https://mira.tg/)는 다른 전제에서 시작합니다. Telegram 안에서 네이티브로 동작하므로 별도 앱을 열지 않고 개인 채팅, 그룹, 채널에서 사용할 수 있습니다. 대화 컨텍스트를 기억하고, 대화를 요약하고, 결정을 추적하고, 외부 도구를 연결하고, 메시지를 실제 행동으로 바꾸는 에이전트로 소개됩니다.

업무의 출발점이 이미 대화일 때 특히 자연스럽습니다. 팀은 Mira를 그룹에 추가하고, 결정 내용을 확인하고, 합의를 후속 작업으로 바꾸거나, Telegram을 떠나지 않고 브리핑을 요청할 수 있습니다. 별도의 개인 작업 공간을 구성하기보다 공유 채팅 안에서 업무를 위임하는 경험에 가깝습니다.

## LightVela가 더 적합한 경우

AI 에이전트를 개인 작업 환경의 지속적인 일부로 만들고 싶다면 LightVela가 적합합니다. 최신 메시지에 반응하게 하는 데 그치지 않고, 행동 방식, 지식, 사용할 기능, 실행 시점을 직접 설계할 수 있습니다.

매일 아침 정보 확인, 경쟁사 모니터링, 제품 업데이트를 소셜 초안으로 변환, 주간 리서치 요약 등을 맡길 수 있습니다. 핵심은 한 번의 완벽한 답변이 아니라 유용했던 상호작용을 계속 작동하는 시스템으로 만드는 것입니다.

스킬은 재사용 가능한 기능을 제공하고 예약 작업은 일정에 따라 반복 업무를 실행합니다. 아침 브리핑으로 시작해 리서치 스킬을 추가하고 가장 확인하기 쉬운 채널로 결과를 보낼 수 있습니다.

고정된 제품 경험보다 에이전트의 역할을 명시적으로 구성하고 싶을 때도 적합합니다. 모델, 유도할 행동, 추가 기능, 에이전트가 나타날 채널을 선택할 수 있습니다. [LightVela 개요](../01-overview.md)는 이러한 요소의 관계를 설명합니다.

LightVela는 계속 발전하는 하나의 개인 에이전트에 집중합니다. 주된 요구가 복잡한 Telegram 대화를 이해하고 그 자리에서 행동하는 것이라면 Mira가 더 즉각적일 수 있습니다.

## Mira가 더 적합한 경우

업무, 커뮤니티, 의사결정이 이미 Telegram에서 이루어진다면 Mira가 적합합니다. 공식 사이트는 콘텐츠, 받은 편지함, 암호화폐 모니터링, 쇼핑, 여행 계획, 알림, 연결 도구를 지원하는 Telegram 네이티브 비서로 설명합니다. 요청이 시작되는 채팅 안에 이미 필요한 컨텍스트가 있다는 점이 장점입니다.

팀과 커뮤니티에도 자연스럽습니다. 긴 그룹 대화를 요약하고, 미결정 사항을 드러내고, 발언을 담당자가 있는 후속 작업으로 바꿀 수 있습니다. 전용 작업 시스템보다 Telegram을 더 자주 사용하는 제품 팀, 창업자, 크리에이터, 커뮤니티 운영자에게 유용합니다.

Telegram 중심 모델에서도 일일 브리핑과 반복 워크플로를 지원할 수 있습니다. 적절한 시간의 요약, 리서치 작업, GitHub, Notion, Google Drive 같은 연결 서비스를 채팅에서 사용할 수 있어 답변에서 행동으로 옮길 때 화면 전환을 줄입니다.

경계는 Telegram에 대한 집중입니다. Telegram 안의 사회적 컨텍스트에는 강하지만, 하나의 에이전트에 페르소나, 모델, 스킬, 예약 작업, 여러 채널을 장기적으로 설계하려면 LightVela가 더 명시적인 제어 기능을 제공합니다.

## 어떤 제품을 선택해야 할까요?

LightVela가 적합한 조건:

- **하나의 개인 에이전트가 필요함:** 구성할수록 더 유용해지는 Hermes Agent를 원합니다.
- **연속성이 중요함:** 같은 에이전트가 설정을 유지하며 계속 사용 가능해야 합니다.
- **루틴을 직접 구성함:** 스킬과 반복 예약 작업을 자신의 습관에 맞추고 싶습니다.
- **유연하게 접근함:** 워크플로에 맞는 여러 채널에서 사용하고 싶습니다.
- **직접 제어함:** 모델, 페르소나, 기능, 워크플로 형태를 관리하고 싶습니다.

Mira가 적합한 조건:

- **Telegram이 활동의 중심임:** 개인 업무, 팀 결정, 커뮤니티 활동이 채팅에서 이루어집니다.
- **대화 메모리가 필요함:** 누가 무엇을 말했고 어떤 일이 남았는지 이해해야 합니다.
- **빠르게 위임함:** 메시지를 알림, 작업, 요약, 초안, 연결 도구 실행으로 바꾸고 싶습니다.
- **그룹에서 공유함:** 개인 및 그룹 대화에 참여하는 공유 비서가 필요합니다.
- **설정을 최소화함:** 별도 작업 공간을 구성하기 전에 바로 대화를 시작하고 싶습니다.

결론적으로 **개인 루틴에 맞춰 발전하는 하나의 AI 에이전트에는 LightVela, Telegram이 대화·업무·후속 조치의 중심이라면 Mira가 적합합니다.**
