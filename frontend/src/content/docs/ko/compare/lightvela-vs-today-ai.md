# LightVela vs Today.AI: 항상 실행되는 개인 AI 비서에는 어느 쪽이 적합할까요?

## 요약

**메시징 앱에서 접근하고, 여러 모델과 스킬을 구성하고, 자동 작업을 예약할 수 있는 실용적인 상시 온라인 AI 에이전트가 필요하다면 LightVela가 적합합니다.** 일상의 개인 데이터와 선제적인 제안을 중심으로 한 앱 기반 개인 운영 체제를 원한다면 Today.AI가 적합합니다.

LightVela의 문서화된 제품 모델은 클라우드에서 호스팅되는 Hermes Agent를 중심으로 합니다. Today.AI의 공개 포지셔닝은 개인 컨텍스트, 선제적인 지원, 기기 간 경험을 강조합니다. LightVela는 지속형 에이전트 호스팅과 명시적인 제어가 더 이해하기 쉬우며, Today.AI는 사용자의 삶을 계속 이해하고 요청하기 전에 행동하는 실험적인 비전을 제시합니다.

![상시 개인 AI 비서를 위한 LightVela와 Today.AI 비교](../images/lightvela-vs-today-ai.png)

## 한눈에 비교하기

이 표는 제품 형태와 일상적인 소유 방식을 비교하며, 벤치마크나 가격의 우열을 판단하지 않습니다. Today.AI에 공개된 정보는 LightVela의 제품 문서보다 아직 제한적입니다.

| 비교 항목 | LightVela | Today.AI |
| - | - | - |
| **제품 형태** | 클라우드 호스팅 Hermes Agent | 개인 AI 비서 및 AI 네이티브 OS 비전 |
| **주요 접근 방식** | 메시징 채널과 웹 콘솔 | 네이티브 앱과 기기 간 경험 |
| **메모리** | 대화를 이어 가는 지속형 에이전트 메모리 | 개인 컨텍스트에서 구성되는 살아 있는 메모리 |
| **선제적 작업** | 명시적인 자동 작업과 예약 작업 | 사용자가 요청하기 전에 행동하도록 설계 |
| **확장성** | 모델, 채널, 스킬, 자동 작업 | 모델과 생태계 세부 사항은 개발 중 |
| **적합한 사용자** | 지금 사용할 수 있는 상시 에이전트를 원하는 사용자 | 선제적인 개인 OS를 탐색하는 얼리어답터 |

## 일상에서 달라지는 점

가장 간단한 차이는 비서가 어디에 존재하는지입니다. LightVela는 Hermes Agent를 클라우드에서 실행하고 Telegram, WhatsApp, Discord, Slack, WeChat 같은 채널을 통해 같은 에이전트에 접근하게 합니다. Today.AI는 기기와 서비스에서 컨텍스트를 수집하고, 중요한 정보를 정리하고, 적절한 시점에 제안하는 개인 운영 계층에 가깝게 소개됩니다.

월요일 아침을 예로 들면, Today.AI의 공개 [랜딩 페이지](https://today.ai/landing)는 일정, 건강 신호, 프로젝트, 관계, 끝내지 못한 목표를 연결한 모닝 브리프를 제시합니다. 살아 있는 메모리, 선제적 제안, 앱 커넥터, 클라우드 컴퓨터, 기기 간 제어도 같은 비서 경험의 일부로 설명합니다.

LightVela에서는 비서의 작업 환경을 더 명시적으로 정의합니다. 모델을 연결하고, 채널을 선택하고, [스킬](../configuration/skill.md)을 설치하고, [자동 작업](../configuration/automation.md)으로 알림, 요약, 반복 리서치를 예약합니다. 사용자의 하루 전체를 관찰하는 운영 체제보다는 직접 형태를 정하는 신뢰 가능한 에이전트에 가깝습니다.

이 차이는 신뢰와 예측 가능성에도 영향을 줍니다. LightVela에서는 어떤 기능과 일정을 사용할지 사용자가 결정합니다. Today.AI는 더 넓은 컨텍스트를 이해해 다음에 중요할 일을 파악하고 적절한 순간에 개입하는 것을 목표로 합니다. 한쪽은 명확한 제어 화면을 제공하고, 다른 쪽은 삶을 더 많이 이해함으로써 유용해지는 주변형 비서를 지향합니다.

## LightVela가 더 적합한 경우

LightVela의 강점은 운영 방식이 명확하다는 점입니다. 지속형 에이전트를 위한 서버 설정, 컨테이너 유지 관리, 계속 켜 두어야 하는 로컬 컴퓨터가 필요 없습니다. [LightVela 개요](../01-overview.md)는 개인 기기와 독립적으로 사용 가능한 클라우드 호스팅 Hermes Agent를 설명합니다.

메모리와 선제적 작업은 에이전트가 계속 사용 가능할 때 의미가 있습니다. 노트북 기반 비서는 기기가 잠들거나 네트워크가 바뀌거나 교체되면 사용할 수 없을 수 있습니다. LightVela는 독립적으로 실행되므로 예약 작업과 이후 대화가 개인 기기의 온라인 상태에 좌우되지 않습니다.

구성 경계도 명확합니다. Hermes Agent, 모델, 채널, 스킬, 자동 작업을 주요 구성 요소로 분리합니다. 여러 채널을 같은 에이전트에 연결해 메모리와 행동을 공유하고, 스킬로 특정 워크플로 기능을 추가할 수 있습니다.

에이전트를 다시 만들지 않고 모델을 바꾸고, 별도의 페르소나를 만들지 않고 채널을 추가할 수 있습니다. 자동 작업은 알림, 요약, 통지 같은 반복 업무의 예약 계층을 제공합니다. 이미 사용하는 커뮤니케이션 도구 안에서 같은 에이전트를 사용하고 싶을 때 특히 명확한 선택입니다.

## Today.AI가 더 적합한 경우

Today.AI의 강점은 제품의 포부입니다. 공개 자료는 살아 있는 메모리, 선제적 지원, 늘어나는 커넥터, 클라우드 컴퓨터, 기기 간 제어, 커뮤니티 스킬을 개인 중심 비서에 결합한다고 설명합니다.

이는 LightVela와 다른 출발점입니다. 사용자가 요청을 표현하기 전에 일정, 프로젝트, 건강 신호, 관계, 미완료 목표를 연결해 하루의 형태를 이해하려 합니다.

네이티브 앱과 여러 기기에서의 도움을 선호하는 사람에게도 흥미롭습니다. 공개 자료는 사용자가 이미 쓰는 기기를 넘나드는 경험과, 제안만으로 부족한 작업에서 브라우저, 파일, 코드를 처리하는 클라우드 컴퓨터를 설명합니다. 커뮤니티 스킬은 재사용 가능한 워크플로를 추가하는 수단으로 제시됩니다.

다만 성숙도와 공개 범위를 고려해야 합니다. Today.AI의 공개 홈페이지는 현재 방문자를 대기자 명단으로 안내하고, 이용약관은 기능이 바뀔 수 있는 얼리 액세스 베타로 설명합니다. 구체적인 모델과 생태계 정보도 아직 발전 중이므로, 널리 제공되고 완전히 투명한 플랫폼 단계는 아닙니다.

따라서 개인 운영 계층의 가능성을 탐색하려는 얼리어답터에게 자연스러운 선택입니다. 문서화된 설정 경로, 예측 가능한 구성 경계, 지금 사용할 수 있는 클라우드 에이전트가 필요하다면 LightVela가 더 명확합니다.

## 어떤 제품을 선택해야 할까요?

LightVela가 적합한 조건:

- **항상 실행되는 에이전트가 필요함:** 노트북이나 휴대전화가 깨어 있는지에 의존하고 싶지 않습니다.
- **익숙한 채널에서 접근함:** 하나의 새 독립 앱에만 의존하고 싶지 않습니다.
- **명시적으로 제어함:** 모델, 스킬, 채널, 메모리, 예약 자동 작업을 직접 구성하고 싶습니다.
- **문서화된 설정을 중요하게 생각함:** 설정을 이해하고 반복하고 조정하고 싶습니다.
- **지금 시작함:** 사용할 수 있는 클라우드 호스팅 Hermes Agent를 원합니다.

Today.AI가 적합한 조건:

- **더 넓은 개인 컨텍스트가 필요함:** 데이터, 기기, 서비스에서 생활의 전체 모습을 구성하길 원합니다.
- **네이티브 앱을 선호함:** Mac, iOS, Android를 넘나드는 경험을 원합니다.
- **선제적 제안을 원함:** 요청 전에 도착하는 도움과 일일 정보 흐름에 관심이 있습니다.
- **넓은 데이터 접근을 허용함:** 개인 컨텍스트 접근을 비서 경험의 일부로 받아들일 수 있습니다.
- **얼리 액세스를 즐김:** 모델과 생태계가 변하는 단계부터 탐색하고 싶습니다.

결론적으로 **지금 사용할 수 있고 명시적으로 구성 가능한 지속형 개인 에이전트에는 LightVela, AI 비서가 개인 운영 계층으로 발전하는 가능성을 탐색하려는 얼리어답터에게는 Today.AI가 적합합니다.**

두 제품은 인접한 문제를 해결합니다. LightVela는 에이전트를 안정적으로 사용할 수 있고 확장 가능하게 만들며, Today.AI는 비서가 한 사람의 생활 리듬을 얼마나 깊이 이해하고 예측할 수 있는지 탐구합니다.
