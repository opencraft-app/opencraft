# LightVela vs Viktor.com: 개인 AI 에이전트를 운영하려면 어느 쪽이 적합할까요?

## 요약

**장기 메모리, 유연한 모델 구성, 메시징 채널, 스킬, 예약 작업을 갖춘 항상 사용 가능한 개인 AI 동반자가 필요하다면 LightVela가 적합합니다.** Slack, GitHub, Notion, Stripe, Salesforce, Google Ads 같은 비즈니스 도구를 넘나들며 팀의 공유 작업 공간 안에서 일하는 AI 동료가 필요하다면 Viktor.com이 적합합니다.

차이는 단순히 어느 AI가 더 똑똑한지가 아닙니다. 에이전트가 어디에 존재하고, 누구에게 속하며, 어떤 일을 맡도록 설계되었는지가 핵심입니다.

![개인 AI 에이전트 운영을 위한 LightVela와 Viktor.com 비교](../images/lightvela-vs-viktor.png)

## 한눈에 비교하기

| 비교 항목 | LightVela | Viktor.com |
| - | - | - |
| **주요 역할** | 개인용 클라우드 AI 에이전트 | 팀을 위한 공유 AI 동료 |
| **주요 인터페이스** | 웹 콘솔과 메시징 채널 | Slack, Microsoft Teams, 웹 앱, Discord |
| **메모리 모델** | 대화와 채널을 아우르는 개인 에이전트 메모리 | 공유 작업 공간 컨텍스트와 메모리 |
| **연동** | 메시징 채널, 스킬, 예약 작업, 모델 공급자 | 3,200개 이상의 비즈니스 도구 연동 |
| **설정 방식** | 서버 유지 관리가 필요 없는 관리형 클라우드 에이전트 | Viktor를 연결하고 도구 권한을 부여한 뒤 업무 위임 |
| **적합한 용도** | 개인 지원과 장기적인 협업 | 여러 도구를 넘나드는 비즈니스 운영 |

## 실제 차이는 소유권입니다

LightVela는 오래 함께 사용하는 개인 에이전트를 소유한다는 개념을 중심으로 합니다. Hermes Agent는 클라우드에서 실행되고, 개인 기기가 오프라인이어도 사용할 수 있으며, 지원되는 메시징 채널에서 접근할 수 있습니다. 메모리, 성격, 모델, 스킬, 예약 작업은 한 사용자와의 지속적인 관계를 중심으로 구성됩니다. [LightVela 개요](../01-overview.md)는 이러한 요소가 어떻게 연결되는지 설명합니다.

Viktor.com은 다른 방식을 택합니다. Viktor는 Slack과 Microsoft Teams 안에 있는 AI 동료로 소개되며, 팀 전체가 메시지를 보내고 채널에 초대하고 작업 공간 컨텍스트를 공유할 수 있습니다. 현재 자료는 웹 채팅과 Discord도 설명하지만, 중심 개념은 개인 동반자가 아니라 공유 업무 환경입니다.

“내 업무 방식을 기억하고 오래 함께할 에이전트가 필요한가?”라는 질문에는 LightVela가 더 명확합니다. “회사의 도구를 넘나들며 모두를 위해 일하는 AI가 필요한가?”라는 질문에는 Viktor가 맞춰져 있습니다.

같은 소유권 경계는 [LightVela vs Mira](./lightvela-vs-mira.md)에서도 나타납니다. 다만 Mira는 Telegram 대화에서 시작하고, Viktor는 공유 비즈니스 작업 공간과 연결된 운영에서 시작합니다.

## LightVela가 더 적합한 경우

이미 소통하는 여러 공간에서 에이전트를 사용해야 한다면 LightVela가 적합합니다. 채널을 연결하고 모델을 구성하고 [스킬](../configuration/skill.md)을 설치하고 반복되는 [예약 작업](../configuration/automation.md)을 만들 수 있습니다. 서버를 유지 관리하지 않고 같은 에이전트에 알림, 리서치, 정보 정리, 콘텐츠 작업, 일상 대화를 맡길 수 있습니다.

모델 계층도 유연합니다. 지원되는 모델 공급자를 구성하고 에이전트와의 관계를 다시 만들지 않은 채 모델을 바꿀 수 있습니다. 스킬은 Hermes의 기능을 확장하고 예약 작업은 언제 업무를 실행할지 결정합니다.

같은 클라우드 환경에서 다른 에이전트 런타임을 탐색할 수도 있습니다. [DeepSeek Harness](../configuration/deepseek-harness.md)는 Hermes Agent와 별도로 관리되는 서비스로 실행되며, 자체 WebUI, 공급자 설정, 플러그인 지원 프로필을 제공합니다. 기본 개인 에이전트를 교체하지 않고 플러그인 중심 환경을 실험할 때 유용합니다.

LightVela에서는 다음과 같은 방식으로 사용할 수 있습니다.

- 메시징 채널에서 질문합니다.
- 에이전트에 반복 작업을 맡깁니다.
- 전문 워크플로를 위한 스킬을 설치합니다.
- 에이전트의 더 넓은 컨텍스트를 유지하면서 모델을 바꿉니다.
- Hermes를 교체하지 않고 다른 에이전트 런타임을 시험합니다.

대신 LightVela는 한 사용자와 하나의 에이전트 사이의 개인적인 관계에 집중합니다. 여러 비즈니스 시스템에 작업을 기록하는 팀 전체의 운영자가 필요하다면 Viktor가 더 직접적인 선택입니다.

## Viktor.com이 더 적합한 경우

Viktor의 가장 큰 강점은 비즈니스 소프트웨어 전반에 걸친 폭입니다. 공식 자료는 CRM, 분석, 광고, 엔지니어링, 재무, 생산성 도구를 포함한 3,200개 이상의 연동을 설명합니다. [Viktor 연동 디렉터리](https://viktor.com/integrations)에서 기업의 기존 도구 묶음을 지원하는 연결을 확인할 수 있습니다.

요청할 수 있는 업무의 종류도 달라집니다. 워크플로를 함께 생각하는 데서 그치지 않고 Stripe와 HubSpot을 대조하거나, Notion 대시보드를 업데이트하거나, Linear 이슈를 분류하거나, 여러 연결 시스템에서 보고서를 준비하도록 요청할 수 있습니다.

대화에서 반복 업무를 직접 설정할 수도 있습니다. Slack이나 Teams에서 작업을 설명하고 일정을 지정해 확인하면 Viktor가 반복 실행합니다. [예약 작업 공식 문서](https://viktor.com/docs/scheduled-tasks)는 반복 비즈니스 운영을 위한 이 흐름을 설명합니다.

기술 팀을 위해 공개 API, MCP 서버, OpenAI 및 Anthropic 호환 접근 방식도 제공합니다. 비동기 스레드, 실행, 산출물, 연동 검색, 사용량, 승인 상태를 다루는 개발자 기능으로 에이전트를 프로그래밍 가능한 비즈니스 워크플로에 포함할 수 있습니다.

[보안 문서](https://viktor.com/security)는 OAuth 또는 보안 API 연결, 범위가 제한된 접근 권한, 민감한 작업 전 승인, 감사 가능성, 자격 증명을 모델에 노출하지 않고 실행 시점에 주입하는 방식을 설명합니다.

트레이드오프는 공유 소유권입니다. 여러 사람과 비즈니스 도구가 같은 운영 컨텍스트에 참여하는 작업 공간에는 가치가 있지만, 메모리, 페르소나, 일상 루틴이 주로 개인에게 속하는 에이전트와는 다른 관계입니다.

## 어떤 제품을 선택해야 할까요?

LightVela가 적합한 조건:

- **개인 에이전트가 필요함:** 자신의 루틴에 맞춰 더 유용해지는 AI 동반자를 원합니다.
- **연속성이 중요함:** 팀 전체 컨텍스트보다 장기 메모리와 하나의 지속적인 관계가 중요합니다.
- **메시징에서 접근함:** 이미 사용하는 채널에서 에이전트와 대화하고 싶습니다.
- **구성을 직접 제어함:** 모델, 스킬, 예약 작업, 에이전트 행동을 개인 워크플로에 맞추고 싶습니다.
- **런타임 유연성이 필요함:** 하나의 클라우드 환경에서 Hermes와 추가 에이전트 런타임을 탐색하고 싶습니다.

Viktor.com이 적합한 조건:

- **공유 작업 공간에서 일함:** Slack, Microsoft Teams, Discord가 업무의 중심입니다.
- **여러 사람이 한 AI 동료를 사용함:** 팀 전체가 메시지를 보내고 채널에 초대하고 싶습니다.
- **비즈니스 도구의 폭이 중요함:** CRM, 분석, 재무, 프로젝트 관리, 엔지니어링 도구를 연결해야 합니다.
- **도구 간 실행이 필요함:** 답변 작성에 그치지 않고 비즈니스 작업을 수행해야 합니다.
- **개발자 접근이 필요함:** 공개 API, MCP 또는 SDK 호환 접근을 워크플로에 포함해야 합니다.

결론적으로 **개인에게 속하는 지속형 에이전트 관계에는 LightVela, 비즈니스 도구에 연결된 팀용 AI 운영자에는 Viktor.com이 적합합니다.**
