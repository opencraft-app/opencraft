# 빠른 시작

## 요약

**LightVela에서 첫 대화를 시작하는 데는 약 5분이 걸립니다. 로그인한 뒤 플랜을 활성화하고, 플랫폼이 Hermes Agent 인스턴스를 생성하도록 한 다음 모델을 구성하거나 플랜에 포함된 월간 모델 크레딧을 사용하세요. 이어서 메시징 채널 하나를 연결하고 메시지를 보내 답장을 받으면 됩니다. 모든 과정은 브라우저에서 진행되므로 서버를 구매하거나 로컬 환경에 배포할 필요가 없습니다. 가장 빠른 방법은 플랜 크레딧을 사용하고 QR 코드로 WeChat을 연결하는 것입니다. 자체 모델 API 키와 다른 채널은 나중에 추가할 수 있습니다.**

---

이 튜토리얼에서는 로그인부터 WeChat에서 Hermes 응답 수신까지 전체 프로세스를 안내합니다. 약 5분 정도 소요됩니다.

## 이 페이지에서는 다음을 다루고 있습니다.

- LightVela에 로그인

- Launch 플랜 활성화 및 Hermes 인스턴스 생성

- Telegram / WhatsApp / Discord / Slack / WeChat 채널 연결하기

- WeChat으로 메시지 보내고 답장 받기

> 💡 **전제 조건**
>
> - Google 또는 GitHub 계정
>
> Launch 플랜에는 100 체험 크레딧이 포함되어 있으므로 사전에 대형 언어 모델 API 키를 준비하지 않고도 채팅을 시작할 수 있습니다.

---

## 1. LightVela에 로그인하세요

[lightvela.ai](https://lightvela.ai)에 접속해 오른쪽 상단의 "로그인"을 클릭하세요. 로그인 창에서 Google 또는 GitHub를 선택하고 약관에 동의한 뒤 인증을 완료하세요.

![](./images/2-1.webp)

---

## 2. Launch 플랜 활성화

홈페이지로 돌아가서 "지금 만들기"를 클릭하여 플랜 페이지로 이동한 다음 "Launch"를 선택하고 "지금 활성화"를 클릭하세요.

![](./images/2-2.webp)

> ⚠️ **Launch에는 청구 시작 후 신규 사용자를 위한 14일 무료 체험이 제공됩니다**
>
> LightVela는 공개 베타 버전에 진입하고 2026년 8월 18일(싱가포르 시간)에 청구를 시작할 계획입니다. 청구가 시작된 후 신규 사용자는 Launch를 14일 동안 무료로 사용해 볼 수 있습니다. [LightVela 유료 버전 공지](./announcements/public-beta.md)를 참조하세요.

활성화가 성공하면 상단 탐색에 "My Hermes"가 표시되고 페이지가 자동으로 콘솔로 리디렉션됩니다. 플랜에 대한 자세한 내용은 [LightVela란 - 플랜 정보](./01-overview.md#about-plans)를 참조하세요.

---

## 3. Hermes 인스턴스 생성

콘솔에 들어가면 아직 Hermes가 생성되지 않았기 때문에 페이지에 빈 상태가 표시됩니다.

![](./images/20260424-113103-70fi.webp)

"지금 만들기"를 클릭하세요. 그러면 "Hermes를 위한 커피를 준비하고 두뇌를 깨우는 중..."이라는 생성 애니메이션이 표시됩니다. 약 12초 정도 기다리세요.

![](./images/20260424-113120-qvlx.webp)

생성이 완료되면 콘솔 상단에 Hermes 기본 정보 카드가 표시되고 상태는 ● 실행 중이며 모델, 채널 및 스킬에 대한 세 가지 구성 버튼이 아래에 나타납니다.

![](./images/2-5.webp)

> 💡 **Hermes 이름 바꾸기**
>
> 이름이나 옆에 있는 연필 아이콘을 클릭하고 새 이름을 입력한 후 Enter를 눌러 저장하세요. 이름은 식별자로만 사용되며 에이전트 동작에는 영향을 주지 않습니다.

---

## 4. WeChat 채널을 연결하세요

"채널" 버튼을 클릭하고 드롭다운에서 "WeChat"을 선택한 다음 "액세스 승인"을 클릭하면 QR 코드가 나타납니다.

![](./images/2-6.webp)

휴대폰의 WeChat에서 "스캔"을 사용하여 QR 코드를 스캔한 다음 휴대폰에 표시되는 메시지에 따라 인증을 완료하세요. 인증이 성공하면 대화 상자가 자동으로 닫히고 "연결된 채널" 영역에 "WeChat" 레코드가 나타나고 봇 계정이 WeChat 연락처에 자동으로 추가됩니다.

> ⚠️ **스캔 후**
>
> 스캔 후 WeChat은 봇 계정을 추가하라는 메시지를 표시합니다. 추가한 후 해당 계정으로 채팅하는 것은 Hermes와 채팅하는 것과 동일합니다.

자세한 내용은 [채널 구성 - WeChat](./configuration/channel-wechat.md)을 참조하세요.

---

## 5. 첫 번째 메시지 보내기

WeChat에서 추가된 봇 계정을 찾아 테스트 메시지를 보냅니다.

```
Hi
```

![](./images/2-7.webp)

몇 초 내에 Hermes로부터 응답을 받아야 합니다. Hermes는 이제 WeChat을 통해 채팅할 수 있습니다.

> 💡 **메시지 청구**
>
> 기본적으로 모델 호출에는 Launch 플랜에 포함된 100 체험 크레딧을 사용하므로 추가 구성이 필요하지 않습니다. 크레딧이 소진된 후 "1. 모델" 카드에 자신만의 API 키를 구성하세요. [모델 구성](./configuration/model.md)을 참조하세요.

---

## 고급: 자신만의 모델 구성(선택 사항)

특정 공급자의 모델을 사용해야 하거나 크레딧이 소진된 후에도 Hermes를 계속 사용해야 하는 경우 콘솔에서 "1. 모델" 카드를 열고 소스와 모델을 선택한 다음 API 키를 입력하고 "기본값으로 추가"를 클릭하세요. 전체 프로세스는 [모델 구성](./configuration/model.md)을 참조하세요.

## FAQ

| 이슈 | 가능한 원인 | 솔루션 |
|---|---|---|
| Launch 플랜을 활성화할 수 없습니다 | 현재 프로모션 또는 결제 절차를 이용할 수 없습니다. | [구독 페이지](/subscribe)와 공식 공지를 확인하세요. |
| Hermes 생성 화면이 오랫동안 그대로입니다 | 클라우드 초기화가 지연되거나 네트워크가 불안정합니다. | 페이지를 새로 고치세요. 1분 후에도 응답이 없으면 "+ Create Hermes"를 다시 클릭하세요. |
| WeChat QR 코드를 스캔한 후 콘솔에 응답이 없습니다. | QR 코드가 만료되었습니다 | 대화 상자를 닫고 "액세스 승인"을 다시 클릭하여 새 QR 코드를 생성하세요. |
| 메시지를 보낸 후 응답이 없습니다. | 체험 크레딧이 소진되었거나 채널이 연결되지 않았습니다. | "연결된 채널" 상태를 확인하세요. 크레딧이 소진된 후 자체 API 키를 구성하세요 |
| WeChat에서 봇 연락처가 사라집니다. | 승인이 취소되었거나 접속이 끊어졌습니다. | 콘솔로 돌아가서 "채널" 카드에서 다시 액세스를 승인하세요. |
