# 스킬로 IM 에이전트를 고객 서비스·커뮤니티·동반자 어시스턴트로 만드는 방법

## 요약

**하나의 IM 에이전트를 고객 지원 에이전트, 커뮤니티 어시스턴트 또는 AI 동반자로 만드는 핵심은 스킬과 페르소나의 역할 분담입니다. 스킬은 수행 가능한 작업을 확장하고, `SOUL.md`는 에이전트의 정체성과 행동 범위를 정의합니다.** 둘 다 필요합니다. 페르소나 없는 스킬은 일관성 없는 답변을 만들고, 스킬 없는 페르소나는 재사용 가능한 방법이 부족합니다. LightVela의 스킬은 Skills.sh와 ClawHub 공개 마켓플레이스에서 제공됩니다. 현재는 대화에서 Hermes에게 요청해 설치하거나 삭제하고(콘솔 패널 설치는 곧 출시), 채팅에서 사용 가능 여부를 확인합니다. 세 가지 시나리오의 주된 차이는 경계 설계입니다. 고객 지원에는 명시적인 전달 조건이 필요하고, 커뮤니티 어시스턴트는 언제 침묵해야 하는지 알아야 하며, 동반자 활용에는 다루지 않을 주제가 분명해야 합니다. 출시 전에 안전 체크리스트를 모두 확인하세요.

![스킬로 IM 에이전트를 고객 서비스·커뮤니티·동반자 어시스턴트로 만들기](../images/use-case-06-im-agent-skill-scenarios.png)

## 이 가이드가 필요한 사용자

Telegram, WhatsApp 또는 다른 메시징 채널을 연결했으며 구체적인 워크플로에 에이전트를 사용하려는 사용자를 위한 가이드입니다.

지원 책임자, 커뮤니티 운영자, 장기간 함께 작업할 AI 동반자를 원하는 개인에게 특히 유용합니다.

## 사전 요구 사항

- 실행 중인 LightVela Hermes Agent.
  아직 만들지 않았다면 [빠른 시작](../02-quickstart.md)부터 진행하세요.

- 일반 대화를 이미 처리할 수 있는 메시징 채널.
  [Telegram에서 뚜렷한 페르소나를 가진 Hermes Agent를 구성하는 방법](./telegram-persona-agent.md) 또는 [WhatsApp에서 뚜렷한 페르소나를 가진 Hermes Agent를 구성하는 방법](./whatsapp-persona-agent.md)부터 시작할 수 있습니다.

- 대상 워크플로, 허용된 작업, 사람에게 전달해야 하는 상황에 대한 초기 정의.

- [Skills.sh](https://skills.sh/) 또는 [ClawHub](https://clawhub.ai/)에서 선택한 신뢰할 수 있는 스킬.

## 스킬과 페르소나의 경계 이해하기

스킬은 웹 탐색, 콘텐츠 정리, 일일 요약 또는 전문 워크플로처럼 호출 가능한 기능 패키지입니다.

SOUL.md는 에이전트의 정체성, 말투, 의사 결정 방식, 확인이 필요한 작업을 설명하는 데 더 적합합니다.

사용자 프로필과 장기 메모리는 사용자의 정체성, 선호도, 확인된 사실, 진행 중인 컨텍스트를 위한 공간입니다.

고객 응대 스크립트, 그룹 규칙, 고위험 권한을 구분 없이 하나의 페르소나 설명에 넣지 마세요.

## 단계

### 1. 에이전트의 주요 시나리오 정의

시나리오마다 필요한 스킬 조합과 안전 경계가 다릅니다.

| 시나리오 | 주요 목표 | 스킬 방향 | 먼저 정의할 경계 |
|---|---|---|---|
| 고객 서비스 | 일반 질문에 답하고 복잡한 요청 전달 | 지식 검색, 티켓 정리, 주문 조회 | 불확실하면 전달하고, 승인 없이 환불을 약속하거나 주문을 변경하지 않음 |
| 커뮤니티 어시스턴트 | 멤버 환영, FAQ 답변, 대화 요약 | 콘텐츠 검색, 요약, 예약 미리 알림 | 스팸 방지, 멤버 정보 보호, 관리자를 대신해 운영 결정을 내리지 않음 |
| AI 동반자 | 일관된 동반, 미리 알림, 장기 협업 제공 | 메모리 정리, 일정 관리, 콘텐츠 생성 | 거절과 개인정보 보호 존중, 의존성을 키우는 행동 방지, 불확실성 명시 |

한 번에 많은 스킬을 설치하지 말고 주요 시나리오 하나로 시작하세요.

### 2. 참고 자료와 페르소나 브리프 준비

고객 서비스에는 제품 FAQ, 서비스 시간, 전달 경로, 사람 담당자의 연락처를 준비합니다.

커뮤니티 운영에는 환영 메시지, 자주 묻는 질문, 커뮤니티 규칙, 요약 형식을 준비합니다.

AI 동반자에는 선호하는 이름, 말투, 주도성 수준, 다루지 않을 주제를 적어 둡니다.

Hermes가 참고할 자료는 [클라우드 스토리지](../configuration/files.md)에 두고, 안정적인 페르소나 규칙은 [Personality와 SOUL.md](./im-agent-persona-soul-md.md)를 통해 SOUL.md에 넣습니다.

### 3. 스킬 선택 및 설치

현재 LightVela에서는 대화를 통해 Skills.sh 또는 ClawHub의 스킬을 설치해 달라고 Hermes에 요청할 수 있습니다.

연결된 채널에서 다음과 같이 요청하세요.

    Please install a Skill suitable for organizing customer-service FAQs from Skills.sh or ClawHub, and first explain what permissions it needs.

스킬 이름을 알고 있다면 명확하게 지정합니다.

    Please install [Skill name]. First tell me what it will read, which external services it will call, and whether it can send proactive messages.

콘솔의 시각적 스킬 설치 진입점은 아직 현재 페이지 상태의 제한을 받으므로, 지원되는 설치 절차는 [스킬 구성](../configuration/skill.md)을 참고하세요.

고위험 스킬은 설치 전에 추가 확인을 요청할 수 있습니다.

확인하기 전에 스킬 출처, 권한, 외부 API 호출, 능동적 동작을 검토하세요.

### 4. 시나리오에 맞게 스킬 검증

대규모 사용자에게 공개하기 전에 일대일 대화에서 새 스킬을 테스트하세요.

고객 서비스는 다음 요청으로 시작합니다.

    Answer this question using the prepared FAQ. If the material does not contain an answer, say so clearly and suggest a human handoff.

커뮤니티 어시스턴트는 다음 요청으로 시작합니다.

    Summarize this discussion in no more than five points and list the questions that still have no conclusion.

AI 동반자는 다음 요청으로 시작합니다.

    Use my configured voice to give me a short check-in for today, and explain which details would be retained as long-term memory.

에이전트가 예상한 스킬을 호출하고, 올바른 참고 자료를 사용하고, 불확실할 때 멈추어 제한 사항을 설명하는지 확인하세요.

### 5. 반복 가능한 작업에 자동 작업 사용

환영 메시지, FAQ, 요약, 미리 알림은 서로 다른 트리거를 사용할 수 있습니다.

일일 커뮤니티 요약 전송이나 미해결 건에 대한 지원팀 미리 알림처럼 정해진 시각에 실행할 작업에는 [자동 작업](../configuration/automation.md)을 사용하세요.

모든 채널이 동일한 능동적 메시지 유형을 받을 수 있다고 가정하지 말고 자동 작업마다 알림 방식과 대상 채널을 확인하세요.

## 시나리오별 권장 사항

### 고객 서비스 어시스턴트

스킬은 정보를 검색하고, 컨텍스트를 정리하고, 답변 초안을 작성하게 하며, SOUL.md는 에이전트가 전문적이고 명확하며 신중한 태도를 유지하게 합니다.

환불, 가격 변경, 신원 확인, 데이터 삭제, 기타 고위험 작업에서는 에이전트가 영향을 설명하고 사람의 확인을 기다리도록 요구하세요.

참고 자료가 불완전하거나, 사용자가 문제를 상급자에게 전달하려 하거나, 요청이 승인 범위를 벗어나면 추측하지 말고 사람에게 전달하세요.

### 커뮤니티 어시스턴트

스킬은 FAQ를 검색하고, 대화 요점을 추출하고, 미리 알림 초안을 작성하게 하며, 페르소나 브리프는 에이전트가 커뮤니티 어조와 관리자 규칙을 따르게 합니다.

그룹 액세스, @멘션 트리거, 권한, 메시지 전달은 채널마다 다르므로 워크플로를 구성하기 전에 관련 채널 문서를 읽으세요.

대상 채널이 현재 그룹 채팅을 지원하지 않는다면 이 문서를 실제 그룹 채팅 설정으로 간주하지 말고 일대일 대화에서 스킬과 콘텐츠 워크플로를 검증하세요.

### AI 동반자

SOUL.md에는 안정적인 동반 스타일을 설정하고, 메모리와 사용자 프로필에는 확인된 선호도와 장기 컨텍스트를 저장하세요.

능동적 미리 알림에는 명확한 빈도, 일시 중지 방법, 방해 금지 시간이 있어야 합니다. 주도성이 무제한 메시지로 바뀌어서는 안 됩니다.

Hermes가 선호도를 유지하게 하려면 대화에서 기억해 달라고 요청하고, 더 이상 유지하지 않으려면 잊어 달라고 요청하세요.

## 안전 체크리스트

- 설치 전에 스킬 출처, 권한, 외부 서비스 종속성을 확인합니다.

- 테스트 중에는 일대일 대화와 위험도가 낮은 자료를 사용합니다.

- 외부 메시지 전송, 주문 변경, 파일 삭제, 기타 되돌릴 수 없는 작업 전에 확인을 요구합니다.

- 고객 서비스와 커뮤니티 워크플로를 위한 사람 전달 경로를 준비합니다.

- 메모리, 사용자 프로필, 클라우드 스토리지를 주기적으로 검토하고 더 이상 필요 없는 정보를 제거합니다.

## FAQ

### 스킬을 설치하면 에이전트의 페르소나도 자동으로 바뀌나요?

아니요.

스킬은 주로 에이전트가 할 수 있는 일을 확장하고, 페르소나는 SOUL.md와 관련 설정으로 정의됩니다.

스킬 지침과 출력이 한 작업의 스타일에 영향을 줄 수는 있지만 안정적인 역할과 경계 정의를 대체해서는 안 됩니다.

### 고객 서비스 스킬이 환불을 직접 처리할 수 있나요?

시스템 권한, 비즈니스 규칙, 사람 확인 요구 사항이 모두 명확할 때만 그러한 작업을 고려하세요.

기본적으로는 에이전트가 정책을 조회하고 권장 사항을 작성한 뒤 실행 전에 확인을 기다리게 하세요.

### 커뮤니티 어시스턴트가 Telegram 그룹에 직접 참여할 수 있나요?

BotFather에서 Group Privacy를 비활성화하고, Bot을 그룹에 추가하고, `@bot_username`으로 멘션하면 Telegram 그룹 메시지를 지원합니다.
그룹 질의응답, 요약, 미리 알림 초안은 [Telegram 그룹 AI 커뮤니티 어시스턴트를 사용하는 방법](./telegram-group-community-assistant.md)을 참고하세요.

### 모든 참고 자료를 메모리에 넣어야 하나요?

아니요.

장기 메모리는 적은 양의 안정적인 컨텍스트를 위한 것이며, 제품 FAQ, 커뮤니티 규칙, 대규모 참고 자료는 [클라우드 스토리지](../configuration/files.md)에 두거나 스킬이 필요할 때 읽게 하는 편이 적합합니다.
