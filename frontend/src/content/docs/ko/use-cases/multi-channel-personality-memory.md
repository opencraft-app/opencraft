# 하나의 페르소나와 장기 메모리를 유지하며 에이전트를 Telegram과 WhatsApp에 연결하는 방법

## 요약

**Telegram과 WhatsApp을 같은 Hermes Agent에 연결하면 두 채널을 하나의 에이전트로 들어가는 진입점으로 사용할 수 있습니다. 플랫폼마다 설정을 복제할 필요 없이 에이전트의 페르소나, 스킬, 자동 작업, 장기 메모리를 공유합니다.** 다만 "통합"의 범위는 에이전트 레이어에 한정됩니다. 각 채널의 인증 절차와 메시지 제한은 별도로 유지되므로 Telegram과 WhatsApp을 각각 인증해야 합니다. 공유 여부를 가장 확실히 확인하려면 한 채널에서 사실을 알려 준 뒤 다른 채널에서 그 내용을 물어보세요. 올바르게 답한다면 두 진입점이 같은 에이전트에 연결된 것입니다. 연결 후에는 답변이 다른 대화가 아니라 메시지를 보낸 바로 그 대화로 돌아오는지도 확인하세요.

![하나의 성격으로 Telegram 및 WhatsApp에 연결된 하나의 에이전트 및 장기 메모리](../images/use-case-07-multi-channel-personality-memory.png)

## 대상 독자

이 가이드는 하나의 AI 비서 정체성과 맥락을 유지하면서 여러 메시징 앱을 오가려는 사용자를 위한 것입니다.

Telegram과 WhatsApp을 오가면서 개인 비서, 연구 파트너 또는 고객 지원 도우미를 한곳에서 관리하고 싶을 때 유용합니다.

## "하나의 에이전트"가 의미하는 범위

하나의 에이전트를 공유한다고 해서 두 채널의 현재 대화 내용 전체가 실시간으로 동기화되는 것은 아닙니다.

두 진입점은 에이전트 레이어의 설정과 장기 맥락을 공유하지만, 현재 진행 중인 대화는 각 채널의 개별 세션에 속합니다.

다른 채널에서도 확인된 사실을 활용하려면 Hermes에게 기억해 달라고 요청한 뒤, 다른 진입점에서 해당 내용을 물어 확인하세요.

페르소나, 장기 메모리 및 스킬은 에이전트 계층에 속하고 Bot 토큰, QR 인증, 대화 진입점 및 메시지 형식은 채널 계층에 속합니다.

## 전제 조건

- 실행 중인 LightVela Hermes Agent.
  아직 생성하지 않았다면 [빠른 시작](../02-quickstart.md)부터 시작하세요.

- 작동하는 모델 구성 또는 사용 가능한 평가판 크레딧.

- 정상적으로 사용할 수 있는 Telegram 계정과 봇입니다.

- 정상적으로 사용할 수 있는 WhatsApp 계정입니다.

- Telegram 그룹 메시지 설정에 대한 이해: BotFather에서 그룹 개인 정보 보호를 비활성화하고 봇을 그룹에 추가한 다음 `@bot_username`와 대화를 시작합니다.
- WhatsApp 그룹 지원은 여전히 ​​자체 채널 문서의 적용을 받는다는 점을 이해합니다.

## 단계

### 1. 대상 에이전트를 하나만 선택합니다

LightVela 콘솔을 열고 Telegram과 WhatsApp을 함께 연결할 Hermes Agent 하나를 선택합니다.

의도적으로 다른 페르소나, 메모리 및 스킬을 원하지 않는 한 채널당 하나의 에이전트를 생성하지 마십시오.

### 2. Telegram을 연결하세요

[채널 구성 - Telegram](../configuration/channel-telegram.md)에 따라 봇을 생성하고 대상 에이전트에 대한 Telegram 채널 설정에 HTTP API 토큰을 붙여넣습니다.

Telegram에서 테스트 메시지를 보내고, 콘솔에 채널이 연결된 것으로 표시되는지 확인한 후, 응답이 예상되는 봇으로 반환되는지 확인하세요.

뚜렷한 Telegram 특성도 원한다면 [Telegram에서 독특한 특성으로 Hermes Agent를 구성하는 방법](./telegram-persona-agent.md)을 참조하세요.

### 3. WhatsApp을 연결하세요

동일한 Hermes Agent에 대한 채널 설정에서 WhatsApp을 선택하고 [채널 구성 - WhatsApp](../configuration/channel-whatsapp.md)에 따라 QR 인증을 완료합니다.

WhatsApp에서 해당 봇 연락처를 열고 테스트 메시지를 보낸 후 응답이 정상적으로 반환되는지 확인합니다.

뚜렷한 WhatsApp 특성도 원하는 경우 [WhatsApp에서 고유한 특성으로 Hermes Agent를 구성하는 방법](./whatsapp-persona-agent.md)을 참조하세요.

### 4. 에이전트 수준 페르소나를 하나로 구성합니다

대상 에이전트의 "Personality" 섹션을 열고 `SOUL.md`에 정의된 역할, 말투, 우선순위, 행동 경계가 두 채널 모두에 적합한지 확인합니다.

특성은 에이전트 계층에 있으므로 Telegram 및 WhatsApp에 두 개의 복사본을 구성할 필요가 없습니다.

성격을 변경해야 하는 경우 [SOUL.md를 사용하여 IM 에이전트의 역할, 성격 및 음성을 정의하는 방법](./im-agent-persona-soul-md.md)을 참조하세요.

변경 후에는 각 채널에서 새 대화를 시작하고 빠른 자체 검사를 실행하여 새 성격이 활성화되어 있는지 확인하세요.

### 5. 에이전트 수준 메모리와 사용자 프로필을 구성합니다

콘솔에서 "메모리"를 열고 에이전트 메모리 및 사용자 프로필 용량이 워크플로에 적합한지 확인하세요.

Telegram과 WhatsApp은 동일한 클라우드 에이전트의 장기 메모리를 공유하므로 동일한 ID, 언어, 기본 설정을 두 번 입력할 필요가 없습니다.

채널에서 다음을 보낼 수 있습니다.

    나는 모든 일일 브리핑이 결론부터 시작하여 세 가지 핵심 증거를 제시하기를 원한다는 점을 기억하십시오.

그런 다음 다른 채널로 전환하고 다음을 보냅니다.

    앞서 설정한 일일 브리핑 형식을 사용하고 간단한 예를 보여주세요.

채널이 다르게 동작하는 경우 먼저 동일한 에이전트에 연결되어 있는지 확인한 다음 현재 대화에 /new가 필요한지 확인하세요.

### 6. 공유 스킬을 한 번만 설치합니다

스킬은 채널이 아니라 에이전트에 설치되므로 Telegram용과 WhatsApp용으로 따로 설치할 필요가 없습니다.

Hermes에게 채널 중 하나에서 대화를 통해 스킬을 설치하도록 요청한 다음 스킬 목록을 업데이트하고 위험도가 낮은 작업으로 스킬을 검증하도록 요청하세요.

자세한 흐름은 [스킬 구성](../configuration/skill.md)을 참조하고, 설치를 확인하기 전에 스킬 소스, 권한 및 외부 서비스 종속성을 검토하세요.

### 7. 채널별 차이점 테스트

두 채널에서 같은 프롬프트를 보내 결과를 비교합니다.

    귀하의 현재 역할과 불확실성을 처리하는 방법을 설명하십시오.

    내가 저장한 기본 설정을 사용하여 이 콘텐츠를 세 가지 핵심 사항으로 바꾸세요.

그런 다음 미디어 메시지, 사전 알림 또는 봇 연락처가 나타나는 방식 등 채널에 속하는 동작을 테스트합니다.

성격과 장기적인 메모리는 일관성을 유지해야 하지만 메시지 형식, 미디어 기능, 승인 및 사전 전달 제한은 다를 수 있습니다.

## 하나의 에이전트와 두 진입점의 구조

    Hermes Agent 1개
    ├── one SOUL.md
    ├── 에이전트 메모리 1개 및 사용자 프로필
    ├── 설치된 스킬 한 세트
    ├── 자동 작업 1세트
    ├── Telegram 진입점
    └── WhatsApp 진입점

자동 작업 알림 방법에는 여전히 명시적인 대상 채널이 필요합니다.

공유된 에이전트로 인해 모든 알림이 Telegram 및 WhatsApp 모두로 전송된다고 가정하지 마십시오.

## FAQ

### Hermes에게 Telegram에서 기억하라고 요청한 내용이 WhatsApp에 나타나나요?

예. 두 채널이 같은 Hermes Agent에 연결되어 있고 해당 정보가 에이전트 메모리나 사용자 프로필에 저장되었다면 다른 채널에서도 사용할 수 있습니다.

현재 Telegram 대화의 모든 메시지가 자동으로 실시간 WhatsApp 대화 내용이 되지는 않습니다.

### 두 채널의 말투가 완전히 같지 않은 이유는 무엇인가요?

채널별 메시지 형식, 미디어 기능, 세션 상태, 모델의 출력 방식이 세부적인 표현에 영향을 줄 수 있습니다.

먼저 두 채널이 모두 동일한 에이전트에 연결되어 있는지 확인한 다음 필요할 때 /new를 전송하여 대화 시작 시 새 SOUL.md가 로드되도록 합니다.

### Telegram과 WhatsApp에 서로 다른 페르소나를 설정할 수 있나요?

두 채널이 하나의 에이전트에 연결되어 있다면 기본적으로 같은 에이전트 레이어의 페르소나를 사용합니다.

완전히 다른 역할과 메모리가 필요한 경우에는 다른 에이전트를 만들고 채널을 별도로 연결하세요.

### WhatsApp 그룹은 메모리를 Telegram과 공유할 수 있나요?

현재 WhatsApp 문서에는 그룹 채팅이 지원되지 않는다고 나와 있습니다.
Telegram은 그룹 개인 정보 보호를 비활성화하고 봇을 그룹에 추가하고 `@bot_username`와 대화를 시작한 후 그룹 메시지를 지원합니다.

다중 채널 공유는 에이전트 레이어의 일관성을 유지하지만 각 채널의 자체 설정 조건이나 기능 경계를 변경하지는 않습니다.

### 자동 작업이 채널 모두에 자동으로 전송되나요?

아니요.

자동 작업을 생성하거나 편집할 때 알림 방법과 대상 채널을 확인한 후 전송 결과를 별도로 테스트하세요.
