# 크레딧

## 요약

**모델 크레딧은 입력과 출력을 포함한 모델 호출 사용량을 측정합니다. Launch, Launch AI, Cruise, Cruise AI에는 각각 월 100, 4,500, 200, 10,000크레딧이 포함됩니다. 활성 플랜 사용자는 일회성 추가 크레딧 팩도 구매할 수 있으며, 지급 후 1개월 동안 유효하고 자동 갱신되지 않습니다. 대화와 모델을 사용하는 Agent Task는 크레딧을 소모하지만 Notification Task와 Script Task는 모델을 호출하지 않습니다. 크레딧이 부족하면 구매 가능한 팩을 추가하거나 다음 할당을 기다리거나 자체 모델 API 키를 설정할 수 있습니다.**

---

모델 크레딧은 LightVela가 Hermes Agent의 모델 사용량을 측정하는 데 사용하는 단위입니다. 각 플랜에는 월간 크레딧 할당이 포함됩니다. 에이전트가 대화나 작업 중에 언어 모델을 호출할 때마다 사용량에 따라 크레딧이 차감됩니다. 이 페이지에서는 크레딧이 무엇인지, 어떻게 할당 및 소비되는지, 플랜과 어떻게 관련되는지 설명합니다.

## 이 페이지에서 다루는 내용

- 모델 크레딧의 의미와 변환 방법

- 플랜이 매달 크레딧을 할당하는 방법

- 크레딧이 소비되는 방식 및 토큰과의 관계

- 크레딧이 플랜 및 모델과 관련되는 방식

---

## 모델 크레딧은 무엇인가요?

모델 크레딧은 언어 모델 호출을 측정합니다. 대화, 모델을 호출하는 [Agent Task](./configuration/automation.md), 모델을 사용하는 스킬은 크레딧을 소모합니다. Notification Task와 Script Task는 모델을 호출하지 않습니다.

대략적인 전환은 **1크레딧 ≒ 10,000토큰**입니다. 토큰은 모델에서 처리되는 텍스트의 기본 단위입니다. 입력(에이전트로 보내는 콘텐츠)과 출력(생성되는 응답) 모두 사용량에 포함됩니다.

> ℹ️ 플랫폼에 표시된 정확한 변환 및 측정 규칙은 신뢰할 수 있습니다. 토큰당 비용은 모델마다 다를 수 있습니다.

---

## 크레딧 할당 방법

크레딧은 **플랜에 따라 매월 할당**되며 월별 금액은 등급에 따라 다릅니다.

| 플랜 | 월간 모델 크레딧 |
|---|---:|
| Launch | 100 |
| Cruise | 200 |
| Launch AI | 4,500 |
| Cruise AI | 10,000 |

플랜별 리소스는 [플랜](./plans.md)에서, 현재 판매 여부와 가격은 [구독 페이지](/subscribe)에서 확인하세요.

## 추가 크레딧 팩

활성 플랜 사용자는 [구독 페이지](/subscribe#subscribe-credits)에서 일회성 모델 크레딧 팩을 구매할 수 있습니다. 지급 후 1개월 동안 유효하며 자동 갱신되지 않습니다. 만료일이 빠른 크레딧부터 사용하고, 만료일이 같으면 먼저 지급된 크레딧부터 사용합니다. 현재 가격과 구매 가능한 단위는 결제 화면에서 확인하세요.

---

## 크레딧이 소비되는 방식

각 상황에서 언어 모델을 호출하려면 Hermes가 필요하므로 다음 상황에서 크레딧이 소비됩니다.

- **에이전트와 대화** — Telegram, WhatsApp, Discord, Slack, WeChat 또는 지원되는 다른 채널을 통해 메시징

- **Agent Task 실행** — 모델을 호출하는 [예약 작업](./configuration/automation.md) 실행

- **스킬 사용** — 실행 중 추론을 위해 스킬이 모델을 호출하도록 허용

사용법은 대화 길이와 선택한 모델에 따라 다릅니다. 콘텐츠가 길고 컨텍스트가 많을수록 일반적으로 더 많은 토큰이 사용되므로 더 많은 크레딧이 사용됩니다. 보다 경제적인 모델을 선택하고 상황에 초점을 맞추면 사용량이 줄어들 수 있습니다. [모델 구성](./configuration/model.md)을 참조하세요.

---

## 크레딧이 플랜 및 모델과 관련되는 방식

- **플랜에 연결됨**: 크레딧은 플랜 리소스의 일부이며 월간 주기에 따라 할당됩니다. 현재 사용 가능한 크레딧 획득 또는 보충 방법은 [구독 페이지](/subscribe)에 표시되며 플랫폼의 최신 규칙이 적용됩니다.

- **모델에 따라 다름**: 모델은 토큰당 비용이 다를 수 있으므로 동일한 대화가 다른 모델을 사용하여 다른 수의 크레딧을 소비할 수 있습니다.

- **할당 주기**: 크레딧은 매월 할당됩니다. 롤오버 및 만료는 플랫폼의 현재 규칙을 따릅니다.

현재 기간에 대한 크레딧을 모두 사용하는 경우 모델 호출에 의존하는 에이전트 기능은 새로운 할당이 가능하거나 플랫폼이 다른 옵션을 제공할 때까지 제한됩니다.

## FAQ

### 크레딧은 플랜과 어떤 관련이 있나요?

크레딧은 플랜에 따라 매월 지급됩니다. 활성 플랜 사용자는 일회성 추가 크레딧 팩도 구매할 수 있습니다. 현재 옵션과 가격은 [구독 페이지](/subscribe)에서 확인하세요.

### 1크레딧은 얼마나 오래 지속되나요?

1크레딧은 약 10,000개의 토큰입니다. 이것이 지원하는 대화 횟수는 각 입력 및 출력의 길이와 선택한 모델에 따라 다르므로 메시지로 고정된 변환이 없습니다. 대화가 길수록 일반적으로 크레딧이 더 빨리 소모됩니다.

### 모든 모델은 동일한 비율로 크레딧을 소비합니까?

아니요. 모델은 토큰당 비용이 다르므로 동일한 작업이 모델에 따라 다른 수의 크레딧을 소비할 수 있습니다. [모델 구성](./configuration/model.md)에서 필요에 맞는 모델을 선택하세요.

### 크레딧을 모두 사용한 후에도 계속할 수 있나요?

구매 가능한 추가 크레딧 팩을 사거나 다음 플랜 지급을 기다리거나 자체 모델 API 키를 설정할 수 있습니다. 사용할 크레딧이나 키가 없으면 모델을 호출하는 기능이 제한됩니다.
