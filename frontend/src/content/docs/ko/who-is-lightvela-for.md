# LightVela는 누구를 위한 것인가요?

## 요약

**LightVela는 사용자를 기억하고 대화를 거듭할수록 더 잘 맞춰지는 장기적인 AI 동반자를 원하지만 서버, 컨테이너, API 인증을 직접 관리하고 싶지 않은 사람에게 적합합니다. 특히 별도의 앱보다 평소 사용하는 메시징 앱에서 AI와 대화하고 싶거나, 매번 자신을 다시 설명하지 않도록 대화 간에 유지되는 메모리가 필요한 사용자에게 유용합니다. LightVela가 클라우드 배포와 운영, 24/7 가동을 담당하므로 사용자는 브라우저에서 설정만 하면 됩니다. 반대로 데이터가 기기를 벗어나지 않는 완전한 로컬 실행이 필요하거나, 기반 모델을 직접 학습·미세 조정해야 하거나, 에이전트를 자체 웹사이트나 앱에 삽입하려는 경우에는 적합하지 않습니다.**

---

LightVela는 Tencent Cloud Lighthouse 팀의 클라우드 호스팅 에이전트 제품입니다. **서버, 컨테이너 또는 API 인증을 관리할 필요 없이 온라인 상태를 유지하고 상황을 학습하며 시간이 지남에 따라 더욱 도움이 되는 개인 AI 동반자를 원하는 사람들**을 위해 설계되었습니다. LightVela는 클라우드에서 배포, 운영 및 24/7 가용성을 처리합니다. 웹 콘솔에서 에이전트를 구성한 다음 Telegram, WhatsApp, Discord, Slack 또는 WeChat을 통해 Hermes Agent와 통신합니다.

아직 잘 모르겠다면 [LightVela란 무엇인가](./01-overview.md)부터 시작해 보세요.

***

## 누구를 위한 것인가

LightVela는 특히 다음과 같은 경우에 유용합니다.

* **기술적인 설정 없이 AI 에이전트를 원하는 사람들**
  서버, Docker, 리버스 프록시, API 인증을 이해할 필요가 없습니다. 사용 가능한 플랜을 활성화하면 LightVela가 시각적 콘솔을 통해 클라우드 런타임을 구성하고 관리합니다.

* **이미 사용하고 있는 메시징 앱에 AI가 포함되기를 원하는 사람들**
  Hermes는 [채널](./04-core-concepts.md)을 통해 Telegram, WhatsApp, Discord, Slack, WeChat에 연결됩니다. 별도의 앱으로 전환하지 않고 평소 메시지를 주고받는 곳에서 그대로 대화할 수 있습니다.

* **언어 모델을 유연하게 선택하고 싶은 사람들**
  LightVela는 ChatGPT, Claude, Gemini, DeepSeek, Qwen, Zhipu, Hunyuan 및 기타 OpenAI 호환 엔드포인트에 연결할 수 있습니다. 설정에 대한 자세한 내용은 [모델 구성](./configuration/model.md)을 참조하세요.

* **대화 전반에 걸쳐 메모리가 필요한 분들**
  기본 챗봇과 달리 Hermes는 세션 전반에 걸쳐 대화 내용과 장기 기억을 유지할 수 있으므로 매번 다시 소개할 필요가 없습니다.

* **24/7 이용 가능한 독립적으로 실행되는 에이전트를 원하는 사람들**
  각 Hermes 인스턴스는 격리된 클라우드 환경에서 실행되며 로컬 장치가 온라인인지 여부에 관계없이 계속 사용 가능합니다.

***

## 일반적인 사용 사례

LightVela는 특히 다음과 같은 경우에 효과적입니다.

* 알림, 정보 정리, 주문형 질문을 위한 **개인 AI 비서**입니다. [LightVela로 개인 AI 도우미 구축](./use-cases/personal-ai-assistant.md)을 참조하세요.

* **항상 사용 가능한 대화 엔드포인트** 에이전트를 Telegram, WhatsApp, Discord, Slack 또는 WeChat에 연결합니다.

* **예약된 일일 작업**은 자동으로 실행되고 관심 있는 정보를 요약합니다.

* **장기적인 메모리 및 개인 지식 관리**, 함께 일할수록 더욱 유용해지는 에이전트와 함께하세요.

***

## 전제조건

시작하기 전에 다음이 필요합니다.

* LightVela에 로그인하기 위한 Google 또는 GitHub 계정. 국제 사이트에서는 중국 본인 인증을 요구하지 않습니다.

* [구독 페이지](/subscribe)에서 현재 사용 가능한 플랜을 선택하고 활성화합니다. 공개 베타 및 청구 시작 후 신규 사용자는 14일 동안 Launch를 무료로 사용해 볼 수 있습니다.

* Telegram, WhatsApp, Discord, Slack 또는 WeChat과 같은 지원되는 메시징 계정이 하나 이상 있습니다.

자체 서버나 운영 경험이 필요하지 않습니다.

***

## 확실하지 않은 경우

데이터가 장치를 떠나지 않는 완전한 로컬 배포가 필요하거나 기초 모델을 교육하거나 미세 조정하려는 경우 또는 에이전트를 자신의 웹 사이트나 앱에 직접 포함해야 하는 경우 LightVela는 적합하지 않을 수 있습니다.
