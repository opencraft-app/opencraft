# LightVela란 무엇인가요?

## 요약

**LightVela는 Tencent Lighthouse 팀이 제공하는 클라우드 호스팅 에이전트 플랫폼이며, 현재 제품은 대형 언어 모델 기반 AI 에이전트인 Hermes Agent입니다. LightVela가 클라우드 배포와 운영, 24/7 가동을 관리하므로 구성 파일을 작성하거나 SSH로 서버에 접속할 필요가 없습니다. 시각적 관리 패널에서 항목을 선택해 설정한 뒤 평소 사용하는 메시징 앱에서 에이전트와 대화할 수 있습니다. 대화가 이어져도 에이전트는 사용자를 기억하며, 사용자가 모델과 도구, 페르소나를 선택합니다. LightVela는 2026년 8월 18일(싱가포르 시간)에 결제가 활성화된 공개 베타를 시작할 예정입니다. 기존 비공개 베타 플랜은 1개월 연장되고, 신규 사용자는 Launch 플랜을 14일간 무료로 체험할 수 있습니다. 최신 상태는 구독 페이지에서 확인하세요.**

> 시간이 지남에 따라 사용자를 더 잘 이해하는 클라우드 호스팅 Hermes Agent입니다.

>
> * **공개 베타 및 청구**: LightVela는 공개 베타에 돌입하고 2026년 8월 18일(싱가포르 시간)에 청구를 시작할 계획입니다. 공개 베타 및 청구가 공식적으로 시작된 후 베타 사용자의 기존 플랜 유효 기간이 1개월 더 연장됩니다. [LightVela 유료 버전 공지](./announcements/public-beta.md)를 참조하세요.
>
> * **공개 베타 및 청구 시작 후 신규 사용자 혜택**: 신규 사용자는 Launch 플랜을 14일 동안 무료로 사용해 볼 수 있습니다.

LightVela는 Tencent Lighthouse 팀의 클라우드 에이전트 호스팅 제품입니다. 모든 사람이 **진정으로 자신에게 속한 AI 동반자**를 소유할 수 있도록 설계되었습니다. 매번 자기 소개를 요청하는 도구가 아니라 **당신을 알고, 기억하고, 시간이 지남에 따라 더 잘 이해하는** 장기적인 존재입니다.

에이전트는 24/7 온라인 상태를 유지하고 독립적으로 실행되며 항상 채팅할 준비가 되어 있습니다. 모델, 도구 및 페르소나를 결정합니다.

시각적 콘솔을 통해 구성 장벽을 낮췄습니다. 구성 파일이나 서버 로그인이 필요 없으며 웹 페이지에서 옵션을 선택하기만 하면 설정이 완료됩니다.

현재 LightVela 제품은 **Hermes Agent**, 대형 언어 모델로 구동되는 AI 에이전트입니다. 향후 더 많은 즉시 사용 가능한 제품이 추가될 수 있습니다. 이 문서는 Hermes Agent에 중점을 둡니다.

## 누구를 위한 것인가

* AI 에이전트를 사용하고 싶지만 서버, 컨테이너, API 인증 및 관련 인프라에 대한 기술적 지식이 없는 사용자

* 독립형 앱 대신 일상적인 메시징 플랫폼(Telegram / WhatsApp / Discord / Slack / WeChat)을 통해 AI와 상호 작용하는 것을 선호하는 사용자

* 여러 대형 언어 모델 공급자(ChatGPT, Claude, Gemini, Deepseek, Qwen, Zhipu, Hunyuan 등 포함) 중에서 선택하려는 사용자

* 매번 처음부터 시작하는 대신 대화 전반에 걸쳐 지속적인 메모리가 필요한 사용자

## 적합하지 않음

* 데이터가 장치 외부로 유출되지 않고 완전한 로컬 실행이 필요한 사용자

* 기본 모델을 훈련하거나 미세 조정해야 하는 사용자

* 에이전트를 자신의 웹사이트나 애플리케이션에 통합해야 하는 개발자

***

## 제품특징

* **완전 관리형 배포**: 클라우드는 환경 설정 및 런타임 관리를 자동으로 처리합니다. 서버 운영, 컨테이너 이미지 또는 인프라 지식이 필요하지 않습니다.

* **격리된 런타임 환경**: 각 Hermes Agent 인스턴스에는 자체 런타임 환경, 리소스 격리, 24/7 가용성 및 로컬 장치에 대한 종속성이 없습니다.

* **다중 모델 지원**: 주류 중국어 대형 언어 모델, 공급자 Coding Plan 구독 또는 OpenAI 호환 엔드포인트에 연결합니다. [모델 구성](./configuration/model.md)을 참조하세요.

* **다중 채널 액세스**: Telegram, WhatsApp, Discord, Slack, WeChat, QQ, WeCom, Lark에서 Hermes Agent와 대화할 수 있습니다

* **스킬 확장**: [SkillHub](https://skillhub.tencent.com)에서 스킬 패키지를 설치하여 Hermes Agent 기능을 확장합니다.

* **사용 준비 완료**: Launch 플랜에는 체험 크레딧이 포함되어 있으므로 모델을 별도로 구성하지 않고도 활성화 후 채팅을 시작할 수 있습니다.

* **전용 클라우드 스토리지**: 대화 및 메모리 데이터는 독립적으로 저장됩니다.

## 작동 원리

LightVela는 클라우드의 각 사용자에 대해 전용 Hermes Agent 인스턴스를 실행한 다음 이를 어댑터 계층을 통해 사용자가 선택한 메시징 플랫폼에 연결합니다.

```
User (sends a message in Telegram / WhatsApp / Discord / Slack / WeChat)
      ↓
User-dedicated Hermes Agent instance in the LightVela cloud
      ↓
Calls the configured large language model (GPT / Claude / Gemin / ...)
      ↓
Response returns through the original channel
```

완전한 대화 루프에는 세 가지 구성이 필요합니다.

1. **모델**: Hermes Agent가 호출하는 대형 언어 모델입니다. Launch 플랜에는 체험 크레딧이 포함되어 있으며 직접 사용할 수 있습니다. 자신만의 API 키를 구성할 수도 있습니다

2. **채널**: Hermes Agent(Telegram / WhatsApp / Discord / Slack / WeChat)와 채팅하는 데 사용되는 메시징 플랫폼

3. **스킬**(선택 사항): Hermes Agent의 추가 기능

## 플랜에 대하여

LightVela는 플랜 기반으로 요금을 청구합니다. 플랜을 활성화하면 Hermes Agent 인스턴스 1개와 해당 플랜에 포함된 리소스 및 크레딧을 사용할 수 있습니다.

현재 이용 가능한 플랜:

| 플랜 | 정가 | 현재 상태 |
| --------- | ------- | ---- |
| Launch | $7.5/월 | 공개 베타 및 청구 시작 후 신규 사용자를 위한 14일 무료 체험 |
| Cruise | $15/월 | 유료 플랜 |

Launch 플랜에는 다음이 포함됩니다: Hermes Agent 인스턴스 1개, 2코어 4G 격리 런타임 환경, 50G 전용 클라우드 스토리지, 100 체험 크레딧, 24/7 가용성 및 콘솔 액세스.

> ℹ️ **베타 플랜 안내**
>
> LightVela는 공개 베타 버전에 진입하고 2026년 8월 18일(싱가포르 시간)에 청구를 시작할 계획입니다. 공개 베타 및 청구가 공식적으로 시작된 후 베타 사용자의 기존 플랜 유효 기간은 1개월 더 연장되며 신규 사용자는 Launch를 14일 동안 무료로 사용해 볼 수 있습니다. [LightVela 유료 버전 공지](./announcements/public-beta.md)를 참조하세요.

## 등대와의 관계(선택)

Tencent Cloud에 익숙한 사용자의 경우: LightVela는 Tencent Lighthouse 클라우드 에이전트 배포 기능을 즉시 사용할 수 있는 패키지로 이해할 수 있습니다. LightVela는 Tencent Cloud 계정, 리소스 관리 및 클라우드 리소스 운영과 같은 개념을 제거하고 에이전트 구성 및 메시징 플랫폼에 연결이라는 두 가지 핵심 작업만 남깁니다.

Cloud 에이전트를 처음 사용하는 경우 이 섹션을 건너뛸 수 있습니다.
