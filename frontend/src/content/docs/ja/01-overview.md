# LightVelaとは何ですか

## 概要

**LightVelaはTencent Lighthouseチームによるクラウドホスト型エージェントプラットフォームであり、現在の製品はHermes Agentです — 大規模言語モデル上に構築されたAIエージェントです。LightVelaはクラウドでの展開、運用、24/7の稼働時間を管理するため、設定ファイルを書いたりサーバーにSSHで接続する必要はありません：すべてをビジュアルパネルでポイント＆クリックで設定し、その後、Webの「日常 → チャット」でBotと直接会話するか、普段使うメッセージングアプリを接続できます。会話を通じてユーザーを記憶し、モデル、ツール、ペルソナを選択できます。現在のプランと新規ユーザー向け特典は[サブスクライブページ](/subscribe/)で確認できます。**

---

> 時間とともにあなたをより理解するクラウドホスト型Hermes Agent。

LightVelaはTencent Lighthouseチームによるクラウドエージェントホスティング製品です。これは、**自分だけのAIコンパニオンを持つ**ことを誰でも可能にするよう設計されています—毎回自己紹介を求めるツールではなく、**あなたを知り、あなたを覚え、時間とともにより理解する**長期的な存在です。

あなたのエージェントは24時間/7オンラインにあり、独立して動作し、いつでもチャットの準備ができています。モデル、ツール、ペルソナはあなたが決めます。

ビジュアルコンソールを通じて設定のハードルを下げています: 設定ファイル不要、サーバーログイン不要、ウェブページ上でオプションを選択するだけで設定が完了します。

現在のLightVela製品は、**Hermes Agent**であり、これは大規模言語モデルを搭載したAIエージェントです。将来的には、より多くのすぐに使用可能な製品が追加される可能性があります。本ドキュメントはHermes Agentに焦点を当てています。

## 対象ユーザー

* サーバー、コンテナ、API認証および関連インフラの技術知識がなくてもAIエージェントを利用したいユーザー

* スタンドアロンアプリではなく、日常的に使用するメッセージングプラットフォーム（Telegram / WhatsApp / Discord / Slack / WeChat）を通じてAIとやり取りしたいユーザー

* 複数の大規模言語モデルプロバイダー（ChatGPT、Claude、Gemini、Deepseek、Qwen、Zhipu、Hunyuanなどを含む）から選択したいユーザー

* 会話のたびに最初から始めるのではなく、会話を通じて永続的なメモリを必要とするユーザー

## 適していないのは

* データをデバイス外に出さずに完全にローカルで実行する必要があるユーザー

* 基盤モデルのトレーニングや微調整が必要なユーザー

* 自分のウェブサイトやアプリケーションにエージェントを統合する必要がある開発者

***

## 製品の機能

* **完全管理型デプロイメント**：クラウドが環境設定と実行時管理を自動で処理します。サーバー操作、コンテナイメージ、インフラ知識は不要です

* **専用クラウド環境**: 各Hermes Agentインスタンスは専用クラウド環境、リソースの隔離、24/7の可用性を備え、ローカルデバイスには依存しません

* **マルチモデル対応**: 主流の中国語大規模言語モデル、プロバイダーのCoding Planサブスクリプション、またはOpenAI互換のエンドポイントに接続可能です。詳細は[モデルの設定](./configuration/model.md)

* **マルチチャネルアクセス**: Telegramを通じてHermes Agentと、WhatsApp、Discord、Slack、WeChat、QQ、WeCom、およびLarkでチャットできます

* **スキル拡張**：コンソールで[Skills.sh](https://skills.sh/)と[ClawHub](https://clawhub.ai/)のスキルやスキルパッケージを検索してインストール

* **すぐに使用可能**: Launchプランには試用クレジットが含まれているため、モデルを別途設定することなく、アクティベーション後すぐにチャットを開始できます

* **専用クラウドストレージ**: 会話およびメモリデータは独立して保存されます

## 仕組み

LightVelaはHermes Agentをクラウドで実行します。Webチャットから送信でき、必要に応じて外部のメッセージングアプリも接続できます。

```
User (sends a message in Web Chat or a connected messaging app)
      ↓
User-dedicated Hermes Agent instance in the LightVela cloud
      ↓
Calls the configured large language model (GPT / Claude / Gemin / ...)
      ↓
Response returns to the same conversation entry point
```

Webチャットでの会話に外部チャネルは不要です:

1. **モデル**: Hermes Agent により呼び出される大規模言語モデル。Launchプランには試用クレジットが含まれており、そのまま使用可能です。また、独自のAPIキーを設定することもできます

2. **チャット入口**: My Agentのチャットで選択中のBotと会話します。Telegram、WhatsApp、Discord、WeChatなどのアプリで使う場合だけチャネルを設定します

3. **スキル**（オプション）: Hermes Agent の追加機能

## プランについて

1つのプランでHermes Agentのクラウドインスタンスを1つ利用できます。その中でLaunchシリーズは最大5つ、Cruiseシリーズは最大10のBotに対応します。Botは独立したプロファイルであり、追加のHermesインスタンスではありません。

| プラン | 毎月のモデルクレジット | Bot数 |
|---|---:|---:|
| Launch | 100 | 5 |
| Launch AI | 4,500 | 5 |
| Cruise | 200 | 10 |
| Cruise AI | 10,000 | 10 |

価格、初回特典、販売状況は変わる場合があります。購入前に[サブスクライブページ](/subscribe)を確認してください。有効なプランがあれば、1回払いの[追加クレジットパック](./credits.md)も購入できます。

## ライトハウスとの関係（任意）

Tencent Cloud に精通しているユーザー向け: LightVela は、Tencent Lighthouse クラウドエージェントの展開機能の使えるパッケージとして理解できます。LightVela は、Tencent Cloud アカウント、リソース管理、クラウドリソース操作といった概念を取り除き、エージェントの設定とメッセージングプラットフォームへの接続という2つの主要なアクションのみを残します。

クラウドエージェントが初めての場合は、このセクションをスキップできます。
