# IMエージェントの役割、性格、声をSOUL.mdで定義する方法

## 概要

**IMエージェントが「同じ人のように感じるかどうか」は、そのチャネルを通じて動作するかどうかではなく、そのペルソナによります。`SOUL.md`は役割、口調、優先事項、行動、制限を持ち、Hermesランタイムにおけるコアペルソナファイルです。** LightVelaではクラウドファイルシステムに直接触れることはありません — エージェントの設定ページのペルソナセクションから、ペルソナをランダムで引くか、短いクイズに答えるかの2つの入口があります。ペルソナカードの役割、口調、行動メモを確認してから、[Inject Persona]を選んで適用します。具体的な事実ではなく、評価可能な原則を書きましょう：「結論を先に述べる」「不確実な点を明確にする」「外部メッセージを送る前に確認する」などがペルソナですルールは短期記憶に、プロジェクト名やポートは長期記憶に属します。注入後は、実際の会話でトーンと制限を確認してください。

![SOUL.md を使用して、IMエージェントの役割、人格、声を定義します。](../images/use-case-05-im-agent-persona-soul-md.png)

## 対象者

このガイドは、IMエージェントにパーソナルアシスタント、研究パートナー、学習コンパニオン、日常の顧客対応アシスタントなどの安定した役割を与えたい人向けです。
まだメッセージングチャネルを選択していない場合は、まず[AIエージェントをメッセージングプラットフォームに接続する方法](./chinese-messaging-channels.md)。

## まず三つのコンテキストレイヤーを理解してください

### `SOUL.md`：エージェントが誰で、どのように機能するか

`SOUL.md`は、役割、声、優先事項、行動、境界など、安定したペルソナルールに最適です。
「結論を先に述べる」「不確実性を明確にする」「外部メッセージを送信する前に尋ねる」などのルールはここに含まれます。

### ユーザープロファイル：あなたが誰で、どのように扱われたいか

ユーザープロファイルは、言語、タイムゾーン、身元、背景、コミュニケーションの好みに最適です。
例えば、「私はシンガポールにいます」、「デフォルトで英語を使用する」、「期限を先に表示する」は、通常はユーザーの設定であり、エージェントの識別ルールではありません。

### 長期記憶: 共に構築したもの

長期記憶は、プロジェクトの状態、決定事項、共有作業からの再利用可能なコンテキストに最適です。
継続的な会話を通じて成長し、[メモリ管理](../configuration/memory.md)。

これら三つを混ぜると、エージェントの識別、ユーザーの設定、一時的なプロジェクトのコンテキストが互いに干渉してしまいます。
それらを分けておくことで、会話が実際のユーザーや作業に合わせて適応する間、人格は安定したままになります。

## 前提条件

- 進行中の LightVela Hermes Agent。
で確認または容量管理することができます。まだ作成していない場合は、まず[クイックスタート](../02-quickstart.md)。

- 構成されたモデルと少なくとも1つの利用可能な会話チャンネル。

- 簡単なペルソナの概要。
エージェントが誰にサービスを提供するか、主に何を行うか、どのような口調にすべきか、常に確認が必要なアクションはどれかを決めます。

## 手順 / 主要な概念

### 1. 5つの質問でペルソナの目標を定義する

ソウルを選ぶ前に、次の5つの質問に答えてください：

- エージェントは誰ですか？

- 主に誰を助けますか？

- 通常はどのような口調で話すべきですか？

- 情報が不確実な場合、どうすべきですか？

- どの外部アクションには事前確認が必要ですか？

回答をこのように計画ブリーフにまとめてください：

```text
Role: A research assistant for personal projects
Audience: A user who wants reliable conclusions quickly
Voice: Concise, professional, friendly, conclusion first, evidence second
Behavior: Break down questions, flag uncertainty, and ask only one key question when needed
Boundaries: Never send external messages, change files, or take high-risk actions without confirmation
```

このテンプレートは、ペルソナを選び、調整するのに役立ちます。
これはLightVelaが任意のクラウドファイルに対する汎用エディターを提供するという意味ではありません。

### 2. エージェント設定でのパーソナリティの開放

LightVela コンソールで、対象の Hermes Agent の設定を開き、「パーソナリティ」を選択します。
国際サイトでは、「ランダムソウル抽選」と「ソウルパーソナリティテスト」の両方の入り口が提供されています。

ランダム抽選を使って、異なる役割スタイルを試してみてください。
パーソナリティテストは、あなたのコミュニケーションや行動の好みにより合ったソウルを求める場合に使用します。

各カードの役割、声、行動の説明を確認し、計画概要に最も合ったものを選んでください。

### 3. 選択したソウルを`SOUL.md`に注入する

ソウルを選択して、「ソウルを注入」をクリックします。
LightVelaは選択したソウルを現在のHermes Agentの`SOUL.md`に書き込み、既存のファイルを置き換える前にバックアップを保持します。

エージェントには同時に1つの人格しかアクティブになりません。
役割を切り替えたい場合は、再注入する前に新しいカードの境界を確認してください。

注入が成功したら、IMチャンネルに戻り、以下を送信します:

```text
/new
```

Hermes Agentは新しい`SOUL.md`を、新しい会話が始まるときに読み込みます。
これは重要です。なぜなら、既存の会話には以前のペルソナのスナップショットがまだ保持されている可能性があるからです。

### 4. 会話を通じてユーザーの好みや永続的な事実を追加する

すべての情報を`SOUL.md`に入れないでください。
安定したペルソナは短く保ち、個人の好みやプロジェクトの事実はユーザープロフィールや長期記憶に任せてください。

例えば、Hermesに次のように伝えます：

```text
Remember that I am in Singapore time and want a concise weekday plan at 8:00 AM, with deadlines listed first.
```

または：

```text
Forget the Friday evening reminder preference I mentioned earlier. Do not schedule it again.
```

Hermesは会話を通じて記憶と忘却のリクエストを処理します。
で収集してください。[メモリ管理](../configuration/memory.md)でメモリおよびユーザープロファイルの内容と容量を確認します。

### 5. 実際の作業にのみスキルをインストールする

パーソナリティはエージェントの動作を定義しますが、外部の機能を自動的に追加するわけではありません。
ブラウジング、資料の整理、情報の検索、またはその他の具体的な作業を行わせたい場合は、適切なスキルをインストールし、まずそのソースと権限を確認してください。

まず[スキルを設定する](../configuration/skill.md)。
スキルと性格は互いに補完しあうべきであり、不明確なペルソナの境界を補うためにハイリスクなスキルを使うべきではありません。

## ペルソナがアクティブであることを確認してください

新しい会話を始めたら、自己紹介を求める以上のことを行いましょう。
少なくとも次の四つのケースをテストしてください:

```text
What is your current role, main job, and default voice?
```

```text
How do you respond when you are uncertain about a fact?
```

```text
If I ask you to send a message to an external service, what do you do first?
```

```text
Turn this material into conclusions, evidence, and questions that still need confirmation.
```

エージェントが役割、声、安全性の境界を保持しているか、そしてユーザープロファイルや長期記憶の関連コンテキストを利用できるかを確認してください。
挙動が不安定な場合は、別のソウルを選ぶか注入する前にペルソナのルールを簡略化してください。

## FAQ

### クラウド`SOUL.md`を手動で編集する必要がありますか？

通常はありません。
LightVelaのパーソナリティのエントリーがソウルを生成して注入するため、通常の使用では直接クラウドファイルシステム操作は不要です。

### `SOUL.md`を変更すると、すべてのメッセージングチャネルに影響しますか？

同じHermes Agentのエージェントレベルの動作に影響します。
そのエージェントがTelegramとWhatsAppに接続されている場合、新しい会話では両方のチャネルがパーソナリティを使用しますが、各チャネルは引き続き独自の認証、メッセージ形式、能力制限を持ちます。

### `SOUL.md`はメモリを置き換えることができますか？

いいえ。
`SOUL.md`は安定したアイデンティティと行動ルールを説明するべきであり、メモリは変化する事実、プロジェクトのコンテキスト、共有経験を保持するべきです。

### 1つのエージェントが同時に複数のアクティブな人格を持つことはできますか？

現在、1つのエージェントは同時に1つのアクティブな人格しか持ちません。
完全に異なる役割が必要な場合は、1つのエージェントのソウルを繰り返し上書きするのではなく、別のエージェントを作成してください。

### `/new`はいつ送るべきですか？

新しい人格を導入した後、IMチャンネルで`/new`を送信してください。
これは、新しいソウルが会話の初期化中に読み込まれることを明確にします。
