# 1つのエージェントをTelegramとWhatsAppに接続しながら、1つのパーソナリティと長期メモリを維持する方法

## 概要

**Telegram と WhatsApp は、同じ Hermes Agent への2つの入り口として機能することができます。両方のチャネルが同じエージェントに接続されている限り、エージェントレベルのペルソナ、スキル、スケジュールタスク、長期記憶を共有し、プラットフォームごとに複製する設定は不要です。** しかし、「統合」には定義された範囲があります：共有されるのはエージェントレベルの資産であり、各チャネルは独自の認証フローとメッセージ制限を保持するため、接続は2つの独立した認証ステップになります。共有を確認する最も直接的な方法は、片方のチャネルで何かを述べ、もう一方でそのことを尋ねることです — 正しい答えが返ってくれば、両方の入り口が同じエージェントに解決されることを証明します。接続後は、返信が正しく届くことも確認してください。別の会話ではなく、あなたがメッセージを送った会話からです。

![TelegramおよびWhatsAppに接続された1つの人格と長期記憶を持つ1つのエージェント](../images/use-case-07-multi-channel-personality-memory.png)

## 対象者

このガイドは、一つのAIアシスタントの身元を保持したまま、メッセージアプリを切り替えたい人向けです。

これは、TelegramとWhatsAppの間を移動するとき、または一つの場所からパーソナルアシスタント、研究パートナー、またはサポート作成アシスタントを管理したいときに役立ちます。

## 「一人のエージェント」の意味を理解する

1つのエージェントということは、2つのチャネルがライブチャットの全てのやり取りをリアルタイムで共有するという意味ではありません。

2つの入口はエージェントレベルの設定と永続的なコンテキストを共有しますが、各現在の会話は依然としてそれぞれのチャネルセッションに属します。

もし他のチャネルに確定した事実を知らせたい場合は、Hermesにそれを記憶させ、その後他の入口から確認してください。

ペルソナ、長期記憶、およびスキルはエージェント層に属し、ボットトークン、QR認証、会話の入口、およびメッセージ形式はチャネル層に属します。

## 前提条件

- 進行中の LightVela Hermes Agent。
で確認または容量管理することができます。まだ作成していない場合は、まず[クイックスタート](../02-quickstart.md)。

- 動作するモデル構成または利用可能なトライアルクレジット。

- 通常通り使用できるTelegramアカウントとボット。

- 通常通り使用できるWhatsAppアカウント。

- Telegramグループメッセージの設定に関する理解：BotFatherでグループプライバシーを無効にし、ボットをグループに追加してから、`@bot_username`で会話を開始する。
- WhatsAppのグループサポートは、そのチャンネルのドキュメントに従うことを理解していること。

## 手順

### 1. 1つのターゲットエージェントを選択する

LightVela コンソールを開き、どの単一の Hermes Agent が Telegram と WhatsApp の両方の接続を受け取るかを決定します。

意図的に異なるペルソナ、メモリ、スキルを持たせたい場合を除き、チャンネルごとにエージェントを作成しないでください。

### 2. Telegram を接続します

従って[チャンネルを設定 - Telegram](../configuration/channel-telegram.md)Botを作成し、対象のエージェントのTelegramチャンネル設定にHTTP APIトークンを貼り付けます。

Telegram でテストメッセージを送信し、コンソールにチャンネルが接続されていることを確認し、返信が期待されるボットに返ってくることを確認します。

もし別のTelegramのパーソナリティも設定したい場合は、次を参照してください[Telegramで個別の人格を持つHermes Agentを設定する方法](./telegram-persona-agent.md)。

### 3. WhatsAppを接続する

同じHermes Agentのチャンネル設定でWhatsAppを選択し、次に従ってQR認証を完了します[チャンネルを設定 - WhatsApp](../configuration/channel-whatsapp.md)。

対応するボットの連絡先をWhatsAppで開き、テストメッセージを送信して、返信が正常に返ってくることを確認してください。

もし別のWhatsAppのパーソナリティも設定したい場合は、次を参照してください[WhatsAppで独自の個性を持つHermes Agentを設定する方法](./whatsapp-persona-agent.md)。

### 4. エージェントレベルのパーソナリティを1つ設定する

対象のエージェントの「パーソナリティ」セクションを開き、SOUL.mdの役割、声の設定、優先順位、行動範囲が両方のチャネルで機能することを確認します。

パーソナリティはエージェント層にあるため、TelegramとWhatsAppで2つ設定する必要はありません。

パーソナリティを変更する必要がある場合は、次を参照してください[IMエージェントの役割、性格、声をSOUL.mdで定義する方法](./im-agent-persona-soul-md.md)。

変更後は、各チャネルで新しい会話を開始し、簡単なセルフチェックを実施して、新しいパーソナリティが有効になっていることを確認してください。

### 5. エージェントレベルのメモリとユーザープロファイルを設定する

コンソールで「メモリ」を開き、エージェントメモリとユーザープロファイルの容量がワークフローに適していることを確認してください。

Telegram と WhatsApp は同じクラウドエージェントの長期メモリを共有しているため、同じID、言語、設定を二度入力する必要はありません。

その後、別のチャネルに切り替えて、以下を送信します:

以前設定した日次ブリーフィング形式を使用して、短い例を見せてください。

チャンネルの挙動が異なる場合、まずそれらが同じエージェントに接続されていることを確認し、次に現在の会話が/new.を必要としているかどうかを確認してください。

### 6. 共有スキルを一度だけインストールする

スキルはエージェントの能力構成に属するため、Telegram用のインストールとWhatsApp用の別のインストールは必要ありません。

Hermesにどちらかのチャンネルで会話を通じてスキルをインストールさせ、それからスキルリストを更新させ、低リスクのタスクでスキルを検証してください。

については、参照してください[スキルを設定する](../configuration/skill.md)詳細な手順については、スキルのソース、権限、外部サービスの依存関係を確認してからインストールを確認してください。

### 7. チャンネル固有の違いをテストする

両方のチャンネルで同じプロンプトを実行します：

保存済みの設定を使用して、この内容を3つの重要なポイントにまとめます。

その後、メディアメッセージ、積極的なリマインダー、またはBotの連絡方法など、チャンネルに固有の動作をテストします。

パーソナリティと長期記憶は一貫性を保つべきですが、メッセージ形式、メディア機能、認証、および能動的配信の制限は異なる場合があります。

## 1つのエージェントと2つのエントリーポイントのための有用な構造

1つの Hermes Agent
├── 1つの SOUL.md
├── 1つのエージェントメモリとユーザープロファイル
├── 1つのインストール済みスキルセット
├── 1つのスケジュールタスクセット
├── Telegram エントリーポイント
└── WhatsApp エントリーポイント

スケジュールタスク通知の方法には、依然として明示的な対象チャンネルが必要です。

共有エージェントがあるからといって、すべてのリマインダーがTelegramとWhatsAppの両方に送信されると仮定しないでください。

## FAQ

### 私がTelegramでHermesに覚えてもらうようお願いしたことは、WhatsAppに表示されますか？

はい、両方のチャンネルが同じHermes Agentに接続されており、その情報がエージェントのメモリまたはユーザープロファイルに保存されている場合、表示されます。

現在のTelegramの会話内のすべてのメッセージが、自動的にライブWhatsAppトランスクリプトになるわけではありません。

### なぜ2つのチャンネルはまったく同じ音に聞こえないのですか？

チャンネルのメッセージ形式、メディア機能、セッション状態、およびモデルの出力は詳細に影響を与える可能性があります。

まず、両方のチャンネルが同じエージェントに接続されていることを確認し、必要に応じて/newを送信して、会話開始時に新しいSOUL.mdが読み込まれるようにします。

### TelegramとWhatsAppに異なるパーソナリティを設定できますか？

両方のチャンネルが1つのエージェントに接続されている場合、デフォルトでは同じエージェントレベルのパーソナリティを使用します。

まったく異なる役割とメモリが必要な場合は、別々のエージェントを作成し、チャンネルを個別に接続してください。

### WhatsAppグループはTelegramとメモリを共有できますか？

現在のWhatsAppのドキュメントでは、グループチャットはサポートされていないと記載されています。
Telegramは、グループプライバシーを無効にし、ボットをグループに追加し、`@bot_username`との会話を開始した後にグループメッセージをサポートします。

マルチチャネル共有はエージェント層を一貫させますが、それぞれのチャネルの設定条件や機能の境界を変更することはありません。

### スケジュールタスクは両方のチャネルに自動で送信されますか？

いいえ。

スケジュールタスクを作成または編集する際には、その通知方法と対象チャネルを確認し、配信結果を別々にテストしてください。
