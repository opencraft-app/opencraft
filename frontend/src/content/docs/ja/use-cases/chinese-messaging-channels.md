# AIエージェントをメッセージングプラットフォームに接続する方法

## 概要

**Hermes Agentをメッセージングプラットフォームに接続するのは一つの考え方に基づいています。チャネルはエントリーポイントであり、エージェントが機能するものです。1つのクラウドエージェントは接続されたすべてのチャネルで同じモデル、スキル、メモリを共有するため、プラットフォームごとに別々のボットは必要ありません。** このフローは4つのステップで構成されています:チャネルが自分の地域で利用可能であることを確認(グローバルリージョンはTelegram、WhatsApp、Discord、Slack、WeChat、QQ、WeCom、Larkをサポートしている;中国地域はWeChat、QQ、WeCom、Lark、DingTalkをサポートしています);プラットフォーム側での完全な承認による認証取得;コンソールで接続し、チャネルが接続済みと表示されていることを確認します。その後、テストメッセージを送信し、返信が届くか確認同じ会話からメッセージを送った場所で。認証情報は機密情報です - 長期的なコンテキストに書き込んだり、チャットに貼り付けたりしないでください。

![LightVela メッセージングプラットフォーム接続](../images/use-case-messaging-platforms.webp)

## 対象者

このガイドは、ウェブコンソールだけでなく、メッセージングアプリからHermesに話しかけたい人向けです。また、1つのアシスタントを複数の場所で利用したい場合にも役立ちます。例えば、個人的な用途でTelegram、コミュニティ用にDiscordといった使い分けです。

まずは1つのチャンネルから始めましょう。別のチャンネルは、異なるコンテキスト、対象者、またはデバイスの利用習慣に対応する場合にのみ追加してください。

## 前提条件

- 実行中の Hermes Agent を持つ LightVela アカウントを使用します。必要に応じて[クイックスタート](../02-quickstart.md)を作成してください。

- チャネルが接続された後にHermesが応答できるように、動作するモデル構成またはトライアルクレジット。

- 接続したいプラットフォームへのアクセス。一部のプラットフォームはQRコードによる認証フローを使用し、他のプラットフォームはボットトークンまたはプラットフォームの資格情報を必要とします。

- 設定が完了したらすぐに送信できるテストメッセージ。

## 手順 / 主要な概念

### 1. 会話に合ったチャネルを選択する

アシスタントを実際に使用する場所に基づいて選択してください。接続できるプラットフォームの数ではありません。Telegram、WhatsApp、Discord、Slack、およびWeChatは一般的な選択肢です：

| チャネル | 適しているのは |
| --- | --- |
| Telegram | 個人的なメッセージ、軽量のルーチン、直接の会話 |
| WhatsApp | 日常的なコミュニケーションと通知（WhatsAppが既にデフォルトの場合） |
| Discord | コミュニティ、開発者グループ、整理されたディスカッションスペース |
| Slack | チームのコラボレーション、ワークスペース通知、チャンネルワークフロー |
| WeChat | 毎日WeChatを使用する人の個人的な会話 |

LightVela は、他のサポートされているチャネル用のセットアップページも提供します。コンソールのチャネルページは、現在あなたの Hermes Agent に利用可能なものの信頼できる情報源です。

### 2. プラットフォーム固有の接続フローを完了する

コンソールでチャネルエリアを開き、プラットフォームを選択して、その認証または資格情報のフローに従います。無関係なプラットフォームから資格情報をコピーするのではなく、対応するガイドを使用してください：

- [Telegram](../configuration/channel-telegram.md)
- [WhatsApp](../configuration/channel-whatsapp.md)
- [Discord](../configuration/channel-discord.md)
- [Slack](../configuration/channel-slack.md)
- [WeChat](../configuration/channel-wechat.md)

ボットトークン、アプリケーションID、およびシークレットはパスワードのように扱ってください。それらをグループチャット、公共のドキュメント、または他の人へのメッセージに貼り付けないでください。認証情報が漏洩した場合は、Hermesを再接続する前に、それを発行したプラットフォームで回転させてください。

![LightVela チャネル接続ページ](../images/use-case-messaging-connection.png)

### 3. 簡単な会話で接続を確認する

コンソールにチャンネルが接続済みと表示されたら、該当プラットフォームでボットや会話を見つけ、短いメッセージを送信してください：

```text
Hi Hermes. Please reply with the channel you received this from.
```

これはフルパスを確認します：プラットフォームがメッセージを配信できるか、Hermesに動作するモデルがあるか、返信が同じ場所に戻れるかです。うまくいかない場合は、まず接続状況を確認し、その後[モデルの設定](../configuration/model.md)。

### 4. チャンネル間で共有すべき内容を決定する

複数のチャンネルが同じ Hermes Agent に接続される場合、それらは同じアシスタントへの異なる入り口です。つまり、エージェントはサポートされるチャンネル間で同じメモリ、作業設定、およびインストールされたスキルを保持できます。

で収集してください。[メモリ管理](../configuration/memory.md)でアクティブなモデルを確認して、Hermesに保持してほしい長期的なコンテキストを見直してください。もしあるチャンネルが別の対象者向けであったり、非常に異なる役割が必要な場合は、関連性のない期待を1つの会話履歴に混ぜるのではなく、ユースケースを分けて考えることを検討してください。

![チャンネル間で共有される同じ Hermes Agent コンテキスト](../images/use-case-messaging-memory.png)

もし Discord がコミュニティ用に使用したいチャンネルであれば、続けて[LightVelaとDiscordを体験：あなたのAIエージェント Discord Bot があなたのチャンネルにサービスを提供します](./discord-community-agent.md)。

## FAQ

### 複数のメッセージプラットフォームを一つの Hermes Agent に接続できますか？

はい。サポートされているチャンネルは同じエージェントを指すことができ、これにより同じ設定された動作やメモリを保持したまま、複数のメッセージングアプリからアクセスできます。

### どのチャンネルを最初に接続すべきですか？

普段最もよく使うものを選んでください。最初のメッセージを送るのが簡単な場合、パーソナルアシスタントはより役立つ可能性があります。Telegram、WhatsApp、Discord、Slack、およびWeChatにはそれぞれ詳細な設定ガイドがあります。

### チャンネルは接続済みと表示されるのに、なぜHermesが応答しないのですか？

簡単なテストメッセージを送信し、その後、アクティブなモデルやトライアルクレジットが利用可能か確認してください。問題が続く場合は、チャンネルを再接続し、[診断](../configuration/diagnostics.md)でメンテナンスオプションや最近のログを確認してください。

### 1つのボット資格情報を複数のHermes Agentで共有できますか？

プラットフォームと意図するワークフローが明確に対応している場合を除いて、共有は避けてください。1つの資格情報を1つの明確な目的に紐付けることで、トラブルシューティングやアクセス管理がはるかに簡単になります。
