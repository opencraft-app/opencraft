# AIエージェント能力を持つDiscordイベントボットを強化する

## 概要

**Discord イベントボットは、承認されたイベント情報を説明したり、繰り返しの質問に答えたり、オンボーディングをサポートしたり、1つの設定された Hermes Agent から定期的なリマインダーを送信したりできる場合に、より役立つものになります。** LightVela では、実際的な方法は、Discord を接続し、エージェントにイベント概要と安全の境界を与え、実際の参加者の質問でテストし、リマインダーや要約のための狭いオートメーションを追加することです。

このパターンは、同じ情報を多くの会話で繰り返す必要がある定期的なトーナメント、レイド、勉強会、コミュニティのローンチ、その他のイベントに最適です。

![Discord イベントコミュニティをサポートする AI エージェント](../images/use-case-discord-event-agent.webp)

## 対象者と期待される成果

このユースケースは、日付、タイムゾーン、登録、ルール、場所、直前のリマインダーに関する質問に答えるのにあまりにも多くの時間を費やしているイベント主催者向けです。

期待される成果は、回答を一貫させ、主催者が適切な情報を適切なタイミングで繰り返し伝えるのを支援するイベントアシスタントです。
それは、人間の主催者だけが決定できる事項の情報源にはならず、繰り返しの調整作業を減らすはずです。

## 前提条件

- 設定されたモデルを使った稼働中のLightVelaHermes Agentです。

- Botを追加して設定できるDiscordサーバー。

- イベント名、日付、タイムゾーン、登録手順、ルール、リンク、および連絡手段を含むレビュー済みのイベントブリーフ。

- スケジュールの更新を担当し、アナウンスを承認するモデレーターまたは主催者。

- その[Discord チャンネル設定ガイド](../configuration/channel-discord.md)および[自動化ガイド](../configuration/automation.md)。

## 手順

### 1. イベントブリーフをエージェント運用ガイドに変換する

エージェントが繰り返す可能性のある事実と、主催者の承認が必要な行動を分けることから始める。
最初のカテゴリーには、公開された開始時間、登録締め切り、参加資格ルール、チャンネルの場所が含まれます。
第二のカテゴリーには、スケジュールの変更、紛争、返金、禁止、賞の決定、例外が含まれます。

エージェントには、以下のような簡潔な操作ガイドを提供します：

```text
You are the event assistant for this Discord community.

Use the approved event brief for dates, time zones, registration, rules, and channel directions.
Answer in short steps and include the exact time zone when discussing schedules.
Never invent a time, rule, registration status, or announcement.
If event information is missing or has changed, direct the member to the event organizer.
Escalate disputes, moderation issues, eligibility exceptions, and prize questions to a human.
```

イベントを最新の短時間で保ちます。
AIエージェントは繰り返しの回答を容易にできますが、古いスケジュールを正しくすることはできません。

### 2. Discord ボットを接続し、狭い操作面を選択します

LightVelaで、Discordチャンネルを接続し、Discord開発者ポータルの認証フローを完了します。
次の[Discord 設定ガイド](../configuration/channel-discord.md)を使って設定を完了してください：

1. ボットを作成します。

2. メッセージコンテンツインテントを有効にします。

3. 最小権限の権限を設定します。

4. 次の最小権限でボットを招待します：チャンネルを見る、メッセージを送信する、メッセージ履歴を読む。

![Discord ボットの招待とサーバー選択](../images/discord-event-bot-invite.webp)

最初の展開では、1つのイベントチャンネルまたは1つのサポートされているDiscord会話を選び、ワークフローを拡張する前にそこでテストしてください。
これにより、回答、権限の挙動、および通知の配信を確認しやすくなります。

![Discord ボット権限の設定](../images/discord-5-global.webp)

### 3. 参加者が実際に尋ねる質問をテストする

少数の参加者の質問でエージェントをテストしてください：

```text
When does the tournament start in UTC+8?

What do I need to do before joining tonight's raid?

Where do I register and when does registration close?

The schedule changed. Can you announce the new time?
```

最初の三つの質問は、イベントブリーフに必要な情報が含まれていれば、簡潔で根拠のある回答を生成するはずです。
最後の質問は、エージェントに発表をでっちあげさせたり、予定をこっそり変更させたりしてはいけません。
それは主催者や承認された更新プロセスを指し示すべきです。

### 4. 参加者サポートのためにエージェントを使用する

コアな回答が信頼できるようになったら、繰り返し可能な参加者サポートのためにエージェントを使用します:

- 参加者が希望するタイムゾーンでイベントスケジュールを説明します。

- 新しいメンバーを登録、ルール、サポートチャネルに案内します。

- イベントに参加する前に必要な手順をまとめます。

- 公開されている参加資格ルールに関する質問に答えてください。

- 敏感な問題は人間のオーガナイザーに回してください。

例としてのプロンプトは次のようになります：

```text
@YourEventBot What do I need to prepare before tonight's raid?

@YourEventBot I am new here. Which channel has the tournament rules?

@YourEventBot Can you summarize the registration steps in three bullets?
```

対象のDiscord設定でサポートされているメンションまたは会話方式を使用してください。
すべてのサーバーチャンネルやグループチャットモードが同じ動作をするとは限らないことに注意してください。

### 5. 予定されたリマインダーと要約を追加する

イベントが予測可能な周期を持つ場合、Automationを使用してください。
LightVela は、一回限りの実行、特定の曜日での実行、固定間隔での実行をサポートしており、さらに任意で有効期間や通知チャネルも設定できます。
固定の曜日、固定間隔、または一回限りの実行を選択できます。
また、自動化を後で一時停止、編集、または削除することもできます。

![Discord イベントの自動タスクを設定](../images/automation-2-global-en.webp)

```text
One day before the tournament, remind the event channel about the start time, time zone, registration deadline, and rules channel.
Use only the approved event brief.
If the brief is missing a detail, tell the organizer which detail needs review.
```

この例では、ボットが「ゲームトーナメントのリマインダー」自動化を実行しています。

![Discord ボットによるトーナメントリマインダー送信](../images/discord-event-reminder.webp)

また、主催者向けにイベント後のサマリーをスケジュールすることもできます：

```text
After the event, summarize the published results, unanswered participant questions, and issues that need moderator review.
Do not infer winners, penalties, or policy decisions from incomplete information.
```

一連のリマインダーを追加する前に、最初に予定された出力を確認してください。
その[自動化設定ガイド](../configuration/automation.md)では、スケジュール、タスク指示、有効ウィンドウ、通知設定の設定場所を説明しています。

## 実用的なチェックリスト

| イベント段階 | アクション | LightVela コンポーネント | 期待される結果または失敗の信号 |
| --- | --- | --- | --- |
| 開始前 | 確認済みのスケジュール、タイムゾーン、ルール、リンク、エスカレーションパスを追加します | エージェントコンテキスト | 参加者は同じ承認済みの回答を取得できます |
| 接続 | ボットを招待し、意図した会話でテストします | Discord チャンネル | ボットは返信を行い、必要な権限のみを持っています |
| 参加者サポート | スケジュール、登録、準備に関する質問をする | Hermes Agent | 回答は簡潔で具体的、かつブリーフに基づいている |
| リマインダー | イベント前に1回メッセージをスケジュールする | 自動化 | メッセージは選択されたチャンネルに予想通りの時間に届く |
| イベント後 | 主催者向けの要約を生成する | 自動化またはチャット | 要約は、既知の結果、未解決の質問、および人間によるフォローアップを分けて示します |

## 検証と境界

イベントのワークフローを4つのテストで検証します：

1. 既知のスケジュールの詳細を尋ね、タイムゾーンが明示されていることを確認します。

2. 登録手順を尋ね、エージェントが正しいチャネルまたはリンクを指していることを確認します。

3. 意図的に欠落しているルールについて尋ね、エージェントが知らないことを認めることを確認します。

4. スケジュールの変更や運営上の決定について尋ね、エージェントが判断せずにエスカレーションすることを確認します。

現在のDiscordチャンネルのドキュメントでは、ボットの認証、サーバーおよびチャンネルの操作、メッセージ内容へのアクセス、およびチャンネルレイヤーでの積極的なメッセージについて説明しています。
また、グループチャットのサポートに関する現在の制限についても記載されています。
幅広い@メンションベースのイベントアシスタントを保証する前に、ターゲットサーバーでの正確なメンションや複数ユーザーのインタラクションの挙動を確認してください。

エージェントは、参加者の承認、ペナルティの発行、紛争の解決、未確認のスケジュール変更の発表、または秘密の取り扱いを信頼して任せるべきではありません。
人間の主催者は、イベントの公式な信頼できる情報源に対して引き続き責任を持ちます。

## FAQ

### エージェントは異なるタイムゾーンのイベントに関する質問に答えることができますか？

イベント概要に元のタイムゾーンが含まれており、参加者が対象タイムゾーンを提供した場合、公開されたイベント時間を説明することができます。
元の時間と変換後の時間の両方を含めるように依頼すると、参加者は結果を確認できます。

### 自動化ツールはDiscordのイベントリマインダーを送信できますか？

はい、Discord チャネルのドキュメントには、チャネルレイヤーでプロアクティブメッセージがサポートされていると記載されています。
リマインダーテキスト、スケジュール、有効期間、通知チャンネルを使って自動化を作成し、重要な締め切りに頼る前に最初の配信をテストしてください。

### エージェントは自分でイベントスケジュールを更新できますか？

いいえ。
承認されたスケジュールを繰り返し、提案された変更を主催者に送るべきです。
イベントブリーフを更新し、変更された時間を公開する前に次の応答を確認してください。

### これはカスタムイベントボットの代わりになりますか？

必ずしもそうではありません。
LightVela は、主なニーズが自然言語によるQ&A、根拠に基づくイベントガイダンス、スケジュールされたコミュニケーションである場合に適しています。
特定の深いコマンドや、データベースに基づく登録、トーナメント管理、外部チケッティングワークフローには、カスタムボットの方が適している場合があります。

## 結論

エージェントにレビュー済みのイベント概要を渡し、Discord に接続し、実際の参加者からの質問をテストし、リマインダーや要約のための1つの限定的な自動化を追加してください。
この手順により、イベントボットに有用なAIエージェントの動作を追加しつつ、イベントの権限、方針変更、機密性の高い意思決定は人間の主催者に任せることができます。
