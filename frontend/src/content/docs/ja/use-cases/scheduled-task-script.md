# LightVelaでスクリプトタスクを実行する

スクリプトタスクは、AIモデルを呼び出さずにBashまたはPythonスクリプトをスケジュールどおりに実行できるため、クラウドでホストされるAgentの実用的な活用方法です。
明確で予測可能なルールを持つ定期的なシステムチェックがあるときに使用できます。
ユーザーは、ディスク使用量アラートや、欠落または古くなったファイルを検出するチェックに利用しています。

## スクリプトで解決できる一般的な問題

多くの小さなシステム問題は、単純なチェックで検出できます。
しかし、このようなチェックは何かが動かなくなるまで忘れられがちです。

- ディスク使用量が気付かないうちに増える。
- 毎日のエクスポートが新しいファイルを生成しなくなる。
- バックアップファイルが古くなる。
- 他の作業に影響してから問題が発見される。

LightVelaでは、スクリプトタスクにBashまたはPythonコード、スケジュール、有効時間枠、配信チャンネルを設定できます。
タスクはモデルを呼び出さないため、モデルトークンを消費しません。
[スケジュールタスクのドキュメント](https://lightvela.ai/docs/configuration/automation?from=social_x)で利用可能なスケジュールと通知のオプションを説明しています。

## ケース1: ディスク使用量アラート

毎朝、Bashスクリプトタスクが空きディスク容量を確認し、使用率が80%に達した場合にのみ報告します。

スクリプト:

```bash
used=$(df -P / | awk 'NR==2 {gsub("%", "", $5); print $5}')

if [ "$used" -ge 80 ]; then
  echo "Disk usage alert: ${used}% used."
fi
```

![ディスク使用量アラート用の繰り返しスクリプトタスクを作成する](../images/scheduled-task-script-1.webp)

ディスク使用量がしきい値を下回る場合、スクリプトは何も出力せず、通知も送信されません。
これにより、注意が必要な場合を除き、定期チェックを静かに保てます。

## ケース2: 欠落または古いエクスポート

平日の毎晩、Pythonスクリプトタスクが最新のエクスポートファイルが存在し、過去24時間以内に更新されたかを確認します。

スクリプト:

```python
from pathlib import Path
from time import time

file = Path("/path/to/latest-export.csv")

if not file.exists() or time() - file.stat().st_mtime > 86400:
    print("Export alert: the latest file is missing or over 24 hours old.")
```

![欠落または古いエクスポートを確認する繰り返しスクリプトタスクを編集する](../images/scheduled-task-script-2.webp)

例のパスを実際のエクスポート場所に置き換えてください。
ファイルが存在して新しい場合、スクリプトは不要なメッセージを送らずに静かに完了します。

## IMで直接更新を受け取る

LightVelaでは、[チャンネル設定](https://lightvela.ai/docs/configuration?from=social_x)を通じてAgentをWhatsApp、Telegram、WeChat、Discordなどに接続できます。
一つまたは複数のチャンネルを同時に接続できます。
スケジュールタスクでは、設定済みの各チャンネルを切り替え、スクリプトアラートをどこに配信するかを決められます。

![スクリプトタスクがディスク使用量チェック結果をTelegramに直接送信する](../images/scheduled-task-script-3.webp)

スクリプトが空でない標準出力を生成すると、Hermesはその出力をIMに直接送信します。
スクリプトが何も出力しない場合、タスクは通知を送らずに完了します。

## 複数のタスクを管理する

必要な数だけスケジュールタスクを設定できます。
作成後は、スクリプトとスケジュールを編集し、一時停止し、過去の実行を閲覧できます。
特に重要なファイルにアクセスする場合は、スケジュールする前にすべてのスクリプトをテストしてください。

![スクリプトタスクを含む現在のジョブ一覧](../images/scheduled-task-script-4.webp)

LightVelaを使うと、個人用Hermes Agentが他の作業に集中している間も予測可能なチェックを継続的に処理できます。
