# 最初のHermesインスタンスをどのようにアクティブにしますか？

## 概要

**最初のHermesインスタンスを作成する手順は次の通りです：GoogleまたはGitHubでサインインし、利用可能なプランを選択し、現在のプランのルールに従ってアクティベートし、プラットフォームにインスタンスを自動で作成させ、その後モデルとチャネルを設定します。すべてブラウザ上で行われ、サーバーを購入したり、ローカルにデプロイしたりする必要はありません。Hermesインスタンスはエージェントが稼働するクラウドランタイムであり、一旦作成されると24時間オンラインの状態が維持されます。準備が整ったら、「My Hermes」コンソールを開き、モデルの設定、メッセージングチャネルの接続、スキルのインストールを行ってください。まだ自分のモデルAPIキーを持っていない場合でも、プランに含まれるモデルクレジットを使ってすぐに会話を始めることができます。**

---

Hermes インスタンスは、あなたの LightVela エージェントが存在するクラウドランタイムです。最初のインスタンスを有効化するには、次の5つのステップに従います：**Google または GitHub でサインイン → 利用可能なプランを選択 → 現在の有効化フローを通して有効化 → LightVela にインスタンスのプロビジョニングを任せる → モデルとチャンネルを設定**。すべてブラウザ上で行われ、サーバーの購入やローカルデプロイは不要です。このページでは、手順を順を追って説明します。

## このページで扱う内容

- 最初の Hermes インスタンスを有効化するための完全なプロセス

- 各ステップの前提条件と重要な詳細

- 有効化後のエージェントの設定方法と使用方法

## 前提条件

- GoogleアカウントまたはGitHubアカウント

- 現在使用可能なプランは、[サブスクライブページ](/subscribe)から選択します。国際サイトでは中国の実名認証は不要です。

- 接続する予定の少なくとも1つのメッセージングアカウント、例えばTelegram、WhatsApp、Discord、Slack、またはWeChat

---

## アクティベーションの流れ

### 1. GoogleまたはGitHubでサインイン

LightVelaを開き、GoogleまたはGitHubでアクセスを許可してください。LightVelaアカウントは、初めてサインインした際に自動的に作成されるため、別途パスワードを設定する必要はありません。今後も同じサインインIDを使用して、同じHermesインスタンスやデータにアクセスすることができます。

### 2. 購読ページで利用可能なプランを選択する

を開いて、現在利用可能なプランやクオータを確認してください。[サブスクライブページ](/subscribe)は現在利用可能なプランとクオータを表示します。[計画](./plans.md)はLaunchとCruiseのリソース構造を説明しますが、現在アクティベートできる内容についてはサブスクライブページが公式です。

国際サイトでは、中国の実名確認手続きはありません。Google または GitHub でサインインした後、現在利用可能なプランを自由に選択できます。

### 3. 現在の国際的なアクティベーションフローを通じてプランを有効化する

LightVela プランは、2026年8月18日（シンガポール時間）にパブリックベータに入り、課金を開始する予定です。パブリックベータおよび課金が正式に開始された後、ベータユーザーの既存プランの有効期限はさらに1か月延長され、新規ユーザーは Launch を14日間無料で試すことができます。プランカードの指示に従ってアクティベートし、最新情報はサブスクライブページを参照してください。

### 4. LightVela にインスタンスを自動的にプロビジョニングさせる

プランが有効化されると、LightVela は **専用のクラウド環境を自動的に割り当て、最初の Hermes インスタンスを作成します**。サーバーを購入、デプロイ、設定する必要はありません。プロビジョニングは通常すぐに開始され、インスタンスが準備完了したらコンソールを開くことができます。

### 5. Agent を設定して起動する

インスタンスが準備完了したら、コンソールを開き基本設定を完了させます：

1. **モデルの構成** — 基礎となる言語モデルを選択してください。詳細は[モデルの設定](./configuration/model.md)

2. **チャンネルを接続する** — Telegram、WhatsApp、Discord、Slack、WeChat、または他のサポートされているチャンネルを追加し、メッセージアプリからエージェントと会話します

3. **オプションでスキルや自動化を追加** — エージェントができることを拡張できます。詳細は[オートメーションを設定](./configuration/automation.md)

最初のHermes Agentがクラウドで24/7.オンラインのまま使用できる準備ができました

## FAQ

### アクティベーション後、インスタンスはどのくらいで使用できますか？

LightVelaはプランアクティベーション後にHermesインスタンスのプロビジョニングを自動的に開始します。インスタンスが準備できたら、コンソールでモデルとチャンネルを設定し、会話を開始してください。

### 請求が開始された後はどうなりますか？

請求が正式に開始された後、ベータユーザーの既存プランの有効期限はさらに1か月延長されます。新しいユーザーはLaunchを14日間無料で試すことができます。最新情報は[サブスクライブページ](/subscribe)および[LightVela 有料版の発表](./announcements/public-beta.md)をご確認ください。

### 1つのアカウントで何台のHermesインスタンスを起動できますか？

この数は、選択したプランのエージェント許容量によって異なります。LaunchおよびCruiseにはそれぞれ1つのエージェントが含まれています。詳細は[計画](./plans.md)。

### 起動後にサーバーを維持する必要はありますか？

いいえ。あなたの Hermes インスタンスはLightVelaが管理するクラウド環境で動作しています。LightVelaが運用と24/7の可用性を担当し、あなたはウェブコンソールを通じてエージェントを設定するだけです。
