# LightVela vs Today.AI：常時稼働する個人用AIアシスタントにはどちら？

## 概要

**メッセージングアプリからアクセスでき、複数モデル、スキル、自動タスクを明示的に設定できる実用的な常時稼働AIエージェントが欲しいなら、LightVelaが適しています。** 日々の個人データと先回りした提案を中心にした、アプリ型のパーソナルOSを求めるならToday.AIが適しています。

LightVelaはクラウドホスト型Hermes Agentを中心にした製品モデルを公開しています。一方、Today.AIの公開情報は、個人の文脈、プロアクティブな支援、デバイス横断の体験を強調しています。LightVelaは永続的なエージェントのホスティングと明示的な管理が分かりやすく、Today.AIは生活の全体像を組み立て、依頼前に行動するという実験的なビジョンを示しています。

## ひと目で比較

これは製品形態と日常での所有方法の比較であり、ベンチマークや価格の優劣ではありません。Today.AIについて公開されている情報は、LightVelaの製品ドキュメントより限定的です。

| 比較軸 | LightVela | Today.AI |
| - | - | - |
| **製品形態** | クラウドホスト型Hermes Agent | 個人用AIアシスタント／AIネイティブOSの構想 |
| **主なアクセス** | メッセージングチャネルとWebコンソール | ネイティブアプリとデバイス横断体験 |
| **メモリ** | 会話をまたぐ永続的なエージェントメモリ | 個人の文脈から構成する更新型メモリ |
| **先回りした仕事** | 明示的な自動タスクとスケジュールジョブ | ユーザーが依頼する前の支援を目指す設計 |
| **拡張性** | モデル、チャネル、スキル、自動タスク | モデルとエコシステムの詳細は発展途上 |
| **適するユーザー** | 今すぐ使える常時稼働エージェントが欲しい人 | プロアクティブな個人OSを試したい早期利用者 |

## 日常利用で変わること

最も単純な違いは、アシスタントがどこに存在するかです。LightVelaはHermes Agentをクラウドで動かし、Telegram、WhatsApp、Discord、Slack、WeChatなどのチャネルから同じエージェントへアクセスできるようにします。Today.AIは、デバイスやサービスから文脈を集め、重要な情報を整理し、適切なタイミングで提案する個人向けオペレーティングレイヤーとして示されています。

月曜の朝を例にすると、Today.AIの公開[ランディングページ](https://today.ai/landing)は、予定、健康シグナル、プロジェクト、人間関係、未完了の目標を結び付けるモーニングブリーフを想定しています。また、更新型メモリ、先回りした提案、アプリコネクター、クラウドコンピューター、デバイス横断管理を同じアシスタント体験の要素として紹介しています。

LightVelaでは、作業環境をより明示的に定義します。モデルを接続し、チャネルを選び、[スキル](../configuration/skill.md)を追加し、[自動タスク](../configuration/automation.md)でリマインダー、ダイジェスト、定期調査などを設定します。生活全体を観察するOSというより、自分で形を決める信頼性の高いエージェントに近い設計です。

この違いは信頼と予測可能性にも関係します。LightVelaでは、どの能力とスケジュールを有効にするかをユーザーが決めます。Today.AIは、より広い文脈を理解することで次に重要なことを見つけ、適切な時点で支援することを目指します。一方は明確な管理面を提供し、もう一方は生活をより多く理解することで役立つ環境型アシスタントを目指します。

## LightVelaが適している場合

LightVelaの強みは運用の明確さです。永続的なエージェントに必要なサーバー構築、コンテナ保守、常時起動するローカルPCを不要にします。[LightVelaの概要](../01-overview.md)では、個人端末から独立して利用できるクラウドホスト型Hermes Agentを説明しています。

メモリや先回りした作業は、エージェントが常時利用できて初めて価値を持ちます。ノートPC上のアシスタントは、スリープ、ネットワーク変更、端末交換で使えなくなることがあります。LightVelaではエージェントが独立して稼働するため、スケジュールタスクや将来の会話は個人端末のオンライン状態に依存しません。

設定の境界も明確です。Hermes Agent、モデル、チャネル、スキル、自動タスクという主要要素を分離しています。複数のチャネルを同じエージェントへ接続してメモリと振る舞いを共有し、スキルで特定ワークフローの能力を追加できます。

モデルを変更してもエージェントを作り直す必要はなく、別チャネルを追加しても別の人格にはなりません。自動タスクはリマインダー、要約、通知などの定期実行レイヤーを提供します。普段のコミュニケーションツール内で同じエージェントを使いたい場合に、特に分かりやすい選択です。

## Today.AIが適している場合

Today.AIの強みは製品ビジョンです。公開情報では、更新型メモリ、先回りした支援、拡大するコネクター、クラウドコンピューター、デバイス横断管理、コミュニティスキルを、個人中心のアシスタントへ組み合わせています。

これはLightVelaとは異なる出発点です。ユーザーが依頼を言語化する前に、予定、プロジェクト、健康シグナル、人間関係、未完了の目標を結び付け、1日の流れを理解することを目指します。

ネイティブアプリと複数デバイスでの支援を好む人にも興味深い選択です。公開資料では、普段使うデバイスを横断する体験に加え、提案だけでは足りない場合にブラウザー、ファイル、コードを扱うクラウドコンピューターを説明しています。コミュニティスキルも再利用可能なワークフローを追加する手段として紹介されています。

ただし、成熟度と公開情報には注意が必要です。Today.AIの公開ホームページは現在ウェイトリストへ案内しており、利用規約では機能が変更される可能性のある早期アクセスのベータとして説明されています。モデルやエコシステムの詳細も発展途上で、広く利用可能で完全に透明なプラットフォームという段階ではありません。

そのため、個人向けオペレーティングレイヤーの可能性を試したい早期利用者には自然な選択です。一方、文書化された設定手順、予測可能な境界、今すぐ使えるクラウドホスト型エージェントが必要なら、LightVelaの方が明確です。

## どちらを選ぶべきか

LightVelaが向いている条件：

- **常時稼働するエージェントが欲しい：** スマートフォンやPCの起動状態に依存したくない。
- **普段のチャネルから使いたい：** 新しい単独アプリだけに依存したくない。
- **明示的に管理したい：** モデル、スキル、チャネル、メモリ、自動タスクを自分で設定したい。
- **文書化された手順を重視する：** 設定を理解し、再現し、調整したい。
- **今すぐ始めたい：** 利用可能なクラウドホスト型Hermes Agentを使いたい。

Today.AIが向いている条件：

- **より広い個人文脈が欲しい：** データ、デバイス、サービスから生活の全体像を構成してほしい。
- **ネイティブアプリを好む：** Mac、iOS、Androidを横断する体験が欲しい。
- **先回りした提案を求める：** 依頼前に届く支援や日次情報ストリームに魅力を感じる。
- **広いデータアクセスを許容できる：** 個人文脈へのアクセスを体験の一部として受け入れられる。
- **早期アクセスを楽しめる：** モデルやエコシステムが変化する段階から試したい。

結論として、**現在利用でき、明示的に設定可能な永続的な個人用エージェントにはLightVela、AIアシスタントが個人向けOSへ進化する可能性を試したい早期利用者にはToday.AIが適しています。**

両者は隣接した問題を解決しています。LightVelaはエージェントを安定して利用可能かつ拡張可能にし、Today.AIはアシスタントが個人の生活リズムをどこまで理解し先回りできるかを探っています。
