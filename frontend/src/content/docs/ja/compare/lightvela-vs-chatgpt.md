# LightVela vs ChatGPT: 個人用AIアシスタントを作るにはどちらが最適ですか？

## 概要

**もしあなたの目標が、個人的なAIエージェントをホストし、それが常に利用可能で、自分自身のワークフローに属するものであれば、LightVelaの方がより直接的に適しています。** ChatGPTは、会話、ファイル、リサーチ、執筆、そしてさまざまな種類のタスクのための広範で洗練されたAIワークスペースを望む場合に適しています。どちらも支援できることは重なる部分がありますが、根本的には同じ製品ではありません。

![個人用AIアシスタントを構築するためのLightVelaとChatGPTの比較](../images/lightvela-vs-chatgpt.webp)

## 概要

| 重要なポイント | LightVela | ChatGPT |
| - | - | - |
| **主な役割** | 専用のHermes Agentをホストする | 汎用AIワークスペース |
| **ランタイム** | 専用クラウドエージェント 24時間利用可能 /7 | ChatGPT アカウント、チャット、プロジェクト、GPT |
| **パーソナライゼーション** | モデル、ツール、ペルソナ、スキル、チャンネル | メモリ、指示、プロジェクト、カスタムGPT |
| **インタラクション** | Telegram、WhatsApp、Discord、Slack、WeChat などのメッセージングチャンネル | ChatGPT Web、モバイル、デスクトップ、音声、ファイル、キャンバス |
| **最適** | 設定して戻れる永続的なエージェント | さまざまなタスクに対応できる柔軟なアシスタント |

## 重要な違い: ワークスペースかエージェントか？

LightVelaは別の質問から始まります：

> **もし、1つの実際のエージェントを作り、それを一度設定してオンラインに保ち、普段使っているメッセージングアプリに接続し、習慣を構築したい場合はどうしますか？**

LightVelaはクラウドに専用のHermes Agentをホストし、そのモデル、ツール、ペルソナ、スキル、接続されたチャネルを制御できます。このエージェントはあなたのローカルデバイスとは独立してオンラインのままでいるよう設計されています。

これによりLightVelaはより広範ではなくなりますが、より集中したものになります。

ChatGPTはほとんど何でも尋ねられる場所として非常に優れています。

OpenAIの[ChatGPT機能概要](https://help.openai.com/en/articles/9260256)では、Web検索、データ分析、音声、Canvas、メモリ、プロジェクト、スケジュールタスク、カスタムGPTなどが、プランや設定に応じてChatGPTで利用可能な機能として一覧化されています。ChatGPTは、その周囲に多数のツールを備えた幅広い会話型アシスタントとして設計されています。

プロジェクトは、ChatGPTを特に継続作業に便利にします。チャットをグループ化したり、ファイルをアップロードしたり、カスタム指示を追加したりして、プロジェクトを時間をかけて集中させることができます。OpenAIは[プロジェクト](https://help.openai.com/en/articles/10169521-projects-in-chatgpt)を長期的な作業のためのスマートな作業スペースとして説明しています。

それは強力ですが、それでもChatGPTの中のワークスペースです。

## LightVelaの方がより直接的です

エージェント自体を保持したい製品にする場合、LightVelaの方が適しています。

あなたは単にタスクのためにAIワークスペースを開くだけではありません。特定のアイデンティティ、モデル構成、スキル、そして通信チャネルを持つHermes Agentを設定しているのです。

この違いは、プロンプトではなくルーチンで考えるとより明確になります。

ChatGPTでは、プロジェクトを開いてその月の計画を手伝ってもらうことができます。

LightVelaでは、HermesをTelegramに接続し、繰り返し行うワークフローを与えれば、あなたのノートパソコンを開かなくても、明日、来週、来月も利用可能であることを期待できます。

LightVelaはまた、エージェントの設定をより直接的に示します。あなたは[モデル](https://lightvela.ai/docs/configuration/model)を選択したり、[チャンネル](https://lightvela.ai/docs/configuration)に接続したり、構成コンソールでHermesを[スキル](https://lightvela.ai/docs/configuration/skill)を通じて拡張することができます。

エージェントが同じ種類の作業を繰り返し行う必要がある場合、LightVelaの[自動化](https://lightvela.ai/docs/configuration/automation)そのパターンを、毎回手動で再起動するのではなく、エージェントの操作ルーチンの一部にします。

## ChatGPTがより適している場合

ChatGPT は、エージェントの設定を気にせずに広範な AI ワークスペースを使いたいときに適しています。作業内容が変わっても、ドキュメント、調査、画像、コード、その他の一時的なタスクの間を移動できます。

継続的な専門作業の場合、[GPT](https://help.openai.com/en/articles/8554397-create-a-gpt)は、独自の指示や知識を持つChatGPTのカスタマイズ版を作成することを可能にします。持続的なエージェントのアイデンティティを維持するよりも幅広さが重要な場合に選んでください。

## 日常使用の違い

> **LightVelaは、個人的に持っているエージェントのように感じます。ChatGPTは、非常に有能な場所に行くような感覚です。**

これは、ChatGPTが物事を記憶できないという意味ではありません。ChatGPTにはメモリ、プロジェクトメモリ、カスタム指示、カスタムGPTがあります。違いは、LightVelaが広範な会話、ワークスペース、アシスタントのコレクションではなく、一つのホストされたHermes Agentを中心にしていることです。

ある人々にとっては、ChatGPTの柔軟性こそがまさに求めているものです。彼らは一つの固定されたアシスタントのアイデンティティを望んでいません。その場その場で最適なツールを求めています。

他の人々にとっては、その柔軟性は関係を絶えず作り直しているように感じられることがあります：新しいチャット、新しいプロジェクト、新しい指示ブロック、または新しいコンテキストウィンドウ。
