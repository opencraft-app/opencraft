# LightVela vs Manus：あなたのAIエージェントをホストするのに最適なのはどちらですか？

## 概要

**個人的なHermes Agentをオンラインで維持し、設定を覚え、あなたがすでに使っているメッセージングチャンネルで活動させたい場合はLightVelaを選んでください。** 定義されたタスク（リサーチ、ブラウザ作業、レポート、ワークフローなど）を引き渡し、エージェントに成果物に向けて作業させたい場合はManusを選んでください。「エージェント」という言葉で重なりますが、日常的な使用では非常に異なる出発点から始まります。

![LightVelaを通じて、AIエージェントのホスティングや利用のためのManusと比較して、一箇所で設定することができます](../images/lightvela-vs-manus.webp)

## 概要

| 重要なポイント | LightVela | Manus |
| - | - | - |
| **開始点** | あなたの継続的なクラウドホスト型Hermes Agent | エージェントに完了してほしい目標やタスク |
| **日常の表面** | メッセージングチャネルと設定コンソール | 仮想コンピュータとブラウザワークスペース |
| **ランタイム** | 常時オンラインの専用Hermes Agent | デフォルトではタスクサンドボックス;オプションで永続的なクラウドコンピュータ |
| **メインコントロール** | モデル、チャネル、ペルソナ、スキルを選択 | 成果を説明;必要に応じて介入 |
| **最適** | 毎日戻る個人用エージェント | 自律的な調査と多段階実行 |

## 2つの異なる出発点

LightVelaはよりパーソナルな方法を取ります。クラウドで専用のHermes Agentをホストし、24/7利用可能に保ち、Telegram、WhatsApp、Discord、Slack、WeChatなど、設定されたチャンネルを通じて会話することを可能にします。[LightVelaの概要](https://lightvela.ai/docs/overview)この部分では、ホストされたモデルと、エージェントが日常のツールにどのように接続し続けるかを説明しています。

Manusは、自身の仮想コンピューターを備えた自律的な汎用AIエージェントであると自称しています：あなたは成果を与え、Manusは計画、実行、そして作業を返します。その[クラウドブラウザ](https://manus.im/docs/features/cloud-browser)は、ウェブサイトのナビゲーション、フォームの入力、情報の抽出、複数ステップにわたるブラウザワークフローの完遂が可能です。

> **LightVelaは保持するエージェントから始まります。Manusはタスクから始まります。**

## 日常使用で何が変わるか

違いは普通の火曜日に最も感じやすいでしょう。

LightVelaを使うと、やり取りは次のような感じになります：“このトピックを注視しておいて”、“明日リマインドして”、“このプロジェクトを前に進める手助けをして”、あるいは単に“前回何を決めたんだっけ？”という具合です。重要なのは完成されたひとつの成果物ではありません。時間をかけて同じHermes Agentを持ち続けることであり、そこにはあなたが選んだ文脈と設定があります。

Manusを使うと、例えば次のように言うかもしれません：“30社の競合を調査して価格を収集し、簡単な市場レポートにまとめて。”エージェントはブラウザを使って情報を収集し、結果をまとめることができます。これは、明確なゴールラインがある制約された作業に最適な形です。

つまり、設定に関する質問も異なります。LightVelaでは、どの[モデル](https://lightvela.ai/docs/configuration/model)を使用するかを決定し、接続したい[チャンネル](https://lightvela.ai/docs/configuration)を接続し、[スキル](https://lightvela.ai/docs/configuration/skill)コンソールを通じてあなたのルーチンに合うものです。Manusでは、結果の品質はしばしば、タスク、その制約、そして「完了」の状態をどれだけ明確に説明できるかで決まります。

## LightVela がより適している場所

LightVela は、タスクだけでなくエージェント自体を保持したい場合により意味があります。

ホストされたHermes Agentは、慣れ親しんだ場所に戻りたいときに便利です。同じ設定のモデル、同じ接続されたチャンネル、同じスキル、そして同じ進行中の会話のコンテキストが使えます。エージェントを利用可能にするためだけに、ノートパソコンを起動したままにしたり、サーバーを管理したりする必要はありません。

それは「この作業を私の代わりに完了して」という種類の便利さとは異なります。むしろ、考えが浮かんだときにいつでもメッセージを送れる持続的なアシスタントを持つことに近いものです。

自分の習慣に合わせてエージェントを形作ることを重視する場合、LightVelaもより適しています：モデルの構成、会話を行う場所の選択、Hermesにスキルを追加することなどです。繰り返し作業がある場合は、[スケジュールタスク](https://lightvela.ai/docs/configuration/automation)すべてのリクエストを新しいプロジェクトとして扱うのではなく、設定することもできます。

## Manusがより適している場合

Manusは、明確な出力がある限定されたブラウザタスクにより適しています。その[クラウドブラウザ](https://manus.im/docs/features/cloud-browser)ウェブサイトや認証済みセッションで動作できます。CAPTCHAやSMSなどの確認手順は引き続きあなたの操作が必要です。

- **調査または報告:** 定義されたブリーフを比較または報告に変換します。
- **ブラウザ操作:** ウェブアプリ全体で具体的なワークフローを完了します。
- **永続的な実行:** 継続して動作させる必要があるプロセスにはCloud Computerを使用してください。詳細は[ヘルプ記事](https://help.manus.im/en/articles/15392111-what-is-the-cloud-computer)。

## どちらを選ぶべきでしょうか？

次の場合はLightVelaを選んでください：

- **継続性を望む場合:** 単一のタスクを超えて利用可能なHermes Agentを望む場合。
- **メッセージングを好む場合：** 日常のチャネルでエージェントに連絡したい場合。
- **関係を形作りたい場合:** モデル、チャネル、スキル、パーソナリティを時間をかけて制御したい場合。
- **インフラを減らしたい場合:** サーバーのセットアップやローカルデバイスの保守なしで、常に稼働しているエージェントを望む場合。

次の場合はManusを選択してください:

- **完成された結果を望む場合:** エージェントに明確で複数ステップのタスクを実行させ、出力を得たい場合。
- **ブラウザで作業する場合:** ブラウザベースのツールやリサーチワークフローで多くの時間を過ごす場合。
- **タスクの概要を好む場合:** 継続的な個人用エージェントを維持するよりも、仕事を説明する方を好む場合。

正直言って、互いを補完することもできます。**LightVelaは、あなたが近くに置いておくHermes Agentになれます—メッセージを送ったり、設定したり、習慣を築いたりする相手です。Manusは、大きなブラウザ作業のために送り出す集中した作業者になれます。**
