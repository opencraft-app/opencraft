# LightVela vs Mira：個人用AIエージェントを動かすならどちら？

## 概要

**自分の習慣に合わせた1体のHermes Agentへ、再利用可能なスキル、スケジュールタスク、選んだメッセージングチャネルを組み合わせたいならLightVelaが適しています。** 仕事やコミュニティがTelegramに集まっており、会話からフォローアップ、要約、リマインダー、実行へつなげたいならMiraが適しています。

両製品ともチャット画面を超えた支援を目指しますが、出発点は異なります。MiraはTelegram中心のアシスタントで、LightVelaはより広いワークフローへ成長できる設定可能な個人用エージェントです。

![個人用AIエージェントを動かすためのLightVelaとMiraの比較](../images/lightvela-vs-mira.png)

## ひと目で比較

| 比較軸 | LightVela | Mira |
| - | - | - |
| **最適な用途** | 長期的に使う個人用AIエージェント | Telegram内の個人またはチーム向けアシスタント |
| **中心となる体験** | 1体のエージェントを習慣や好みに合わせて設定 | 会話を理解させ、その場から行動を依頼 |
| **設定の中心** | スキル、スケジュールタスク、メモリ、ペルソナ、モデル、チャネル | Telegramのチャット、グループ文脈、接続ツール、定期アクション |
| **日常の価値** | 1回の会話を超えて継続作業する一貫したエージェント | チャット、タスク、接続ツール間の切り替えを削減 |
| **強み** | 時間とともに改善する個人ワークフロー | 会話からのフォロー、ブリーフィング、コンテンツ、チーム調整 |

## 日常利用で変わること

実用上の違いは、1つのプロンプトへの回答品質ではなく、エージェントが日常のどこに存在し、その動作モデルをどこまで自分で設計したいかです。

LightVelaでは、クラウド上のHermes Agentを自分の働き方に合わせて設定し、必要が変わっても同じエージェントと会話を続けます。[スキル](../configuration/skill.md)、[スケジュールタスク](../configuration/automation.md)、[モデル](../configuration/model.md)、普段使うチャネルを組み合わせ、単発のやり取りを継続的なワークフローへ変えられます。

毎日のブリーフィング、定期ウォッチ、コンテンツ草稿、リマインダーなどを毎回作り直す必要はありません。LightVelaは、1体のエージェントと進化する1つの設定を継続して改善する設計です。

[Mira](https://mira.tg/)は異なる前提から始まります。Telegram内でネイティブに動作し、別アプリを開かずに個人チャット、グループ、チャネルから使えます。会話の文脈を記憶し、要約、意思決定の追跡、外部ツール接続、メッセージから実際のアクションへの変換を行うエージェントとして位置付けられています。

仕事の発生源が会話そのものである場合に自然です。チームはMiraをグループへ追加し、決定事項を確認したり、合意をフォロータスクへ変えたり、Telegramを離れずにブリーフィングを依頼できます。個人用ワークスペースを設定するより、共有チャット内で仕事を委任する体験に近いものです。

## LightVelaが適している場合

AIエージェントを個人の作業環境の一部として継続利用したい場合、LightVelaが適しています。直近のメッセージへ反応させるだけでなく、振る舞い、知識、使用可能な能力、実行タイミングを自分で設計できます。

毎朝の情報確認、競合ウォッチ、製品更新からソーシャル草稿への変換、週次リサーチ要約などを任せられます。重要なのは1回の完璧な回答ではなく、有用なやり取りを継続して動く仕組みに変えられることです。

スキルは再利用可能な能力、スケジュールタスクはスケジュール実行を提供します。朝のブリーフィングから始め、調査スキルを追加し、最も見やすいチャネルへ結果を送る構成が可能です。

固定された製品体験ではなく、エージェントの役割を明示的に設定したい場合にも適しています。モデル、促したい振る舞い、追加能力、表示先のチャネルを選べます。[LightVelaの概要](../01-overview.md)では、これらの要素の関係を説明しています。

トレードオフとして、LightVelaは進化する1体の個人用エージェントを中心にしています。主な目的が忙しいTelegram会話の理解と、その場からの実行であれば、Miraの方が直接的です。

## Miraが適している場合

仕事、コミュニティ、意思決定がすでにTelegram上にある場合、Miraが適しています。公式サイトでは、コンテンツ作成、受信トレイ、暗号資産モニタリング、買い物、旅行計画、リマインダー、接続ツールを支援するTelegramネイティブのアシスタントとして説明されています。リクエストが始まるチャット内に、すでに文脈があることが利点です。

チームやコミュニティにも自然に適合します。長いグループ会話を要約し、未決事項を示し、発言から担当付きのフォローアップへ変えられます。Telegramを専用タスクシステムより頻繁に使う製品チーム、創業者、クリエイター、コミュニティ運営者に有用です。

Telegram中心のモデルでも、日次ブリーフィングや定期ワークフローを支援できます。適切な時刻の要約、調査タスク、GitHub、Notion、Google Driveなどの接続サービスをチャットから利用できます。回答から行動へ移るために別の画面へ切り替える必要を減らします。

境界はTelegramへの集中です。Telegram内の社会的な文脈には強い一方、1体のエージェントのペルソナ、モデル、スキル、スケジュールタスク、複数チャネルを長期的に設計したい場合は、LightVelaの方が明示的な管理画面を提供します。

## どちらを選ぶべきか

LightVelaが向いている条件：

- **1体の個人用エージェントが欲しい：** 改善するほど役立つHermes Agentを使いたい。
- **継続性を重視する：** 同じエージェントに設定を保持して長期利用したい。
- **ルーチンを設定したい：** スキルと定期的なスケジュールタスクを習慣に合わせたい。
- **柔軟にアクセスしたい：** ワークフローに合う複数のチャネルから使いたい。
- **直接管理したい：** モデル、ペルソナ、能力、ワークフローを自分で決めたい。

Miraが向いている条件：

- **Telegramが活動の中心：** 個人作業、チームの意思決定、コミュニティ活動がチャット内にある。
- **会話の記憶が必要：** 誰が何を話し、何が未完了かを理解してほしい。
- **すぐ委任したい：** メッセージをリマインダー、タスク、要約、草稿、外部ツール操作へ変えたい。
- **グループで共有したい：** 個人とグループの会話へ参加できる共有アシスタントが欲しい。
- **設定を最小化したい：** 別のワークスペースを構成せず、すぐチャットを始めたい。

結論として、**自分のルーチンに合わせて育てる1体の個人用AIエージェントにはLightVela、Telegramが会話・仕事・フォローアップの中心ならMiraが適しています。**

異なる実行モデルのアシスタントとも比較したい場合は、[LightVela vs Grok Bot](./lightvela-vs-grok-bot.md)を参照してください。
