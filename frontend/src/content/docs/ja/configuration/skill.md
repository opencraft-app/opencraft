# スキルを設定する

## 概要

**スキルは、あなたのHermes Agentが呼び出せる追加機能パックで、基本的な会話を超えて、To-Doの整理、日報の生成、Webブラウジング、ニュース検索、画像生成などの具体的なタスクに対応できます。スキルはSkills.shとClawHubから提供され、これらのスキルマーケットプレイスはOpenClawとHermesで共有されています。スキルは任意で、エージェントはスキルがインストールされていなくても通常通り会話が可能です。そのため、推奨されるアプローチは、能力の限界に達した後でのみスキルをインストールすることです。インストール方法は2通りあります — コンソールのスキルセクションで名前で検索する方法、または会話中にエージェントにインストールを依頼する方法です。インストール済みのスキルはコンソールから削除できます。**

---

スキルとは、Hermes が呼び出す追加の能力パッケージです。スキルは、タスクの具体的な処理を基本的な会話以上に拡張します。例えば、ToDo の自動整理、日報の生成、ウェブページの閲覧、ニュースの検索、画像の生成などがあります。

すべてのスキルは から提供されます[**Skills.sh**](https://skills.sh/)および[**ClawHub**](https://clawhub.ai/)— OpenClawとHermesが共有するスキルマーケットプレイス。

> 💡 **スキルは任意です**
>
> Hermesはデフォルトではスキルをインストールしません。Hermesはスキルがインストールされていなくても通常通りチャットできます。スキルは特定のタスクの能力を拡張するためにのみ使用されます。使用中に能力の限界を発見した後、必要に応じてインストールすることをお勧めします。

## スキルの位置付け

Hermesを大規模モデルと組み合わせることでユーザーにインテリジェントなAIアシスタントを提供すると、スキルはそれの「手足」となります。スキルは既に展開されたHermesの能力の境界をさらに拡張することができます。

スキルはHermesの「アプリケーション」と考えることができます：

- 基本的な会話能力 = オペレーティングシステム

- スキル = 必要に応じてインストールされるアプリケーション


各スキルは単一のタスクに焦点を当てています。例えば：

- ウェブページを閲覧したり、ブラウザで情報を検索したりする

- 日々のやることを自動で整理する

- 予定されたニュースブリーフィングを送信する

- 説明から画像を生成する

- リアルタイムの株式・ファンド情報を照会する

- チャット記録を構造化されたノートに整理する


Hermesは会話の文脈に基づいて、自動的に対応するスキルを呼び出すかどうかを判断します。ユーザーが指定する必要はありません。

## 方法1：コンソールパネルからインストール（近日公開）

LightVelaコンソールは、"スキル"ボタンに視覚的なスキル設定エントリを提供します。Skills.shまたはClawHubで見つけたスキル名を入力して、素早くインストールできます。

### 1. LightVelaコンソールに入る

LightVelaにサインインし、右上の "マイAIパートナー" をクリックしてコンソールに入り、"スキル" ボタンを見つけます。

### 2. 検索してインストール

記録されたスキル名を検索ボックスに入力します（例：`gmail`）そして **+** ボタンをクリックします。

![](../images/clawhub-install-global-en.webp)

### 3. 会話で利用可能か確認する

接続されたチャンネルに戻ります（Telegram / WhatsApp / Discord / Slack / WeChat）。最初に Hermes にスキルリストの更新を依頼し、現在利用可能なスキルを確認します：

```
Please update your skill list
```

```
What skills are currently available?
```

新しくインストールしたスキルがリストに表示されたら、会話で使用を開始できます。

## 方法 2: 会話を通じて直接インストールする

コンソールパネルを使用する以外に、Hermesに直接会話を通じてスキルをインストールするよう依頼することもできます。インストールするスキルは、依然としてSkills.shまたはClawHubにリストされている必要があります。

### 1. 会話チャンネルが利用可能か確認する

まず、Hermesが少なくとも1つのチャンネル（Telegram / WhatsApp / Discord / Slack / WeChat）に接続されており、現在正常にチャットできることを確認してください。

### 2. Hermesにインストールするスキルを伝える

以下のコマンドを参照として使用します。Hermesにインストールしたいスキルを伝え、`[skill name]`をSkills.shまたはClawHubからの実際の名前に置き換えてください：

```
Please install a skill from Skills.sh or ClawHub. Its name is [skill name]
```

例えば、`mcd`（マクドナルドのアシスタント）をインストールするには：

```
Please install a skill from Skills.sh or ClawHub. Its name is mcd
```

すべてが順調に進めば、Hermes は直接インストールを完了し、結果を知らせます。

> ⚠️ **高リスクスキルの二重確認**
>
> 選択したスキルが Skills.sh または ClawHub 上で高リスクとして表示されている場合（安全でない動作を含む可能性があります）、Hermes はあなたに注意を促し、インストール前に二重確認を要求します。スキルの動作を十分に理解したうえで、続行するかどうかを判断してください。判断がつかない場合は、注意して進めてください。

### 3. インストール結果を確認する

Hermesにスキルの使い方を表示して、インストールが成功したか確認するように依頼できます：

```
Please show me how to use it
```

または、スキル名を明示的に指定することもできます：

```
Please show me how to use mcd
```

## スキル使用例

`agent-browser`ブラウザ操作スキルを例として、インストール後にHermesに以下のタスクを実行するよう依頼できます。

> ℹ️ **注意**
>
> 以下の例ではWeChatチャンネルを使用しています。Telegram、WhatsApp、Discord、およびSlackも同じ方法で動作します。

### シナリオ1：ウェブページを閲覧する

```
Use the browser to visit Baidu and tell me what is on the page
```

Hermesはページを開き、内容をテキスト形式で返します。

### シナリオ 2: ブラウザで情報を検索する

```
Use the browser to look up today's top 5 trending news stories
```

### シナリオ 3: 複数ステップの複雑なタスク

```
Use the browser to search ClawHub and find the currently most-installed email skill
```

このタスクには、ウェブページを開く、読み込みを待つ、内容を入力する、ボタンをクリックするといった複数のステップが含まれます。比較的複雑です。Hermes はこれらのステップを完了して結果を返します。

![](../images/clawhub-browser-example-global-en.webp)

## インストールされたスキルを削除する

もう使用しないスキルがある場合は、会話を通じて Hermes に削除を依頼できます。

### 1. 現在インストールされているスキルを確認する

```
What skills do you currently have installed?
```

### 2. 特定のスキルの削除をリクエストする

削除したいスキルを見つけて、削除コマンドを送信してください:

```
Please delete the email skill
```

すべてが順調に進めば、Hermesは削除を完了し、その結果を知らせます。

> ℹ️ **二次確認の可能性**
>
> 使用しているモデルやHermesの性格設定によっては、削除時に注意を促す場合があります。実際の必要に応じて確認を返信してください。

### 3. 削除結果を確認する

現在インストールされているスキルを再度確認し、対象のスキルがリストから削除されていることを確認してください：

```
Check again what skills you currently have installed
```

> ℹ️ **現在は会話ベースでの削除のみサポートされています**
>
> LightVelaはクラウドホストモードを使用しており、ユーザー向けのファイルシステム操作は提供していません。スキルはHermesとの会話を通じてのみ削除できます。

---

## 成功状態

- 対象のスキルはコンソールの「インストール済みスキル」リストに表示されます

- 会話で関連するリクエストを行うと、Hermesはスキルを正しく認識して呼び出すことができます

- スキルは会話を通じて通常どおり削除できます


---

## インストールの安全上のヒント

スキルは実行時に Hermes の機能を呼び出す権限を持ち、次のことが含まれる場合があります：

- 外部 API の呼び出し（対応するクォータの消費）

- 会話内容の読み取りまたは送信

- スケジュールされた操作の実行

インストールする前に、スキル作成者が信頼できることを確認してください。次のことを推奨します：

- 公式に認証されたスキルを Skills.sh または ClawHub で優先的に選ぶ

- ダウンロード数が多く、評価の高いスキルを優先する

- スキル説明で権限の詳細を注意深く読んでください

- 説明が不明瞭なスキルや見慣れない作者のスキルには注意してください

## FAQ

### スキルが見つかりません

**考えられる原因**：名前が間違っているか、スキルがSkills.shまたはClawHubから削除されている可能性があります。

**解決策**: 次にアクセスしてください[**Skills.sh**](https://skills.sh/)または[**ClawHub**](https://clawhub.ai/)正確なスキル名と現在の状況を確認するため。

### インストールは成功するが会話では効果が現れない

**考えられる原因**：モデルがスキルを使用すべきことを認識していないか、スキルリストが更新されていない可能性があります。

**解決策**：

1. 会話で「スキルリストを更新してください」と送信してください。

2. 「XXスキルを使用してYYを完了してください」のように、より明確な指示を使用してください。


### インストール時に「レート制限が発動しました。後で再試行してください」と表示されます。

**考えられる原因**：Skills.shとClawHubは、サービスの安定性を保護するためにAPIレート制限を適用します。

**解決策**：しばらく待ってから再試行してください。ピーク時間を避けることをお勧めします。

### スキルの呼び出しが失敗し続けます

**考えられる原因**：

- スキルが必要とする外部サービスが一時的に利用できない

- スキルのバージョンが古い

- 対応するモデルが、ツール呼び出しなどスキルに必要な機能をサポートしていない


**解決策**：

- Skills.sh または ClawHub でスキルのコメントや最新バージョン情報を確認してください

- ツール呼び出しをサポートするモデルに切り替えてみてください

- 問題が解決しない場合は、スキル作者に連絡してください


### インストールされているスキルが多すぎると、Hermesの応答が遅くなります

**考えられる原因**: スキルが多いほど、エージェントの意思決定の負担が増えます。

**解決策**: よく使うスキルだけを残し、使用しないスキルは削除してください。

### スキルの開発方法

Skills.shおよびClawHubの開発者向けドキュメントを参照してください（利用可能な場合）。
