# Botの管理

## 概要

**BotはHermes Agent内の独立したプロフィールです。メインBotはAgentと同時に作成され、追加Botごとにモデル設定、ペルソナ、メモリ、Skills、チャネル、スケジュールタスクを個別に持てます。Botを作成するときは、既存BotをコピーするかBasic setupを使用します。メインBotを含む作成可能数はプランによって決まります。**

> **国際サイトでの提供状況**
>
> 追加Botの作成機能は段階的に提供されています。この期間中、国際サイトでは**Create Bot**入口がデフォルトで表示されません。入口が利用できない場合は、引き続きメインBotを使用してください。

## このページの内容

- Hermes AgentとBotの関係
- 既存BotのコピーまたはBasic setupによるBot作成
- 各作成方法で継承される内容
- Botの切り替え、名前変更、削除

## 開始前の確認

1. Hermes Agentが実行中であることを確認します。
2. プランに追加Botの空きがあることを確認します。上限にはメインBotも含まれます。
3. **Agents**を開き、管理するAgentを選択します。

## Botを作成する

作成入口が利用できる場合：

1. **New Bot**を選択します。
2. 60文字以内のBot名を入力します。
3. 作成方法を選択します。
4. 継承内容を確認し、**Confirm creation**を選択します。
5. 新しいBotのプロビジョニングが完了してから、設定または使用を開始します。

表示されるコピー方法は、現在選択中のBotによって異なります。メインBotでは**Copy current (main Bot)**が表示されます。追加Botでは**Clone current**または**Clone main Bot**を選択できます。

## 作成方法を選ぶ

| 方法 | 継承される内容 | 継承されない内容 |
| --- | --- | --- |
| Copy current、Clone current、Clone main Bot | 選択したコピー元Botのモデル、ペルソナ、Skills、ユーザー設定、長期メモリ | 現在の会話、チャット履歴、スケジュールタスク、実行状態、チャネル接続 |
| Basic setup | メインBotの現在のプライマリモデルとProvider認証情報、および組み込みシステムSkills | フォールバックモデル、その他の設定済みモデル、ペルソナ、メモリ、メインBotに後からインストールしたSkills、チャネル、スケジュールタスク |

**Basic setupは空のBotではありません。** 開始に必要な最小限のモデルと組み込みSkill設定を保持しながら、個別の振る舞い、メモリ、連携を分離します。

## 新しいBotを確認する

プロビジョニング完了後：

1. 入力した名前の新しいBotタブが表示されることを確認します。
2. 新しいBotを選択し、モデルとSkillsが選んだ作成方法に合っていることを確認します。
3. [Soul](./personality.md)の追加、[Skills](./skill.md)のインストール、チャネル接続、[スケジュールタスク](./automation.md)の作成を行う前に、対応する設定ページを開きます。

## 複数のBotを使う

BotタブはAgentコンソールの上部に表示されます。モデル設定、ペルソナ、メモリ、Skills、チャネル、スケジュールタスク、診断を変更する前に対象Botのタブを選択してください。

各Botは独自のプロフィールとデータを持ちます。あるBotへの変更がほかのBotへ自動反映されることはありません。コンソールの**Chat**機能は現在メインBotでのみ利用でき、Agent単位のメンテナンスもメインBotから実行します。

Bot名を変更するには、対象Botを選択して表示名を編集します。新しい名前は60文字以内です。

## Botを削除する

- 追加Botを削除すると、そのBotのプロフィールとデータが完全に削除されます。
- Botが所有するチャネルを切断してから削除します。
- メインBotを削除する前に、追加Botをすべて削除します。
- メインBotを削除すると、すべてのチャット、設定、インストール済みSkills、メモリ、関連データを含むAgent全体が削除されます。

削除は元に戻せません。確認メッセージをよく読み、指定されたBot名を入力してから確定してください。

## トラブルシューティング

### Botを追加作成できないのはなぜですか？

国際サイトでの段階的な提供中で作成入口が非表示になっている、現在のAgentバージョンでマルチBot機能が利用できない、Agentが実行されていない、またはプランのBot上限に達している可能性があります。

### コピーしたBotに会話、タスク、チャネルがないのはなぜですか？

これらは意図的にコピーされません。必要に応じて、新しいBotでチャネルを再接続し、スケジュールタスクを作り直してください。

### Basic setupでもモデルとSkillsが表示されるのはなぜですか？

Basic setupはメインBotの現在のプライマリモデルとProvider認証情報を継承し、組み込みシステムSkillsのみを保持します。メインBotのほかのモデル、ペルソナ、メモリ、後からインストールしたSkills、チャネル、スケジュールタスクはコピーしません。
