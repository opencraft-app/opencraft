# Workbench

## 概要

**My Workbenchでは、LightVelaのAI Agentを使って静的Webサイトを作成、デプロイ、管理できます。開始テンプレートを選ぶか、サイトを最初から説明し、Agentと一緒に内容を調整して公開できます。**

![My Workbenchの概要](../images/workbench-01.png)

デプロイ後は、公開アドレス、現在の状態、既存のワークベンチを一つの場所で確認できます。

ベータ版に関する注意：My Workbenchはベータ機能です。機能の進化に伴い、生成とデプロイの手順が変更される場合があります。

## My Workbenchでできること

My Workbenchは、Agentチャットと管理された静的Webサイトのワークフローを接続します。
自分のワークベンチの「worksite」を開始するか、用意されたテンプレートを選び、Agentと対話して内容を調整し、専用リンクでサイトをプレビューできます。

![My Workbenchページ](../images/workbench-02.png)

LightVelaがホスティング処理を管理するため、別のホスティングサーバーやクラウドアカウントを設定する必要はありません。

## My Workbenchを開く

1. [https://lightvela.ai/agents/](https://lightvela.ai/agents/)を開きます。
2. 左側のナビゲーションでMy Workbenchを開きます。

Workbenchページには、現在の使用量、利用可能なテンプレート、既存のワークベンチが表示されます。

## 開始テンプレートを選ぶ

開始テンプレートを使うと、明確な方向性から始められます。
作成したいWebサイトの種類に応じてテンプレートを選べます。

- Clean Utility Dashboard：フォーム、情報検索、軽量な社内ツール。
- Data Dashboard：主要指標、傾向、ビジネス概要、日次レポート。
- Campaign Landing Page：キャンペーンページ、登録ページ、交換ページ。
- Personal Showcase：ポートフォリオ、個人ホームページ、サービス紹介。

テンプレートを選ぶと、準備済みのリクエストが入力されたAgentチャットが開きます。

![開始テンプレート](../images/workbench-03.png)

空白のオプションを選び、Agentに要件を段階的に確認してもらうこともできます。

## AgentチャットでWorkbenchを作成する

1. 開始テンプレートを選ぶか、空白のワークベンチから始めます。
2. Webサイトの目的、対象者、内容、ビジュアル方針を説明します。
3. Agentが要件を確認する質問に回答します。
4. 生成結果を確認し、Agentに変更を依頼します。
5. Webサイトの準備ができたら、Agentに最新バージョンの公開を依頼します。

現在のワークフローでは、生成サイトにReact、TypeScript、Tailwind CSS、一般的なUIライブラリを使用します。

![AgentチャットでWorkbenchを作成](../images/workbench-04.png)

Agentには、内容を編集可能に保ち、事前に用意した架空のビジネスデータを避け、適切な場合はブラウザーのlocal storageを一時的なローカルデータに使うよう指示されています。

## Workbenchの状態を確認する

各ワークベンチにはデプロイ状態があり、訪問できるかどうかを確認できます。

| 状態 | 説明 |
| --- | --- |
| Building | Webサイトを生成または準備しています。 |
| Publishing | 最新バージョンを公開しています。 |
| Online | Webサイトを公開アドレスで利用できます。 |
| Update failed | 最新の生成または公開に失敗しました。 |
| Offline | Webサイトを利用できないか、削除されています。 |

ワークベンチがOnlineで公開アドレスを持つ場合は、Visitを選択して開きます。

![Workbenchの状態とWebサイトのプレビュー](../images/workbench-05.png)

ワークベンチがBuildingまたはPublishingの場合は、処理が完了するまで待ち、必要に応じてページを更新します。

## 既存のWorkbenchを管理する

既存のワークベンチ一覧には、Webサイト名、公開アドレス、作成日、現在の状態が表示されます。

ワークベンチを更新するには、Agentチャットに戻って変更内容を説明します。
変更結果を確認したら、Agentに更新版の公開を依頼します。

ワークベンチを削除するには：

1. 一覧から対象のワークベンチを探します。
2. 削除操作を選択します。
3. 削除を確認します。

ワークベンチを削除すると、すぐにオフラインになり、関連ファイルも削除されます。
この操作は取り消せません。

## Workbenchの割り当てとホスティング制限

Workbenchの上限はプランによって異なります。

- Launchプラン：1つのワークベンチを作成できます。
- 上位プラン：最大5つのワークベンチを作成できます。

上限に達した場合は、別のワークベンチを作成する前に既存のワークベンチを削除するか、プランをアップグレードします。

## よくある問題

| 問題 | 考えられる原因 | 対処方法 |
| --- | --- | --- |
| Workbenchページでサインインを求められる | セッションの有効期限が切れています。 | 再度サインインしてMy Workbenchを開きます。 |
| 新しいワークベンチを作成できない | プランの上限に達した可能性があります。 | 使用量を確認するか、未使用のワークベンチを削除します。 |
| 状態がBuildingまたはPublishingのままになる | デプロイ処理中です。 | 少し待ってからページを更新します。 |
| Visit操作を利用できない | ワークベンチがまだOnlineではありません。 | 状態がOnlineになるまで待ちます。 |
| 状態がUpdate failedになる | 最新の生成または公開に失敗しました。 | Agentの回答を確認し、必要な変更を加えて再試行します。 |
| 別のブラウザーでWebサイトのデータが消える | データがブラウザーのlocal storageに保存されています。 | 共有または永続データが必要な場合はバックエンドサービスを使います。 |
| 削除したワークベンチが一覧に残る | 削除処理中です。 | クリーンアップを待ってページを更新します。 |

## 現在の制限

My Workbenchは、Agentチャットを通じて静的Webサイトを作成、ホスティングするための機能です。
サーバー側ストレージ、管理データベース、永続的なフォーム処理、共有アカウント、任意のバックエンドサービスは提供しません。
ワークベンチ数、トラフィック、ストレージ、パッケージサイズ、ファイル数は有効なプランによって異なります。

## FAQ

### どのようなWebサイトを作成できますか？

ダッシュボード、社内ツール、キャンペーンページ、ポートフォリオ、ランディングページなどの静的フロントエンドWebサイトを作成できます。

### コーディング経験は必要ですか？

いいえ。
自然言語で希望を説明すると、Agentが要件確認、生成、公開を案内します。

### 既存のワークベンチを更新できますか？

はい。
Agentチャットに戻り、変更を説明して結果を確認した後、Agentに更新版の公開を依頼します。

### Webサイトにデータを保存できますか？

静的Webサイトは、現在のブラウザーのlocal storageにデータを一時保存できます。
LightVelaはWorkbenchサイト向けのサーバー側永続ストレージを提供しません。

### 別のホスティングアカウントは必要ですか？

いいえ。
LightVelaが静的ワークベンチのホスティングワークフローを提供します。

### ワークベンチをすぐに利用できないのはなぜですか？

生成と公開には時間がかかる場合があります。
現在の状態を確認し、Onlineになってから公開アドレスを開きます。
