# チャット

## 概要

**チャットページは、LightVelaコンソールに組み込まれたメッセージングウィンドウであり、外部チャネルに接続せずにHermes Agentと直接やり取りできます。モデルを設定した直後にエージェントが正常に動作するか確認するのに便利です。同じエージェント、同じペルソナ、同じ長期記憶を外部のメッセージングチャネルと共有しているため、ここで設定した好みは他のチャネルにも適用され、その逆も同様です。**

---

チャットウィンドウを使ってHermes Agentとやり取りするには、「チャット」ページを開いてください。

## 会話の記憶

Hermes Agent は会話が続くにつれて自動的に反復および進化します。「メモリ」ページを訪問して、あなたの記憶について詳しく学びましょう。

![](../images/agentchat-2-global-en.webp)

### 記憶の仕組み

Hermes Agent は次の2つの仕組みによって自動的に長期記憶を構築します:

- **コンテキスト圧縮**: 長い会話から重要な情報を抽出して、長期的な記憶にまとめます。

- **主要な記憶ノード**：個人の好み、使用習慣、後で再利用する価値のあるプロジェクト関連情報を自動的にキャプチャします。

### 記憶の保存方法

記憶は2種類の文書に永続化されます：

- `MEMORY.md`：プロジェクト情報、実行環境、協力規約

- `USER.md`：ユーザーの個人的な好み、使用習慣、コミュニケーションスタイル

長期的価値のある内容のみが保持されるため、Hermes Agentは後の会話で一貫したパーソナライズされた応答を提供できます。
