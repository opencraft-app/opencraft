# チャット

## 概要

**LightVelaにサインインしてプランを有効化すると、外部メッセージングチャネルを接続しなくても、My Agentのサイドバーにある日常のチャットから選択中のBotと会話できます。サイドバーにはそのBotの会話が表示され、新しい会話の開始や既存の会話の再開ができます。送信前にBotがオンラインで、プランのモデルクレジットが利用可能か、モデルが設定済みであることを確認してください。**

![サイドバーを閉じた国際版LightVelaの新規チャット画面](../../images/chat-overview-en.webp)

## 会話を始める

1. My Agentを開き、サイドバー上部で使用するBotを選びます。
2. 日常のチャットを開いて新しい会話を選びます。概要ページのBotカードから、そのBotの新しい会話を始めることもできます。
3. 入力欄に質問や依頼を書き、送信します。
4. 会話画面で返信を確認します。新しい会話の入力欄はすぐに表示されます。接続中に送信したメッセージは、接続後に自動で送信されます。既存の会話を開くときは、待機メッセージが短時間表示されることがあります。

Webチャットに外部チャネルの接続は不要です。同じBotをTelegram、WhatsApp、Discord、WeChatで使う場合は、チャネル画面で接続してください。

## 会話の再開と管理

選択中のBotの最近の会話はチャットの下に表示されます。タイトルを選ぶと再開でき、「もっと見る」で古い会話を表示できます。各会話のメニューから名前の変更や削除ができます。Botを切り替えると、そのBotの会話一覧に変わります。

Hermesは長期的に役立つ好みやプロジェクト情報を必要に応じて保存します。選択中のBotの長期記憶は[メモリ](./memory.md)で確認できます。新しい会話を始めても、その記憶は消えません。

## 結果の確認とトラブル対処

- **正常な状態**：送信したメッセージが会話に表示され、Botが返信し、再読み込み後もサイドバーから会話を再開できます。
- **読み込み表示が続く場合**：Botがオンラインか確認し、ページを再読み込みしてください。入力欄が表示されるまで待ちます。
- **送信できない、または返信がない場合**：プランのモデルクレジットまたは[モデル設定](./model.md)を確認し、Botが一時停止していないことを確かめてください。Webチャットに外部チャネルは不要です。
