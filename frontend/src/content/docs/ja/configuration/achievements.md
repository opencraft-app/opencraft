# Achievements

## 概要

**Achievements ページでは、現在の Bot に紐づく Hermes Agent の利用進捗を確認できます。解除済み、発見済み、シークレット Achievements、到達した最高ティアに加えて、各カードの状態、カテゴリ、進捗、カウントルール、利用できる場合は発生元セッションを表示します。** 現在の Bot の Hermes 履歴を再スキャンし、ツール利用、デバッグ、モデル設定、メモリ、Skills、ドキュメント作業、自動化などの行動が認識されたかを確認できます。

![統計カード、状態フィルタ、カテゴリフィルタ、Achievements カード一覧を表示する Achievements ページ](../../images/achievements-overview.webp)

---

Achievements は手動で設定するものではありません。LightVela は、現在の Bot の Hermes Agent が過去に行った操作や会話履歴から Achievements を生成します。どの Agent 機能をすでに試したか、また Achievements モジュールが最新の履歴を読み取っているかを確認するために使います。

LightVela を使い始めたばかりの場合は、まず [Chat](./agent-chat.md)、[Skills の設定](./skill.md)、[メモリ管理](./memory.md)、[Scheduled Tasks](./automation.md) などの基本操作を試し、その後 Achievements に戻って進捗を確認してください。

## はじめる前に

1. LightVela にサインインし、少なくとも 1 つの Hermes Agent が有効であることを確認します。
2. 確認したい Bot のコンソールを開きます。
3. 意味のある進捗を確認するには、その Bot に実際の会話、ツール呼び出し、設定変更、または Scheduled Task の履歴が必要です。

Achievements は Bot 単位で読み取られます。別の Bot に切り替えると、スナップショットと進捗が異なる場合があります。

## Achievements を開く

1. LightVela にサインインします。
2. My Hermes コンソールを開きます。
3. 設定ナビゲーションで Achievements を選択します。
4. 現在の Bot の Hermes 履歴が読み込まれるまで待ちます。

読み込みが完了すると、統計カード、状態フィルタ、カテゴリフィルタ、Achievements カード一覧が表示されます。

## 統計カードを読む

ページ上部には 4 つの統計が表示されます。

| 統計 | 意味 |
| --- | --- |
| 解除済み | 条件を満たした Achievements の数と、現在表示可能な合計数です。 |
| 発見済み | 進捗はあるが、まだ解除されていない Achievements です。 |
| シークレット | 関連する行動が検出されるまで正確な条件が非表示の Achievements です。 |
| 最高ティア | 現在の Bot が到達した最高ティアです。順序は Copper、Silver、Gold、Diamond、Olympian です。 |

ページに Hermes 履歴を読み取り中という表示がある場合、Achievements モジュールはまだセッションをスキャンしています。統計を判断する前に完了を待ってください。

## Achievements を絞り込む

統計の下にある 2 つのフィルタを使います。

1. **状態フィルタ**: すべて、解除済み、発見済み、シークレットを切り替えます。
2. **カテゴリフィルタ**: Agent Autonomy、Debugging Chaos、Vibe Coding、Hermes Native、Research/Web、Tool Mastery、Model Lore、Lifestyle などで絞り込みます。

一致する Achievements がない場合は、両方のフィルタをすべてに戻してください。それでも空の場合は、現在の Bot の履歴を再スキャンします。

## Achievements カードを読む

各カードには次の情報が含まれることがあります。

| 項目 | 意味 |
| --- | --- |
| 名前と説明 | その Achievement が表す Hermes Agent の行動です。シークレット Achievements は発見されるまで非表示として表示されます。 |
| 状態 | 解除済み、発見済み、またはシークレットです。 |
| ティア | ティア付きの解除済み Achievements では Copper、Silver、Gold、Diamond、Olympian が表示されます。 |
| 進捗 | 現在の進捗、次のしきい値、または割合です。シークレット Achievements では条件が非表示になります。 |
| カウントルール | 展開すると、ツール呼び出し、ログ確認、モデル設定、ドキュメント作業など、何が数えられているかを確認できます。 |
| 発生元セッション | 一部の Achievements では、進捗の根拠になったセッションタイトルが表示されます。 |

カウントルールは Hermes Agent の履歴から取得されます。カードにルールが返されていないと表示される場合でも、その Achievement が解除できないという意味ではありません。

## 履歴を再スキャンする

会話、ツール呼び出し、設定変更を終えたばかりなのにページが変わらない場合は、履歴を再スキャンします。

1. Achievements を開きます。
2. 右上の再スキャンボタンをクリックします。
3. ボタンの回転が止まるか、履歴読み取りメッセージが消えるまで待ちます。
4. 統計カードと関連する Achievements カードが更新されたか確認します。

再スキャンは現在の Bot の Hermes 履歴を読み取ります。履歴が長い Bot では時間がかかる場合があります。

## 進捗が認識されたか確認する

実際の操作を完了した後は、次の手順で確認します。

1. 現在の Bot で、ログ確認、ツール利用、モデル設定変更、Scheduled Task の実行、ドキュメント更新など、カウント対象になり得る操作を行います。
2. Achievements に戻って再スキャンします。
3. 状態フィルタで発見済みまたは解除済みを選びます。
4. 関連カードのカウントルールを開き、進捗、割合、発生元セッションが変わったか確認します。

変化がない場合は、まずその操作が表示中の Bot で行われたことを確認してください。

## FAQ

### 機能を使った直後に Achievement が更新されないのはなぜですか？

ページは現在の Bot の履歴スナップショットを読み取ります。直近の操作後は再スキャンが必要な場合があります。履歴が多い場合もスキャンに時間がかかります。

### シークレット Achievements があるのはなぜですか？

シークレット条件は、Hermes Agent が関連行動を検出した後に表示されます。デバッグ、ツール、メモリ、Skills、プラグイン、モデル設定、自動化のワークフローで Hermes Agent を使い続けると、徐々に開示されます。

### Achievements の読み込みに失敗するのはなぜですか？

Hermes Agent が一時的に利用できない、データ解析に失敗した、Achievements コマンドが失敗した、といった原因が考えられます。まず更新または再試行し、続く場合は [Diagnostics](./diagnostics.md) でサービス状態とログを確認してください。

### Bot を切り替えると Achievements が変わるのはなぜですか？

Achievements は現在の Bot の履歴から読み取られます。Bot ごとに会話、ツール呼び出し、メモリ、Skills、モデル設定履歴が異なるため、進捗も異なります。

### Achievements はプラン、クレジット、権限に影響しますか？

いいえ。Achievements は利用進捗を表示するだけです。プラン、AI クレジット、Bot クォータ、権限は変更しません。課金については [Plans](../plans.md) と [Credits](../credits.md) を確認してください。
