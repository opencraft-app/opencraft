# メモリ管理

## 概要

**メモリとは、Hermesが会話やデバイスを跨いで重要な情報を保持することを可能にするものです — あなたの好み、あなた自身、現在取り組んでいること、そして長期的なコラボレーションを通じて蓄積された経験です。メモリはHermesを単発の質問応答から、時間とともにあなたをより理解するアシスタントへと変える基盤です。メモリはエージェントの内部とモデルの外部に存在するため、モデルを切り替えても忘れることはありません。コンソールのメモリとユーザープロファイルページで、蓄積された内容の確認、編集、削除が可能であり、すべてのメッセージチャネルで1つのメモリを共有します。**

---

メモリは、会話やデバイスを超えて重要な情報をヘルメスが保持するのに役立ちます—あなたの好み、身元、進行中の作業、そして長期的な協力を通じて形成される体験です。これにより、ヘルメスは一度きりの質問応答ツールから、時間と共にあなたをよりよく理解する長期的なアシスタントへと変わります。

![LightVelaコンソールのメモリとユーザープロフィールページ](../images/memory-management-overview-en.png)

LightVelaはクラウド上でホストされているため、これらのメモリはクラウド内のあなたのHermesインスタンスに保存されます。デバイスを変更したり、Telegram、WhatsApp、Discord、Slack、WeChatの間を切り替えても、それらは失われません。今日TelegramでHermesに何かを伝えた場合でも、明日WhatsAppで会話を続けるときに、Hermesはそれを覚えています。

## 記憶が重要な理由

記憶がなければ、AIアシスタントとの会話は毎回白紙の状態から始まります。あなたは自分が誰で、何を好み、前回の会話がどこで終わったかを説明しなければなりません。記憶がその問題を解決します：

- **同じことを繰り返す必要が少なくなる**：Hermesに一度だけ、あなたがシンガポールに住んでいて、朝のブリーフィングを好むことを伝えれば、毎回繰り返す必要はありません。

- **チャネル間で一貫性を保つ**：Telegram、WhatsApp、Discord、Slack、およびWeChatは同じ記憶を共有します。チャネルを切り替えても、あなたを理解している同じアシスタントと話していることになります。

- **継続的な使用で改善**：一緒に作業することで、Hermesはあなたのルーチン、好みの名前、進行中のプロジェクトを記憶し、その応答がますます適切になります。

記憶をHermesの長期ノートのように考えてください。すべてのカジュアルなメッセージを保持するわけではなく、後で役立ちそうな詳細を保持します。

---

## 記憶の2種類

コンソールのメモリページには2つのタブがあり、それぞれ異なる目的を持っています：

### メモリ

これは、Hermes が長期的なコラボレーションを通じて築く **経験と事実** を含みます—あなたが共有した好み、合意された作業方法、そして時間を経て繰り返されるニーズです。Hermes は会話中にこの内容を自動的に維持し、使用を続けるにつれてエントリも進化します。

### ユーザープロフィール

これは、あなたの身元、所在地、職歴、長期的な好みなど、**あなたが誰であるか** の安定した記録です。一般的なメモリと比べて、ユーザープロフィールは、Hermes が任意の会話であなたの基本的な状況を迅速に理解するのに役立つ、持続的なプロフィールカードのように機能します。

> ℹ️ **それらの違い**
>
> 簡単に言うと、**ユーザープロフィール** は「あなたはどのような人ですか？」に答え、**メモリ** は「私たちの間で何が起こったか、そして何に合意したか？」に答えます。両者を組み合わせることで、Hermesはあなた自身とあなたとのコラボレーションの履歴の両方を理解するのに役立ちます。

## メモリと使用容量を確認する

1. LightVela にサインインし、右上の「My Hermes」をクリックしてコンソールを開きます。

2. 設定ナビゲーションで「メモリ」を見つけ、メモリページを開きます。

3. ページ上部で **メモリ統計** を確認します：現在使用されている文字数、容量の上限、および使用率のパーセンテージ。

4. 「メモリ」と「ユーザープロファイル」のタブを切り替えて、それぞれの種類のコンテンツを確認してください。

どちらかの種類が空の場合、ページには「エージェントのメモリなし」または「ユーザープロファイルなし」と表示されます。これは通常、Hermes を十分に使用していないため、その種類のメモリがまだ構築されていないことを意味します。コンテンツは時間とともに蓄積されます。

> 💡 **使用率の意味**
>
> メモリには容量の上限があります。使用率がその上限に近づくと、Hermes はより重要な情報を優先し、古いエントリを削除します。使用率を監視することで、容量を増やすか、不要な情報を削除するかを判断するのに役立ちます。

---

## メモリ容量制限を調整する

Hermes により多くの情報を保持させたい場合は容量制限を増やし、適切な場合は減らすことができます。

- **メモリ** は 500 から 4,000 文字まで設定できます。

- **ユーザープロファイル** は 500 から 3,000 文字まで設定できます。

新しい制限は保存後に有効になります。

> ⚠️ **新しい制限を保存するとゲートウェイが一時的に再起動され、現在の会話が中断される場合があります**
>
> 新しい容量制限を保存すると、構成を適用するためにHermesゲートウェイが一時的に再起動します。進行中の会話は一瞬中断される場合がありますが、すぐに回復します。作業に影響がない短時間の中断時に変更を行ってください。

---

## 会話を通じてメモリを追加または削除する

コンソールで内容を確認するだけでなく、Hermesに直接情報を記憶させたり忘れさせたりすることもできます。これは、日常の使用中にメモリを管理する最も自然な方法です。

**記憶させるように依頼する:**

```
Remember that I want my daily briefing at 8:00 AM.
```

```
Remember that I prefer concise, direct answers.
```

**忘れさせるように依頼する:**

```
I no longer need the daily briefing we discussed. Please forget that preference.
```

Hermesはあなたの意図を解釈し、関連するメモリ項目を更新し、何が変わったかを教えてくれます。

> ℹ️ **メモリ内容は現在、会話を通じて維持されています**
>
> LightVelaは管理されたクラウドモデルを使用しており、ユーザー向けのファイルシステム操作は公開されていません。メモリ内容の追加や削除は主にHermesと話すことで行い、コンソールを使用して内容を確認したり容量制限を調整したりします。

## FAQ

### Hermesは私が明示的に保存するよう頼んでいないことまでなぜ覚えていたのですか？

これは予想されることです。Hermesは、時間の経過とともに役立つ可能性のある情報、例えばあなたの好み、身元、作業上の合意事項などを自動的に特定します。情報を保持してほしくない場合は、会話の中でその情報を忘れるように頼んでください。

### デバイスやチャネルを変更してもメモリは残りますか？

はい。メモリはクラウドインスタンスに保存され、特定のデバイスやチャネルに依存しません。Telegram、WhatsApp、Discord、Slack、およびWeChatはすべて同じメモリを共有します。

### メモリが容量に達した場合はどうなりますか？

使用量が制限に近づくと、Hermesはより重要な情報を優先し、古くなったりあまり役に立たない項目を徐々に削除します。より多くの情報を保持させたい場合は、メモリページで容量の上限を増やしてください。

### なぜメモリページにはメモリがないと表示されるのですか？

そのタイプのメモリにはまだコンテンツが蓄積されていません。Hermesと作業を続けるか、重要な詳細を直接覚えてもらうように頼むと、コンテンツが表示され始めます。

### 容量の上限を変更した後、なぜ会話が一時停止したのですか？

新しい制限を保存すると、一時的にゲートウェイが再起動し、会話が一瞬中断されることがあります。少し待ってから、もう一度メッセージを送信してください。
