# ソウルズ

## 概要

**パーソナリティは、1つのHermes Agentの安定した役割、声、優先順位、および行動の境界を定義します。**

**エージェントのパーソナリティ設定からソウルを選択し、その説明を確認して、エージェントの`SOUL.md`を更新するために注入します。**

**エージェントには同時に1つのソウルしかアクティブにならず、変更後はルールが更新されるよう新しい会話を開始する必要があります。**

![LightVelaコンソールのソウルパーソナリティカード](../images/soul-1.png)

## このページの内容

- パーソナリティとソウルの制御内容
- ソウルを選んで注入する
- 新しいパーソナリティが有効になっていることを確認する
- パーソナリティ、ユーザーの好み、記憶、スキルを分離して保持する
- 一般的な制限とトラブルシューティングの手順

## パーソナリティが制御するもの

ソウルは、LightVela がエージェントの `SOUL.md` に書き込む選択されたペルソナです。
それはエージェントが誰であるか、通常どのようにコミュニケーションを取るか、何を優先するか、そしてどの境界を尊重すべきかを定義します。

「結論から述べる」、「不確実性を明確に伝える」、「外部アクションを実行する前に確認する」といった安定した指示にはパーソナリティを使用してください。
プロジェクトの事実を変更するため、単発のリクエスト、または汎用クラウドファイルエディタとして使用しないでください。

パーソナリティはエージェントに属し、特定の会話チャネルには属しません。
同じエージェントがTelegramとWhatsAppに接続されている場合、両方のチャネルでの新しい会話は同じアクティブなソウルを使用します。

## 始める前に

1. 設定したいパーソナリティを持つHermes Agentを開きます。
2. エージェントがモデルを持ち、少なくとも1つの使用可能な会話チャネルがあることを確認し、結果を確認できるようにします。
3. 常に確認が必要な役割、対象、声、優先事項、および行動を決定します。

短いブリーフで十分な場合が多いです。
例えば：「結論を証拠の前に示し、不確実性を明示し、会話の外に何かを送る前に確認する簡潔な研究アシスタント。」

## ソウルを設定する

### パーソナリティを開く

1. LightVela コンソールで **エージェント** を開く。
2. 設定したい Hermes Agent を選択する。
3. そのエージェントの設定で **パーソナリティ** セクションを開く。

この設定は選択したエージェントにのみ適用されます。
異なる役割や声を他の場所で設定したい場合は、設定する前に別のエージェントに切り替えてください。

### ソウルを選択

**ランダムなソウルを引く**を使って、利用可能なペルソナスタイルを探索します。
**ソウル性格テスト**は、コミュニケーションや行動の好みに基づいた推奨を希望する場合に使用します。

![ランダムなソウルダイアログを描く](../images/soul-2.png)

選択する前に、各ソウルカードの役割、声、行動の説明、境界を確認してください。
名前やトーンだけで選ぶのではなく、準備したブリーフに合ったソウルを選んでください。

### ソウルを注入

1. 使用したいソウルを選択してください。
2. **魂を注入** を選択します。
3. 人格セクションで注入結果を確認します。
4. 接続された会話チャネルに戻り、`/new` を送信します。

注入が成功すると、LightVela は選択した魂を現在のエージェントの `SOUL.md` に書き込み、既存の人格を置き換える前にバックアップを保持します。
既存の会話は以前の人格スナップショットを保持する場合があるため、`/new` は更新された魂を読み込む会話を開始します。

### 自分の魂をアップロード

推奨カードを選ぶ代わりに、すでに持っているMarkdownソウルを適用したい場合は、このオプションを使用します。

1. LightVelaコンソールで対象のHermes Agentを選択します。
2. **パーソナリティ**で、**パーソナリティファイルをアップロード**を選択します。
3. ソウルを含むMarkdownファイルを選択します。
4. 内容を確認または編集した後、**注入**を選択します。
5. エージェントにすでにソウルがある場合は、置き換えるかどうか確認します。
6. 接続された会話チャネルに戻り、`/new` を送信します。

![ペルソナファイルのアップロードダイアログ](../images/soul-3.png)

ファイル名は`soul.md`である必要はありませんが、`.md`拡張子を使用し、UTF-8でエンコードされ、20 KBを超えない必要があります。
LightVelaは、最終編集を行えるように注入前のファイル内容を表示します。
既存のソウルを置き換えるとき、LightVelaはアップロードされた内容を選択したエージェントの`SOUL.md`に書き込む前にバックアップを作成します。

アップロードは、エージェントが選択されている場合にのみ利用できます。
推奨ソウルのダウンロード可能なコピーが必要で、エージェントが選択されていないか、エージェントのサンドボックスに書き込めない場合、`soul.md`ファイルはローカルのフォールバックとしてのみ使用してください。
そのフォールバックをダウンロードしても、エージェント自体は更新されません。

## ソウルがアクティブであることを確認する

`/new`を送信した後、エージェントの設定された動作を示すいくつかのリクエストでテストします。

```text
What is your current role, main job, and default voice?
```

```text
How do you respond when you are uncertain about a fact?
```

```text
If I ask you to send a message to an external service, what do you do first?
```

新しいソウルは、エージェントが新しい会話で意図された役割、声、境界を一貫して守る場合にアクティブです。
チャネル別の手順が必要な場合は、次を参照してください。[IMエージェントの役割、性格、声をSOUL.mdで定義する方法](../use-cases/im-agent-persona-soul-md.md)。

## 一般的な問題をトラブルシューティングする

| 問題 | 考えられる原因 | 取るべき対応 |
| --- | --- | --- |
| 返信がまだ以前の口調を使用している | 会話はソウルが変更される前に始まりました | `/new`を送信し、その後、新しい会話で動作を再確認してください。 |
| 選択されたソウルはエージェントの実際の業務に適していません | ソウルカードは役割や境界ではなくスタイルで選ばれました | パーソナリティに戻り、カードの詳細を確認し、エージェントの概要に合ったソウルを注入してください。 |
| エージェントがプロジェクトの事実を忘れています | 変化する事実がメモリではなくパーソナリティに配置されました | `SOUL.md`では安定したルールを維持し、変化する事実をヘルメスに記憶させてください。 |
| エージェントは必要なタスクを実行できません | 性格は行動を定義し、能力を定義するものではありません | ソースと権限を確認した後、適切なスキルをインストールまたは設定してください。 |
| コンソールは`soul.md`を適用する代わりにダウンロードします | エージェントが選択されていないか、エージェントのサンドボックスが新しい構成を書き込めませんでした | 対象の実行中エージェントを選択し、再度インジェクションを試みてください。ダウンロードしたファイルはエージェントを変更しません。インジェクションが成功したことをコンソールで確認した後にのみ`/new`を送信してください。 |
| 自分のソウルをアップロードすることはできません | エージェントが選択されていないか、ファイルが20 KB以内の有効なUTF-8 Markdownファイルではありません | 対象のエージェントを選択し、ファイル要件を満たす`.md`ファイルをアップロードしてください。 |

## FAQ

### 1つのエージェントに複数のアクティブソウルを持たせることはできますか？

いいえ。
1つのエージェントには同時に1つのアクティブソウルしかありません。
一つのエージェントの性格を何度も置き換えるのではなく、真に異なる役割が必要な場合は別々のエージェントを作成してください。

### クラウドの `SOUL.md` を手動で編集できますか？

通常の使用では、クラウドファイルシステムへの直接操作は必要ありません。
性格設定はソウルを生成して注入しますが、任意のクラウドファイルの汎用編集用エディターではありません。

### 既存の `SOUL.md` をアップロードできますか？

はい、可能です。
**性格ファイルをアップロード** を使って、最大 20 KB の UTF-8 Markdown ファイルを選択し、確認または編集して選択したエージェントに注入してください。
エージェントがすでにソウルを持っている場合、LightVelaは確認を求め、交換する前にバックアップを取ります。

### ソウルを変更すると新しい能力がインストールされますか？

いいえ。
ソウルはエージェントの行動の仕方を変えますが、スキルは具体的な能力や再利用可能な手順を追加します。

### 新しいソウルは記憶やチャット履歴を消しますか？

いいえ。
ソウルを注入すると、エージェントの現在の人格設定が置き換わります。
長期記憶や既存の会話履歴は削除されません。
