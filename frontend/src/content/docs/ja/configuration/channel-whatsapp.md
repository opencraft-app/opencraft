# チャンネルを設定 - WhatsApp

## 概要

**WhatsApp チャンネルは、WeChat のようにQRコードで接続されます。これにより、Hermes Agent を WhatsApp の会話に迅速に参加させることができます：コンソールのチャンネルセクションで WhatsApp を選択し、QRコードを生成して、携帯電話の WhatsApp でスキャンして会話を始めてください。WhatsApp がインストールされた電話と設定されたモデル（またはプランに含まれる月次モデルクレジット）が必要です。1つのエージェントは同時に複数のチャンネルに接続でき、同じペルソナと長期メモリを共有します。**

---

WhatsApp チャンネルは WeChat と同様に QR コードアクセスを使用しており、Hermes Agent を WhatsApp の会話に素早く接続するのに適しています。

## このページの内容

- WhatsApp を携帯電話で使用して QR コードをスキャンし、アクセスを承認する

- WhatsApp で Hermes Agent とチャットする


> 💡 **前提条件**
>
> - WhatsApp がインストールされた携帯電話
>
> - 完了する[モデル構成](./model.md)（またはLaunchプランに含まれる100トライアルクレジットを使用）
>

---

## 手順

### 1. コンソールに入る

LightVela にサインインし、右上の「My Hermes」をクリックしてコンソールに入り、「Channel」ボタンを見つけます。

### 2. WhatsApp チャンネルを選択する

WhatsApp カードを見つけ、「+ 接続」をクリックします。

### 3. 携帯電話で WhatsApp を使って QR コードをスキャンする

1. 携帯電話で WhatsApp を開く

2. 右上の「カメラ」ボタンをタップする

3. コンピュータ画面のQRコードをスキャン

![](../images/whatsapp-1-global-en.webp)

4. 接続を完了するには、携帯電話の指示に従ってください

### 4. WhatsAppに自分を見つけてください

![](../images/whatsapp-2-global.webp)

自分自身とチャットしましょう — それがあなたのボットです。

ボットとのチャットを開き、テストメッセージを送信します:

```
Hi
```

数秒以内にHermes Agentの返信が届くはずです。

![](../images/whatsapp-3-global-en.webp)

---

## 成功状態

- コンソールの「接続済みチャネル」リストには「WhatsApp」が含まれています

- 対応するボットはWhatsAppの連絡先で見つけることができます

- メッセージを送信するとHermes Agentが返信します


---

## サポートされているメッセージタイプ

アクセスに成功すると、WhatsAppボットは基本的なテキストメッセージを受信して返信することができ、次のような追加のメッセージタイプもサポートします:

| WhatsApp ボットがサポートするメッセージタイプ | サポート状況 |
|---|---|
| テキストメッセージの受信 | ✅ サポート |
| 画像および動画の受信 | ✅ サポート |
| ファイルの受信 | ✅ サポート |
| テキストメッセージで返信 | ✅ サポート |
| 画像および動画で返信 | ✅ サポート |
| ファイルで返信 | ✅ サポート |
| メッセージを積極的に送信（例：スケジュールされたリマインダー） | ✅ サポート |

> ℹ️ **実際の処理能力はモデルによります**
>
> 上の表は、チャネルレイヤーにおいて WhatsApp ボットがサポートしているメッセージタイプのみを示しています。画像、ファイル、その他のタスクが実際に処理可能かどうかは、Hermes Agent に接続されている大規模言語モデルが対応する機能を持っているかにも依存します。

## FAQ

| 問題 | 考えられる原因 | 解決策 |
|---|---|---|
| WhatsApp に接続できません | 電話番号の形式が正しくないか、WhatsApp ビジネス設定が不完全です | +1 や +86 などの完全な国際形式を使用し、WhatsApp ビジネス / Meta 設定が完了していることを確認してください |
| 認証コードが届かない | 電話番号が利用できない、ネットワークの遅延、またはWhatsAppの認証制限 | 電話番号がWhatsAppメッセージを受信できることを確認する；数分待って再試行する |
| 認証コードを入力した後、無効と表示される | コードが期限切れか、誤って入力された | 新しいコードをリクエストし、余分な空白がないことを確認する |
| アクセス後、コンソールに反応がない | 認証または設定の同期が完了していない | コンソールをリフレッシュしてステータスを確認してください。アクセスが成功しなかった場合は、再度試してください |
| WhatsAppでボットの連絡先が見つからない | ボットの番号が保存されていない、またはチャットが開始されていません | ボットの番号を保存するか、コンソールで提供されたリンク／QRコードからチャットを開いてください |
| メッセージ送信後に応答がありません | モデルが設定されていない、試用クレジットがなくなった、またはWhatsAppチャンネルが正常に接続されていません | 「1. モデル」カードの「現在のモデル」ステータスを確認し、WhatsAppチャンネルが接続済みになっていることを確認してください |
| 画像、ファイル、または音声メッセージを受信できません | メディアの権限、フォーマット、またはチャンネルの機能制限 | ファイル形式がサポートされていることを確認してください；音声が認識できない場合は、音声認識／メディア処理が有効になっているか確認してください |
| 先制メッセージが失敗する | WhatsApp はメッセージテンプレートと会話ウィンドウを通じて先制メッセージを制限します | ユーザーがボットとの会話を開始したことを確認してください；会話ウィンドウが期限切れの場合は、承認されたメッセージテンプレートを使用してください |
| リンク解除方法 | — | 「接続済みチャンネル」リストから対応するWhatsAppの記録を削除してください |
| 同じWhatsApp番号が複数のHermes Agentインスタンスに接続できますか | 推奨されません。1つのWhatsApp番号は1つのHermes Agentに紐付けるべきです | 複数のHermes Agentインスタンスが必要な場合は、別々のWhatsApp番号を使用してください |

## チャンネルノート

- **メッセージタイプ**: テキスト、画像、動画、ファイル、音声メッセージなどをサポートします。詳細は上記の「サポートされているメッセージタイプ」を参照してください

- **グループチャットのサポート**: 現在、グループチャットはサポートされていません。サポートされているのは1対1の会話のみです

- **接続の中断**: 長時間応答がない場合は、認証が取り消された可能性があります。コンソールに戻り、再度アクセスを許可してください
