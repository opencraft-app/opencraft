# チャンネルを設定 - WeCom

## 概要

**WeCom チャンネルはQRコードで接続でき、WeChat と並んで設定が最も簡単です — Hermes Agent を企業の職場で使用するのに適しています：コンソールのチャンネルセクションで WeCom を選択し、承認してQRコードを生成し、携帯電話の WeCom でスキャンすると会話を始められます。WeCom がインストールされ、設定済みのモデル（またはプランに含まれる月額モデルクレジット）が必要です。1人のエージェントは、同じペルソナと長期記憶を共有しながら、複数のチャンネルに同時に接続できます。**

---

WeCom チャンネルはQRコードアクセスを使用しており、設定が最も簡単なチャンネルです。

## このページの内容

- LightVelaでWeComアクセスQRコードを生成する

- スマートフォンでWeComを使ってQRコードをスキャンする

- WeComでHermes Agentとチャットする


> 💡 **前提条件**
>
> - WeComがインストールされたスマートフォン
>
> - 完了する[モデル構成](./model.md)（またはLaunchプランに含まれる100トライアルクレジットを使用）
>

---

## 手順

### 1. コンソールに入る

LightVela にサインインし、右上の「My Hermes」をクリックしてコンソールに入り、「Channel」ボタンを見つけます。

### 2. WeComチャンネルを選択する

WeComモジュールを見つけ、「+ 接続」をクリックする。

### 3. 「アクセスを許可」をクリック

ページにQRコードが表示されます。

![](../images/wecom1-en.webp)

> ⚠️ **QRコードの有効期限**
>
> QRコードは数分で有効期限が切れます。有効期限が切れた場合は、ダイアログを閉じて「アクセスを承認」を再度クリックし、新しいQRコードを生成してください。

### 4. スマートフォンでWeComを使ってスキャンする

1. スマートフォンでWeComを開く

2. 右上の「+」をタップ → 「スキャン」

3. コンピュータ画面のQRコードをスキャン


![](../images/wecom2.webp)

4. 携帯の指示に従い、認証を完了する

![](../images/wecom3.webp)

![](../images/wecom4.webp)

### 5. 作成したボットとチャットする

スキャンが成功した後:

- ダイアログは自動的に閉じられ、作成したボットページに移動します

- WeCom は自動的にボットを連絡先に追加します


ボットのチャットウィンドウを開き、テストメッセージを送信します：

```
Hello
```

数秒以内にHermes Agentの返信を受け取ります。

![](../images/wecom5-en.webp)

---

## 成功状態

- コンソールの「接続済みチャンネル」リストに「WeCom」の項目が表示されます

- ボットはあなたの WeCom 連絡先で見つけることができます

- メッセージを送信するとHermes Agentの返信が届きます


---

## サポートされているメッセージタイプ

統合後、WeCom ボットは基本的なテキスト以上をサポートします。全リスト：

| WeCom ボット — サポートされているメッセージタイプ | サポート状況 |
| --- | --- |
| テキストメッセージの受信 | ✅ はい |
| 画像 / 動画を受信 | ✅ はい |
| ファイルの受信 | ✅ はい |
| 音声メッセージを受信する | ✅ はい |
| テキストメッセージで返信 | ✅ はい |
| 画像 / 動画で返信 | ✅ はい |
| ファイルで返信 | ✅ はい |
| メッセージを自発的に送信（例：予定されたリマインダー） | ✅ はい |

> ℹ️ **実際の機能はモデルによって異なります**
>
> 上の表は、WeComボットがチャネル層で受信および返信できる内容のみを反映しています。画像やファイル処理などのタスクが実際に動作するかどうかは、Hermes Agentに接続されている基盤LLMがこれらの機能をサポートしているかに依存します。

## FAQ

| 症状 | 考えられる原因 | 解決策 |
| --- | --- | --- |
| スキャン後、WeComに「無効なQRコード」と表示される | QRコードの有効期限が切れています | ダイアログを閉じ、「アクセスを承認」を再度クリック |
| スキャン後、デスクトップで応答がない | ネットワーク遅延または認証がまだ完了していない | ステータスを確認するためにコンソールページを更新; 接続されていない場合は再試行 |
| WeComにボットの連絡先が見つからない | 「サービス通知」にまとめられたメッセージ | WeComの上部から「LightVela」またはあなたのHermes Agent名を検索 |
| メッセージ送信後に応答がありません | モデルが設定されていないか、試用クレジットが使い切られました | 「1. モデル」カードで「現在のモデル」ステータスを確認してください |
| 切断方法 | — | 「接続済みチャンネル」リストからエントリを削除 |
| 1つのWeComアカウントで複数のHermes Agentインスタンスに接続できますか | LaunchプランではHermes Agentは1つまでです | 該当なし |

## チャンネルノート

- **メッセージタイプ**: テキスト、画像、動画、ファイル、音声など — 上記の「対応メッセージタイプ」を参照

- **グループチャット対応**: 現時点ではグループチャットはサポートされておらず、1対1の会話のみ対応

- **接続が切れる**：長時間応答がない場合は通常、認証が取り消されたことを意味します — コンソールから再認証してください
