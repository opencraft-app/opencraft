# Botの切り替え

## 概要

**Botの切り替えを使うと、1つのLightVelaクラウドAgentに複数の専門Botを配置できます。調査、計画、コーディング、コンテンツ、サポート、定期ワークフローなどの用途別にBotを作成し、Agentのプロフィールメニューから切り替えられます。**

**各Botには固有のワークスペースコンテキストがあります。空のBotを作成するか既存のBotをコピーするかによって、モデル設定、メモリ、Skills、人格、スケジュールタスク、チャンネル接続の継承ルールが変わります。**

## 開始前の準備

- LightVelaにサインインし、実行中のクラウドAgentを開きます。
- 追加のBotを作成する場合は、現在のプランで新しいBotを作成でき、別のBotが作成中または削除中ではないことを確認します。
- チャンネルを接続する場合は、そのチャンネルに必要な認証情報または認証方法を準備します。

## Botを作成する

**新しいBot**を選択し、アバター、名前、説明を設定して、空のBotを作成するか既存のBotをコピーするかを選びます。

すでに別のBotがある場合、作成ダイアログには **現在のBotをコピー**、**メインBotをコピー**、**空白で作成** が表示されることがあります。

たとえば、財務アナリストBotを作成する場合は、次のように入力できます。

> <strong>名前：</strong> Alpha Analyst
>
> <strong>説明：</strong> Alpha Analystは、企業レポート、市場ニュース、ポートフォリオのパフォーマンス、バリュエーション、金融リスクの分析を専門としています。根拠に基づく簡潔な分析を提供し、事実と仮定を明確に区別し、分析を保証された金融アドバイスとして提示しません。

![アバター選択、名前、説明、作成ボタンを含むLightVelaのBot作成フォーム](../../images/bots-switching-create.webp)

作成画面には、ヘルスマネージャー、マーケットウォッチャー、AI学習バディなど、役割別のテンプレートが表示されることもあります。

![ヘルスマネージャー、マーケットウォッチャー、AI学習バディを含むLightVelaのBot作成テンプレート](../../images/bots-switching-templates.webp)

内容を入力したら作成を確定し、新しいBotのプロビジョニングが完了するまで待ちます。

## Botのワークスペースと設定

作成後、Botには専用の設定ワークスペースが用意されます。AgentのメインページにあるBotタブからBotを選び、そのBotで利用できるメモリ、Skills、人格、スケジュールタスク、接続済みチャンネルなどを管理できます。

![My BotsセクションにBotカードが表示されたLightVela Agentの概要](../../images/bots-switching-overview.webp)

作成モードによって、新しいBotが継承する内容が決まります。

| 作成モード | 継承される内容 | 個別に開始される内容 |
| --- | --- | --- |
| 空白で作成 | プライマリモデルとプロバイダー認証情報、システム提供のSkills | 予備モデル、その他の設定済みモデル、人格、メモリ、メインBotに後から追加したSkills、チャンネル、スケジュールタスク |
| 現在のBotをコピー または メインBotをコピー | モデル、人格、Skills、ユーザー設定、長期メモリ | 現在の会話、過去のチャット履歴、スケジュールタスク、ランタイム状態、チャンネル接続 |

設定を分離したい場合は、確定前に作成ダイアログの継承内容を確認します。作成後は、各Botの[メモリ](./memory.md)、[Skills](./skill.md)、[スケジュールタスク](./automation.md)を個別に管理できます。

## Botを独立して作成する理由

1つのBotで多くの作業を処理できますが、役割が増えるほどコンテキストの管理は難しくなります。調査、旅行計画、財務分析、品質確認などの専用Botを作ると、メモリ、Skills、人格設定、スケジュールタスクを目的ごとに整理できます。

独立したBotを使うと、別の作業で利用しているBotを変更せずに、異なる作業スタイルを試すこともできます。

![複数のBotを選択できるLightVelaのBotプロフィールメニュー](../../images/bots-switching-selector.webp)

これにより、LightVelaのワークスペースを整理しやすくなります。Botを切り替えるには、Agentワークスペース左上のアクティブなBotプロフィールをクリックし、メニューから別のBotを選択します。

## 複数のBotを同時に使う方法

複数のBotを、対応するメッセージングチャンネルに接続できます。利用できるチャンネルの組み合わせはLightVelaの地域によって異なります。

| LightVelaのバージョン | 複数Botの連携に対応するチャンネル |
| --- | --- |
| 中国版 | QQ、WeCom、Lark、DingTalk |
| グローバル版 | Telegram、Discord、Slack、QQ、WeCom、Lark |

WeChatやWhatsAppなどのチャンネルでは、現在の設定により1つのインスタンスに接続できるBotが1つだけになる場合があります。別のBotがチャンネルを所有している場合、LightVelaは通知を表示し、そのチャンネルを所有するBotを管理する入口を提供します。

![WeChatが別のBotに占有され、1つのBotだけが接続できることを示すLightVelaの通知](../../images/bots-switching-wechat.webp)

## Botの切り替えとチャンネル接続を確認する

切り替えまたは接続後、次の点を確認します。

1. アクティブなBotの名前とアバターが選択したBotに変わります。
2. 設定ページに、選択したBotのワークスペースと設定が表示されます。
3. 接続済みチャンネルが、その接続を所有するBotの下に表示されます。
4. 短いテストメッセージが目的のBotに届き、返信が返ります。

グループチャンネルでは、設定した権限でテストメッセージを送り、Botがグループのコンテキストを読むだけなのか、返信もできるのかを確認します。

## よくある問題

| 問題 | 考えられる原因 | 対処方法 |
| --- | --- | --- |
| **新しいBot**を利用できない | プランのBot上限に達した、または別のBotが作成中か削除中 | 現在の処理が終わるまで待つ、不要なBotを削除する、上限の高いプランに変更する |
| コピーの選択肢を利用できない | コピー元となる有効な現在のBotまたはメインBotがない | **空白で作成**を選ぶか、対象のBotに戻ってから作成ダイアログを開く |
| Bot一覧を一時的に利用できない | Agentインスタンスが停止している、またはBot一覧のリクエストに失敗した | Agentを起動または更新し、Bot設定ページを再読み込みする |
| チャンネルが別のBotに接続済み | チャンネルに1つのBotだけが所有できる制限がある | 通知から所有Botを開くか、チャンネル設定ページに従って接続を解除して再接続する |
| グループメッセージに返信がない | Botのグループ権限またはチャンネル設定が不完全 | [Telegram](./channel-telegram.md)、[Discord](./channel-discord.md)、または該当チャンネルの設定ページを確認して、もう一度テストする |

## グループでBotとチャットする

対応するグループチャットには複数のBotを招待できます。設定した権限に応じて、Botはグループのコンテキストを読んだり、ユーザーの質問に返信したり、その両方を行ったりできます。

グループでの動作と設定手順はプラットフォームによって異なります。Botを招待する前に該当チャンネルの設定ページを確認し、必要に応じて直接メンションなどのプラットフォーム対応トリガーでテストします。
