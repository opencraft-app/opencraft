# Botの切り替え

## 概要

**Botの切り替えを使うと、1つのLightVelaクラウドAgentに複数の専門Botを配置できます。調査、計画、コーディング、コンテンツ、サポート、定期ワークフローなどの用途別にBotを作成し、Bot のアバターバーから切り替えられます。**

**各Botには固有のワークスペースコンテキストがあります。空のBotを作成するか既存のBotをコピーするかによって、モデル設定、メモリ、Skills、人格、スケジュールタスク、チャンネル接続の継承ルールが変わります。**

## 開始前の準備

- LightVelaにサインインし、実行中のクラウドAgentを開きます。
- 追加のBotを作成する場合は、現在のプランで新しいBotを作成でき、別のBotが作成中または削除中ではないことを確認します。
- チャンネルを接続する場合は、そのチャンネルに必要な認証情報または認証方法を準備します。

## Botを作成する

Google または GitHub でログインし、利用可能なプランを有効にしたら、[Agent コンソール](/agents/overview/)を開きます。最初の Bot の設定では、必須の名前を入力し、必要に応じて説明を追加して外見を調整します。**作成**を選び、作成と初期設定の完了を待ちます。設定が完了したら **旅を始める** を選択し、その Bot の Web チャットを開きます。メッセージチャネルの接続は任意です。返信には利用可能なモデルクレジット、または設定済みのモデルが必要です。

追加の Bot を作成するには、作成機能が利用可能でプランの上限に余裕がある状態で**Bot を新規作成**を選びます。**名前**は必須、**説明**は任意です。必要に応じて外見を調整してください。初期選択は**空の状態から作成**です。コピー可能な Bot がある場合は、**詳細設定**を開いて具体的なコピー元を選びます。使用中の Bot をコピーするには、**Botを管理 → Bot をコピー**を開きます。フォームではその Bot がコピー元として選択されます。コピー元を確認して**作成**を選び、完了を待ちます。

閉じる操作と詳細なコピー設定は、有効なコピー元の Bot がある場合にのみ表示されます。コピー元のない初回設定は完了する必要があります。外見の設定では色、形、アクセサリーを変更できますが、コピー元は選択しません。

以下は現在の追加 Bot 作成フォームとおすすめテンプレートの実際の画面です。Agent に既存の Bot があるため、閉じるボタンと詳細設定が表示されています。初回 Bot の設定画面ではありません。

![LightVela の追加 Bot 作成フォームに表示されるおすすめテンプレート](../../images/bots-switching-templates.webp)

## Botのワークスペースと設定

Bot バーで目的の Bot のアバターを選択します。画面が狭い場合は、先にナビゲーションパネルを開いてください。モデル、メモリ、スキル、チャネル、定期タスクを変更する前に名前を確認してください。Web チャットと会話一覧は選択した Bot に対応し、追加の Bot も Web チャットを利用できます。Web チャットにメッセージチャネルの接続は不要です。

![チャネル、スキル、定期タスクのナビゲーションに隣接する LightVela の Bot アバターバー](../../images/bots-switching-overview.webp)

作成モードによって、新しいBotが継承する内容が決まります。

| 作成モード | 継承される内容 | 個別に開始される内容 |
| --- | --- | --- |
| 空の状態から作成 | プライマリモデルとプロバイダー認証情報、システム提供のSkills | 予備モデル、その他の設定済みモデル、人格、メモリ、メインBotに後から追加したSkills、チャンネル、スケジュールタスク |
| Bot をコピー | モデル、人格、Skills、ユーザー設定、長期メモリ | 現在の会話、過去のチャット履歴、スケジュールタスク、ランタイム状態、チャンネル接続 |

設定を分離したい場合は、確定前に作成ダイアログの継承内容を確認します。作成後は、各Botの[メモリ](./memory.md)、[Skills](./skill.md)、[スケジュールタスク](./automation.md)を個別に管理できます。

## Botを独立して作成する理由

1つのBotで多くの作業を処理できますが、役割が増えるほどコンテキストの管理は難しくなります。調査、旅行計画、財務分析、品質確認などの専用Botを作ると、メモリ、Skills、人格設定、スケジュールタスクを目的ごとに整理できます。

独立したBotを使うと、別の作業で利用しているBotを変更せずに、異なる作業スタイルを試すこともできます。

![2 つの Bot と新規 Bot ボタンを表示する LightVela のアバターバー](../../images/bots-switching-selector.webp)

Bot バーで目的の Bot のアバターを選択します。画面が狭い場合は、先にナビゲーションパネルを開いてください。モデル、メモリ、スキル、チャネル、定期タスクを変更する前に名前を確認してください。Web チャットと会話一覧は選択した Bot に対応し、追加の Bot も Web チャットを利用できます。Web チャットにメッセージチャネルの接続は不要です。

## 複数のBotを同時に使う方法

複数のBotを、対応するメッセージングチャンネルに接続できます。利用できるチャンネルの組み合わせはLightVelaの地域によって異なります。

| LightVelaのバージョン | 複数Botの連携に対応するチャンネル |
| --- | --- |
| グローバル版 | Telegram、Discord、WeChat、Slack、QQ、WeCom、Lark |

同じインスタンスの異なるBotは、それぞれ別のWeChatアカウントを接続できます。WeChat接続はBotごとに管理します。WhatsAppは引き続き1インスタンスにつき1つのBotのみ接続可能です。他のBotには所有者の案内と管理リンクが表示されます。

## Botの切り替えとチャンネル接続を確認する

切り替えまたは接続後、次の点を確認します。

1. アクティブなBotの名前とアバターが選択したBotに変わります。
2. 設定ページに、選択したBotのワークスペースと設定が表示されます。
3. 接続済みチャンネルが、その接続を所有するBotの下に表示されます。
4. 短いテストメッセージが目的のBotに届き、返信が返ります。

グループチャンネルでは、設定した権限でテストメッセージを送り、Botがグループのコンテキストを読むだけなのか、返信もできるのかを確認します。

## よくある問題

| 問題 | 考えられる原因 | 対処方法 |
| --- | --- | --- |
| **新しいBot**を利用できない | プランのBot上限に達した、または別のBotが作成中か削除中 | 現在の処理が終わるまで待つ、不要なBotを削除する、上限の高いプランに変更する |
| コピーの選択肢を利用できない | コピー元となる有効な現在のBotまたはメインBotがない | **空白で作成**を選ぶか、対象のBotに戻ってから作成ダイアログを開く |
| Bot一覧を一時的に利用できない | Agentインスタンスが停止している、またはBot一覧のリクエストに失敗した | Agentを起動または更新し、Bot設定ページを再読み込みする |
| チャンネルが別のBotに接続済み | チャンネルに1つのBotだけが所有できる制限がある | 通知から所有Botを開くか、チャンネル設定ページに従って接続を解除して再接続する |
| グループメッセージに返信がない | Botのグループ権限またはチャンネル設定が不完全 | [Telegram](./channel-telegram.md)、[Discord](./channel-discord.md)、または該当チャンネルの設定ページを確認して、もう一度テストする |

## グループでBotとチャットする

対応するグループチャットには複数のBotを招待できます。設定した権限に応じて、Botはグループのコンテキストを読んだり、ユーザーの質問に返信したり、その両方を行ったりできます。

グループでの動作と設定手順はプラットフォームによって異なります。Botを招待する前に該当チャンネルの設定ページを確認し、必要に応じて直接メンションなどのプラットフォーム対応トリガーでテストします。
