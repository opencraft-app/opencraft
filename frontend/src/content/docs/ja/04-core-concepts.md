# コアコンセプト

## 概要

**LightVelaには5つの基本概念があります。Hermes Agentはクラウドインスタンス、Botはその中の独立したプロファイルです。各Botにはモデル設定、接続チャネル、スキルがあり、ペルソナ、メモリ、スケジュールタスクを個別に保持できます。同じBotにつながるチャネルはその設定を共有しますが、異なるBotの設定は自動共有されません。メッセージはチャネルから対象Botに届き、必要に応じてスキルとモデルを使い、元のチャネルに返信します。**

---

LightVelaの5つの基本概念はHermes Agent、Bot、モデル、チャネル、スキルです。このページではそれぞれの関係を説明します。

## コンセプトの関係

```text
Hermes Agent (cloud instance)
  └─ Bot profiles (main Bot and optional additional Bots)
       ├─ Primary model and optional fallbacks
       ├─ Connected channels
       └─ Skills, Soul, memory, scheduled tasks
```

| コンセプト | 役割 | 説明 |
|---|---|---|
| Hermes Agent | 会話の主体 | AIエージェントのインスタンス自体 |
| Bot | 独立したプロファイル | モデル、チャネル、スキル、ペルソナ、メモリ、スケジュールタスクを個別に持つ |
| モデル | 言語能力 | Hermes Agentによって呼び出される大規模言語モデル |
| チャネル | インタラクションのエントリーポイント | ユーザーがHermes Agentとチャットするプラットフォーム |
| スキル | 能力の拡張 | Hermes Agentによって呼び出される追加の能力パッケージ |

## Hermes Agent

Hermes AgentはLightVelaのAIエージェントインスタンスです。Hermes Agentを作成することは、クラウドで独立したエージェントインスタンスを起動することと同等です。

Hermes Agentには以下の特徴があります:

- **専用クラウド環境**: 各 Hermes Agent は専用環境で実行され、他のインスタンスからリソースが隔離されます

- **永続的なメモリ**: 会話内容はセッションをまたいで保存され、エージェントは応答時に過去のコンテキストを使用します

- **常時オンライン**: 24/7 実行され、ユーザーのローカルデバイスに依存しません

現在のLaunchプランでは、最大1つの Hermes Agent インスタンスの作成がサポートされています。

---

## Bot

各Hermes AgentにはメインBotがあり、プランの上限と提供状況に応じて追加Botを利用できます。Botは同じクラウドインスタンス内にありますが、設定とデータは独立しています。モデル、チャネル、スキル、メモリを変更する前に対象Botを選んでください。[Botの管理](./configuration/bots.md)を参照してください。

---

## モデル

モデルとは、Hermes Agent の思考と応答を動かす大規模言語モデル（LLM）のことです。LightVela は自らモデルをトレーニングしません。代わりに、ユーザーはコンソールの「Model」カードで呼び出し方法を選択します:

| 方法 | 請求モード | APIキーの提供元 | 使用例 |
|---|---|---|---|
| モデルコーディングプラン | 月額 | 提供者 | 高頻度使用 |
| モデルAPI | 従量課金 | 提供者 | 低頻度使用またはトライアル |
| カスタムモデル | エンドポイントによる | ユーザー提供 | 海外モデルやOpenAI互換のエンドポイントに接続 |

さらに、Launchプランには100のトライアルクレジットが含まれているため、設定なしですぐにチャットを開始できます。トライアルクレジットがなくなった後は、自分のAPIキーを設定できます。

対応モデル、API キーの取得、およびモデル選択ガイドについては、 を参照してください[モデルの設定](./configuration/model.md)。

> Botが同時に使うプライマリモデルは1つです。ほかのモデルやフォールバックを設定でき、切り替え時に以前の設定を削除する必要はありません。[モデル切り替え](./configuration/multiple-models.md)を参照してください。

## チャンネル

チャンネルは、ユーザーがHermes Agentとチャットするメッセージングプラットフォームの入口です。LightVelaは現在、以下のチャンネルをサポートしています:

| チャネル | アクセス方法 | 使用例 |
|---|---|---|
| WeChat | QRコード認証 | 日常の個人使用向き、中国のユーザーに適しています |
| Telegram | Botトークンアクセス | 個人またはチームのメッセージ、簡単な設定、軽量なスケジュールタスクに適しています |
| WhatsApp | WhatsAppでQRコードをスキャン | 国際的なユーザーとの通信、カスタマーサービス、通知およびリマインダー |
| Discord | Botトークンアクセス | コミュニティ運営、開発者コミュニティ、ゲームまたは趣味のグループ |
| Slack | ボットトークン / アプルトークンアクセス | チームコラボレーション、ワークスペース通知、チャンネルベースのワークフロー |

**Channels**の**WeChat**カードで**+ Connect**を選び、スマートフォンでQRコードをスキャンしてください。

各チャネルの詳細アクセス手順:[チャンネルの設定 - WeChat](./configuration/channel-wechat.md) / [Telegram](./configuration/channel-telegram.md) / [WhatsApp](./configuration/channel-whatsapp.md) / [Discord](./configuration/channel-discord.md) / [Slack](./configuration/channel-slack.md)。

> 💡 **複数チャンネルの共存が可能**
>
> 同じBotに接続した複数のチャネルは、そのBotのペルソナとメモリを共有します。別のBotの設定は自動共有されません。

---

## スキル

スキルはHermes Agentによって呼び出せる追加の機能パッケージです。それらは、Hermes Agentを基本的な会話以上に拡張し、やることリストの整理、日報作成、ウェブ閲覧、画像生成など特定のタスクに対応します。

国際サイトのスキルは[Skills.sh](https://skills.sh/)と[ClawHub](https://clawhub.ai/)から提供されます。コンソールの**Skills**ページで配布元と説明を確認してからインストールしてください。

コンソールの**Skills**で個別のスキルを検索するか**Skill Packages**を閲覧し、**Install**を選択します。**Installed**で結果を確認してください。詳しくは[スキルの設定](./configuration/skill.md)を参照してください。

> ⚠️ **インストール前のセキュリティチェック**
>
> スキルは実行時にHermes Agentの機能を呼び出す権限があります。スキルをインストールする前に、作成者が信頼できるか確認し、ダウンロード数が多く評価が高いスキルを優先してください。

---

## インタラクションフロー

完全な会話フローは次のように機能します：

1. ユーザーがチャネル（例えばWeChat）を通じてHermes Agentにメッセージを送信します

2. Hermes Agentはメッセージに基づいてスキルを呼び出す必要があるかどうかを判断します

3. モデルはコンテキストを処理し、応答を生成します

4. 生成された応答は元のチャネルを通じてユーザーに返されます
