# プラン

## 概要

**Agent コンソールの左サイドバー下部にあるアバターメニューには、プロフィールとユーザー ID を管理する「アカウント」と、契約、クレジット使用量、更新、支払い方法を管理する「プランとお支払い」の 2 つの入口があります。**

**LightVela には Launch、Cruise、Launch AI、Cruise AI の4つのプランがあります。各プランは Hermes Agent 用の専用クラウド環境と月間モデルクレジットを提供し、Launch 系列は最大5 Bot、Cruise 系列は最大10 Bot に対応します。Bot 数と Hermes Agent のインスタンス数は異なり、各プランで利用できる Hermes Agent は1つです。価格や購入可能状況は購読画面で確認してください。**

---

LightVelaは、軽量なスタートポイントから高頻度のエージェント利用までのニーズに対応するために、**Launch、Cruise、Launch AI、Cruise AI**の4つのプラン階層を提供します。各プランはHermes Agent用の専用クラウド環境と月ごとのAIクレジット割り当てを提供します。このページでは、プランの位置付け、リソース、利点、返金ルール、および申請手順について説明し、適切なプランを選択できるようにしています。

## プランとは何ですか？

### アカウントと支払いの入口

LightVela にログインします。Agent コンソールの左サイドバー下部にあるアバターと名前にカーソルを合わせて、メニューを開きます。

- **アカウント（Account）**：[アカウントページ](/account/)でプロフィールの確認、表示名の変更、ユーザー ID のコピー、ログアウトを行います。
- **プランとお支払い（Plans & billing）**：[プランとお支払いページ](/account/billing/)で契約中のプラン、有効期間、クレジット使用量、支払い方法を確認し、プランを更新します。

「プランとお支払い」で契約の状態を確認してください。更新可能なプランがある場合は更新ボタンを選び、画面の案内に従います。未契約の場合は作成ボタンからサブスクライブページへ進み、プランを選択できます。支払い方法のセクションではカードを追加できます。カード情報は決済サービスのページで入力し、LightVela は完全なカード番号を保存しません。

ページタイトルで目的のページにいることを確認できます。購入済みプランが表示されない場合は、購入時と同じアカウントでログインしているか確認してから再読み込みし、重複注文は避けてください。カードが表示されない場合は、決済サービス側の手続きを完了してから戻り、再読み込みしてください。

### プランとリソース

プランとは、LightVelaでHermes Agentを有効化するリソースパッケージです。現在利用可能なプランを有効化すると、LightVelaは独自のCPU、メモリ、ストレージを備えた**専用クラウド環境**を割り当てます。あなたのHermes Agentは、サーバーを購入したりローカルに何かをデプロイしたりする必要なしに、24/7オンラインのままにすることができます。

プランごとの主な違いは、**実行環境、ストレージ、Bot 上限、月間モデルクレジット**です。会話、チャネル、スキル、スケジュールタスク、長期記憶などの基本機能は各プランで利用できます。

リアルタイムの価格、在庫、割引、購入可能性が[サブスクライブページ](/subscribe)に表示されます。以下の値は、現在のリソース構造、標準リスト価格、およびAIクレジットの割り当てを示しています。

### すべてのプランに含まれるエージェント機能

すべてのHermes Agentには、次の基本機能が含まれています：

- **適応型エージェントの行動** — エージェントは使用することで学習し、あなたのニーズにより適合するようになります

- **24時間/7利用可能** — クラウドホスティングにより、デバイスをオンにしておく必要なくオンラインを維持します

- **簡単な構成コンソール** — ウェブから構成[モデル](./configuration/model.md)、チャネル、およびスキル

- **対応メッセージングチャンネル** — WeChat、QQ、Lark、Telegram、WhatsApp、Discord、Slack、WeComを含む対応チャネルでエージェントとチャットできます

- **主流モデルAPI** — 必要に応じてプランのAIクレジットを使用するか、自分のモデルAPIキーを設定できます

- **厳選されたスキルとスキルパック** — エージェントの再利用可能な機能をインストール

- **カスタムペルソナ、スケジュールタスク、長期メモリ、診断** — 日常使用、予定実行、コンテキスト蓄積、実行時トラブルシューティングをカバー

AIクレジットの割り当てと使用方法については、こちらをご覧ください[クレジット](./credits.md)。

### プラン変更規則

利用中のプランは、条件を満たす場合にアップグレードできます。「プランとお支払い」または[サブスクライブページ](/subscribe)で現在のプランから選択できるアップグレード先を確認し、表示されたプランを選んで注文を確定し、支払いを完了してください。条件に応じて、同じプラン系列内または異なる系列へのアップグレードが選択できる場合があります。実際に表示されるアップグレード先のみ選択できます。

アップグレードの支払額は、現在のプランの残りの有効期間や変更先などによって異なります。固定のアップグレード料金はなく、**最終的な支払いページに表示される実際の金額が優先されます**。支払い後はコンソールでプランの状態と特典を確認してください。希望する変更先が選択肢に表示されない場合、現在のプランからはその変更先にアップグレードできません。同じプランの有効期間を延ばす場合は更新を利用してください。

### プランのライフサイクル

プランが期限切れになると、1日後にプランの特典が一時停止されます。データは期限切れ日から14日間保持されます。保持期間が終了すると、データは削除され、回復できなくなります。

## 返金ガイド

LightVela 国際サイトの注文は、メールでの返金申請をサポートしています。返金ルールはLightVela プラン注文の返金ルールと共有されています。ルールと手順は以下の通りです。

### 返金ルール

- 各アカウントはプラン注文の返金権利を**1回**だけ利用できます。

- **月額プラン**: 実際の支払い時から**24時間以内**であれば、付与されたAIクレジットが使用されていない場合に申請可能です。

- **四半期プラン**: 実際の支払い時から**72時間以内**であれば、付与されたAIクレジットが使用されていない場合に申請可能です。

返金申請が承認されるかどうかは、LightVelaサポートチームの審査によります。

### 申請方法

1. 返金規則を確認し、関連する条件を満たしていることを確認してください。

2. メールを送信してください[lightvela@tencent.com](mailto:lightvela@tencent.com)メールには、サインイン用のメール／サインイン方法、LightVelaユーザーID、プラン名、注文時間などのアカウント情報、返金の理由、エージェントが作成または実行されたか、AIクレジットが使用されたか、チャネル、スキル、スケジュールタスクが接続されたかなど、アカウントの現在の使用状況を明確に記載してください。

3. LightVelaサポートチームは、**3営業日**以内にあなたの申請を処理します。

4. 返金申請が承認されると、システムが返金を処理します。返金は**5～10営業日**以内に元の支払い方法に返金されます。申請が承認されない場合、多くは返金ルールが満たされていないことが原因です。

## FAQ

### 各プランの料金はいくらですか？

リアルタイムの価格、在庫、割引、税金、および購入可能性は、[サブスクライブページ](/subscribe)および支払いページに表示されます。この文書の価格表には、現在の月額標準料金のみが記載されています。

### プランをアップグレードまたは切り替えることはできますか？

利用中のプランは、コンソールまたはサブスクライブページに表示される対象プランへアップグレードできます。条件を満たせば異なるプラン系列への変更も選択できますが、表示された対象プランから選択してください。実際の支払額は最終的な支払いページで確認してください。

### 1つのプランには何人のエージェントが含まれますか？

Launch、Cruise、Launch AI、Cruise AI はそれぞれ1つのエージェントが含まれています。エージェントの許容量は、同時に実行できる Hermes のインスタンス数です。

### クレジットがなくなった場合はどうなりますか？

クレジットはモデルの使用量を測定します。クレジットがなくなると、モデルを呼び出す機能が制限されます。現在利用可能な次のステップは、プラットフォームの最新ルールによって管理されます。詳細は[クレジット](./credits.md)を参照してください。
