# 如何开通第一个 Hermes 智能体伙伴？

## 摘要

**开通第一个 Hermes 智能体伙伴分四步：用 QQ 或微信一键登录 → 完成实名认证（首次开通套餐前必需，一次生效）→ 在订阅页选择并开通一档套餐 → 平台自动创建 Agent 实例。全程在网页点选完成，无需购买服务器或做本地部署。前置条件只有三项：一个可用的 QQ 或微信账号、完成实名认证、选定一档套餐（启航 Launch 新用户首单免费体验 14 天，巡游 Cruise 规格与积分更充裕，两个 AI 版提供更高模型积分）。创建完成后进入「我的 Hermes」管理台，即可配置模型、接入微信 / QQ / 企业微信 / 飞书 / 钉钉通道并安装技能。**

---

Hermes 智能体伙伴是运行在 LightVela 云端的 Agent——你的专属 AI 伙伴就住在这里。开通第一个 Hermes 智能体伙伴的过程是：**登录账号 → 完成实名认证 → 选择并开通套餐 → 平台自动创建**。整个流程在网页上点选完成，无需购买服务器或做本地部署。本页按顺序说明每一步。

## 前置条件

- 一个可用的 QQ 或微信账号（用于登录）

- 完成实名认证（首次开通套餐前必需）

- 选定一档[套餐](./plans.md)

---

## 开通流程

### 1. 登录账号

LightVela 使用 QQ / 微信社交账号一键登录，无需单独注册密码。首次登录会自动创建账号。登录方式与账号体系详见[账号与实名认证](./03-account.md)。

> ℹ️ 同一用户用 QQ 与微信分别登录会产生两个独立账号，数据不互通，建议固定使用一种登录方式。

### 2. 完成实名认证

**首次开通任意套餐前，账号必须完成实名认证**。若未认证就点击开通，页面会提示前往「我的账号」进行实名。认证只需填写真实姓名与身份证号，一次生效、后续开通任何套餐都无需重复认证。详细流程见[账号与实名认证](./03-account.md)。

### 3. 选择套餐

进入[订阅页](/subscribe/)，选择适合的套餐档位：

- **启航 Launch** — 低成本上手，新用户首单免费 14 天

- **巡游 Cruise** — 日常主力，规格与积分更充裕

- **启航 Launch AI** — 启航规格 + 更高模型积分

- **巡游 Cruise AI** — 巡游规格 + 更高模型积分，适合高频使用

各档规格、积分、促销、续费与退款规则见[套餐管理](./plans.md)。

### 4. 开通套餐，自动创建

在套餐卡上点击「立即订阅」或「免费订阅」（新用户启航 Launch 活动），按提示完成下单。开通成功后，平台会**自动为你分配一个专属云端环境并创建第一个 Hermes 智能体伙伴**，你无需手动配置服务器。

### 5. 配置并唤醒你的 Agent

智能体伙伴创建后，进入管理台完成基础配置，让 Agent 真正跑起来：

1. **配置模型** — 选择底层大模型，见[模型配置](./configuration/model.md)

2. **连接通道** — 绑定微信 / QQ / 企业微信 / 飞书 / 钉钉等聊天入口，之后即可在聊天软件里直接和 Agent 对话

3. **（可选）安装技能与设置定时任务** — 为 Agent 扩展能力，见[技能配置](./configuration/skill.md)

完成后，你的第一个 Hermes Agent 就 7×24 小时在线待命了。

## 常见问题

### 开通后多久能用

套餐开通成功后，平台会即时创建 Hermes 智能体伙伴。你随后进入管理台配置模型与通道，配置完成即可开始对话。

### 免费试用到期后会怎样

启航 Launch 首单免费 14 天。试用期结束后按套餐规则计费，具体以订阅页与账号页的提示为准。

### 一个账号能开几个 Hermes 智能体伙伴

取决于所选套餐的 Agent 配额。当前已上线的启航 / 巡游 / 启航 AI / 巡游 AI 均含 1 个 Agent 配额。详见[套餐管理](./plans.md)。

### 开通后需要自己维护服务器吗

不需要。Hermes 智能体伙伴运行在 LightVela 托管的云端环境中，平台负责运维与 7×24 小时在线，你只需在网页上做配置。
