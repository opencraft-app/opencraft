# 如何开通第一个 Hermes 智能体伙伴？

## 摘要

**开通第一个 Hermes Agent 的顺序是：用 QQ 或微信登录、完成首次开通所需的实名认证、在订阅页选择启航或巡游系列及模型积分档位，再按引导为首个 Bot 命名并创建。全程在网页完成，无需自行购买服务器。订阅页会按月付或季付、积分档位和当前活动显示实际价格；创建后可在「我的 AI 伙伴」的「日常 → 对话」直接聊天；模型、技能及微信、QQ、企业微信、飞书、钉钉等外部通道按需配置。**

---

Hermes 智能体伙伴是运行在 LightVela 云端的 Agent——你的专属 AI 伙伴就住在这里。开通第一个 Hermes 智能体伙伴的过程是：**登录账号 → 完成实名认证 → 选择并开通套餐 → 按引导创建**。整个流程在网页上点选完成，无需购买服务器或做本地部署。本页按顺序说明每一步。

## 前置条件

- 一个可用的 QQ 或微信账号（用于登录）

- 完成实名认证（首次开通套餐前必需）

- 选定一档[套餐](./plans.md)

---

## 开通流程

### 1. 登录账号

LightVela 使用 QQ / 微信社交账号一键登录，无需单独注册密码。首次登录会自动创建账号。登录方式与账号体系详见[账号与实名认证](./03-account.md)。

> ℹ️ 同一用户用 QQ 与微信分别登录会产生两个独立账号，数据不互通，建议固定使用一种登录方式。

### 2. 完成实名认证

**首次开通任意套餐前，账号必须完成实名认证**。若未认证就点击开通，页面会提示前往「我的账号」进行实名。认证只需填写真实姓名与身份证号，一次生效、后续开通任何套餐都无需重复认证。详细流程见[账号与实名认证](./03-account.md)。

### 3. 选择套餐

进入[订阅页](/subscribe/)，先选择月付或季付，再选择套餐系列与模型积分档位：

- **启航 Launch** — 2 vCPU、8 GB 内存、50 GB 存储，可选每月 100 或 4500 模型积分；订阅页展示最多 5 个 Bot

- **巡游 Cruise** — 4 vCPU、16 GB 内存、80 GB 存储，可选每月 200 或 10000 模型积分；订阅页展示最多 10 个 Bot

首购优惠、可售状态和最终应付金额以订阅页和支付页实时展示为准。各系列权益、额外积分包、续费与退款规则见[套餐管理](./plans.md)。

### 4. 开通套餐，完成首个 Bot 创建

在套餐卡上点击「立即订阅」或符合当前活动条件时显示的「免费订阅」，按提示确认选中的付费时长、积分档位和订单金额。开通成功后，页面进入首个 Bot 的创建引导：选择外观，填写必填的「名字」和可选的「描述」，然后点击 **创建**，等待创建及配置步骤完成，再点击 **开始旅程** 进入该 Bot 的工作区。没有可复制的 Bot 时，不显示「高级」中的复制来源，也没有用于返回已有 Bot 的关闭入口。外观区域可以自行搭配颜色、形状和配饰，或选择随机样式；这与创建更多 Bot 时的复制选项不同。LightVela 托管云端环境，你无需手动配置服务器；若账号已有 Bot，则进入现有管理台。

### 5. 配置并唤醒你的 Agent

智能体伙伴创建后，进入管理台完成基础配置，让 Agent 真正跑起来：

1. **模型配置** — 套餐模型积分可用时可直接开始；需要自有模型时见[模型配置](./configuration/model.md)

2. **网页对话** — 在「日常 → 对话」新建会话并发送消息，见[对话](./configuration/agent-chat.md)

3. **按需连接通道** — 若要在微信、QQ、飞书等聊天软件中使用 Bot，再连接对应通道

4. **（可选）安装技能与设置定时任务** — 为 Agent 扩展能力，见[技能配置](./configuration/skill.md)

完成后，确认管理台选中了新 Bot，在网页对话发送「你好」并收到回复。若选择了角色模板，还应检查模板列出的技能和定时任务是否配置成功；页面提示部分配置未完成时，到相应配置页重试。

## 创建未完成时

- **创建按钮不可用**：先填写非空的「名字」，再检查页面是否提示套餐或额度限制。
- **仍在创建或配置中**：等待页面完成，避免重复发起创建。
- **提示已创建但配置未就绪**：先查看 Bot 列表，回到该 Bot 的设置页检查；不要把配置失败直接当作 Bot 没有创建。
- **已有 Bot，还想再创建一个**：按[管理与切换 Bot](./configuration/bots-switching.md)操作。再次创建默认空白创建，有可复制来源时才显示「高级」和关闭入口。

## 常见问题

### 开通后多久能用

套餐开通并完成首个 Bot 创建后，若模型积分可用或已配置模型，即可在网页「日常 → 对话」发送消息；外部通道可稍后连接。创建时间以管理台显示的实际状态为准。

### 免费试用到期后会怎样

若购买时订阅页显示首单免费活动，免费期限及到期处理以该订单和[套餐与费用页](/account/billing/)为准。套餐不会因为本文档的活动描述自动续费；到期后如需继续使用，可从 Agent 管理台左下角头像菜单选择「套餐与费用」查看状态并按页面提示续费。

### 一个套餐可以创建几个 Bot

当前订阅页展示启航系列最多 5 个、巡游系列最多 10 个 Bot。能否新建以及当前剩余数量，还取决于账号权益、当前 Bot 数和功能开放状态，以管理台实际提示为准。详见[管理与切换 Bot](./configuration/bots-switching.md)及[套餐管理](./plans.md)。

### 开通后需要自己维护服务器吗

不需要。Hermes 智能体伙伴运行在 LightVela 托管的云端环境中，平台负责运维与 7×24 小时在线，你只需在网页上做配置。
