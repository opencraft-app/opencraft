# AI 积分说明

## 摘要

**AI 积分用于计量 Hermes Agent 的模型调用，约 1 积分对应 10000 Token，输入与输出都会计入消耗。国内站启航 Launch 可选每月 100 或 4500 积分，巡游 Cruise 可选每月 200 或 10000 积分；已有有效套餐的用户还可另购有效期为 1 个月的模型积分包。对话、智能任务及调用模型的技能会消耗积分，固定通知任务和脚本任务本身不调用模型。积分不足时可按需购买积分包、等待下一周期套餐额度，或配置自有模型 API Key；具体额度和价格以订阅页实时展示为准。**

---

AI 积分（Credits）是 LightVela 用来计量 Hermes Agent 模型调用消耗的额度单位。套餐积分按所选档位提供；已有有效套餐的用户还可购买额外积分包。Agent 只有在调用大模型时才会产生对应模型积分消耗。

## AI 积分是什么

AI 积分是 Hermes Agent 调用大模型的**计量单位**。你的 Agent 每次对话、执行定时任务或运行技能时，都会向底层大模型发起请求，这些请求按消耗的 Token 数折算成积分扣减。

换算关系：**1 积分 ≈ 10000 Token**。Token 是大模型处理文本的基本单位，输入（你发给 Agent 的内容）和输出（Agent 生成的回复）都会计入消耗。

> ℹ️ 具体换算比例与计费口径以平台实时展示为准。

## 积分如何发放

套餐积分**按所选档位随套餐提供**，订阅页当前展示以下选项：

| 套餐系列 | 每月模型积分选项 |
|---|---|
| 启航 Launch | 100 或 4500 积分 / 月 |
| 巡游 Cruise | 200 或 10000 积分 / 月 |

高积分档适合预计模型调用较多的用户。不同档位的实时价格与活动见[套餐管理](./plans.md)；购买前以[订阅页](/subscribe/)的选中档位和支付页为准。

## 购买额外积分包

已有有效套餐、需要增加模型调用额度时，可在[订阅页的模型积分区域](/subscribe/?section=credits)选择积分包。当前页面提供 1000、2000、4000、8000 和 12000 积分选项；价格以页面实时询价为准。积分包自支付成功并到账起有效 **1 个月**，到期未使用的额度失效，也不能续费；需要更多额度时可重新购买。

有多份可用额度时，实际抵扣优先使用到期时间更早的额度；到期时间相同，则优先使用创建时间更早的额度。购买积分包不会更改原套餐系列、Bot 数或每月套餐积分档位。可在「套餐与费用」页查看额度和有效期，购买前核对当前账号与套餐状态。

## 积分如何消耗

积分在以下场景（包括但不限于）被消耗，本质都是 Hermes Agent 调用了大模型：

- **和 Agent 对话** — 你在微信 / QQ / 企业微信 / 飞书 / 钉钉等通道与 Agent 聊天

- **运行智能任务** — Agent 按计划调用模型理解、分析或生成内容

- **运行技能** — 技能内部调用模型完成推理

固定文字的[通知任务](./configuration/automation.md#新建通知任务)与确定性[脚本任务](./configuration/automation.md#新建脚本任务)本身不调用模型，模型 Token 消耗为零；它们仍需有效套餐和相应的云端资源。对话与智能任务的消耗量取决于输入、输出和上下文规模。

---

## 积分与套餐的关系

- **套餐积分**：随选定的套餐积分档位提供，按套餐周期使用。

- **额外积分包**：已有有效套餐时可另购，有效期自到账起 1 个月；不是套餐自动发放额度。

如果可用积分用尽，依赖模型调用的功能会受限。可购买积分包、等待下一周期套餐额度，或在[配置模型](./configuration/model.md)中使用自有大模型 API Key。

## 常见问题

### 积分和套餐价格是分开算的吗

套餐已包含所选档位的月度积分；已有有效套餐时，也可以另购积分包。它们是不同额度来源，额外购买会产生独立订单。具体价格、可选档位和有效期以[订阅页](/subscribe/)展示为准。

### 1 积分能聊多久

1 积分约等于 10000 Token。实际能支撑多少轮对话取决于每轮的输入输出长度与上下文规模，无法给出固定轮次，长对话消耗更快。

### 积分用完了还能继续用吗

积分用尽后，依赖模型调用的功能会受限。可以在有效套餐下购买积分包、等待下个周期套餐额度，或配置自有大模型 API Key。
