# AI 积分说明

AI 积分（Credits）是 LightVela 用来计量 Hermes Agent 模型调用消耗的额度单位。每档套餐每月发放一定数量的积分，Agent 在对话、执行任务时调用大模型会按用量扣减积分。本页说明积分是什么、怎么发放、如何消耗，以及和套餐的关系。

## AI 积分是什么

AI 积分是 Hermes Agent 调用大模型的**计量单位**。你的 Agent 每次对话、执行自动任务或运行技能时，都会向底层大模型发起请求，这些请求按消耗的 Token 数折算成积分扣减。

换算关系：**1 积分 ≈ 10000 Token**。Token 是大模型处理文本的基本单位，输入（你发给 Agent 的内容）和输出（Agent 生成的回复）都会计入消耗。

> ℹ️ 具体换算比例与计费口径以平台实时展示为准。

---

## 积分如何发放

积分**随套餐按月发放**，不同套餐的月度积分额度不同：

| 套餐 | AI 积分（标准档） |
|---|---|
| 启航 Launch | 100 积分 / 月 |
| 巡游 Cruise | 200 积分 / 月 |
| 启航 Launch AI | 4500 积分 / 月 |
| 巡游 Cruise AI | 10000 积分 / 月 |

Launch AI 和 Cruise AI 提供更高的 AI 积分额度，可以支持更高频的对话、技能和自动任务。各档实时价格与活动见[套餐管理](./plans.md)。

---

## 积分如何消耗

积分在以下场景（包括但不限于）被消耗，本质都是 Hermes Agent 调用了大模型：

- **和 Agent 对话** — 你在微信 / QQ / 飞书等通道与 Agent 聊天

- **执行自动任务** — Agent 按计划自动运行的定时任务

- **运行技能** — 技能内部调用模型完成推理

消耗量取决于对话长度与上下文规模：内容越长、上下文越多，单次消耗的 Token（进而积分）越多。

---

## 积分与套餐的关系

- **和套餐绑定**：积分是套餐权益的一部分，随套餐按月发放，不单独售卖。

- **额度周期**：积分按月度周期重置。

如果积分在当月用尽，Agent 的模型调用会受限，需等待下月发放或单独配置其他大模型 API Key。

---

## 常见问题

### 积分和套餐价格是分开算的吗

不是。积分是套餐自带的权益，随套餐按月发放，不需要单独购买。选购套餐时选择的积分档位不同，价格也可能不同，以[订阅页](/subscribe/)为准。

### 1 积分能聊多久

1 积分约等于 10000 Token。实际能支撑多少轮对话取决于每轮的输入输出长度与上下文规模，无法给出固定轮次，长对话消耗更快。

### 积分用完了还能继续用吗

积分用尽后，依赖模型调用的功能会受限，需等待下个周期发放或单独配置其他大模型 API Key。
