## 摘要

**Agent 越用越顺手，不是因为它神秘地自动升级，而是因为可复用的方法被沉淀为 Skill，稳定事实被保留为 Memory，并在合适的场景再次加载。**
Memory 让它知道发生过什么。
Skill 让它知道下次遇到同类问题该怎么做。

---

## 引子：经验如果不能复用，就只是一次聊天

一次成功的研究、排障或内容发布，往往包含一套可重复的步骤。
如果步骤只留在聊天记录里，下次还得从头摸索。
Skill 的意义是把已经验证的方法写成带触发条件的操作规范。

## 一、Memory 和 Skill 是两种积累

| 积累 | 保存什么 | 如何被使用 |
| --- | --- | --- |
| Memory | 事实、偏好、结论、经历 | 与当前问题相关时召回 |
| Skill | 场景、步骤、边界、检查项 | 场景匹配时加载并执行 |

"用户喜欢结论先行"是 Memory。
"写发布说明前先核对版本和链接"是 Skill。

## 二、自我改进不是无边界自改

可靠的改进需要把新方法变成可审查的规则。
一个好的 Skill 应说明何时使用、按什么步骤执行、成功标准是什么，以及哪些边界不能越过。
这样 Agent 的能力增长才可解释、可复用、可纠正。

## 三、让积累真正有价值

先在真实任务中验证流程。
再把稳定且可复用的步骤沉淀为 Skill。
当产品、工具或政策变化时，更新 Skill，而不是让旧经验无限沿用。

## 结论

Agent 的"越用越顺手"来自有结构的积累。
Memory 保留背景。
Skills 保留方法。
人和 Agent 都能看懂并持续改进这套系统。
