## 摘要

**Hermes Agent 能按时主动找你，不是因为它一直在聊天窗口里等待，而是因为自动任务把"何时执行"、"做什么"和"发到哪里"保存成可调度的任务。**
到点后，调度器启动一次独立执行，再按配置投递结果。

---

## 引子：主动，不等于永远在线地盯着你

"每天早上给我新闻摘要"看起来像一句普通指令。
但它至少包含三件事：什么时候执行、执行什么、结果送到哪里。
自动化任务把这三件事从一次聊天变成可重复运行的工作。

## 一、定时任务是一份明确的执行合同

一项自动任务通常包含名称、提示词、计划、投递目标，以及可能固定的模型配置。
它可以是一次性、间隔式或 Cron 计划。

| 字段 | 回答的问题 |
| --- | --- |
| Schedule | 什么时候运行？ |
| Prompt | Agent 要完成什么？ |
| Deliver | 结果发到哪里？ |
| Model | 这次执行用哪个推理引擎？ |

## 二、到点后会发生什么

调度器 tick 到目标时间后，触发一次任务执行。
这不是把旧聊天记录机械重放，而是启动独立的 Agent 工作，并使用任务配置决定投递。
因此任务提示词应写清目标、边界和输出格式。

## 三、可靠性的三个习惯

先手动验证一次任务内容。
再设置计划并确认目标通道。
最后查看最近运行记录，而不是只看任务是否已创建。
模型切换后，也应检查是否要同步仍在运行的自动任务。

## 结论

自动化让 Agent 从"等你提问"变成"在约定时间完成约定工作"。
