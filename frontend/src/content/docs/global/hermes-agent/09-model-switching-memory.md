## 摘要

**切换模型不会让 Hermes Agent 自动失忆，因为模型、人格和记忆本来就是三层独立资产。**
模型决定如何推理。
`SOUL.md` 定义角色与表达边界。
`USER.md` 和 `MEMORY.md` 保存用户画像与跨会话事实。
真正需要额外检查的是已经固定模型的自动任务。

---

## 引子：回答风格变了，记忆是不是也没了

换模型后，Agent 的措辞、速度或工具选择可能明显不同。
这很容易让人误以为"它不认识我了"。
但表现变化与持久数据丢失是两件事。

## 一、三层各自回答不同问题

| 层 | 它负责什么 | 换模型后的状态 |
| --- | --- | --- |
| Model | 推理与生成 | 被替换 |
| Persona | 角色、语气、边界 | 保留 |
| Memory | 偏好、事实、共同经历 | 保留 |

模型会重新解释同一份上下文，所以体验可能不同。
但它不会因为被替换就主动清空这些独立文件。

## 二、为什么仍可能感觉"不一样"

不同模型对指令的遵循程度、上下文压缩、工具调用和表达习惯不同。
如果新模型更简短，或更少主动引用背景，它看起来就像忘记了。
遇到这种情况，先确认 Memory 和 Persona 文件仍在，再评估新模型是否适合你的任务。

## 三、切换后的检查清单

1. 用一条已知偏好做一次普通聊天验证。
2. 检查 Persona 是否仍符合预期。
3. 查看自动任务是否固定在旧模型，并决定是否同步。

## 结论

模型是可替换的推理引擎。
人格和记忆是让 Agent 长期保持"是同一个它"的持久层。
