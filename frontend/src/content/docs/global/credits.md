# AI 积分说明

AI 积分（Credits）是 LightVela 用来计量 Hermes Agent 模型调用消耗的额度单位。每档套餐每月发放一定数量的积分，Agent 在对话、执行任务时调用大模型会按用量扣减积分。本页说明积分是什么、怎么发放、如何消耗，以及和套餐的关系。

## AI 积分是什么

AI 积分是 Hermes Agent 调用大模型的**计量单位**。你的 Agent 每次对话、执行[自动任务](./configuration/automation.md)或运行技能时，都会向底层大模型发起请求；这些请求会根据消耗的 Token 数折算成积分。

换算关系：**1 积分 ≈ 10000 Token**。Token 是大模型处理文本的基本单位，输入（你发给 Agent 的内容）和输出（Agent 生成的回复）都会计入消耗。

> ℹ️ 具体换算比例与计量口径以平台实时展示为准。

---

## 积分如何发放

积分**随套餐按月发放**，不同套餐的月度积分额度不同：

| 套餐 | AI 积分（标准档） |
|---|---|
| 启航 Launch | 100 积分 / 月 |
| 巡游 Cruise | 200 积分 / 月 |
| 远航 Voyage | 500 积分 / 月（敬请期待） |

部分套餐可能提供**更高的积分档位**。当前可选档位以[订阅页](/subscribe)的套餐卡片为准，各档资源与额度见[套餐说明](./plans.md)。

---

## 积分如何消耗

积分在以下场景（包括但不限于）被消耗，本质上都是 Hermes Agent 调用了大模型：

- **和 Agent 对话** — 通过 Telegram、WhatsApp、Discord 或 WeChat 等通道与 Agent 交流

- **执行自动任务** — Agent 按计划运行[定时任务](./configuration/automation.md)

- **运行技能** — 技能在执行过程中调用模型完成推理

消耗量取决于对话长度与上下文规模：内容越长、上下文越多，单次消耗的 Token 和积分通常越多。

---

## 积分与套餐的关系

- **和套餐绑定**：积分是套餐资源的一部分，按套餐的月度周期发放。当前可用的获取或补充方式以[订阅页](/subscribe)与平台规则为准。

- **额度周期**：积分按月度周期重置。

如果积分在当月用尽，Agent 的模型调用会受限，需等待下月发放或单独配置其他大模型 API Key。

---

## 常见问题

### 积分和套餐是怎样关联的

积分是套餐包含的资源，按月随套餐发放。不同积分档位对应的当前可用性与后续价格以[订阅页](/subscribe)为准。

### 1 积分能聊多久

1 积分约等于 10000 Token。实际可支持的对话轮数取决于每轮输入输出长度与上下文规模，无法换算成固定轮次；长对话通常消耗更快。

### 积分用完了还能继续用吗

积分用尽后，依赖模型调用的功能会受限，需等待下个周期发放或单独配置其他大模型 API Key。
