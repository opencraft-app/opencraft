# 体验积分说明

模型积分（Credits）是 LightVela 用来计量 Hermes Agent 模型调用消耗的额度单位。每档套餐按月提供一定数量的积分；Agent 在对话或执行任务时调用大模型，会按用量扣减积分。本页说明积分是什么、如何发放与消耗，以及积分和套餐的关系。

## 模型积分是什么

模型积分是 Hermes Agent 调用大模型的**计量单位**。你的 Agent 每次对话、执行[自动任务](./configuration/automation.md)或运行技能时，都会向底层大模型发起请求；这些请求会根据消耗的 token 数折算成积分。

换算关系：**1 积分 ≈ 10000 token**。token 是大模型处理文本的基本单位，输入（你发给 Agent 的内容）和输出（Agent 生成的回复）都会计入消耗。

> ℹ️ 具体换算比例与计量口径以平台实时展示为准；不同模型的单位 token 成本可能不同。

---

## 积分如何发放

积分**随套餐按月发放**，不同套餐的月度积分额度不同：

| 套餐 | 模型积分（标准档） |
|---|---|
| 启航 Launch | 100 积分 / 月 |
| 巡游 Cruise | 200 积分 / 月 |
| 远航 Voyage | 500 积分 / 月（敬请期待） |

部分套餐可能提供**更高的积分档位**。当前可选档位以[订阅页](/subscribe)的套餐卡片为准，各档资源与额度见[套餐说明](./plans.md)。

---

## 积分如何消耗

积分会在以下场景中消耗，本质上都是 Hermes Agent 调用了大模型：

- **和 Agent 对话** — 通过 Telegram、WhatsApp、Discord 或 WeChat 等通道与 Agent 交流

- **执行自动任务** — Agent 按计划运行[定时任务](./configuration/automation.md)

- **运行技能** — 技能在执行过程中调用模型完成推理

消耗量取决于对话长度与所选模型：内容越长、上下文越多，单次消耗的 token 和积分通常越多。选择更经济的模型、控制上下文长度，都有助于降低积分消耗。模型选择见[模型配置](./configuration/model.md)。

---

## 积分与套餐、模型的关系

- **和套餐绑定**：积分是套餐资源的一部分，按套餐的月度周期发放。当前可用的获取或补充方式以[订阅页](/subscribe)与平台规则为准。

- **和模型相关**：不同大模型的单位 token 成本不同，同样的对话在不同模型下消耗的积分可能不一样。

- **额度周期**：积分按月度周期发放，是否结转以及有效期以平台当前规则为准。

如果积分在当月用尽，Agent 中依赖模型调用的功能会受到限制，直到新的额度可用或平台提供其他处理方式。

## 常见问题

### 积分和套餐是怎样关联的

积分是套餐包含的资源，按月随套餐发放。不同积分档位对应的当前可用性与后续价格以[订阅页](/subscribe)为准。

### 1 积分能聊多久

1 积分约等于 10000 token。实际可支持的对话轮数取决于每轮输入输出长度与所选模型，无法换算成固定轮次；长对话通常消耗更快。

### 不同模型消耗积分一样吗

不一样。模型的单位 token 成本不同，同一任务在不同模型下可能产生不同的积分消耗。可在[模型配置](./configuration/model.md)中按需选择。

### 积分用完了还能继续用吗

积分用尽后，依赖模型调用的功能会受限。新的额度何时可用或是否有其他补充方式，以平台当前规则为准。
