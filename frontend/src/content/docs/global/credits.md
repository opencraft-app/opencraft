# 体验积分说明

## 摘要

**模型积分用于计量模型调用的输入和输出。启航 Launch、启航 Launch AI、巡游 Cruise、巡游 Cruise AI 每月分别包含 100、4,500、200、10,000 积分。有效套餐用户还可购买一次性积分包，到账后有效期为 1 个月且不自动续费。对话及调用模型的 Agent Task 会消耗积分；Notification Task 和 Script Task 不调用模型。积分用尽后，可购买符合条件的积分包、等待下期额度，或配置自己的模型 API Key。**

---

模型积分（Credits）是 LightVela 用来计量 Hermes Agent 模型调用消耗的额度单位。每档套餐按月提供一定数量的积分；Agent 在对话或执行任务时调用大模型，会按用量扣减积分。本页说明积分是什么、如何发放与消耗，以及积分和套餐的关系。

## 模型积分是什么

模型积分用于计量大模型调用。对话、调用模型的[Agent Task](./configuration/automation.md)和使用模型的技能会消耗积分；Notification Task 与 Script Task 不调用模型。

换算关系：**1 积分 ≈ 10000 token**。token 是大模型处理文本的基本单位，输入（你发给 Agent 的内容）和输出（Agent 生成的回复）都会计入消耗。

> ℹ️ 具体换算比例与计量口径以平台实时展示为准；不同模型的单位 token 成本可能不同。

---

## 积分如何发放

积分**随套餐按月发放**，不同套餐的月度积分额度不同：

| 套餐 | 每月模型积分 |
|---|---:|
| 启航 Launch | 100 |
| 巡游 Cruise | 200 |
| 启航 Launch AI | 4,500 |
| 巡游 Cruise AI | 10,000 |

各档资源见[套餐说明](./plans.md)，当前可售状态与价格以[订阅页](/subscribe)为准。

## 额外积分包

有效套餐用户可在[订阅页](/subscribe#subscribe-credits)一次性购买模型积分包。积分到账后有效期为 1 个月，不自动续费。先消耗到期时间较早的积分；到期时间相同时先消耗较早到账的积分。可选额度和价格以结算页为准。

---

## 积分如何消耗

积分会在以下场景中消耗，本质上都是 Hermes Agent 调用了大模型：

- **和 Agent 对话** — 通过 Telegram、WhatsApp、Discord、Slack 或 WeChat 等通道与 Agent 交流

- **执行 Agent Task** — Agent 按计划运行需要模型推理的[定时任务](./configuration/automation.md)

- **运行技能** — 技能在执行过程中调用模型完成推理

消耗量取决于对话长度与所选模型：内容越长、上下文越多，单次消耗的 token 和积分通常越多。选择更经济的模型、控制上下文长度，都有助于降低积分消耗。模型选择见[模型配置](./configuration/model.md)。

---

## 积分与套餐、模型的关系

- **和套餐绑定**：积分是套餐资源的一部分，按套餐的月度周期发放。当前可用的获取或补充方式以[订阅页](/subscribe)与平台规则为准。

- **和模型相关**：不同大模型的单位 token 成本不同，同样的对话在不同模型下消耗的积分可能不一样。

- **额度周期**：积分按月度周期发放，是否结转以及有效期以平台当前规则为准。

如果积分在当月用尽，Agent 中依赖模型调用的功能会受到限制，直到新的额度可用或平台提供其他处理方式。

---

## 常见问题

### 积分和套餐是怎样关联的

积分按月随套餐发放；有效套餐用户也可一次性购买额外积分包。当前可选档位和价格以[订阅页](/subscribe)为准。

### 1 积分能聊多久

1 积分约等于 10000 token。实际可支持的对话轮数取决于每轮输入输出长度与所选模型，无法换算成固定轮次；长对话通常消耗更快。

### 不同模型消耗积分一样吗

不一样。模型的单位 token 成本不同，同一任务在不同模型下可能产生不同的积分消耗。可在[模型配置](./configuration/model.md)中按需选择。

### 积分用完了还能继续用吗

可以购买符合条件的一次性积分包、等待下期套餐额度，或配置自己的模型 API Key。没有可用积分或 Key 时，依赖模型调用的功能会受限。
