# 如何开通第一个 Hermes 实例？

## 摘要

**开通第一个 Hermes 实例的流程是：使用 Google 或 GitHub 登录 → 选择可用套餐 → 按当前套餐规则开通 → 平台自动创建实例 → 配置模型与通道。全程在网页完成，无需购买服务器或做本地部署。Hermes 实例即运行在 LightVela 云端的 Agent 运行环境，创建后可 7×24 小时在线。创建完成后进入「我的 Hermes」管理台，即可配置模型、接入聊天通道并安装技能；若暂时没有自有模型 API Key，可直接使用套餐按月提供的模型积分开始对话。**

Hermes 实例是运行在 LightVela 云端的 Agent 运行环境——你的专属 AI 伙伴就住在这里。开通第一个 Hermes 实例的过程是：**使用 Google 或 GitHub 登录 → 选择可用套餐 → 按当前套餐规则开通 → 平台自动创建实例 → 配置模型与通道**。整个流程都在网页上完成，无需购买服务器或进行本地部署。本页按顺序说明每一步。

## 前置条件

- 一个可用的 Google 或 GitHub 账号

- 在[订阅页](/subscribe)选择一个当前可用的套餐；国际站不要求完成中国实名认证

- 至少一个准备接入的聊天通道，例如 Telegram、WhatsApp、Discord、Slack 或 WeChat

---

## 开通流程

### 1. 使用 Google 或 GitHub 登录

访问 LightVela，选择 Google 或 GitHub 完成授权登录。首次登录会自动创建 LightVela 账号，无需另外设置密码。建议后续继续使用同一个登录身份，以便访问原有的 Hermes 实例与数据。

### 2. 从订阅页选择可用套餐

进入[订阅页](/subscribe)，查看当前开放的套餐与名额。启航 Launch 和巡游 Cruise 的资源结构见[套餐说明](./plans.md)，但实际可开通档位以订阅页为准。

国际站没有中国实名认证前置步骤。使用 Google 或 GitHub 登录后，即可选择当前可用的套餐。

### 3. 按当前国际站套餐规则开通套餐

LightVela 计划将于 2026 年 8 月 18 日（新加坡时间）起转入公测并开启计费。正式转入公测并开启计费后，内测用户现有套餐的有效期将额外延长 1 个月，新用户可免费体验启航版 14 天。在套餐卡片上按页面提示完成开通，请以订阅页显示为准。

### 4. 等待 LightVela 自动创建实例

套餐开通成功后，LightVela 会**自动分配一个专属云端环境并创建你的第一个 Hermes 实例**。你不需要手动购买、部署或配置服务器。实例通常会立即开始创建，完成后即可进入管理台。

### 5. 配置并唤醒你的 Agent

实例创建后，进入管理台完成基础配置，让 Agent 真正跑起来：

1. **配置模型** — 选择底层大模型，见[模型配置](./configuration/model.md)

2. **连接通道** — 接入 Telegram、WhatsApp、Discord、Slack、WeChat 或其他支持的聊天通道，之后即可在聊天软件中直接与 Agent 对话

3. **（可选）安装技能与设置自动任务** — 为 Agent 扩展能力，见[自动任务配置](./configuration/automation.md)

完成后，你的第一个 Hermes Agent 就会在云端 7×24 小时在线待命。

## 常见问题

### 开通后多久能用

套餐开通成功后，平台会自动创建 Hermes 实例。实例就绪后进入管理台配置模型与通道，配置完成即可开始对话。

### 开启计费后会怎样

正式转入公测并开启计费后，内测用户现有套餐有效期会额外延长 1 个月；新用户可免费体验启航版 14 天。请关注[订阅页](/subscribe)和 [LightVela 付费版本公告](./announcements/public-beta.md)，获取最新说明。

### 一个账号能开几个 Hermes 实例

取决于所选套餐的 Agent 配额：启航与巡游各含 1 个。详见[套餐说明](./plans.md)。

### 开通后需要自己维护服务器吗

不需要。Hermes 实例运行在 LightVela 托管的云端环境中，平台负责运行维护与 7×24 小时在线；你只需在网页中完成配置。
