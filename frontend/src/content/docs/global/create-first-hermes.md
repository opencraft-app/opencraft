# 如何开通第一个 Hermes 实例？

## 摘要

**开通第一个 Hermes 实例的流程是：使用 Google 或 GitHub 登录 → 选择可用套餐 → 按当前套餐规则开通 → 平台准备实例 → 选择 Bot 外观并填写名字 → 完成配置，点击「开始旅程」 → 在网页对话，外部通道按需配置。全程在网页完成，无需购买服务器或做本地部署。Hermes 实例即运行在 LightVela 云端的 Agent 运行环境，创建后可 7×24 小时在线。完成 Bot 创建与配置后进入「我的 AI 伙伴」，可先在「日常 → 对话」聊天，再按需配置模型、外部通道与技能；若暂时没有自有模型 API Key，可直接使用套餐按月提供的模型积分开始对话。**

---

Hermes 实例是运行在 LightVela 云端的 Agent 运行环境——你的专属 AI 伙伴就住在这里。开通第一个 Hermes 实例的过程是：**使用 Google 或 GitHub 登录 → 选择可用套餐 → 按当前套餐规则开通 → 平台准备实例 → 选择 Bot 外观并填写名字 → 完成配置，点击「开始旅程」 → 在网页对话，外部通道按需配置**。整个流程都在网页上完成，无需购买服务器或进行本地部署。本页按顺序说明每一步。

## 前置条件

- 一个可用的 Google 或 GitHub 账号

- 在[订阅页](/subscribe)选择一个当前可用的套餐；国际站不要求完成中国实名认证

- 只有计划在聊天软件中使用 Bot 时，才需要准备 Telegram、WhatsApp、Discord、WeChat 或 Slack 账号

---

## 开通流程

### 1. 使用 Google 或 GitHub 登录

访问 LightVela，选择 Google 或 GitHub 完成授权登录。首次登录会自动创建 LightVela 账号，无需另外设置密码。建议后续继续使用同一个登录身份，以便访问原有的 Hermes 实例与数据。

### 2. 从订阅页选择可用套餐

进入[订阅页](/subscribe)，查看当前开放的套餐与名额。启航 Launch 和巡游 Cruise 的资源结构见[套餐说明](./plans.md)，但实际可开通档位以订阅页为准。

国际站没有中国实名认证前置步骤。使用 Google 或 GitHub 登录后，即可选择当前可用的套餐。

### 3. 按当前国际站套餐规则开通套餐

从[订阅页](/subscribe/)选择当前可用的套餐，按照套餐卡片提示完成开通。首购活动和价格以页面展示为准。

### 4. 等待 LightVela 自动创建实例

套餐开通成功后，LightVela 会**自动分配一个专属云端环境并创建你的第一个 Hermes 实例**。你不需要手动购买、部署或配置服务器。实例通常会立即开始创建，完成后即可进入管理台。

### 5. 创建 Bot 并完成基础配置

云端实例准备好后，在「创建你的 LightVela Bot」中完成首次引导：

1. 依次选择**颜色、形状、配饰**，或使用「随机样式」。
2. 填写**名字**与可选**描述**；需要时选一个推荐模板。
3. 点击**创建**，等待页面完成配置。
4. 点击**开始旅程**，进入新 Bot 的网页对话。

首次创建没有可复制的 Bot，因此不显示「高级」；这是必做引导，没有关闭按钮。若配置失败，使用弹窗中的重试或恢复提示。实例已分配并不等于 Bot 配置已经完成。

![Bot 创建表单示例，可选择外观并填写名字](../images/bots-switching-create.webp)

图示为已有 Bot 后的再次创建表单，因此带有「高级」选项；首次创建的外观与资料填写方式相同，但没有「高级」和关闭按钮。

![创建表单中的可选推荐模板](../images/bots-switching-templates.webp)

### 6. 验证第一次对话

在「日常 → 对话」发送「你好」，确认 Bot 在线并收到回复。使用套餐模型积分即可开始；需要自有模型时见[模型配置](./configuration/model.md)。网页对话的入口与会话操作见[对话](./configuration/agent-chat.md)。

![创建后通过左侧头像选择 Bot，并从「对话」进入网页聊天](../images/bots-switching-selector.webp)

如果需要在 Telegram、WhatsApp、Discord 或 WeChat 中使用同一 Bot，再连接对应通道。技能与[定时任务](./configuration/automation.md)可在对话正常后按需添加；外部通道不是首次网页对话的前置条件。

## 常见问题

### 开通后多久能用

套餐开通成功后，平台会准备 Hermes 实例；随后需要在网页中完成 Bot 创建引导。实例就绪、Bot 配置完成且模型积分可用或已配置模型时，可先在网页「日常 → 对话」发送消息；外部通道可稍后连接。

### 如何查看当前套餐与活动

套餐、首购活动和续费规则请以[订阅页](/subscribe/)与[套餐说明](./plans.md)为准。

### 一个账号能开几个 Hermes 实例

取决于所选套餐的 Agent 配额：启航与巡游各含 1 个。详见[套餐说明](./plans.md)。

### 开通后需要自己维护服务器吗

不需要。Hermes 实例运行在 LightVela 托管的云端环境中，平台负责运行维护与 7×24 小时在线；你只需在网页中完成配置。
