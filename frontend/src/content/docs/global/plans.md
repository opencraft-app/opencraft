# 套餐说明

LightVela 提供**启航 Launch、巡游 Cruise、远航 Voyage**三档套餐，覆盖从轻量上手到专业进阶的不同需求。每档套餐都会为你开通独立的云端 Hermes Agent 运行环境，并按月提供模型积分。本页说明各档套餐的定位、规格与权益，帮助你按需选择。

## 本页覆盖

- 三档套餐的定位与适合人群

- 各档的独立环境规格、存储与模型积分

- 所有套餐共享的 Agent 核心能力

- 当前内测开放方式与选购说明

---

## 套餐是什么

套餐（Plan）是你在 LightVela 上开通 Hermes Agent 的资源包。开通任意当前可用的套餐后，平台会为你分配一个**专属云端运行环境**（独立的 CPU、内存和存储），你的 Hermes Agent 可以在其中 7×24 小时在线运行，无需自己购买服务器或进行本地部署。

不同档位的区别主要在**独立环境规格、专属存储容量、每月模型积分**，而 Agent 的核心能力——自主进化、多通道接入、技能、自动任务和长期记忆等——在各档套餐中保持一致。

国际站目前处于内测阶段，套餐通过**限量、限时免费的开放流程**提供。开放档位、名额与后续价格可能调整，请以[订阅页](/subscribe)的实时信息为准。下方数值用于说明当前套餐的资源与积分结构。

## 所有套餐共享的 Agent 能力

无论选择哪一档，你的 Hermes Agent 都具备以下能力，差异只在环境规格与积分额度：

- **Agent 自主进化** — Agent 在使用中持续学习，逐渐理解你的需求

- **7×24 小时在线** — 云端托管，无需本地设备保持开机

- **极简配置面板** — 在网页中完成[模型](./configuration/model.md)、通道和技能配置

- **连接支持的聊天通道** — 可接入 Telegram、WhatsApp、Discord、WeChat、QQ、WeCom 和 Lark

- **接入主流模型 API** — 自由选择适合自己的底层大模型

- **精选技能与技能包** — 为 Agent 安装可复用的能力

- **人设注入** — 自定义 Agent 的角色与表达风格

- **自动任务** — 让 Agent 按固定时间自动执行任务，详见[自动任务配置](./configuration/automation.md)

- **长期记忆** — Agent 可以记住历史对话与你的偏好

- **诊断中心** — 排查运行状态与异常

## 开放与选择

- **当前阶段**：国际站处于内测阶段，当前可用套餐采用限量、限时免费的开放方式。

- **可用性与价格**：套餐开放范围、剩余名额与未来价格可能变化，请始终以[订阅页](/subscribe)为准。

- **积分档位**：部分套餐可能提供不同积分档位。当前可选档位与对应权益以订阅页的套餐卡片为准，积分机制见[AI 积分说明](./credits.md)。

- **开通前置**：使用 Google 或 GitHub 登录后即可选择当前可用套餐；国际站不要求完成中国实名认证。

## 常见问题

### 各档套餐的价格是多少

国际站目前采用限量、限时免费的内测开放方式，可用套餐与后续价格会随产品阶段调整。请查看[订阅页](/subscribe)获取当前信息。

### 套餐之间可以升级或更换吗

当前平台暂不支持在已开通套餐上直接升级或更换套餐，请以管理台与订阅页提供的实际选项为准。

### 一个套餐可以开几个 Agent

启航与巡游各含 1 个 Agent 配额；远航含 3 个，但目前仍为敬请期待。Agent 配额指可同时运行的 Hermes 实例数量。

### 积分用完了会怎样

积分用于模型调用计量。用完后，依赖模型调用的功能会受限；后续可用方式以平台当前规则为准。详见[AI 积分说明](./credits.md)。
