## 套餐是什么

### 账号与套餐费用入口

先登录 LightVela。在 Agent 管理台，将鼠标移到左侧导航底部的头像与账号名上，展开菜单：

- **账号（Account）**：打开[账号页](/account/)，查看个人资料、修改显示名、复制用户 ID 或退出登录。
- **套餐与费用（Plans & billing）**：打开[套餐与费用页](/account/billing/)，查看订阅套餐、有效期、积分用量与支付方式；续费也从这里发起。

进入「套餐与费用」后，在「订阅套餐」卡片查看当前状态，有可续费套餐时点击「立即续费」并按页面指引操作。尚未订阅时，可通过「立即创建」前往订阅页选购。在「支付方式」区域可添加支付卡，卡片信息在支付服务商的页面填写，LightVela 不存储完整卡号。

通过页面标题确认进入了正确页面。若已购买但没有显示套餐，请确认登录账号与购买时一致，再刷新页面；若支付卡尚未更新，先确认已完成支付服务商页面的操作，再返回刷新，不要重复提交。

### 套餐与资源

套餐（Plan）是你在 LightVela 上开通 Hermes Agent 的资源包。开通任意当前可用的套餐后，平台会为你分配一个**专属云端运行环境**（独立的 CPU、内存和存储），你的 Hermes Agent 可以在其中 7×24 小时在线运行，无需自己购买服务器或进行本地部署。

不同档位的区别主要在**独立环境规格、专属存储容量、每月 AI 积分**，而 Agent 的核心能力——自主进化、多通道接入、技能、定时任务和长期记忆等——在各档套餐中保持一致。

各档实时价格、库存、折扣与可购买状态以[订阅页](/subscribe)展示为准。下方数值用于说明当前套餐的资源、标准原价与 AI 积分结构。

### 所有套餐共享的 Agent 能力

无论选择哪一档，Hermes Agent 都具备以下基础能力：

- **Agent 自主进化**：Agent 在使用中持续学习，逐步理解你的偏好与工作方式。

- **7×24 小时在线**：云端托管运行，不依赖本地设备开机。

- **极简配置面板**：在网页中配置[模型](./configuration/model.md)、通道、技能和定时任务。

- **连接主流聊天通道**：在微信 / QQ / 飞书等入口直接和 Agent 对话。

- **接入主流模型 API**：可使用套餐 AI 积分，也可按需配置自有模型 API Key。

- **精选技能 / 技能包**：为 Agent 安装可复用能力，扩展任务边界。

- **人设注入、定时任务、长期记忆与诊断中心**：覆盖日常使用、定时执行、上下文沉淀和运行排查。

关于 AI 积分如何发放与消耗，见[AI 积分说明](./credits.md)。

### 套餐变更说明

当前平台暂不支持在已开通套餐上直接升级、更换或降级套餐。已有套餐生效时，订阅页会优先标记当前套餐；如需继续使用当前套餐，请通过续费延长有效期。如需更换套餐，请以套餐与费用页和订阅页当前提供的实际操作入口为准。

### 套餐生命周期说明

套餐到期后，套餐权益将在 1 天后暂停，数据自到期日起保留 14 天；保留期满后，数据将被释放且无法恢复。

## 退款指引

LightVela 国际站订单支持通过邮件申请退款，退款规则与 LightVela 套餐订单退款规则共享。具体规则和申请步骤如下。

### 退款规则

- 同一账号下的套餐订单仅可享受 **1 次**退款权益。

- **月付套餐**：自订单实际支付后 **24 小时内**，且未使用任何套餐内 AI 积分，可申请退款。

- **季付套餐**：自订单实际支付后 **72 小时内**，且未使用任何套餐内 AI 积分，可申请退款。

退款申请是否通过以 LightVela 支持团队审核结果为准。

### 申请步骤

1. 根据退款规则，确认自己已满足相关条件。

2. 发送邮件至 [lightvela@tencent.com](mailto:lightvela@tencent.com)。邮件中请写清楚：账号信息（如登录邮箱 / 登录方式、LightVela 用户 ID、套餐名称和订单时间）、退款原由，以及当前账号的使用情况（如是否已创建或运行 Agent、是否已使用 AI 积分、是否已接入通道 / 技能 / 定时任务等）。

3. LightVela 支持团队会在 **3 个工作日**内处理你提交的申请。

4. 退款申请审核通过后，系统将执行退款操作，退款将在 **5-10 个工作日**内原路退回。若审核不通过，通常是因为不满足退款规则。

## 常见问题

### 各档套餐的价格是多少

各档实时价格、库存、折扣、税费和可购买状态以[订阅页](/subscribe)及支付页展示为准。本文档中的套餐定价表仅列当前月付标准原价。

### 套餐之间可以升级或更换吗

当前平台暂不支持在已开通套餐上直接升级或更换套餐，请以管理台与订阅页提供的实际选项为准。

### 一个套餐可以开几个 Agent

当前已上线的启航 Launch、巡游 Cruise、启航 Launch AI、巡游 Cruise AI 均含 1 个 Agent 配额。Agent 配额指可同时运行的 Hermes 实例数量。

### 积分用完了会怎样

积分用于模型调用计量。用完后，依赖模型调用的功能会受限；后续可用方式以平台当前规则为准。详见[体验积分说明](./credits.md)。
