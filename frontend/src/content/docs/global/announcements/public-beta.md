我们推出 LightVela，是希望让每个人都能更轻松地拥有一个长期在线的个人 AI Agent。你不需要处理服务器部署、运行环境和日常运维，也不需要一直守在本地设备前，就可以创建一个 7x24 小时在线、能够持续记忆和执行任务的 AI 伙伴。

## 产品能力持续建设中

- 人设与个人 Agent 配置：支持配置 Agent 的名称、人设、模型与使用偏好。
- 定时任务：支持按周期、间隔或指定时间执行提醒、总结、通知等任务。
- 记忆与上下文沉淀：支持查看和管理 Agent 已沉淀的记忆与上下文。
- 云存储与文件管理：支持查看和管理 Agent 使用过程中的云端文件。
- 网页内对话与多通道沟通：支持网页内对话，并逐步接入 Telegram、WhatsApp、Discord、Slack、WeChat、QQ、WeCom、Lark 等通道。
- 技能、工具与插件扩展：已接入 SkillHub，支持网页浏览、信息查询、日报整理、图像生成等扩展能力。
- 诊断与恢复：支持对通道、模型或 Agent 运行异常进行诊断与恢复。
