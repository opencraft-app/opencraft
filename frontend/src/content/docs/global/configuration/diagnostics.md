# 诊断中心

诊断中心用于排查 Hermes Agent 的异常情况。你可以在同一处查看和导出近期日志、重置模型配置，或在保留数据的前提下重装 Agent。

## 本页覆盖

- 查看和导出近期日志
- 重置异常的模型配置
- 保留数据重装 Agent
- 判断何时应使用恢复操作，何时应寻求进一步帮助

> **建议按影响最小的方式处理：** 先看日志，再执行必要的修复操作。重置配置和重装 Agent 更适合持续存在的问题。

## 开始前

1. 打开出现问题的 Agent。
2. 记录异常表现、发生时间，以及它影响的是聊天、已连接的渠道，还是某一项具体任务。
3. 如果是模型无法使用，重置前先检查[配置模型](./model.md)中的当前设置。

## 打开诊断中心

1. 打开 **Agents**，选择出现问题的 Agent。
2. 打开 **Diagnostics** 区域。
3. 选择近期日志的时间范围：1、3、6、12 或 24 小时。
4. 选择 **Refresh** 加载日志。

![LightVela 管理台中的诊断中心](../images/diagnostics-overview.png)

优先选择刚好覆盖异常发生时间的最短范围。时间窗口更小，通常更容易将错误和触发它的操作对应起来。

## 查看和导出日志

通过日志确认 Agent 当时是否正常运行，并定位异常发生的时间。需要保留记录或向支持人员说明问题时，可以将当前时间范围内的日志导出为文件。

反馈问题时，建议提供：

- 大致发生时间；
- 当时让 Agent 执行的操作；
- 选用的日志时间范围；
- 相关报错信息，但不要包含密钥或 API Key 等敏感内容。

## 修复模型配置

如果 Agent 无法使用已配置的模型，并且确认过提供商、模型选择和凭证后问题仍未解决，可在诊断中心选择 **Reset model configuration**。

该操作会初始化 Hermes Agent 的模型配置，以便重新设置。完成后：

1. 返回[配置模型](./model.md)。
2. 添加或选择要使用的模型。
3. 在[聊天](./agent-chat.md)中发送一条简短消息进行测试。

> **注意：** 只有在准备好重新配置可用模型时才重置模型配置。提供商临时故障或网络波动，不应作为第一次处理就直接重置。

## 保留数据重装 Agent

对于查看日志和检查模型设置后仍持续的问题，诊断中心提供 **Reinstall Agent (keep data)**。它会执行 Hermes Agent 的后台重装流程，并保留数据。

1. 阅读诊断中心显示的操作说明。
2. 启动重装后，保持页面打开并留意状态变化。
3. 完成后重新加载 Agent 控制台。
4. 在聊天中测试一项简单任务，再检查云存储和日常设置。

![重装 Agent 确认弹窗](../images/diagnostics-reinstall.webp)

维护期间，Agent 可能暂时不可用。重装尚未完成时，请不要连续发起另一项修复操作。

## 备份与恢复：以控制台显示为准

部分账户会在诊断中心看到 **Backup & Recovery** 面板。只有当你的控制台显示该面板时，才按照其中的提示创建备份或恢复兼容的 Hermes 备份包；不要假设每个 Agent 或账户都具备此选项。

恢复前，请保留无法替代的文件副本。你可以先通过[云存储](./files.md)检查 Agent 当前保存的文件。

## 确认问题已解决

出现以下情况时，通常说明问题已恢复：

- 近期日志不再重复出现同一错误；
- Agent 能在聊天中正常回复简单测试；
- 预期的模型与文件可以再次正常使用。

若同一错误再次出现，请先导出相关日志，并记录下一次出现的时间，再继续排查或反馈。

## 常见问题

### 应该选择多长的日志时间范围？

选择刚好包含问题的最短时间范围。只有在问题更早开始或偶发出现时，才使用更长范围。

### 重装会清除 Agent 数据吗？

诊断中心的操作标注为 **Reinstall Agent (keep data)**，设计目标是保留数据。仍建议不要中断维护过程，并在完成后检查 Agent 状态。

### 每次模型报错都需要重置模型配置吗？

不需要。请先在[配置模型](./model.md)检查所选模型和凭证，并确认提供商可用。仅在模型配置本身需要重新建立时，才使用重置。

## 下一步

- 回到[聊天](./agent-chat.md)，测试修复后的 Agent。
- 遇到模型问题时，查看[配置模型](./model.md)或[模型切换](./multiple-models.md)。
- 任务依赖的文件缺失或无法访问时，检查[云存储](./files.md)。
