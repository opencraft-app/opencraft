# 高级设置

## 摘要

**高级设置用于调整 Hermes Agent 的记忆和上下文管理方式。**
你可以控制长期记忆、用户画像和长对话自动压缩，并设置压缩何时开始、保留多少近期内容以及始终保留多少条最近消息。
每次成功保存后，系统会重启 Gateway 并重新读取配置，以确认新设置已经生效。

![LightVela 管理台中的高级设置](../images/setting-1-cn.png)

## 本页覆盖

- 管理长期记忆和用户画像。
- 管理长对话的自动压缩。
- 设置压缩触发阈值、压缩保留比例和最近消息保留数量。
- 恢复记忆或上下文管理分组的默认值。

## 开始前

1. 确认目标 Agent 正在运行。
2. 打开 **Agents**，然后选择要配置的 Agent。
3. 进入 **高级设置**。

如果 Agent 未运行，页面会显示当前值，但不能修改设置。

## 可调整的项目

| 分组 | 设置 | 作用 |
| --- | --- | --- |
| 记忆 | 长期记忆 | 让 Agent 在后续会话中读取和更新长期记忆。 |
| 记忆 | 用户画像 | 让 Agent 记录和使用你的偏好、沟通方式与使用习惯。 |
| 上下文管理 | 自动压缩 | 在长对话接近上下文限制时，自动总结较早内容。 |
| 上下文管理 | 压缩触发阈值 | 设置上下文占用达到哪个比例时开始压缩，可填写 0 到 1。 |
| 上下文管理 | 压缩保留比例 | 设置压缩后保留多少近期对话原文，可填写 0.1 到 0.8。 |
| 上下文管理 | 保留最近消息 | 设置无论如何压缩都完整保留的最近消息数量，最少为 1 条。 |

## 修改设置

### 开关类设置

1. 选择长期记忆、用户画像或自动压缩旁边的开关。
2. 阅读确认提示，确认开启或关闭该设置。
3. 等待保存完成。

关闭长期记忆或用户画像不会删除已经保存的内容。
关闭自动压缩不会删除已有的压缩参数，但会停止自动总结较早的对话内容。

### 数值类设置

1. 选择要调整的数值右侧的编辑按钮。
2. 输入符合范围的数值。
3. 选择保存按钮，或按 Enter 保存。
4. 如需放弃修改，选择取消按钮或按 Escape。

只有在自动压缩开启时，才可以修改压缩触发阈值、压缩保留比例和保留最近消息。

## 恢复默认

高级设置按 **记忆** 和 **上下文管理** 两个分组提供 **恢复默认**。

1. 在需要重置的分组中选择 **恢复默认**。
2. 阅读确认提示。
3. 选择确认恢复。

恢复默认只会清除当前分组的自定义设置，并恢复为 Hermes Agent 的默认值。
它不会影响另一个分组，也不会删除 Agent 的已有记忆内容。

## 确认已生效

保存或恢复默认成功后，页面会显示最新读取到的值。
如果使用自动压缩，可以继续进行较长对话，确认 Agent 会按新的上下文管理规则工作。
如果调整了记忆设置，可以在后续对话中观察 Agent 是否按预期使用记忆和偏好。

## 常见问题

### 为什么无法修改设置？

先确认 Agent 正在运行。
保存、恢复默认或读取配置进行中时，控件也会暂时不可用。

### 为什么某个设置显示为当前 Agent 版本不支持？

该 Agent 当前运行的版本不支持此项配置。
请使用可用的设置，或在 Agent 更新后重新查看此页面。

### 为什么输入的数值无法保存？

压缩触发阈值只能填写 0 到 1。
压缩保留比例只能填写 0.1 到 0.8。
保留最近消息必须是大于或等于 1 的整数。

### 为什么关闭自动压缩后，其他压缩设置不可编辑？

这三个数值只在自动压缩开启时生效。
重新开启自动压缩后，可以继续调整它们。

### 保存后出现重启或验证失败提示怎么办？

配置可能已经写入，但 Gateway 重启或重新读取配置没有完成。
刷新页面后检查显示的值，再决定是否重试。
