# 记忆管理

## 摘要

**记忆（Memory）让 Hermes 记住跨对话、跨设备的关键信息——你的偏好、身份、正在推进的事项，以及在长期协作中沉淀的经验。它是 Hermes 从「一次性问答」变成「越用越懂你的长期助理」的基础。记忆存放在 Agent 之内、模型之外，因此切换模型不会让它遗忘。你可以在管理台的记忆与用户画像页面查看、编辑或清理已沉淀的内容，多个聊天通道共享同一份记忆。**

LightVela 采用云端托管：这些记忆保存在你的 Hermes 云端实例中，不会因为你更换手机或切换通道（Telegram、WhatsApp、Discord、Slack、WeChat）而丢失。今天在 Telegram 告诉它的事，明天在 WhatsApp 对话时它依然记得。

## 为什么需要记忆

没有记忆的 AI 助手，每次对话都像从一张白纸开始——你得反复说明自己是谁、喜欢什么、上次聊到哪里。记忆解决的正是这个问题：

- **少重复交代**：说过一次“我在新加坡、习惯早上收简报”，之后就不用再说。

- **跨通道一致**：Telegram、WhatsApp、Discord、Slack 和 WeChat 共享同一份记忆，换个入口，它还是同一个懂你的助理。

- **越用越顺手**：随着协作深入，Hermes 会记住你的工作习惯、常用称呼和正在跟进的项目，回答会越来越贴合你。

可以把记忆理解为 Hermes 的“长期笔记本”：它不保存每一句闲聊，只沉淀那些对以后有用的关键信息。

## 两类记忆

在管理台的“记忆”页，内容分为两个标签页，分别对应两种不同用途：

### 记忆

这是 Hermes 在长期协作中自行沉淀的**经验与事实**——你交代过的偏好、约定的做事方式、反复出现的需求等。Hermes 会在对话中自动维护这些内容，条目也会随着使用不断更新。

### 用户画像

这是关于**“你是谁”**的一份稳定档案——例如你的身份、所在城市、职业背景和长期偏好等不常变化的信息。相比“记忆”，用户画像更像一张长期有效的名片，帮助 Hermes 在任何对话中快速对齐你的基本情况。

> ℹ️ **两者的区别**
>
> 简单来说：**用户画像**回答“你是一个怎样的人”，**记忆**回答“我们之间发生过什么、约定过什么”。两者配合，Hermes 才能既了解你，又记得你们的协作历史。

## 查看记忆与占用情况

1. 登录 LightVela，点击右上角“我的 Hermes”进入管理台。

2. 在设置导航中找到“记忆”，进入记忆页。

3. 页面顶部会显示**记忆统计**：当前已占用的字符数、容量上限，以及占用百分比。

4. 切换“记忆”与“用户画像”两个标签页，即可分别查看各自的内容。

如果某一类记忆当前为空，页面会提示“暂无 Agent 记忆”或“暂无用户画像”。这通常意味着你与 Hermes 的协作还比较少；随着使用，它会逐渐积累内容。

> 💡 **占用百分比的意义**
>
> 记忆容量有上限。当占用接近上限时，Hermes 会倾向于保留更重要的信息，并淘汰过时的条目。留意这个百分比，可以帮助你判断是否需要调高容量，或清理不再需要的内容。

## 调整记忆容量上限

如果你希望 Hermes 记住更多内容，可以在记忆页调高容量上限；也可以按需要调低。

- **记忆**容量可在 500 到 4000 字符之间调整。

- **用户画像**容量可在 500 到 3000 字符之间调整。

调整并保存后即可生效。

> ⚠️ **保存上限会触发短暂重启，可能中断当前会话**
>
> 保存新的容量上限时，Hermes 网关会短暂重启以应用新配置。正在进行的对话可能会暂时中断，稍候即可恢复。建议在不影响使用的时段调整。

## 通过对话增删记忆

除了在管理台查看，你还可以直接在对话中让 Hermes 记住或忘掉某些信息。这也是日常使用中最自然的方式。

**让它记住：**

```
记一下，我以后发简报统一用早上 8 点
```

```
记住我更喜欢简洁、直接的回答，不要太长
```

**让它忘掉：**

```
之前让你记的那个每天发简报的事，不用了，忘掉吧
```

Hermes 会理解你的意图，更新对应的记忆条目并告知结果。

> ℹ️ **当前以对话方式维护记忆内容**
>
> LightVela 采用云端托管模式，不提供面向用户的文件系统操作。记忆内容的增加与删除主要通过与 Hermes 对话完成；管理台则用于查看内容和调整容量上限。

## 常见问题

### 我没主动让它记，它却记住了

这是正常现象。Hermes 会在对话中自动判断哪些信息值得长期保留，例如你的偏好、身份和约定。如果你不希望它记住某条信息，直接在对话中让它忘掉即可。

### 换了手机或通道，记忆还在吗

在。记忆保存在云端实例中，与设备和通道无关。Telegram、WhatsApp、Discord、Slack 和 WeChat 共享同一份记忆。

### 记忆占用满了会怎样

当占用接近上限时，Hermes 会优先保留更重要的信息，逐步淘汰过时或次要的条目。如果你确实需要它记住更多内容，可在记忆页调高容量上限。

### 记忆页显示“暂无记忆”

这表示当前这一类记忆还没有积累内容。多与 Hermes 协作一段时间，或直接让它记住一些关键信息，内容就会出现。

### 调整容量上限后对话卡住了

保存上限会触发一次短暂重启，正在进行的会话可能瞬时中断。稍等片刻再发送消息即可恢复。
