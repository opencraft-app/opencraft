# 人设

## 摘要

**Soul 决定一个 Hermes Agent 稳定的角色、语气、优先级和行为边界。**

**你可以在 Agent 的「人设」设置中选择推荐 Soul，或上传自己的 Markdown 人设文件，再将内容注入到该 Agent 的 `SOUL.md`。**

**同一个 Agent 同一时间只会有一个生效中的 Soul，修改后需要开启新会话，让新的规则被加载。**

## Soul 可以控制什么

Soul 是 LightVela 写入 Agent `SOUL.md` 的人设配置。
它定义 Agent 是谁、通常如何表达、优先处理什么，以及应当遵守哪些行为边界。

适合写入 Soul 的是稳定规则，例如“先给结论”“不确定时明确说明”或“发送外部消息前先确认”。
不要把会变化的项目事实、一次性的临时需求，或任意云端文件编辑需求放进 Soul。

人设属于 Agent，而不是某一个消息通道。
同一个 Agent 同时连接 Telegram 和 WhatsApp 时，两个通道中的新会话都会使用同一个当前 Soul。

## 开始前准备

1. 打开你想配置人设的 Hermes Agent。
2. 确认该 Agent 已配置模型，并至少有一个可用于验证结果的对话通道。
3. 先想清楚 Agent 的角色、服务对象、语气、优先级，以及哪些动作必须先确认。

一份简短的说明通常已经足够。
例如：“一名简洁的研究助理，先给结论再给依据，明确不确定性，发送任何外部内容前先询问。”

## 配置 Soul

### 打开人设

1. 在 LightVela 控制台中打开 **Agents**。
2. 选择想要配置的 Hermes Agent。
3. 打开该 Agent 设置中的 **人设**。

该设置只会影响当前选中的 Agent。
如果其他 Agent 需要不同的角色或语气，请先切换到对应 Agent 再进行配置。

### 选择 Soul

使用 **随机抽取人设** 浏览可用的人设风格。
如果想根据你的沟通和行为偏好获得建议，可以使用 **答题测试人设**。

![随机抽取人设弹窗](../images/soul-2.png)

在选择前，先查看每张 Soul 卡片中的角色、语气、行为说明和边界。
优先选择符合准备说明的人设，而不是只按名称或语气挑选。

### 注入 Soul

1. 选择要使用的 Soul。
2. 选择 **注入**。
3. 在人设区域确认注入结果。
4. 回到已连接的对话通道并发送 `/new`。

注入成功后，LightVela 会把选中的 Soul 写入当前 Agent 的 `SOUL.md`，并在替换已有内容前保留备份。
已经开始的会话可能仍保留旧的人设快照，所以 `/new` 会开启一个读取新 Soul 的会话。

### 上传自己的 Soul

如果你已经准备好 Markdown 人设文件，而不是想从推荐卡片中选择，可以使用上传功能。

1. 在 LightVela 控制台中选择目标 Hermes Agent。
2. 在 **人设** 中选择 **上传人设文件**。
3. 选择包含 Soul 内容的 Markdown 文件。
4. 查看或编辑文件内容，然后选择 **注入**。
5. 如果 Agent 已经有人设，确认要覆盖当前内容。
6. 回到已连接的对话通道并发送 `/new`。

![上传人设文件弹窗](../images/soul-3.png)

文件名不必是 `soul.md`，但必须使用 `.md` 扩展名、采用 UTF-8 编码，并且不超过 20 KB。
LightVela 会在注入前展示文件内容，方便你作最后检查或编辑。
覆盖已有 Soul 时，LightVela 会先备份旧文件，再把上传的内容写入当前 Agent 的 `SOUL.md`。

只有选中 Agent 后才能上传。
如果没有选中 Agent，或 Agent 沙箱无法写入而下载了推荐 Soul 的 `soul.md` 文件，该文件只是本地兜底副本。
下载文件本身不会更新任何 Agent。

## 将不同类型的上下文放在正确的位置

| 保存位置 | 适合保存什么 | 示例 |
| --- | --- | --- |
| 人设和 `SOUL.md` | 稳定的角色、语气、优先级和行为边界 | “明确说明不确定性，发送外部消息前先确认。” |
| 用户画像 | 用户的身份、地点、语言和沟通偏好 | “默认使用中文，优先展示截止日期。” |
| 记忆 | 会变化的事实、决策和长期项目背景 | “当前项目将在周五发布。” |
| 技能 | 可复用的能力和操作流程 | 网页研究、文件整理或日报工作流 |

使用[记忆管理](./memory.md)查看记忆和用户画像容量。
当 Agent 需要新能力而不是新行为规则时，请使用[配置技能](./skill.md)。
想进一步理解这些边界，可以查看[Hermes Agent 的性格从哪里来](../hermes-agent/10-persona-user-memory.md)。

## 验证 Soul 是否生效

发送 `/new` 后，用能体现配置行为的问题测试 Agent。

```text
你当前的角色、主要任务和默认语气是什么？
```

```text
当你不确定一个事实时，你会怎样回复？
```

```text
如果我让你向外部服务发送一条消息，你会先做什么？
```

当 Agent 在新会话中持续遵守设定的角色、语气和边界时，新的 Soul 已经生效。
如果需要按消息通道查看完整示例，可以参考[如何通过 SOUL.md 设定 IM Agent 的角色、性格与说话方式？](../use-cases/im-agent-persona-soul-md.md)。

## 常见问题排查

| 问题 | 可能原因 | 处理方式 |
| --- | --- | --- |
| 回复仍使用旧语气 | 该会话在 Soul 修改前已经开始 | 发送 `/new`，然后在新会话中再次测试。 |
| 选择的 Soul 不符合 Agent 的真实工作 | 只按风格选择，没有看角色和边界 | 回到人设区域，查看卡片详情并注入更符合说明的 Soul。 |
| Agent 忘记了某个项目事实 | 将变化的事实写入人设，而不是记忆 | 将稳定规则保留在 `SOUL.md`，通过对话让 Hermes 记住变化的事实。 |
| Agent 无法完成需要的任务 | 人设定义行为，不会新增能力 | 先检查来源和权限，再安装或配置合适的技能。 |
| 控制台下载了 `soul.md`，没有完成注入 | 没有选中 Agent，或 Agent 沙箱无法写入 | 选择正在运行的目标 Agent 后重试。下载的文件不会改变 Agent。只有控制台确认注入成功后再发送 `/new`。 |
| 无法上传自己的 Soul | 没有选中 Agent，或文件不是符合要求的 UTF-8 Markdown 文件 | 选择目标 Agent，然后上传不超过 20 KB 的 `.md` 文件。 |

## 常见问题

### 一个 Agent 可以同时有多个生效中的 Soul 吗？

不可以。
一个 Agent 同一时间只能有一个当前 Soul。
如果确实需要完全不同的角色，建议创建不同 Agent，而不是反复替换同一个 Agent 的人设。

### 我可以手动编辑云端的 `SOUL.md` 吗？

正常使用不需要直接操作云端文件系统。
人设设置可以生成、上传和注入 Soul，但它不是任意云端文件的通用编辑器。

### 我可以上传已有的 `SOUL.md` 吗？

可以。
使用 **上传人设文件** 选择不超过 20 KB 的 UTF-8 Markdown 文件，查看或编辑后注入到已选中的 Agent。
如果 Agent 已经有人设，LightVela 会先请求确认并保留备份，再替换当前内容。

### 修改 Soul 会安装新能力吗？

不会。
Soul 会改变 Agent 的行为方式，技能才会增加具体能力和可复用操作流程。

### 新 Soul 会清除记忆或聊天记录吗？

不会。
注入 Soul 只会替换 Agent 当前的人设配置，不会删除长期记忆或已有聊天记录。
