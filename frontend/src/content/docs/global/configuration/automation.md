# 自动任务

自动任务（Tasks）可让 Hermes 按照预设时间或触发条件，自动执行指定工作，无需人工重复操作。适用于定时提醒、日报生成、新闻追踪、内容发布等场景。

所有任务均可灵活配置执行频率与运行规则，让你的 AI 助手持续主动工作。

## 添加自动任务

可在 Hermes 左方「自动任务」标签查看自动任务。随后点击右上角「+ 添加」，新建自动任务。

![](../images/automation-1-global.png)

打开后，可编辑你的自动任务。

![](../images/automation-2-global.png)

- **名称**：自动化任务方案命名

- **执行时间**：设置任务执行周期（固定星期、固定间隔、单次执行三选一）

- **任务说明**：填写任务提示词，供智能代理执行自动化方案，参考示例：
  - 每日 21:00 汇总未读邮件
  - 归档存放超 30 天的订阅邮件
  - 每周日提醒浇花

- **生效时间段**：限定任务有效运行时段（留空代表全天候持续运行）

- **通知方式**：可选开关，勾选接收任务执行通知的渠道

## 自定任务模版

若不清楚需要配置什么自动化任务，可点击「模版」选用现成的自动任务方案。

![](../images/automation-3-global.png)

---

## 自动任务管理

自动化任务创建完成后，可在「自动任务」页面查看已启用任务。

![](../images/automation-4-global.png)

在此页面可按需查看自动化任务详情、编辑修改、暂停运行或删除你的自动任务。

![](../images/automation-5-global.png)
