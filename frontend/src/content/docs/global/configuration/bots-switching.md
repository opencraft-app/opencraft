# Bot 切换

## 摘要

**Bot 切换允许一个 LightVela 云端 Agent 承载多个用途不同的 Bot。你可以为研究、规划、编程、内容创作、支持或定时工作流创建专用 Bot，然后通过桌面端左侧的 Bot 头像栏快速切换；窄屏先展开导航，再选择目标头像。**

**每个 Bot 都有自己的工作区上下文。创建空白 Bot 或复制已有 Bot 时，LightVela 对模型设置、记忆、技能、人设、定时任务和通道连接采用不同的继承规则。**

## 开始前

- 登录 LightVela，并打开一个正在运行的云端 Agent。
- 如果要创建额外的 Bot，请确认当前套餐允许继续创建，并且没有其他 Bot 正在创建或删除。
- 如果计划接入通道，请准备该通道所需的凭证或授权方式。

## 创建 Bot

首次使用时，先完成「创建你的 LightVela Bot」引导：依次选颜色、形状和配饰，填写名字与可选描述，点击**创建**，等待配置完成，再点击**开始旅程**。首次创建没有「高级」和关闭按钮。

已有 Bot 后，在 Bot 头像栏点击**新建 Bot**。默认是空白创建；要复制已有设置，展开**高级 → 创建方式**，选择「复制 + Bot 名称」。也可以先选中来源 Bot，再打开**管理 Bot → 复制 Bot**，表单会预选该来源。第二次及之后的创建均使用这条路径。

例如，要创建一个金融分析师 Bot，可以填写：

> <strong>名称：</strong> Alpha Analyst
>
> <strong>描述：</strong> Alpha Analyst 专注于分析公司报告、市场新闻、投资组合表现、估值和金融风险。它提供简洁且有证据支持的分析，明确区分事实与假设，不会将分析表述为保证性的金融建议。

![已有 Bot 时的再次创建表单](../../images/bots-switching-create.webp)

图示为已有 Bot 后的再次创建表单，带有「高级」和关闭按钮；不代表首次创建引导。

「推荐模板」是可选项，实际名称以页面为准。选择模板会填入该角色的资料和外观；不选模板仍可继续创建。

![国际站创建页面中的推荐模板，包含 Health Steward、Market Analyst 和 Industry Researcher](../../images/bots-switching-templates.webp)

点击**创建**后，按原有配置流程等待完成，再点击**开始旅程**进入新 Bot 的对话。失败时按页面提示重试或恢复，不要反复提交创建。

## Bot 工作区与设置

创建完成后，Bot 会拥有自己的设置工作区。你可以在桌面端左侧 Bot 头像栏中选择该 Bot；窄屏先展开导航。选中后，并管理该 Bot 可用的设置，包括记忆、技能、人设、定时任务和已连接通道。

![Bot 头像栏和通道、技能、定时任务导航](../../images/bots-switching-overview.webp)

创建方式决定新 Bot 继承哪些内容：

| 创建方式 | 会继承的内容 | 会独立开始的内容 |
| --- | --- | --- |
| 空白创建 | 主模型及其提供商凭证，以及系统预置技能 | 备用模型、其他已配置模型、人设、记忆、主 Bot 后续安装的技能、通道和定时任务 |
| 复制已有 Bot | 模型、人设、技能、用户偏好和长期记忆 | 当前对话、历史会话、定时任务、运行状态和通道连接 |

如果需要保持设置独立，请在确认创建前查看创建对话框中的继承说明。创建后，你可以分别管理每个 Bot 的[记忆](./memory.md)、[技能](./skill.md)和[定时任务](./automation.md)。

## 为什么要独立创建多个 Bot？

一个 Bot 可以处理很多任务，但随着职责增加，它的上下文会变得更难管理。研究员、旅行规划师、金融分析师或质量检查员等专用 Bot，可以分别维护更聚焦的记忆、技能、人设设置和定时任务。

独立的 Bot 也方便你测试另一种工作方式，而不会影响已经用于其他任务的 Bot。

![LightVela 左侧头像列，包含两个 Bot 与新建入口](../../images/bots-switching-selector.webp)

这样可以让 LightVela 工作区更有条理。要切换 Bot，请点击另一个 Bot 的头像；高亮项代表当前 Bot。修改名字与描述使用「管理 Bot → 修改资料」；点击当前头像可打开换装，保存更新外观，也可关闭退出。详见[管理 Bots](./bots.md)。

## 如何同时使用多个 Bot？

你可以将多个 Bot 连接到支持多 Bot 集成的即时通信通道。可用的通道组合取决于 LightVela 所在区域：

| LightVela 版本 | 支持多 Bot 集成的通道 |
| --- | --- |
| 中国版本 | 微信、QQ、企业微信、飞书、钉钉 |
| 国际版本 | Telegram、Discord、微信、Slack、QQ、企业微信、飞书 |

同一实例中的不同 Bot 可以分别连接不同微信账号；每个 Bot 独立管理自己的微信连接。WhatsApp 仍限制同一实例同时只由一个 Bot 连接；其他 Bot 会看到占用提示和管理入口。

## 检查 Bot 切换或通道连接结果

完成切换或连接后，请检查以下内容：

1. 当前 Bot 的名称和头像已经变为你选择的 Bot。
2. 设置页面显示的是所选 Bot 的工作区和配置。
3. 已连接的通道显示在实际拥有该连接的 Bot 下。
4. 发送一条简短测试消息，确认消息到达预期 Bot 并收到回复。

如果使用群聊通道，请按照已配置的权限发送测试消息，确认 Bot 能否读取群上下文，以及是否可以回复。

## 常见问题

| 问题 | 可能原因 | 处理方式 |
| --- | --- | --- |
| **新建 Bot** 不可用 | 当前套餐已达到 Bot 数量上限，或另一个 Bot 仍在创建或删除 | 等待当前操作完成，删除不再使用的 Bot，或升级到上限更高的套餐 |
| 无法选择复制选项 | 首次创建没有可复制来源，或来源列表尚未加载 | 首次创建直接填写资料；已有 Bot 时展开 **高级** 并检查来源列表 |
| Bot 列表暂时不可用 | Agent 实例已停止，或 Bot 列表请求失败 | 启动或刷新 Agent，然后重新加载 Bot 设置页面 |
| 通道已经连接到另一个 Bot | 该通道存在单 Bot 占用限制 | 使用提示中的入口打开占用该通道的 Bot，或根据通道配置页面断开后重新连接 |
| 群消息没有收到回复 | Bot 的群权限或通道配置不完整 | 查看对应的 [Telegram](./channel-telegram.md)、[Discord](./channel-discord.md) 或其他通道配置页面，然后再次测试 |

## 在群聊中与多个 Bot 对话

你可以将多个 Bot 邀请到支持的群聊中。根据设置的权限，Bot 可以读取群聊上下文、回复用户问题，或同时执行这两类操作。

不同平台的群聊行为和设置步骤可能不同。邀请 Bot 前，请先完成对应的通道配置，并按照平台要求通过直接提及 Bot 或其他触发方式进行测试。
