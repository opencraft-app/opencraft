# 管理 Bots

## 摘要

**Bot 是同一个 Hermes Agent 内相互独立的 Profile。主 Bot 会随 Agent 一起创建，其他 Bot 可以分别配置模型、人设、记忆、Skills、通道和定时任务。新建 Bot 时，可以复制已有 Bot，也可以选择「空白创建」（英文界面显示为 Basic setup）。套餐决定可创建的 Bot 总数，主 Bot 也计入数量。**

> **国际站开放状态**
>
> 国际站正在分阶段开放新建 Bot 能力。在此期间，**新建 Bot** 入口默认不显示；如果当前看不到入口，请继续使用主 Bot。

## 本页覆盖

- Hermes Agent 与 Bot 的关系。
- 通过复制或基础配置新建 Bot。
- 不同创建方式会继承和不会继承的内容。
- 切换、重命名和删除 Bot。

## 开始前准备

1. 确认 Hermes Agent 正在运行。
2. 确认当前套餐还有 Bot 名额；主 Bot 也计入套餐上限。
3. 打开 **Agents**，选择要管理的 Agent。

## 新建 Bot

当新建入口可用时：

1. 点击 **新建 Bot**。
2. 输入不超过 60 个字符的 Bot 名称。
3. 选择创建方式。
4. 核对继承说明，然后点击 **确认创建**。
5. 等待新 Bot 创建完成，再继续配置或使用。

可选的复制方式取决于当前选中的 Bot。在主 Bot 中会显示 **复制当前（主 Bot）**；在其他 Bot 中可以选择 **复制当前** 或 **复制主 Bot**。

## 选择创建方式

| 创建方式 | 继承 | 不继承 |
| --- | --- | --- |
| 复制当前、复制当前（主 Bot）或复制主 Bot | 来源 Bot 的模型、人设、Skills、用户偏好和长期记忆 | 当前对话、历史会话、定时任务、运行状态和通道连接 |
| 空白创建（Basic setup） | 主 Bot 当前主模型及其 Provider 凭据，以及系统预置 Skills | 备用模型、其他已配置模型、人设、记忆、主 Bot 后续安装的 Skills、通道和定时任务 |

**Basic setup 并非完全空白。** 它保留开始使用所需的最小模型配置和系统预置 Skills，同时让个性化行为、记忆与外部接入保持独立。

## 确认新 Bot

创建完成后：

1. 确认顶部出现了一个使用所填名称的新 Bot 页签。
2. 选择新 Bot，检查其模型和 Skills 是否符合所选创建方式。
3. 添加[人设](./personality.md)、安装[技能](./skill.md)、接入通道或创建[定时任务](./automation.md)前，先打开对应配置页继续设置。

## 使用多个 Bot

Agent 管理台顶部会显示 Bot 页签。修改模型、人设、记忆、Skills、通道、定时任务或查看诊断信息前，请先选择目标 Bot。

每个 Bot 都有独立的 Profile 和数据；修改一个 Bot 不会自动更新其他 Bot。管理台的 **对话** 功能目前仅支持主 Bot，Agent 级维护也应在主 Bot 中进行。

如需重命名，请先选择目标 Bot，再编辑其显示名称。名称最长为 60 个字符。

## 删除 Bot

- 删除其他 Bot 会永久删除该 Bot 的 Profile 和数据。
- 删除前需要先断开该 Bot 占用的通道。
- 删除主 Bot 前，必须先删除其他 Bot。
- 删除主 Bot 会删除整个 Agent，包括所有会话、配置、已安装 Skills、记忆和相关数据。

删除操作无法撤销。请仔细阅读确认信息，并按提示输入 Bot 名称后再确认。

## 常见问题

### 为什么无法新建 Bot？

国际站的新建入口可能仍处于隐藏状态；当前 Agent 版本也可能尚不支持多 Bot，Agent 可能未运行，或者套餐中的 Bot 数量已经达到上限。

### 为什么复制后的 Bot 没有会话、任务或通道？

这些内容不会随复制操作带入。请根据需要为新 Bot 重新接入通道并创建定时任务。

### 为什么选择 Basic setup 后仍然有模型和 Skills？

Basic setup 会继承主 Bot 当前的主模型和 Provider 凭据，并只保留系统预置 Skills；不会复制主 Bot 的其他模型、人设、记忆、后续安装的 Skills、通道或定时任务。
