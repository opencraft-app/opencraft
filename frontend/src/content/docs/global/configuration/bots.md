# 管理 Bots

## 摘要

**Bot 是同一个 Hermes Agent 内相互独立的 Profile。首次使用时，先在「创建你的 LightVela Bot」中选择外观、填写名字，再完成配置并点击「开始旅程」。已有 Bot 后，可从头像列的「新建 Bot」继续创建，或通过「管理 Bot → 复制 Bot」复制当前 Bot。每个 Bot 可以分别配置模型、人设、记忆、技能、通道和定时任务，主 Bot 也计入套餐数量上限。**

## 开始前准备

- 登录 LightVela，打开正在运行的 [Agent 管理台](/agents/)。
- 创建额外 Bot 前，确认套餐还有 Bot 名额，且没有创建或删除操作正在进行。
- 先选中需要管理的 Bot；外观、资料和配置操作作用于当前选中的 Bot。

## 首次创建 Bot

首次进入创建流程时，完成以下步骤：

1. 在左侧依次选择**颜色、形状、配饰**。也可以使用「随机样式」；外观之后仍可修改。
2. 填写**名字**；**描述**为可选项，可用来说明助手的用途。
3. 如有合适的「推荐模板」，可直接选择。模板会填入对应资料与外观；不选模板也能创建。
4. 点击**创建**，等待配置完成。
5. 看到完成状态后，点击**开始旅程**，进入当前 Bot 的网页对话。

首次创建没有可复制来源，因此不显示「高级」。首次引导是必做流程，没有关闭按钮；点击「创建」后会进入配置阶段。不要在配置尚未完成时重复创建；出错时按弹窗中的提示重试或恢复。

## 再次创建与复制

第二次、第三次及之后的创建都属于再次创建，具体数量受套餐限制。

### 空白创建

1. 在桌面端左侧 Bot 头像列点击 **新建 Bot**；窄屏先展开导航，再使用 Bot 头像栏中的同名入口。
2. 选择外观，填写名字与可选描述，或使用推荐模板。
3. 默认使用**空白创建**，无需展开「高级」。
4. 点击**创建**，等待配置完成，再点击**开始旅程**。

### 复制已有 Bot

可以从以下两个入口选择来源：

- **管理 Bot → 复制 Bot**：先选中要复制的 Bot，再打开管理菜单。创建表单会预选这个 Bot 作为来源。
- **新建 Bot → 高级 → 创建方式**：从下拉框选择「复制 + Bot 名称」。主 Bot 带有「主 Bot」标记，也可以切回「空白创建」。

核对来源、名字和描述后再点击**创建**。复制来源可能是主 Bot，也可能是其他已存在的 Bot。

## 创建方式的继承规则

| 创建方式 | 会带入的内容 | 不会带入的内容 |
| --- | --- | --- |
| 复制已有 Bot | 来源 Bot 的模型、人设、Skills、用户偏好和长期记忆 | 当前对话、历史会话、定时任务、运行状态和通道连接 |
| 空白创建 | 主 Bot 当前主模型及其 Provider 凭据；新 Profile 初始化系统预置 Skills | 备用模型、其他已配置模型、人设、记忆、主 Bot 后续安装的 Skills、通道和定时任务 |

空白创建保留开始使用所需的最小配置，但不会复制主 Bot 的个性化资料或后续安装的技能。复制完成后，如果重新选择了模板，新 Bot 会使用该模板的人设；不要将选择模板理解为完整保留来源人设。

## 切换、修改资料与换装

- **切换 Bot**：桌面端点击左侧另一个 Bot 的头像；窄屏先展开导航，再点击 Bot 头像栏中的头像。当前选中项会高亮。
- **修改名字与描述**：选中目标 Bot，打开 **管理 Bot → 修改资料**，编辑后保存。
- **修改外观**：点击当前 Bot 的头像打开换装，依次调整颜色、形状和配饰，保存后更新。点击关闭可退出尚未保存的换装。

修改外观不会创建新 Bot，也不会更换其模型、记忆或通道。切换后的网页对话和配置页属于所选 Bot；新建会话不会清空该 Bot 的长期记忆。

## 创建后的结果校验

1. 确认 Bot 头像栏中出现使用所填名字的新 Bot，并选中它。
2. 在网页[对话](./agent-chat.md)发送简短消息并确认收到回复。
3. 检查模型、[人设](./personality.md)、[记忆](./memory.md)和[技能](./skill.md)是否符合所选创建方式。
4. 需要外部聊天软件或周期任务时，再为这个 Bot 接入通道、创建[定时任务](./automation.md)。

每个 Bot 的配置和数据独立；修改一个 Bot 不会自动更新其他 Bot。

## 删除 Bot

- 删除其他 Bot 会永久删除该 Bot 的 Profile 和数据。
- 删除前需要先断开该 Bot 占用的通道。
- 删除主 Bot 前，必须先删除其他 Bot。
- 删除主 Bot 会删除整个 Agent，包括所有会话、配置、已安装 Skills、记忆和相关数据。

删除无法撤销，请阅读确认信息并按提示输入 Bot 名称后再确认。

## 常见问题

### 为什么无法新建 Bot？

检查套餐 Bot 名额、Agent 运行状态及是否有创建或删除操作未完成。入口是否开放也取决于当前站点的功能开关与 Agent 版本；以管理台提示为准。

### 为什么复制后的 Bot 没有会话、任务或通道？

这些内容不会随复制带入。请在新 Bot 下重新连接通道并创建任务。

### 为什么空白创建仍然有模型和 Skills？

空白创建会带入主 Bot 当前的主模型和对应 Provider 凭据，并为新 Profile 初始化系统预置 Skills；不会复制主 Bot 后续安装的 Skills 或其他个性化配置。

### 换装和复制 Bot 有什么不同？

换装只修改当前 Bot 的外观；复制会创建一个占用套餐名额的新 Bot。只想换外观时，点击当前头像即可。
