# 如何用 Agent 管理长期记忆和个人知识？

有用的知识通常有两种完全不同的形态。
有些信息描述了你是谁以及你的工作方式，应该保持稳定；另一些信息属于会不断变化的文档、笔记和项目材料。
如果把两者当成同一种东西管理，助手会变得不够有用。

LightVela 为 Hermes Agent 同时提供长期记忆和云存储。
记忆帮助它在不同对话之间保留持久上下文，云存储则为你提供管理工作材料和参考文件的位置。
两者结合使用，可以让个人 AI Agent 更容易被交代任务、重新查看和持续改进。

![LightVela Agent 的记忆和个人知识](../images/use-case-agent-memory.webp)

## 适合谁

这个使用方式适合希望助手了解自己的偏好和重复性工作，但不希望它把每一份文档都记入记忆的人。
它适用于持续进行的项目、个人研究、学习笔记、客户工作，以及任何会反复使用相同上下文的流程。

目标不是建立一个完美的档案库。
目标是让重要上下文容易找到，并让 Hermes 始终对齐那些应该长期保留的内容。

## 前置条件

- 一个已经运行中的 Hermes Agent，以及通过控制台或已连接通道与它对话的方式。

- 对信息可以存放在哪里有基本了解：[记忆管理](../configuration/memory.md)用于长期上下文，[云存储](../configuration/files.md)用于文件和文件夹。

- 一组你确实会重复使用的材料，而不是把拥有的每个文件都未经筛选地堆积起来。

- 明确的隐私边界，确定哪些内容希望 Hermes 保留或查看。

## 操作步骤 / 核心说明

### 1. 区分稳定上下文和参考材料

把应该影响未来对话的事实写入记忆，例如你偏好的写作风格、时区、当前角色、长期目标，或希望项目如何推进的规则。
把会变化的材料，例如简报、会议记录、草稿和研究文件，保存在云存储中。

例如，你可以告诉 Hermes：

```text
记住我希望研究笔记区分事实、假设和开放问题。
每当我们复盘项目时，都使用这个结构。
```

重点不是让 Hermes 把每一份源文件都存成记忆。
重点是让它拥有一种持久方式，理解你希望如何处理这些文件。

### 2. 整理你预计会反复查看的文件

在云存储中创建与实际工作对应的简洁文件夹结构。
使用有意义的名称，并把相关材料放在一起，例如按客户、项目、课程或研究问题分别建立文件夹。

当你希望 Hermes 处理文件时，告诉它你的目标，并指出相关材料。
例如：

```text
帮我准备这次项目复盘。
请使用最新简报和会议记录，然后列出尚未解决的决定和问题。
```

![包含项目文件的云存储文件夹](../images/use-case-memory-knowledge-storage.png)

### 3. 定期复查记忆，不要假设它永远正确

定期打开记忆管理，查看记忆和用户画像标签页。
用户画像是关于你的稳定信息，记忆则保存你与 Hermes 协作过程中形成的有用经验和工作上下文。

如果偏好发生变化，请在对话中明确说明：

```text
我不再需要很长的每周更新。
请忘记这个偏好，并把每周总结控制在五个项目符号以内。
```

记忆在保持最新时最有用。
如果某些上下文会让 Hermes 走向错误的方向，请删除或修正它，而不是添加第二条互相冲突的指令。

### 4. 把复查过的知识变成实际对话

使用[对话](../configuration/agent-chat.md)页面或已连接通道，把文档和记忆转化为具体的下一步行动。
你可以要求 Hermes 进行比较、制作大纲、列出开放问题，或为某次具体会议生成回顾。
眼前的结果越明确，就越容易验证 Hermes 是否使用了正确的上下文。

如果你的复查有固定节奏，可以使用一个[自动任务](../configuration/automation.md)提醒你重新查看文件夹，或准备定期回顾。
建议先从简单的提醒或总结开始，不要直接授予一个范围很大的开放式任务。

## 常见问题

### 记忆和云存储有什么区别？

记忆是帮助 Hermes 理解你和持续协作关系的长期上下文。
云存储用于管理文件和文件夹。
记忆应该记录重要规则和偏好，文件则应该保存底层材料。

### Hermes 会自动把每个文件当作长期记忆吗？

不会。
请有意识地区分两者。
使用记忆管理保存持久上下文，使用云存储整理希望在具体工作中参考的材料。

### 我可以让 Hermes 忘记某些内容吗？

可以。
告诉 Hermes 哪些内容不应继续保留，然后查看相关的记忆或用户画像信息，以便确认修改结果。

### 我应该先把什么内容放进记忆？

先记录那些能够影响几乎每次对话质量的偏好，例如你的时区、沟通风格、角色、当前重点，以及你希望重复性工作采用的格式。
