# 如何让 Hermes Agent 7×24 小时在线？

只有当问题出现时随时可用，而不只是你的电脑开着时，助手才最有帮助。
无论是用手机快速得到回复、在上班前收到定时简报，还是在忙完一天后查看待跟进事项，这种可用性都很重要。

Hermes Agent 是 LightVela 中的云端 AI Agent。
配置好模型和对话通道后，它可以独立于你的本地设备保持可用，无论你从哪里给它发消息，都能使用相同的记忆和行为方式。

![LightVela 控制台中在线的 Hermes Agent](../images/use-case-hermes-online.webp)

## 适合谁

如果你希望不用让电脑一直运行，就能通过手机、团队通道或控制台联系助手，这个使用方式很适合你。
它也适合每日简报、提醒或定期状态检查等自动化流程。

在线不等于无人管理。
你仍然应该选择可信的技能，复查重复执行的指令，并确认模型和通道能够持续按预期工作。

## 前置条件

- 一个在 LightVela 控制台中运行的 Hermes Agent。
  [快速开始](../02-quickstart.md)介绍了账号设置和首次创建流程。

- 已经配置好的模型或可用的体验积分。
  Hermes 需要模型才能生成回复。

- 至少一个已连接的通道，例如 Telegram、WhatsApp、Discord 或 WeChat，这样你才有实际联系它的方式。

- 如果你希望 Hermes 不只是等待消息，还能主动执行工作，则需要一个可选的重复任务。

## 操作步骤 / 核心说明

### 1. 让 Agent 能通过你实际使用的通道被联系到

选择一个通道作为联系 Hermes 的默认方式。
对于个人使用，通常应选择你每天已经会查看多次的应用。
先完成连接，发送一条简短的测试消息，并确认 Hermes 能够回复，再进行更多配置。

你可以查看 [Telegram](../configuration/channel-telegram.md)、[WhatsApp](../configuration/channel-whatsapp.md)、[Discord](../configuration/channel-discord.md) 和 [WeChat](../configuration/channel-wechat.md) 的详细说明。

![运行中的 Hermes Agent 与已连接通道](../images/use-case-hermes-online-channel.png)

### 2. 让工作配置保持简单且容易查看

重要组成部分包括当前启用的模型、已连接的通道、已安装的技能和记忆。
你不需要频繁修改它们，但当 Hermes 没有回复，或某项任务需要新的能力时，知道这些配置在哪里会很有帮助。

使用[配置模型](../configuration/model.md)确认当前启用的模型，并记录模型提供方或体验积分状态。
如果安装技能，只添加真实工作流程需要的技能，并在[配置技能](../configuration/skill.md)中复查它们。

### 3. 使用记忆保持助手的连续性

当助手不会每次都从头开始时，常驻在线的体验会更有用。
告诉 Hermes 你希望带入未来对话的偏好和工作上下文，并定期在[记忆管理](../configuration/memory.md)中复查。

例如，你可以告诉 Hermes：

```text
记住我喜欢用项目符号接收更新，紧急工作需要清楚标记。
```

这样，即使消息来自不同设备或受支持的其他通道，也能延续同一段工作关系，而不是从空白页面开始。

### 4. 当可用性需要转化为行动时，添加定时任务

在线的 Hermes 可以等待你的消息，但一个简单的自动任务可以让它在正确的时间主动开始一项已知流程。
先从一个成功条件清晰的任务开始：

```text
每个工作日上午 8:30，准备一份简短简报，包括今天的日程重点、未完成的跟进事项和第一个行动。
```

在[自动任务](../configuration/automation.md)中创建时间安排，如果合适，可以选择一个通知通道。
检查前几次执行结果，如果范围太大，应让指令更具体，而不是立即添加另一个自动任务。

## 常见问题

### Hermes 需要我的电脑一直开着吗？

不需要。
Hermes 运行在 LightVela 的云端环境中，Agent 和通道配置完成后，你可以关闭本地设备。

### 为什么 Hermes 显示在线但没有回复？

先确认通道连接状态，以及当前启用的模型或体验积分状态。
如果你刚刚修改过配置，请等待更新完成，然后再次发送一条简单的测试消息。
[诊断](../configuration/diagnostics.md)页面可以帮助你查看维护信息和最近的日志。

### 我可以连接多个通道吗？

可以。
受支持的通道可以连接到同一个 Hermes Agent，并共享相同的 Agent 行为和记忆。
请选择一个默认通道，只有在其他通道能解决实际访问需求时再添加它们。

### 让 Agent 7×24 小时自动执行任务安全吗？

请只使用范围清晰的指令和可信的技能。
建议先从只读或低风险流程开始，复查输出，并避免让自动任务获得你不希望它自动重复执行的操作权限。
