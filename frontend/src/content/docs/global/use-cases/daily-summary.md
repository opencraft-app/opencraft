# 如何用 Hermes Agent 做每日信息总结？

每日总结有价值的地方，不是内容很长，而是在你主动询问之前，先把正确的上下文交给你：发生了什么、什么需要关注，以及什么可以稍后处理。

Hermes 可以把重复性的复盘变成每日 AI 助手流程。
LightVela 提供云端 Agent、用于发送结果的通道、可选的信息获取技能，以及负责执行时间安排的自动任务。
什么才算是“今天有用的总结”，由你来决定。

![Hermes Agent 发送的每日信息总结](../images/use-case-daily-summaries.webp)

## 适合谁

这个使用场景适合经常浏览项目更新、笔记、文件或重复对话，并希望获得一个更精炼起点的人。
它可以用于个人晨报、每日项目回顾、学习记录，或者一份聚焦于后续行动的清单。

第一份总结最好有明确且有限的目的。
“总结所有内容”通常范围太大，而“突出这个项目的变化、已做决定、阻塞事项和下一步行动”则更容易判断和持续改进。

## 前置条件

- 一个已经运行中的 Hermes Agent，以及一个你希望接收总结的已连接通道。

- 已经配置好的模型或可用的体验积分。
  如果 Hermes 没有回复，请查看[配置模型](../configuration/model.md)。

- 明确的上下文来源。
  这可以是你粘贴到对话中的材料、你在云存储中管理的文件，或可信且相关的技能能够访问的信息。

- 如果你希望总结无需手动提示就能运行，还需要一个可选的自动任务时间安排。

## 操作步骤 / 核心说明

### 1. 明确总结要帮助你做出的一个决定

先说清楚这份总结服务于哪个时刻。
例如，决定先做什么、检查项目是否被阻塞，或在离开一天后快速了解进展。

给 Hermes 一条同时定义信息来源和输出结构的指令：

```text
当我分享项目更新时，请用四个部分总结：
发生了什么、做出了哪些决定、有哪些阻塞事项，以及接下来最重要的三个行动。
控制在 250 字以内，并标记任何紧急事项。
```

这样可以把一个笼统的请求变成可重复的格式，方便你每天比较结果。

### 2. 有意识地选择信息来源

Hermes 只能总结它收到的内容，或者通过你配置的能力访问到的信息。
手动流程中，可以把相关更新粘贴或转发到对话里。
如果是基于文件的工作，可以把材料整理在[云存储](../configuration/files.md)中，并告诉 Hermes 当前复盘需要参考哪个文档或文件夹。

如果需要外部数据源，请从可信来源选择合适的技能，并在使用前确认它的行为。
[配置技能](../configuration/skill.md)会介绍技能如何扩展 Hermes 的普通对话能力。

![每日总结使用的云存储来源](../images/use-case-daily-summary-storage.png)

### 3. 先在普通对话中测试结果

在设置自动任务之前，先手动让 Hermes 生成一份总结。
检查这些部分是否有用、语气是否足够简洁，以及重要细节是否有遗漏。

可以使用以下指令继续调整：

```text
把截止时间放在最前面。
```

```text
除非会影响下一步行动，否则不要重复已经完成的工作。
```

```text
最后加一个我需要在明天之前回答的问题。
```

[对话](../configuration/agent-chat.md)页面适合用来迭代指令，确认效果后再把它变成重复任务。

### 4. 按照已经验证过的版本创建自动任务

当手动指令已经能够稳定生成你认可的结果后，再创建自动任务。
给它设置明确的时间和具体指令，如果希望结果自动送达，还可以选择一个已连接的通知通道。

```text
每个工作日下午 6:00，根据我今天分享的更新生成每日项目总结。
包括变化、阻塞事项和最重要的三个下一步行动。
以简洁的项目符号发送给我。
```

在[自动任务](../configuration/automation.md)中完成设置。
检查前几次执行结果，如果总结范围太大、太长或缺少正确上下文，再调整指令内容。

## 常见问题

### Hermes 可以自动总结任何信息吗？

只能总结 Hermes 在对话中收到的信息、通过你配置的文件和技能访问到的信息，或通过你设置的工作流程获得的信息。
请明确管理信息来源，并为任何外部访问使用可信的技能。

### 为什么我的总结很笼统？

你的指令可能范围太大。
请明确受众、信息来源、时间范围和输出部分。
相比泛泛地要求总结，要求列出决定、阻塞事项和下一步行动，通常更容易得到可执行的结果。

### 我应该马上设置自动任务吗？

不建议。
先手动测试指令，等你能够判断什么是好的结果后，再设置自动任务，这样可以节省时间，也不会把一个不好用的格式固定下来。

### 如果总结没有发送过来怎么办？

检查自动任务状态和通知通道，然后确认 Hermes 在普通对话中仍然能够回复。
如果需要，可以先查看[诊断](../configuration/diagnostics.md)，再创建新的任务。
