# 如何用 AI Agent 能力增强 Discord 活动机器人？

## 摘要

**当 Discord 活动机器人能够解释已确认的活动信息、回答重复问题、支持新成员入门，并通过同一个 Hermes Agent 发送定时提醒时，它会更有用。** 在 LightVela 中，实际流程是连接 Discord，为 Agent 提供活动简报和安全边界，用真实参与者问题进行测试，然后为提醒或总结增加范围明确的定时任务。

这个模式适合定期比赛、Raid、学习小组、社群发布和其他需要在多个对话中反复传达相同信息的活动。

![为 Discord 活动社群提供支持的 AI Agent](../images/use-case-discord-event-agent.webp)

## 适合谁以及预期结果

这个使用方式适合经常回答日期、时区、报名、规则、地点和临时提醒等问题的活动组织者。

预期结果是一个活动助手，让参与者获得一致的答案，并帮助组织者重复传达正确的信息。
它应该减少重复协调工作，但不应该成为只能由人工组织者决定的事项的唯一事实来源。

## 前置条件

- 一个已经运行并完成模型配置的 LightVela Hermes Agent。

- 一个你可以添加和配置 Bot 的 Discord 服务器。

- 一份已经复查的活动简报，包括活动名称、日期、时区、报名步骤、规则、链接和联系频道。

- 一名负责更新日程并审核公告的管理员或组织者。

- [Discord 通道配置指南](../configuration/channel-discord.md) 和[定时任务指南](../configuration/automation.md)。

## 操作步骤

### 1. 把活动简报整理成 Agent 工作指南

先把 Agent 可以重复的事实，与必须经过组织者批准的操作分开。
前一类包括已经发布的开始时间、报名截止时间、参与规则和频道位置。
后一类包括日程变更、争议、退款、封禁、奖励决定和特殊例外。

可以从下面这段工作指南开始：

```text
你是这个 Discord 社群的活动助手。

使用已经确认的活动简报回答日期、时区、报名、规则和频道指引问题。
使用简短步骤回答，并在讨论日程时写出明确的时区。
绝不要编造时间、规则、报名状态或公告。
如果活动信息缺失或已经变化，请把成员引导给活动组织者。
将争议、管理问题、参与资格例外和奖励问题升级给人工处理。
```

保持活动简报最新。
AI Agent 可以让重复回答更容易，但无法让过时的日程变得正确。

### 2. 连接 Discord Bot，并选择范围明确的运行位置

在 LightVela 中连接 Discord 通道，并完成 Discord Developer Portal 的授权流程。
使用 [Discord 配置指南](../configuration/channel-discord.md) 完成以下设置：

1. 创建 Bot。

2. 开启 Message Content Intent。

3. 配置最小权限。

4. 使用最小权限邀请 Bot：View Channels、Send Messages 和 Read Message History。

![Discord Bot 邀请和服务器选择](../images/discord-event-bot-invite.webp)

第一次上线时，选择一个活动频道或一个受支持的 Discord 会话进行测试，再逐步扩大使用范围。
这样更容易检查回答、权限行为和通知投递情况。

![Discord Bot 权限配置](../images/discord-5-global.webp)

### 3. 测试参与者真正会问的问题

用一组常见的参与者问题测试 Agent：

```text
比赛按 UTC+8 是什么时候开始？

参加今晚的 Raid 之前需要做什么？

在哪里报名，报名什么时候截止？

日程变了，你可以发布新的时间吗？
```

如果活动简报包含所需信息，前三个问题应该得到简洁且有依据的回答。
最后一个问题不应该让 Agent 编造公告或悄悄修改日程。
它应该把成员引导给组织者，或指向已经确认的更新流程。

### 4. 让 Agent 支持参与者

当核心回答稳定后，可以让 Agent 处理以下重复性参与者支持：

- 按参与者要求的时区解释活动日程。

- 把新成员引导到报名、规则和支持频道。

- 总结参加活动前必须完成的步骤。

- 回答已经发布的参与资格规则问题。

- 把敏感问题转交给人工组织者。

示例提示可以是：

```text
@YourEventBot 参加今晚的 Raid 之前需要准备什么？

@YourEventBot 我是新成员，哪个频道有比赛规则？

@YourEventBot 可以用三个项目符号总结报名步骤吗？
```

使用目标 Discord 设置所支持的提及或会话方式。
不要假设每个服务器频道或多人会话模式都具有相同的行为。

### 5. 增加定时提醒和总结

当活动有可预测的节奏时，可以使用定时任务。
LightVela 支持单次执行、固定星期和固定间隔，也支持可选的生效时间段和通知渠道。
你可以选择固定星期、固定间隔或单次执行。
之后也可以暂停、编辑或删除定时任务。

![配置 Discord 活动定时任务](../images/automation-2-global.webp)

```text
在比赛前一天提醒活动频道，包含开始时间、时区、报名截止时间和规则频道。
只使用已经确认的活动简报。
如果简报缺少详情，请告诉组织者需要复查哪一项信息。
```

在这个示例中，Bot 正在运行“Game tournament reminder”定时任务。

![Discord Bot 发送比赛提醒](../images/discord-event-reminder.webp)

也可以为组织者安排活动后总结：

```text
活动结束后，总结已经发布的结果、没有回答的参与者问题，以及需要管理员复查的问题。
不要根据不完整的信息推断获胜者、处罚或规则决定。
```

先复查第一条定时输出，再增加一系列提醒。
关于时间安排、任务说明、生效时间段和通知设置，请查看[定时任务配置指南](../configuration/automation.md)。

## 实用检查表

| 活动阶段 | 操作 | LightVela 组件 | 预期结果或失败信号 |
| --- | --- | --- | --- |
| 活动前 | 加入已经复查的日程、时区、规则、链接和升级路径 | Agent 上下文 | 参与者可以得到一致的已确认答案 |
| 连接 | 邀请 Bot，并在目标会话中进行测试 | Discord 通道 | Bot 能够回复，并且只拥有所需权限 |
| 参与者支持 | 询问日程、报名和准备问题 | Hermes Agent | 回答简洁、具体，并且有活动简报依据 |
| 提醒 | 设置一条活动前消息 | 定时任务 | 消息在预期时间发送到所选频道 |
| 活动后 | 为组织者生成总结 | 定时任务或对话 | 总结区分已知结果、开放问题和人工跟进事项 |

## 验证方式与边界

使用四个测试验证活动流程：

1. 询问一个已知的日程详情，确认时区明确。

2. 询问一个报名步骤，确认 Agent 指向正确的频道或链接。

3. 询问一个故意缺失的规则，确认 Agent 会承认自己不知道。

4. 要求 Agent 修改日程或做管理决定，确认它会升级给人工，而不是自行决定。

当前 Discord 通道文档覆盖 Bot 授权、服务器与频道互动、消息内容读取以及通道层面的主动发送消息能力。
文档同时说明了当前关于群聊支持的限制。
如果你的方案依赖广泛的成员提及或特定的多人互动模式，请在承诺基于 @mention 的活动助手之前，先在目标服务器中确认实际行为。

Agent 不应该被信任去批准参与者、发出处罚、解决争议、发布未经复查的日程变更或处理密钥。
人工组织者仍然负责活动的正式事实来源。

## 常见问题

### Agent 可以回答不同的时区问题吗？

如果活动简报包含源时区，并且参与者提供目标时区，Agent 可以解释已经发布的活动时间。
建议让它同时写出原始时间和换算后的时间，方便参与者核对。

### 定时任务可以发送 Discord 活动提醒吗？

可以，Discord 通道文档将主动发送消息列为通道层面的支持能力。
创建定时任务，设置提醒文本、时间安排、生效时间段和通知频道，然后在依赖它处理关键截止时间前先测试第一条消息。

### Agent 可以自行更新活动日程吗？

不可以。
它应该重复已经确认的日程，并把变更建议转交给组织者。
更新活动简报后，先复查下一次回答，再发布变化后的时间。

### 这是自定义活动 Bot 的替代品吗？

不一定。
如果主要需求是自然语言问答、有依据的活动引导和定时沟通，LightVela 是合适的选择。
如果需要高度特定的命令、数据库报名、赛程管理或外部票务流程，自定义 Bot 可能更合适。

## 结论

为 Agent 提供经过复查的活动简报，连接 Discord，测试真实的参与者问题，然后增加一条用于提醒或总结的范围明确的定时任务。
这个流程可以为活动 Bot 增加有用的 AI Agent 能力，同时把活动权限、规则变更和敏感决策留给人工组织者。

如果你想先了解更宽泛的社群助手模式，可以查看[Meet LightVela for Discord：服务你所在频道的 AI Agent Discord Bot](./discord-community-agent.md)。
