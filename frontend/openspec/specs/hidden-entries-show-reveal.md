# Hidden entries show() reveal

国际站“我的作品”能力保持可用，但其发现入口默认隐藏。用户在浏览器控制台调用 `show()` 后，当前已挂载组件中的“我的作品”入口与其他隐藏工具一起展示。

## Behavior

- 头像菜单中的“我的作品”默认不渲染，`show()` 后渲染。
- Agent “使用”分组中的“我的作品”默认不渲染，`show()` 后渲染。
- `/agents/websites/` 路由和作品面板不受展示开关影响，直接访问仍可用。
- 账号页“支付方式”区块默认不挂载，账号页调用 `show()` 后才挂载。
- 订阅页的下单和信用卡支付流程不受展示开关影响。
- `show()` 保持既有链式调用语义，不覆盖同一页面上其他组件注册的彩蛋行为。

## Non-goals

- 不增加服务端权限或鉴权门禁。
- 不持久化 `show()` 状态。
- 不修改网站创建、发布、删除或查询能力。
