# Bot 创建中断恢复

适用创建引导的现有区域开关：国内站启用，国际站仍沿用原流程。

- 创建请求或配置执行期间注册 `beforeunload`；成功、部分失败、阻断失败及卸载后解除。浏览器提示是预防手段，不能保证所有关闭/刷新场景都会触发。
- 创建 API 返回 Bot 后，URL 保留新 Bot 的 `?bot=`，不切入另一条 `?creating=` 渲染分支。
- 拿到 Bot ID、等待沙箱之前保存表单、头像、模板 ID、克隆保留人设意图。按 Bot 隔离存入 sessionStorage，有效期 30 分钟；每次执行进度变化更新成功步骤。
- 仅在页面提供匹配的 Bot ID 与 profile 后自动恢复；空 ID 新建表单不得消费其他 Bot 的快照，零成功步骤同样恢复。恢复前通知父页面持有引导锁。
- 刷新恢复时重新初始化预热行与等待计时；实时探活成功后结束预热提示，不从快照复用上次的预热结果。
- 计划指纹核对步骤类型和稳定命令，避免同数量的技能/任务更新误用旧进度；SOUL 命令含动态备份时间戳，指纹不包含该命令。已成功步骤跳过，未知/未完成步骤继续执行。
- 每条模板定时任务在沙箱内按 profile 持有文件锁，串行执行 `hermes cron list --all` 与条件创建。同名任务（含暂停任务）保留，不重复创建。列表失败或格式无法识别时该步骤失败并在现有进度页显示，不盲目创建。
- 执行完毕清除快照；非必需步骤失败仍停留在清单页供用户确认、前往对应配置页处理。阻断错误保留快照并解除离页提示，提供沿用同一 Bot 的“重试”按钮。已卸载组件的迟到响应不得写回新一轮进度。

- 创建期从完整 Bot 列表解析目标 profile，目标转 active 后仍可继续；不会回退到 main 或其他 Bot。
- 侧边栏资料读取与总览编辑同样等待明确的 profile：缺失、空串和空白值均不执行读写；仅后端明确返回 `main` 时才能操作主 Bot。资料缓存按 Bot/profile 隔离，目标变更立即隐藏旧资料并关闭编辑草稿；异步读回时若目标已变更，不得继续写入。
- 克隆且未选模板时，读取继承人设失败、缺失或无法解析均停止配置，重试成功后才写入。
- 引导完成触发总览定时任务统计重新拉取，迟到的旧响应不得覆盖新结果。

边界：这是同标签页刷新恢复，不承诺跨设备、关闭标签页、禁用浏览器存储后的自动恢复。创建 API 返回前的未知结果没有服务端幂等契约，本轮不自动重发创建请求。后续若要求关闭页面后也保证全程完成，需要后端持久化创建任务及幂等键。

验证：相邻 `agent-onboarding-recovery.test.tsx` 覆盖真实组件重挂载、Bot/profile 隔离、首步前恢复和离页保护；`agent-buddy-setup-cron.test.ts` 实际执行生成命令并模拟 CLI，覆盖并发重试、暂停任务及查询失败。
