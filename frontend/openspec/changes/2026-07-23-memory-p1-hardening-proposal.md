# Agent 记忆页 P1 稳定性修复提案

## 状态

- 规模：M
- 分支：`frontsandbox/memory-p1-hardening`
- 设计确认：用户已确认
- 详细设计：`2026-07-23-memory-p1-hardening-design.md`

## 目标

在不新增后端接口、不改变记忆算法和页面信息架构的前提下，修复记忆页的 Hermes 路径、YAML/payload 契约、命令超时、跨 Agent 异步竞态、并发保存和部分成功提示六类 P1 问题。

## 范围

- 读取命令遵守 `HERMES_HOME`，缺失时回退 `$HOME/.hermes`。
- 使用 YAML safe-load 读取 `memory` 配置；不存在时合法回退，其他读取/格式错误显式失败。
- 使用固定 JSON 标记和严格 payload 校验。
- read/config/restart 命令统一设置 120 秒超时。
- 保存绑定 `botId + requestId`，切换 Agent 后旧结果不得更新当前 UI。
- 任意限额保存期间禁用两张限额卡片。
- 区分未保存失败、完整成功和配置已保存后的部分成功。

## 非目标

- 不新增或修改后端接口。
- 不重构整个设置页。
- 不修改 Hermes runtime、配置格式或记忆算法。
- 不处理本轮审查发现的 P2 埋点字段语义问题。
- 不新增第三方前端依赖或视觉改版。

## 验收标准

1. 自定义 Hermes 根目录和带行尾注释的合法 YAML 均可正确读取。
2. 文件权限/编码错误、非法 YAML 和非法 payload 不再伪装成正常空态。
3. 所有记忆页远程命令均有 120 秒超时。
4. A Agent 的旧读取/保存结果不会覆盖切换后的 B Agent。
5. 保存期间不会并发提交第二个限额修改。
6. 配置未写入时提示失败；配置写入后的后续故障提示部分成功且不回滚。
7. 正常读取、编辑和保存路径保持可用。
