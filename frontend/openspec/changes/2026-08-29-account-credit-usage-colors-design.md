# 账号页模型积分使用率颜色分级设计

**Status:** 已实现并通过定向测试、前端质量门禁与本地页面刷新验收。

**Size:** S。账号页订阅套餐卡片内的局部视觉反馈调整，不改变积分计算、套餐接口、布局或交互。

## 目标

让“已使用积分”的百分比文字与进度条使用同一套四档颜色，并在使用率超过 95% 时用深红色强化告警。

同时在高使用率状态下提供句内模型配置入口，区分“即将用尽”和“已用尽”。

## 颜色规则

| 显示使用率 | 百分比文字与进度条颜色 |
|---|---|
| `< 50%` | `var(--lw-accent)` |
| `50%–79%` | `#C67B1E` |
| `80%–95%` | `#CF3D4C` |
| `> 95%` | `#991B1B` |

页面继续按现有逻辑将使用率四舍五入为整数，因此“超过 95%”对应最终显示值 `96%–100%`；`95%` 仍使用现有红色。

## 实现设计

- 在 `account-page.tsx` 当前积分计算附近，根据 `usedPercent` 计算一个共享的 `creditUsageColor`。
- 百分比文字和进度条填充色都读取该变量，避免两处条件分支漂移。
- 不抽取新组件或公共工具，不新增依赖，不修改积分数值与进度宽度计算。

## 高使用率提示

- `usedPercent <= 95`：不显示提示。
- `usedPercent > 95` 且 `credit_available > 0`：显示“模型积分即将用尽，为避免智能体停止响应，请尽快配置自有模型”，其中“配置自有模型”可点击。
- `credit_available <= 0`：无论总积分是否为 `0`，都显示“模型积分已用尽，如未配置自有模型，智能体将无法继续响应。立即配置模型”，其中“立即配置模型”可点击。
- 两个链接都进入 `/agents/models`，提示位于积分进度条下方，不新增独立按钮。
- 使用率继续显示整数，不增加小数位。

## 句内跳转图标

- “配置自有模型”和“立即配置模型”两个链接末尾都增加现有 `lucide-react` 的 `ChevronRight`。
- 图标尺寸为 `12px`（Tailwind `h-3 w-3`），与链接文字垂直居中，文字和图标间距为 `2px`（`gap-0.5`）。
- 文字与图标共同属于同一个 `AppLink` 可点击区域；图标设置 `aria-hidden="true"`，不改变链接的可访问名称。
- 链接继续使用当前深红色、字重和下划线样式，不改变目标 `/agents/models`。
- 不采用 `ExternalLink`：目标是站内页面；不采用 `ArrowRight`：相较现有账号页的 `ChevronRight` 视觉更重且一致性更弱。

## 验证设计

- 在现有账号页测试中覆盖 `49 / 50 / 79 / 80 / 95 / 96` 六个边界值。
- 每个值同时断言百分比文字颜色和进度条填充色。
- 补充 `95%` 无提示、`96%` 有余额提示、余额为 `0` 的已用尽提示，以及两种链接目标断言。
- 断言两种模型配置链接都包含一个不可访问树读取的右箭头 SVG，同时保持原链接名称不变。
- 先运行新增测试确认 RED，再做最小实现并确认 GREEN。
- 最后运行账号页定向测试、`pnpm check` 和目标文件 `git diff --check`。

## 非目标

- 不调整“已使用积分”数值本身的主题色。
- 不调整套餐有效期、续费或销毁逻辑。
- 不修改国内站与国际站的区域差异。
