# 自动任务最近执行空状态去灰底设计

**状态：** 已实现并通过本地验证

**分支：** `frontsandbox/automation-empty-state-transparent`

## 目标

在 `/agents/automations/` 的“最近执行”页签没有执行记录时，去掉“暂无执行记录”这一行的浅灰色背景，让图标和文案直接展示在外层白色卡片内。

## 实现方案

仅调整 `frontend/src/pages/marketing/agent-automations-panel.tsx` 中 `RecentCronRunsPanel` 的空状态行：

- 删除 `bg-black/[0.02]`，去掉浅灰色填充。
- 删除 `rounded-lg`，避免透明容器保留无意义的圆角语义。
- 保留外层白色卡片的边框、阴影和圆角。
- 保留空状态行的间距、时钟图标、字号和文字颜色。

国内站和国际站共用该组件，本次调整对两站同时生效。

## 非目标

- 不修改有执行记录时的列表样式。
- 不修改加载态、错误态、页签或刷新交互。
- 不修改文案、i18n、数据请求或 Hermes Cron 逻辑。

## 验收标准

- 没有执行记录时，“暂无执行记录”不再显示浅灰底框。
- 外层白色卡片仍保留现有边框、阴影与圆角。
- 时钟图标、文案、内外间距和颜色保持不变。
- 有执行记录时的列表样式和功能保持不变。
- 针对空状态样式的回归测试、TypeScript 检查和 diff 检查通过。

## 风险与回退

改动只影响空状态行的两个 Tailwind class，不涉及业务状态或数据流。需要回退时恢复 `rounded-lg bg-black/[0.02]` 即可。
