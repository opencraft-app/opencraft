# 高级设置关闭审批状态提示移除设计

**Status:** 已完成方案确认，等待规格复核后进入实施。

**Size:** S。仅移除高级设置审批模式右侧的一条重复状态说明及其多语言资源，不改变审批配置或交互。

## 目标

当审批模式为“关闭审批”时，不再在选择器下方展示“当前高风险操作无需审批”状态提示。所有已支持语言均不再保留或渲染该提示。

## 方案

- 删除 `AgentCommonSettingsPanel` 中仅在 `approvalMode === "off"` 时渲染该提示的 JSX 条件块。
- 继续保留审批模式选择器中的“关闭审批”选项、保存流程和关闭审批前的风险确认弹窗。
- 通过项目 i18n 抽取脚本删除中文源文案及对应 `k_c56b6745`，同步清理英语、西班牙语、印尼语、日语、韩语、简体中文和繁体中文资源。
- 不使用 CSS 隐藏或空翻译，避免遗留不可见 DOM、无效条件分支和废弃字典条目。

## 测试与验收

- 修改现有 `approvalMode: "off"` 用例：确认选择器仍显示“关闭审批”，但状态提示不存在，且页面不自动打开确认弹窗。
- 将现有六种非简体中文语言的本地化提示测试改为逐语言断言对应译文不再出现；简体中文由关闭审批状态用例覆盖。
- 运行高级设置面板定向测试并执行 `pnpm i18n:extract`、`pnpm i18n:check`、`pnpm check` 与 `git diff --check`。
- 检查七份语言字典及 `zh-to-key.json`，确认 `k_c56b6745` 和中文源文案均已删除。
- 国内站浏览器 smoke 确认关闭审批状态下红框位置不再显示提示，选择器和确认弹窗行为保持正常。

## 非目标

- 不删除或重命名“关闭审批”选项。
- 不修改关闭审批确认弹窗中的风险说明。
- 不修改 `approvals.mode` 的读取、保存、默认值或 Hermes 命令。
- 不调整高级设置页面其他文案、布局、样式或区域边界。
