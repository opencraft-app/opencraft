# 한국어 법무 번역 검수 체크리스트

## 게이트 상태

- 상태: 법무/원어민 검수 대기
- 공개 전환: 검수 완료 전까지 `ko-KR` 생산 언어 선택기 노출 금지
- 기준 문서: 영문 원문

## 공통 확인

- [ ] 회사명, 서비스명, 법인 정보, 주소, 이메일, URL이 원문과 일치한다.
- [ ] 조항 번호, 제목, 문단, 목록, 표의 개수와 순서가 영문 원문과 일치한다.
- [ ] 권리, 의무, 제한, 면책, 해지, 준거법 표현의 법적 의미가 누락되거나 확대되지 않았다.
- [ ] 정의된 용어가 문서 전체에서 일관되게 사용된다.
- [ ] 날짜, 기간, 금액, 통화, 법령명을 원문과 대조했다.
- [ ] 모든 내부 링크가 `/ko-kr/` 하위 경로를 유지한다.

## 필수 영문 우선 문구

- [ ] 다음 문구가 개인정보 처리방침, 쿠키 정책, 서비스 이용약관에 정확히 포함된다.

> 영문 버전과 본 한국어 번역본 간에 모순 또는 불일치가 있는 경우, 관련 법령에 별도 규정이 없는 한 영문 버전이 우선합니다.

## 페이지별 확인

### 개인정보 처리방침

- [ ] 처리 목적, 법적 근거, 보유 기간 표가 원문과 항목별로 일치한다.
- [ ] 제3자 제공, 국외 이전, 이용자 권리, 민원 처리 안내를 검수했다.

### 쿠키 정책

- [ ] 쿠키 유형, 제공자, 목적, 보유 기간 표가 원문과 일치한다.
- [ ] 브라우저 및 제3자 쿠키 설정 링크가 정상 작동한다.

### 서비스 이용약관

- [ ] 이용 조건, 금지 행위, 지식재산권, 서비스 제한, 면책, 해지 조항을 검수했다.
- [ ] 총 455개 구조 블록이 영문 기준과 일치한다.

### 오픈 소스 고지

- [ ] 헤더와 설명만 한국어로 제공되고 라이선스 원문은 영문으로 보존된다.
- [ ] 라이선스별 컴포넌트 목록과 저작권 귀속 정보가 원문과 일치한다.
