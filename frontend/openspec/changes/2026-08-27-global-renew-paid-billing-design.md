# 国际站续费付费开关设计

## 目标

国际站续费入口统一由运行时 `paidBillingEnabled` 控制：开关严格为 `true` 时允许续费，关闭或缺省时保持 Coming Soon。国内站续费行为不变。

## 方案

- 扩展 `isRenewalAvailableForRegion`，同时消费站点和已标准化的付费开关。
- 账号页、Agent 到期提醒和续费弹窗统一调用该策略函数。
- 账号页在国际站开关关闭时继续展示不可点击的 Coming Soon 按钮；开启后复用现有续费弹窗和支付链路。
- Agent 到期提醒在国际站开关关闭时保持静态提醒；开启后恢复可点击入口。
- 续费弹窗保留独立门禁，关闭时不询价、不下单，防止其他调用方绕过入口控制。

## 边界

- 不修改续费后端协议、支付流程、价格计算或国内站实名逻辑。
- 不新增运行时配置字段，不修改视觉样式和用户文案。
- `paidBillingEnabled` 为 `false` 或未配置时均按关闭处理。

## 验收

- 国际站开关关闭：账号页显示 Coming Soon，Agent 提醒不可点击，续费弹窗不发起询价。
- 国际站开关开启：账号页和 Agent 提醒均可打开续费弹窗，弹窗正常询价。
- 国内站原有续费可用性不受国际站门控影响。
