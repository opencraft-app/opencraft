# 账号页续费按钮标题栏布局设计

## 目标

将已订阅状态下“订阅套餐”卡片底部的“立即续费”按钮移动到卡片标题栏右侧，与“订阅套餐”标题保持同一行。

## 范围

- 仅调整账号页已订阅套餐卡片的续费入口位置。
- 保留现有按钮样式、图标、可用/禁用状态、Coming Soon Tooltip、续费弹窗与点击逻辑。
- “销毁套餐”按钮以及隔离期、过期状态提示继续保留在卡片内容底部。
- 不修改套餐数据、续费资格判断、付费开关、实名校验或任何接口调用。

## 布局方案

标题栏使用单行 flex 布局：标题位于左侧，续费控件位于右侧。标题允许占据剩余空间，续费控件保持完整宽度且不收缩，避免中英文按钮文案被裁切。

续费控件沿用当前 `canRenew`、`renewalAvailable` 与 `operablePass` 条件，直接从内容区移动到标题栏，不复制业务分支。内容底部操作区继续承载可销毁状态下的“销毁套餐”按钮，以及隔离期/过期状态说明；即使国际站 Coming Soon 场景不可销毁，状态说明也必须保留。普通生效套餐不再保留底部分隔线或空操作区。

## 响应式与可访问性

- 标题和续费按钮始终保持同一行；按钮使用现有可访问名称与键盘行为。
- Coming Soon 状态继续使用现有 `RenewComingSoonButton`，保留 focus/hover Tooltip 和 `aria-describedby`。
- 不增加绝对定位、新动画、新颜色或新组件原语。

## 验证

- 先增加结构测试，确认续费按钮位于“订阅套餐”标题容器内，并观察旧布局下测试失败。
- 实施最小 JSX 移动后确认结构测试通过，同时复跑现有续费可用、Coming Soon、弹窗和实名流程测试。
- 运行账号页相关测试、`pnpm check` 与 `git diff --check`。
