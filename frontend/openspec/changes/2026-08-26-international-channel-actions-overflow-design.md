# 国际站渠道卡片操作按钮防溢出设计

## 背景

国际站渠道卡片在已连接状态下会同时显示“配置教程”“断开”和“重新连接”三个操作。现有按钮区使用不可换行的横向 Flex 布局，并按较短的中文、英文文案设置固定水平内边距。西语 `Tutorial de configuración`、`Desconectar`、`Reconectar` 的最小内容宽度之和超过三列卡片的可用宽度，导致 Slack 卡片的按钮越过右侧边界；印尼语等长文案也存在同类风险。

## 目标

- 国际站已连接渠道卡片的三个操作始终位于卡片边界内。
- 卡片宽度足够时保持单行布局；空间不足时允许操作组自然换行。
- 保留完整本地化文案、按钮语义、点击行为、颜色和焦点状态。
- 未连接渠道卡片继续保持“配置教程 + 连接”的既有布局。

## 范围

- 修改 `agent-channel-panel.tsx`，为国际站 ChannelPanel 增加明确的样式作用域标记。
- 修改 `agent-config/standard-panel.css`，仅在国际站作用域内调整已连接卡片的操作布局。
- 添加静态布局回归测试，锁定作用域、收缩与换行能力。
- 浏览器验收西语 Slack 已连接态，并检查 Telegram、Discord 等相邻卡片没有布局回归。

## 非目标

- 不缩短或替换西语、印尼语翻译。
- 不修改 Slack 连接、断开、重连或教程跳转逻辑。
- 不改变国内站渠道卡片布局和行为。
- 不调整卡片网格列数、卡片宽度或其他设置页样式。

## 设计

ChannelPanel 根节点根据 `ops.productConfig.isI18n` 增加国际站 modifier class。国际站已连接卡片的操作区启用可换行 Flex：教程按钮允许收缩并占据剩余空间，右侧“断开 + 重新连接”作为不可拆散的操作组保持右对齐；当两组的最小宽度无法同时容纳时，右侧操作组整体换到下一行。按钮自身保持完整文字和现有视觉，仅使用必要的 `min-width: 0`、`flex` 和 `justify-content` 约束防止最小内容宽度撑破容器。

## 验收标准

1. 西语 Slack 已连接态的三个按钮均不超出卡片右边界。
2. 当前截图所示桌面宽度下优先保持同一行；更窄卡片下允许第二行，不能出现横向溢出。
3. 未连接卡片布局不变。
4. 国内站不获得国际站 modifier class 对应的布局规则。
5. 相关 Vitest、`pnpm check`、`git diff --check` 通过，浏览器 smoke 无新增控制台错误。

## 风险与回退

风险主要是不同浏览器字体度量导致临界宽度下提前换行。布局按内容自然换行，不依赖固定断点，因此换行只会增加卡片高度，不会遮挡或溢出。若视觉验收认为第二行高度不可接受，可回退 CSS 作用域规则而不影响任何通道数据或操作逻辑。
