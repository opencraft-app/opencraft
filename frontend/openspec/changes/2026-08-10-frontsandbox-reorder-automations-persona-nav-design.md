# Agents 左侧导航顺序调整设计

**状态：** 待用户复核后实施

**分支：** `frontsandbox/reorder-automations-persona-nav`

## 目标

将 `/agents` 左侧导航中的“自动任务”和“人设”对调，使局部顺序从：

```text
技能 → 人设 → 自动任务 → 记忆
```

调整为：

```text
技能 → 自动任务 → 人设 → 记忆
```

## 实现方案

仅交换 `frontend/src/pages/marketing/agent-settings-page.tsx` 中 `settingsSections` 数组的两项顺序。该数组是当前导航展示顺序的唯一控制点，桌面和移动端共用。

不修改路由、图标、文案、权限、页面内容或点击行为，也不引入 CSS 排序和新的配置抽象。

## 验收标准

- `/agents` 导航中“自动任务”显示在“人设”上方。
- 两个入口仍分别跳转到原有自动任务页和人设页。
- 其他导航项的相对顺序保持不变。
- TypeScript 检查通过，并通过针对导航顺序的静态回归测试或等价检查。

## 风险与回退

改动只涉及数组顺序，不影响业务状态和数据流。若需回退，恢复两项原始排列即可。
