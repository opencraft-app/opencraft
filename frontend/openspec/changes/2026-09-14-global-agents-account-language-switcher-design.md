# 国际站 Agent 账号菜单语言切换设计

## 目标

国际站 Agent 管理页不再在 LightVela 标识旁展示语言/站点切换器。语言入口随用户账号入口统一收口到账号菜单，并仅切换国际站已发布语言。

## 范围

- 仅 Agent 路由的正常态与加载态关闭产品 header 语言入口；其他产品页和公开页保持现状。
- 国际站 `UserAvatarMenu` 增加“语言”二级菜单，桌面侧栏和移动端头像菜单共用。
- 子选项从 `SWITCHER_VISIBLE_LOCALES` 派生，排除国内站 `zh-CN`；不展示“中国站”跨站入口。
- 国内站账号菜单不渲染语言项。

## 交互与可访问性

- 桌面侧栏账号区在鼠标移入时打开一级菜单，未进入语言浮层时移出收起；点击和键盘触发仍然可用。
- “语言”使用项目现有 Radix Popover；桌面端鼠标移入该行即在账号菜单右侧打开独立浮层，点击和键盘触发仍然可用，不改变一级菜单高度，空间不足时由浮层自动避让。
- 语言列表使用原生单选组；当前语言动态置顶，只通过 `checked` 状态与勾选图标表达。鼠标 hover 打开时阻止浮层自动聚焦第一项，选项行不显示灰色焦点框；键盘操作通过文字下划线保留 `focus-visible` 反馈，其余语言维持 locale 注册表顺序。
- 选择新语言沿用 Agent 控制台的强制刷新机制，使 Tea SDK 文案同步更新。

## 验证

- 组件测试覆盖国际站语言清单、当前项、无中国站入口、语言行 hover 展开、鼠标选择态样式及国内站负向行为。
- Agent 加载边界测试锁定正常态与加载态均关闭 header 语言入口。
- 运行 i18n、前端检查、双区域构建，并验证国际站桌面/移动端和国内站桌面页面。
