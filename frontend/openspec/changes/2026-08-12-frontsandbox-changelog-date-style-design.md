# 更新日志左侧日期样式设计

**状态：** 已实现并通过本地验证

**分支：** `frontsandbox/changelog-date-style`

## 目标

参考 Viktor Changelog 的日期标签，只调整 LightVela `/changelog` 左侧月份区域，让日期信息成为更清晰的紫色视觉锚点。

## 实现方案

- 保留现有 `ChangelogMonthGroup` 数据结构、按月分组方式和 `140px + 1fr` 页面网格。
- 在每个月份文本前增加 Lucide `CalendarCheck` 线性图标，图标仅作装饰并设置 `aria-hidden="true"`。
- 日期标签使用 `48px` 高度和 `16px` 图文间距；文字和图标使用 `#6E47FF`，不使用背景、边框、圆角或额外水平内边距。
- 桌面端继续位于左列；移动端沿用当前单列布局，日期标签按内容宽度左对齐。

## 明确排除

- 不把月份改成具体发布日期，不修改任何更新日志文案或数据。
- 不增加 Viktor 的吸顶日期、左侧连接线或新的滚动行为。
- 不调整右侧标题、描述、配图、点线时间轴、分组间距、页头或页脚。
- 不新增依赖；复用项目已有的 `lucide-react`。

## 验收标准

- 国内站和国际站的所有月份标签均展示日历勾选图标和紫色文字，不展示底框。
- 日期标签的高度、内边距、图文间距和图标尺寸与确认方案一致。
- 现有月份文案、分组顺序、右侧内容和响应式结构保持不变。
- Changelog 定向测试、`pnpm check`、`pnpm i18n:check` 与 `git diff --check` 通过，并完成桌面端和移动端浏览器 smoke。

## 风险与回退

改动仅涉及月份标签的 JSX 与样式，不影响数据和交互。若需回退，恢复原月份 `<p>` 并移除 `CalendarCheck` 导入及对应样式断言即可。
