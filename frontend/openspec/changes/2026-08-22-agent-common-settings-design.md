# 国内站 Agent 常用设置设计

## 用户场景

用户希望在 LightVela 网页端直接看到当前 Agent 真正生效的常用 Hermes 配置，并以接近 Hermes 客户端的表单方式逐项修改，无需理解 YAML 或进入终端。

## 范围

首版仅覆盖国内站和以下 6 项：

| 页面项 | Hermes key | 控件 | 有效范围 |
|---|---|---|---|
| 长期记忆 | `memory.memory_enabled` | 开关 | boolean |
| 用户画像 | `memory.user_profile_enabled` | 开关 | boolean |
| 自动压缩 | `compression.enabled` | 开关 | boolean |
| 压缩触发阈值 | `compression.threshold` | 数字 | 0–1 |
| 压缩保留比例 | `compression.target_ratio` | 数字 | 0.1–0.8 |
| 保留最近消息 | `compression.protect_last_n` | 整数 | ≥1 |

明确排除国际站、Memory/Profile Budget、Memory Provider、Context Engine、文件修改检查点、整页批量保存和配置迁移；按分组恢复默认属于独立操作，不改变逐项保存模型。

## 数据流

1. 页面加载后在目标 Agent 内执行只读命令。
2. `hermes config get <key> --json` 返回当前有效值；同时只读 `~/.hermes/config.yaml` 判断该 key 是否显式存在。
3. 面板直接用有效值渲染，不额外展示是否显式配置；`defaultedKeys` 仅在内部用于判断分组是否已经全部恢复默认，不主动写回默认值。
4. 开关点击后立即提交；数字项先从只读值进入编辑态，用户点击保存或按 Enter 后，前端通过静态字段映射生成 `hermes config set` 命令，不能接受任意 key 或任意 shell 片段。
5. 配置命令成功后重启 Gateway，再完整回读；目标值一致才显示成功。
6. 配置已写入但重启或回读失败时显示部分成功，提示配置可能已保存但尚未确认生效。
7. 分组恢复默认时，仅对该分组中存在显式配置的 allowlist 字段执行 `hermes config unset`；全部字段处理完成后只重启一次 Gateway，再完整回读并确认这些字段均已重新沿用 Hermes 默认值。

## 交互状态

- `loading`：初次读取；表单不可编辑。
- `ready`：展示当前有效值，不区分显式配置与 Hermes Agent 默认值。
- `editing(field)`：数字项展示输入框、保存与取消按钮；未修改时保存不可用，Esc 取消并恢复原值。
- `saving(field)`：仅该字段显示保存中，避免重复提交。
- `success(field)`：显示短暂「已保存」。
- `error(field)`：保留用户输入并显示可重试错误。
- `unsupported(field)`：只读，说明当前 Agent 版本不支持。
- Agent 非运行态：整页只读并说明需先启动 Agent。

关闭自动压缩只禁用三个数值控件，不清空其值。关闭长期记忆或用户画像不删除 `MEMORY.md` / `USER.md`。

数字项默认在与输入框一致的轻边框只读容器内展示当前值。铅笔按钮完整悬浮在容器右上方，不覆盖容器边框或数值；外层交互区域为按钮预留顶部空间，使桌面端可从数字框稳定移入按钮，键盘聚焦时同样显示，移动端保持可见，避免依赖 hover。保存按钮或 Enter 才提交，取消按钮或 Esc 放弃草稿；失焦不自动保存。

保存成功统一使用项目顶部 Toast 短暂提示，不在每个配置项下方常驻绿色成功文案。保存中、输入校验错误、保存失败和部分成功仍就近显示，保证需要用户关注或处理的信息不会自动消失。

长期记忆、用户画像和自动压缩三个开关无论开启或关闭，都先显示同一个动态确认弹窗。弹窗标题使用「确认开启/关闭「配置名」？」；记忆类开关说明关闭不会删除已有文件，自动压缩说明关闭后长对话可能更快达到上下文限制且已有参数仍保留。取消、遮罩关闭、关闭按钮或 Esc 不修改配置；确认后沿用既有单项保存、Gateway 重启、回读验证和 Toast 反馈链路。操作可逆，确认按钮沿用 LightVela 的 `--text-primary` 黑色主按钮，不使用 Hermes 蓝色或危险红色；取消按钮保持白底描边。

每个一级分组标题右侧放置一个低优先级轻量描边按钮「恢复默认」。「记忆」按钮覆盖长期记忆和用户画像；「上下文管理」按钮覆盖自动压缩及三个压缩参数。按钮基础外观直接复用「添加自动任务」弹窗中「前往通道配置」的样式：`rounded-md border border-black/10 px-2 py-1 text-[12px] font-medium text-black/70 transition hover:bg-black/[0.04]`，不添加图标；「恢复默认」在此基础上保留键盘焦点和 disabled 状态。按钮常驻，当该分组全部字段均已沿用默认值时置灰，避免布局跳动并明确当前无需恢复。页面正在读取、保存或恢复配置、Agent 未运行时，两个恢复按钮与全部设置控件均不可操作。

点击「恢复默认」后显示分组级确认弹窗。标题使用「确认恢复「分组名」设置？」；说明动态使用「将重置「分组名」分组下的自定义配置，重新恢复为 Hermes Agent 默认值。」；操作按钮为「取消」和「确认恢复」。由于恢复会移除该分组的显式配置，「确认恢复」使用 LightVela 危险操作的红色主按钮（`bg-red-600`，悬停 `bg-red-700`）；取消按钮保持白底描边。该颜色调整仅适用于恢复默认弹窗，长期记忆、用户画像和自动压缩的开启/关闭确认按钮继续使用黑色主按钮。取消、遮罩关闭、关闭按钮或 Esc 均不修改配置。

恢复默认不把当前 fallback 数字或布尔值重新写入配置，而是通过 `hermes config unset` 移除该分组内当前显式存在的 allowlist 字段，使其继续跟随 Hermes 自身默认值。所有 unset 操作结束后只重启一次 Gateway，再回读 `values` 与 `defaultedKeys` 验证结果。成功后显示 Toast「已恢复默认」；只要已有字段被移除，但后续字段、Gateway 重启或回读验证失败，就按部分成功处理，提示可能已有部分配置恢复并建议刷新确认；尚未移除任何字段即失败时显示恢复失败。恢复过程使用请求 ID 和进行中状态避免重复点击或与单项保存并发。

记忆分组的两条列表说明与既有「持久记忆」页面保持语义一致。长期记忆使用「让 Agent 在会话中读取和更新长期记忆文件 MEMORY.md。」；用户画像使用「让 Agent 使用 USER.md 按需记录和更新你的偏好、沟通方式与使用习惯。」。列表说明不重复展示关闭影响，开关确认弹窗文案保持不变。

长期记忆和用户画像的说明末尾均追加行内链接「查看内容」。两个链接统一在当前页面跳转到 `/agents/memory`，不打开新窗口；链接沿用 LightVela 常规链接样式，并保留可辨识的键盘焦点状态。测试需覆盖两个链接的可访问名称和目标地址。

常用设置页面顶部仅显示标题「常用设置」，移除「管理常用的记忆与上下文行为。修改后会自动重启 Gateway 并验证结果。」说明。下方记忆与上下文管理分组的标题和间距保持不变；测试需确认旧说明不再渲染。

压缩保留比例的说明使用「压缩后保留多少近期对话原文；数值越大，保留越多，可填写 0.1 到 0.8。」。该文案保留输入范围，同时用用户可感知的结果解释 `compression.target_ratio`，不再使用「Token 比例」表述；配置键、校验范围和保存流程不变。

设置行在 `sm` 及以上宽度使用两列布局。开关项的右侧控制列按开关实际宽度占位，让左侧标题、说明和「查看内容」链接尽量使用剩余空间，减少窄桌面宽度下的提前换行；数字项继续为输入框保留 `17rem` 控制列。低于 `sm` 时维持单列堆叠，文案允许自然换行，不使用强制不换行或横向滚动。

## 配置分类

- 「记忆」：长期记忆、用户画像；说明为“管理跨会话保留的长期信息与用户偏好。”
- 「上下文管理」：自动压缩、压缩触发阈值、压缩保留比例、保留最近消息；说明为“管理长对话的上下文处理与压缩设置。”，以宽泛表述覆盖整个分组，不单独强调触发时机或原文保留范围。
- 仅在第二个一级分类前使用一条低对比度细线分隔；组内设置项之间不使用横线，也不新增卡片。

## 页面与区域边界

- 路由：`/agents/settings`。
- 导航：Agent 详情「管理」分组中的「常用设置」。
- 国内站生成并渲染该路由；国际站不生成且直接访问返回 404。

## 验收标准

- 6 项值来自目标 Agent 当前有效配置，而不是网页硬编码状态。
- 开关点击立即保存；数字项进入编辑态后，通过保存按钮或 Enter 保存，通过取消按钮或 Esc 放弃，失焦不自动保存。
- 每次写入均完成 Gateway 重启与回读验证。
- 两个一级分组标题右侧均显示「恢复默认」；分组全部沿用默认时按钮置灰，恢复时仅清除该分组的显式 allowlist 配置，并在一次 Gateway 重启后完成回读验证。
- 恢复成功使用 Toast「已恢复默认」；恢复失败和部分成功具有可区分的反馈，恢复过程中不能并发修改其他配置。
- 不支持、错误、部分成功和缺省状态均有明确反馈。
- 窄桌面宽度下，开关项不再为右侧控件预留 `17rem` 空列；数字输入项宽度和移动端单列布局保持不变。
- 不影响既有「记忆」页和国际站信息架构。
