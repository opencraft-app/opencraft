# 当前需求提案

> 当前需求：参考 `lightvela-next-figma.zip` 与截图，仅升级 `/agents/*` 控制台左侧导航样式。

## 背景

当前 `/agents/*` 控制台左侧区域仍是卡片式 profile 和卡片式导航，和新设计稿中更轻、更窄、以分隔线组织的侧边导航方向不一致。本轮只处理左侧导航视觉和 profile 操作收纳，避免扩大到顶栏、通道卡片、记忆页或内容区。

最新 `origin/master` 已包含国内站公测公告和 `/docs` 公告目录能力；本分支合并后仅在该基线之上保留左侧导航视觉改动。

## 范围

- 调整左侧 Agent profile 的头像、名称、状态、更多操作按钮和创建入口视觉。
- 调整左侧导航项的间距、图标尺寸、选中态和 hover 态。
- 保留 master 已有导航入口、条件入口和路由，不新增或删除能力。
- 将 profile 中原有重启 / 删除快捷操作收敛进更多菜单，继续复用原确认弹窗与禁用逻辑。

## 非目标

- 不改公开站点顶栏、页脚、页面背景或整体内容区宽度。
- 不改通道页卡片、按钮、SDK 面板内部样式。
- 不改记忆页统计卡、Tab、列表或刷新交互样式。
- 不改 `/agents/*` 业务逻辑、路由映射、登录态、实例操作和数据读取。
- 不改国内站公测公告文档、首页公告条或 docs 信息架构。
