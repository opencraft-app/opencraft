# 需求提案：LightVela 场景任务安装器 v1

## 背景

用户进入 `/agents/automations` 时已经能创建 Hermes Cron 自动任务，但页面心智仍然偏“配置表单”。新用户需要先理解频率、投递、prompt、通道和最近执行，才能把 Hermes 变成一个持续工作的个人 Agent。

本需求把首个自动任务路径前移为“选一个场景先跑一次”。用户从明确目标进入，填写少量业务字段，先通过一次性执行看到试跑结果，再把同一份配置添加为常态化自动任务。

## 范围

本次覆盖已有 Hermes 实例 / 已订阅用户。无实例或未订阅状态沿用现有创建、订阅流程，创建成功后再进入本场景器。

首发四个场景：

- A股财经早报
- 世界杯今日赛况
- 每日新闻
- AI 发展动态

v1 采用“一次性执行 + 最近执行”完成试跑，底层复用现有 Cron 能力，不新增后端调度接口。试跑下发后立即开始，创建成功后先通过微信 / QQ 给用户接单确认，结果稍后推送；用户仍必须能把同一份配置创建为周期自动任务。

## 用户路径

1. 用户进入 `/agents/automations`。
2. 页面在现有模板 / 添加入口之外展示场景任务区。
3. 用户选择场景，打开安装弹窗。
4. 用户填写场景字段，选择微信或 QQ 主动推送；未连接时可在弹窗内扫码接入。
5. 用户点击“先跑一次”，前端创建下发后立即开始的一次性任务。
6. 创建成功后关闭配置弹窗，通过微信 / QQ 推送接单确认消息，自动任务页提示结果稍后推送，并展示添加为自动任务入口。
7. 用户收到推送或在最近执行查看结果后，可继续点击“添加为自动任务”。
8. 前端基于同一份 draft 只替换 schedule，创建周期 Cron。
9. 自动任务列表刷新，用户能看到已生效任务。

## 设计原则

- 保持工具型控制台风格，不做营销化引导页。
- 场景配置、prompt 生成和 schedule 生成独立于 React 组件，便于测试。
- v1 不要求显式选择技能，场景 prompt 内部表达需要的搜索、摘要、来源说明等能力。
- 场景试跑首版优先微信 / QQ 主动推送；未扫码接入时在场景安装弹窗内完成连接。
- A股财经早报必须展示非投资建议提示。
- AI 发展动态不默认加入“对 LightVela 的启发”小节。

## 非目标

- 不改造无实例 / 未订阅 onboarding。
- 不建设独立场景市场。
- 不新增运行时调度语义或后端接口。
- 不做财经荐股、交易建议或赛事版权深度接入。
- 不实现新闻反馈偏好写入。

## 验收

- 四个场景入口在 `/agents/automations` 可见。
- 任一场景可打开安装弹窗并填写字段。
- 已扫码接入微信或 QQ 时，试跑和常态任务结果可主动推送到对应通道。
- 未扫码接入微信或 QQ 时，场景安装弹窗内可直接扫码连接。
- 点击“先跑一次”会创建下发后立即开始的一次性任务，并立即关闭配置弹窗。
- 系统会尽快通过微信 / QQ 发送接单确认消息；自动任务页提示结果稍后推送，结果可通过消息通道和最近执行查看。
- 页面提示条或场景入口可继续添加为周期自动任务。
- 现有模板、添加、编辑、暂停、恢复、删除、最近执行能力不回归。
