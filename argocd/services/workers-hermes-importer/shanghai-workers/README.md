# workers-hermes-importer / shanghai-workers

GitOps source for the `hermes-import-worker` deploy unit on `cls-56a1mbml`
(`shanghai-workers` Argo cluster).

- AppProject: `argocd/projects/shanghai-workers.yaml`
- Target cluster: `argocd/clusters/shanghai-workers.yaml`
- Root app: `argocd/root/shanghai-workers.yaml`
- App: `argocd/apps/shanghai-workers/workers-hermes-importer.yaml`
- Shared runtime app: `argocd/apps/shanghai-workers/workers-runtime.yaml`
- Image pin: `workers-platform.env` (`WORKERS_IMAGE`)
- Runtime secrets: generated by `workers-runtime` from
  `argocd/secrets/shanghai-workers/workers-runtime-secrets.sops.yaml`.
- Worker CR manifests: copied from
  `workers/k8s/overlays/shanghai-workers/hermes-importer/` (keep in sync when
  overlay changes).

This worker runs the same `rescue-exporter` binary as rescue export, but starts
it with `--mode hermes-import` and `TEMPORAL_TASK_QUEUE=hermes-import`. It only
registers the Hermes import workflow and TAT/COS cleanup activities needed by
that workflow.
