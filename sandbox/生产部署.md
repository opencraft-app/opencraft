# Sandbox 部署说明

本文件已替换旧的现场输出粘贴记录。

当前请统一参考：

- [docs/deploy-guides/sandbox-deploy-guide.md](../docs/deploy-guides/sandbox-deploy-guide.md)
- [docs/agent-guides/sandbox-agent-guide.md](../docs/agent-guides/sandbox-agent-guide.md)

原则：

- 测试环境敏感配置统一来自 `.secret/sandbox/test.env`
- 发布统一走 `ENV=beijing-sandbox bash sandbox/scripts/deploy-k8s.sh`
- pool 镜像切换统一走 `ENV=beijing-sandbox bash sandbox/scripts/rollout-pool-image-via-pod.sh rollout <img-id> --pools pool-c0,pool-c1,pool-c2,pool-c3,pool-c4,pool-c5`
- 不要把临时环境地址、凭据、控制台输出直接提交到仓库
