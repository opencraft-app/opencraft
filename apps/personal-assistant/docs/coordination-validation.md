机制证据覆盖：

- Work 要求版本不变时多次执行与旧写者隔离；迟到旧父回合失败不能阻塞新执行。
- 两条运行中指令有序进入后继；受理/安排/原生接受分开；重复输入与冲突处理；总量有界。
- 同根累计步数及编号去重；已提交副作用/旧报告和快照保留。
- Goal CAS、计划原子创建、无环约束、依赖在 Result 接受后释放、消费证据固定、上游变化传递失效和显式 rebase。
- 暂停门控原生/动作/父复核；真实 Codex 中止后重启，原执行/原线程恢复。
- 系统报告交付与所属 Goal 扩展/复核同事务；引用非法或目标错误会回滚结果接受。
- 模型复核不冒充用户确认；达成目标显式 reopen 后才能改工作；旧计划不自动伪造百分比进度。
- Goal 查询分页与只读范围，优先级/等待加权、每目标并发；真实 CLI 和 socket 共用回执。
- schema18 升级保持原生绑定、收据、原目录身份、快照、报告、结果与 foreign keys；旧工作不伪造 Goal。其他历史迁移在全量覆盖。
