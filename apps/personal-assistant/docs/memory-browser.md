# 个人管家记忆浏览

入口：助理 → 我的助理 → 记忆。首版不提供 WebDAV，不新建记忆存储。

## 展示与文档

- 事实按最近更新时间倒序、key 稳定打破并列，每页 30 条；展示命中总数，正文/关键字搜索、长期档案/日期记录筛选。
- 分页游标绑定原快照和搜索条件。内容变化后明确要求刷新，不混合不同版本。
- 活跃页面每 15 秒和窗口重新获得焦点时检查版本；仅提示有变化，不自动替换选中内容、草稿或滚动。
- “文档目录”独立列出私有 `profile.md`、`log/YYYY-MM.md`，包括没有识别出事实的普通 Markdown；显示识别条数和字符数。原文只读、每次 8000 字符；分页校验文档版本。
- 可供召回不代表每轮全部注入；原文中的普通段落也不自动视为有效事实。

## 草稿和错误

- 切换事实、搜索、筛选、刷新、切换目录和关闭面板时提示放弃未保存草稿。浏览器离开/重载沿原生 beforeunload 提示。
- 应用内离开后返回，可恢复同一登录传输和精确主人/管家绑定下的临时草稿与未确认请求 ID。仅内存缓存，最多 8 个绑定、10 分钟，不进 localStorage/磁盘；授权变化清空。不是跨登录、强制重载或关闭浏览器后的永久草稿承诺。
- 断线时隐藏私有展示，但保留当前组件的纠正草稿；重新通过当前主人鉴权后才恢复显示。不会向其他主人或其他绑定恢复。
- 版本冲突明确说未应用；可读取最新版本并保留草稿，对照后由主人明确选择新的编辑基础，不静默覆盖新版本。已被忘记的条目不能由旧草稿复活。
- 未确认写入沿原输入 ID 幂等重试。离线、未初始化、锁忙、待恢复事务、存储异常、重复内容、缺失条目和过时分页分别给安全提示；错误不暴露路径或凭据，不伪装为空列表。

## 来源、写入和权限

- 来源只展示当前管家历史里真实存在的用户消息；缺失证据明确标示，不补造归因。
- 明确纠正保留原始证据 ID，记录方式变为 explicit；页面明确原始聊天不是纠正后表述的原话。多次纠正继续保留原始依据，文件旁车仍负责持久化，不新建来源数据库。
- 忘记复用原 tombstone、CAS、输入回执和显式 epoch，并清除该条目当前来源关联；不删除原始对话，不保存可恢复的旧事实副本。
- 公共 RPC → Collaboration → 当前安装 Host → 原独立助理进程 → 原 UoW/MemoryService。只有当前登录 Human 主人的当前绑定可访问。群成员、Bot 或客户端指定 owner 均不授予权限；异步返回前重验绑定和 Host。
- 当前仅支持 bot-v1 的私有 agent scope；不暴露共享/project 记忆、任意路径、旁车、凭据、数据库或模型管理端口。

## 离线只读

- 原进程就绪时继续使用原 UoW、文件权威和 SQL 索引，写入路径不变。
- 原进程未运行、缺配置或排队时，可信 Host 可根据 Core 传来的当前绑定验证本地 bot-v1 档案、owner 和 agent 身份。不接受 renderer 选根目录或 owner。
- 复用原 MemoryFileStore 解析器的 readOnly 模式和同一文件短锁，只读原始文件。锁只用于一致读，不初始化档案、不启动 runner/模型、不迁移/重建索引、不执行文件恢复。
- 存在 pending journal 时只返回 recovery_required，交给原运行时恢复；不把中间态当事实，不清理事务日志。仅原锁机制可以回收已证明死亡的锁 owner。
- 来源必要时 SELECT-only 打开现有 assistant.sqlite，校验 DB identity 并限制为本管家的用户消息；不打开写连接或扩展授权。
- 未创建过的档案明确提示先运行一次；离线不能纠正/忘记。整个 Host/服务器不可达不等于可离线访问服务。
