# 问题驱动召回：独立提交与配对复测

2026-11-09。读取修正独立提交 **98c1d13**；旧基线 **1bd48d4**，均在本地分支 `experiment/retrieval`。原独立实验目录没有Git，先封存原实现为基线，再单独提交修正；未部署Join或推送远端。

本轮17题结果为 **7/17 → 9/17**，增加2道正确题，没有旧对新错。新增两题均核实为“事实已存储、旧初始视图缺失、新初始视图召回后答对”。仅3个人物、一次生成、已知回归集，尚不能宣称泛化或统计显著，也没有重跑腾讯两路作新排名。

## 固定与隔离

- Reader固定DeepSeek `deepseek-v4.1-flash-1017 / provider-default reasoning`；提炼和独立复核固定混元4 `hy4 / reasoningEffort=none`，均经同一固定Codex二进制。
- 沿用三方v3计划的全部17题、3人物、角色、背景和因果前缀。每个前缀只提炼一次，两路共享同一已学习记忆；问答前后事实和学习任务不变校验通过。
- 旧路直接加载基线原Queries、ReadModel及readerInput；新路调用候选生产实现，评测器不重写召回算法。相同reader指令、每题最多6次查询/7轮、单次12000字节/累计48000字节；交替先后次序，新原生模型线程。
- 问题、选项不回流为学习证据；自动召回只接当前问题，gold和题型只在父评分器。沿用严格选项评分，失败计入分母，没有择题重跑。
- 这是问题词面召回、输入去重、不完整标记和零命中提示的一组改动，不能把总收益归因于其中任一单项。

正确率增加11.8个百分点；7题两路均对、8题两路均未答对（其中旧路有1次失败）。记忆视图字节减少46.3%，不同事实覆盖增加28.5%。全部答题token减少35.5%，但包含旧路失败题的额外调用；只看双方都完成的16题，token减少17.6%，不能把35.5%全归因于正文去重。

原始用量是harness阶段观察，不代表供应商HTTP请求次数或费用账单。视图字节统计只含memoryContext和memoryRecall，不能当作模型实际输入token。零命中提示已通过机制测试；本轮没有证明该提示单独增加正确题。

## 准备与剩余边界

三个共享记忆库分别29/62/53条活跃事实；23个实际批次中17个提交、6个最终复核拒绝。全部240条用户交流按原到达边界进入原生学习，未发生消息字符裁剪，但不代表每个事实都被正确提炼。复核拒绝是否过严仍未验收。

共享准备合计约952.0秒、723858个已知token，只计算一次，不能分别计作两路各自开销；整轮约20.25分钟。准备成本没有被本次读取修正解决，且本轮新学习结果不等于历史v3的学习结果；正确对照是本轮配对7→9，不能用新路9与历史分数作单变量解释。

此次不改提炼/复核提示词、事实/墓碑、schema或文件权威。内部仍为词面匹配，无向量、词形归一、同义词理解或隐含关系保证；原项目grant与最多3个项目初始注入限制保留，显式后续查询沿原授权范围。
