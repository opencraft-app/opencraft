# π-Bench integration

Inherits ../AGENTS.md. This directory owns only the public benchmark channel and
run manifest. Pin the upstream revision; import its user simulator and scorer
without rewriting prompts or hidden intent logic. Hidden intents, persona,
checklists and scoring logs never enter the assistant process.

The first track is a **capability-limited dialogue pilot**, not the full benchmark:
the product has no AppWorld/Brave or general workspace-write adapter. Do not run
NanoBot or a bare Codex client and label it our butler. Use the product's public
socket with its actual reception, delegated execution and memory owners. Preserve
one fresh profile across the selected episode prefix. No production deployment.

All models/credentials are explicit. Simulator configuration changes, bounded
turn counts and unavailable tools must be recorded, not hidden behind an official
leaderboard score. Keep failures and unmet requirements. Capture only real
user-visible messages; acknowledgements are progress, not completed replies.
