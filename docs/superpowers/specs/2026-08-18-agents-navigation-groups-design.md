# Agent 左侧导航分组设计

## 目标

把 `/agents` 左侧当前平铺的功能入口改为两级信息架构，让用户按“配置、使用、成长、管理”理解和查找功能。

## 信息架构

| 一级分类 | 英文 | 二级入口 |
| --- | --- | --- |
| 配置 | Setup | 通道、模型、技能 |
| 使用 | Use | 对话、自动任务、我的作品（仅国际站） |
| 成长 | Growth | 人设、记忆、成就 |
| 管理 | Manage | 云存储、诊断中心 |

一级顺序固定为 `Setup → Use → Growth → Manage`。国内站不展示“我的作品”；国际站沿用当前英文 `My creations`。

## 交互与视觉

- 一级分类是静态分组标题，不可点击，默认全部展开。
- 二级入口保留现有图标、选中态、路由和点击行为。
- 桌面端纵向展示四组；移动端每组独立占一行区域，组内继续使用现有网格布局。
- 一级标题与二级入口通过字号、颜色和缩进形成层级，不新增动画、折叠状态或持久化逻辑。
- 二级入口组内间距使用 `2px`，菜单项高度使用 `36px`；一级分类之间维持现有 `12px` 间距。
- 隐藏的“终端、浏览器”保持现状，不纳入默认四组。
- 自动任务首次加载时，右上角刷新按钮禁用并保持静态；只有用户主动刷新时才显示旋转反馈。

## 可访问性

每个一级分类使用带可见标签的 `role="group"` 容器；二级入口继续使用链接和 `aria-current="page"` 表达当前页面。

## 验收标准

- 国内站按 `配置 / 使用 / 成长 / 管理` 展示 `3 / 2 / 3 / 2` 个入口。
- 国际站“我的作品”位于“使用”分组，英文保持 `My creations`。
- 桌面与移动端均能清晰识别一级分类和二级入口。
- 原有路由、选中态、隐藏工具与反馈入口不受影响。
- 自动任务页面显示“加载中”时，刷新按钮不可点击且图标不旋转；主动刷新仍有旋转反馈。
