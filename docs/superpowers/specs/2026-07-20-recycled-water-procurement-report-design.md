# 再生水厂设备材料比价报告 Word 版式设计

## 目标

将《再生水厂设备材料比价报告.md》转换为可编辑、适合打印与评审的正式商务报告版 Word 文档。完整保留原文、数据、报价口径、风险提示和免责声明，不改写结论，不补充未经来源支持的信息。

## 版式方案

- 采用 `standard_business_brief` 商务报告体系：Letter 纸张、正文 11 磅、1 英寸页边距、克制的蓝灰色层级。
- 首页使用简洁报告标题块，不增加独立空白封面；标题下保留“依据”和“配套交付物”，以提示框呈现。
- 正文按原 Markdown 的七个章节组织，使用真实的 Word 标题、项目符号与编号格式。
- 页眉显示报告简称，页脚显示页码；多页表格重复表头。

## 表格策略

- “重点设备最低市场采购价”八列表格采用单独的横向页面，设置固定列宽并优先保证设备名称、规格和来源依据的可读性。
- “按系统分类合价汇总”和“待询价清单”保持纵向页面。
- 表头使用浅灰蓝底色，金额和数量列按内容类型对齐；单元格允许自动换行和跨页扩展，不设置可能截断内容的固定行高。
- 表格采用明确的 Word DXA 几何，避免自动适配导致列宽漂移。

## 内容转换规则

- 保留粗体、行内代码、引用、分隔线和末尾免责声明的语义。
- 修复 Markdown 中因换行拆开的表格单元格，仅恢复其原有文字关系，不纠正或猜测源数据中的截断字段。
- 不嵌入外部链接、不重新核验市场价格，也不修改数字格式。

## 验收标准

- 生成 `.docx` 后渲染全部页面为 PNG 并逐页检查。
- 不出现文字重叠、裁切、缺字、断裂表格、异常空白页或错误的横纵向切换。
- 最终只交付 Word 文档，原 Markdown 与内部渲染文件不改动、不交付。
