# Web 混元听写

Web 的设置 → 通用 → 语音输入可选择自动、混元语音或浏览器语音。
自动模式仅在后台服务和当前浏览器录音能力均就绪时选择混元；显式选择混元不会在失败后偷偷切换服务。
Mac 系统听写保持原实现，本轮没有增加桌面云录音端口。

## 部署

在设置 → 服务器 → 模型服务添加提供商，用途选“混元语音转写”；默认声明 `ep-hyasr3`，保存 TokenHub 密钥并启用连接。然后在语音输入选择转写模型。配置沿用安装数据目录 models/models.json 和 models/credentials.json：前者只存凭据引用，后者沿用现有私有仓库权限。不是新增环境文件或另一份密钥数据库，也不把密钥发送到所选 SSH Server。

`OPENCRAFT_SPEECH_PUBLIC_ACCESS=1` 仍明确允许公网访问者使用此安装实例的付费语音服务；否则只允许 loopback-only 网关。它是部署准入策略，不是提供商配置，不继承 SSH 共享模式，不提供租户隔离或计费账本。

旧环境配置必须由操作人员显式导入（路径需按当前安装选择）：

```sh
npm run migrate:speech-models -- --source /absolute/private.env --models /absolute/install-data/models
```

命令只读取私有文件，将密钥放入同一模型凭据仓库；已有语音选择时不覆盖。旧文件保留供核对/回退，不再被新版语音服务读取。核对后移除旧密钥/MODEL 部署配置，单独保留 PUBLIC_ACCESS 准入策略。本次源码实现与当前预览是否已替换需分别核验，测试不会导入真实配置。

迁移前需以私有权限备份模型目录。旧版本的严格模型校验不认识新增的 type/defaultSpeechModel 字段，回退必须同时恢复迁移前模型文档（及匹配的凭据快照），不能只切回旧程序却继续读已迁移文档。不得用旧快照覆盖迁移后用户的新修改；存在新修改时先核对并另行备份。

公网由 HTTPS 入口转发并保留公开 Host。转写 POST 要求匹配 Origin，无跨域通配或凭据透传。
保存配置后刷新语音页即可，不需要重启后端。`GET /__opencraft_speech/capabilities` 只报告公开能力、模型选择/管理目录、revision 和不可读绑定票据；`POST /__opencraft_speech/model` 以 expectedRevision/CAS 保存明确选择。
`POST /__opencraft_speech/transcribe` 接收 `audio/wav` 原始字节、会话/attempt/绑定票据头和可选语种，不接受 URL、凭据或执行 Server。
Header/body 受后端校验；结果必须带匹配会话/attempt 身份。后端固定访问 TokenHub HTTPS 同步端点，不跟随重定向。

录音最多120秒；后端仅接受单声道16kHz PCM16 WAV，最大3,840,044字节，依据实际头与样本数计算时长。
上传最多15秒，上游识别最多90秒；同一实例最多2个上传/识别、每分钟最多10个新的付费尝试。
客户端不自动重试付费请求。重复attempt绑定音频摘要、语种和配置票据，五分钟内返回缓存回执，最多64份；
进程重启不保证回执持久化，也不宣称供应商支持幂等提交。

## 生命周期

录音开始固定语音配置票据，停止及显式重试仍用该票据。转写前配置已换模型/密钥时拒绝旧录音，请重新录制；不静默换模型处理旧音频。提交后的供应商调用仍使用提交时的配置，不保证供应商取消或退款。停用/删除所选连接保留不可用选择，只有用户明确选择才能换模型。聊天模型变化、连接显示名称变化不应取消录音。

录音器收齐停止事件后转换音频，并立即释放麦克风。采集启动超时、权限拒绝、设备中断或录音时页面进入后台均失败，不自动插入部分文本。
服务失败可原位重试同一段临时音频，最多两次，等待重试两分钟后释放。成功、取消、草稿/View更换或扩展销毁后释放；音频不进入会话附件、历史、数据库或日志。
失败使旧发送意图失效；点击重试只允许写入，不会自动发送。取消立即撤销写入资格并中断本地请求，不保证上游停止计费。

## 验证与边界

```sh
npm run test:hunyuan-speech
npm run test:native-speech
npm run build:web
npm run smoke:hunyuan-dictation
npm run smoke:speech-model-settings
```

浏览器 smoke 用真实录音/API/Composer和共享设置控件，仅麦克风设备与付费供应商替身。
覆盖宽屏/触屏、浅深主题、停止插入、失败重试不发送、取消和换草稿后的迟到结果。
真机权限、iPhone编码兼容、嵌入页麦克风授权、识别质量/耗时/费用仍须单独验收，合成测试不能证明。
