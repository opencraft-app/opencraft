### Ownership

- The shared Bridge Host owns durable command receipts, byte budgets, and the outbox. The Gateway owns the committed inbox cursor, route identity projection, and event delivery. Node and Cloudflare share these contracts. The JSONL frame limit is 10 MiB. Commands and input leave envelope headroom. A normal outbox page is at most 12 MiB. Node and WorkspaceHost can reassemble larger retained events from 4 MiB transport fragments, up to 64 MiB. The Host storage worker retains at most one encoded event and sends the HTTP attachment only the requested fragment. Committed inbox replay uses a conservative 12 MiB page budget and allows a single larger event to advance the cursor. Node keeps one row per event and retains whole-event reads above the fragment budget. WorkspaceHost also uses one row until the encoded payload and projection exceed its inline SQL budget. Larger events retain a small route index row and store their UTF-8 payload in chunks. Placement rollback archives those chunks in the same transaction as their event rows.
- The Codex adapter owns native Turn metadata reads and translation of supported Codex media, tool items, Thread status, and human interactions.
- The OpenCraft Host owns shared interaction state, response admission, continuation, and retries. Docker routes Bridge work through the same owners and durable stores as its existing Codex path.

Local verification uses synthetic Codex and DSH providers with the real Bridge Gateway, Local Agent Host, Node and Workerd stores, and Chromium Workbench fixtures. Live acceptance on the installed downstream product is pending.
