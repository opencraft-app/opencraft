# Session 与 Thread

Session 是顶层执行容器。Thread 是 session 内一条有序 conversation 或 sub-task stream。

```ts
export type Session = {
  id: string;
  backend: BackendKind;
  environment_id: string;
  status: SessionStatus;
  title: string;
  created_at: string;
  updated_at: string;
};
```

Wire DTO 字段名以 OpenAPI 为准，使用 `snake_case`。

## Requirements

### Requirement: Session 拥有 Threads

每个 thread MUST 属于且只属于一个 session。

#### Scenario: backend 创建 sub-agent work

- **WHEN** backend 创建 sub-task 或 sub-agent
- **THEN** daemon 在同一个 session 下创建或投影 child thread

### Requirement: thread timeline 可独立读取

Thread timelines SHOULD 可以独立 fetch。

#### Scenario: 打开 sub-task review

- **WHEN** 用户打开 sub-task thread
- **THEN** client 可以只拉取该 thread timeline
