# Event Envelope

Event envelope 是排序、replay、同步和 projection 的最小 canonical 单元。

```ts
export type VelaEventEnvelope<TPayload = unknown> = {
  event_id: string;
  epoch: number;
  seq: number;
  session_id: string;
  thread_id?: string;
  type: VelaEventType;
  created_at: string;
  affected_views?: AffectedView[];
  source: EventSourceRef;
  payload: TPayload;
  raw?: RawProviderEvent;
};
```

这是 wire DTO 形状，字段名以 OpenAPI 为准并使用 `snake_case`。内部 Rust/TypeScript 类型可以使用本地命名风格，但序列化到 API 时必须映射为这里的字段。

`VelaEventType` 必须来自 [事件词表](/docs/api/event-vocabulary)。`affected_views` 用来告诉 client 哪些 read model 需要刷新；它不是 payload 的任意字段。

## Raw Provider Event

`raw` 是诊断材料，不是 wire compatibility contract。它可以保存 provider 原始 JSONL、stderr 摘要或 adapter 处理时的原始片段，但普通 UI、SDK 和 read model 不得依赖 `raw` 字段决定显示逻辑。

正常 provider lifecycle 可以被 adapter 吸收而不产生 canonical event，因此并不是每个 provider raw event 都一定有对应的 `VelaEventEnvelope`。如果需要完整 provider trace，应使用 diagnostics/trace 或测试 cassette；canonical event log 只保存会影响 replay、projection 或诊断的事实。

## Requirements

### Requirement: canonical events 可 replay

Canonical events MUST 包含足够信息重建 read models。

#### Scenario: transcript projection 丢失

- **WHEN** projection storage 被删除
- **THEN** daemon 可以 replay events 并重建 transcript rows

### Requirement: raw payload 可选

Raw provider payload MAY 保留，但 client MUST NOT 依赖它。

#### Scenario: privacy mode 禁止 raw retention

- **WHEN** raw retention 被关闭
- **THEN** clients 仍然可以通过 canonical projections 正常渲染

### Requirement: raw trace 不等于 canonical event

Provider raw lifecycle event MAY be absorbed by adapter and never become a canonical event.

#### Scenario: provider 输出普通 turn_start

- **WHEN** provider 输出普通 `turn_start`
- **THEN** adapter 可以吸收它
- **AND** canonical log 仍然只依赖 runtime 写入的 `turn.started`
