CloudAgent is the agent runtime and gateway surface for durable sessions,
workspace-backed execution, and channel integrations.

CloudAgent 是面向持久会话、Workspace 执行和渠道集成的 Agent runtime 与 gateway 边界。

Start with the HTTP Run API if you are integrating a backend service, channel
adapter, or automated test client.

如果你要接入后端服务、渠道适配器或自动化测试客户端，请从 HTTP Run API 开始。

## Key Surfaces / 关键边界

| Surface | Use / 用途 |
| --- | --- |
| CloudAgent HTTP Run API | Durable session/run protocol for non-WebSocket clients. 非 WebSocket 客户端使用的持久会话与运行协议。 |
| ACP | Interactive protocol compatibility layer. 交互式协议兼容层。 |
| Wisp runtime | Persistent workspace and runtime recovery layer. 持久化 Workspace 与运行时恢复层。 |
| ChannelGateway | Channel adapter that should use the HTTP Run API for durable traffic. 渠道适配器，持久流量应接入 HTTP Run API。 |

## Recommended Integration Path / 推荐接入路径

1. Probe `/v1/cloudagent/capabilities`.
2. Create or load a CloudAgent session.
3. Submit a run with an idempotent caller-generated `run_id`.
4. Replay or stream events with `after_seq`.
5. Read the durable result.

1. 探测 `/v1/cloudagent/capabilities`。
2. 创建或加载 CloudAgent 会话。
3. 使用调用方生成的幂等 `run_id` 提交运行。
4. 通过 `after_seq` 回放或读取事件流。
5. 读取持久化结果。
