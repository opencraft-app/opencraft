</p>

## <span className="lang-en">Key Surfaces</span><span className="lang-zh">关键边界</span>

| Surface | <span className="lang-en">Use</span><span className="lang-zh">用途</span> |
| --- | --- |
| CloudAgent HTTP Session Events API | <span className="lang-en">Qoder-like durable session event protocol for non-WebSocket clients, with SSE streaming and replay.</span><span className="lang-zh">面向非 WebSocket 客户端的类 Qoder 持久会话事件协议，支持 SSE 事件流和回放。</span> |

## <span className="lang-en">Recommended Integration Path</span><span className="lang-zh">推荐接入路径</span>

<div className="lang-en">

1. Probe `/v1/cloudagent/capabilities`.
2. Create or load a CloudAgent session.
3. Submit a `user.message` event with an idempotent caller-generated `Idempotency-Key` or `client_event_id`.
4. Replay or stream public session events with `after_seq` / `after_id`.
5. Stop on `session.status_idle` or `session.error`.

</div>

<div className="lang-zh">

1. 探测 `/v1/cloudagent/capabilities`。
2. 创建或加载 CloudAgent 会话。
3. 使用调用方生成的幂等 `Idempotency-Key` 或 `client_event_id` 提交 `user.message` 事件。
4. 通过 `after_seq` / `after_id` 回放或读取公开会话事件流。
5. 遇到 `session.status_idle` 或 `session.error` 后结束本轮观察。

</div>
