<p>
  <span className="lang-en">The CloudAgent HTTP Run API is for channel gateways, backend services, and test clients that need to call CloudAgent without holding a long-lived ACP WebSocket.</span>
  <span className="lang-zh">CloudAgent HTTP Run API 面向渠道网关、后端服务和测试客户端。它们可以调用 CloudAgent，而不需要持有长生命周期 ACP WebSocket。</span>
</p>

<p>
  <span className="lang-en">Use this API for durable channel traffic. Do not multiplex many channel conversations over one ACP WebSocket.</span>
  <span className="lang-zh">持久渠道流量应该使用这套 API。不要把多个渠道会话复用到同一条 ACP WebSocket 上。</span>
</p>

  <span className="lang-zh">Devcloud 内网入口：</span>

<p>

## <span className="lang-en">Basic Flow</span><span className="lang-zh">基本流程</span>

<div className="lang-en">

1. Create or load a session.
2. Submit a run with a caller-generated `run_id`.
3. Read events using `after_seq`.
4. Read the final durable result.
5. If the observer disconnects, resume from the last committed `after_seq`.

</div>

<div className="lang-zh">

1. 创建或加载会话。
2. 使用调用方生成的 `run_id` 提交运行。
3. 使用 `after_seq` 读取事件。
4. 读取最终持久化结果。
5. 如果观察方断开连接，从最后确认的 `after_seq` 继续读取。

</div>

## <span className="lang-en">Create Session</span><span className="lang-zh">创建会话</span>

```bash
curl -sS \
  -H "Content-Type: application/json" \
  -H "X-Tenant-ID: $CLOUDAGENT_TENANT_ID" \
  -H "X-Project-ID: $CLOUDAGENT_PROJECT_ID" \
  -d '{
    "cwd": "/workspace",
    "agent_version": "builtin.v1",
    "workspace_version": "builtin.v1"
  }' \
  "$CLOUDAGENT_BASE_URL/v1/cloudagent/sessions"
```

<p>
  <span className="lang-en">Response:</span>
  <span className="lang-zh">响应：</span>
</p>

```json
  "state": "ready",
  "runtime_generation": 1
}
```

## <span className="lang-en">Submit Run</span><span className="lang-zh">提交运行</span>

<p>
  <span className="lang-en">Generate a stable idempotency key per inbound channel message:</span>
  <span className="lang-zh">为每条入站渠道消息生成稳定的幂等 key：</span>
</p>

```bash
export RUN_ID="job_channel_${MESSAGE_ID}"
```

<p>
  <span className="lang-en">Submit:</span>
  <span className="lang-zh">提交：</span>
</p>

```bash
curl -sS \
  -H "Content-Type: application/json" \
  -H "X-Tenant-ID: $CLOUDAGENT_TENANT_ID" \
  -H "X-Project-ID: $CLOUDAGENT_PROJECT_ID" \
  -d '{
    "run_id": "'$RUN_ID'",
    "text": "你好",
    "cwd": "/workspace"
  }' \
  "$CLOUDAGENT_BASE_URL/v1/cloudagent/sessions/$SESSION_ID/runs"
```

## <span className="lang-en">Event Replay And Stream</span><span className="lang-zh">事件回放与流式读取</span>

<p>
  <span className="lang-en">Replay committed events:</span>
  <span className="lang-zh">回放已提交事件：</span>
</p>

```bash
curl -sS \
  -H "X-Tenant-ID: $CLOUDAGENT_TENANT_ID" \
  -H "X-Project-ID: $CLOUDAGENT_PROJECT_ID" \
  "$CLOUDAGENT_BASE_URL/v1/cloudagent/runs/$RUN_ID/events?after_seq=0"
```

<p>
  <span className="lang-en">Stream new events as newline-delimited JSON:</span>
  <span className="lang-zh">以 newline-delimited JSON 方式读取新增事件：</span>
</p>

```bash
curl -N \
  -H "X-Tenant-ID: $CLOUDAGENT_TENANT_ID" \
  -H "X-Project-ID: $CLOUDAGENT_PROJECT_ID" \
  "$CLOUDAGENT_BASE_URL/v1/cloudagent/runs/$RUN_ID/events?after_seq=0&stream=true"
```

<p>
  <span className="lang-en">The stream is HTTP NDJSON. It is not WebSocket and not Server-Sent Events.</span>
  <span className="lang-zh">该流是 HTTP NDJSON，不是 WebSocket，也不是 Server-Sent Events。</span>
</p>
