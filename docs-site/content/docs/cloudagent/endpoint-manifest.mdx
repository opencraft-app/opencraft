The docs site exposes a minimal CloudAgent endpoint manifest at:

```text
/cloudagent-endpoints.json
```

This is not a full OpenAPI contract yet. It is a stable v1 inventory for AI
agents, tests, and integration clients that need to discover the durable run
surface without scraping prose.

## Shape

```ts
type CloudAgentEndpoint = {
  method: 'GET' | 'POST';
  path: string;
  purpose: string;
  auth: 'scope';
  stability: 'v1';
  source_path: string;
};
```

## Contract

- The manifest is generated from `docs-site/lib/cloudagent-endpoints.ts`.
- Endpoint prose links back to `cloudagent/gateway/docs/cloudagent-http-run-integration.md`.
- Future full OpenAPI output should be generated from route/schema truth, not maintained as a second hand-written source of truth.
