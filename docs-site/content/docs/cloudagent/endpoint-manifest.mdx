The docs site exposes a CloudAgent endpoint manifest at:

```text
/cloudagent-endpoints.json
```

This manifest is derived from the generated OpenAPI schema. It is a compact
inventory for AI agents, tests, and integration clients that need endpoint
discovery without scraping rendered prose.

## Shape

```ts
type CloudAgentEndpoint = {
  method: string;
  path: string;
  purpose: string;
  auth: 'scope';
  stability: 'v1';
  source_path: string;
};
```

## Contract

- The manifest is generated from `docs-site/openapi/cloudagent.json`.
- `docs-site/openapi/cloudagent.json` is generated from Go code in
  `cloudagent/gateway/internal/wrapper/cloudagent_run_spec.go`.
- The full reference is rendered by Scalar at `/reference/cloudagent` and
  embedded in `/docs/cloudagent/api`.
- Do not maintain a second endpoint table by hand; update the Go protocol spec
  and rerun `./makedocs.sh`.
