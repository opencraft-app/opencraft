This documentation site is the root portal for mono2.

The first curated section is CloudAgent because it already has a durable HTTP
run protocol, runtime lifecycle notes, and integration docs that need stable
human and AI entrypoints.

## AI Entry Points

| Endpoint | Purpose |
| --- | --- |
| `/llms.txt` | Compact AI index for crawlers and coding agents. |
| `/llms-full.txt` | Full text export of the curated docs. |
| `/docs-index.json` | Machine-readable page index. |
| `/cloudagent-endpoints.json` | Compact endpoint inventory derived from the CloudAgent OpenAPI schema. |

## Generation Contract

The repository root exposes `./makedocs.sh`. Each component can own a local
`makedocs.sh` that exports deterministic docs fragments into this portal.

This keeps the docs site generic while allowing each directory to document
itself without requiring a central generator to understand all subsystem
details.

## Source Policy

The docs-site keeps source MDX readable and stable. Pages should include
frontmatter with owner, status, last review date, tags, and source path so AI
systems can reason about freshness and ownership.
