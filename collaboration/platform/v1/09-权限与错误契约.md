# 权限与错误契约

## 1. 主体

| 主体 | 凭证 | 作用域 |
|---|---|---|
| Human | Bearer Access Token | Account + Server Member |
| Human IM SDK | 短期 UserSig | 全局 Human UserID |
| Agent Runtime API | 短期 Runtime Token | 一个 Agent + 一个 Server |
| Agent IM SDK | 短期 UserSig | 一个 Agent UserID |
| Tencent Worker | 服务端内部身份 | 部署级 IM/TAT |

Computer 具有长期 bootstrap credential 与可轮换的短期 ComputerBearer；它们只允许
bootstrap、Assignment、launch/session、observation 与 heartbeat 端点。平台仍通过 TAT
服务端 API 完成纳管和 PTY；腾讯云管理员 Secret 不属于任何外部主体。

## 2. 判定顺序

1. 认证和 Token 当前性；
2. Account/Agent credential 当前性；
3. Server 与 Member 当前性；
4. 资源归属；
5. 角色或 Runtime capability；
6. revision/idempotency；
7. 限流；
8. TDSQL shardkey 与资源归属；
9. 执行副作用。

错误响应不泄露跨 Server 资源是否存在。

## 3. Server 角色

| 操作 | Owner | Admin | Member |
|---|---:|---:|---:|
| 修改 Server | ✓ |  |  |
| 邀请 Admin | ✓ |  |  |
| 邀请 Member | ✓ | ✓ |  |
| 管理 Human Member | ✓ | 有限制 |  |
| 管理 Agent/Computer | ✓ | ✓ |  |
| deploy/start/stop Agent | ✓ | ✓ |  |
| 打开 Computer PTY | ✓ | ✓ |  |
| 创建 Channel | ✓ | ✓ |  |
| 查看 Agent/Channel/Task | ✓ | ✓ | ✓ |

## 4. IM Session

Human `/me/im/session`：

- Auth Session 当前；
- Account.imState=ready；
- 签发 Account.imUserId 的短期 UserSig；
- 不接受 serverId 或任意 userId。

Computer launch/session：

- Computer credential 当前，且 assignment epoch/revision、launchId、generation、attempt
  和 Agent credential version 全部匹配；
- Agent/Member active；
- Agent.imState=ready；
- Computer 未 removed；
- 只签发该 Agent.imUserId 与当前 launch 的短期 Runtime Token；
- 返回的 Runtime Token 只能访问当前 Agent 资源。

Human 不能请求 Agent UserSig；Agent 不能请求 Human 或其他 Agent UserSig。

Refresh Token、Invite Token 和 Runtime credential 中的 accountId/serverId 前缀只用于
TDSQL 路由。路由后仍必须验证完整 Secret 哈希及数据库当前状态，不能把自报 shardkey
当作授权证据。

## 5. Channel 与聊天

- 列出 Channel：active Server Member；
- 公开 Channel：active Member 可加入；
- 私密 Channel：Owner/Admin 或已有权限的邀请；
- `#全员`：active Member 自动加入，不允许退出；
- 消息读写最终以腾讯 IM membership 为准；
- Agent Runtime 只能处理腾讯 SDK 实际交付给自身的消息；
- replyPolicy 不能扩大腾讯 membership；
- 平台不提供消息发送代理或任意 From_Account 接口。

Human↔Human C2C 由腾讯云 IM 关系策略处理，平台不创建 Server DM ACL。

## 6. Agent

- 创建、修改、删除、credential rotate：Owner/Admin；
- deploy/start/stop/restart：Owner/Admin；
- 创建时必须绑定同 Server、已纳管的 active Computer，不允许创建未绑定 Agent；
- 修改 computerId/runtimeKind 需要 Agent desiredState=stopped；
- computerId 只能迁移，不能清空；Computer 瞬时离线不影响绑定，但会阻止执行类操作；
- 删除 Agent 会撤销 credential 并停止 Runtime；
- Agent Runtime 不能读取腾讯云管理员密钥；
- Runtime Token 不能管理 Computer、Member、Channel 或其他 Agent；
- Runtime 直接使用自身 IM SDK 回复，不通过平台伪装其他用户。

## 7. Computer 与 TAT

- 创建、修改、移除 Computer：Owner/Admin；
- 生成外部 Computer 结构化注册材料：Owner/Admin；
- 打开 PTY：Owner/Admin；
- 仍有 active Agent 绑定的 Computer 不可移除；
- 平台只允许固定 TAT 模板，不暴露任意 RunCommand；
- `StartSession` 只允许目标 Computer 的授权 Human；
- TAT 注册材料和 PTY session 信息不缓存、不记录、不向普通 Member 暴露；
- 移除 Computer 不销毁或关机真实实例。

## 8. Task 与 Reminder

Task：

- active Member 可创建；
- creator、Owner/Admin 可指派、验收、退回、关闭或重新打开；
- Human 没有 Task claim 权限，也不会成为执行 owner；
- Runtime Token 只能查看和更新当前 Agent 负责的 Task；
- Runtime 更新必须匹配 Task revision；
- Runtime 不能把 owner 改为其他成员；
- sourceMessageRef 不授予聊天访问权。

Reminder：

- active Member 可为 Server 内 Agent 创建；
- creator 可修改/取消自己的 Reminder；
- Owner/Admin 可管理全部；
- Runtime 只能查询和确认当前 Agent 的 occurrence。

## 9. 腾讯云调用

- 腾讯云管理员 API 只由服务端 Worker 和 PTY Session handler 调用；
- TencentOperation 从数据库映射推导资源 ID；
- 外部请求不能提供任意腾讯 UserID、GroupId、TopicId 或 TAT InstanceId 覆盖；
- 云凭证只从 Secret Manager 注入；
- 腾讯普通配额不用于给终端签发管理能力；
- 所有高权限调用记录脱敏审计。

## 10. TDSQL 隔离

- Server 资源查询必须同时携带 serverId 和 resourceId；
- Runtime Token 固定 serverId，忽略客户端尝试覆盖；
- Account 资源从 JWT accountId 路由；
- 数据库不使用外键，Repository 必须显式验证同 Server 归属；
- 全局邮箱、slug、TAT instance 唯一性只由对应 registry 写事务建立；
- 非白名单业务不能开启跨 shardkey 事务；
- 缺失 shardkey 不允许退化为在线全分片搜索；
- 恢复扫描使用独立运维身份、严格超时和批次上限。

## 12. HTTP 映射

| 类别 | HTTP |
|---|---:|
| 未认证 | 401 |
| 无权限/无 Server 可见性 | 403 或统一 404 |
| 不存在 | 404 |
| revision/idempotency/状态冲突 | 409 |
| 参数或 schedule 无效 | 422 |
| 限流 | 429 |
| 异步受理 | 202 |
| 腾讯云暂不可用 | 503 |

429 带 `Retry-After`。异步腾讯云错误通过 operation 查询返回，不伪装同步成功。

## 13. 日志与信息暴露

永不记录：

```text
password
refresh/access token
Human/Agent UserSig
Runtime credential
腾讯云 Secret/签名
TAT 注册码与结构化注册材料
PTY WebSocket URL/token/输入输出
普通聊天正文和附件 URL
```

普通 Member 不读取 Computer 详情、TAT 结果、Runtime 本机配置或内部错误原文。跨
Server ID 组合统一返回不可枚举结果。
